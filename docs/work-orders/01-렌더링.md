# 작업 지시서 01 — 렌더링 기반

담당: 메인. 소유 파일: `src/scene/SceneSetup.ts`, `src/models/materials.ts`, `src/models/thumbnails.ts`.

## 목표
"밋밋하고 떠 보이는" 화면을 **스튜디오에서 촬영한 제품 사진**처럼 — 금속이 금속으로 읽히고, 부품이 바닥과 서로에게 접지되어 보이게.

## 구성

| 항목 | 내용 |
|---|---|
| 재질 | `materials.ts` 공용 PBR 라이브러리(강재·크롬·주철·알루미늄·황동·청동·구리·고무·도장·플라스틱·목재·유리·ghost·glow). 헤어라인/미세 노이즈 맵 공유 |
| 환경맵 | 자체 스튜디오 씬(하늘 그라데이션 + 소프트박스 2 + 스트립 라이트 3) → PMREM. 평면 강재에도 하이라이트 띠 |
| 조명 | 키(그림자 2048, PCF Soft) + 필 + 림 + 반구광. 테마별 강도 표 `THEMES` |
| 후처리 | `EffectComposer`(MSAA×4, HalfFloat) → `GTAOPass`(앰비언트 오클루전) → `OutputPass`(ACES 톤매핑) |
| 테마 | `setTheme('light' \| 'dark')` — 배경 그라데이션·안개·바닥·격자·노출·AO 강도 일괄 전환 |
| 품질 | `setQuality('high' \| 'low')` — low는 후처리 생략·픽셀비 1.25·그림자 1024. 2초가량 30fps 미만이면 자동 하향(`onAutoLowQuality`) |
| 카메라 | `flyTo(view, immediate?)` — 미션별 `MachineDef.view`로 부드럽게 이동. 사용자가 조작을 시작하면 즉시 중단. 세로 화면은 수직 화각 자동 보정 |

## 주의 (실제로 겪은 문제)
- **GTAO 법선 패스의 검은 사각형**: `scene.background`가 텍스처면 three가 내부 평면 메시로 배경을 그리는데, 법선 패스의 `overrideMaterial`이 여기에도 걸려 원점에 2×2 검은 사각형이 찍힌다.
  → `overrideVisibility`에서 `scene.background = null`로 비웠다가 `restoreVisibility`에서 복원.
- 법선 패스에서 제외해야 하는 것: 스프라이트(라벨), 선, 슬롯 링(`userData.slot`), 보조 메시(`userData.noAO`), 투명 재질(유리·ghost) — 제외하지 않으면 라벨 자리가 검게 타거나 유리가 불투명 AO를 만든다.
- 썸네일 전용 렌더러(`thumbnails.ts`)에도 환경맵이 있어야 금속이 검게 나오지 않는다.

## 검증
- `preview.html?parts=all`, 기계별 캡처를 light/dark 모두 확인. AO 끈 화면(`&q=low`)과 비교.
- 저사양 대응: `q=low`에서도 화면이 깨지지 않는지.
