# 작업 지시서 03 — 기계요소 부품 22종 재모델링

먼저 `00-개요.md`를 읽는다. 소유 파일: `src/models/factory.ts`, 필요하면 `src/models/parts/*.ts`(신규 분할).

## 목표

부품 패널 썸네일·도감·퀴즈·조립 비행 애니메이션에 쓰이는 22종 부품을 **교과서 삽화 수준으로 한눈에 구별되는 실물감 있는 모델**로 다시 만든다.
현재 모습: `shots/parts-before.png` (원기둥·상자 조합 수준).

## 유지할 계약

- `buildPart(builder: BuilderId): THREE.Group` — 22종 모두. 반환 그룹은 원점 근처, 최대 변 0.8~1.6 정도(이후 `normalizePart`가 정규화).
- `normalizePart`, `disposeObject`, `mat`, `ChainPath2D`(수식 그대로), `buildChainAlongPath(path, linkPitch, z)`,
  `gearShape(teeth, r, toothH, tipFrac)`, `buildSpurGearMesh(teeth, r, toothH, depth, color)`,
  `buildHelicalGearMesh(...)`, `buildBevelGearMesh(...)` — **이름·인자·반환 타입 유지**.
  기계 파일(Bicycle/Clock/Treadmill/Steering)이 이 함수들을 직접 쓴다. 치형·모따기 등 내부 품질은 자유롭게 개선.
  - `buildChainAlongPath`가 만든 자식들의 `userData.s`(경로 호장거리)는 유지 — 자전거가 체인 애니메이션에 쓴다.
  - `gearShape`의 반환은 축 구멍 없는 외곽 Shape, 바깥 반지름 r, 이뿌리 r - toothH 를 유지.
- 재질은 `materials.ts` 사용. `mat()`은 호환용으로 남긴다.

## 부품별 요구

| id | 핵심 식별 요소 (이게 안 보이면 실패) |
|---|---|
| bolt 나사(볼트와 너트) | 육각 머리(모따기), **실제 나선 나사산**, 축에 반쯤 끼워진 육각 너트 + 와셔 |
| pinParallel 평행 핀 | 굵기 일정, 양끝 모따기. 테이퍼 핀과 나란히 놓아도 구별되게 |
| pinTaper 테이퍼 핀 | 눈에 띄는 기울기(1:6 이상 과장), 굵은 쪽 끝 둥글림 |
| pinSplit 분할 핀 | 반원 단면 두 가닥, 고리 머리, 끝이 벌어진 형태 |
| axle 차축 | 양끝 나사부 + 너트, 중앙 허브 접촉부(고정축임이 드러나게 평면 가공부) |
| driveShaft 전동축 | 키 홈(keyway), 단차(계단) 축, 한쪽 끝 플랜지 또는 유니버설 조인트 |
| crankShaft 크랭크축 | 메인 저널–크랭크 암(웹)–크랭크 핀–균형추. 자전거가 아닌 일반 크랭크축 형상 |
| bearing 볼 베어링 | 내륜·외륜(궤도 홈), 볼 8~10개, 리테이너(케이지). 단면이 보이게 일부 컷어웨이 권장 |
| spring 스프링 | 압축 코일 스프링, 양끝 좌권(끝이 평평하게 감김) |
| blockBrake 블록 브레이크 | 바퀴 림 일부 + 브레이크 암 + 고무 블록 + 케이블 |
| discBrake 디스크 브레이크 | 통풍 구멍 뚫린 디스크 + 허브 + 캘리퍼(빨강) + 패드 |
| frictionWheel 마찰차 | 맞닿은 두 원판(가장자리 고무 띠), 각자의 축 |
| spurGear 평 기어 | **인벌류트풍 곡선 치형**, 허브·키 홈, 웹 경량 구멍 |
| helicalGear 헬리컬 기어 | 비스듬한 이가 매끈하게(층 계단이 보이지 않게 — 프로파일을 비틀어 직접 메시 생성) |
| bevelGear 베벨 기어 | 원뿔면 위의 이, 꼭짓점을 향해 수렴. 직각으로 맞물린 2개 한 쌍 |
| wormGear 웜과 웜 기어 | 나사 모양 웜(실제 나선 솔리드) + 오목한 이의 웜 휠(청동), 축이 엇갈림 |
| rackPinion 래크와 피니언 | 직선 래크(사다리꼴 이) + 피니언, 실제로 맞물리는 피치 |
| beltPulley 벨트와 풀리 | V홈 풀리 2개(크기 다름) + 납작한 벨트(튜브 말고 띠 단면) |
| sprocket 스프로킷 | 롤러 체인용 치형(둥근 이골), 경량 구멍 |
| chain 체인 | 안/바깥 플레이트(8자형) + 롤러 + 핀. InstancedMesh 권장 |
| cam 캠 | 달걀형 판 캠 + 축 + 롤러 종동절 + 가이드 |
| link 링크 | 4절 링크(크랭크–커넥팅 로드–레버–고정 링크), 핀 조인트 |

## 방법 힌트

- 인벌류트풍 치형: 압력각 20° 기준으로 이 측면을 인벌류트 곡선 6~8점 샘플링, 이끝·이뿌리 필렛.
- 나선(나사산·웜): 단면 프로파일을 축 따라 회전·이동시키며 직접 BufferGeometry 인덱싱(튜브 감기 금지 — 솔리드처럼 보여야 한다).
- 회전체는 `LatheGeometry`로 프로파일(모따기·홈 포함)을 돌려 만든다.
- 파일이 길어지면 `src/models/parts/` 아래로 나누고 `factory.ts`는 조립·export만.

## 검증

- `node scripts/shot.mjs "preview.html?parts=all" shots/03-parts.png` + 부품별 근접 캡처(`?part=id`) 22장을 직접 확인.

- 기계 4종(bicycle/clock/treadmill/steering)이 여전히 동작하는지 `?machine=...&steps=all&t=2` 로 확인(다른 작업자가 동시에 고치는 중일 수 있음 — 에러가 내 변경 때문인지 구분해 보고).
