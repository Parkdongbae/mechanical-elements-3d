## 4. 공통 규칙

### 4-1. 깨지면 안 되는 계약
- `src/machines/types.ts`의 `Machine` 인터페이스, `MachineDef`의 `id`·`steps[].partId` 순서
- `src/models/factory.ts`의 export 시그니처: `mat`, `gearShape`, `buildSpurGearMesh`, `buildHelicalGearMesh`,
  `buildBevelGearMesh`, `ChainPath2D`, `buildChainAlongPath`, `buildPart`, `normalizePart`, `disposeObject`
  (기계 파일들이 직접 import 한다 — 시그니처 유지, 내부 품질만 개선)
- 진행도 localStorage 키 `mech3d-progress-v2` 구조
- 교과서(2022 개정 미래엔 기술·가정② 5단원) 4분류·명칭. 학습 문구를 바꿀 때 명칭을 임의로 바꾸지 않는다.

### 4-2. 재질
- 모든 메시는 `src/models/materials.ts`의 함수로 재질을 만든다:
  `steel() darkSteel() chrome() castIron() aluminum() brass() bronze() copper() rubber() paint(color) plastic(color) wood() glass() ghost() glow(color)`
- 직접 `new THREE.MeshStandardMaterial`을 쓰는 것은 위 함수로 표현 불가능할 때만.
- 함수는 호출마다 새 재질을 반환한다. 같은 재질을 여러 메시에 쓸 때는 변수에 담아 재사용(드로콜·메모리 절약).
  단, 개별로 emissive/opacity를 바꿔야 하는 메시는 전용 인스턴스를 쓴다.

### 4-3. 모델링 품질 기준
- 좌표 단위: three 단위 1 ≈ 실물 약 0.3~0.4m 감각. 기계 전체가 대략 반경 3 안에 들어오게.
- 원기둥 세그먼트는 지름에 맞게: 굵은 것 32~48, 가는 축 16~24. 육안으로 각이 보이면 안 된다.
- 모서리는 모따기/필렛(Extrude bevel, LatheGeometry 프로파일, 얇은 토러스)으로 하이라이트가 잡히게.
- 겹쳐 박힌 도형(z-fighting, 관통)이 보이지 않게. 떠 있는 부품이 없게(모든 부품은 무언가에 붙어 있어야 한다).
- 메시에 `castShadow = true`, 큰 면에는 `receiveShadow = true`.
- 성능: 기계 1개 총 삼각형 40만 이하, 드로콜 250 이하. 반복 부품(체인 링크, 볼트, 톱니)은 `InstancedMesh` 또는 지오메트리 병합.
- 움직이는 부품은 **물리적으로 말이 되게**: 맞물린 기어는 접점 속도가 같고 방향이 반대, 벨트·체인은 풀리 접선을 따른다.

### 4-4. 코드
- TypeScript strict + `noUncheckedIndexedAccess`. `any` 금지. 주석은 한국어, "왜"만.
- 새 의존성 추가 금지(three, cannon-es만 사용). three/examples/jsm 은 사용 가능.
- 3D 라벨(스프라이트·지시선)은 `layers.set(1)` (라벨 토글 대상). 슬롯 링 등 AO에서 제외할 보조 메시는 `userData.noAO = true`.

## 5. 시각 검증 방법 (필수)

dev 서버는 이미 `http://localhost:5173` 에 떠 있다(다시 띄우지 말 것). HUD 없는 미리보기 페이지를 헤드리스 Chrome으로 캡처한다.

```bash
node scripts/shot.mjs "preview.html?part=spurGear" shots/spur.png
node scripts/shot.mjs "preview.html?parts=all" shots/parts.png
node scripts/shot.mjs "preview.html?machine=bicycle&steps=0" shots/bike0.png
node scripts/shot.mjs "preview.html?machine=bicycle&steps=all&t=2" shots/bike-run.png 5000
# 옵션: &theme=dark  &cam=x,y,z,tx,ty,tz (카메라 위치/타깃)  &t=초 (시뮬레이션을 그 시점에 정지)  &labels=0
```

- 캡처한 PNG를 **직접 열어 눈으로 확인**한다(Read 도구). 최소 2개 각도 + 다크 테마 1장.
- 움직임은 `&t=1`, `&t=1.5` 처럼 시점을 달리해 2장 비교(회전 방향·관통·분리 확인).
- `shots/`는 gitignore 대상. 파일명 앞에 자기 작업 번호를 붙인다(예: `shots/03-spur.png`).
- 타입 검사: `npx tsc --noEmit` — **자기 소유 파일의 에러만 책임**진다(다른 작업자의 작업 중 에러는 무시하고 보고).
- 브라우저 패널(Claude_Browser)은 메인 작업자가 사용 중이므로 쓰지 않는다.
