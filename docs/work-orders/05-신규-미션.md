# 작업 지시서 05 — 신규 미션 3종

먼저 `00-개요.md`를 읽는다. 그다음 `src/machines/types.ts`, `src/data/machines.ts`(automata/discbrake/wiper 정의),
참고 구현으로 `src/machines/Treadmill.ts`와 `src/machines/Steering.ts`(2단계 미션의 전형), `src/models/factory.ts`, `src/models/materials.ts`.

소유 파일: `src/machines/CamAutomata.ts`, `src/machines/DiscBrakeRig.ts`, `src/machines/Wiper.ts` (지금은 임시 스텁 — 전부 교체).

## 공통 계약

- `BaseMachine` 상속, 클래스명·`id`는 스텁 그대로(`automata`, `discbrake`, `wiper`). `stepCount = 2`.
- 미션 흐름: 미완성 기계가 보이고 빈 자리에 초록 슬롯 링이 펄스 → 사용자가 하단 패널에서 정답 부품 선택 →
  main이 `buildStepModel(step)` 모델을 `getFlyTarget(step)`으로 날린 뒤 `installStep(step, model)` 호출 → 2단계 완료 시 `createSim()` 가동.
- `buildStepModel`은 **이 기계에 실제로 장착될 모양**의 부품을 만든다(패널 썸네일의 일반 부품과 달라도 됨).
  `installStep`에서 `model.position` 등을 기계 좌표로 다시 맞춘다(이중 오프셋 주의).
- `slotTarget(step)`: 오답 부품이 날아와 부딪힐 지점(슬롯 위치). `reset()`: 설치 부품 제거·슬롯 복원·애니메이션 상태 초기화.
- `createSim().getDisplay()`: 우측 정보 패널에 2~3개 수치(`{label, value, unit, tone}`) — 학습 포인트가 되는 수치.
- 순차 슬롯: 1단계 설치 시 `hideSlot(0); showSlot(1)`.
- 부품 이름 라벨이 필요하면 스프라이트를 만들고 `layers.set(1)`.

## 1) 캠 오토마타 — `CamAutomata` (id `automata`)
- 단계: ① 전동축(`driveShaft`) ② 캠(`cam`)
- 모습: 나무 상자 프레임(앞면 개방 또는 투명 아크릴)의 **오토마타 장난감**. 옆면에 크랭크 손잡이, 윗판에 구멍 3개와
  종동절(수직 막대), 막대 위에 단순한 인형/동물 3개(색이 다른 귀여운 형상 — 저폴리 새·물고기·별 등).
- ① 전동축: 상자를 가로지르는 축 자리가 비어 있음(양쪽 베어링 구멍만). 설치하면 손잡이와 연결.
- ② 캠: 축 위에 캠 3개(위상 120°씩 차이, 형상은 달걀형·편심 원·하트형 등으로 달리하면 좋다).
- 시뮬레이션: 손잡이·축 회전(약 40rpm) → 각 캠 윤곽을 **실제로 계산**해 종동절이 캠 표면에 붙어 오르내림(관통·이격 없음).
- 표시: 손잡이 회전수(rpm), 캠 1회전당 왕복 횟수(1회), 종동절 이동 거리(행정, cm).

## 2) 디스크 브레이크 — `DiscBrakeRig` (id `discbrake`)
- 단계: ① 볼 베어링(`bearing`) ② 디스크 브레이크(`discBrake`)
- 모습: 자동차 **앞바퀴 코너 모듈**을 정비대에 올린 모습 — 너클/허브 캐리어, 스트럿(스프링+쇽업소버), 휠+타이어.
  바퀴 안쪽이 보이도록 휠은 스포크 사이가 뚫린 알로이 휠, 카메라는 안쪽 3/4 뷰.
- ① 볼 베어링: 허브 중앙의 베어링 자리. 설치 전에는 바퀴가 장착되지 않은 상태로 옆에 대기 → 설치 후 바퀴가 장착되고(follow-up 또는 installStep 내 연출) 천천히 회전 시작 가능.
- ② 디스크 브레이크: 통풍 디스크 + 캘리퍼(빨강) + 패드 한 조.
- 시뮬레이션(주기 약 6초 반복): 가속 → 정속 회전 → **브레이크 작동**(패드가 디스크를 실제로 집는 이동, 캘리퍼 강조, 디스크가 마찰열로 붉게 발광) → 감속 정지 → 해제.
- 표시: 바퀴 회전수(rpm), 브레이크 상태(작동/해제 — tone red/blue), 주행 속도(km/h, 타이어 지름 기준 환산).

## 3) 와이퍼 — `Wiper` (id `wiper`)
- 단계: ① 웜과 웜 기어(`wormGear`) ② 링크(`link`)
- 모습: 자동차 **앞유리(곡면 `glass`) + 카울 패널** 일부. 유리 아래에 와이퍼 모터(원통 모터 + 기어 하우징, 하우징은 `ghost`로 내부가 보임),
  와이퍼 암 2개 + 블레이드. 유리에 빗방울(작은 반구/점 인스턴스)이 있으면 닦이는 느낌이 산다(선택).
- ① 웜과 웜 기어: 모터 축의 웜 + 출력축의 웜 휠. 설치 전에는 모터만 헛돈다(축 끝 마커가 빠르게 회전).
- ② 링크: 웜 휠의 크랭크 → 연결 로드 → 두 와이퍼 피벗의 레버(4절 링크 2조).
- 시뮬레이션: 모터(빠름, 예: 3000rpm 표시 — 화면에서는 시각적으로 빠르게) → 웜 기어 감속(1/50 등 실제 잇수비로 계산) → 크랭크 회전 →
  **4절 링크 기구학을 실제로 풀어서**(크랭크-로커) 와이퍼 암이 약 100° 왕복. 로드 길이가 변하지 않아야 한다.
- 표시: 모터 회전수, 웜 휠 회전수(감속비 명시), 와이퍼 왕복 횟수(회/분).
