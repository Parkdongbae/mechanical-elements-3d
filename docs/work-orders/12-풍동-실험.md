# 작업 지시서 12 — 탐구 실험: 풍동 실험 (맛보기 CFD)

먼저 `00-개요.md`와 `11-탐구-실험-3종.md`의 "공통 구조"(AppMode, 패널·스타일·검증 규칙)를 읽는다.

## 사용자 요청 (원문 요지)
- 풍동 실험 메뉴를 만든다. 전산유체역학(CFD) 기법을 **중·고등학생 수준**으로 체험하게 한다. **실제 데이터 기반이 아닌 맛보기**면 된다.
- 테슬라처럼 **도어 손잡이가 감춰진 것** 같은 설계를 학생이 직접 **비교**할 수 있어야 한다.
- **공기저항계수 측정, 주행 안정성(다운포스) 검증, 풍절음 개선**을 모두 확인. **풍절음은 실제로 소리가 들려야** 한다.
- **사이드미러, A필러, 도어 틈새, 자동차 하부 처리** 등으로 공기저항계수가 내려가는지 올라가는지 확인할 수 있어야 한다.
- 고속 주행 시 **다운포스가 없으면 코너링과 직진 안정성이 어떻게 되는지** 직접 확인할 수 있어야 한다.

## 정직성 원칙 (중요)
- 화면에 항상 보이는 한 줄: **"학습용 맛보기 모델이에요. 수치는 경향을 보여 주기 위한 값이며 실제 자동차의 측정값이 아닙니다."**
- 특정 실차의 수치라고 표시하지 않는다. 브랜드명은 쓰지 않는다("매립형 손잡이(전기차에서 많이 쓰는 방식)" 정도).
- 값의 **방향(오르내림)과 상대적 크기**는 공기역학 상식과 맞아야 한다(돌출물·틈·거친 하부 → 저항·소음 증가, 매끈한 형상 → 감소, 스포일러 → 다운포스 증가와 약간의 저항 증가).
- 물리 공식은 실제 그대로: 항력 **F = ½·ρ·v²·Cd·A**, 양력/다운포스 **L = ½·ρ·v²·Cl·A**, 필요한 동력 **P = F·v** (ρ = 1.2 kg/m³, A는 상수로 명시). 화면에 식과 대입 값을 보여 준다.

## 구성 — 상단 탭 3개

### ① 공기저항 (Cd 측정)
- **3D 풍동**: 풍동 안(바닥·벽 격자, 앞쪽 송풍 팬 암시)에 세단형 자동차. 바람은 앞에서 뒤로.
  - **유선(streamline) 시각화**: 입자/선이 차체를 타고 흐르고, 속도에 따라 색이 변한다(빠름 → 따뜻한 색). 돌출물 뒤와 차 뒤에는 **소용돌이(후류) 영역**이 생기고, 선택한 부품에 따라 그 크기가 달라진다.
    맛보기 유동 모델이면 된다: 차체를 감싸는 타원체/상자 주위의 퍼텐셜 유동 근사 + 부품별 국소 교란(난류 볼륨에서 입자에 무작위 소용돌이 속도 추가) 정도. 입자는 `THREE.Points` 또는 얇은 리본(InstancedMesh)으로 수천 개까지, 60fps 유지.
  - **압력 분포 보기 토글**: 차체 표면을 정체점(앞 범퍼·앞유리 아래)은 빨강, 가속 구간(지붕)은 파랑으로 색칠(정점 색, 맛보기 식: Cp ≈ 1 − (국소 속도/자유류 속도)²).
- **부품 선택(각 항목 2~3가지, 누르면 3D가 실제로 바뀐다)**:
  | 항목 | 선택지 (왼쪽이 저항 큼) |
  |---|---|
  | 도어 손잡이 | 돌출형 / **매립형(히든)** |
  | 사이드미러 | 큰 사각 미러 / 유선형 미러 / 카메라 미러(소형) |
  | A필러 | 각진·세운 필러 / 둥글고 눕힌 필러 |
  | 도어 틈새 | 넓은 틈·단차 / 좁은 틈 + 고무 실링 |
  | 하부 처리 | 노출(배기관·서스펜션이 드러남) / 평평한 언더커버 / 언더커버 + 디퓨저 |
  | 휠 | 열린 스포크 휠 / 에어로 휠 커버 |
  | 뒤 스포일러 | 없음 / 립 스포일러 / 큰 윙 |
  | (선택) 차고 | 높음 / 낮음 |
- **결과 패널**: Cd(큰 숫자, 변화량 ▲▼ 색 표시), 항력(N), 그 속도에서 공기저항을 이기는 데 필요한 동력(kW), 항목별 기여도 막대(어떤 부품이 Cd를 얼마나 올리고 내렸는지).
- **풍속 슬라이더**: 0~200 km/h. 속도를 2배로 하면 항력은 4배, 동력은 8배가 되는 것을 그래프(속도–항력 곡선, 현재 점 표시)로.
- **비교 기능(핵심)**: "현재 설정을 A로 저장" → 설정을 바꾸면 A 대비 B의 Cd·항력·소음·다운포스 차이를 나란히 표시. "모두 기본형"/"모두 공력 최적화" 프리셋 버튼. 화면 분할까지는 필요 없고 수치·막대 비교면 된다(가능하면 A의 유선을 옅게 겹쳐 보여 주기).

### ② 주행 안정성 (다운포스)
- **개념 표시**: 차를 누르는 힘(다운포스, 아래 화살표)과 띄우는 힘(양력, 위 화살표)이 속도에 따라 커지는 것을 3D 화살표로. 앞·뒤 축 하중(무게 + 다운포스)을 수치로.
  타이어가 낼 수 있는 최대 횡력 ≈ **μ × (차 무게 + 다운포스)** 임을 식으로 보여 준다(μ, 차 질량 상수 명시).
- **코너링 시험(직접 확인)**: 위에서 본(또는 3/4 시점) 원형/S자 코스에서 차가 설정한 속도로 주행. 버틸 수 있는 최대 코너 속도 **v_max = √(μ·(g + L/m)·r)** (L은 그 속도의 다운포스 — 양력이면 음수).
  설정 속도가 한계를 넘으면 차가 **바깥으로 미끄러져 코스를 이탈**(타이어 자국, 경고), 스포일러·디퓨저를 달아 다운포스를 키우면 같은 속도로 통과. 같은 조건에서 "다운포스 없음" 유령 차와 나란히 달리게 하면 차이가 한눈에 보인다.
- **직진 안정성 시험**: 고속 직선 주행 중 **옆바람 돌풍**이 분다. 다운포스가 없거나 양력이 큰 설정은 차가 크게 흔들리고 차선에서 밀려나며, 다운포스가 있으면 흔들림이 작다(접지 하중이 클수록 횡변위·요 흔들림이 작아지는 단순 모델). 차선 이탈 거리(m)를 수치로.
- 속도 슬라이더(80~250 km/h), 부품 설정은 ①과 공유(스포일러·디퓨저·하부·차고가 Cl에 영향). "다운포스를 키우면 저항도 조금 늘어난다"는 trade-off를 수치로 확인할 수 있게.

### ③ 풍절음 (소리로 확인)
- **실제 소리 재생(Web Audio API)**: "소리 듣기" 버튼(사용자 동작 후 AudioContext 시작, 다시 누르면 정지, 음량 슬라이더). 탭을 떠나거나 `exit()` 하면 반드시 정지·해제.
  - 기본 바람 소리: 필터를 건 노이즈(브라운/핑크 계열), 속도가 오르면 음량과 컷오프 주파수가 함께 오른다(음압은 대략 속도의 5~6제곱에 비례 — 화면 dB 표시는 맛보기 식).
  - 부품별 소리 성분을 **귀로 구분되게**: 사이드미러·A필러 → 중고역의 거친 바람 소리(대역 통과 노이즈) 증가, 도어 틈새 → **휘파람 같은 좁은 대역의 음(공명 필터, 속도에 따라 음높이 변화)**, 돌출 손잡이 → 약한 고역 쉿 소리, 하부 노출 → 저역 웅웅거림.
  - 설정을 바꾸면 소리가 즉시 부드럽게 바뀐다(게인 램프). "A/B 번갈아 듣기" 버튼.
- **표시**: 실내 소음 추정 dB(맛보기), 주파수 막대(AnalyserNode 스펙트럼) 또는 부품별 소음 기여 막대, 3D에서는 소음이 나는 부위에 물결 표시.
- 소리를 켤 수 없는 환경(교실)에서도 막대·스펙트럼으로 차이를 볼 수 있어야 한다.

## 검증
- `node scripts/shot.mjs "preview.html?mode=wind" shots/12-wind.png 5000`, 모바일 `... 5000 390 844`, 다크 `&theme=dark`.
- 자체 playwright 스크립트로: 부품을 하나씩 바꾸며 Cd가 기대 방향으로 변하는지 수치 추출·기록, 탭 ②에서 다운포스 유/무로 코너 이탈/통과가 갈리는지, 탭 ③에서 AudioContext가 running이 되고 설정 변경 시 게인/필터 값이 바뀌는지(`page.evaluate`로 확인) 캡처와 함께 확인.
- 보고서에 부품별 Cd·Cl·dB 변화표(기본형 → 각 옵션)와 손계산 검산(예: 120km/h, Cd 0.30, A 2.2㎡ → F = ½·1.2·33.3²·0.30·2.2 ≈ 440N) 포함.
- `npx tsc --noEmit` 자기 파일 에러 0. 60fps 유지(입자 수 조절), `exit()` 후 오디오·씬·리스너 누수 없음.
