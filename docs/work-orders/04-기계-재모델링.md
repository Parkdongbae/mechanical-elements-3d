# 작업 지시서 04 — 절차 생성 기계 4종 재모델링

먼저 `00-개요.md`를 읽는다. 그다음 자기 담당 파일 전체와 `src/machines/types.ts`, `src/data/machines.ts`(해당 기계의 steps),
`src/models/factory.ts`(쓰는 함수), `src/models/materials.ts`를 읽는다.

- **04-A**: `src/machines/Bicycle.ts`, `src/machines/Clock.ts`
- **04-B**: `src/machines/Treadmill.ts`, `src/machines/Steering.ts`

## 목표

기계 본체가 "도형 조합"이 아니라 **실물 기계처럼 보이게** 다시 모델링한다. 미션 로직은 그대로 둔다.

## 유지할 것 (바꾸면 미션이 깨진다)

- 클래스명, `id`, `stepCount`, 단계 순서와 각 단계가 뜻하는 부품(`machines.ts`의 steps와 1:1)
- `Machine` 인터페이스 메서드의 의미: `buildStepModel(step)`이 만든 모델을 main이 날려 보낸 뒤 `installStep(step, model)`로 넘긴다.
  `getFollowUps/installFollowUp`(자전거의 바퀴·앞 스프로킷 자동 장착)도 유지.
- `reset()` 후 다시 조립 가능, `createSim()`의 표시 항목(label/value/unit)과 수치 관계(기어비·rpm)
- 슬롯 링: `addSlot/hideSlot/showSlot` 패턴. 슬롯 위치는 새 모델의 실제 장착 위치에 맞춰 옮겨도 된다.
- HANDOFF.md 8-3의 과거 버그 재발 금지(체인이 스프로킷 안쪽을 감음, 크랭크축 이중 오프셋 등).

## 기계별 요구

### 자전거 (04-A)
- 프레임: 다이아몬드 프레임 비례(헤드튜브 각 ~72°, 시트튜브 각 ~73°), 튜브 접합부가 매끈하게, 드롭아웃, 광택 도장(`paint`).
- 포크·핸들바·스템·그립, 안장(곡면)과 시트포스트, **안장 밑 스프링 자리(6단계)**.
- 바퀴: 타이어(트레드 느낌), 림, 허브, **스포크 28~32개**(InstancedMesh), 밸브. 회전이 보이게 스포크/밸브가 드러나야 한다.
- 구동계: 크랭크 암·페달, 체인링(앞 스프로킷)·뒤 스프로킷은 factory의 스프로킷 치형, 체인은 `buildChainAlongPath`.
- 완료 시: 페달 60rpm → 뒷바퀴 100rpm(1.67), 체인 이동, 평행 핀이 체인을 따라 이동(기존 동작 유지).
- 받침: 뒷바퀴가 떠서 도는 **정비 스탠드**를 모델링해 "공중에 뜬 자전거" 느낌을 없앤다.

### 시계 (04-A)
- 무브먼트가 보이는 **스켈레톤 벽시계/탁상시계**: 문자판 링(숫자 눈금), 시침·분침, 앞 유리(`glass`), 받침 또는 케이스.
- 뒤쪽/내부에 태엽통(배럴)과 기어 트레인이 보이게. 태엽(1단계)·평 기어(2단계) 자리가 잘 보여야 한다.
- 기어는 황동(`brass`), 지지판은 `aluminum`/`darkSteel`, 축(아버)에 보석 베어링 느낌의 작은 포인트.
- 완료 시 기존 rpm 관계 유지(태엽 드럼 → 분침 → 시침), 맞물린 기어 방향 정확히.

### 러닝머신 (04-B)
- 데크 프레임, 앞·뒤 롤러, **주행 벨트(납작한 띠, 텍스처로 이동이 보이게 줄무늬/로고 마커)**, 모터(권선·방열핀), 모터 커버는 반투명(`ghost`)으로 내부가 보이게.
- 손잡이 기둥·콘솔(화면 발광), 측면 발판 레일.
- 볼 베어링(1단계) 자리는 롤러 축 끝 베어링 하우징, 벨트와 풀리(2단계)는 모터 풀리–롤러 풀리 구동 벨트.
- 완료 시: 모터 롤러 60rpm → 벨트 1.13m/s, 윗면이 뒤로 흐름(기존 유지).

### 자동차 핸들(조향 장치) (04-B)
- 스티어링 휠(림·스포크 3개·혼 패드), 기울어진 컬럼, 유니버설 조인트, **래크 하우징(반투명 컷어웨이)**, 타이로드, 너클, 앞바퀴 2개(타이어 트레드·휠).
- 서브프레임/크로스멤버로 바퀴와 래크가 한 구조물에 붙어 있게(떠 있는 부품 금지).
- 래크와 피니언(1단계)은 하우징 안에서 맞물림이 보이게, 링크(2단계)는 타이로드.
- 완료 시: 핸들 ±55° → 래크 ±29cm → 바퀴 조향(기존 유지). 피니언 회전과 래크 이동이 피치로 일치.

## 카메라 시점 제안
기계가 가장 잘 보이는 시점을 찾아 보고서에 `view: { pos: [x,y,z], target: [x,y,z] }` 값으로 적는다(메인이 machines.ts에 반영).
캡처는 `&cam=` 옵션으로 확인.

## 검증
- `?machine=<id>&steps=0`, 단계별(`steps=1..n`), `steps=all&t=1` / `t=1.6` 두 시점, 다크 테마. 모두 직접 열어 확인.
- 캡처 파일명 접두어 `shots/04a-` 또는 `shots/04b-`.
