# 작업 지시서 02 — 메뉴·UI 재구성

담당: 메인. 소유 파일: `index.html`, `src/main.ts`, `src/ui/*`, `src/styles/tokens.css`, `src/styles/app.css`, `src/state/*`, `src/data/machines.ts`.

## v1의 문제
- 좌측 세로 버튼 목록 + **3단 호버 메뉴**(자동차 구동방식 → 내연기관/전기 → 차종): 태블릿에서 쓰기 어렵고 어디에 무엇이 있는지 보이지 않는다.
- 상단 바에 앱 제목·긴 미션 문장·칩·버튼이 한 줄로 몰려 잘린다.
- 부품 패널이 호버로 열리고 닫혀 의도치 않게 사라진다.
- 진행 상황(무엇을 끝냈는지)을 한눈에 볼 곳이 없다.

## v2 정보 구조

```
홈 (#/)
├─ 이어서 하기 / 전체 진행도(미션·도감·퀴즈)
├─ 학습 모드: 기계요소 도감(#/enc) · 단원 퀴즈(#/quiz)
└─ 미션 카드 15종 — 4묶음
   ├─ 생활 속 기계: 자전거, 시계, 러닝머신, 회전놀이기구, 캠 오토마타
   ├─ 자동차 장치: 자동차 핸들, 디스크 브레이크, 와이퍼
   ├─ 자동차 구동방식: FF, FR, AWD, 싱글 모터, 듀얼 모터
   └─ 기어와 구조물: 기어의 종류, 철골공사
미션 (#/m/<id>)
├─ 좌상단: 홈 버튼 + 묶음/미션 이름
├─ 상단 중앙: 미션 안내 + 단계 스테퍼(완료/현재/대기) → 완성 시 "다음 미션" 버튼
├─ 우상단: 힌트 · 다시하기 · 이름표 · 설정
├─ 우측: 동력 전달 수치 패널(+ 속도 슬라이더)
└─ 하단 독: 4대분류 버튼 → 부품 트레이(클릭으로 열고 닫음)
```

- 해시 라우팅: 뒤로 가기가 동작하고, 수업 시간에 특정 미션 링크를 바로 공유할 수 있다.
- 카드에는 정답(부품 이름)을 노출하지 않고 **필요한 분류의 색 점**과 단계 수만 보여 준다.
- 설정: 난이도(쉬움/보통/어려움) · 화면 테마(밝게/어둡게) · 그래픽 품질 · 효과음 · 진행도 초기화(확인 대화상자).

## 디자인 원칙
- 색·간격·그림자는 `tokens.css` 변수만. `<html data-theme>` 전환으로 밝음/다크 동시 지원.
- 4대분류 색(결합용 주황·축용 파랑·제어용 보라·전동용 빨강)을 UI와 3D 강조에 일관되게.
- 아이콘은 인라인 SVG(`ui/icons.ts`), 이모지는 미션 카드의 대체 그림에만.
- 터치 영역 44px 이상, 호버 전용 상호작용 금지, `:focus-visible` 표시, Esc로 패널 닫기.
- 반응형 기준: 1080px(도구 버튼 글자 숨김), 820px(모바일 레이아웃 — 미션 카드 2열, 독 전체 폭).

## 홈 카드 썸네일
`node scripts/thumbs.mjs` — 미리보기 페이지에서 각 미션의 완성 상태를 800×500으로 캡처해 `public/thumbs/<id>.jpg`에 저장. 모델을 바꾸면 다시 실행. 파일이 없으면 카드는 이모지 대체 그림을 보여 준다.

## 검증
- `node scripts/ui-flow.mjs <id> <light|dark> [w] [h]` — 트레이 열기 → 정답 선택 → 완료까지 자동 캡처.
- 1280×800 / 820×1180 / 390×844, light·dark 각각에서 겹침·잘림 확인.
