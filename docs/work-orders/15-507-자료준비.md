# 작업 지시서 15 — 「507 기계 운동」 자료 준비 (전사·번역·도판 좌표)

작성: Fable(메인) · 2026-11-24
전체 계획은 `16-507-전체계획.md`. 이 문서는 **앱 코드가 아닌 자료(데이터)** 를 만드는 일이다.

## 책
- Henry T. Brown, *Five Hundred and Seven Mechanical Movements* (초판 1868, 뉴욕). 공유 저작물.
- 원본: `mechanical_movements_507/Mechanical_Movements_507.pdf` — 138쪽 스캔본, **글자 층 없음**(쪽마다 그림 1장).
- 구성: 왼쪽 **도판 쪽**(번호 붙은 판화 9~10개가 칸에 들어 있음)과 오른쪽 **본문 쪽**(같은 번호의 설명)이 마주 본다.
  PDF 쪽 번호(0부터) 13 = 도판(1~10번), 14 = 본문(1~10번), 15 = 도판, 16 = 본문 … 이 번갈아 이어진다. 앞쪽(0~12)은 표지·서문·색인, 맨 뒤는 광고 등일 수 있다.

## 할 일 — 맡은 쪽 범위의 모든 (도판, 본문) 쌍에 대해

1. 쪽을 그림으로 뽑아 직접 본다: `python scripts/mm507/render_page.py <쪽> <출력.png> [dpi]` (본문은 dpi 130 이상 권장, 출력은 스크래치패드에).
2. **본문 전사**: 번호별 영어 원문을 정확히 옮긴다. 줄바꿈 하이픈은 이어 붙이고, 원문의 철자·문장부호·이탤릭 기호(a, b, A, B 같은 부품 기호)는 그대로. 읽기 어려운 낱말은 확대(dpi 200)해 다시 보고, 그래도 불확실하면 `[?]`를 붙인다. 한 번호의 설명이 다음 쪽으로 이어지면 이어 붙인다. 여러 번호를 한 문단에서 설명하면(예: "8. … 9. …") 번호별로 나눈다.
3. **번역·풀이**(중학생 대상, 한국어):
   - `titleKo`: 12자 안팎의 이름(예: "열린 벨트 전동", "엇걸이 벨트", "원뿔 풀리 변속"). 책에 이름이 없으면 내용에 맞게 짓는다.
   - `ko`: 원문의 충실한 번역(존댓말 '~합니다' 대신 설명문 '~한다' 체). 부품 기호는 원문대로.
   - `easy`: 2~3문장의 쉬운 풀이 — 무엇이 움직여서 무엇이 되는지, 어디에 쓰이는지. 원문에 없는 사실을 지어내지 않는다(쓰임새가 확실하지 않으면 생략).
   - `category`: 아래 중 하나 — `belt`(풀리·벨트·로프), `gear`(기어), `ratchet`(래칫·간헐 운동), `cam`(캠·편심), `crank`(크랭크·링크·레버), `escapement`(탈진기·시계), `governor`(조속기), `steam`(증기 기관·밸브 장치), `pump`(펌프·유체), `tool`(공구·클램프·기타 기구), `misc`.
   - `mech`: 3D 모델링용 메모(영어 또는 한국어, 3~6줄) — 판화에 보이는 부품 목록, 축의 방향, 어떤 부품이 구동(입력)이고 어떻게 움직이는지(회전/왕복/간헐, 방향, 속도비 추정), 판화에서 읽은 대략의 크기 비.
4. **도판 좌표**: 도판 쪽에서 번호별 판화의 영역을 구한다 — 쪽 그림에 대한 **정규화 좌표** `[x0, y0, x1, y1]`(0~1, 왼쪽 위 원점). 번호 글자와 그림 전체가 들어가고 이웃 그림·칸 선은 들어가지 않게.
   방법: 칸을 나누는 가는 선을 그림 처리(행·열 방향 어두운 화소 합)로 찾아 칸을 구한 뒤, 한 칸에 두 번호가 있으면(예: 8·9) 눈으로 보고 나눈다. 구한 영역으로 **실제로 잘라 낸 그림을 몇 개 열어 확인**한다.
5. 결과를 쌍마다 JSON 한 파일로 저장: `data/mm507/p<도판 쪽 3자리>.json`
```json
{
  "platePage": 13, "textPage": 14,
  "figures": [{ "n": 1, "box": [0.14, 0.26, 0.40, 0.44] }],
  "texts": [{
    "n": 1,
    "en": "Illustrates the transmission of power by simple pulleys and an open belt. In this case both of the pulleys rotate in the same direction.",
    "titleKo": "열린 벨트 전동",
    "ko": "단순한 풀리와 열린 벨트로 동력을 전달하는 모습이다. 이 경우 두 풀리는 같은 방향으로 회전한다.",
    "easy": "두 바퀴(풀리)에 벨트를 걸면 한쪽이 돌 때 다른 쪽도 같은 방향으로 돈다. 축이 멀리 떨어져 있어도 힘을 전할 수 있다.",
    "category": "belt",
    "mech": "Two equal pulleys on parallel horizontal shafts, one above the other; open flat belt. Driver = upper pulley; both rotate the same way, same speed."
  }]
}
```
6. 도판·본문이 아닌 쪽(표지, 서문, 색인, 광고)은 건너뛰되, 보고서에 "쪽 N: 무엇"을 적는다. 서문(Preface)은 역사 소개에 쓰므로 전사해 `data/mm507/preface.json`(`{ "page": n, "en": "...", "ko": "..." }`)에 넣는다(맡은 범위에 있을 때만).

## 규칙
- 수정·생성 가능: `data/mm507/*.json`과 스크래치패드의 임시 파일뿐. 앱 코드(`src/`), 다른 문서는 건드리지 않는다. git 명령 금지.
- 번호가 빠지거나 겹치지 않게: 맡은 범위의 첫 번호와 끝 번호, 번호 개수를 보고서에 적는다.
- 전사는 추측으로 채우지 않는다. 불확실한 곳은 `[?]`로 표시하고 보고서에 목록으로 적는다.

## 보고
맡은 쪽 범위, 만든 파일 목록, 번호 범위와 개수, `[?]` 표시한 곳, 건너뛴 쪽과 이유, 좌표를 눈으로 확인한 표본.
