# 작업 지시서 11 — 탐구 실험 3종 (변속·동력 전달)

먼저 `00-개요.md`(공통 규칙·재질·품질·검증 방법)를 읽는다.

## 배경 (사용자 요청)
기계요소 조립 미션과 별개로, **직접 조작하며 원리를 익히는 실험** 3개를 주메뉴(홈 '탐구 실험실')에 추가한다.
1. **자전거 기어 변속** — 요즘 자전거의 앞·뒤 스프로킷 개수를 실제대로 보여 주고, 학생이 앞·뒤 기어를 바꿔 보며 언제 쓰는지, 속도가 어느 정도인지 알게 한다.
2. **자동차 기어 변속** — FF 전륜구동 기준 5단 변속기를 학생이 직접 조작하고, 각 단을 언제 쓰는지와 속도를 알게 한다. **수동 변속기와 자동 변속기 두 가지** 모두.
3. **자동차의 동력 전달** — FR 후륜구동을 예로 엔진에서 바퀴까지 전체 과정을 알게 한다.

## 11-A 자전거 기어 변속 — `BikeGears`

- **실제 구성**: 요즘 많이 타는 구성을 고를 수 있게 한다(탭/세그먼트).
  - 생활·하이브리드 자전거 **3×7 = 21단**: 앞 체인링 48/38/28T, 뒤 스프로킷 14-16-18-20-22-24-28T
  - 로드 자전거 **2×11 = 22단**: 앞 50/34T, 뒤 11-12-13-14-15-17-19-21-23-25-28T
  - 산악자전거(MTB) **1×12 = 12단**: 앞 32T, 뒤 10-12-14-16-18-21-24-28-33-39-45-51T
  - 기본 선택은 3×7. 바퀴 둘레는 구성별 실제 값(예: 700×35C ≈ 2.17m, 700×25C ≈ 2.11m, 29×2.25 ≈ 2.29m)을 상수로 두고 화면에 표시.
- **3D**: 자전거 구동계를 크게 — 크랭크·체인링(여러 장), 뒤 카세트(스프로킷 여러 장이 실제 크기 순서로), 체인, **앞·뒤 변속기(디레일러)** 와 풀리 2개, 뒷바퀴(스포크), 프레임 뒤 삼각 일부.
  선택한 단에 맞춰 체인이 해당 체인링·스프로킷으로 옮겨 가고(짧은 전환 애니메이션, 뒤 디레일러 케이지 각도가 체인 길이에 맞춰 변함), 페달 회전수에 따라 뒷바퀴가 기어비대로 돈다.
  체인 경로는 스프로킷 바깥을 감아야 한다. `src/models/parts/gears.ts`의 `sprocketOutline`, `src/models/factory.ts`의 `ChainPath2D`/`buildChainAlongPath`, `src/machines/Bicycle.ts`의 바퀴·체인 처리 방식을 참고(수정 금지).
- **조작**: 앞 변속(＋/－ 또는 체인링 버튼), 뒤 변속(＋/－ 또는 스프로킷 버튼) — 실제 변속 레버처럼 왼손=앞, 오른손=뒤 구분. 페달 회전수(케이던스) 슬라이더 40~110rpm(기본 70). 키보드 ←→(앞) ↑↓(뒤).
- **표시**: 현재 단(예: 앞 2단 38T × 뒤 4단 20T), 기어비(앞÷뒤), 페달 1회전당 이동 거리(m), **속도(km/h) = 케이던스 × 기어비 × 바퀴 둘레 × 60 / 1000**, 페달 무게감(가벼움~무거움 막대).
  전체 단의 기어비 표(앞×뒤 격자, 현재 칸 강조, 누르면 그 단으로 이동), **쓰임새 안내**: 기어비 구간에 따라 "가파른 오르막·출발", "완만한 오르막·맞바람", "평지 주행", "빠른 평지·내리막" 등.
  체인이 심하게 비틀리는 조합(앞 큰×뒤 큰, 앞 작은×뒤 작은)은 "체인이 비스듬해져 권장하지 않아요" 경고.
- **지형 미니 과제**(선택이지만 권장): "오르막이에요 — 알맞은 기어는?" 처럼 지형 3~4개를 차례로 제시하고 적절한 기어비 범위에 들어오면 통과.
- 진입 시 카메라는 구동측(오른쪽)에서 구동계가 가득 차게.

## 11-B 자동차 기어 변속 — `CarShift`

- **차량 설정(화면에 명시)**: FF 전륜구동 소형차, 5단. 기어비 1단 3.545 / 2단 1.904 / 3단 1.310 / 4단 0.969 / 5단 0.815 / 후진 3.250, 종감속비 4.058, 타이어 195/65R15(둘레 ≈ 1.99m), 공회전 800rpm, 최대 6500rpm.
  **속도(km/h) = 엔진 rpm ÷ (기어비 × 종감속비) × 타이어 둘레 × 60 ÷ 1000**. 역방향으로 rpm도 계산.
- **모드 전환(상단 세그먼트)**: `수동 변속기` / `자동 변속기`.
- **수동 모드**
  - 화면의 **H자 변속 레버**(1-2-3-4-5-R, 가운데 중립)를 누르거나 끌어서 단 선택. **클러치 페달**(누르고 있는 동안만 변속 가능 — 버튼 길게 누르기/토글, 키보드 Shift), **가속 페달**(슬라이더 또는 길게 누르기, 키보드 ↑), **브레이크**(키보드 ↓).
  - 간단한 주행 모델: 엔진 토크 곡선(단순화) × 기어비 → 구동력, 주행 저항 → 가속. 클러치를 밟으면 엔진과 변속기가 분리(rpm 독립). 클러치를 급히 떼거나 속도에 비해 단이 높으면 **시동 꺼짐/노킹 안내**, rpm이 레드존이면 경고. 너무 복잡하게 만들지 말고 학습용으로 안정적으로.
  - 변속 안내: 현재 속도·rpm에 맞는 권장 단, "지금 3단으로 올리세요" 같은 코치 문구. 단별 **쓰임새와 속도 범위 표**(1단: 출발·가파른 오르막 0~약 30km/h … 5단: 고속 정속 주행·연비) — 속도 범위는 위 공식으로 2000~6000rpm 기준 계산해 채운다.
- **자동 모드**
  - **P-R-N-D** 셀렉터 + 가속·브레이크 페달만. D에서는 속도와 가속 페달 깊이에 따라 스스로 1→5단 변속(업/다운시프트 선도), 현재 단 표시, "클러치 페달이 없고 변속기가 알아서 단을 바꿔요" 설명.
  - 수동과의 차이를 한눈에: 토크 컨버터(유체로 동력 전달 — 정차 중에도 시동이 꺼지지 않음)와 자동 변속 개념을 짧게. P는 주차(바퀴 잠금), N은 중립.
- **3D**: 가로배치 엔진 + 트랜스액슬(변속기 케이스 `ghost`로 내부 기어 쌍 5개와 선택된 단의 기어·싱크로 슬리브 강조) + 디퍼렌셜 + 구동축 + 앞바퀴, 차체는 단순 윤곽. 엔진 풀리·기어·구동축·바퀴가 **계산된 회전수 비율로** 돈다(화면에서는 너무 빠르면 비율 유지한 채 스케일 다운).
  `src/machines/drivetrainParts.ts`(다른 에이전트가 작성 중 — 바퀴·차체·엔진·변속기·구동축 빌더)가 완성되면 import 해서 써도 된다(수정 금지, 없으면 자체 모델링). `src/machines/Gearbox.ts`(작성 중)는 참고만.
  자동 모드에서는 클러치 자리에 토크 컨버터를 보여 준다.
- **계기판**: 속도계(km/h)·회전계(rpm, 레드존)·현재 단 — SVG 또는 CSS로 아날로그/디지털 계기.
- 모바일: 페달·레버가 하단 시트에 들어가고 3D는 위쪽.

## 11-C 자동차의 동력 전달 — `PowerFlow`

- **내용**: FR 후륜구동의 동력 전달 전체 과정을 **단계별 투어**로.
  1. 엔진 — 연료의 폭발로 피스톤이 왕복 → 크랭크축이 회전 운동으로 바꿈
  2. 플라이휠·클러치 — 회전을 고르게 하고, 동력을 잇거나 끊음
  3. 변속기 — 기어를 바꿔 물려 회전 속도와 힘(토크)을 조절
  4. 프로펠러 샤프트(추진축) — 차 뒤쪽으로 회전을 전달(유니버설 조인트로 각도 변화 흡수)
  5. 종감속 기어·차동기어 — 회전 방향을 90° 바꾸고 감속하여 힘을 키움, 커브에서 좌우 바퀴의 회전수 차이를 허용
  6. 차축(구동축) — 좌우 뒷바퀴로 전달
  7. 바퀴 — 노면을 밀어 차가 나아감
- **3D**: FR 차량 섀시 투시도(세로배치 엔진 컷어웨이로 피스톤·크랭크가 보이면 최상, 변속기, 프로펠러 샤프트, 뒤 디퍼렌셜의 링·피니언 기어가 보이는 컷어웨이, 뒤 차축, 바퀴 4개, 반투명 차체).
  `src/machines/drivetrainParts.ts`(다른 에이전트가 작성 중)의 빌더가 완성되면 import 해서 써도 된다(수정 금지, 없으면 자체 모델링). `src/machines/CarEngine.ts`(작성 중)는 참고만.
- **연출**: 단계를 선택하면 카메라가 해당 부품으로 이동(`flyTo`), 그 부품만 강조(나머지는 흐리게/반투명), **동력 흐름 표시**(부품을 따라 이동하는 발광 입자/화살표)가 엔진에서 현재 단계까지 이어진다.
  "전체 보기" 단계에서는 처음부터 끝까지 흐름이 반복 재생. 모든 회전 부품은 서로 맞는 비율·방향으로 회전.
- **조작**: 이전/다음, 단계 목록(스테퍼), 자동 재생, 가속 페달 슬라이더(엔진 회전수 변화 → 각 부품 회전수가 표로 갱신: 엔진 rpm → 변속기 출력 rpm(선택 단, 3단 고정 또는 선택 가능) → 프로펠러 샤프트 → 종감속 후 차축 rpm → 차속 km/h).
  커브 주행 토글(좌/우 회전 시 차동기어가 좌우 바퀴 회전수를 다르게 — 수치로 표시)을 5단계에 넣으면 좋다.
- **마무리**: 마지막에 3~4문항의 순서 맞히기/빈칸 확인 문제(선택이지만 권장) — "엔진 → ( ) → 변속기 → …".
- FF와의 차이 한 줄 비교(FF는 엔진·변속기·디퍼렌셜이 앞에 모여 있어 프로펠러 샤프트가 없다)를 요약 카드로.
