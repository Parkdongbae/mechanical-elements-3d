# PRD — 「507 기계 운동」 유튜브 쇼츠

작성 2026-11-25. 실제 제작은 사용자가 이 문서와 작업 지시서 21을 검토한 뒤 따로 지시한다.

## 1. 목표
- 앱에 만든 507 기계 운동 3D 모델을 1번부터 차례로 15초 이내 세로 영상(쇼츠)으로 만든다.
- 한 번호마다 **한글판·영어판** 두 편을 만든다. 1~160번이면 320편이다.
- 보는 사람이 "이게 어떻게 움직이지?" 하고 멈춰 보게 하고, 앱으로 들어와 직접 돌려 보게 한다.

## 2. 대상과 채널
- 대상: 기계·과학에 관심 있는 중고생과 일반인. 한글판은 한국어 사용자, 영어판은 해외 사용자.
- 채널: 사용자의 유튜브 채널. 한·영을 한 채널에 올릴지 두 채널로 나눌지는 질문 Q4.

## 3. 영상 한 편의 구성(총 14.5초 이하, 1080×1920, 30fps)

| 구간 | 길이 | 화면 | 소리 |
|---|---|---|---|
| ① 인트로 | 0~1.5초 | 「Five Hundred and Seven Mechanical Movements」 상징 화면(1868년 원서 판화 느낌 + 번호 "No. 1 / 507"). Canva 로 만든 정지 이미지에 짧은 확대 효과 | 효과음 한 번 + 배경음악 시작 |
| ② 훅 | 1.5~3.5초 | 원본 판화(흑백)가 화면 가득 → 3D 모델로 바뀌는 전환(같은 구도) | 더빙 첫 문장(질문형) |
| ③ 작동 | 3.5~11.5초 | 카메라 무빙 3단(§4). 이름표 켬, 화살표 끔, 지시선 표시. 아래쪽에 자막(쉬운 풀이) | 더빙(쉬운 풀이 요약) |
| ④ 아웃트로 | 11.5~14.5초 | "직접 돌려 보세요" + 앱 주소, 구독·좋아요 버튼 애니메이션 | 더빙 끝 문장 + 음악 페이드아웃 |

- 한글판: 화면 글자·이름표·자막·더빙 모두 한글. 영어판: 모두 영어(앱의 한/영 전환과 영어 사전 사용).
- 이름표 켜기, 화살표 끄기(앱 설정 `showLabels=true`, `showArrows=false`).

## 4. 카메라 무빙(눈길 + 지적 호기심)
번호마다 자동으로 고르되, 모델의 부품 정보(키트 표식 `userData.mm`)를 써서 "핵심 접촉부"를 찾는다.
1. **판화 → 3D 정합 전환**(②): 판화와 같은 정면 구도에서 시작해 판화를 겹쳐 놓고 0.5초에 걸쳐 사라지게 한다. "판화가 살아난다"는 첫인상.
2. **궤도 반 바퀴 + 다가가기**(③ 앞부분 4초): 정면에서 45° 비스듬히 돌며 천천히 다가간다. 입체감을 보여 준다.
3. **핵심부 클로즈업**(③ 뒷부분 3초): 기어 물림·벨트가 감기는 곳·캠과 따름쇠 접점·래칫 걸쇠 같은 맞닿는 자리로 확대해 머문다. 이때 그 부품 이름표 하나만 강조(크게)한다.
4. 마지막 1초는 다시 전체가 보이게 물러나며 아웃트로로 넘긴다.
- 움직임 속도: 모델 재생 속도는 기본 1배, 클로즈업 때 0.5배(느린 동작)로 "어떻게 맞물리는지" 보이게.

## 5. 대본(쉬운 풀이 기반)
- 원천: `public/mm507/catalog.json` 의 `easy`(한글), `easyEn`(영어).
- 15초 안에 읽을 수 있게 줄인다: 한글 약 45~60자, 영어 약 28~35단어.
- 형식: ① 질문 한 문장(훅) → ② 원리 한두 문장 → ③ "앱에서 직접 돌려 보세요" 고정 문장.
- 줄이는 작업은 Claude(Sonnet)가 번호마다 한 번 하고, 길이 검사 스크립트로 확인한다.

## 6. 더빙(무료)
- 1안(추천): **edge-tts**(Microsoft Edge 온라인 음성, 무료·가입 없음). 한글 `ko-KR-SunHiNeural`(여)·`ko-KR-InJoonNeural`(남), 영어 `en-US-AriaNeural`·`en-US-GuyNeural`. 음질이 좋고 단어별 시간 정보를 줘서 자막 맞추기가 쉽다. 상업적 이용 약관은 명확하지 않다(수익 창출 채널이면 위험 — 질문 Q1).
- 2안: **Piper**(오픈소스, 내 컴퓨터에서 돌아감, MIT 계열 모델). 영어 음질은 괜찮고 한글 음성은 선택지가 적고 덜 자연스럽다.
- 3안: 유튜브 자체 기능 없음 — 외부 유료(Typecast, ElevenLabs)는 이번 범위 밖.

## 7. 배경음악(무료)
- 1안(추천): **유튜브 오디오 보관함**(YouTube Studio 안, 무료, 저작권 표기 없이 쓸 수 있는 곡 다수). 사용자가 로그인해서 곡을 내려받아야 한다.
- 2안: **Pixabay Music**(무료, 저작자 표시 불필요, 가입 없이 내려받기 가능한 곡 다수).
- 곡은 3~5개를 골라 번호마다 돌아가며 쓴다. 음량은 더빙 아래로(-18 LUFS 근처, 더빙 -14).

## 8. 인트로 이미지(Canva)
- Canva 로 1080×1920 이미지 2장(한글판·영어판 글자만 다름)을 만든다: 오래된 종이 질감, 1868년 원서 표지 느낌의 세리프 글꼴 "Five Hundred and Seven Mechanical Movements", 기어·벨트 판화 장식, 가운데 비운 자리에 번호를 영상에서 얹는다.
- 원서 판화는 저작권이 끝난 자료(1868)라 그대로 쓸 수 있다.

## 9. 업로드 정보
- 제목 예: `[507 기계 운동 #1] 열린 벨트 전동 #shorts` / `[507 Mechanical Movements #1] Open belt drive #shorts`.
- 설명란: 쉬운 풀이 2~3문장 + 앱 링크 `https://mechanical-elements-3d.vercel.app/#/mm/<번호>` + 원서 표기(Henry T. Brown, 1868) + 해시태그.
- 태그: 기계, 기구학, 기어, mechanism, engineering, 507movements 등.
- 업로드 방식은 질문 Q3(직접 올리기 / YouTube Data API 자동 올리기).

## 10. 성공 기준
- 한 편 14.5초 이하, 1080×1920, 소리 끊김·자막 어긋남 없음.
- 이름표가 보이고 화살표는 안 보임, 판화와 첫 장면 구도가 맞음.
- 번호마다 한·영 두 파일과 업로드용 메타데이터(제목·설명·태그) JSON.
- 첫 10편을 사용자가 보고 승인한 뒤 나머지를 묶음으로 만든다.

## 11. 범위 밖
- 유료 음성·유료 음악, 사람 목소리 녹음, 긴 영상(1분 이상).
- 161번 이후 모델 제작(모델이 생기면 같은 파이프라인으로 추가).

## 12. 사용자에게 필요한 일(가입·로그인)
- 유튜브: 채널 로그인. API 자동 업로드를 고르면 Google Cloud 프로젝트 생성·OAuth 동의(사용자가 직접).
- 유튜브 오디오 보관함을 쓰면 YouTube Studio 로그인 후 곡 내려받기(사용자가 직접).
- Canva: 이 세션에 Canva 도구가 연결되어 있다. 처음 쓸 때 Canva 로그인·권한 허용이 필요할 수 있다.
- 설치(제가 함): ffmpeg, edge-tts(또는 Piper). 지금 이 컴퓨터에는 둘 다 없다.

## 결정 사항(2026-11-25)
- 더빙 edge-tts, 배경음악 유튜브 오디오 보관함, 업로드 YouTube Data API 자동(예약), 한·영 한 채널(제목 [한]/[EN], 언어별 재생목록).

## 13. 더 좋은 아이디어(제안)
1. **"이건 어디에 쓰일까?" 마지막 질문**: 끝에 실제 쓰임(자동차, 시계, 재봉틀 등) 퀴즈를 내고 답은 댓글/고정 댓글로 — 댓글 참여가 늘어 알고리즘에 유리.
2. **시리즈 묶음**: 벨트(1~11), 도르래(12~22), 기어(23~)처럼 묶어 재생목록을 만들고, 영상 왼쪽 위에 "벨트 3/11" 같은 진행 표시.
3. **판화 대 3D 분할 화면**: 위 절반 판화, 아래 절반 3D를 1초 보여 주는 장면 — 원서 팬에게 강한 인상.
4. **같은 녹화로 가로 영상도**: 10개씩 묶어 1~2분 가로 영상(유튜브 일반 영상)으로 재활용.
5. **앱 안 "쇼츠 모드" 버튼**: 녹화 파이프라인을 앱의 개발 기능으로 넣어 두면 모델을 고칠 때마다 다시 뽑기 쉽다.
6. **업로드 일정**: 하루 2편(한·영 각 1)씩 예약 업로드하면 160일치 콘텐츠.
