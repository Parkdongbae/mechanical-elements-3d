# 206 두 폴 래칫
원문(en): "A continuous circular movement of the ratchet-wheel, produced by the vibration of the lever carrying two pawls, one of which engages the ratchet-teeth in rising and the other in falling." — 두 폴을 단 레버가 흔들리면, 한 폴은 올라갈 때, 다른 폴은 내려갈 때 이를 걸어 래칫 바퀴가 계속 한 방향으로 돈다.
쉬운 풀이: 레버가 올라갈 때와 내려올 때 각각 다른 폴이 이를 밀어 래칫 바퀴가 같은 방향으로 계속 돈다.
판화 묘사: 톱니(톱날 이) 바퀴 하나, 가운데 축(짙음). 위 오른쪽에 **고정 받침점**(짙은 원, 판화 [291·40])에 걸린 레버가 있고, 레버의 왼쪽 끝 핀(흰 고리, [222·65], 바퀴 중심 바로 위)에 **휜 폴 두 개**가 함께 걸려 있다: 하나는 바퀴 왼쪽으로 내려가 끝이 갈고리처럼 10시 방향 이 **밑**을 걸고, 다른 하나는 오른쪽으로 내려가 끝이 2시 방향 이 **위**에 얹힌다. 레버 오른쪽 끝은 판화 위 테두리 밖으로 이어진다(잘린 끝).

## ★ 판화 읽기
판화 499×502 px, 1 px = 0.005. 바퀴 중심 [222·267.5], 이끝 반지름 155 px, 이뿌리 141 px, 안쪽 테 원 131 px, 허브 36 px.
1. 바퀴는 몇 개이고 크기 차례는? → 래칫 바퀴 1개(이끝 반지름 0.775). 이 수는 2시~5시 사이 7.5 피치/68° → 약 40개.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 두 폴이 같은 핀에서 갈라져 바퀴 위쪽 둘레를 따라 왼쪽·오른쪽으로 휜다(앞뒤 층이 다름).
4. 고정점은? → 레버 받침점(짙은 원) 바퀴 중심에서 (+0.345, +1.1375), 바퀴 축. 모형은 둘 다 뒤판에 고정 축.
5. 손잡이·크랭크는? → 레버 오른쪽 손잡이 끝(판화 밖). 모형: 손잡이 끝을 연결봉으로 오른쪽 아래 크랭크 원판에 이음(보충 — 판화 밖의 "흔드는 힘").
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 바퀴 바깥 둘레에 톱날 이. 곧은(가파른) 면이 **반시계 쪽**을 향한다(오른쪽 3시 근처에서 이의 윗면이 곧고, 왼쪽 9시 근처에서 아랫면이 곧다). 왼쪽 갈고리 폴은 10시 근처 이의 곧은 면을 아래에서 걸어 **위로 당기고**, 오른쪽 폴은 2시 근처 이의 곧은 면을 위에서 **아래로 민다** — 둘 다 바퀴를 **시계 방향**으로 돌린다.
7. 한 줄에 놓인 것은? → 폴 핀이 바퀴 중심 바로 위 같은 세로선(x 차 0.0015 → 0). 받침점–폴 핀–손잡이가 한 직선(레버, 수평에서 19.9° 기욺).
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 돌 수 없는 곳은? → 계속 돈다. 다만 판화의 레버 배치(폴 핀이 받침점 왼쪽에서 거의 위아래로만 움직임)로는 **올라갈 때(갈고리 폴) 바퀴가 4.26°, 내려갈 때(미는 폴) 13.74°** 로 두 행정의 양이 3배 차이 난다(왼쪽 폴은 핀의 움직임과 폴 방향이 69° 어긋나 힘이 덜 전해짐). → ★질문 거리.

## 해석(결정 사항)
- 이 면을 반지름선에서 20° **갈고리꼴**(이끝이 반시계 쪽으로 기울어 이골을 덮음)로 기울였다: 두 폴이 짐을 받을 때 모두 이골 안쪽으로 끌려 들어가 빠지지 않는다(곧은 반지름 면이면 미는 폴이 밀려 나옴 — 모멘트 계산). 판화의 거의 반지름 면과 20° 차.
- 폴 코는 둥근 끝(반지름 0.014) + 미는 면 여유각 + 몸과 이어지는 목은 둥근 필릿(0.02) — 155번 "폴이 이 닿는 곳이 각져 보임" 지적을 미리 막는다. 윤곽은 아래 점열(계산·검사 완료)을 그대로 쓴다.
- 두 폴은 핀에 헐겁게 걸려 **제 무게로** 바퀴에 얹힌다(왼쪽 폴은 핀 왼쪽 아래로 늘어져 반시계로, 오른쪽 폴은 오른쪽 아래로 늘어져 시계로 기울려 함 → 둘 다 코가 바퀴 쪽으로 눌림). 스프링 없음.
- 한 주기(크랭크 한 바퀴)에 바퀴는 정확히 **2이(18°)** 시계로. 판화에 없는 보충: 크랭크 원판·연결봉·받침 축 셋.

## 구동
`theta += OMEGA * speed * dt`(크랭크 각, 1.6 rad/s, 한 주기 3.93 s). 모든 자세는 `state206(theta)` 의 닫힌 식 + 모듈 적재 때 한 번 만든 폴 들림 표.

## 동작 (`state206(theta)` — 모두 닫힌 식, 각도 rad)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀 Pk = K + rk·(cos(thF + u), sin(thF + u)).
2. 손잡이 핀 H = `circleIntersect([P0x, P0y], 0.75, [Pkx, Pky], 1.091699, true)`, γ = atan2(H.y − P0.y, H.x − P0.x) − hdir. (u = 0 → γ = +18.8°, u = π → −18.8°, 정확히.)
3. 폴 핀 Q(γ) = P0 + 0.366947·(cos(hdir + π + γ), sin(hdir + π + γ)).
4. 가상 구석점: CL = `circleIntersect(W, Rc, Q, LL, true)`(왼쪽 해), CR = `circleIntersect(W, Rc, Q, LR, false)`(오른쪽 해). UL(γ) = atan2(CL − W), UR(γ) = atan2(CR − W).
5. 상수(모듈에서 한 번 계산, 기대값): uL0 = UL(+18.8°) = 148.0192°, uR0 = UR(+18.8°) = 27.4989°, URlow = UR(−18.8°) = 44.7292°, ULlow = UL(−18.8°) = 140.2396°. tL = uL0 − uR0 − 13p = 3.5203°, dUL = uL0 − ULlow = 7.7796°, dUR = URlow − uR0 = 17.2303°, tR = dUL + dUR − 2p − tL = 3.4895°, A1 = dUL − tL = 4.2592°, rho0 = uL0 − tL − eps = 142.6401°.
6. 바퀴 시계 누적각 Φ: u < π(폴 핀 **올라감**): Φ = n·2p + max(0, (uL0 − UL(γ)) − tL), 갈고리 폴 구동 = (uL0 − UL(γ)) > tL. u ≥ π(**내려감**): Φ = n·2p + A1 + max(0, (URlow − UR(γ)) − tR), 미는 폴 구동 = (URlow − UR(γ)) > tR. `ratchet.rotation.z = rho0 − Φ`.
7. 폴 각: baseHook = atan2(CL − Q), basePush = atan2(CR − Q). `lamHook = baseHook + liftHook`, `lamPush = basePush + liftPush`(들림은 u 에서 표를 보간). 구동 중인 폴의 들림은 0(코가 이골 구석에 앉음).
8. 들림 표(모듈 적재 때 한 번): u_i = 2π·i/1440, 두 주기를 차례로 돌며 둘째 주기 값을 저장. 각 시각에 폴마다 — 구동 중이면 lift = 0, 아니면 앞 시각의 lift 에서 시작해 `follow`:
   - 침범 판정 pen(λ): 코 중심 c = Q + L·(cos λ, sin λ) 를 바퀴 로컬로(c − W 를 −(rho0 − Φ) 회전) 옮겨, 바퀴 윤곽(80점) 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범.
   - 바깥 방향 out: 갈고리 폴 −1(시계로 돌면 들림), 미는 폴 +1. 침범이면 out 쪽으로 0.02° 씩(최대 2000번) 가다 처음 침범 아님을 찾고, 아니면 −out 쪽으로 0.02° 씩(최대 1500번) 가다 처음 침범을 찾는다. 그 두 각 사이를 이분법 25번, 침범 아닌 쪽을 답으로.
