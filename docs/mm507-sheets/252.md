# 252 비스듬한 홈으로 롤러 이동
원문(en): "A and B are two rollers which require to be equally moved to and fro in the slot, C. This is accomplished by moving the piece, D, with oblique slotted arms, up and down." — A 와 B 는 홈 C 안에서 같은 거리만큼 앞뒤로 움직여야 하는 두 롤러이다. 이것은 비스듬한 홈이 있는 팔을 가진 부품 D 를 위아래로 움직여서 이룬다.
쉬운 풀이: 두 롤러의 축 핀은 고정된 가로 홈 C 와, D 의 비스듬한 팔 홈에 **함께** 끼어 있다. D 가 올라가면 두 홈이 겹치는 자리가 바깥으로 옮겨 가 두 롤러가 똑같이 벌어지고, 내려가면 오므라든다. **롤러를 움직이는 것은 두 홈이다(시간표로 롤러를 옮기지 않는다)** — 시간표는 D 를 오르내리는 크랭크 각뿐.
판화 묘사(원본 463×453 px, [x·y]): 왼쪽에 벌어진 끝을 가진 고정 받침([30~70·65~205]), 거기서 오른쪽으로 뻗은 가로 막대([70~430·108~165]) 속에 긴 가로 홈 C(위 선 y 123, 아래 선 150, 글자 C [160·135]). 홈 위에 큰 원 둘(롤러 A [225·135], B [315·135], 반지름 약 37 px, 두 원 사이 틈 약 16 px), 가운데 짙은 핀. 아래에 부품 D: 두꺼운 가로 바탕([95~440·345~385], 밑이 둥글게 처짐)과 가운데 네모 덩이 D([245~295·345~390]), 덩이 밑으로 가는 막대가 그림 아래 끝까지([262~278·390~450]). 바탕 양끝 근처([140·345], [400·345])에서 두 팔이 안쪽 위로 비스듬히(세로에서 약 22°) 올라가 각 롤러 핀에 이른다. 팔마다 긴 홈(두 줄 선, 양 끝 둥금)이 바탕 가까이(y 330)부터 핀 위까지 나 있다.

## ★ 판화 읽기
판화 하나(정면). 세계 1 px = 0.0075, 판화 x 270(D 가운데) = 세계 x 0, 판화 y 108 = 세계 y 2.80.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 롤러 2 개(같은 크기, 반지름 0.28). 기어·풀리 없음. D 를 움직이는 크랭크 원판 1 개 보충(판화 밖).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 줄 없음. 정면에서 팔과 가로 막대 C 가 겹친다(다른 층: 막대 C 뒤, 팔 앞, 롤러 맨 앞).
4. 고정점은? → 왼쪽 받침과 가로 막대 C(뒤판에 붙음), D 막대의 안내 통, 크랭크 축 받침(뒤판).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에는 D 아래 막대만 있고 움직이는 것은 그림 밖. 원문 "moving the piece D up and down" → 크랭크 원판의 핀이 D 덩이의 가로 홈을 밀어 D 를 오르내리게 보충(스카치 요크).
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 롤러 핀은 가로 홈 C 와 팔의 비스듬한 홈 **두 홈 속에** 동시에 들어 있다(홈 벽이 핀을 양쪽에서 0.002 틈으로 끼움).
7. 한 줄에 놓인 것은? → 두 롤러 중심과 홈 C 중심선이 같은 높이(y 2.60). D 덩이·막대·크랭크 축이 한 세로선(x 0). 두 팔은 x 0 에 대해 좌우 대칭.
8. 판화에 글자가 가리키는 부품은? → A = 왼쪽 롤러, B = 오른쪽 롤러, C = 가로 홈(막대 C 의 홈), D = 아래 부품(바탕 + 덩이 + 비스듬한 팔).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → (가) 판화의 자세는 두 롤러가 거의 닿은(틈 0.115) 자세라 더 오므라들 수 없다 → 판화 자세를 D 의 **가장 낮은 자세**로 보고, D 가 0.40 올라가며 롤러가 0.16 씩 벌어졌다 돌아오게 했다. (나) D 를 움직이는 것이 판화에 없다 → 크랭크 원판 + D 덩이 가로 홈(스카치 요크)과 막대 안내 통 보충, D 덩이를 판화보다 넓게(x ±0.28). (다) 롤러는 무엇에도 굴러 닿지 않으므로 돌지 않고 핀과 함께 옮겨 간다(돌림 표시 없음) → ★질문 거리.

## 해석(결정 사항)
- 핀 중심 = 가로 홈 중심선(y 2.60)과 팔 홈 중심선의 교점. 왼쪽 팔 홈 중심선(D 가 가장 낮을 때): x = −0.3375 − 0.4·(2.60 − y)(세로에서 21.8°, tan 0.4). D 가 d 만큼 올라가면 교점 x = ∓(0.3375 + 0.4·d) — **A 는 왼쪽, B 는 오른쪽으로 똑같이**.
- 크랭크 각 θ = 0.8·t(반시계), D 높이 d = 0.2·(1 − cos θ)(0~0.40), 크랭크 핀 (0.2 sin θ, 1.11 − 0.2 cos θ) 이 늘 D 덩이 홈 중심선(y 0.91 + d) 위.

## 구동
