# 236 두 폴 래칫 2
원문(en): "A nearly continuous circular movement is imparted to the ratchet-wheel on vibrating the lever, a, to which are attached the two pawls, b and c." — 레버 a를 흔들면 래칫 바퀴에 거의 연속적인 원운동이 전해진다. 이 레버에는 두 폴 b와 c가 붙어 있다.
쉬운 풀이: 폴 두 개가 번갈아 이를 밀어서, 레버가 올라갈 때도 내려갈 때도 바퀴가 같은 방향으로 거의 쉬지 않고 돈다.
판화 묘사(원본 485×454 px, [x·y]): 아래 가운데 톱날 바퀴(허브 겹원 [239·275], 이끝 원 중심 약 [233·268] 반지름 88 px, 이뿌리 75 px, 이 16개)와 왼쪽 둘레의 굽은 화살표(왼쪽에서 아래로 = **반시계**). 위에 **레버 a**: 작은 받침 구멍 [269·117](글자 a 옆), 왼쪽으로 길게 뻗은 손잡이(끝 [30·95]), 받침 왼쪽 핀 [197·109] 과 오른쪽 아래 핀 [310·149](겹원). 왼쪽 핀에서 **폴 b** 가 거의 세로로 내려가 바퀴 **왼쪽**(바퀴 중심에서 154°) 이골 [167·237] 에, 오른쪽 핀에서 **폴 c** 가 왼쪽 아래로 비스듬히 바퀴 **위쪽**(106°) 이골 [213·193] 에 걸린다.

## 다섯 장 공통 폴·이 규칙 (225·232·235·236·237 같음)
- 폴(태핏·멈춤 폴 포함) **코 끝은 원 반지름 rn = 0.014**, 코와 몸이 만나는 **오목 목은 필릿 0.02**, 나머지 볼록 모서리 0.006 — 아래 점열에 이미 들어 있다(155 "폴 닿는 곳이 각져 보임" 방지). 점열을 고치거나 다시 그리지 말 것.
- **톱날 이(225·236·237)**: 곧은 면이 반지름선(237 은 띠의 수직선)에서 **20° 갈고리꼴**(이끝이 폴 쪽으로 기울어 이골을 덮음 — 206 과 같음), 비탈은 이끝 → 다음 이뿌리 직선, 이끝은 뾰족. 판화가 대칭 이를 그린 232(네모 이)·235(별 이)만 판화를 따른다.
- 폴의 **미는 면은 이 곧은 면에서 여유각**(폴이 이에 대해 도는 만큼 + 여유)을 두어 코 원만 닿는다.
- 침범 판정(들림 계산): 코 원 중심이 바퀴 윤곽 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범(206 과 같음).
- 색: **거는 폴 = 그 폴 재질 emissive 0x7a4a00(주황빛), 쉬는 폴 = 0x000000** — 폴마다 재질을 따로 만든다.
- 재질: 바퀴는 `steel()`(밝음 — 이가 보이게, 검은 재질 금지), 폴은 `brass()`, 팔·레버는 `castIron()`.

## 해석(결정 사항)
- 두 폴은 핀에 헐겁게 걸려 **제 무게로** 바퀴에 얹힌다: b 는 핀 아래로 늘어지면 코가 바퀴 왼쪽 옆으로 기대고, c 는 핀 왼쪽으로 늘어져 코가 바퀴 위로 눌린다. 스프링 없음.
- 레버 흔들림 ±20°(판화 자세 γ = 0 이 가운데). 한 주기(크랭크 한 바퀴)에 바퀴는 정확히 **2이(45°)** 반시계: 손잡이 내림(γ 증가) 29.786°, 올림(γ 감소) 15.214°.
- 폴 몸은 코에서 바퀴 바깥 방향으로 0.20 올라간 뒤 핀으로 간다(구동 중 폴이 바퀴에 대해 b 36°, c 20° 돌아도 이끝에 닿지 않게 — 검산). 그래서 판화처럼 코 끝이 갈고리로 꺾여 보인다.
- 판화 손잡이 끝은 받침점에서 2.04 이지만 ±20° 흔들면 판 위(3.15)를 넘으므로 **1.8 로 줄임**.
- 판화에 없는 보충: 크랭크 원판·크랭크 축·연결봉(c 핀에 걸림), 바퀴 축·레버 받침 축.

## 구동

## 동작 (`state236(theta)` — 닫힌 식)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀 P = K + rk·(cos(thF + u), sin(thF + u)).
2. c 핀 Qc = `circleIntersect([0.3315, 2.309], 0.4421, [P.x, P.y], 0.951207, false)`, γ = atan2(Qc.y − 2.309, Qc.x − 0.3315) − (−37.97°)(−180°~180° 로). (u = 0 → γ = −20°, u = π → +20°, 정확히.)
3. b 핀 Qb = F + 0.6158·(cos(173.66° + γ), sin(173.66° + γ)).
4. 가상 구석: Cb = `circleIntersect(W, Rc, Qb, Lb, true)`, Cc = `circleIntersect(W, Rc, Qc, Lc, true)`. Ub = atan2(Cb − W), Uc = atan2(Cc − W).
5. 상수(기대값): Ub(−20°) = 133.1364°, Ub(+20°) = 171.5251°, Uc(−20°) = 119.2395°, Uc(+20°) = 94.1919°. tb = (Uc(−20°) − Ub(−20°)) mod p = 8.6031°, tc = (Ub(+20°) − Uc(+20°)) mod p = 9.8333°, A1 = 29.7856°(171.5251 − 133.1364 − tb), A2 = 15.2144°(119.2395 − 94.1919 − tc), 둘의 합 45°(2p).
