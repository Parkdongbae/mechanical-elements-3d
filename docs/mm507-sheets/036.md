# 036 맹글 휠과 피니언
판화: 큰 원판 면에 C자로 휜 톱니 띠(양쪽 가장자리에 이가 바깥으로 나 있고 왼쪽 끝이 반원으로 말려 있다)가 있고, 작은 피니언이 그 띠를 **바깥에서** 물고 띠 둘레를 돈다. 휠 면에 파인 안내 홈이 피니언을 띠에 붙여 둔다. 피니언 축은 휠 중심 바로 아래에 세운 고정 막대의 세로 홈에 끼어 오르내린다. 원문: 피니언은 한 방향으로 계속 도는데 축이 홈 속에서 오르내리며 띠의 바깥쪽 이와 안쪽 이를 번갈아 물어 휠이 정·역으로 왕복한다.
(처음 설계는 "닫힌 톱니 고리 속을 피니언이 지난다"로 읽었으나 판화 확대 대조에서 틀린 것으로 확인 — 끝의 "검증 후 수정" 참조.)
구동: 피니언(일정 각속도 PIN_W = 3.2 rad/s = 2·OMEGA — 한 주기가 길어 보이도록 빠르게). theta = 피니언 절대 각.

## 부품과 치수 (키트 추가 `mangleTrack` 사용)
- `displayStand()`, 휠 중심 (0, 1.85), 휠 반지름 1.15: 원판(두께 0.05) + 테두리(0.07 폭) + 허브(반지름 0.17) + 테두리 표시점. `shaftZ(0,1.85,0.4,0.04)`.
- 톱니 띠 + 안내 홈 판: `mangleTrack({ pinionTeeth: 10, module: 0.022, rOuter: 0.88, rInner: 0.5, loopTeeth: 117, width: 0.09, rib: true, plateR: 1.07, hubR: 0.2 })` — 휠 위(z 0.1)에 얹는다. 띠 위 이 수 = 117 − 10 = 107.
- 피니언: `spurGear(10, 0.022, { width: 0.07, spokes: 0, driver: true })` + 축 막대(z −0.03 ~ 0.27). 피치 반지름 rp = 0.11. 중심 z = 0.1.
- 세운 막대: 폭 0.14, y 0.32~1.62, z 0.32(앞), 가운데에 세로 홈(y 0.95~1.37 + 반지름 0.032). 아래에 주철 받침. 피니언 축에 와셔.

## 동작 (순수 구름 조건 — 근사 없이 정확)
- 피니언 중심이 휠 좌표에서 지나는 닫힌 경로 C(s)(호장 s, 반시계): 바깥 팔(반지름 0.88) → 끝 반원(ρ = 0.19) → 안쪽 팔(반지름 0.5, 시계 방향) → 끝 반원. 이 경로의 **안쪽(왼쪽)** 으로 rp 만큼 들인 곡선이 띠의 피치선이고 이는 바깥(피니언 쪽)으로 난다(외접). 띠 이 수 117 − 10.
- 안내 홈 벽 = 경로의 바깥(오른쪽)으로 rp + m + 틈(0.012) 띄운 곡선 — 판(바깥 반지름 1.07, 허브 구멍 0.2)에 뚫린 구멍.
- 슬롯이 휠 중심 아래 수직선이므로 휠 각 φ(s) = −π/2 − arg C(s), 피니언 중심 높이 = 중심에서 |C(s)| 아래.
- 피니언 절대 각 θp = φ(s) + s/rp (외접이라 피니언은 휠 기준 +s/rp 만큼 구른다). θp 는 s 에 단조 증가하므로 매 프레임 테이블로 역산 (`track.solve(theta)`).
- 팔 반각 A = (L − 2πρ)/(2(R1+R2)) ≈ 143°, 끝 반원까지 넣으면 휠 각 범위 약 ±159° 왕복(식으로 계산한 값). 피니언 중심은 휠 중심 아래 0.5~0.88 사이를 오르내린다(y 0.97~1.35). 한 주기 = 피니언 117/10 = 11.7바퀴 ≈ 23 s.
- 절대 자세로 매 프레임 계산: wheel.rotation.z = φ, pinion.position.y = 1.85 − dist, pinion 각 = theta.

## 표시
- tag(z 0.35~0.5): '맹글 휠', '피니언', '세운 막대(홈)', '톱니 고리'.
- notes: 피니언 '한 방향으로 계속 회전', 휠 '반시계/시계로 회전', 휠 각.

## 확인
- t=1(휠 약 34° 자리)과 t=1.6(약 19°): 휠 표시점이 시계 방향으로 약 15° 돈다. 피니언 이가 띠의 이 사이에 물리고 박히지 않으며, 피니언 이끝이 안내 홈 벽에 닿지 않는다(가까이 `cam=0.9,1.3,1.5,0,1.3,0.1`).

## 키트 추가 (gear3.ts)
- `mangleTrack(opts): { group, pinionPitchR, length, solve(thetaP) }` — 기본(rib 없음)은 안쪽 이가 난 C자 홈 속을 피니언이 도는 꼴, `rib: true` 는 판화 36번 꼴(바깥 이가 난 C자 톱니 띠 + 안내 홈 판, 옵션 `plateR`·`hubR`·`clearance`). 이 단면 사다리꼴(이골 반폭 SA 0.24 / 이끝 시작 TA 0.38, 원피치 대비) + 위 운동학 풀이. 검사용 2D 윤곽 `group.userData.outlines = { rib, groove }`.

## 검증 후 수정 (Opus, 2026-11-25)
- **구성**: 처음 설계는 닫힌 톱니 고리(안쪽 이) 속을 피니언이 지나는 꼴이었다. 판화는 양쪽 가장자리에 이가 난 C자 톱니 띠를 피니언이 바깥에서 물고, 휠 면 안내 홈이 피니언을 가두는 꼴 → `mangleTrack` 에 `rib` 옵션을 넣어 바꿨다.
- **운동식**: θp = φ − s/rp(단조 감소) → θp = φ + s/rp(단조 증가). 띠 이 수 114 + 10 → 117 − 10.
- **치수**: rOuter 0.84 → 0.88, rInner 0.56 → 0.5(ρ 0.14 → 0.19), loopTeeth 114 → 117, 막대 홈 y 0.99~1.35 → 0.95~1.37, `plateR: 1.07`·`hubR: 0.2` 추가.
- **이 단면**: 이골을 넓혀 SA 0.24 / TA 0.38 (인벌류트 피니언과의 겹침을 줄임).
- **확인값**: t=1 → 1.6 에 휠이 시계 방향 15°(34° → 19°). 처음 표의 "65° 자리, 14°"는 옛 구성의 값.
