# 224 지름이 변하는 풀리
원문(en): "This represents an expanding pulley. On turning pinion, d, to the right or left, a similar motion is imparted to wheel, c, which, by means of curved slots cut therein, thrusts the studs fastened to arms of pulley outward or inward, thus augmenting or diminishing the size of the pulley." — 피니언 d 를 돌리면 바퀴 c 가 돌고, c 에 파인 굽은 홈이 풀리 팔에 박힌 스터드를 바깥·안쪽으로 밀어 풀리 지름이 커졌다 작아졌다 한다.
쉬운 풀이: 작은 기어 d 를 돌리면 가운데 바퀴 c 가 조금 돈다. c 의 나선 모양 홈 6개가 팔 6개의 스터드를 밀어 팔과 테 조각이 한꺼번에 바깥(또는 안)으로 미끄러진다.
판화 묘사(원본 510×516 px, 정면): 중심 약 [227·223]. 바깥에 **테 조각 6개**(반지름 ≈ 190 px, 조각 사이 틈은 30°+60°k 자리 — 팔 사이). **팔 6개**가 0°·60°·120°·180°·240°·300° 방향으로 곧게 뻗음(팔마다 가운데 긴 홈, 그 홈에 동그란 핀 — 반지름 ≈ 128 px). 가운데 **바퀴 c**: 바깥 둘레에 이(약 36개, 바깥 반지름 ≈ 87 px), 판 안에 **굽은 홈 6개**(안쪽 끝 반지름 ≈ 27 px, 바깥 끝 ≈ 69 px, 반시계로 갈수록 바깥으로 — 홈 하나가 약 74° 걸침), 홈마다 점(스터드, 반지름 ≈ 54 px, 팔과 같은 방향). 가운데 축 고리 + 점. 위쪽(약 96°, 중심에서 121 px)에 **작은 피니언 d**(이 약 10개)가 c 의 이와 물림 — 피니언 뒤에 굽은 받침판(위 두 팔 사이). 글자: d(피니언), c(바퀴), 왼쪽 팔 위 b(팔 바깥쪽), a(왼쪽 팔의 동그란 핀 옆).

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.005.
1. 바퀴는 몇 개이고 크기 차례는? → 기어 2개: 바퀴 c(이 36, 피치 반지름 0.432) > 피니언 d(이 10, 피치 반지름 0.12). 풀리 자체는 테 조각 6개가 모인 원(바깥 반지름 0.885 ~ 1.045, 판화 자세 0.965).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에 없음(지름이 변하는 풀리 자체만 그렸다). 이 모델도 벨트 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 가운데 축(뒤판 받침에 고정)과 그 축에 박힌 거미판(팔의 안내 띠 6개·피니언 받침판). 데모에서는 풀리 전체를 돌리지 않고 거미판을 멈춰 둔다.
5. 추·손잡이·크랭크는? → 판화에 없음. 피니언 d 축 앞에 작은 손잡이 원판(보충)을 두어 사람이 돌리는 것으로 본다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 바퀴 c 는 **바깥 둘레**에 이, 피니언 d 는 c 의 **바깥(위쪽, 90°)**에서 물림(바깥 물림, 반대 방향으로 돎).
7. 한 줄에 놓인 것은? → 팔 k 의 반지름 선 위에: c 의 홈 속 스터드, 팔의 안내 핀(반지름 0.64), 테 조각 k 의 가운데. 피니언 d 중심은 c 중심의 바로 위(같은 세로선 x = 0).
8. 판화의 글자가 가리키는 부품은? → **d** = 피니언, **c** = 굽은 홈 바퀴, **b** = 왼쪽 팔(바깥쪽), **a** = 왼쪽 팔 홈에 낀 동그란 핀(안내 핀). (a·b 는 원문에 없다 → ★질문 거리 1)
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 구조는 일치. ① 원문 "studs fastened to arms" 의 스터드는 판화에서 **c 의 홈 속 점**이고, 팔 위 동그란 원(a)은 거미판에 박혀 팔 홈을 안내하는 핀으로 해석(→ 질문 1). ② 피니언은 판화에서 약 96° 자리 → 90° 로 맞춤(c 와 같은 세로선). ③ 판화 위쪽 굽은 받침판의 작은 홈·점(잠금 나사로 보임)은 생략 → 질문 2. 계속 돌 수 없는 곳은 없음(왕복 동작으로 홈 끝에 닿지 않게 범위를 정함).

## 해석(결정 사항)
- 거미판(가운데 원판 + 팔 안내 띠 6 + 피니언 받침판)은 축에 고정되어 멈춰 있다. 바퀴 c 는 축에 헐겁게 끼워져 피니언 d 에 의해 돈다(각 Δ). 팔 6개는 각자 반지름 방향으로만 미끄러진다(안내 핀이 팔의 긴 홈에, 스터드가 c 의 나선 홈에).
- c 의 홈 중심선(c 로컬 극좌표): **r = 0.145 + 0.15485·(φ − φin,k)**, φ ∈ [φin,k, φin,k + 1.2915 rad(74°)], φin,k = ψk − 0.67813 rad(38.85°), ψk = k·60°. 그래서 c 가 Δ 돌면 스터드 반지름 rs = 0.25 − 0.15485·Δ.
- 피니언 d 를 왕복으로 돌려 rs = 0.25 + 0.08·sin(0.5t) (0.17 ~ 0.33). 풀리 바깥 반지름 = rs + 0.715 (0.885 ~ 1.045, 지름 1.77 ~ 2.09).
- 판화에 없는 보충: 뒤판 축받이·가운데 고정 축·거미판(뒤 층, 어두운 색), 피니언 손잡이 원판(노란 표시), c 의 노란 표시 막대.

## 구동
피니언 d 가 입력(손잡이). 시간 함수(결정적):
- Δ(t) = −0.51663·sin(0.5t) [rad] (c 의 rotation.z). 0.51663 = 0.08 / 0.15485.
- rs(t) = 0.25 + 0.08·sin(0.5t).
- 피니언 각 θd(t) = `meshAngle([0, 0], 36, Δ, [0, 0.552], 10)` (바퀴 c 를 기어1로, 중심은 O 기준 로컬). dθd/dΔ = −3.6.
- t = 0 = 판화 자세(rs 0.25, 테 바깥 반지름 0.965). 주기 12.566 초(t = 3.14 에서 가장 큼, 9.42 에서 가장 작음).

## 동작 (`state224(t)` — 결정적)

4. 홈 검산: 스터드 c 로컬 각 φ = ψk − Δ → φ − φin,k = 0.67813 − Δ ∈ [0.1615, 1.1948] ⊂ [0, 1.2915]. 홈 양 끝에서 각 0.16·0.097 rad 여유(반지름으로 0.025·0.015).
