# 039 태양-유성 기어
판화: 왼쪽에 플라이휠 축의 태양 기어(바깥에 4조각 림), 오른쪽에 같은 크기의 유성 기어. 팔이 두 중심을 이어 거리를 고정하고, 연결봉이 유성 기어 중심에서 위로 올라간다(유성에 단단히 붙음). 원문(와트): 연결봉에 고정된 유성이 한 번 돌 때(공전) 태양 기어(플라이휠 축)는 두 번 돈다.
구동: 팔 각 alpha += OMEGA·speed·dt (연결봉 한 번 오르내림 = alpha 2π).

## 부품과 치수
- 잇수 20, 모듈 0.04 → 피치 반지름 0.4, 팔 길이 D = 0.8. 태양 중심 S = (−0.2, 1.55) 고정, 기어 z = 0.13, 폭 0.1.
- 태양: `spurGear(20, 0.04, { width: 0.1, spokes: 4, driver: true })`. 뒤쪽 z 0.03 에 플라이휠 `pulley(0.64, { width: 0.06, spokes: 4, flat: true })`(같은 축·같은 각). `shaftZ(S, 0.34, 0.05)`.
- 유성: `spurGear(20, 0.04, { width: 0.1, spokes: 4 })`, 중심 P = S + D(cos α, sin α).
- 팔: 스타디움 막대 길이 0.8(z 0.215) 양끝 머리 캡, S 중심으로 α 회전. 연결봉: 길이 0.72 막대 + 윗 눈(고리), 유성 중심에서 위로, 회전 없이 평행 이동(z 0.275).

## 동작 (식)
- 유성은 연결봉에 고정이라 절대 자세가 일정(ε = 0). 팔 각 α, 유성 절대 회전 0 일 때 ω태양 = ω팔 · (1 + z유성/z태양) = 2·α' (잇수 같음).
- 태양 각 θs = 2α + π − 1.5·(2π/20) — meshAngle 의 맞물림 조건에서 나온 값(유성 자세 0). 유성 자세는 `meshAngle(S, 20, θs, P, 20)` 로 계산(항상 같은 값이어야 한다).
- arm.rotation.z = α, sun/flywheel.rotation.z = θs, planet.position = P, rod.position = P.

## 표시
- rotArrow(0.55, true) 태양 앞. tag: ‘태양 기어’(고정), ‘유성 기어’(유성을 따라 이동 — 위치는 끝의 "검증 후 수정"), ‘연결봉’.
- notes: 식, 공전 : 태양 = 1 : 2, 태양 회전수.

## 확인
- t=1, 1.6: 팔이 각 α 만큼 돌고 유성 표시점은 같은 방향을 유지(절대 회전 없음), 태양 표시점은 α 의 두 배 각만큼 돈다. 이가 박히지 않는다.
