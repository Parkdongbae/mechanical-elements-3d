# 200 한 바퀴로 두 속도
원문: "A mode of obtaining two different speeds on the same shaft from one driving-wheel." — 구동 바퀴 하나로 같은 축에서 두 가지 속도를 얻는 방법. 쉬운 풀이: 크기가 다른 두 기어가 한 축에 있고, 구동 기어가 위 것 또는 아래 것과 맞물려 속도가 둘 중 하나가 된다.

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 px [x·y]).
1. 바퀴는? → 세로축에 마주 보는 원뿔 모양 기어 2개(위 큰 것 [100~350·190~240], 아래 작은 것 [150~300·325~365]). 오른쪽에 비스듬한 막대(축)를 끼운 띠 모양의 구동 기어 1개.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 세로축은 위아래로 길게 뻗어 있으나 받침은 그리지 않음.
5. 구동은? → 오른쪽 비스듬한 막대(축) [270~440·260~350]의 구동 기어(원문 "one driving-wheel").
6. 기어는? → 위·아래 기어 모두 마주 보는 면에 이가 났고, 구동 기어가 둘 사이의 오른쪽에서 위 또는 아래 이에 물린다.
7. 한 줄에 놓인 것은? → 두 이판과 세로축은 같은 세로선(x 230).
8. 글자가 가리키는 부품은? → 글자 없음(번호 200 뿐).
9. 판화와 원문이 다르거나 돌 수 없는 곳은? → 판화는 원뿔(베벨)로 그려졌으나 같은 평기어 하나가 두 베벨과 모두 바르게 물릴 수 없다(원뿔 각이 다름). 마주 보는 두 이판(크라운, 이가 면에 선 기어)과 평기어로 풀었다. 질문 거리 없음.

## 해석(결정 사항)
- 이판: 위 24 잇수(맞물림 반지름 0.432, 이가 아래), 아래 16 잇수(0.288, 이가 위). 모듈 0.036. 평기어 10 잇수(피치 반지름 0.18). 속도비 평기어 : 이판 = 10 : 24(0.42) 또는 10 : 16(0.63).
- 평기어 축은 위 이판 맞물림 자리(x −0.018, y 1.87)와 아래 이판 맞물림 자리(x −0.162, y 1.71) 사이를 비스듬히(판화의 기울어진 막대) 미끄러진다. 오른쪽 안내판의 세로 홈이 축을 안내한다.
- 방향은 두 모드가 서로 반대(평기어가 위 이판은 아래에서, 아래 이판은 위에서 문다). 판화 문구의 "같은 방향"과 다르다.
- 한 번 옮기는 사이(어느 이판에도 안 물림)는 세로축이 멈춘다. 한 주기 평기어 각 `PERIOD200`은 위상이 닫히도록 정함(아래 이판의 놓인 각 `EPS200` 포함).
- 판화에 없는 보충: 세로축 받침 둘(뒤판), 안내판, 축 끝 손잡이.

## 구동
평기어 theta 누적(+X 둘레), theta += OMEGA·speed·dt. 세로축은 종동.

## 부품과 치수 (새 부품은 `kit/k200.ts`, 이미 구현됨. 상수 `K200`)
세로축 (x −0.45, z 0.27). 위 이판 피치 평면 y 2.05, 아래 1.53(간격 0.52). 이판 지름 약 1.0 이라 z −0.24~0.78.
- 위 이판(name `crownU`): `crownGear(24, 0.036, {width 0.12, bore 0.045})` 로컬 +Z → −Y(`rotation.x = π/2`).
- 아래 이판(name `crownL`): `crownGear(16, 0.036, {width 0.12, bore 0.045, driver})` 로컬 +Z → +Y(`rotation.x = −π/2`), 메시 `rotation.z = EPS200`.
- 세로축(name `axisY`): 반지름 0.038, y 0.85~2.95, 피벗 +Y 둘레. 받침 `wallRing200(−0.45, 2.55)`, `(−0.45, 1.1)`.
- 평기어(name `pinion`): `spurGear(10, 0.036, {width 0.1, spokes 4, driver})` 축 +X, 수레 `carriage` 위치 (x, y, 0.27), 평기어 축 막대 반지름 0.022 길이 1.6, 끝 손잡이 x +1.42.
- 안내판(고정): `slotPlate200()` x 1.15, 세로 홈 y 1.71~1.87.
- 전체 범위: x −0.96~1.9, y 0.85~2.95.

## 동작 (theta 의 닫힌 식 — `state200(theta)` = { psi, s, mode, dir, x, y })
`axisY.rotation.y = psi`, 수레 위치 (x, y), `pinion.rotation.x = theta`. 위 이판 물림: psi = ψa − (10/24)θ(방향 −), 놓임, 아래 이판: psi 증가 (10/16)θ(방향 +). 시각: t = 1 (위 이판), 1.6, 7(아래 이판), 30.
