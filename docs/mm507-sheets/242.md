# 242 띠 브레이크
원문(en): "A brake used in cranes and hoisting machines. By pulling down the end of the lever, the ends of the brake-strap are drawn toward each other, and the strap tightened on the brake-wheel." — 기중기와 감아올리는 기계에 쓰는 브레이크. 레버 끝을 아래로 당기면 브레이크 띠의 양 끝이 서로 가까워지고, 띠가 브레이크 바퀴를 죈다.
쉬운 풀이: 바퀴를 거의 한 바퀴 감싼 얇은 띠의 두 끝을 레버에 걸었다. 레버 끝을 내리면 띠 위 끝이 아래 끝 쪽으로 당겨져 띠가 바퀴를 꽉 죄고, 마찰로 바퀴가 멈춘다.
판화 묘사(원본 485×426 px, 정면): 왼쪽에 큰 브레이크 바퀴(바깥 띠 지름 262 px, 중심 ≈[170·224]) — 가운데 둥근 보스 안에 검은 축. 바퀴 둘레를 두 줄 선의 얇은 띠가 위·왼쪽·아래로 감싸고, 오른쪽에서 두 가닥으로 떨어져 나온다. 위 가닥은 오른쪽 아래로 내려와 작은 고리 A′[305·215] 를 지나 큰 고리 [334·249] 로, 아래 가닥은 작은 고리 [293·257] 에서 끝난다. 아래 작은 고리 → 큰 고리 → 오른쪽 손잡이 끝 [445·228] 이 **한 직선**(레버, 기울기 10.8°)이다.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px = 0.00813(띠 안쪽 반지름 123 px = 1.0).
1. 바퀴는 몇 개이고 크기 차례는? → 브레이크 바퀴 1개(테 바깥 반지름 1.00). 다른 바퀴 없음.
2. 줄·벨트는? → 띠 1개(얇은 쇠띠, 두께 0.025, 폭 0.12). 아래 끝 = 레버 받침점 핀 B, → 바퀴 오른쪽 아래(접점 322°)에서 바퀴에 붙어 **아래 → 왼쪽 → 위**로 바퀴 둘레를 287° 감고 → 오른쪽 위(접점 35°)에서 떨어져 → 위 끝 고리 A → 링크 → 레버의 핀 P.
3. 교차하는 가닥이 있는가? → 없음(두 가닥 모두 바퀴 오른쪽, 위 가닥이 위·아래 가닥이 아래).
4. 고정점은? → 바퀴 축(뒤판), 레버 받침점 B(뒤판에서 나온 핀 — 띠 아래 끝도 이 핀에 걸림). 보충: 위 멈춤 핀 `upStop`, 용수철 걸이 `springPeg`(둘 다 뒤판).
5. 추·손잡이·크랭크는? → 손잡이 = 레버 오른쪽 끝(나무 손잡이). 사람이 이 끝을 내린다(빨간 화살표).
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 받침점 B · 핀 P · 손잡이 끝 H 가 한 직선(레버). 위 띠 가닥 · 고리 A · 핀 P 가 한 직선(띠가 당기는 방향 = 링크 방향).
8. 글자가 가리키는 부품은? → 글자 없음(번호 242 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 큰 고리 P 를 받침점으로 읽으면 두 띠 끝이 레버에 단단히 붙어 서로 가까워지지 않는다(원문과 어긋남). 그래서 **아래 작은 고리 B 를 받침점**(띠 아래 끝도 여기 고정), P 를 레버 위 핀, A–P 를 짧은 링크로 읽는다 — 그러면 레버를 내릴 때 P 가 내려가 A 를 B 쪽으로 당겨 "양 끝이 가까워진다"가 그대로 맞고, B·P·H 가 한 직선인 판화와도 맞는다. 띠는 안 늘어나므로 죌 때 띠가 바퀴에서 뜨는 틈은 0.029 뿐(실제 브레이크처럼 작음). ★질문 거리.

## 해석(결정 사항)
- 바퀴 중심 W = (−0.65, 1.65). 받침점 B = W + 1.10·(cos −14.9°, sin −14.9°) = (0.4130, 1.3672)(판화는 1.04 — 틈이 열릴 자리를 위해 1.10 으로 조금 뗌). 레버: B 에서 P 까지 0.34, 손잡이 끝 H 까지 1.26. 링크 A–P 0.363.
- 레버 각 ε: 죈 자리 ε0 = 10.8°(판화 자세), 푼 자리 εR = 35.8°(손잡이를 25° 들어 올림, 위 멈춤 핀에 닿음).
- 띠 길이 L0 = 6.121087 이 늘 같다. 레버 각마다 띠가 감기는 원 반지름 Rb(띠 두께 가운데)를 이분법으로 풀어 L = L0 이 되게 한다. 죈 자리 Rb = 1.0125(띠 안쪽이 바퀴 테 1.00 에 닿음), 푼 자리 Rb = 1.0411(틈 0.0286).
- 바퀴는 짐에 끌려 반시계로 돌다가, 띠가 닿으면 1.5 초 동안 고르게 느려져 멈추고, 풀면 다시 돈다(시간표).
- 판화에 없는 보충: 되돌림 용수철(레버를 푼 자리로 올림)과 걸이, 위 멈춤 핀, 빨간 당김 화살표, 바퀴 노란 표지, 죄는 동안 띠 빨강.

## 구동
한 주기 12 초, τ = t mod 12, s(u) = u²(3 − 2u)(u 는 0~1 로 자름).
- 레버 각 ε(t): τ < 2 → εR / 2 ≤ τ < 3 → εR + (ε0 − εR)·s(τ − 2) / 3 ≤ τ < 8 → ε0 / 8 ≤ τ < 9 → ε0 + (εR − ε0)·s(τ − 8) / τ ≥ 9 → εR. (ε0 = 0.188496 rad, εR = 0.624828 rad.)
- 바퀴 각 θw(t) = 9.375·floor(t/12) + a(τ): τ < 3 → 1.5τ / 3 ≤ τ < 4.5 → 4.5 + 1.5u − 0.5u²(u = τ − 3) / 4.5 ≤ τ < 9 → 5.625 / 9 ≤ τ < 10 → 5.625 + 0.75u²(u = τ − 9) / τ ≥ 10 → 6.375 + 1.5(τ − 10). (끊김 없음 — 3, 4.5, 9, 10, 12 초에서 양쪽 값 같음, 검산.)
- 바퀴 빠르기 ω: 1.5 → (3~4.5 초) 0 으로 → (9~10 초) 1.5 로.

## 동작 (모델 `update` 안 — 결정적, t 만으로)
1. τ = t mod 12, ε = ε(t), θw = θw(t)(구동 절).
2. P = B + 0.34·(cos ε, sin ε). dP = |P − W|, aP = atan2(Py − 1.65, Px + 0.65).
3. 띠 반지름 Rb: lo = 1.0, hi = 1.06 에서 60 번 이분법 — 가운데 m 으로 L(m) 을 계산해 L(m) > L0 이면 hi = m, 아니면 lo = m. L(Rb) 식:
   - tA = aP + acos(Rb/dP)(위 접점 각), sP = √(dP² − Rb²)
   - tB = AB − acos(Rb/1.10)(아래 접점 각), sB = √(1.21 − Rb²)
   - wrap = (tB − tA) 를 0~2π 로 접은 값(반시계로 tA → 위·왼쪽·아래 → tB)
   - L = (sP − 0.363) + Rb·wrap + sB
4. TA = W + Rb·(cos tA, sin tA), TB = W + Rb·(cos tB, sin tB), A = P + 0.363·(TA − P)/sP(위 가닥·고리 A·핀 P 한 직선).
5. 적용: `wheel.rotation.z = shaft.rotation.z = θw`, `lever.rotation.z = ε`, 링크 위치·각, 띠 세 토막·고리 A, 용수철, 당김 화살표, 바퀴 화살표 `visible = ω > 0.05`.
