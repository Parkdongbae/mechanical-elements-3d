# 056 선반 변속 레버
판화(public/mm507/fig/056.png, 확대 shots/_verify/056-fig-x4.png 로 다시 읽음 — Fable 교차 읽기 2026-11-25): 그림 하나. 선반 주축대를 축 방향에서 본 그림이다. 왼쪽에 큰 평기어(이 약 48개), 오른쪽에 3단 단차 풀리(동심 호 3겹)와 그 앞의 작은 피니언(윗부분 이 4~5개만 프레임 윗턱 위로 보임). 피니언·단차 풀리는 같은 축(주축)이고, 그 축은 **큰 바퀴 축과 같은 높이**에 있다(물림 자리는 프레임 뒤에 가려 있다). 앞쪽에 주철 프레임(받침 + S자 목 + 왼쪽으로 뻗은 팔)이 큰 바퀴 **앞**을 가로지르고, 그 팔 왼쪽 끝에 레버의 받침점(이중 원)이 있다. 레버는 받침점에서 위로 곧게 선 긴 손잡이(끝이 둥근 방울)와, 받침점에서 오른쪽 아래로 불룩한 판으로 된 한 몸이다. 판에는 **휜(원호) 홈**이 있고 홈의 오른쪽 위 끝에 큰 바퀴 축 핀(작은 원)이 들어 있다. 홈은 핀 자리에서 왼쪽 아래로 내려가며 받침점에 가까워진다(받침점–홈 거리: 핀 쪽 끝 0.44 → 반대 끝 0.27, 큰 바퀴 피치 반지름 0.96 기준). 받침점·핀·주축은 거의 한 수평선 위에 있다.
원문 요지: 선반에서 속도 변환 기어를 맞물리거나 풀어 주는 장치. 레버를 누르면, 큰 바퀴 축이 미끄러지는 홈이 레버의 받침점에 대해 치우쳐(편심으로) 파여 있어 큰 바퀴 축이 뒤로 끌려가 이가 풀린다.

★ 판화 읽기
1. 바퀴: 3개. 단차 풀리(3단, 가장 큰 단이 큰 바퀴보다 조금 큼) > 큰 평기어(약 48) > 피니언(약 14). 단차 풀리와 피니언은 한 축.
2. 줄·벨트: 판화에 없음(단차 풀리에 걸릴 벨트는 그려지지 않았다). 만들지 않는다.
3. 교차 가닥: 없음.
4. 고정점: 프레임(바닥 받침 위에 선 주철 몸). 레버 받침점과 주축 베어링(네모 상자 속 원)이 프레임에 있다. 큰 바퀴 축은 프레임의 가로 안내 홈에서 좌우로 미끄러진다(레버 판 오른쪽의 네모 턱이 그 안내 자리).
5. 손잡이: 레버 하나. 받침점에서 위로 선 긴 막대(길이 ≈ 큰 바퀴 반지름의 1.6배), 끝에 둥근 방울. 받침점 아래·오른쪽으로 홈 판이 한 몸.
6. 기어: 둘 다 바깥 이. 피니언이 큰 바퀴의 **오른쪽(같은 높이)** 에서 물린다. 판화에서 물림 자리는 프레임 윗턱에 가려 있다.
7. 한 줄에 놓인 것: 레버 받침점 — 큰 바퀴 축 핀 — 주축(피니언·단차 풀리)이 한 수평선. 레버 손잡이는 받침점 바로 위 세로선.
8. 글자: 판화에 글자 없음.
9. 판화와 원문이 다른 곳: 없음. 판화는 맞물린 상태만 보여 준다. 레버를 "누르는" 방향은 손잡이가 왼쪽 아래로 넘어가는 쪽(홈이 받침점에 가까워지는 끝이 핀 쪽으로 올라오는 회전)으로 읽었다.

## 구동
피니언(구동, 반시계, theta += OMEGA·speed·dt). 피니언은 쉬지 않고 돌고, 큰 바퀴만 레버가 맞물리고 푸는 시간표(아래)에 따라 돈다 또는 선다. 레버 자세는 theta 의 함수로 자동 반복(눌렀다 올림).

## 레버 홈 해석 (원호 홈, 핀은 y = 1.50 수평선 위)
핀이 W0 에서 s(0 ~ 0.17)만큼 왼쪽으로 물러날 때 레버 각 ψ(s):
- ρ(s) = 0.44 − s (받침점–핀 거리), e = 0.1714, 홈 반지름 0.2865.
- K(s) = (ρ² + e² − 0.2865²) / (2ρe), ψ(s) = acos K(s) − acos K(0). ψ(0) = 0, 반시계가 +.
- 값: s = 0 / 0.03 / 0.06 / 0.09 / 0.12 / 0.15 / 0.17 → ψ = 0° / 13.9° / 24.3° / 33.5° / 42.1° / 50.7° / 56.5°.
- 레버가 반시계로 약 56° 넘어간다(손잡이가 왼쪽 아래로 "눌림"). 그때 손잡이 끝 = (−2.05, 2.30), 구슬 포함 x ≥ −2.10(전시 x ±2.2 안). 곧은 자세의 손잡이 끝 y = 2.95.
- 레버 로컬 핀 위치 q(s) = (ρ cos ψ, −ρ sin ψ) 는 언제나 홈 중심선 위(Cs 까지 거리 0.2865). 판화의 홈 방향(핀 쪽 끝에서 왼쪽 아래로 휘어 받침점에 가까워짐)과 같다.

## 동작 (모든 자세는 theta 의 절대 함수)
- 주기 8.0 rad(구동각 기준). τ = θ mod 8. f(x) = x²(3−2x).
  - 0 ~ 1.9: 맞물림(s = 0) · 1.9 ~ 2.6: 풀림 이동 · 2.6 ~ 5.0703: 풀린 채 정지(s = 0.17) · 5.0703 ~ 5.7703: 다시 맞물림 이동 · 5.7703 ~ 8: 맞물림.
  - s(τ) = 0.17·f((τ − 1.9)/0.7) (풀림), 0.17·(1 − f((τ − 5.0703)/0.7)) (맞물림). 맨 처음(t = 0)은 맞물림.
- 이끝이 서로 벗어나는 한계: 중심 거리 > 1.32(이끝 반지름 합 0.32 + 1.00) → s ≥ 0.08. 여유를 두어 s = 0.09 에서 큰 바퀴 구동을 끊는다. f⁻¹(0.09/0.17) = 0.5205, 정지 시작 t0 = 1.9 + 0.7·0.5205 = 2.2643, 정지 끝 = 5.0703 + 0.7·(1 − 0.5205) = 5.4060, 정지 길이 = π (= 피니언 이 14개 중 정확히 7피치).
- 유효 각 Q(θ) = θ − (지난 정지 구간 수)·π − (τ < t0 이면 0, t0 ≤ τ ≤ t0 + π 이면 τ − t0, 그 뒤 π). 정지가 정확히 7피치라 다시 맞물릴 때 이가 이골에 곧바로 들어간다(위상 점프 없음).
- 위치: 큰 바퀴 중심 (W0.x − s(τ), 1.50), 핀·이름표도 같이. 물러나는 방향이 두 중심을 잇는 선(수평)이라, 부분 물림(0 < s < 0.09) 동안 W0 기준 위상을 그대로 써도 틈만 커지고 침범은 없다.
- 큰 바퀴 자세: rotation.z = `meshAngle([0.84, 1.50], 14, Q, [−0.40, 1.50], 48)` (맞물림일 때 속도비 −14/48 = −0.2917, 시계. 풀리면 Q 가 멈춰 바퀴도 정지).
- 피니언 rotation.z = θ (반시계), 단차 풀리 같은 각. 레버 그룹 rotation.z = ψ(s).

## 판화 대조 후 고친 것 (Fable 교차 읽기 2026-11-25)
- 피니언 위치: "큰 바퀴 오른쪽 위 25°" → **같은 높이의 오른쪽**(판화의 주축 베어링·단차 풀리 중심이 큰 바퀴 축과 한 수평선).
- 레버 홈: 직선 홈 → **휜 원호 홈**(판화·원문 "치우쳐 파인 홈"). 받침점은 "홈보다 왼쪽 아래"가 아니라 핀과 같은 높이의 왼쪽. 레버 기울기 30° → 56°.
- 받침점 지지: 판화에 없는 앞 기둥·가로 막대·뒤 안내 블록 → 판화의 **앞 프레임 팔**(받침점 + 안내 홈)로 바꿈.
