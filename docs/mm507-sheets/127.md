# 127 공기 펌프용 랙과 피니언
원문: "Motion used in air-pumps. On vibrating the lever fixed on the same shaft [with] the spur-gear, reciprocating rectilinear motion is imparted to the racks on each [side], which are attached to the pistons of [two] pumps, one rack always ascending while [the] other is descending." — 공기 펌프에 쓰는 운동. 평기어와 같은 축에 고정된 레버를 흔들면 기어 양쪽의 랙이 곧게 왕복한다. 랙은 두 펌프의 피스톤에 붙어 있고, 한 랙이 올라가면 다른 랙은 늘 내려간다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/127-fig-x4.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 평기어(피니언) 1개가 한가운데. 판화 치수(px): 축 자리 x 214, y 221. 이끝 원 반지름 83 쯤, 이가 20° 간격(반지름 78 원에서 이 경계가 0°·20°·43°·63°·84°… 로 재짐) → **18잇수**, 랙의 이 간격 24px × 18 ÷ 2π = 피치 반지름 69. 테 안쪽에 굽은 살 4개와 허브(두 겹 원).
2. 줄·벨트는? → 없음. 대신 **세로 랙 2개**: 왼쪽 랙(x 104 ~ 151, y 40 ~ 345)은 이가 **오른쪽**(기어 쪽) 가장자리에, 오른쪽 랙(x 281 ~ 332, y 115 ~ 435)은 이가 **왼쪽**(기어 쪽) 가장자리에 났다. 둘 다 13잇수쯤(이 간격 23.8px·24.6px), 길이 약 305·320px. 그리고 **곧은 레버 1개**: 왼쪽 위의 공 손잡이(15, 133)에서 오른쪽 아래의 공 손잡이(424, 318)까지 한 직선이고, 그 직선이 기어 축 자리를 지난다(x 214 에서 y 223).
3. 교차하는 가닥은? → 레버가 두 랙과 기어의 **뒤**를 지난다: 레버 선이 왼쪽 랙의 왼쪽 변에서 끊기고 오른쪽 랙의 오른쪽 변에서 다시 나온다(랙·기어 선은 끊기지 않음).
4. 고정점은? → 기어 축(제자리에서 돎). 랙을 곧게 잡아 주는 안내와 펌프는 그리지 않았다.
5. 추·손잡이·크랭크는? → 레버 양 끝의 공 손잡이 2개(두 사람이 마주 잡고 흔드는 꼴). 레버는 기어와 **같은 축에 고정**(원문). 판화의 순간에 레버는 왼쪽이 들린 채 24.3° 기울어 있다(수평에서 시계 방향으로 24.3°).
6. 이는 어디에 났고 무엇이 물리는가? → 피니언은 바깥 둘레 전체에 이. 왼쪽 랙의 이가 피니언의 왼쪽(180° 방향)에서, 오른쪽 랙의 이가 피니언의 오른쪽(0° 방향)에서 물린다. 피니언이 시계 방향으로 돌면 왼쪽 랙이 올라가고 오른쪽 랙이 내려간다.
7. 한 줄에 놓인 것은? → 두 랙이 서로 나란한 세로선, 피니언 축에서 좌우 같은 거리. 레버의 두 손잡이와 축이 한 직선. 판화의 순간 왼쪽 랙이 오른쪽 랙보다 75 ~ 90px 높다(레버가 시계 방향으로 돌아간 자세와 맞는 방향).
8. 글자가 가리키는 부품은? → 글자 없음(번호 127 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳이 없다. 랙의 높이 차(랙 하나가 가운데에서 약 41px = 피치 반지름의 0.6배 → 기어 각 34°)와 레버 기울기(24.3°)가 10° 쯤 어긋나지만 그림 오차로 보고, 모형은 레버가 수평일 때 두 랙이 같은 높이가 되게 한다(레버 각 = 기어 각). 기구 해석에는 영향 없음. 문제 없음.
- 그 밖의 선: 두 랙의 아래 끝은 물결 모양 파단선(더 내려가 피스톤에 이어진다는 뜻), 위 끝은 반듯하게 마감. 오른쪽 랙의 오른쪽 변·윗변이 굵은 것은 음영. 왼쪽 가장자리의 긴 세로선은 판화 칸의 테두리.

## 해석(결정 사항)
- 기구: 레버를 시소처럼 흔들면 같은 축의 피니언이 좌우로 번갈아 돌고, 피니언 양옆에 마주 물린 두 랙이 서로 반대로 오르내린다. 랙 아래에 달린 피스톤 두 개가 번갈아 내려가므로 쉬는 행정 없이 펌프질이 이어진다.
- 판화 비: 피니언 18잇수(피치 반지름 69px → 0.405, 모듈 0.045), 랙 13잇수(길이 1.838), 레버 반길이 216 ~ 233px ≈ 피치 반지름의 3.2배 → 1.3. 판화의 순간(레버가 시계 방향 24.3°, 왼쪽 랙이 위)을 t = 1 로 맞춘다.
- 레버 흔들림 진폭은 ±30° 로 정함(판화의 순간 24.3° 가 그 안의 한 자세).
- 판화에 없는 보충(최소): 랙 등받이 롤러 4개(랙이 피니언에서 밀려나지 않게 — 안내), 랙 아래의 피스톤 막대·피스톤과 유리 실린더 2개(원문에만 나오는 "펌프의 피스톤"을 보이게, 실린더 뚜껑이 막대 안내를 겸함), 축의 뒤판 받침, 공통 받침대.

## 구동
레버(손으로 흔듦). theta += OMEGA(1.6)·speed·dt. 레버·피니언 각 phi = 30°·sin(theta − 1.6 − 0.944) (0.944 = asin(24.3/30)) — 한 번 왕복 3.93 s.

## 동작 (모두 theta 의 닫힌 식 — `pump127(theta)` 가 돌려준다)
- phi = 30°·sin(theta − 1.6 + asin(−24.3/30)) (반시계 +). `pinion.rotation.z = phi`, `lever.rotation.z = phi` (같은 축).
- 왼쪽 랙 yL = 2.0 − 0.405·phi(rad), 오른쪽 랙 yR = 2.0 + 0.405·phi. 범위 1.788 ~ 2.212(행정 0.424), 늘 yL + yR = 4.0(하나가 오르면 다른 하나가 같은 만큼 내린다).
- 맞물림 위상: phi = 0 에서 피니언의 이골이 정확히 0°·180° 를 향하고(18잇수 `spurGear` 기본 위상) 두 랙의 가운데 이가 축 높이에 온다 → 위 식 그대로 두면 이가 맞는다(더할 상수 없음).
- 시각: **t = 1.0 (theta 1.6, phi −24.3° — 판화 자세: 레버 왼쪽이 위, 왼쪽 랙 2.172, 오른쪽 랙 1.828)**, **t = 1.6 (theta 2.56, phi +0.5° — 레버가 거의 수평, 두 랙이 거의 같은 높이 1.997·2.003)**.
