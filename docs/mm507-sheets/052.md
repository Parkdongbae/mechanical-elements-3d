# 052 핀 원판 클러치
판화: 가로 축(좌우)이 한 줄로 놓이고 왼쪽부터 ① 왼쪽 끝 작은 축 토막과 굵은 허브 블록, ② 두꺼운 원판(오른쪽 면에서 위·아래 두 곳에 짧은 돌기=스터드가 튀어나옴), ③ 가는 축이 오른쪽으로 이어지고, ④ 얇고 키 큰 원판(구멍 원판)이 그 축에 끼워져 있다 — 키는 왼쪽 원판보다 약간 크다, ⑤ 원판 뒤로 허브와 홈 달린 고리(깃), ⑥ 그 깃에 핀으로 걸린 막대(받침점 원이 아래에 있고 오른쪽 아래로 긴 손잡이가 뻗음), ⑦ 오른쪽 축 끝 머리(둥근 끝, 가운데 가로 홈). 그림의 상태는 두 원판이 떨어져 있다. 원문: 또 다른 종류의 클러치 상자다. 오른쪽 원판에는 다른 원판에 고정된 스터드에 맞는 구멍이 두 개 있다. 눌러 붙이면 스터드가 구멍에 들어가 두 원판이 함께 돈다.

판화 해석: 그림 하나뿐이므로 그것을 만든다. 왼쪽 부분(왼쪽 원판·허브·왼쪽 축 토막)은 구동 쪽 "구동 슬리브"이고 굵은 허브 속을 가는 축이 헐겁게 지나간다. 오른쪽 부분(구멍 원판·허브·깃·축·머리)은 피동 쪽이고 축에 키로 끼어 미끄러진다. 레버는 깃 **아래 왼쪽**에 받침점이 있고 손잡이가 **오른쪽 아래**로 뻗는다 — 손잡이를 **들면**(레버가 반시계로 돌면) 위쪽 팔이 깃을 왼쪽으로 밀어 스터드가 구멍에 들어가고, 누르면 떨어진다. 판화에서 축이 이어져 보이는 것을 "피동 축이 구동 슬리브를 관통한다"로 해석했다(안 그러면 클러치가 의미 없다).

★ 판화 읽기 (질문표)
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 기어·풀리 없음. **원판 2개**: 왼쪽 = 두껍고 조금 작은 원판(오른쪽 면 위·아래에 스터드 2개), 오른쪽 = 얇고 조금 더 큰 원판(구멍 원판, 옆에서 본 그림이라 구멍은 안 보임). 그 밖에 왼쪽 허브 블록, 오른쪽 원판의 허브, 홈 깃(칼라), 오른쪽 축 끝의 둥근 머리.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 레버의 **받침점(작은 겹원)** 하나 — 깃의 왼쪽 아래, 오른쪽 원판 아랫부분 앞. 축 받침은 판화에 없음(베어링 기둥 2개는 보충).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → **레버**: 위쪽 팔 끝의 핀이 깃의 홈에 걸리고, 받침점에서 **오른쪽 아래**로 긴 손잡이 팔이 뻗는다(ㄱ자로 꺾인 레버). 손잡이를 들면 원판이 왼쪽(스터드 쪽)으로 간다.
6. 기어는? → 없음. 물리는 것은 **스터드 2개 ↔ 구멍 2개**(축 방향으로 끼움).
7. 한 줄에 놓인 것은? → 모든 회전 부품이 **가로 축 한 줄** 위(왼쪽 축 토막 – 허브 – 왼쪽 원판 – 가는 축 – 오른쪽 원판 – 허브 – 깃 – 축 – 머리). 스터드 2개는 축에서 같은 거리(위·아래 대칭).
8. 글자가 가리키는 부품은? → 글자 없음(번호 52 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → 없음. 원문 "오른쪽 원판에 구멍 2개, 다른 원판에 스터드" = 판화. 두 원판 사이로 축이 이어져 보이는 것은 "한쪽 축이 다른 쪽 원판 속에 헐겁게 꽂혀 있다"로 읽었다(기구는 달라지지 않음).

구동: 구동 슬리브 theta += OMEGA·speed·dt (X 축 둘레). 피동 축은 클러치가 물릴 때만 돈다.

## 부품과 치수 (축 가로 X, 축 높이 Y = 1.95, 축 깊이 ZC = 0.275)
- 전시 영역: x ±1.6, y 최대 2.45, z: 오른쪽 원판 R 0.5 → ZC ± 0.5 = −0.225~0.775, 왼쪽 R 0.45 → −0.175~0.725. E6 만족(≤ 0.8, ≥ −0.25). 판화는 원판이 더 크지만 깊이 때문에 줄였다.
- 축 방향 배치는 판화 x 를 0.0075/픽셀로 옮긴 값(전체 폭 약 3.2).
- 구동 슬리브(청동, 모두 θ 로 회전): 입력 축 토막(반지름 0.06) x −1.58~−1.38, 허브 블록(반지름 0.12) x −1.38~−1.15, 왼쪽 원판 `clutchDisc(0.45, 0.16, { studs: { count: 2, radius: 0.36, r: 0.04, len: 0.17 }, hubR: 0.1, hubLen: 0.2, driver: true })`, 원판 x −0.95~−0.79(허브는 −1.15 까지), 스터드 끝 x −0.62. 로컬 Z → 세계 +X: 쿼터니언 = Rx(θ)·Ry(+90°). 스터드는 각 θ, θ+π.
- 피동 축(강철): 반지름 0.045, x −1.12~1.09(−1.12~−0.79 구간은 구동 슬리브 속, 숨음). 오른쪽 머리: 둥근 끝 원기둥 반지름 0.17 길이 0.48 x 1.09~1.57, 가운데 가로 홈 띠(darkSteel, 폭 0.04)와 표시선. 각 α 로 회전(Rx(α)).
- 구멍 원판(황동, 피동, 미끄러짐): `clutchDisc(0.5, 0.16, { holes: { count: 2, radius: 0.36, r: 0.07 }, hubR: 0.1, hubLen: 0.34 })`, 원판 x ∈ [f, f+0.16], 허브는 +X 쪽 f+0.16~f+0.5. 로컬 Z → 세계 −X: 쿼터니언 = Rx(α)·Ry(−90°). 구멍·스터드 모두 2개(π 간격)라 정렬 조건은 θ ≡ α mod π. 구멍 반지름 0.07 > 스터드 반지름 0.04 → 정렬 오차 ±0.03/0.36 = ±0.083 rad 허용.
- 깃(황동, 피동, name `collar`): x f+0.5~f+0.62, 가운데 목(반지름 0.10)과 양쪽 플랜지(반지름 0.19, 폭 0.025) = 홈. α 로 회전, x 는 f 를 따라 이동. 핀이 홈 바닥 위에 앉는다.
- 시프터 레버(name `shifter`, 받침점 P = (0.0, 1.125), 위쪽 팔 길이 Lr = 0.7 — 판화처럼 받침점이 원판 바로 아래, 깃의 **왼쪽 아래**): 받침 기둥(castIron 반지름 0.05, 뒤판 z −0.30 에서 z = ZC 까지) + 받침 핀. 팔은 P 에서 위로 0.7 올라가 끝 핀(반지름 0.025)이 깃 홈에 들어간다. 핀 중심 = P + Lr·(sin φ, cos φ), x = x_c = f + 0.56 이므로 φ = asin(x_c / 0.7) (−17.5° ~ +14.9°), 팔 그룹(원점 P) rotation.z = −φ. 핀 중심의 축에서의 거리 = 1.95 − (1.125 + 0.7 cos φ) = 0.125 ~ 0.157 → 목(0.10) + 핀 0.025 위, 플랜지(0.19) 안에서 홈을 따라 조금 오르내린다. 손잡이: P 에서 로컬 −16°(오른쪽 아래)로 길이 0.9, 끝에 나무 손잡이(rod + 짧은 원기둥). 손잡이 끝 y = 1.125 + 0.9·sin(−16° − φ) = 0.66(떨어짐) ~ 1.15(물림).
- 베어링 기둥(castIron): 왼쪽 x = −1.26(허브 블록을 감싸는 링 안 0.125 바깥 0.17), 오른쪽 x = 0.80(축 링 안 0.047 바깥 0.09), 뒤판에서 z = ZC 까지.

## 동작 — 주기 시간표 (간헐·클러치 — theta 로 절대 계산)
p = (theta + π) mod 4π, k = floor((theta + π)/4π). 주기 4π rad(속도 1 에서 약 7.85 s). 원판 위치 f 와 피동각 α:

| p 구간 | 상태 | f(원판 왼쪽 면 x) | α(피동각) |
|---|---|---|---|
| [π, 1.5π) | 떨어짐, 피동 정지 | −0.38 | E_k = 2πk |
| [1.5π, 1.9π) | 붙이는 중(손잡이 올라감) | smoothstep −0.38 → −0.60 | E_k |
| [1.9π, 2π−0.04) | 스터드 끝(−0.62)에 거의 닿은 채(간격 0.02) 스치며 대기 | −0.60 | E_k |
| [2π−0.04, 2π+0.04] | 스터드가 구멍에 들어감(θ ≡ 0 mod π: 정렬 순간) | smoothstep −0.60 → −0.77 | E_k |
| [2π+0.04, 2.8π] | 물림 — 함께 회전 | −0.77 | E_k + (p − 2π) |
| [2.8π, 3π] | 떼는 중(스터드가 빠짐), 원판은 관성으로 계속 | smoothstep −0.77 → −0.38 | E_k + (p − 2π) |
| [3π, 5π] (다음 주기 p < π 까지) | 관성 감속 → 정지 | −0.38 | E_k + π + g(p − 3π) |

- g(s) = s − s²/(4π) (속도가 1 → 0 으로 일정하게 줄어드는 감속, g(2π) = π). 한 주기에 피동이 2π 돌고 정지 자세가 구멍이 정렬되는 자세로 돌아온다. E_k = 2πk. 시작 theta = 0 에서 p = π, k = 0, 정지(α = 0).
- p < π(다음 주기 앞부분)은 직전 주기의 관성 구간: α = E_k − π + g(p + π). p = 4π 와 다음 주기 p = 0 에서 α = E_k − 0.25π 로 같다(연속).
- 속도비(피동/구동) = 0 → 1(물림 1:1) → (1 − s/2π)(감속) → 0.
- speed < 0 이어도 같은 식(theta 음수, k 음수). f 와 α 는 theta 에서 직접 계산, 자세는 Rx(각)·Ry(±90°)로 매 프레임 설정.

## 확인
- t=1(theta 1.6, p=1.51π): 떨어짐, 구동 원판 표시점만 돈다, 구멍 원판·축·머리 정지. t=1.6(theta 2.56, p=1.82π): 원판이 스터드 쪽으로 다가가 거의 닿음(f ≈ −0.56), 피동은 정지.
- 물림은 정면 두 장에 안 보이므로 `t=2.6`(p ≈ 2.33π, f = −0.77, 피동이 구동과 같은 각), `t=3.9`(떼는 중), `t=4.6`(관성)도 찍는다.
- 비스듬·위 근접(`cam=0.2,3.0,3.2,-0.4,1.95,0.275` 등): 스터드가 구멍 안에 박히지 않음(스터드 끝 −0.62 가 원판 뒷면 −0.61 안쪽), 홈 속 핀이 깃에서 벗어나지 않음.
- 수치: α(θ) 연속(주기 이음에서 점프 없음), 물림 구간 속도비 1.000, 정렬 순간 구동각·피동각 차 mod π ≤ 0.04.
