# 098 불규칙 진동 운동(고리 홈 팔)
원문: 원판이 돌면 불규칙한 진동(흔들림) 운동이 나온다. 원판에 **크랭크 핀**이 박혀 있고, 그 핀이 흔들리는 팔에 판 **끝없는 홈(닫힌 고리 홈)** 안에서 움직인다.
판화: 큰 원(원판) 앞에 알약 모양의 팔이 비스듬히 겹쳐 있다. 팔 안에 점선 알약이 두 겹(= 고리 홈의 바깥 벽과 안쪽 벽), 팔의 오른쪽은 가는 목으로 좁아져 빗금 친 축(받침축)의 고리에 닿고, 그 너머로 짧은 두 줄(팔의 꼬리, 잘려 그려짐)이 이어진다. 원판 한가운데에 점선 동심원 두 개.

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/098-fig-x4.png`, 홈 부분 `098-fig-crop.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없다. 회전체는 **원판 1개**(반지름 555 px — 이 표의 px 는 4배 확대본 기준). 그 밖에 흔들리는 팔 1개, 받침축 1개.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 팔의 받침축(오른쪽 빗금 원, 원판 중심에서 오른쪽으로 868 px = 원판 반지름의 1.56배, **같은 높이**)과 원판의 축(원판 중심). 받침대는 그려져 있지 않다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 핀이 원판 면에 박혀 있다(원문). 판화에는 핀이 따로 뚜렷이 그려져 있지 않다 — 9번 참조.
6. 기어는? → 없음. 맞닿는 짝은 **핀 ↔ 고리 홈의 두 벽** 하나뿐.
7. 한 줄에 놓인 것은? → 원판 중심과 팔 받침축이 같은 높이(가로 한 줄). 고리 홈의 긴 축을 늘이면 받침축을 지난다(판화에서 재면 받침축에서 18 px 벗어남 — 같은 선으로 본다).
8. 판화에 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 원문과 같고 계속 돈다. 다만 **핀 자리가 판화에 뚜렷하지 않다**: 원판 중심의 점선 동심원 두 개는 중심이 원판 중심과 13 px 밖에 안 떨어져 있어 핀이 될 수 없고(핀이라면 크랭크 반지름이 0), 팔 뒤에 가려진 **원판 축과 허브**로 읽는다. 핀 반지름은 아래 "닫힘 조건"으로 정해진다. 질문 거리는 아니고 해석 기록으로 남긴다(없음).
- 그 밖의 선: 점선 알약 두 겹 = 팔 **뒷면**(원판 쪽)에 판 홈이라 가려져서 점선. 두 점선 사이 띠(폭 약 70 px)가 홈. 아래쪽 홈 길 위의 작은 얼룩(680, 1385 px)은 핀 자리 표시로 보인다 — 그 자리에 핀이 있으면 팔 기울기가 약 11° 로 계산되어 판화의 9° 와 맞는다(핀이 아래쪽 반 바퀴에 있을 때 **아래쪽 길**에 있다는 근거).
- 팔은 판화에서 왼쪽 끝이 약 9° 내려가 있다.

## 해석(결정 사항)
- **닫힘 조건**: 핀은 원판 중심 O 둘레 반지름 c 의 원을 돈다. 받침축 P 에서 핀까지 거리는 D − c ~ D + c. 홈 고리 위에서 P 까지 거리가 같은 점은 위쪽 길·아래쪽 길에 하나씩이므로, 핀은 멀어지는 반 바퀴 동안 한쪽 길로 나가고 가까워지는 반 바퀴 동안 다른 길로 돌아온다(고리를 한 바퀴). 그러려면 홈 고리의 가까운 끝 = D − c, 먼 끝 = D + c, 곧 **a + r = c**(a = 곧은 구간 반길이, r = 끝 반원 반지름).
- 판화 치수(px): 홈 중심선 가까운 끝 425, 먼 끝 1260 → c = 417(원판 반지름의 0.75), D = 848~868. 모델: 원판 반지름 1.0, c = 0.75, D = 1.56, a = 0.425, r = 0.325.
- **어느 길로 도는가**: 핀이 위쪽 반 바퀴일 때 위쪽 길, 아래쪽 반 바퀴일 때 아래쪽 길(판화의 자세와 맞는 쪽). 이때 팔의 흔들림은 ±15.8°. 반대로 돌게 하면 ±45° 가까이 흔들려 판화와 다르고 전시 영역도 벗어난다.
- 불규칙함: 팔이 왼쪽 끝을 내리는 데 원판 211.7°, 올리는 데 148.3° 가 걸린다(비 1.43 : 1). 각속도 비(팔/원판)는 핀이 받침축 쪽 끝을 지날 때 −0.21, 먼 끝을 지날 때 +0.135.
- 판화는 홈을 팔 뒷면의 막힌 홈으로 그렸다. 모델은 홈과 핀이 보이도록 **뚫린 고리 홈**으로 만들고, 가운데 섬을 앞면의 띠쇠 다리 2개로 바깥 테에 잡는다(다리는 판화에 없음).

## 구동
원판(반시계). theta += OMEGA(1.6)·speed·dt. 위상 θe = theta + 4.01 (t = 1 에서 θe = 321.4° — 팔 +9.0°, 판화 자세).

## 부품과 치수 (키트 `kit/k098.ts`, 이미 구현됨. 값은 `LOOP098` 상수)
- 원판(name `disk`): `crankPinDisk()` 중심 (−0.75, 1.5), 그룹 z = 0.02(원판 면 z −0.02 ~ 0.06). 반지름 1.0, 두께 0.08, 청동. 뒤쪽 허브 보스. 핀(name `pin098`, 키트가 붙임)은 원판 로컬 (0.75, 0), 반지름 0.055, 앞면에서 0.15 솟아 z 0.21 까지.
- 원판 축: `shaftZ(−0.75, 1.5, 0.1, 0.06)` — 뒤판에서 나와 원판 앞면에서 끝난다(팔이 그 앞을 지나므로 더 길면 안 된다).
- 팔(name `arm`): `loopGrooveArm()` 받침점 (0.81, 1.5), 그룹 z = 0.18(팔 면 z 0.14 ~ 0.22, 띠쇠 다리 0.234 까지). 황동. 팔 로컬: 홈 고리 가운데가 로컬 x = −1.56(축 위), 홈 중심선 = 곧은 구간 반길이 0.425 + 끝 반원 반지름 0.325, 홈 폭 0.12(핀 지름 0.11 — 틈 한쪽 0.005), 바깥 테 끝 반원 반지름 0.5, 목(폭 0.24 → 0.12), 받침 보스 반지름 0.12, 꼬리 0.42(+x 쪽, 판화의 잘린 두 줄).
- 받침축: `shaftZ(0.81, 1.5, 0.27, 0.05)` — 뒤판에서 나와 팔 보스를 꿴다. 원판 테두리(x = 0.25)에서 0.56 떨어져 있어 닿지 않는다.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 가로 범위: 원판 −1.75 ~ 0.25, 팔 −1.675 ~ 1.232. 세로: 원판 0.5 ~ 2.5, 팔 0.46 ~ 2.54(흔들리는 팔 먼 끝의 최고·최저, `s098.mjs`).

## 동작 (모두 theta 의 닫힌 식 — `loopArmAngle`)
- `disk.rotation.z = θe` (반시계).
- `arm.rotation.z = loopArmAngle(θe)` = sgn(sin θe)·β(d) − δ, δ = atan2(c·sin θe, D − c·cos θe), d = 받침축 ↔ 핀 거리, β(d) = 홈 중심선에서 받침축까지 거리가 d 인 점이 팔 축과 이루는 각(`loopGrooveBeta`: 가까운 반원 / 곧은 구간 / 먼 반원 세 구간).
- 한 주기 = 원판 한 바퀴(3.93 s). 누적 없음.
- 시간표(θe): 0°(핀이 받침축 쪽 끝, 팔 0°) → 74.2°(팔 −15.8°, 왼쪽 끝이 가장 높음) → 180°(핀이 먼 끝, 팔 0°) → 285.8°(팔 +15.8°, 왼쪽 끝이 가장 낮음) → 360°.
- 시각: t = 0.5 (θe 275.6°, 팔 +15.4°), **t = 1.0 (θe 321.4°, 팔 +9.0° — 판화)**, **t = 1.6 (θe 16.4°, 팔 −3.5°, 핀이 가까운 끝을 막 돌아 위쪽 길로)**, t = 2.2 (θe 71.4°, 팔 −15.8°), t = 3.0 (θe 144.8°, 팔 −5.0°).
