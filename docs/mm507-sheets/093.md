# 093 홈 요크 크랭크
원문: 크랭크 손목 핀(crank-wrist)이 홈 파인 요크(slotted yoke) 안에서 움직이는 크랭크 운동. 그래서 흔들리는 연결봉(피트먼)이 필요 없다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/093-fig-x4.png` 로 다시 읽음(아래 px 는 4배 그림 기준).
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 가는 선으로 그린 큰 원 = 크랭크 원판(가운데 px (1212, 1000), 반지름 약 480px). 그 한가운데에 작은 원 두 겹(반지름 115·60px) = 허브와 축.
2. 줄·벨트는? → 없음. 연결봉도 없다(원문: 필요 없음). 대신 **가로로 긴 홈 테(요크)** 하나가 핀을 감싼다. 요크 바깥 길이 1200px·높이 260px, 홈 안쪽 길이 1030px·높이 145px. 요크 가운데에서 위(짧게 230px)·아래(길게 780px)로 둥근 막대가 뻗고, 두 끝은 타원으로 잘린 단면 = 더 이어지는 막대.
3. 교차하는 가닥은? → 없음. 요크와 막대가 원판 **앞**을 지나간다(원판의 원이 요크·막대에서 끊긴다).
4. 고정점은? → 판화에는 없다. 축 받침도, 막대 안내도 그리지 않았다(막대가 위아래로만 움직이려면 안내가 있어야 한다 — 보충).
5. 추·손잡이·크랭크는? → 크랭크 핀 = 홈 오른쪽 안의 빗금 친 원(반지름 80px, 가운데 px (1530, 790)). 축 중심에서 376px(원판 반지름의 0.78배), 가로선에서 33° 위. 빗금 = 잘린 단면, 곧 핀이 원판에서 보는 쪽으로 솟아 홈을 지나간다는 뜻.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 핀 ↔ 홈의 위·아래 면(핀 지름 ≈ 홈 높이 — 핀이 홈을 따라 좌우로 미끄러지며 요크를 위아래로 민다).
7. 한 줄에 놓인 것은? → 위 막대·아래 막대·축 중심이 같은 세로선(x 1215 ~ 1225px). 요크의 높이 = 핀의 높이.
8. 글자가 가리키는 부품은? → 글자 없음(번호 93 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 기구는 원문과 같고 그대로 돈다. 참고: 허브·축의 원이 아래 막대 위에 겹쳐 그려졌는데, 막대가 축을 뚫는 것이 아니라 축 **앞**을 지나가는 것으로 읽었다(축은 원판 앞면 가까이에서 끝난다).
- 그 밖의 선: 막대가 요크에 닿는 곳이 살짝 넓어진다 = 뿌리의 이음 깃. 핀 오른쪽의 초승달 꼴 = 홈 끝의 둥근 면과 핀 사이 틈.

## 해석(결정 사항)
- 판화 비: 크랭크 반지름 = 원판 반지름의 0.78배, 홈 안쪽 반길이 = 크랭크 반지름의 1.37배(핀이 끝에 닿지 않는다), 막대 지름 ≈ 핀 지름의 0.75배.
- 막대 안내 부시 2개(위·아래)는 판화에 없음 — 요크 막대가 떠 있지 않게 하는 최소 보충. 부시가 원판 위·아래 밖에 있어야 하므로, 막대가 행정 내내 부시에 걸리도록 **위 막대를 판화보다 길게** 했다(판화는 위 막대가 짧게 잘려 있다. 요크 중심에서 위 1.12, 아래 1.14). 전시 높이 3.3 과 바닥에 맞추느라 원판을 판화 비보다 조금 작게(반지름 0.52) 잡았다.
- 회전 방향은 판화에 없다 → 반시계.

## 구동
크랭크 원판(theta 누적, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 요크 한 번 왕복.

## 부품과 치수 (새 부품은 모두 `kit/k092.ts`, 이미 구현됨. 치수 상수 `K93`)
배치 상수: CY = 1.72 (축 높이, x 는 0), ZD = 0.04 (원판 가운데 평면), ZY = 0.2 (요크·막대 평면).
- 원판(name `disc`): `crankDisc(K93.R, K93.crank)` — 원판 반지름 0.52, 두께 0.08, 크랭크 반지름 0.4, 핀 반지름 0.075. 위치 (0, CY, ZD). 핀은 로컬 +X 에서 앞으로 솟아 로컬 z 0.26 까지. 키트가 핀 표식 child 에 name `crankPin`(요크 평면)을 붙여 둔다. 청동 판 + 강철 핀.
- 축: `shaftZ(0, CY, 0.125, 0.06)` — 끝 너트가 z 0.125 까지라 막대(z 0.14 부터) 뒤로 지나간다.
- 요크(name `yoke`): `slotYoke()` — 홈 반길이 0.55(끝 둥근 부분 포함), 홈 반폭 0.078(핀과 틈 0.003), 테 두께 0.07, 판 두께 0.1, 막대 반지름 0.06, 요크 중심에서 위 끝 1.12·아래 끝 1.14. 위치 (0, CY + y(θ), ZY). 가로 ±0.62. 황동 테 + 강철 막대(한 몸).
- 위 안내(name `guideUp`, 고정): `rodGuideY(0, 2.37, ZY, K93.rodR)` — 고리 y 2.32 ~ 2.42. 아래 안내(name `guideDown`): `rodGuideY(0, 1.07, ZY, K93.rodR)` — 고리 y 1.02 ~ 1.12. 둘 다 뒤판에서 나온 팔 끝의 고리(판화에 없음).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 세로 범위: 원판 1.2 ~ 2.24, 막대 위 끝 2.44 ~ 3.24, 아래 끝 0.18 ~ 0.98.

## 동작 (모두 theta 의 닫힌 식 — `scotchYoke93(theta)` 가 돌려준다)
- 핀 각 a = theta − 1.6 + 33° (t = 1 에서 33° = 판화 자세). `disc.rotation.z = a`.
- 핀 P = (0.4·cos a, CY + 0.4·sin a).
- 요크 높이 = CY + y, y = 0.4·sin a (정확한 사인 운동). 요크의 x 는 늘 0 — 핀이 홈 안에서 좌우 ±0.4 로 미끄러질 뿐 요크는 좌우로 움직이지 않는다.
- 범위: 요크 중심 1.32 ~ 2.12, 행정 0.8 = 크랭크 반지름의 2배.
- 시각: **t = 1.0 (a = 33°, 판화 자세, 요크 1.938)**, **t = 1.6 (a = 88°, 맨 위 2.12 근처)**, t = 2.58 (a = 178°, 가운데를 지나 내려가는 중), t = 3.56 (a = 268°, 맨 아래).

## notes
① 크랭크 반지름 '0.4 → 행정 0.8(반지름의 2배)' ② 요크 높이 '반지름 × sin(각) — 정확한 사인 운동' ③ 지금 요크 위치 '가운데에서 ±N.NN' ④ 연결봉 '없음(핀이 홈 속을 좌우로 미끄러진다)' ⑤ 원판 회전수.

## 확인
- t = 1 정면: 판화와 같은 모양(핀이 홈 오른쪽, 요크가 축보다 위). t = 1.6 정면: 요크가 맨 위, 핀이 홈 가운데.
- 근접 `cam=0.4,2.3,1.5,0.2,1.9,0.15`(핀과 홈), 옆 `cam=3.2,1.72,0.3,0,1.72,0.1`(층: 원판 → 축 너트 → 요크·막대), `cam=0,2.9,1.6,0,2.37,0.2`(위 안내와 막대).
- 수치: `node shots/_verify/s092.mjs` → 핀이 홈 밖으로 나감 0, 틈 0.003, 핀 x 끝 ±0.475 < 홈 반길이 0.55, 위 막대 끝 최저 2.44 > 위 안내 윗면 2.42, 이음 깃 꼭대기 최고 2.308 < 위 안내 아랫면 2.32, 아래 막대 끝 최고 0.98 < 아래 안내 아랫면 1.02, 이음 깃 바닥 최저 1.132 > 아래 안내 윗면 1.12.

## 검증 후 수정 (Opus, 2026-11-25)
- autocheck poly fail(깊이 0.078, 핀 → yoke.slotHole)은 실제 침범이 아니라 이름 문제였다: 검사는 윤곽 이름에 소문자 `hole`/`groove` 가 있어야 구멍으로 보는데 키트 이름 `slotHole`(대문자 H)은 막힌 판으로 읽혀, 홈 속 핀이 판에 박힌 것으로 판정됐다. 수치로 확인: 0~12 s 60 시각 모두 핀 윤곽이 홈 안(요크 기준 핀 높이 오차 0).
- 수정: `m093.ts` 에서 요크 윤곽을 같은 점으로 `outlines.hole` 이름으로 다시 단다(키트 k092 는 92·94 공용이라 손대지 않음). → autocheck pass(fail 0).
- 눈 검증: 판화와 같은 기구(원판 1·핀 1·홈 요크 1·위아래 막대, 연결봉 없음), t=1 자세가 판화와 같고 t=1.6 맨 위, t=4.2 핀이 홈 오른쪽에서 미끄러짐. 안내 고리 2개·축이 뒤판에 받쳐짐, 이름표가 부품을 가리지 않음. 회전 화살표(z 0.32)가 요크 앞을 지나 홈 일부를 가리는 정도는 표시용이라 둠.
