# 124 활비비(피들 드릴)
원문: "Fiddle drill. Reciprocating rectilinear motion of the bow, the string of which passes around the pulley on the spindle carrying the drill, producing alternating rotary motion of the drill." — 활비비. 활을 곧게 밀고 당기면, 드릴을 단 축의 도르래(실패)를 **한 바퀴 감은** 활시위가 축을 돌려 드릴이 정회전·역회전을 번갈아 한다.

## ★ 판화 읽기
판화는 그림 하나 — 드릴 축을 **끝에서 본** 그림(축이 종이에 수직). 4배 확대 `shots/_verify/124-fig-x4.png` 로 다시 읽음(아래 [x·y] 는 4배 확대 그림의 px 자리).
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 드릴 축 위의 작은 도르래(실패). 중심 [1055·1040], 동심원 셋: 바깥 반지름 약 155(턱), 가운데 100(몸통의 단), 안쪽 55(빗금 = 축의 단면).
2. 줄·벨트는 몇 개이고 어디서 어디로? → 활시위 1개. 활의 아래 끝 매듭 [330·1650] 에서 오른쪽 위로 곧게 올라가 도르래의 **왼쪽 위**에 접하고, 도르래를 한 바퀴 감은 뒤(끝에서 본 그림이라 감긴 부분은 도르래 원과 겹쳐 보이고, 접점에 시위가 원으로 들어가는 짧은 꺾임이 있다) 같은 직선으로 이어져 활의 위 끝 매듭 [1420·400] 에서 끝난다. 시위 길이 1658, 방향은 수평에서 48.9°. 접점은 아래 끝에서 56 % 자리. 도르래 중심에서 시위 직선까지 146 ≈ 도르래 바깥 반지름 → 시위가 도르래에 닿아 있다.
3. 교차하는 가닥은? → 정면에서는 없음. 한 바퀴 감긴 시위는 들어오는 가닥과 나가는 가닥이 축 방향으로 줄 굵기만큼 어긋난다(판화는 끝에서 본 그림이라 겹쳐 한 줄).
4. 고정점은? → 판화에는 없음. 드릴 축의 받침(축받이)도, 뚫는 재료도 그리지 않았다. 활은 손에 쥐는 도구라 받침이 없다.
5. 추·손잡이·크랭크는? → 없음. 구동은 활(손으로 시위 방향으로 밀고 당김). 활대의 양 끝이 시위 매듭 밖으로 조금 더 나와 있다(아래 끝이 손잡이 쪽).
6. 기어는? → 없음. 맞닿는 짝: 시위 ↔ 도르래 몸통(감김 마찰 — 시위가 가면 도르래가 돈다), 시위 끝 ↔ 활대 양 끝(감아 맨 매듭 — 판화의 빗금 띠), 드릴 축 ↔ 축받이(판화에 없음).
7. 한 줄에 놓인 것은? → 시위의 두 직선 가닥이 한 직선 위(접점을 지나는 접선). 도르래는 그 직선의 오른쪽 아래, 활대는 왼쪽 위로 휘어 있다(휨 약 290 = 시위 길이의 0.175).
8. 글자가 가리키는 부품은? → 글자 없음(번호 124 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 판화 그대로 돈다(활이 시위 방향으로 오가면 도르래가 번갈아 돈다). 드릴 날은 판화에 보이지 않는다(축 끝에서 본 그림) — 원문의 "spindle carrying the drill" 에 따라 축 앞 끝에 날을 단다.
- 그 밖의 선: 활대의 두 줄 = 둥근 활대의 두께. 양 끝의 빗금 띠 = 시위를 감아 맨 자리. 위 끝의 타원·아래 끝의 고리 = 매듭 밖으로 나온 활대 끝.

## 해석(결정 사항)
- 기구: 활(휜 나무 막대) + 시위 + 실패 달린 드릴 축. 시위는 실패 몸통을 **시계 방향으로 한 바퀴(360°)** 감는다. 활이 오른쪽 위(+)로 s 만큼 가면 시위도 s 만큼 지나가고 실패는 s / (몸통 반지름 + 시위 반지름) 만큼 **시계**로 돈다. 돌아올 때는 반시계.
- 배치: 판화처럼 축을 끝에서 본다 → 드릴 축 = Z 방향(뒤판에 수직), 활과 시위는 뒤판과 나란한 평면. 시위 방향 48.9°(판화).
- 치수(판화 1px ≈ 1/720): 시위 길이 2.3, 접점은 아래 끝에서 1.29(56 %), 실패 몸통 반지름 0.20(턱 0.25), 활 휨 0.40. 왕복 진폭 0.6 → 실패 회전 ±162°. 끝 위치에서도 남는 가닥이 아래 0.69, 위 0.41.
- 감긴 시위는 나선: 한 바퀴에 축 방향으로 0.04(시위 굵기 0.024 보다 넓게) — 들어오는 가닥 z 0.34, 나가는 가닥 z 0.38. 활은 그만큼(1°) 비스듬히 놓인다.
- 실패는 **납작 림 + 양쪽 턱**(V 홈이 아님 — 한 바퀴 감긴 줄이 나란히 놓이려면 납작해야 한다).
- 판화에 없는 보충: 드릴 축받이(뒤판 보스 + 팔 끝 고리), 축 앞 끝의 척과 납작 날, 공통 받침대. 활의 받침은 만들지 않는다(손 도구 — 판화 그대로, 아래 연결 표 참고).

## 구동
활(손). theta += OMEGA(1.6)·speed·dt, 활 변위 s = 0.6·sin(theta − 1.6). 한 번 왕복 3.93 s.

## 부품과 치수 (새 부품은 모두 `kit/k122.ts`, 이미 구현됨. 치수 상수 `K124`, `K124_C`, `K124_CHORD`)
배치 상수(세계 좌표): 접점 T = `K124.T` = (0.05, 1.8), 시위 방향 u = (cos 48.9°, sin 48.9°) = (0.657, 0.754), 실패·드릴 축 중심 SC = `K124_C` = (0.2098, 1.6606)(접점에서 시위의 오른쪽 아래로 0.212), 실패 가운데 평면 ZS = `K124.zS` = 0.36.
- 드릴 축(name `spindle`, 도는 것): `drillSpindle()` — 회전축 로컬 Z, 원점 = 실패 가운데. 실패(child name `spool`): 몸통 반지름 0.20·폭 0.12(납작 림), 턱 반지름 0.25·두께 0.02. 축 반지름 0.04, 뒤 끝 로컬 z −0.64, 척(반지름 0.068) 로컬 z 0.17 ~ 0.28, 납작 날 끝 로컬 z 0.40. 위치 (SC, ZS) → 세계 z −0.28 ~ 0.76. 실패는 나무색, 축·날은 강철.
- 축받이(고정, 판화에 없음): `spindleBearing(SCx, SCy, 0.1)` — 뒤판 보스(z −0.30 ~ −0.20, 구멍 0.045) + 뒤판에서 나온 팔(축 아래 0.17, 축에 닿지 않음) 끝의 고리(z 0.06 ~ 0.14, **구멍이 축 방향 = Z**).
- 활(name `bow`): `bow()` — 원점 = 시위 아래 끝 매듭, 로컬 +X 로 `K124_CHORD`(2.3003) 떨어진 곳이 위 끝 매듭, 활대는 로컬 +Y 로 0.40 휜 원호(반지름 0.026 나무), 양 끝이 매듭 밖으로 0.09, 매듭 자리에 감은 끈. 줄 끝 표식 child `bowEndA`(원점)·`bowEndB`. 자세는 `poseBow124(bow, s)` 가 정한다.
- 시위(name `string`): 공용 키트 `new Rope(K124.rho)`(반지름 0.012) — 경로는 `fiddlePath124(s)` 로만(점을 손으로 찍지 않는다).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 범위(활이 양 끝까지 갈 때): x −1.234 ~ 1.224, y 0.259 ~ 3.057, z −0.30 ~ 0.76.

## 동작 (모두 theta 의 닫힌 식 — `fiddle124(theta)` 가 돌려준다)
- `{ s, phi } = fiddle124(theta)`: s = 0.6·sin(theta − 1.6), phi = −s / 0.212(시위 중심선 반지름 = 0.20 + 0.012).
- `spindle.rotation.z = phi` (s 가 늘면 시계). 진폭 ±162.2°.
- `poseBow124(bow, s)` — 활의 아래 끝 = T + u·(−1.29 + s)(z 0.34), 위 끝 = T + u·(1.01 + s)(z 0.38).
- `string.setPath(fiddlePath124(s))` — 아래 끝 → 접점 T → 실패를 시계로 360°(나선, z 0.34 → 0.38) → 접점 T → 위 끝. 매 프레임 다시 놓는다. 감긴 호는 늘 같은 자리(접점 고정), 직선 가닥의 길이만 변한다(아래 1.29 − s, 위 1.01 + s).
- 시각: **t = 1.0 (s = 0 — 판화 자세)**, **t = 1.6 (s = 0.49, phi = −133°, 활이 오른쪽 위로 가는 중)**, t = 1.98 (s = 0.6 끝), t = 3.95 (s = −0.6 반대 끝).

## 검증 후 수정 (Opus, 2026-11-25)
- '시위' 이름표: 만든 쪽이 활과 함께 오가게 했던 것을 되돌리고, 아래 가닥 바로 오른쪽 아래(T − u·0.42 − n·0.22, z 0.5 ≈ (−0.08, 1.34))에 고정했다. 시위 직선은 제자리라 따라갈 필요가 없고, 설계표의 (−0.15, 0.8) 는 시위에서 0.77 떨어져 있었으며 s = −0.6 에서는 받침대 가장자리까지 내려갔다. 새 자리는 활의 양 끝 자세(s = ±0.6)에서 활 매듭·실패 턱을 가리지 않음을 눈으로 확인.
- 그 밖(감긴 시위가 납작 림에 나란히 두 줄, 두 가닥 z 어긋남, 축받이·보스, 날, t = 1 / 1.6 / 1.98 / 3.95 동작)은 판화·원문과 맞아 고치지 않음.
- autocheck 는 이 고정 이름표에 tags warn(「시위」 가 움직이는 bow 를 따라가지 않음)을 낸다. 가장 가까운 움직이는 부품이 활이라서 나는 거짓 경보다 — 이름표가 가리키는 시위 직선은 움직이지 않는다. 경보를 없애려고 이름표를 활과 같이 움직이면 시위에서 멀어지거나(설계표 자리) 실패 턱에 겹친다(아래 가닥 쪽). 최종 판정 warn(fail 0).
