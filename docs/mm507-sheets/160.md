# 160 스프링 발판과 띠
원문: "Alternating curvilinear motion into alternating circular. When the treadle has been depressed, the spring at the top elevates it for the next stroke; the connecting band passes once round the pulley, to which it gives motion." — 발판(트레들)을 밟는 왕복 곡선 운동이 도르래의 앞뒤 왕복 원운동으로 바뀐다. 발판을 밟은 뒤에는 위의 스프링이 발판을 들어 올려 다음 발판을 준비시키고, 연결 띠는 도르래를 한 번 감아 돌려서 도르래를 움직인다. 도르래는 한 번에 한 바퀴 이내씩 앞뒤로 번갈아 돈다.
판화 묘사: 흰 바탕에 기구만 있다. 위에 활처럼 길게 아치진 가는 장대(스프링)가 있고 왼쪽 끝은 잘린 단면으로 막 끊겨 있다. 오른쪽 끝 조금 앞의 아랫면에 검게 엇갈려 그린 매듭이 있고, 거기서 음영을 넣은 가는 띠가 수직으로 곧게 내려온다. 띠의 중간쯤에는 민 원판 도르래(가운데 작은 허브 원과 축 점)가 띠 바로 왼쪽에 붙어 있다(축 받침은 그리지 않았다). 띠는 발판 막대 위의 작은 아치(고리쇠)에서 끝난다. 발판은 왼쪽 아래 종 모양 받침대의 핀에 꿰여 오른쪽 위로 비스듬히(10°쯤) 솟았고 오른쪽 끝이 조금 굵다. 맨 아래의 가로 빗금 = 땅.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대해서 다시 읽음(아래 [x·y] 는 4배 확대 그림의 px 자리, 원판화 497×445).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 도르래 1개뿐. 살·테·홈 없는 민 원판, 가운데에 허브 원과 축 점. [1124·848] 중심껍질 반지름 160, 허브 반지름 40(4배 px). 풀리·기어는 없다.
2. 줄·벨트는 몇 개이고, 각각 어디서 시작해 어느 바퀴의 어느 쪽을 차례로 지나 어디서 끝나는가? → 띠 1개. 위에서는 스프링 오른쪽 끝 근처의 매듭 [1256·364] 아랫면에서 시작해 수직으로 내려오고, 도르래의 **오른쪽 테**에서 한 바투 감겨 지나가, 발판의 고리쇠 [1260·1288] 꼭대기에서 끝난다. 윗가닥·아랫가닥이 정면에서 겹쳐 한 줄로 보인다(두 가닥 다 세로선 x [1220~1280] 위).
3. 교차하는 가닥이 있는가, 어디서? → 엇갈려 교차하는 가닥은 없다. 겹쳐 그려진 곳: 띠가 도르래 **앞**에서 오른쪽 테를 지난다(도르래 원이 띠 음영 아래로 이어진다). 띠는 매듭·고리쇠 앞에서 끝나고, 발판 막대는 받침대 앞을 지난다.
4. 고정점(천장·벽·바닥)은 어디인가? → 아래 빗금(땅) 위의 발판 받침대 하나(받침 핀 자리 [544·1428], 보스 반지름 80). 도르래 축의 받침과 스프링 왼쪽 끝의 고정은 **그리지 않았다**(모형에서 떠 있지 않게 보충 — 기구를 바꾸지 않는 보충).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 추·크랭크 없음. 오른쪽 끝이 굵은 발판이 밟는 손잡이 구실 — 오른쪽 끝을 발로 밟아 내리고(구동), 스프링이 다시 들어 올린다.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음, 도르래는 민판. 맞닿는 짝: 띠 ↔ 도르래 오른쪽 테(한 바퀴 감음, 마찰로 물림), 띠 끝 ↔ 스프링 매듭·발판 고리쇠, 발판 허브 ↔ 받침 핀.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 띠·매듭·고리쇠가 같은 세로선(x [1220~1280]). 도르래의 오른쪽 테 접점도 그 세로선 바로 왼쪽. 발판 막대는 받침 핀에서 오른쪽 위로 뻗은 한 직선이고 스프링의 오른쪽 끝이 그 위에 있다.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 160 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 다른 곳 없음. 판화대로 계속 돈다: 밟으면 띠가 당겨 도르래가 시계로 돌고 스프링이 휘어 힘을 저장하고, 놓으면 스프링이 발판을 들어 올려 도르래가 반대로 돌아온다(한 번에 한 바퀴 이내 — 모형으로 80.9°). 질문 거리 없음.
- 그 밖의 선: 스프링의 나란한 두 줄 = 장대의 윗면·아랫면(두께가 고르고 양 끝이 조금 가늘어진다). 매듭의 엇갈린 검은 줄 = 띠를 스프링에 동여 맨 자리. 띠의 점점한 음영 = 가는 가죽띠. 도르래 가운데의 작은 원과 점 = 허브와 축 끝. 고리쇠의 아치 = 띠 끝을 발판에 누른 U쇠. 받침대의 두 겹 원 = 핀 구멍과 허브. 빗금 = 땅.

## 해석(결정 사항)
- 판화 비(도르래 반지름 160 = 0.345 기준, 4배 px): 받침 핀 ~ 고리쇠 1.57(키트 1.65), 받침 핀은 땅 위 0.33, 도르래 중심은 받침 핀에서 (+1.25, +1.25)(키트 (+1.29, +1.28)) — 키트 `K160` 은 이 비를 도르래 반지름 0.345 로 정리했다.
- 판화의 자세(발판이 오른쪽 위로 10°)를 t = 1 로 맞춘다. 밟아 내려가는 도중이라 도르래는 시계로 도는 중.
- 발판이 오르내리는 각은 위 +12° ~ 아래 −6°(판화의 10° 는 그 사이).
- 띠의 "한 번 감음"은 나선으로: 윗가닥이 앞(z 0.16)에서 들어와 도르래를 한 바퀴(2π) + 2~8° 감으며 뒤(z 0.10)로 옮겨 가고 아랫가닥이 뒤에서 나간다 — 정면에서 두 가닥이 겹쳐 한 줄로 보이는 판화와 같다.
- 회전 방향은 판화에 없다 → 밟으면 도르래 시계(−), 스프링이 올릴 때 반시계(+).
- 판화에 없는 보충: 도르래 축(뒤판 보스), 스프링 왼쪽 끝의 물림쇠, 공통 받침대·뒤판.

## 구동
발판(트레들). theta += OMEGA(1.6)·speed·dt. 한 주기 2π = 3.927 s 에 발판이 한 번 오르내리고, 도르래가 시계로 최대 80.9° 내려갔다가 반시계로 돌아온다(앞뒤로 번갈아 돎). 스프링·띠·도르래는 종동.

## 부품과 치수 (새 부품 없음 — `kit/k158.ts` (158·159·160 공용), 이미 구현됨. 치수 상수 `K160`)
배치 상수: Q = (−0.66, 0.56)(받침 핀), ZB = 0.10(발판 평면), ZD = 0.13(도르래 가운데), ZS = 0.16(띠 윗가닥 = 스프링 앞면), ZA = 0.10(띠 아랫가닥 = 발판 평면). 바닥 = 받침 윗면 y 0.18.
- 장대 스프링(name `spring`): `new PoleSpring160(0.10)` — 휘는 나무 장대, 단면 높이 0.13 × 깊이 0.12, 원호 중심 Cs (0.26, 0.075)·반지름 2.935·130.5° → 66.6°(호 길이 3.273, 그룹은 전시대 좌표 그대로). 왼쪽 끝 (−1.646, 2.307), 오른쪽 끝 (1.426, 2.769), 꼭대기 윗면 y 3.075. `setBend(kappa)` 가 형상·윤곽(`userData.outline`)·맨 곳 표식 child `springTie`(anchor)를 다시 놓는다. 나무.
- 스프링 물림쇠(name `clamp`, 고정, 판화에 없음): `springClamp160(0.10)` — 스프링 왼쪽 끝 0.3 을 위·아래 물림 판으로 감싸고 뒤판까지 받침 벽, 위에 조임 볼트 둘. 주철.
- 도르래(name `drum`): `pulley(0.345, { flat: true, width: 0.16, spokes: 0, hub: 0.048 })` — 민 원판(웹판), 납작 림, 폭 0.16, 중심 (0.63, 1.84), 반지름 0.345. position (0.63, 1.84, 0.13), `rotation.z = P.drum`. 황동. 앞면에 표시점(키트 기본 — 회전이 보이게).
- 도르래 축(name `axle`, 고정, 판화에 없음): `shaftZ(0.63, 1.84, 0.30, 0.045)` — 뒤판 보스에서 나와 도르래 구멍(반지름 0.048)을 꿴다. 앞 너트는 z 0.26~0.30 — 도르래 앞면(0.21) 밖이라 도는 도르래에 파묻히지 않는다.
- 발판(name `treadle`): `treadleBar158(2.36, { dir: 1, h: 0.055, depth: 0.1 })` — 원점 = 받침 핀, 로컬 +X 로 2.36, 높이 0.055, 깊이 0.1, 허브 구멍 반지름 0.034. position Q, z 0.10. `rotation.z = P.up`. 강철. `userData.outline`(막대 몸통).
- 띠 고리쇠(name `staple`, 발판의 child (1.65, 0, 0) — 막대와 같이 기울어짐): `bandStaple158(0.055, 0.085)` — 막대 윗면의 선 반고리(아치) + 꼭대기 매듭. 표식 child `bandEye`(anchor) = 띠 끝 자리(막대 가운데선 위 0.085).
- 받침 핀(name `pin`, 고정): `pivotPin158(0.02, 0.20, 0.032)` — position Q. 뒤 끝은 받침대 머리에 0.01 박히고, 발판 허브(z 0.05~0.15)를 꿰어 앞 머리가 허브 앞에서 막는다.
- 받침대(name `pedestal`, 고정): `bellStandard158(0.38, { topR: 0.16, waist: 0.12, foot: 0.30, bore: 0.034, thick: 0.1, base: [-0.34, 0.34], baseH: 0.09 })` — position (−0.66, 0.18, −0.02). 판화의 종 모양 받침대.
- 띠(name `band`): `new Belt(bandPath160(P.S, P.A, 0.16, 0.10), { style: 'rope', ropeR: 0.016, closed: false })` — 가는 둥근 가죽띠, 단면 반지름 0.016, 감는 원 반지름 0.363 = 0.345 + 0.016 + 0.002. 매 프레임 `setPath` 로 다시 만든다(점 개수 일정). mm 표식: 경로·감긴 호(`bandPath160` 이 tagArc)·열린 양 끝.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침. 판화의 땅 = 받침 윗면).
- 전체 범위: x −1.65(스프링 왼 끝) ~ 1.70(발판 끝), y 0.18(바닥) ~ 3.075(스프링 꼭대기).

## 동작 (모두 theta 의 닫힌 식 — `treadle160(theta)` 가 { up, A, kappa, S, drum, wrapDeg, drop } 를 돌려준다)
- 발판: P.up = (3° + 9°·cos(theta − phase))·DEG, phase = 1.6 − acos(7/9). `treadle.rotation.z = P.up`. 범위 −6° ~ +12°. t = 1 에서 +10°(판화 자세 — cos 이 내려가는 중).
- 띠 아래 끝: P.A = `bandEnd160(P.up)` — 고리쇠 꼭대기(막대 가운데선 위 0.085). 범위 x 0.936~0.992, y 0.472~0.986.
- 스프링: 띠 온 길이가 일정(4.150 — `bandLength160()`, 발판이 가장 올라가고 스프링이 쉴 때)이 되도록 휨 계수 kappa 를 이분법 40회로 푼다 → P.kappa(0 ~ 0.102). `spring.setBend(P.kappa)`. 스프링 오른쪽이 쉴 때보다 최대 0.517 내려온다(P.drop), 오른 끝은 (1.323, 2.113) 까지.
- 띠: path = `bandPath160(P.S, P.A, 0.16, 0.10)` — 스프링 맨 곳 아랫면 S(x 0.926~0.978, y 2.337~2.854) → 도르래 위 접점(각 +0.9° ~ +8.2°) → **시계로 한 바퀴(2π) + 2~8°** 감으며 z 0.16 → 0.10 으로 옮겨 감고 → 아래 접점(각 −3.9° ~ 0°) → A. `belt.setPath(path)` 뒤 `belt.setOffset(−K160.rc·P.drum)` — 띠 표시가 도르래 표면과 함께 흐른다(밟을 때 S 쪽에서 A 쪽으로, 흐른 길이 = 0.363·도르래 돌각).
- 도르래: P.drum = 접점 각 변화 + 윗가닥 길이 변화/0.363 — 밟으면 −(시계)로 0 에서 −80.9° 까지, 스프링이 올리면 0 로 돌아온다. `drum.rotation.z = P.drum`.
- 시각: **t = 1.0 (up +10°, drum −8.7°, kappa 0.011, drop 0.055 — 판화 자세)**, **t = 2.54 (up −6°, drum −80.9°, kappa 0.102, drop 0.517 — 가장 깊이 밟음)**, t = 30 (up −6.0°, drum −80.8° — 주기 3.927 s 로 정확히 닫힌다).

## 표시
- rotArrow 2개(도르래가 앞뒤로 바뀐다): `rotArrow(0.5, true)`(반시계)와 `rotArrow(0.5, false)`(시계)를 도르래 중심 (0.63, 1.84, 0.40) 에 겹쳐 두고, 밟는 동안(P.drum 이 줄어들 때) 시계만, 스프링이 올리는 동안 반시계만 보인다(drum 각의 증감으로 visible 토글). 모든 부품보다 앞 층이라 얇은 호 외에는 아무것도 가리지 않는다.
- tag 이름표 5개: '발판(구동)' (발판 끝 x − 0.25, 끝 y + 0.25, 0.4) — 끝을 따라감, '띠 고리쇠' (A.x + 0.32, A.y, 0.3) — 고리쇠를 따라감, '띠(가죽)' (S.x + 0.42, (S.y + 2.0)/2, 0.3) — 스프링 맨 곳을 따라감, '도르래(종동)' (1.5, 1.35, 0.3) 고정, '스프링 물림쇠(고정)' (−1.4, 1.95, 0.3) 고정.
- view: `{ pos: [0, 1.7, 6.4], target: [0, 1.55, 0] }` — 전시대 전체가 보이게.

## notes
① 발판 기울기 'NN° (−6° ~ +12°)' (P.up) ② 도르래가 돌각 'NN° (최대 80.9°, 밟으면 시계)' (P.drum) ③ 스프링 끝이 내려온 높이 '0.NN (최대 0.52)' (P.drop) ④ 설명 '띠가 도르래를 한 바퀴 감아 돌리고, 스프링이 다시 들어 올려 도르래가 앞뒤로 번갈아 돈다'.

## 확인
- t = 1 정면: 판화와 같은 모양(스프링 아치 — 오른쪽 끝이 매듭에서 조금 이어지다 끝남, 띠가 수직으로 내려와 도르래 오른쪽 테에 붙고 발판이 오른쪽 위로 10°). t = 2.54 정면: 발판이 −6° 로 내려가고 스프링 오른쪽이 0.52 내려와 더 처지며 도르래가 시계로 80.9° 돌아 있다.
- 근접 `cam=1.5,2.6,1.5,0.95,2.75,0.13`(스프링 맨 곳·매듭), `cam=1.35,1.75,1.7,0.7,1.84,0.13`(도르래 감음 — 앞·뒤 가닥이 테 폭 안에서 앞뒤로 나뉜다), `cam=1.3,0.75,1.5,0.95,0.85,0.1`(고리쇠·발판), 옆 `cam=3.6,1.6,0.2,0,1.6,0.1`(층: 받침대 → 발판 → 스프링 → 띠 → 도르래 → 축 너트).
- 수치(키트 식 `treadle160`·`band160` 으로 계산): t = 1 → up 10°, A (0.950, 0.930), kappa 0.0107, S (0.978, 2.799), drum −8.7°, 감긴 각 363.6°. t = 2.54 → up −6°, drum −80.9°, kappa 0.1024, drop 0.517, 감긴 각 368.3°. 주기 닫힘(treadle160(theta + 2π) = treadle160(theta)), 띠 온 길이 4.150 일정, 띠가 림 위에 앉는 자리 +0.002(납작 림 허용 창 −0.002 ~ +0.01 안), 감긴 각은 한 바퀴 + 2~8° 로 350° 를 넘지만 축 방향으로 0.06 옮겨 감는 나선이라 과다 감김이 아니고, 접점 호 가운데는 테 폭의 한가운데(ZD)라 축방향 치우침 0.
- 눈으로: 스프링이 가장 처졌을 때(t = 2.54)도 스프링 아랫면이 도르래의 띠 감음 바깥(반지름 0.379)에서 0.20 이상 떠 있는가, 스프링 오른 끝(1.323, 2.113)이 띠 윗가닥(접점 (0.989, 1.891) — S (0.926, 2.337))과 겹치지 않는가(측정 여유 0.37), 너트·표시점이 도는 도르래에 파묻히지 않는가.

- 물림쇠의 물림 판과 도르래 축은 뒤로 뻗어 뒤판 앞면(전시대 기준 −0.30)에 붙는다(기계 부품 가운데 가장 뒤는 받침판 뒤면 −0.11). 가장 앞 = 축 너트 끝 0.30 · 화살표 0.40 · 이름표 0.45 — 전부 −0.25 ~ 0.8 안.
