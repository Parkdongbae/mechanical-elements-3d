# 136 톱니 모양 캠 바퀴
원문 요지(글자가 일부 깨짐): **옆모습**을 그린 캠 바퀴는 **테(rim)** 가 톱니 모양으로, 또는 바라는 어떤 윤곽으로든 만들어져 있다. 오른쪽의 막대는 테의 톱니(가장자리)에 **늘 눌려 붙어 있게** 되어 있다. 바퀴를 돌리면 막대에 번갈아 하는 직선 운동이 전해진다. 톱니나 테 윤곽의 모양을 바꾸면 이 운동의 성질을 달리할 수 있다. (글자·수치 없음)

## ★ 판화 읽기
판화는 그림 하나 — **바퀴를 옆(축과 직각 방향)에서 본 그림**이다(원문 "a side view"). 4배 확대 `shots/_verify/136-fig-x4.png` 로 다시 읽음. 잰 값(확대본 px): 바퀴 몸통 x 410~530·y 130~1475(높이 1345 = 지름), 톱니 끝 x 690, 축 토막 x 90~340(y 715~885), 허브 턱 x 340~410(y 620~965), 막대 끝 (680, 800), 막대의 턱 x 960, 스프링 x 960~1410(5감김), 세운 판 x 1410~1485·y 615~1555, 막대 오른쪽 끝 x 1790, 바닥선 y 1555.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → **캠 바퀴 1개**. 옆에서 보아 세로로 긴 네모(몸통 두께 120 px, 지름 1345 px)이고, **오른쪽 가장자리(테의 옆면)** 가 지그재그 톱니로 깎여 있다(톱니 높이 약 150 px, 보이는 반 둘레에 8개쯤). 왼쪽 면 한가운데에 허브 턱과 가로축 토막이 붙어 있다 — 축은 가로(X) 방향.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 대신 **곧은 막대 1개**가 가로로 놓여 왼쪽 끝이 톱니에 닿고, 오른쪽의 세운 판의 구멍을 지나 밖으로 나간다. 막대에는 턱이 하나 있고 턱과 세운 판 사이에 **코일 스프링**(5감김)이 끼워져 있다.
3. 교차하는 가닥이 있는가? → 없음. 겹침: 막대는 바퀴 축과 같은 높이에 그려져 있지만 축의 연장선이 아니다 — 원문이 "테의 톱니에 눌린다"고 했으므로 막대는 **테 위(축에서 테 반지름만큼 떨어진 곳)** 에 있고, 판화에서는 보는 사람 쪽(앞) 테에 닿은 것이 축 높이에 겹쳐 보인다.
4. 고정점(천장·벽·바닥)은 어디인가? → 빗금 친 **바닥(받침 대)** 과 그 오른쪽 끝에 선 **세운 판**(아래에 굽은 보강 살). 바닥은 세운 판의 오른쪽 면에서 끝나고 아래로 꺾인다. 바퀴 축의 축받이는 그리지 않았다(축 토막의 왼쪽 끝은 파단선).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 바퀴 축. 막대를 톱니에 누르는 힘은 스프링(턱을 왼쪽으로 민다).
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 맞물리는 기어는 없다. **톱니는 바퀴의 둘레(바깥 원통면)가 아니라 테의 옆면(축 방향, 오른쪽)** 에 났다 — 왕관 꼴. 맞닿는 짝은 톱니 면 ↔ 막대의 왼쪽 끝(뾰족하게 좁아진 끝) 하나뿐이고, 막대는 축과 나란히(가로로) 움직인다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 바퀴 축, 막대, 스프링, 세운 판의 구멍이 정면에서 같은 높이. 바퀴 아래 끝과 바닥 사이는 조금 떠 있다(80 px).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 136 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 다만 판화의 톱니는 위 절반과 아래 절반이 **거울 꼴**로 그려져 있어(실제 옆모습이면 같은 쪽으로 기운다) 톱니가 기운 방향 = 회전 방향을 판화로는 알 수 없음 → 막대가 완만한 면을 타고 오르는 쪽으로 정했다. 질문 거리는 아님.
- 그 밖의 선: 세운 판 왼쪽 아래의 두 곡선 = 굽은 보강 살의 윤곽. 스프링의 겹 타원 = 코일. 막대 턱의 세로 두 줄 = 턱(칼라)의 두께.

## 해석(결정 사항)
- 캠 = **옆면 캠(왕관 캠)**: 테의 오른쪽 가장자리 높이가 둘레를 따라 톱니 꼴로 변한다. 따름 막대는 축과 나란히 놓여 테의 한 점(보는 사람 쪽, 축 높이)에서 톱니를 탄다.
- 톱니: 12개(판화는 16개쯤 — 전시 깊이 때문에 바퀴가 작아 톱니 하나를 알아볼 만하게 줄임), 높이 0.1, 한 칸의 68 % 는 완만하게 오르고 32 % 는 가파르게 내린다. 골과 끝은 둥글다(판화의 둥근 골).
- 막대 끝 = 반지름 0.03 의 둥근 날(날의 축이 바퀴 반지름 방향)이라 테 폭 전체에 선으로 닿는다. 가파른 쪽 골의 굽음(반지름 0.009)이 날보다 작아 날이 골 바닥까지는 내려가지 못한다(들림 최저 0.0022) — 운동식은 이 맞닿음을 그대로 계산한 값.
- 전시 깊이(z −0.25~0.8) 때문에 바퀴 반지름은 0.48 이 한계. 판화 비율(몸통 두께 : 톱니 높이 : 지름)은 지킨다.
- 축받이 둘(받침 대 위에 선 기둥)은 판화에 없음(축을 받치는 최소 보충).

## 구동
바퀴 축. theta += OMEGA(1.6)·speed·dt. 바퀴 각 psi = 0.5 × (theta − 1.6) + 0.02 (rad) — 톱니 하나가 0.654 s 에 지나가게 절반 속도로 돌린다(한 바퀴 7.85 s 에 막대 12번 왕복). t = 1 에서 막대가 골에 가장 깊이 내려앉은 순간(판화 자세).

## 동작 (모두 theta 의 닫힌 식 — 누적 오차 없음)
- psi = 0.5 × (theta − 1.6) + 0.02.
- `camWheel.rotation.x = psi`, `shaft.rotation.x = psi`. 오른손 법칙으로 +X 둘레 — **앞에서 보면 바퀴의 앞면(보는 사람 쪽)이 아래로 내려간다.**
- L = `faceCamLift136(psi)` (0.0022 ~ 0.1000, 주기 30°). `rod.position.x = −0.05 + L`.
- `spring.position.x = rod.position.x + 0.30`, `spring.scale.x = 0.685 − spring.position.x`.
- `setCamSection136(camSection, psi)`.
- 한 톱니의 시간표(psi 를 30° 로 접은 값 u = 0~1): u 0.04 최저(L 0.002) → u 0.04~0.68 **천천히 밀려남**(막대가 오른쪽으로, 스프링이 눌림) → u 0.68 최고(L 0.100) → u 0.68~1.04 **빠르게 되돌아옴**(스프링이 막대를 왼쪽으로 민다). 오름 64 %·내림 36 %.
- 시각: **t = 1.0 (psi 1.1°, 골에 앉은 순간, L 0.002 — 판화 자세)**, **t = 1.4 (psi 19.5°, 톱니 끝, L 0.100)**, t = 1.6 (psi 28.6°, 되돌아오는 중, L 0.040), t = 30 (psi 1330°, L 0.065).

난도 **B** (Sonnet). 부품·운동식은 모두 키트에 있지만 가로축 회전(rotation.x), 스프링 길이 맞추기, 검사용 단면 갱신, 따라가는 이름표, 비스듬한 시점이 있어 A(GLM)에는 주지 않는다.
사용자에게 물을 질문: 없음. (알림 — 묻지 않고 정한 것: 막대는 축의 연장선이 아니라 앞쪽 테 위에 선다, 톱니 12개·높이 0.1, 완만한 면을 오르는 회전 방향, 바퀴는 구동 각의 절반 속도, 축받이 둘 보충.)
