# 007 풀리 3개와 베벨 기어로 정회전·정지·역회전
판화: 오른쪽 위에 수평축의 폭 넓은 구동 풀리, 그 아래 수평축 a 에 풀리 3개가 나란히. 축 a 위에 속 빈 축 b 가 끼워져 있고, 왼쪽에는 베벨 기어 A(축 a 끝)와 B(축 b 끝)가 서로 마주 보며, 그 위에서 수직축 베벨 기어 C 가 둘 다와 맞물린다(판화의 ㄷ자 모양). 원문: 왼쪽 수직축을 구동·정지·역회전시키는 장치. 벨트가 가운데 풀리(헐거운 풀리)에 있으면 운동이 전달되지 않는다. 왼쪽 풀리로 옮기면 그 풀리가 고정된 속 빈 축 b 와 베벨 B 를 통해 수직축이 한 방향으로, 오른쪽 풀리로 옮기면 그 풀리가 고정된 축 a 와 베벨 A 를 통해 반대 방향으로 돈다. 벨트는 포크(벨트 옮기개)로 옆으로 옮긴다.
구동: 위 풀리(항상 일정하게 회전).

## 좌표 (이 운동은 축이 X 방향 — 판화에서 풀리를 옆에서 본 모습)
- 기구 평면 z = 0.15. 수평축은 뒤판에서 나온 브래킷 `pillow(x, y, 0.15, 'x')` 로 받친다.
- 위 구동 풀리 U: 회전축 X, 반지름 0.38, **폭 0.66**(벨트가 세 자리 어디에 있어도 걸리게), 중심 (1.15, 2.65). 축 x 0.6 ~ 1.9, pillow x = 0.7, 1.8.
- 아래 축 a(속 찬 축): 반지름 0.04, y = 0.95, x −1.75 ~ 1.7. pillow x = −1.7, 1.65.
- 속 빈 축 b: 반지름 0.075(관), x −0.8 ~ 1.03, a 를 감싼다. pillow x = 0.1 (b 를 받침).
- 아래 풀리 3개(반지름 0.36, 폭 0.2, 간격 0.02, 모두 회전축 X): 왼쪽 F1 중심 x = 0.93(**b 에 고정**), 가운데 L 중심 x = 1.15(**헐거운 풀리** — a 위에서 자유 회전, 허브 앞에 얇은 슬리브), 오른쪽 F2 중심 x = 1.37(**a 에 고정**). 각 풀리 앞면에 스포크 표시가 보이도록 정면에서 약간 비스듬한 기본 시점을 쓴다(아래 view).
- 베벨 기어(키트 추가 `bevelGear`): 잇수 20, 모듈 0.03 → 피치 반지름 0.3, 45° 마이터.
  - 맞물림 꼭짓점 O = (−1.125, 0.95, 0.15).
  - A: 축 a 위, 이가 +X 를 향함, 피치원 평면 x = −1.425.
  - B: 축 b 끝, 이가 −X 를 향함, 피치원 평면 x = −0.825.
  - C: 수직축(Y) 위, 이가 −Y 를 향함, 피치원 평면 y = 1.25. 수직축 c: 반지름 0.04, y 1.25 ~ 3.05, 위쪽은 뒤판 브래킷 `pillow(-1.125, 2.9, 0.15, …)`(Y 축용이 없으면 작은 주철 상자 + 구멍으로 대신). 축 위 끝에 표시판(작은 원판 + 화살표) — 회전 방향이 보이게.
- 벨트(폭 0.14, 두께 0.02): U 와 아래 풀리 사이의 열린 벨트. 벨트 중심 x = bx(아래 참고). 경로는 YZ 평면의 `openBeltPath([2.65, 0.15], 0.39, [0.95, 0.15], 0.37)` 를 x = bx 평면에 놓은 것(두 원 반지름이 달라도 됨). 매 프레임 bx 가 바뀌면 그룹의 position.x 만 옮긴다.
- 벨트 옮기개: 아랫가닥 앞쪽에 수직 막대(반지름 0.025, y 1.4 ~ 2.0) + 끝의 포크(벨트 양옆 손가락 2개, 간격 0.18). bx 와 함께 X 로 움직이고, 위쪽은 뒤판의 수평 안내봉(x 0.7 ~ 1.6, y = 2.0)에 걸려 미끄러진다.

## 키트 추가 (gear.ts)
- `bevelGear(teeth: number, module: number, opts?: { width?: number; spokes?: number; driver?: boolean }): THREE.Group` — 45° 마이터 베벨. 피치 반지름 R = teeth × module / 2. 회전축 = 로컬 Z, 이가 난 원뿔면이 +Z 를 향하고 **원뿔 꼭짓점이 로컬 (0, 0, R)** 에 오도록(피치원 평면 = 로컬 z = 0). 이는 원뿔면 위의 사다리꼴 돌기(꼭짓점 쪽으로 갈수록 작아짐), 폭(원뿔 모선 방향) 기본 0.12. 뒷면에 허브.
- 1:1 마이터 맞물림 위상: 맞물리는 상대 기어는 반 피치(π / teeth) 어긋나게 둔다.

## 동작 (주기 10초, 시간 누적 T += dt × |speed|, 위 풀리 각 theta)
- 벨트 자리 bx: 0~3s 왼쪽(0.93) → 3~3.6s 가운데로(1.15) → 3.6~4.6s 가운데 → 4.6~5.2s 오른쪽(1.37) → 5.2~8.2s 오른쪽 → 8.2~8.8s 가운데 → 8.8~9.4s 가운데 유지 → 9.4~10s 왼쪽. (옮기는 동안은 smoothstep)
- 위 풀리 U: 회전축 X 각 = theta. 벨트 속도 v = theta' × 0.38, `belt.setOffset(theta * 0.38)`.
- 상태 하나 αC(수직축 각)를 누적한다(이 운동은 예외적으로 적분 상태가 필요 — 맞물림이 바뀌므로):
  - 벨트가 F1(왼쪽) 위: b 가 구동 → dαb = v/0.36 dt. A·B·C 는 항상 맞물려 있으므로 **αC = αb, αa = −αb**(마주 보는 베벨이라 a 와 b 는 서로 반대로 돈다).
  - 벨트가 F2(오른쪽) 위: a 가 구동 → dαa = v/0.36 dt, 같은 관계로 C 는 **반대 방향**.
  - 가운데(헐거운 풀리): 헐거운 풀리 L 만 v/0.36 로 돌고, a·b·C 는 0.4s 동안 감속해 멈춘다.
  - 옮기는 중(두 풀리에 걸침): 구동 비율을 선형 보간.
- 헐거운 풀리 L 의 각은 따로 누적(벨트가 L 에 걸린 정도에 비례해 구동, 아니면 감속).
- 베벨 기어 자세: A.rotation = αa(축 X), B = αb(축 X), C = αC(축 Y) + 반 피치 위상. 각 부호는 이가 실제로 맞물려 나아가는 방향이 되게 한 번 확인한다(꼭짓점 O 에서 보았을 때 A 와 B 가 반대로 돌면 C 와의 접점 속도가 일치).

## 확인
- t=1.5(왼쪽), t=4.0(가운데), t=6.5(오른쪽) 세 장: 벨트·포크 위치가 다르고, 수직축 표시판 화살표가 왼쪽일 때와 오른쪽일 때 반대로 돌며 가운데일 때는 멈춰 있다.
- 비스듬히 `cam=-2.6,2.2,3.2,-1.1,1.1,0.15`: A·B·C 세 베벨이 실제로 맞물려 보인다(이끼리 박히지 않음).
