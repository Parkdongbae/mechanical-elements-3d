# 058 세 단 속도 기어 (벨트를 옮겨 거는 세 가지 속도)
판화(public/mm507/fig/058.png, 확대 shots/_verify/058-fig-x4.png — Fable 교차 읽기 2026-11-25): 축을 옆에서 본 그림 하나(위·아래 두 묶음이 벨트 한 줄로 이어진 한 기구). (위) 가로 축에 긴 통(원동 드럼) 하나. 드럼 **오른쪽 끝에 감긴 세로 띠가 벨트**다(테두리·플랜지가 아니다) — 벨트는 아래로 내려가다 꺾임 표시(`~`)로 끊어 그려졌다. (아래) 주축에 같은 지름의 풀리 4개가 나란히 붙어 있고(세로 금 3줄), 벨트는 **맨 오른쪽 풀리(헐거운 풀리)** 에 걸려 있다. 풀리 묶음 왼쪽으로 축이 뻗고, 세로로 긴 톱니 띠가 3줄 있다. 이 띠 하나하나는 **위아래로 맞물린 기어 한 쌍을 가장자리에서 본 것**이다(위 기어는 주축 쪽, 아래 기어는 아래 축 쪽 — 두 축선이 띠를 가로질러 지나간다). 주축 쪽 기어는 왼쪽 끝이 가장 작고 풀리 쪽이 가장 크며, 아래 축 쪽은 반대(왼쪽이 가장 큼)다. 아래 축은 세 띠를 꿰고 왼쪽 띠에서 오른쪽 띠까지만 그려져 있다. 판화 픽셀(확대본): 풀리·드럼 반지름 ≈ 225, 주축 기어 반지름 왼쪽부터 ≈ 110 / 135 / 210, 아래 축 기어 ≈ 215 / 160 / 100, 두 축 거리 ≈ 275~325.
원문 요지: 벨트의 아래쪽 부분은 **헐거운 풀리** 위에 있다. 다음 풀리는 **주축에 고정**, 그 축 다른 끝에 **작은 기어**. 다음 풀리는 주축 위를 도는 **속 빈 축**에 고정, 거기에 **더 큰 기어**. 왼쪽 네 번째(마지막) 풀리는 또 하나의 **속 빈 축**에 고정, 그 끝에 **가장 큰 기어(풀리에 가장 가까움)**. 벨트를 풀리 사이로 옮기면 **아래 축**에 세 가지 속도가 전달된다.

★ 판화 읽기
1. 바퀴: 풀리·드럼 5개(원동 드럼 1 + 아래 풀리 4, 지름 모두 같음), 기어 6개(세 쌍). 주축 쪽 기어 크기: 왼쪽 끝(작음) < 가운데 < 풀리 옆(큼). 아래 축 쪽은 그 반대. 가장 큰 기어 ≈ 풀리 지름.
2. 줄·벨트: 1개. 원동 드럼의 오른쪽 끝을 감고 곧게 내려와 맨 오른쪽 풀리(헐거운 풀리)를 감는 열린 평벨트(닫힌 고리, 가운데는 끊어 그림).
3. 교차 가닥: 없음(열린 벨트).
4. 고정점: 판화에 축받이가 그려져 있지 않다(판화로는 알 수 없음). 세 축(드럼 축, 주축, 아래 축)은 제자리에서 도는 축.
5. 추·손잡이·크랭크: 없음.
6. 기어: 모두 바깥 이 평기어. 주축 쪽 기어의 아래쪽과 아래 축 쪽 기어의 위쪽이 물린다(세 쌍 모두 위아래).
7. 한 줄에 놓인 것: 세 축이 서로 평행(가로). 드럼의 오른쪽 끝 = 헐거운 풀리 위(같은 세로선), 드럼 폭 = 풀리 4개 폭. 세 기어 쌍은 저마다 한 세로선.
8. 글자: 판화에 글자 없음.
9. 판화와 원문이 다른 곳: 없음. 풀리 차례(오른쪽부터 헐거운 것 → 주축 고정 → 속 빈 축 1 → 속 빈 축 2)와 기어 크기 차례가 원문과 같다.

## 동작 (theta = 드럼 누적 각)
- **벨트 시간표**(주기 30 rad = 18.75 s): 상태 순서 [P1, P2, P3, P2, P1, L], 각 상태 5 rad. θ 구간(rad): P1 0~5 (0~3.1 s), P2 5~10, P3 10~15 (6.3~9.4 s), P2 15~20, P1 20~25, L 25~30 (15.6~18.8 s).
- 벨트 x 위치 xb(θ): 경계(5 의 배수) 앞뒤 ±0.6 rad 동안 이전 상태 x → 다음 상태 x 로 smoothstep, 그 밖에는 현재 상태 x. x 값: P1 0.49, P2 0.32, P3 0.15, L 0.66. 벨트 표시 offset = θ·0.43.
- **구동 풀리 판정**: 경계에서 벨트 중심이 두 풀리의 가운데에 오므로 경계 순간 구동이 바뀐다 → 상태 구간이 곧 구동 구간.
- 누적 구동각 D_P1, D_P2, D_P3, D_L = (그 풀리가 구동 풀리였던 구간 길이 합) = floor(θ/30)·(주기당 길이) + 부분합. 주기당 길이: P1 10, P2 10, P3 5, L 5 rad.
- **아래 축**: θl = −(14/24)·D_P1 − (19/19)·D_P2 − (24/14)·D_P3. 속도비(아래 축 / 드럼): P1 −0.583, P2 −1.000, P3 −1.714, L 0(멈춤).
- **주축 쪽 기어**(구동·유휴 구분 없이 아래 기어에서 계산): A = `meshAngle(cL, 24, θl, cM, 14)`, B = `meshAngle(cL, 19, θl, cM, 19)`, C = `meshAngle(cL, 14, θl, cM, 24)`. 구동 중인 쪽은 이 값의 미분이 +1(드럼과 같은 방향·같은 속도), 나머지 두 기어는 아래 축에 끌려 헛돈다.
- 몸체: 주축·P1·기어 A 는 각 A, 속 빈 축 1·P2·기어 B 는 각 B, 속 빈 축 2·P3·기어 C 는 각 C. 아래 축·기어 A′ B′ C′ 는 한 몸이라 모두 rotation.z = θl. 헐거운 풀리 L: D_L (벨트가 L 위에 있는 구간만 돌고 이외엔 멈춤 — 단순화). 드럼: θ.
- 이 식은 모두 θ 의 직접 함수다(증분 누적 없음).
