# 191 소용돌이 기어
원문: "Scroll-gears for obtaining a gradually increasing speed." — 속도가 점점 빨라지게 하는 스크롤(소용돌이) 기어.
판화 묘사: 위아래로 놓인 같은 모양의 큰 기어 둘. 각 기어는 바깥 가장자리가 나선처럼 바퀴를 한 번 돌며 점점 커지다가 끝에서 반지름 방향의 계단 벽으로 뚝 끊기고, 가장자리 전체에 이가 났다. 한가운데에 흰 고리(허브)와 짙은 원판(축 머리)이 있다. 두 기어는 한 곳(두 계단 벽이 맞닿은 자리, 판화 [215~250·215~270])에서 맞물린다.

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 px [x·y]). 1 px ≈ 0.0062.
1. 바퀴(기어)는 몇 개이고 크기 차례는? → 기어 2개, 모양·크기 같음(같은 나선). 위 [225·135], 아래 [235·350], 허브 흰 고리 반지름 35, 짙은 원판 22.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 두 기어는 같은 층(앞뒤로 겹치지 않음).
4. 고정점은? → 두 기어의 축(뒤판에서 나온 축, 머리가 짙은 원판).
5. 구동은? → 위 기어(그림에 손잡이 없음 — 위 기어를 구동으로 본다).
6. 기어는? → 둘 다 바깥으로 이가 난 나선 기어. 서로 바깥에서 맞물린다(접점은 두 축을 잇는 세로선 위).
7. 한 줄에 놓인 것은? → 두 축이 같은 세로선(x 225~235). 접점·계단 벽이 그 세로선 위.
8. 글자가 가리키는 부품은? → 글자 없음(번호 191 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 계단 벽이 맞닿은 자세(한 번 도는 끝). 두 기어가 같은 나선이라 맞물리려면 대수 나선(r = rmin·e^(φ/k))이어야 하고, 이때 중심 거리 = rmin + rmax. 계단 벽에서 더 돌 수 없으므로 한 바퀴를 가고 오는 왕복으로 보인다(원문 "속도가 점점 빨라진다" = 가는 쪽). 질문 거리 없음.

## 해석(결정 사항)
- 피치 곡선 r(φ) = rmin·e^(φ/k), φ = 0 ~ 2π, rmin 0.50, rmax 0.74, k = 2π/ln(1.5). 중심 거리 C = 1.24. 접점 반지름 합 r1 + r2 = C 가 항상 성립(식으로 보장), 호장은 r 에 선형이라 s1 + s2 = S 이고 이를 같은 간격으로 놓으면 같은 두 기어가 물린다(S = 35.5 피치, 이 35개, 벽 쪽 반 개는 없앰).
- 위 기어 시계, 아래 기어 반시계. 속도비 ω2/ω1 = r1/r2 = 0.67 → 1.5 로 점점 빨라진다.
- 판화 자세(t = 1)를 계단 벽이 닿기 직전(틈 0.05 rad)으로 둔다. 반대 끝(u = 0)에서도 같은 벽이 다시 닿기 직전.
- 판화에 없음(보충): 축 뒷받침(뒤판에서 나오는 축), 이름표 지시선.

## 구동
위 기어. theta 누적 theta += OMEGA·speed·dt. u = smoothstep(0.5 + 0.575·cos(theta − 1.6)), 위 기어 접점 각 φ1 = ε + (2π − 2ε)·u. 한 주기 3.93 s 에 한 번 가고 한 번 돌아온다.

## 부품과 치수 (새 부품은 `kit/k191.ts`, 이미 구현됨. 상수 `K191`)
기어 z 0.05 ~ 0.15(가운데 0.1), 허브 고리 z 0.15 ~ 0.19, 축 마개 0.195 ~ 0.225.
- 위 기어(name `gearU`): `scrollGear191(true)` 를 (0, 2.30) 에, `rotation.z = th1`. 이 높이 +0.04 / 이뿌리 깊이 0.05, 피치 S/35.5 ≈ 0.12, 폭 0.1, 축 구멍 0.062. outline 있음.
- 아래 기어(name `gearL`): `scrollGear191(false)` 를 (0, 2.30 − 1.24 = 1.06) 에, `rotation.z = th2`.
- 축 2개(name `shaftU`, `shaftL`, 고정): `shaftZ(0, y, 0.2…, 0.055)` 뒤판에서 허브 앞 위까지. 축 마개 `pinCap191()` 각 축 끝(짙은 원판 반지름 0.12).
- 전체 범위: x ±0.78, y 0.28(아래 기어 바닥) ~ 3.08(위 기어 꼭대기).

## 동작 (theta 의 닫힌 식 — `pose191(theta)` = { phi1, phi2, th1, th2, u, ratio })
- th1 = −π/2 − φ1 (접점이 아래쪽 −90° 에 오도록), φ2 = k·ln((C − r1)/rmin), th2 = π/2 − φ2 (아래 기어의 접점은 위쪽 +90°).
- 시각: **t = 1 (u = 1, 판화 자세: 두 계단 벽이 맞닿기 직전)**, 1.6, 2.5(중간: 이가 물려 도는 중), 3.3, 30.

- tag 4개(z 0.45): '위 기어(구동)' (−1.5, 3.1), '아래 기어' (−1.5, 0.45), '계단 벽' (1.5, 1.7), '축(고정)' (1.5, 2.9).

## 자동 검사 결과
autocheck 191: PASS (fail 0, warn 0). 대조판 확인: 위아래 같은 나선 기어, 가운데에서 두 계단 벽이 마주 닿는 모양이 판화와 같고 t = 2.5 에서 이가 물려 돈다(윤곽 침범 0.004 이하).
판화와 다르게 푼 곳: 판화는 이가 촘촘한 둥근 기어에 가깝게 그렸으나 맞물림이 성립하도록 대수 나선 피치(rmax/rmin = 1.48)로 만들었고, 벽에 잘리는 반 개 이는 없앴다. 계단 벽이 닿기 직전(0.05 rad)에서 멈추게 했다. 판화의 허브 흰 고리·짙은 원판은 돋은 고리와 축 마개로 표현했다.
