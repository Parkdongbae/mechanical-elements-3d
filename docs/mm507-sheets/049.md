# 049 래칫 베벨 기어 전동
원문: 가로 축의 번갈아 하는 원 운동(왕복 회전)이, 베벨 기어에 붙은 래칫 휠을 통해 세로 축의 연속적인 회전 운동을 만든다. 두 휠의 래칫 톱니가 서로 반대 방향으로 놓여 있고 폴이 반대 방향으로 작용한다. 베벨 기어와 래칫 휠은 축에 헐겁게 끼워져 있고, 폴은 축에 단단히 고정된 팔에 붙어 있다.

★ 판화 읽기 (질문표) — 판화 `public/mm507/fig/049.png`, 확대 `shots/_verify/049-fig-x4.png`·`049-L-x6.png`·`049-R-x6.png` 를 설계표보다 먼저 보고 적음. 정면도(가로 축이 그림과 나란함).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 5개. **베벨 기어 3개**(좌 L · 우 R · 꼭대기, 셋이 거의 같은 크기 — 마이터)와 **래칫 휠 2개**(지름 ≈ 베벨의 0.47, 모서리로 서 있어 톱니가 가로줄로만 보임).
2. 줄·벨트는? → 없음.
3. 교차하는(맞물리는) 곳은? → 꼭대기 베벨이 L·R 두 베벨과 **동시에** 물려 뒤집힌 U(ㄷ) 윤곽. 폴은 각 래칫 휠의 **꼭대기** 위에 얹혀 있다(좌우 모두).
4. 고정점은? → 바닥(빗금) 위에 **받침 기둥 2개**(위는 곧고 아래가 바깥으로 퍼진 곡선). 가로 축이 두 기둥을 지나 양쪽 밖으로 축 끝이 나온다. 세로축 받이는 판화에 없음(보충).
5. 추·손잡이·크랭크는? → 판화에 없음. 가로 축을 왕복시키는 입력 레버는 **판화에 없음(보충 — 왕복 입력을 눈에 보이게)**.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어디서 물리는가? → L·R 베벨은 이가 **안쪽(서로를 향함)**, 꼭대기 베벨은 이가 **아래**. 꼭대기 베벨의 왼쪽 가장자리가 L 의 윗부분과, 오른쪽 가장자리가 R 의 윗부분과 물린다. 래칫 휠은 각 베벨의 **바깥쪽(기둥 쪽)** 에 붙어 있다.
7. 한 줄에 놓인 것은? → 기둥 · 팔 · 래칫 휠 · 베벨 L · (가운데 빈 축) · 베벨 R · 래칫 휠 · 팔 · 기둥이 한 가로 축 위에 좌우 대칭. 세로축은 한가운데 위로 짧게 솟는다(보스 + 축 끝).
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 알 수 없는 곳은? → 래칫 **톱니의 기운 방향**과 폴이 미는 방향은 휠이 모서리로 그려져 **판화로는 알 수 없음** → 원문(두 휠 톱니가 반대, 폴이 반대로 작용)대로 정한다. 그 밖에 어긋나는 곳 없음.

구동: 가로 축(입력). 왼쪽 축 끝의 입력 레버(판화에 없음)가 왕복한다. `theta += OMEGA·speed·dt`, 입력각 s = −50°·cos(theta). 한 주기 2π rad = 3.93 s.

## 해석(결정 사항)
- **(S1b 판정) 구성은 판화와 일치** — 부품 수(베벨 3 · 래칫 2 · 팔과 폴 2벌 · 기둥 2), 이의 방향, 래칫이 베벨 바깥에 있는 것, 폴이 휠 꼭대기에 얹힌 것 모두 같다. 톱니 방향은 판화로 판정할 수 없어 원문을 따랐고, 운동(L 은 앞 행정에, R 은 뒤 행정에 밀어 세 베벨이 한 방향으로 계속 돎)은 원문과 맞다.
- 남긴 차이(비율): 판화의 래칫 지름은 베벨의 0.47, 팔 길이는 베벨 반지름의 0.67 쯤인데 구현은 0.625(반지름 0.30/0.48), 1.04(0.50/0.48)로 조금 크다. 폴·톱니가 눈에 보이게 키운 것 — 눈 검증에서 거슬리면 래칫 0.24·팔 0.34 로 줄일 수 있다(폴 관통 재확인 필요).
- 톱니·폴 방향 점검(코드 좌표로 따져 봄): 휠 L 의 곧은 면은 방위 α + 20° + k·30° 에 있고 그 아래쪽(방위가 작은 쪽)이 이뿌리 → 폴 L 은 뒤쪽 피벗(방위 −0.35 rad)에서 뻗어 +방향으로 **밀어** L 을 +α 로 돌린다. 휠 R 은 거울상(곧은 면 방위 10° − α − k·30°, 그 위쪽이 이뿌리) → 폴 R 은 앞쪽 피벗에서 −방향으로 밀어 R 을 −α 로 돌린다. 미끄러질 때 폴 끝 반지름이 이뿌리 0.25 → 이끝 0.30 으로 올랐다가 다음 면에서 떨어진다. 원문과 맞다.
- 왕복각 ±50°, 래칫 톱니 12개(피치 30°), 폴이 톱니 면에 걸리기 전 헛도는 각 10°. 한 주기에 출력 180°.
- 폴은 팔 끝 핀에 달려 톱니 윤곽을 따라 오르내린다.

## 동작 — 한 주기 θ = 2π
- `φ = mod(θ, 2π)`, 입력각 `s = −50°·cos θ`.
- 출력 누적각 α: 앞 행정(φ ≤ π) `f = max(0, 50°(1 − cos φ) − 10°)`, 뒤 행정 `f = 90° + max(0, 50°(1 + cos φ) − 10°)`, `α = (지난 주기 수)·180° + f`.
- 시간표(초): 0~0.40 폴 L 이 톱니 위를 미끄러짐(α 정지) → 0.40 폴 L 걸림 → 1.96 입력이 끝에서 멈춤(α = 90°) → 1.96~2.37 두 폴 모두 안 걸림 → 2.37 폴 R 걸림 → 3.93 한 주기 끝(α = 180°).
- 폴마다 '다음 톱니면까지 남은 각': `pL = mod(α + 20° − s, 30°)`, `pR = mod(s + α − 10°, 30°)`. 미는 동안 0.
- 자세: 가로 축 `rotation.x = s`, `bevelL` +α, `bevelR` −α(같은 가로 축 둘레 반대), `bevelTop` `rotation.y = α + 7.5°`.
- 물림 부호: 접점 (−0.48, 1.63, 0.28) 에서 L 의 속도 +0.48α' ẑ = 꼭대기의 속도 +0.48α' ẑ. R 쪽 접점 (+0.48, 1.63) 에서 둘 다 −0.48α' ẑ. 일치.
- 모델 `update(dt, speed)`: `theta += OMEGA * speed * dt; st = asm.set(theta);`

## 확인
- 판화 대조(E1·E3): 베벨 이가 서로를 향함, 꼭대기 기어 이가 아래, 래칫 휠이 베벨 바깥(기둥 쪽), 폴이 휠 꼭대기에, 기둥 아래가 바깥으로 퍼짐, 세로축이 위로.
- t=1(theta 1.6): s ≈ +1.5°, α ≈ 40° — L 폴이 걸려 민다. t=1.6: s ≈ +41.7°, α ≈ 82°. 입력이 되돌아오는 theta 4.5 에서도 베벨이 같은 방향으로 계속 돈다(R 폴이 민다).
- 근접 `cam=-0.6,1.9,1.3,-0.48,1.6,0.28`·`cam=0.6,1.9,1.3,0.48,1.6,0.28`: 이가 이골에 물린다. `cam=-0.9,1.8,1.2,-0.7,1.4,0.28`: 폴 끝이 톱니면에 닿고 박히지 않으며 미끄러질 때 들린다. **톱니가 기운 방향과 폴이 미는 방향이 맞는지**(미는 쪽이 곧은 면) 두 휠 모두 본다.
- 옆 `cam=3.4,1.2,0.28,0,1.2,0.28`: 입력 레버 끝 z ≤ 0.8.
