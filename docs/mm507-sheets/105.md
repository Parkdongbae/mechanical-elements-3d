# 105 나사 찍기 프레스
원문: "Screw stamping-press. Rectilinear motion from circular motion." — 나사식 찍기(스탬핑) 프레스. 원운동에서 직선 운동을 얻는다. (원문 끝의 "106 and 107." 은 다음 항목의 머리글이 붙은 것 — 105 와 무관.)

## ★ 판화 읽기
판화는 그림 하나(비스듬한 정면). 4배 확대 `shots/_verify/105-fig-x4.png`·`105-fig-x4c.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 바퀴 없음. 부품은 위에서부터 ① 가로 막대(플라이 바)와 그 양 끝의 렌즈 꼴 쇠공 2개(바깥쪽에 작은 꼭지) ② 막대가 꿰인 머리 블록(위에 작은 꼭지) ③ 굵은 나사 ④ 위아래에 턱이 있는 원통(너트 보스) ⑤ 너트에서 오른쪽으로 나가 아래로 굽은 몸체 ⑥ 나사 아래의 원기둥(램)과 그것을 감싼 고리 + 몸체로 가는 띠. 판화 치수(4배 px): 팔 끝에서 끝 1260, 나사 지름 150, 너트 지름 215·높이 240, 램 지름 190.
2. 줄·벨트는? → 없음. 맞닿는 짝: 나사 ↔ 너트(나사 짝), 나사 끝 ↔ 램 윗면(누름), 램 ↔ 안내 고리(미끄럼 짝).
3. 교차하는 가닥은? → 없음. 나사는 너트 속을 지나 아래로 다시 나온다(너트 위 160px, 아래 200px 가 보임).
4. 고정점은? → 너트 보스와 거기서 나온 굽은 몸체(오른쪽으로 나가 아래로 내려감 — 아래는 잘려 있음), 몸체 안쪽 다리에 붙은 램 안내 고리. 바닥·모루는 그리지 않았다.
5. 추·손잡이·크랭크는? → 손잡이 = 가로 막대(머리 블록을 꿰고 좌우로 같은 길이). 양 끝의 쇠공은 관성 추(플라이 웨이트)이자 손잡이. 머리 블록은 나사 꼭대기에 고정.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 나사산은 정면에서 "/" 로 기운다(오른쪽이 위) = **오른나사**. 산 간격(53px)에 비해 기울기가 크다(앞면 반 바퀴에 80px 올라감 → 리드 160px ≈ 나사 지름의 1.07배) = 산이 **세 줄**인 빠른 나사.
7. 한 줄에 놓인 것은? → 머리 블록·나사·너트·램이 한 세로선(나사 축). 막대는 그 축에 직각인 가로선.
8. 글자가 가리키는 부품은? → 글자 없음(번호 105 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 다만 팔 길이는 판화 비(나사 반지름의 8.4배)대로 하면 팔이 한 바퀴 가까이 도는 동안 전시 깊이를 넘는다 → 팔만 5배로 줄인다(기구는 같음). 문제 없음.
- 그 밖의 선: 너트에서 나온 **두 겹 곡선 두 벌**(위 턱에서 나온 바깥 벌, 아래 턱에서 나온 안쪽 벌) = 너트 높이만 한 두께의 굽은 몸체(거위목)의 바깥 가장자리와 안쪽 가장자리(겹선은 모서리 턱). 굽은 띠쇠 두 개로 읽어도 고정 몸체라는 점은 같다 — 한 덩어리로 만든다. 램 아래 끝의 비스듬한 타원 = 잘린 단면(더 길게 이어짐). 램 고리에서 오른쪽으로 간 두 가로선 = 고리를 몸체 다리에 붙인 띠.

## 해석(결정 사항)
- 기구: 고정 너트 속의 세 줄 오른나사. 팔을 위에서 보아 시계 방향으로 돌리면 나사가 내려가 램을 눌러 찍고, 반대로 돌리면 올라온다. 램은 돌지 않고 안내 고리 안에서 위아래로만 움직인다(나사 끝이 램 윗면의 낮은 목 안에서 헛돈다).
- 팔 길이: 판화는 나사 반지름의 8.4배, 모형은 5배(끝 반지름 0.5) — 깊이 한계(z −0.25 ~ 0.8) 때문. 나머지 비(너트·램·몸체)는 판화대로.
- 한 번 휘두르는 각 300°, 리드 0.24 → 행정 0.2.
- 바닥판·모루·찍을 재료(얇은 놋쇠 원판)는 **판화에 없음**(몸체를 받치고 "찍는다"는 뜻을 보이는 최소 보충).

## 구동
플라이 바(theta 누적). theta += OMEGA(1.6)·speed·dt. theta 2π(3.93 s)에 한 번 내려찍고 올라온다.

## 부품과 치수 (새 부품은 모두 `kit/k104.ts`, 이미 구현됨. 치수 상수 `K105` — 높이는 받침대 윗면 FLOOR = 0.18 기준의 로컬 값)
배치 상수: SX = −0.1 (나사 축 x), ZC = 0.275 (나사 축 z), FLOOR = 0.18.
- 몸체(name `frame`, 고정): `pressFrame()` — 원점 = 나사 축이 받침대 윗면과 만나는 점 → 위치 (SX, FLOOR, ZC). 안에 든 것(월드 높이): 바닥판 0.18~0.28(판화에 없음), 모루 반지름 0.15, 0.28~0.48(판화에 없음), 재료 원판 0.48~0.50(판화에 없음), 램 안내 고리(child `guide`, 안 반지름 0.124, 바깥 0.155, 높이 0.78~0.90) + 띠, 너트 보스(child `nut`, 반지름 0.14, 턱 0.165, 높이 1.50~1.80, 구멍 반지름 0.104), 거위목 팔(두께 0.16, 너트에서 x +0.61 까지 나가 바깥 반지름 0.3 으로 굽어 내려옴, 다리 x 0.31~0.61).
- 나사(name `screw`): `multiStartScrew(0.07, 0.1, 0.24, 3, 0.98, { driver: true })` — 뿌리 반지름 0.07, 바깥 반지름 0.1, 리드 0.24, 세 줄(산 간격 0.08), 길이 0.98, 축 = 로컬 Y, 원점 = 아래 끝. child `screwTip`(아래 끝), `screwTop`(위 끝). 위치 (SX, yTip, ZC).
- 플라이 바(name `flyBar`): `flyBar(0.5)` — 머리 블록 0.24 × 0.16, 막대 반지름 0.027, 쇠공(세로 반지름 0.11, 가로 0.066) 중심이 축에서 0.39, 끝 꼭지 끝이 0.5. 원점 = 머리 블록 가운데 → 위치 (SX, yTip + 0.98 + 0.08, ZC). 나사와 같은 각으로 돈다.
- 램(name `ram`): `pressRam(0.12, 0.42)` — 반지름 0.12, 길이 0.42, 원점 = 윗면 가운데(child `ramSocket`), 아랫면 child `ramFace`. 위치 (SX, yTip, ZC). **돌리지 않는다.**
- 받침대·뒤판 `displayStand()`.
- 전체 가로 범위 −0.6 ~ 0.56, 세로 0.18 ~ 2.31.
- 한 줄 정렬: 플라이 바 머리·나사·너트·램·모루는 모두 x = SX, z = ZC.

## 동작 (모두 theta 의 닫힌 식 — `screwPress105(theta)` 가 { alpha, dy, s } 를 돌려준다)
- s = (1 − cos theta)/2, alpha = −5.236·s (0 ~ −300°, 위에서 보아 시계 방향이 음수), dy = 0.24·alpha/2π (0 ~ −0.2).
- yTip = FLOOR + 0.94 + dy = 1.12 ~ 0.92 (나사 아래 끝 = 램 윗면).
- 대입: `screw.position.y = yTip`, `screw.rotation.y = alpha`, `ram.position.y = yTip`, `flyBar.position.y = yTip + 1.06`, `flyBar.rotation.y = alpha − screwPress105(1.6).alpha` (t = 1 에 팔이 그림 평면에 놓여 판화와 같은 모양이 되게 한 고정 어긋남).
- 나사 운동 확인: 회전 alpha 와 내려감 dy = lead·alpha/2π 가 같이 가므로 너트 높이의 고정된 자리에서 보면 나사산이 움직이지 않는다(너트 안의 암나사와 늘 맞물림).
- 찍는 순간(theta = π): 램 아랫면 0.50 = 재료 윗면 0.50(닿음). 맨 위(theta = 0): 램 아랫면 0.70.
- 시각: **t = 1.0 (theta 1.6: 내려가는 중 51 %, 팔이 가로 = 판화 자세)**, **t = 1.6 (theta 2.56: 92 %, 거의 찍음)**, t = 1.96 (theta π: 찍는 순간), t = 3.93 (맨 위), t = 30 (theta 48: 82 %).

## 표시
- rotArrow 2개: `rotArrow(0.2, false)`(내려갈 때, 위에서 보아 시계)와 `rotArrow(0.2, true)`(올라올 때)를 `rotation.x = −π/2` 로 눕혀 (SX, 플라이 바 높이 + 0.17, ZC) 에. sin theta ≥ 0 이면 앞의 것, 아니면 뒤의 것만 보이게. 플라이 바를 따라 오르내린다.
- tag 4개(z 0.3): '플라이 바(구동)' (SX, 플라이 바 높이 + 0.5) 따라감, '세 줄 나사' (−1.05, 1.3) 고정, '몸체와 너트' (1.4, 1.45) 고정, '램(찍는 쇠)' (−1.1, yTip − 0.3) 따라감.
- view: 전시대 전체가 보이게 position (0.6, 1.9, 6.3), target (0, 1.4, 0.2).
