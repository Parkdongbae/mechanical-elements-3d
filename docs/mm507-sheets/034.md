# 034 내접 기어
판화: 큰 원의 안쪽에 이가 나 있는 링 기어, 그 안 왼쪽에 작은 피니언(축 있음)이 안쪽 이에 맞물린다. 링 중심에는 축이 없다.
구동: 피니언(반시계). 링도 같은 방향으로 돈다.

## 부품과 치수
`internalGear`(키트 추가), `spurGear`, `shaftZ`, `rotArrow`, `tag`. 모듈 0.045.
- 링: `internalGear(48, 0.045, { width: 0.12, wall: 0.11 })` 중심 (0, 1.75), z = 0.12. 피치 반지름 1.08, 이끝(안쪽) 피치 − 1.15m, 이뿌리 피치 + 1.1m.
- 피니언: `spurGear(20, 0.045, { width: 0.14, spokes: 4, driver: true })` 피치 반지름 0.45, 중심 (−0.63, 1.75). 중심 거리 0.63 = 1.08 − 0.45. (판화의 잇수는 대략 20 : 48 로 읽힘.)
- 링은 바깥 롤러 3개(30°, 150°, 270°, 반지름 0.07)가 받친다. 롤러는 링 테두리와 같은 속도로 반대로 돈다.

## 동작
- θ += OMEGA·speed·dt, 피니언 rotation.z = θ.
- 링 = α − (S₂/S₁)(α − θ − S₁/2), α = π(링 중심 → 피니언 방향), S₁ = 2π/20, S₂ = 2π/48. 근거: spurGear 이 중심은 (j+½)S₁, 링 이골 중심은 i·S₂ 이고 접점 방향에서 피니언 이가 링 이골을 향해야 한다. 속도비 dθ₂/dθ₁ = +20/48, 같은 방향.

## 표시
rotArrow 둘 다 반시계. tag '구동 피니언 20', '링 기어 48'. notes: 잇수, 속도비 0.42, 같은 방향.

## 확인
- 두 시점에서 피니언 표시선과 링의 노란 표시 3개가 모두 반시계로 돌고, 링은 피니언의 0.42배만큼.
- 왼쪽 접점에서 피니언 이가 링 이골에 들어가 있다(θ를 훑어 피니언 윤곽이 링 구멍 밖으로 나가지 않음을 수치 확인). 비스듬한 시점 `cam=-0.6,2.2,1.0,-0.9,1.75,0.1`.
