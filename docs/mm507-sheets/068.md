# 068 한 톱니 간헐 기어
원문: 구동 바퀴 B 의 단 하나뿐인 톱니 A 가 바퀴 C 의 홈 속에서 작용하여, B 가 한 바퀴 돌 때마다 C 를 홈 한 칸만큼 돌린다(원문은 "C 가 한 바퀴"라고 적었으나 B 의 잘못). 정지구가 필요 없다 — 구동 바퀴 B 가 C 의 홈 사이 둘레에 **파 놓은 오목한 곳(hollows)** 에 맞아 들어가 잠금 구실을 한다.

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴는 몇 개이고 크기 차례는? → 2개. 왼쪽 B(매끈한 원판)와 오른쪽 C(홈 바퀴)가 거의 같은 크기. 중심 거리는 B 반지름의 약 1.98배(880 : 445), C 의 뿔 끝 반지름은 B 반지름의 약 1.07배.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(두 축의 단면만). B 왼쪽의 세로선은 판 테두리.
5. 추·손잡이·크랭크는? → 없음. 구동은 B(원문).
6. 이는 어디에 났고 무엇이 물리는가? → B 둘레의 오른쪽 위(중심선에서 약 44° 위)에 톱니 A **하나**. 톱니 바로 양옆 둘레는 움푹 파였다(C 의 뿔이 지나갈 자리). C 둘레에는 네모진 홈이 **10개**(판화에서 각을 재면 84°, 53°, 18°, −18°, −51°, −89°, −126°, −163°, 158°, 124° — 간격 약 36°). 홈과 홈 사이 둘레는 B 의 둘레와 같은 굽이로 **오목**하다(B 와 맞닿은 왼쪽 면에서 뚜렷하다. 다른 면은 거의 직선처럼 보이지만 같은 얕은 오목 호). 판화의 순간은 **잠긴 때**: B 의 둥근 둘레가 C 의 왼쪽 오목한 면에 맞아 있고, 톱니 A 는 아직 홈에 들어가기 전이다.
7. 한 줄에 놓인 것은? → 두 축이 같은 높이(가로 한 줄).
8. 글자가 가리키는 부품은? → A = 톱니, B = 구동 바퀴, C = 홈 바퀴. 화살표: B 는 위에서 오른쪽(시계), C 는 위에서 왼쪽(반시계).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 같다. 원문의 "C 가 한 바퀴"는 "B 가 한 바퀴"의 잘못(구동이 B). 없음.
- 그 밖의 선: 축 둘레 두 겹 원 = 허브 고리. 톱니 A 의 S 자 굽이 = 톱니와 양옆 파임이 이어진 윤곽.

## 해석(결정 사항)
- C 는 **홈 10개 + 오목 호 10개**(앞 설계표는 정십이각형·홈 12개·평평한 변으로 읽었다 — 홈 수와 잠금 면이 판화·원문과 달라 고침).
- 오목 호는 잠긴 자세에서 B 중심을 중심으로 하는 반지름 0.702(= B 반지름 0.7 + 틈 0.002)의 원호. 이웃한 두 호가 만나는 곳이 뿔이고, 뿔마다 반지름 방향 홈을 팠다.
- 톱니 A 는 위쪽 뿔의 홈으로 들어가 홈 벽을 밀어 C 를 36° 돌리고 아래쪽으로 나간다. 그동안 뿔은 B 의 원 안으로 0.07 쯤 들어오므로 톱니 양옆을 0.085 깊이로 파 두었다(판화의 파임).
- 잠긴 동안 C 의 흔들림 폭은 ±0.54°(틈 0.002 에서 옴 — 의도한 백래시).
- 치수를 함부로 바꾸지 않는다(홈 반폭을 0.045 로 줄이면 톱니가 끼어 멈춘다 — 수치로 확인). 바꾸려면 `shots/_verify/s068c.mjs` 를 다시 돌려 표를 새로 굽는다.

## 구동
B(theta 가 B 의 누적 각, 시계). theta += OMEGA(1.6)·speed·dt. B 한 바퀴에 C 는 1/10 바퀴(36°, 반시계).

## 부품과 치수 (모두 키트 `kit/k067.ts`, 이미 구현됨. 값은 `ONE_TOOTH` 상수)
- B(name `wheelB`): `oneToothWheel(0.14)` 중심 (−0.69, 1.75), z = 0.12. 반지름 0.7, 톱니 A(뿌리 반폭 0.05, 끝 반폭 0.03, 둘레 밖으로 높이 0.05)는 θe = 0 에서 B 로컬 45°. 톱니 양옆 ±0.24 rad 는 깊이 0.085 파임(끝 0.05 rad 는 비탈). 청동색(구동).
- C(name `wheelC`): `slotWheel(0.14)` 중심 (+0.69, 1.75), z = 0.12. 오목 호 10개(로컬 k·36° 가 호 가운데, 가운데 반지름 0.678), 뿔 반지름 0.755, 뿔마다 홈(반폭 0.055, 바닥 반지름 0.6 → 깊이 약 0.14). 황동. 정지 때 로컬 180° 호가 B 를 마주 본다.
- 중심 거리 d = 1.38. 가로 범위 −1.39 ~ 1.445, 위 y 최대 2.505, 아래 0.995.
- 축: `shaftZ(−0.69, 1.75, 0.34, 0.07)`, `shaftZ(0.69, 1.75, 0.34, 0.07)`. 허브 보스(반지름 0.10)는 바퀴 메시에 들어 있다.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).

## 동작 (모두 theta 의 함수)
- 위상: θe = theta + 4.561 (t = 1 에서 θe mod 2π = 353° — 판화 자세: 잠김, 톱니가 중심선 위 52°. t = 1.6 에서 48° — 밀기 한가운데).
- `B.rotation.z = −θe` (시계). `C.rotation.z = oneToothAngleC(θe)` (반시계, 한 바퀴마다 36° 씩 쌓임).
- `oneToothAngleC` = (q + f)·36°, q = ⌊θe/2π⌋, f = 표 보간(θe mod 2π 의 28° ~ 72° 구간 89개 점, 0.5° 간격; 그 밖은 0 또는 1).
- 주기 시간표(B 한 바퀴 = 3.93 s, θe 기준): 0° ~ 28° 잠김 → 28° ~ 72° **밀기**(약 0.48 s, C 36° 회전. 28° ~ 56° 는 거의 등속(B 의 약 1.02배), 56° ~ 72° 는 느려지며 끝남) → 72° ~ 388° 잠김. 한 바퀴의 약 12% 동안만 C 가 움직인다.
- 속도비: 평균 B : C = 10 : 1.
- 시각: **t = 1.0 (θe 353°, 잠김 — 판화)**, t = 1.3 (θe 20.5°, 톱니가 홈 입구 직전), **t = 1.6 (θe 48°, 밀기 한가운데, C 가 약 20° 진행)**, t = 1.9 (θe 75.5°, 밀기 끝, 다시 잠김).

## 표시
- rotArrow: B `rotArrow(0.5, false)`(시계), C `rotArrow(0.5, true)`(반시계), 각각 바퀴 중심 z = 0.22.
- tag 4개: '구동 바퀴 B(톱니 A 하나)' (−0.95, 2.7, 0.3), '피동 바퀴 C(홈 10개)' (1.0, 2.7, 0.3), '톱니 A' (−0.05, 2.5, 0.3), '오목한 둘레에 B 가 맞아 잠금' (0.0, 0.8, 0.3).
- notes: ① 속도비 'B 10바퀴에 C 1바퀴(홈 10개)' ② 지금 상태 '잠김 / 밀기(C 회전 중)' (θe mod 2π 가 28° ~ 72° 면 밀기) ③ C 가 돈 칸 수 ④ 구동 회전수.

## 확인
- t=1 정면: 판화와 같은 모양 — B 의 둥근 둘레가 C 의 오목한 면에 맞아 있고 톱니 A 는 오른쪽 위. t=1.6 정면: 톱니가 홈 속, 뿔이 B 의 파인 자리로 들어와 있음.
- 근접 `cam=0.0,2.1,1.4,0,1.75,0.12`(접점), `cam=0.0,1.75,2.2,0,1.75,0.12`(정면 근접). t = 1.3, 1.6, 1.9 세 장으로 입구·밀기·출구.
- 수치: `node shots/_verify/x068_070.mjs`(키트 윤곽·표로 한 바퀴 침범) → 최대 침범 0.0021(θe 58.5°, 허용 0.004), 한 바퀴에 C 정확히 36.000°.
