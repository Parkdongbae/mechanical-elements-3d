# 010 곡면 원뿔 풀리
판화: 009 와 같은 배치인데 풀리의 옆선이 곧지 않고 오목/볼록한 곡선이다. 원문: 009 의 변형으로 풀리의 모양이 다르다.

## 부품과 치수·동작
- 009 와 완전히 같되 `conePulley(0.50, 0.22, 0.9, true)`(curved = true: 옆선이 곡선 — 위 풀리는 볼록, 아래 풀리는 오목이 되게 프로파일을 r(u) = r0 + (r1 − r0)·u^1.6 (위), 아래는 1 − (1−u)^1.6 로).
- 벨트 위치의 반지름은 같은 식 r(u) 로 계산(직선 보간 대신).

## 표시
- notes: `[{ label: '속도비(종동/구동)', value: … }, { label: '풀리 모양', value: '곡면' }]`

## 확인
- 009 와 나란히 볼 때 풀리 옆선이 곡선으로 보인다. 벨트가 표면에서 뜨거나 파묻히지 않는다.
