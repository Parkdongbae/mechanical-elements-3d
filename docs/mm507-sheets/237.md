# 237 왕관 래칫
원문(en): "A reciprocating circular motion of the top arm makes its attached pawl produce an intermittent circular motion of the crown-ratchet or rag-wheel." — 위쪽 팔의 왕복 원운동으로, 거기 붙은 폴이 크라운 래칫(왕관 래칫) 또는 래그 휠에 간헐 원운동을 만든다.
쉬운 풀이: 위에서 왔다 갔다 하는 팔 끝의 폴이 왕관 모양 바퀴의 이를 한 칸씩 밀어 바퀴를 조금씩 돌린다.
판화 묘사(원본 479×439 px, 위에서 비스듬히 본 그림): 넓고 얕은 원통 그릇(왕관 바퀴) — 테 **윗가장자리**에 톱날 이가 둘레 전체에(보이는 것 약 13개 → 24개쯤). 그릇 바닥 가운데 짧은 원기둥 허브와 그 위 작은 핀, 허브 위 고리(팔의 눈)에서 가는 **팔**이 오른쪽 뒤로 뻗어 테 위를 지나 그릇 밖까지 나간다(끝 [395·65]). 팔이 테를 지나는 곳 [700~850·120~300 확대] 에 **휜 폴**(초승달 판)이 테 위에 걸쳐 내려와 이에 걸린다. 그릇 밑 가운데에서 세로 축이 아래로 판 밖까지.

## ★ 판화 읽기
판화는 비스듬한 그림 하나(정면 기준으로 위에서 약 35°). 크기 비만 읽는다: 테 바깥 반지름 = 0.49 로 정하면 허브 반지름 0.07, 팔 끝 반지름 0.82(판화 팔이 테 밖으로 약 0.6 반지름만큼 나감), 이 높이 0.075.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 왕관 래칫 1개(테 반지름 0.43~0.49, 이 24개). 다른 바퀴 없음.
2. 줄·벨트는 몇 개이고 어디서 시작해 어디서 끝나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 팔은 테 위(이끝 위 0.165)를 지나고, 폴은 팔 밑에서 테 위로 내려온다.
4. 고정점(천장·벽·바닥)은 어디인가? → 그릇의 세로 축(판화 밑으로 이어짐 → 받침대 위 세움 베어링). 팔은 그릇 허브 위 꼭지(같은 축)에 헐겁게 끼워져 따로 돈다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에 없음(팔 끝이 판 밖으로 잘림). 모형: 팔 끝 핀 → 수평 연결봉 → 세운 크랭크 축 위의 수평 크랭크 원판(보충).
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 테 **윗면**에 위로 선 톱날. 뒤쪽 테에서 왼→오른(위에서 보아 시계)으로 가며 "곧은 면으로 솟고 비탈로 내려감" → 곧은 면이 **반시계 쪽**을 본다. 폴은 반시계 쪽(핀 쪽)에서 와서 곧은 면을 시계 쪽으로 민다 → 그릇은 **위에서 보아 시계**.
7. 한 줄에 놓인 것은? → 세로 축·허브·팔 눈이 한 세로선. 팔은 축에서 곧게 반지름 방향.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 237 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 동작은 그대로 된다. 다만 판화처럼 팔을 **오른쪽 뒤**로 두면 폴 판이 화면에서 옆으로 서서(모서리만 보임) 폴 동작이 안 보이고 크랭크가 뒤판 뒤로 나간다 → 모형은 팔을 **오른쪽 앞(방위 −20°)** 으로 돌려 놓았다 → ★질문 거리.

## 다섯 장 공통 폴·이 규칙 (225·232·235·236·237 같음)
- 폴(태핏·멈춤 폴 포함) **코 끝은 원 반지름 rn = 0.014**, 코와 몸이 만나는 **오목 목은 필릿 0.02**, 나머지 볼록 모서리 0.006 — 아래 점열에 이미 들어 있다(155 "폴 닿는 곳이 각져 보임" 방지). 점열을 고치거나 다시 그리지 말 것.
- **톱날 이(225·236·237)**: 곧은 면이 반지름선(237 은 띠의 수직선)에서 **20° 갈고리꼴**(이끝이 폴 쪽으로 기울어 이골을 덮음 — 206 과 같음), 비탈은 이끝 → 다음 이뿌리 직선, 이끝은 뾰족. 판화가 대칭 이를 그린 232(네모 이)·235(별 이)만 판화를 따른다.
- 폴의 **미는 면은 이 곧은 면에서 여유각**(폴이 이에 대해 도는 만큼 + 여유)을 두어 코 원만 닿는다.
- 침범 판정(들림 계산): 코 원 중심이 바퀴 윤곽 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범(206 과 같음).
- 색: **거는 폴 = 그 폴 재질 emissive 0x7a4a00(주황빛), 쉬는 폴 = 0x000000** — 폴마다 재질을 따로 만든다.
- 재질: 바퀴는 `steel()`(밝음 — 이가 보이게, 검은 재질 금지), 폴은 `brass()`, 팔·레버는 `castIron()`.

## 해석(결정 사항)
- 이의 단면은 테 반지름 Rm = 0.46(테 가운데)에서 펼친 **띠 좌표** (s, y) 로 정한다: s = 위에서 보아 시계로 잰 호 길이. 이 하나 = 삼각형 (0, 1.20) → (−0.027298, 1.275) → (0.120428, 1.20)(곧은 면이 수직에서 20° 갈고리꼴, 이끝이 반시계 쪽으로 0.027298 기울어 이골을 덮음). 이것을 반지름 0.43~0.49 원통에 감는다(아래 '감기').
- 폴은 테 가운데(반지름 0.46)에서 **폴 코가 앉는 방위의 접평면** 위의 판(두께 0.04). 핀 축은 그 접평면의 법선(반지름 방향). 접평면의 좌표 t = 시계 쪽 거리. 코 근처에서는 t 와 s 가 같고, 핀 쪽(t −0.27)에서도 차이 ≤ 0.003(검산 여유 0.01 안).
- 폴은 제 무게로 이에 얹힘(핀 뒤, 코 앞쪽 아래 — 무게 중심이 핀보다 앞이라 코가 눌림). 스프링 없음.
- 구동 중에는 폴이 그릇과 함께 **한 덩이로** 돈다(팔과 그릇이 같은 축이라 폴이 이에 대해 돌지 않음). 팔 흔들림 20.25°, 그중 15°(1이)를 밀고 5.25° 는 헛걸음.
- 판화에 없는 보충: 세움 베어링, 크랭크 축·크랭크 원판·위 베어링 팔(뒤판에서), 수평 연결봉, 바닥의 노란 표지 막대.

## 구동
`theta += OMEGA * speed * dt`(크랭크 각, OMEGA 1.6 rad/s, 한 주기 3.92699 s). 모든 자세는 `state237(theta)` 닫힌 식 + 적재 때 만든 폴 들림 표.

## 동작 (`state237(theta)` — 닫힌 식)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀(X, Zm) = (0.628861 + rk·cos(70° + u), 0.029217 + rk·sin(70° + u)) (세계 z = −Zm).
2. 팔 끝 E = `circleIntersect([-0.35, -0.30], 0.82, [Px, Pzm], 0.644153, false)`, θarm = atan2(Ezm + 0.30, Ex + 0.35), α = TH0 − θarm. (u = 0 → α = −10.125°, u = π → +10.125°, 정확히.)
3. 그릇 시계 누적각 Φ: u < π(팔이 시계로 = **미는 행정**): Φ = n·15° + max(0, α + 10.125° − 5.25°), 구동 = α > −4.875°. u ≥ π(**돌아옴**): Φ = n·15° + 15°. `crown.rotation.y = drumShaft.rotation.y = rho0 − Φ`, rho0 = −49.091060°.
4. 폴: `pawl.rotation.z = λ0 + lift(u)`, λ0 = −32°. 구동 중 lift = 0.
5. 들림 표(적재 때 한 번): u_i = 2π·i/1440, 두 주기, 둘째 저장. 구동이 아니면 앞 시각 λ 에서 `follow`. 침범 판정은 **접평면 2차원**에서: 코 중심 c = (−0.274395, 1.40) + L·(cos λ, sin λ). 띠 어긋남 ε = (θarm − 33.9659°) − crown.rotation.y (rad), off = 0.025286 + 0.46·ε 를 sp 로 나눈 나머지. 띠 다각형: j = −4..4 마다 이뿌리 (off + j·sp, 1.20) → 이끝 (off + j·sp − 0.027298, 1.275), 끝에 (off + 4·sp, 1.20)·밑 (·, 1.10) 으로 닫음. c 가 띠 안이거나 띠까지 거리 < rn − 0.0002 이면 침범. **바깥 방향 out = +1**(λ 증가 = 코가 위로). 0.02° 걸음 + 이분법 25번. 같은 결과의 식: 비탈 직선(기울기 0.075/0.147726)까지 코 중심 거리 = rn, 또는 이끝 꼭짓점 원 교차 — 침범 없는 것 중 가장 작은 λ.
