# 008 단차(계단) 풀리 변속
판화: 위아래 두 축에 계단 모양 풀리가 서로 반대로(큰 쪽과 작은 쪽이 마주 보게) 놓이고 벨트가 한 단에 걸려 있다. 원문: 선반 등 공작 기계에서 가공물에 맞춰 속도를 바꾸는 데 쓰는 속도 풀리.
구도: 판화처럼 **축이 화면 좌우(X) 방향**으로 보이는 옆모습.

## 부품과 치수
- `displayStand()`
- 축 2개: X 방향 `rod`, 길이 1.6, y = 2.5(구동)와 y = 1.0(종동), z = 0.25. 양끝 `pillow(±0.8, y, 0.25, 'x')` 를 뒤판에서 나온 브래킷(상자)에 얹는다.
- 단차 풀리: `steppedPulley([0.50, 0.38, 0.26], 0.2)` 를 회전축이 X 가 되게 돌려(rotation.y = π/2) 위 축에는 큰 단이 왼쪽, 아래 축에는 **반대로**(큰 단이 오른쪽). 단의 x 위치: -0.2, 0, +0.2.
- 벨트: 단 i (0,1,2) 에 걸린다. 단 i 에서 위 반지름 Ru = [0.50,0.38,0.26][i], 아래 반지름 Rl = [0.26,0.38,0.50][i]. 경로는 YZ 평면(x = 단의 x)의 열린 벨트: `openBeltPath([z0, 2.5], Ru, [z0, 1.0], Rl)` 를 (y,z) 로 해석해 3D 점열로.

## 동작 (주기 9초: 단 0 → 1 → 2 → 반복, 각 3초)
- 구동축 각 = theta. 종동축 각 = ∫ omega × Ru/Rl dt (단이 바뀌어도 각이 튀지 않게 누적).
- 단을 바꾸는 0.4초 동안 벨트의 x 를 이전 단에서 다음 단으로 보간하고 반지름도 보간(경로 재생성 — `Belt.setPath`, 005 의 키트 추가 사용).
- 풀리 옆면(끝면)에 표시점이 있어 회전 속도 차이가 보이게.

## 표시
- tag '구동축', '종동축'. notes: `[{ label: '벨트 위치', value: `${i+1}단` }, { label: '속도비(종동/구동)', value: (Ru/Rl).toFixed(2) }]`

## 확인
- t=1(1단, 종동이 빠름 1.92배) / t=4(2단, 1.00) / t=7(3단, 0.52) 캡처에서 벨트 위치와 notes 가 바뀐다.
