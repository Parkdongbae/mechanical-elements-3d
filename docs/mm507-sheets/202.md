# 202 웜과 웜휠
원문(en): "Worm or endless screw and worm-wheel. Modification of 30, used when steadiness or great power is required." — 웜(끝없는 나사)과 웜휠. 30번의 변형으로, 안정된 운동이나 큰 힘이 필요할 때 쓴다. (이 앱의 번호로는 웜·웜휠이 **31번**이다 — 책의 "30" 은 31번 그림을 가리킨다. 30번은 사각 기어라 관계없다.)
쉬운 풀이: 나사 모양의 웜을 돌리면 큰 톱니바퀴가 천천히 돌고 힘은 크게 늘어난다.
판화 묘사: 위에 큰 평톱니 모양의 웜휠(가운데 축 구멍 + 짙은 축), 그 아래에 가로축에 끼운 웜. **웜의 윗변과 아랫변이 모두 가운데가 잘록하게 휘어 있다**(윗변은 휠의 둥근 둘레를 따라 오목) — 휠을 감싸 안는 **장구형(globoid, 힌들리) 웜**이다. 나사산은 정면에서 "\" 로 기운다(오른나사). 웜이 휠의 이를 여러 개(약 9~10개) 동시에 문다 — 이것이 "안정·큰 힘" 의 까닭이다.

## ★ 판화 읽기
판화 444×436 px, 1 px = 0.006. 휠 중심 [217·167], 이끝 반지름 158 px, 웜 축 높이 [·341](휠 중심 아래 174 px), 웜 몸 x [128~305], 웜 양끝 바깥 반지름 56 px, 가운데(목) 바깥 반지름 38 px.
1. 바퀴는 몇 개이고 크기 차례는? → 웜휠 1개(큰 것, 이끝 반지름 0.95) + 웜 1개(장구형, 길이 1.06). 휠 이 수는 판화로 약 50~60개(세어 보면 둘레 간격 약 15 px) → **50** 으로 정함.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 웜 몸이 휠 아래 둘레를 앞뒤로 감싼다(휠 이가 웜 목 속으로 들어감).
4. 고정점은? → 판화에는 받침이 없다(휠 축 구멍과 웜 축 막대만). 모형: 휠 축은 뒤판 보스, 웜 축은 축받이 블록 2개(판화에 없음, 보충).
5. 손잡이·크랭크는? → 없음. 구동은 웜 축(판화의 가로 막대 양끝이 잘린 끝 = 계속 이어짐).
6. 기어 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 휠은 바깥 둘레에 이. 웜은 휠의 **아래쪽**에서 휠의 바깥 이를 문다. 웜의 나사산은 장구형 몸 둘레에.
7. 한 줄에 놓인 것은? → 휠 중심과 웜 가운데(목)는 같은 세로선 x = 0. 웜 축은 수평.
8. 글자가 가리키는 부품은? → 글자 없음(번호 202 뿐).
9. 판화와 원문이 다르거나 돌 수 없는 곳은? → 원문 "Modification of 30" 의 30 은 이 앱 번호로 31(웜·웜기어). 판화 그대로 장구형 웜이면 계속 돈다(한 줄 웜, 휠 50이). 질문 거리 없음.

## 해석(결정 사항)
- 31번(원통 웜, 이 2~3개 물림)과의 차이 = **웜 몸이 휠 피치원을 따라 휜 장구형**이라 물리는 이가 약 10개. 이것을 화면에서 보이게 하는 것이 핵심(아래 ★ 눈에 보여야 할 동작).
- 웜은 공용 키트에 없으므로 새 부품 `globoidWorm`(kit/k202.ts) 을 만든다. 휠은 공용 `wormWheel` 그대로.
- 회전 방향은 판화에 없다 → 웜을 오른쪽(+X)에서 볼 때 반시계(rotation.x 증가), 휠은 **시계**.

## 구동
`theta` = 웜 각(누적), `theta += OMEGA * 3 * speed * dt`(4.8 rad/s, 31번과 같음). 휠은 웜 1바퀴에 이 1개(1 : 50).

## 부품과 치수 (모든 좌표는 세계 좌표, 단위 = 전시 단위)
상수(모델 파일 머리에 한 번만 적고 모든 부품이 이 값에서 계산한다):
- `Z202 = 50`(휠 잇수), `M202 = 0.036`(모듈), 축방향 피치 `P202 = π·0.036 = 0.113097`.
- 휠 피치 반지름 `RP = 50·0.036/2 = 0.9`, 이끝 0.936, 이뿌리 0.855.
- 웜 목 피치 반지름 `RW = 0.17`, 축 간 거리 `CC = 1.07`(휠 피치 반지름 + 웜 목 피치 반지름).
- 물림 반각 `PHI = 5·(2π/50) = 0.628319`(36°) — 웜이 휠 피치원을 감싸는 각의 반.
- 휠 중심 `(0, 1.95)`, 웜 축 높이 `YA = 1.95 − 1.07 = 0.88`, 두 부품의 z 가운데 `Z0 = 0.13`.
- `TAN_LEAD = P202 / (2π·RW) = 0.105882`.

부품:
- `displayStand()`.
- 웜휠(name `wheel`): `wormWheel(50, 0.036, { width: 0.10, spokes: 6, tanLead: -0.105882 })`, 휠 중심 (0, 1.95, 0.13), 바깥 반지름 0.936. **tanLead 는 음수**(이 웜은 휠 아래에서 무는 오른나사라, 휠 이의 비스듬함이 31번과 반대). 휠 허브 구멍 반지름은 키트가 0.126 으로 만든다.
- 휠 축(name `wheelAxle`): `shaftZ(0, 1.95, 0.30, 0.12)` — 반지름 0.12 로 허브 구멍(0.126)을 채운다. 뒤판(z −0.30)에서 z 0.30 까지.
- 장구형 웜(name `worm`): `globoidWorm(K202)` (새 키트, 아래 '키트 추가'), 그룹 위치 (0, 0.88, 0.13), 축 = 로컬 X. 몸 길이 x −0.60~0.60, 목(x = 0) 바깥 반지름 0.206, 양끝 바깥 반지름 0.371, 몸통(이뿌리) 반지름 0.125(목)~0.340(끝).
- 웜 축(name `wormShaft`): `rod(new THREE.Vector3(-1.30, 0.88, 0.13), new THREE.Vector3(1.30, 0.88, 0.13), 0.05)` — 웜 그룹의 자식으로 넣어 같이 돈다(위치 보정: 그룹 로컬 (−1.30,0,0)~(1.30,0,0)).
- 축받이 블록 2개(name `bearingL`, `bearingR`, 고정): 31번과 같은 모양 — `extrude(roundedRect(-0.09, -0.11, 0.09, 0.11, 0.025), depth, 0.01)` 를 castIron 으로, depth = 0.13 + 0.09 − (−0.30) = 0.52, 위치 (±0.95, 0.88, −0.30 + depth/2 = −0.04). 블록 가운데에 축 구멍(반지름 0.055)을 낸다(`shape.holes.push(circlePath(0, 0, 0.055))` 를 extrude 전에).
- 웜 끝 표지(name `wormMark`): 웜 그룹의 자식, `BoxGeometry(0.012, 0.16, 0.012)` paint(0xffcc00) 를 로컬 (0.606, 0.20, 0)(오른쪽 끝면 바로 밖, 목에서 끝면까지 반지름 방향 막대) — 웜이 돌 때 노란 막대가 원을 그린다.
- 전체 범위: x −1.30~1.30, y 0.509(웜 아래 끝)~2.886(휠 꼭대기).

## 동작
- `worm.rotation.x = theta`(오른쪽에서 볼 때 반시계 = 꼭대기가 앞쪽(+z)으로 감).
- `wheel.rotation.z = -Math.PI / 2 - theta / 50`(시계). 위상 근거: 키트 휠은 로컬 각 0 이 이골 가운데(31번 주석: 회전 π/2 − S/2 에서 꼭대기에 이 가운데). 웜 나사산은 theta = 0 에 휠 바로 아래(세계 각 −90°)에 산 가운데가 오므로, 그 자리에 이골이 오도록 −π/2.
- 검산: theta = 0 정면 근접에서 웜 목 꼭대기의 산 하나가 휠 맨 아래 이골 한가운데에 있고, 좌우로 산이 휠 이골마다 하나씩(약 10개) 들어가 있다. theta = 2π 에서 휠이 정확히 이 1개(7.2°) 시계로 돌았다.
- 시각: t = 1 → theta 4.8, 휠 −90° − 5.50°. t = 1.6 → theta 7.68, 휠 −90° − 8.80°. t = 30 → theta 144, 휠 −90° − 165.0°.

## 확인
- t = 1 정면: 판화처럼 휠이 위, 장구형 웜이 아래. 웜 윗변이 휠 둘레를 따라 오목하고 아랫변도 잘록. 나사산이 "\" 로 기운다.
- 근접 `cam=0.0,0.95,0.9,0,1.05,0.13`(목 위 물림), `cam=0.55,1.0,0.9,0.45,1.15,0.13`(오른쪽 끝 쪽 물림 — 여기서도 산이 이골에 들어가 있어야 한다), 옆 `cam=2.6,1.2,0.13,0,1.2,0.13`(웜이 휠 아래를 앞뒤로 감쌈).
- 산이 휠 이와 겹치지 않는다(아래 '틈 계산'). 웜 몸통(이뿌리)과 휠 이끝 틈 ≥ 0.009.
- 틈 계산(구현자 검산용): 휠 평면(z = Z0)에서 산 반폭 w(ρ) = 0.0215 + (ρ − 0.9)·0.364, 휠 이골 반폭(키트 인볼류트, 백래시 0.96) — ρ = 0.936: 산 0.0346 / 이골 0.0460(여유 0.011), ρ = 0.864: 산 0.0084 / 이골 0.0179(여유 0.0095). 휠 폭 끝(±0.05)에서 이 비스듬함과 산 위치 차 최대 0.003(웜 양끝) < 여유.

## 키트 추가 (`kit/k202.ts` — 207번도 같은 키트를 쓴다)
```ts
export const K202 = { teeth: 50, module: 0.036, rw: 0.17, phiMax: 0.628319, hand: 1 as 1 | -1, driver: true, stepsPerTurn: 64, xEnd: 0.60 } as const;
export interface GloboidOpts { teeth: number; module: number; rw: number; phiMax: number; hand: 1 | -1; driver: boolean; stepsPerTurn: number; xEnd: number }
/** 장구형(힌들리) 웜: 로컬 X = 축, 원점 = 목 가운데, 휠은 로컬 +Y 쪽(축에서 CC = rp + rw 떨어짐). */
export function globoidWorm(o: GloboidOpts): THREE.Group;
```
만드는 법(모두 이 식대로, 다른 판단 없이):
- rp = teeth·module/2(0.9), CC = rp + rw(1.07), p = π·module(0.113097), m = module.
- **몸통(core)**: `lathe(profile, 64)` 후 `rotateZ(-Math.PI / 2)`(lathe 의 Y 축 → X 축). profile 은 x = −xEnd..xEnd 를 40 등분한 점 [r(x), x], r(x) = CC − √((rp + 1.25m)² − x²) (목 0.125, 끝 0.340), 양끝에 [0, ±xEnd] 를 더해 막는다. 재질 driver ? bronze() : brass().
- **나사산(한 줄, 이어진 띠 하나)**: 매개변수 ψ ∈ [−teeth·phiMax, +teeth·phiMax](= ±10π, 10바퀴), 간격 2π/stepsPerTurn(641 고리). 각 ψ 에서 가운데 휠각 φc = hand·ψ/teeth.
  단면 4점(휠 평면 극좌표 (ρ, φ), ρ = 휠 중심에서 거리): A = (ρin, φc − δ(ρin)), B = (ρtip, φc − δ(ρtip)), Cq = (ρtip, φc + δ(ρtip)), Dq = (ρin, φc + δ(ρin)).
  ρin = rp + 1.25m + 0.006 = 0.951(몸통 속에 0.006 묻음), ρtip = rp − m = 0.864, δ(ρ) = (0.19·p + (ρ − rp)·tan20°)/ρ.
  (ρ, φ) → 웜 로컬: x = ρ·sin φ, Rr = CC − ρ·cos φ, y = Rr·cos ψ, z = Rr·sin ψ.
  고리 j 와 j+1 사이를 사각형 4개(A–B, B–Cq, Cq–Dq, Dq–A)로 잇고(삼각형 2개씩, 바깥을 향하게), 양끝 고리는 사각 뚜껑. `BufferGeometry` + `creased(geo, 40)` 로 법선. 재질은 몸통과 같게.
- 표식: `setMM(g, { kind: 'worm', fn: 'globoidWorm', teeth: 1, module, rp, rw, cc: CC, axis: 'x' })`.
- 검산: ψ = 0 단면의 산 가운데는 x = 0(목 꼭대기, 휠 쪽). 앞쪽(ψ = π/2)으로 갈수록 x 가 커져 정면에서 "\" 로 기운다(hand = 1 = 오른나사). 산 끝 바깥 반지름: 목 0.206, 끝(φ = ±0.628) 0.371.
