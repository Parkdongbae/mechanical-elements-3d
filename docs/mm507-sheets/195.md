# 195 웜으로 구동하는 이송 롤러
원문: 마주 보는 면이 같은 방향으로 움직여야 하는 이송 롤러 한 쌍을 구동한다. 두 바퀴는 똑같이 생겼고 둘 사이의 웜에 모두 물린다. 한쪽 이만 보이고 다른 쪽은 뒤·옆에 가려져 있다. 판화: 위 바퀴(작은 네모 이), 아래 큰 바퀴, 사이의 웜(점 음영), 가로로 놓인 이송 막대.

## ★ 판화 읽기
1. 바퀴는? → 같은 웜 휠 2개(위·아래, 같은 크기), 그 사이에 웜 1개.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 이송 막대가 두 바퀴 사이를 가로로 지난다.
4. 고정점은? → 두 바퀴 축과 웜 축(축받이).
5. 구동은? → 웜(가로 축).
6. 기어는? → 웜 1줄과 웜 휠 28(둘 다). 위 바퀴는 아랫면, 아래 바퀴는 윗면에서 웜에 물린다.
7. 한 줄에 놓인 것은? → 두 바퀴 중심과 웜은 같은 세로선(x=0), 막대·웜 축은 같은 높이.
8. 글자는? → 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 웜 휠이 막대와 같은 평면. 막대가 웜을 지나려면 층을 나눠야 해서, 웜 휠은 뒤 층·이송 롤러(고무 고리)는 앞 층에 같은 축으로 얹고 막대는 롤러 사이로 지나게 풀었다.

## 구동
웜 각속도 OMEGA·3 = 4.8 rad/s, theta 누적. 휠: 웜 1바퀴에 이 1개.

## 부품과 치수 (키트 추가 없음. 031 번과 같은 식)

- 웜(name `worm`): `wormScrew(0.09, 0.18, π·0.04, 0.62, { driver: true, leftHand: true })` 축 y 1.75, z 0.08, 피치 반지름 0.14. 축 rod ±1.18 + 축받이 블록 x ±0.95.
- 이송 롤러(앞 층 z 0.32): 반지름 0.66 고무 고리(두께 0.07, 폭 0.1) + 허브 + 바퀴살 4. 두 롤러 사이 틈 0.08.
- 이송 막대(name `stock`): 지름 0.066, x ±1.7, y 1.75, z 0.32 + 표시 고리 6개(흐름 표시).
