# 128 세 날개 축과 턱 달린 네모 틀
원문(글자 인식이 깨진 곳을 바로잡음): "A continuous rotary motion of the shaft carrying the three wipers produces a reciprocating rectilinear motion of the rectangular frame. The shaft must revolve in the direction of the arrow for the parts to be in the position represented." — 날개(와이퍼) 셋이 달린 축이 계속 돌면 네모 틀이 곧게 왕복한다. 부품이 그림 자리에 있으려면 축이 화살표 방향으로 돌아야 한다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/128-fig-x4.png` 로 다시 읽음. 아래 px 는 4배 그림 기준.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없다. 가운데에 **세 날개 축 1개**: 빗금 친 둥근 축(반지름 75px) + 허브(140px) + 120° 간격의 곧은 팔 셋 + 팔 끝마다 둥근 공(반지름 62px, 공 중심까지 366px). 판화의 팔 방향은 약 35°(오른쪽 위), 155°(왼쪽 위), 275°(아래).
2. 줄·벨트는? → 없다. 맞닿는 짝은 "날개 끝 공 ↔ 틀 안쪽으로 내민 턱의 옆면" 뿐이다. 판화에서는 오른쪽 위 공이 위 턱의 왼쪽 면에 닿아 있다(미는 중). 나머지 두 공은 아무것에도 닿지 않았다.
3. 교차하는 가닥이 있는가? → 없다. 날개와 틀은 같은 평면(날개가 틀의 창 안에서 돈다).
4. 고정점은? → 날개 축(제자리에서 돈다). 틀은 좌우로만 미끄러진다 — 틀 양옆 가운데에 짧게 잘린 돌기(왼쪽은 나팔꼴 끝, 오른쪽은 그림 가장자리에서 잘림)가 **안내 막대의 뿌리**다. 막대를 받치는 고정 안내는 그리지 않았다.
5. 추·손잡이·크랭크는? → 없다. 굽은 화살표(왼쪽 아래에서 오른쪽 위로, 화살촉이 오른쪽 위)가 축의 회전 방향 = **시계 방향**을 알려 준다.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 이는 없다. 틀의 **안쪽** 가장자리에 턱이 둘: ㉠ 위 턱 — 창의 윗변 오른쪽에서 아래로 내려온 것(왼쪽 면이 곧은 세로 면, 뿌리 왼쪽이 둥근 살, 밑면은 오른쪽으로 갈수록 내려가 끝이 뾰족), ㉡ 아래 턱 — 창의 아랫변 왼쪽에서 위로 솟은 것(오른쪽 면이 곧은 면, 끝은 왼쪽 위가 뾰족). 둘은 틀 중심에 대해 점대칭. 축이 시계 방향이면 위쪽을 지나는 공은 오른쪽으로 가므로 위 턱의 **왼쪽 면**을 밀어 틀을 오른쪽으로, 아래쪽을 지나는 공은 왼쪽으로 가므로 아래 턱의 **오른쪽 면**을 밀어 틀을 왼쪽으로 보낸다.
7. 한 줄에 놓인 것은? → 축 중심, 틀 양옆 돌기(안내 막대)가 같은 높이. 틀 창의 가운데는 축보다 조금 오른쪽(틀이 오른쪽으로 밀려 가는 중이라서).
8. 글자가 가리키는 부품은? → 글자 없음(번호 128 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 없음. 판화 치수(공 반지름 0.17R, 턱 면 간격 1.64R, 턱 면 끝 높이 0.49R)를 그대로 넣어 한 바퀴를 돌려 보면 침범 없이 닫힌다(`shots/_verify/s128.mjs`). 반대로 돌리면 공이 턱의 비스듬한 밑면·등에 걸리므로 원문대로 한 방향만 된다.
- 그 밖의 선: 틀은 두 겹 선(바깥 테와 안쪽 창), 옆변이 바깥으로 조금 볼록 — 모형은 둥근 모서리 네모로 단순화. 화살표 꼬리의 빗금 = 화살 깃(부품 아님).

## 해석(결정 사항)
- 한 주기 = 축 120°: 위 공이 위 턱을 41.2° 동안 밀어 틀을 오른쪽 끝으로 → 18.8° 멈춤 → 아래 공이 아래 턱을 41.2° 밀어 왼쪽 끝으로 → 18.8° 멈춤. 축 한 바퀴에 틀이 3번 왕복한다.
- 턱의 밑면이 비스듬한 까닭: 공이 턱 모서리를 돌아 나갈 때 걸리지 않게 비켜 깎은 것(공·모서리·축이 한 줄이 되는 순간 틀이 끝에 닿고 속도가 0 이 된다).
- 안내 블록 둘은 판화에 없음(막대를 받칠 최소 보충).

## 구동
세 날개 축(theta 누적, **시계 방향**). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s, 틀 왕복 주기 1.31 s.

## 부품과 치수 (새 부품은 모두 `kit/k128.ts`, 이미 구현됨. 치수 상수 `K128`)
배치: 축 중심 (0, 1.75), 날개·틀의 가운데 평면 z 는 0.12.
- 세 날개 축(name `wiper`): `wiperStar128(0.1)` — 공 중심 반지름 0.5, 공 반지름 0.085, 허브 0.19, 팔 반폭 0.045, 두께 0.1. 위치 (0, 1.75, 0.12). 청동. 날개 0 번(로컬 +X) 공에 밝은 표시점.
- 축: `shaftZ(0, 1.75, 0.28, 0.09)` — 뒤판 보스에서 날개 허브를 지나 앞으로(끝 너트 z 0.2 ~ 0.28, 허브 앞면 0.19 보다 앞).
- 턱 달린 네모 틀(name `frame`): `toothedFrame128(0.12)` — 창 반폭 0.91 × 반높이 0.65, 테 폭 0.16(바깥 2.14 × 1.62), 턱의 일하는 면은 틀 중심에서 ±0.41, 턱 두께 0.147, 일하는 면 끝 높이 ±0.245, 양옆 안내 막대 반지름 0.05·길이 0.52(끝 = 틀 중심 ± 1.59). 위치 (s, 1.75, 0.12), s = 틀 변위(−0.121 ~ +0.121). 황동 틀 + 강 막대.
- 안내 블록 2개(고정, 판화에 없음): `slideGuide128(0.05, 0.12)` 를 (−1.38, 1.75, 0.12) 와 (1.38, 1.75, 0.12) 에. **구멍이 X 방향**(막대가 지나는 방향)이고 받침 기둥은 블록 뒷면에서 뒤판으로 간다(막대·틀에 박히지 않는다). 블록 x 범위 ±(1.31 ~ 1.45): 틀 바깥(뿌리 턱 포함 최대 1.236)보다 밖, 막대 끝(최소 1.469)보다 안.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위 −1.71 ~ 1.71, 세로 0.94 ~ 2.56.

## 동작 (모두 theta 의 닫힌 식 — `wiper128(theta)` 가 { phi, s, phase, turns } 를 돌려준다)
- 축이 돈 각(도) rot = (theta − 1.6)·180/π + 30.95. 날개 0 번의 각 phi = 65.95° − rot → `wiper.rotation.z = phi`(라디안, 줄어든다 = 시계 방향).
- 틀 변위 s = `frameShift128(rot)`, p = rot 를 120 으로 접은 값:
  - 0 ≤ p < 41.19 (오른쪽으로 미는 중): 미는 공의 각 a = 65.95° − p. 공 중심 높이 0.5·sin a ≥ 0.245 이면 s = 0.5·cos a + 0.085 − 0.41(면 접촉), 아니면 s = 0.5·cos a + √(0.085² − (0.245 − 0.5·sin a)²) − 0.41(모서리 접촉). a = 24.76° 에서 s = +0.1212 로 끝난다(기울기 0).
  - 41.19 ≤ p < 60: s = +0.1212 (멈춤).
  - 60 ≤ p < 101.19: 위 식에 p − 60 을 넣고 부호를 뒤집는다(아래 공이 아래 턱을 왼쪽으로).
  - 101.19 ≤ p < 120: s = −0.1212 (멈춤).
- `frame.position.x = s`. 주기마다 정확히 닫힌다(누적 없음). 행정 0.2424.
- 시각: **t = 1.0 (rot 30.95°, 미는 공 35° — 판화 자세, s = +0.085)**, **t = 1.3 (rot 58.5°, 오른쪽 끝에서 멈춤, s = +0.121)**, t = 1.6 (rot 86°, 아래 공이 왼쪽으로 미는 중, s = −0.058), t = 1.9 (왼쪽 끝 근처).

## 키트 추가
이미 구현됨: `kit/k128.ts` (128·129·130 공용). 모델은 `'../kit/k128'` 에서 직접 import.
- `K128` — 치수 상수 { R, rb, hubR, armW, bore, Wi, Hi, rc, band, d, tw, yc, tipDrop, fillet, pose, rodR, rodLen }, 파생 상수 `PHI_E128`·`PHI_1128`·`PUSH128`(도)·`SMAX128`
- `wiper128(theta: number): Wiper128` — { phi, s, phase, turns }
- `frameShift128(rot: number): number` — 축이 rot(도) 돌았을 때 틀 변위(주기 120°)
- `wiperOutline128(): V2[]`, `frameHoleOutline128(): V2[]` — 윤곽(검증 스크립트와 같은 식)
- `wiperStar128(thick?: number): THREE.Group` — 세 날개 축, `outline`
- `toothedFrame128(thick?: number): THREE.Group` — 턱 달린 틀 + 안내 막대, `outlines.hole`
- `slideGuide128(holeR: number, zc: number, len?: number): THREE.Group` — X 방향 구멍 안내 블록 + 뒤판 받침
