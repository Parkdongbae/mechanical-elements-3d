# 176 기관 분리 장치(맞물림)
원문: "Contrivance for uncoupling engines." — 그림에 나오지 않은 크랭크 한쪽 팔에 고정된 손목(핀)은, 그려진 크랭크 팔의 고리(링)에 있는 홈이 176 의 자리에 있을 때 이 팔에 운동을 전한다. 177 의 자리로 돌리면 손목은 홈을 그냥 지나가 이 팔을 돌리지 않는다(176·177 공용 설명).

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 px [x·y]).
1. 바퀴는? → 큰 원 2개: 아래 허브 [222·360](바깥 반지름 62, 안쪽 빗금 원 = 단면으로 그린 축 48), 위 고리 [225·68](바깥 반지름 55, 가운데 빗금 원 = 핀 단면 28). 두 원을 긴 사다리꼴 팔이 잇는다(길이 약 290).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 위 고리 안에 좌우 두 개의 호 모양 홈(C 자)이 있고, 고리 양옆에 바깥으로 향한 작은 화살표 둘 [155·72], [325·70] = 구동 핀이 지나는 방향.
4. 고정점은? → 아래 허브의 축(빗금). 위 고리의 핀 단면(빗금)은 팔 끝의 보스.
5. 구동은? → 판화에 안 그려진 다른 크랭크의 손목(핀). 원문 "그림에 나오지 않은 크랭크 한쪽 팔". 모형에서는 같은 축에 구동 크랭크를 더한다(판화에 없음).
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 두 원 중심이 같은 세로선(x 222). 고리 양옆 화살표가 고리 중심과 같은 높이(y 70).
8. 글자가 가리키는 부품은? → 글자 없음(번호 176 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화의 화살표는 핀이 고리를 좌우로 가로지르는 방향. 이 해석에서 핀은 축을 도는 원의 접선 방향으로 고리를 지나므로 홈이 접선 방향이면 지나가고 반지름 방향이면 막힌다(176 = 막힘). 질문 거리 없음.

## 해석(결정 사항)
- 구동 크랭크(핀 반지름 L = 1.24)가 팔과 같은 축을 돈다. 팔 끝 고리 중심이 같은 반지름 L 에 있어 핀이 고리를 가로지른다. 홈이 반지름 방향(176)이면 핀이 고리 바깥에 닿아 팔을 밀고(연결), 홈이 접선 방향(177)이면 핀이 고리의 홈과 가운데 구멍을 지나 그냥 통과(분리).
- 한 주기 6π(18.8 s): 연결(2바퀴) → 고리가 90° 돌아 홈이 열림 → 핀이 한 바퀴 지나가고 팔은 정지 → 핀이 반대쪽에 있을 때 고리가 도로 닫힘 → 핀이 뒤에서 팔을 다시 잡음(주기마다 팔은 정확히 2바퀴, 자세 닫힘).
- 크기: 판화 비 = 팔 290 : 고리 반지름 55 : 허브 62 → L 1.24, 고리 반지름 0.36, 허브 0.30. 전시 한계(반경 L + 0.36 ≤ 1.6)로 축척 줄임.
- 판화의 순간(t = 1)에 팔이 똑바로 위를 향한다. 회전 방향 판화에 없음 → 반시계.
- 판화에 없는 보충: 구동 크랭크, 뒤판 보스.

## 구동
구동 크랭크(theta 누적 반시계). theta += OMEGA·speed·dt. 자세는 `pose176(theta)` 의 닫힌 식(핀 각 = theta − 0.35, 팔 각, 고리 홈 각).

## 동작 (theta 의 닫힌 식 — `pose176(theta)` = { pin, arm, psi, coupled })
u = theta mod 6π. 팔각 = 4πn + (u < 0.6 ? 0.6 + δ : u ≤ 4π + 0.6 ? u + δ : 4π + 0.6 + δ) − 0.35, δ = 0.318(핀이 고리에 닿는 각 차). 홈각 psi = 90°·(smooth((u − 4π)/0.6) − smooth((u − 5π)/0.6)).
시각: t = 1 (θ 1.6, 연결, 팔이 위), 1.6, 5 (θ 8: 연결), 8.5 (θ 13.6 → u 13.6 ≈ 4π+1: 열림), 30.
