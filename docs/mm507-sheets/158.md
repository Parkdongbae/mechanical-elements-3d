# 158 발판과 원판
보류 아님 — 기구는 판화·원문으로 확정된다(크랭크 원판 + 연결봉 + 발판 = 4절 링크).
원문: "Reciprocating curvilinear motion of the treadle gives a circular motion to the disk. A crank may be substituted for the disk." — 발판(트레들)의 왕복 곡선 운동이 원판에 원운동을 준다. 원판 대신 크랭크를 써도 된다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/158-fig-x4.png`, 읽은 점을 덧그린 `shots/_verify/158-fig-ov.png` 로 다시 확인.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 가운데의 큰 민 원판(살·테 없음, 가운데에 축 동그라미). 판화 치수(4배 px): 원판 반지름 388, 축 동그라미 반지름 60. 풀리·기어는 없다.
2. 줄·벨트는? → 없음. 대신 곧은 **연결봉 1개**: 위 끝은 원판 앞면 왼쪽 아래의 크랭크 핀(큰 동그라미, 축에서 321px = 원판 반지름의 0.83배, 왼쪽 아래 −146° 방향), 아래 끝은 발판 막대 밑에 달린 고리(귀)의 핀. 핀 사이 458px = 원판 반지름의 1.18배.
3. 교차하는 가닥은? → 줄이 없다. 겹쳐 그려진 곳: 연결봉이 원판 테 앞을 지나가고(봉 선이 끊기지 않음), 봉 아래 끝 고리가 발판 막대 앞에 그려져 있다. 발판 막대는 받침대 앞을 지난다(받침대 선이 막대에서 끊김).
4. 고정점은? → 바닥(빗금) 위의 주철 틀 하나: 긴 받침판 + 가운데의 종 모양 받침대(원판 축을 받침) + 오른쪽 끝의 귀(발판 받침 핀 구멍). 원판 뒤에 가린 받침대 윗부분은 **점선**으로 그렸다.
5. 추·손잡이·크랭크는? → 크랭크 = 원판 앞면에 박힌 핀. 발로 밟는 발판(긴 막대)이 손잡이 구실: 오른쪽 끝이 귀의 핀에 걸려 흔들리고 왼쪽 끝이 자유 끝(밟는 곳). 추 없음.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 원판 축 ↔ 받침대 구멍(회전), 크랭크 핀 ↔ 봉 위 눈(회전), 발판 귀의 핀 ↔ 봉 아래 눈(회전), 발판 허브 ↔ 받침 핀(회전).
7. 한 줄에 놓인 것은? → 원판 축과 받침대가 같은 세로선. 발판은 거의 수평(왼쪽 끝이 1.7° 올라감)이고 받침 핀·봉 핀·왼쪽 끝이 그 한 줄에 있다(봉 핀만 막대 가운데선보다 원판 반지름의 0.11배 아래 — 막대 밑의 귀).
8. 글자가 가리키는 부품은? → 글자 없음(번호 158 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음, 판화 치수 그대로 계속 돈다(4절 링크 그라스호프 조건: 가장 짧은 변 + 가장 긴 변 2.397 ≤ 나머지 두 변 2.546). 다만 판화 치수(크랭크가 크고 봉이 짧음)대로면 발판이 −3° ~ +46° 로 크게 흔들려 원판 앞까지 올라온다 → 난도·질문 절의 알림.
- 그 밖의 선: 원판 안의 점선 = 원판에 가린 받침대 머리. 바닥의 빗금 = 땅. 봉 아래 끝의 두 겹 동그라미 = 봉 눈과 핀. 봉 눈 위쪽으로 막대 위에 살짝 보이는 호 = 귀의 윗부분.

## 해석(결정 사항)
- 판화의 네 점(원판 축 O, 크랭크 핀, 봉 핀, 받침 핀 Q)을 그대로 옮겼다. 판화의 순간(핀이 왼쪽 아래 −146°, 발판이 거의 수평)을 t = 1 로 맞춘다.
- 실제로는 발판이 원판을 돌리지만(원판의 관성이 사점을 넘긴다) 모형의 운동식은 원판 각 theta 로 쓴다(발판 각은 theta 의 닫힌 식). 이름표에는 발판을 구동으로 적는다.
- 회전 방향은 판화에 없다 → 반시계.
- 층(앞뒤 차례)은 판화대로: 받침대(맨 뒤) → 원판 → 발판 막대 → 연결봉(맨 앞). 크랭크 핀은 원판에서 발판 층을 지나 봉까지 나온다 — 정면에서 크랭크 핀과 막대 가운데선의 거리가 한 바퀴 내내 0.321 이상이라 부딪히지 않는다(측정).

## 구동
원판(theta 누적, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 발판이 한 번 오르내린다.

## 동작
모두 theta 의 닫힌 식 — `treadle158(theta)` 가 { a, pin, T, tilt, rodAngle } 를 돌려준다.
- 원판 각 a = theta − 1.6 − 146° (t = 1 에서 −146° = 판화 자세). `disc.rotation.z = a`.
- 크랭크 핀 P = O + 0.66·(cos a, sin a).
- 봉 핀 T = 원(P, 0.945) ∩ 원(Q, √(1.735² + 0.09²) = 1.7373) 의 두 교점 가운데 P → Q 방향의 오른쪽(아래) 해.
- 발판 기울기 tilt(왼쪽 끝이 올라간 각) = π − (atan2(T − Q) − atan(0.09/1.735)). `treadle.rotation.z = −tilt`.
- 연결봉: position = (P.x, P.y, ZR), `rod.rotation.z = rodAngle = atan2(T − P)`.
- 범위(측정): tilt −2.99° ~ +45.71°(흔들림 48.7°). 전달각 22.8° ~ 111.4°.
- 시각: **t = 1.0 (핀 −146°, tilt 1.5°, 판화 자세)**, t = 1.6 (핀 269°, tilt 2.5°), **t = 2.8 (핀 19°, tilt 45.7° — 발판 최고)**, t = 4.6 (핀 184°, tilt 11.6°).

## 확인
- t = 1 정면: 판화와 같은 모양(핀이 왼쪽 아래, 봉이 아래로 내려가 발판 귀에 닿고 발판은 거의 수평). t = 2.8 정면: 발판이 가장 올라간 자세(왼쪽 끝 높이 2.27).
- 근접 `cam=-1.6,1.2,1.8,-0.65,0.9,0.2`(크랭크 핀·봉·발판 귀), `cam=2.0,1.0,1.6,1.0,0.5,0.2`(받침 귀·받침 핀), 옆 `cam=3.6,1.2,0.1,0,1.2,0.1`(층 차례: 받침대 → 원판 → 발판 → 봉), 위 `cam=0,4.5,0.5,0,1.5,0.1`.
- 수치: `node shots/_verify/s158.mjs`(키트 묶음 `_k158.bundle.mjs` 의 식 그대로) → 봉 길이 오차 0, 발판 핀 자리 오차 0, 막대 아랫면 − 받침판 윗면 최소 0.115, 바닥까지 최소 0.083, 크랭크 핀 ↔ 막대 최소 0.321. `node shots/_verify/s158b.mjs` 로 부품 메시 생성·상자 확인.
- 눈으로: 발판이 올라올 때 막대가 크랭크 핀·축 끝에 박히지 않는가(막대는 원판 앞 층), 받침 귀가 받침판에 붙어 있는가.
