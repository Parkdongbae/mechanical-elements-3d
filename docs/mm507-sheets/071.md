# 071 안쪽 테 잠금 간헐 회전
원문: 구동 바퀴 B 의 테의 **안쪽 둘레**(점선으로 그림)가 잠금 구실을 한다. 바퀴 C 의 스터드 **둘**이 그 안쪽 둘레에 기대어 쉬다가, 탭핏 A 가 스터드 하나를 치면 그 **아래의 다음 스터드가 아래쪽 틈**으로 테 밖으로 나가고 **다른 스터드가 위쪽 틈**으로 테 안에 들어온다.
(070 번의 짝: 070 은 스터드가 테의 **바깥면**에 기대고 틈이 하나, 071 은 스터드가 테 **안**에 들어가 **안쪽 면**에 기대고 틈이 둘이다.)

## ★ 판화 읽기

2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(두 축의 단면만). 왼쪽 세로선·아래 가로선은 판 테두리.
5. 추·손잡이·크랭크는? → 없음. 구동은 B(원문 driving-wheel B).
6. 이(스터드)는 어디에 있고 무엇이 물리는가? → C 의 면에 스터드 **10개**가 반지름 0.81·C 인 원 위에 36° 간격(중심에서 잰 각 81°, 117°, 152°, 189°, 219°, 256°, 289°, 326°, 4°, 40° — B 밖에 7개, B 안에 3개). B 안의 셋은 두 중심을 잇는 선(판화에서 6° 기울어 있다)에서 **+34°, −2°, −38°** — 곧 가운데 하나는 중심선 위, 위·아래 둘은 ±36°. B 에는 실선 원 둘(바깥 둘레 560, 그 안 500)과 **점선 원(455) = 테의 안쪽 면**. 테는 C 쪽에서 두 군데가 끊겼다: **위쪽 틈**(B 중심에서 본 각 136° ~ 155°)과 **아래쪽 틈**(197° ~ 211°), 그 사이에 실선으로 그린 **가드 조각**(155° ~ 197°)이 남아 있다. B 의 허브에서 왼쪽 위(163°)로 뻗은 끝이 뾰족한 두 점선 = **탭핏 A**(길이 약 375, 테 안쪽 면보다 짧다). 판화의 순간은 **잠긴 때**: 위·아래 두 스터드가 테 안쪽 면 가까이(B 중심에서 376·407 + 스터드 반지름 28 ≈ 404 ~ 435, 점선 원 455)에 있고, 탭핏은 가운데 스터드에 닿기 약 25° 전.
7. 한 줄에 놓인 것은? → 두 축(판화에서는 C 가 6° 낮다 — 모형은 같은 높이로 놓는다), 가운데 스터드가 그 선 위.
8. 글자가 가리키는 부품은? → A = 탭핏(글자가 탭핏 아래에 있다), B = 구동 바퀴, C = 스터드 원판. 화살표(B 위쪽, 왼쪽을 향함) = B 반시계.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 같다, 질문 없음. 다만 판화의 치수는 대강이다: ① ±36° 스터드가 꼭 닿으려면 테 안쪽 면이 420(스터드 원)의 0.98배여야 하는데 판화의 점선 원은 1.08배 ② 판화의 위쪽 틈은 쉬는 순간에 이미 스터드가 들어올 자리에 와 있어, 그대로면 밀기 후반에 들어오는 스터드가 테에 걸린다. 둘 다 수치로 풀어 정했다(아래 해석).
- 그 밖의 선: 축 둘레 두 겹 원 = 허브 고리. B 의 500 원 = 테 앞면의 단(모형에서는 따로 만들지 않는다). 글자 A 왼쪽의 작은 원(스터드 원 위가 아님, B 중심에서 384 = 탭핏 끝 반지름) = 판화로는 알 수 없음(탭핏 끝이 지나는 자리 표시로 보임) — 만들지 않는다.

## 해석(결정 사항)
- **쉬는 자세**: 스터드 셋이 테 안에 있다 — 가운데 하나는 중심선 위(B 중심에서 0.46), 위·아래 둘(±36°)이 테 **안쪽 면**(반지름 0.8841)에 안에서 닿는다. C 가 시계로 돌려면 아래 스터드가, 반시계로 돌려면 위 스터드가 테를 뚫고 나가야 하므로 양쪽으로 잠긴다.
- **미는 동안**: 탭핏의 앞 옆면이 가운데 스터드를 위에서 쳐 아래로 민다(C 시계). 아래 스터드는 아래 틈으로 테 밖으로 나가고, 위에서는 새 스터드가 위 틈으로 들어온다. 밀린 스터드가 −36° 자리(테 안쪽 면에 닿는 자리)에 오는 순간 탭핏 끝이 떠난다 → C 는 정확히 36°.
- **탭핏 길이 = (±36° 스터드 중심–B 중심 거리 0.8241) − 스터드 반지름 0.06 = 0.7641**. 이 길이라야 놓이는 자리가 −36° 와 꼭 맞고, 탭핏이 쉬는 위 스터드 옆을 스치듯(틈 0) 지나간다.
- **틈의 자리는 수치로 정했다**(B 로컬, 탭핏 방향 0°, 반시계 +): 아래 틈 22° ~ 62°(스터드가 테 두께를 지나는 구간 24.6° ~ 59.6° + 여유), 위 틈 −83° ~ −57°(−80.6° ~ −59.4° + 여유), 가드 조각 −57° ~ 22°(탭핏이 이 안에 있다). 판화의 틈(탭핏 기준 아래 34° ~ 48°, 위 −27° ~ −8°)보다 넓고, 위 틈은 더 뒤에 있다 — 판화대로면 걸린다.
- 테 두께 0.12(판화 0.23 은 틈이 훨씬 넓어져야 해서 줄임). 테 바깥 반지름 = 앞판 반지름 1.0041.
- 틈이 쉬는 스터드 자리를 지나는 동안은 한쪽 잠금이 풀린다(판화 구조 그대로의 성질, 070 과 같다): chi 79° ~ 118°(아래 틈이 위 스터드 자리를 지남 — 반시계 쪽만 풀림), chi 278° ~ 304°(위 틈이 아래 스터드 자리를 지남 — 시계 쪽만 풀림). 미는 구간 바로 앞 6°(158° ~ 163°, 아래 쪽)와 바로 뒤 6°(218° ~ 223°, 위 쪽)도 틈이 아직 그 자리에 있다. 모형에서 C 는 그 사이 가만히 있다(`shots/_verify/s071.mjs` 의 '받침이 없는 chi').
- 판화의 점선은 'B 의 앞판 뒤에 숨은 것' → B = 앞판(반투명, 틈 자리는 따냄) + 둘레에서 뒤로 뻗은 테 두 조각 + 탭핏. C 판은 그보다 뒤, 스터드·테·탭핏만 같은 깊이에서 만난다.

## 구동
B(반시계) theta += OMEGA(1.6)·speed·dt. C 는 B 한 바퀴에 스터드 하나(36°)만 시계로 돌고 나머지 때는 테 안쪽 면에 잠겨 선다. 평균 속도비 B : C = 10 : 1.

## 동작 (theta = 누적 각)
- B 의 탭핏 방향각 chi(도) = 65.33 + theta(도). `B.rotation.z = chi`(라디안으로). chi = 180° 일 때 탭핏이 C 중심을 향한다.
- C 의 시계방향 누적 회전 a(도) = `studAngle71(chi)` = q·36 + 표(chi 를 0 ~ 360 으로 접은 값), q = ⌊chi/360⌋. `C.rotation.z = −a`(라디안으로).
- 주기 시간표(한 바퀴 = 3.93 s, chi 기준): 0° ~ 164° 정지(양쪽 잠금, 단 79° ~ 118° 는 한쪽만) → **164° ~ 217.5°(53.5°, 15%) C 가 36° 전진** → 217.5° ~ 360° 정지(278° ~ 304° 는 한쪽만). 전진량: chi 170° 2.9°, 180° 7.8°, 190° 13.2°, 200° 19.7°, 212° 32.3°, 217.5° 36°(처음에는 B 의 반쯤 빠르기, 끝으로 갈수록 빨라졌다가 마지막에 0 으로 줄며 놓인다).
- 표 `PUSH71`(0.25° 간격, chi 162° ~ 220°)은 `solvePush71()` 의 접촉 풀이(탭핏 다각형이 스터드 원을 뚫지 않는 가장 작은 a)를 구워 넣은 것. `node shots/_verify/s071bake.mjs` 가 표 = 풀이인지 확인한다.
- 시각: **t = 1.0 (chi 157°, a = 0 — 판화 자세: 잠김, 탭핏이 가운데 스터드에 닿기 직전)**, **t = 1.3 (chi 184.5°, a ≈ 10.1° — 미는 중, 아래 스터드가 아래 틈을 지나는 중)**, t = 1.6 (chi 212°, a ≈ 32.3° — 새 스터드가 위 틈으로 들어오는 중), t = 1.9 (chi 239.5°, a = 36° — 다시 잠김).

## 확인
- t=1 정면: 판화와 같은 모양 — 탭핏이 왼쪽 위를 향하고, 테 안에 스터드 셋(가운데 하나 + 테 안쪽 면에 닿은 둘), 가드 조각이 C 쪽에 있다. t=1.3: 탭핏이 가운데 스터드를 밀어 내리고 아래 스터드가 아래 틈에 걸쳐 있다.
- 근접 `cam=−0.05,2.0,1.6,−0.05,1.75,0.2`(접점), 옆 `cam=3.2,1.75,0.2,0,1.75,0.2`, 위 `cam=0.0,3.9,1.0,0,1.75,0.2`: 스터드·탭핏·테가 같은 깊이(z 0.12 ~ 0.28)에서 만나고, C 판(z ≤ 0.06)과 테 뒷면(0.12), B 앞판(z ≥ 0.315)과 스터드 끝(0.28)은 겹치지 않는다.
