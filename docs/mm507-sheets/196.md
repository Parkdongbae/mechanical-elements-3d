# 196 흔들리는 팔의 기어
원문: 피니언 B 는 고정된 축을 중심으로 돌고, 바퀴 A 를 단 팔에 불규칙한 진동 운동을 준다. 판화: 왼쪽에 이가 난 물결 모양(비원형) 바퀴 A(축점 A 가 왼쪽 끝), 그 아래 고정 축 피니언 B(잇수 9), 오른쪽 고정 받침(해칭 바닥)에서 뻗은 가로 팔 끝에 A.

## ★ 판화 읽기
1. 바퀴는? → 물결 모양 바퀴 A 1개(원이 아님, 한쪽으로 길쭉), 피니언 B 1개(A 보다 작음).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 팔이 바퀴 A 의 면 위를 지난다.
4. 고정점은? → 팔의 오른쪽 축(받침 위), 피니언 B 의 축, 바닥 블록.
5. 구동은? → 피니언 B(한 방향 회전).
6. 기어는? → A 의 물결 모양 둘레 전체에 바깥 이, B 는 바깥 이. 서로 바깥 물림.
7. 한 줄에 놓인 것은? → 팔은 거의 수평(A 와 받침 축이 거의 같은 높이).
8. 글자는? → A(바퀴 축점), B(피니언).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 한 순간. A 는 팔 끝 축에서 자유롭게 돌고 팔이 흔들려야 하므로, A 중심이 받침을 도는 원 위를 가며 B 와 미끄럼 없이 구르도록 풀었다.

## 구동
피니언 B 일정 각속도 OMEGA·1.4 = 2.24 rad/s, theta 누적.

## 동작 (닫힌 풀이 `swingSolver196`)
접점의 A 위 호 길이 σ 를 변수로: B 축의 A 몸 기준 위치 b(σ)=접점+rp·바깥 법선. A 축은 P 를 도는 원 위이므로 |B−A|=|b(σ)| 로 팔 각 α(B 보다 위쪽 해), A 의 각 β=(A→B 방향)−(b 방향). 미끄럼 없는 구름: θ=ψ+σ/rp. θ 에서 σ 는 테이블 역산, 한 주기 = A 1바퀴 = B 3바퀴. 팔 각 약 157°~176°(불규칙).
