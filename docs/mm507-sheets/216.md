# 216 안팎 결손 기어
원문(en): "The external and internal mutilated cog-wheels work alternately into the pinion, and give slow forward and quick reverse motion." — 바깥쪽과 안쪽의 이가 일부 빠진(결손) 톱니바퀴가 번갈아 피니언에 맞물려 느린 전진과 빠른 후진 운동을 준다.
쉬운 풀이: 큰 고리 기어는 안쪽에, 가운데 작은 바퀴는 바깥쪽에 이가 반쪽씩만 있어서 아래 피니언이 둘과 번갈아 맞물린다. 한쪽으로는 천천히, 반대쪽으로는 빨리 돈다.
판화 묘사(원본 470×458 px, [x·y]): 큰 원 고리(바깥 원 중심 [245·256], 반지름 약 208 px). 고리 **안쪽 위 절반**(왼쪽 [57·250] 부터 위를 돌아 오른쪽 [430·245] 까지)에만 안쪽 이 약 25개, 아래 절반은 이 없이 매끈한 안쪽 원. 고리 중심과 같은 자리 [243·258] 에 축(짙은 원)을 단 **가운데 바퀴** — 이는 **아래 절반**에만(약 9개), 위 절반은 매끈한 원. 그 바로 아래 [238·373] 에 축(짙은 원)을 단 **피니언**(이 약 16개, 온 둘레). 피니언 위쪽 이가 가운데 바퀴 아래 이와 물려 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0055. 고리 중심 = 가운데 바퀴 중심(같은 축).
1. 바퀴는 몇 개이고 크기 차례는? → 3개. 안쪽 결손 링(피치 반지름 1.125) > 가운데 바깥 결손 바퀴(0.405) ≈ 피니언(0.36). 링과 가운데 바퀴는 한 축에 붙은 한 몸(뒤 원판으로 이어짐).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 주축 S(링·가운데 바퀴 축, 판화 [243·258]), 피니언 축 P([238·373]). 판화에 받침은 안 그려짐 — 주축은 뒤판에서, 피니언 축은 앞쪽 받침 팔에서(아래 9번·지지 표).
5. 추·손잡이·크랭크는? → 판화에 없음. 원문 "cog-wheels work into the pinion" → 결손 바퀴 쪽(주축)이 구동. 주축 앞 끝에 손잡이 보충.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 큰 링: **안쪽** 가장자리, 판화는 몸 기준 위 절반(0°~180°)에 이 약 25개 — 모델은 양 끝 하나씩 빼 23개(10.8°~169.2°). 가운데 바퀴: **바깥쪽** 가장자리, 판화는 아래 절반(180°~360°)에 약 9개 — 모델은 7개(210°~330°). 피니언(이 16, 온 둘레)은 링 안, 주축 바로 아래에 있어 **아래쪽 이는 링의 안쪽 이와, 위쪽 이는 가운데 바퀴의 바깥 이와** 물린다. 두 이 구간이 반 바퀴씩 엇갈려 한 번에 하나만 물린다.
7. 한 줄에 놓인 것은? → 주축 S 와 피니언 축 P 가 같은 세로선(x = 0). 링 이 구간 끝 두 곳과 가운데 바퀴 이 구간 끝 두 곳이 모두 S 를 지나는 가로선 위(몸 각 0°·180°).
8. 글자가 가리키는 부품은? → 글자 없음(번호 216 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → **있다(수정판).** (1) 판화처럼 링 이 25개·바퀴 이 9개를 반 바퀴씩 맞대면, 피니언이 방향을 바꾸는 순간 앞뒤 약 ±10°(주축) 동안 들어오는 쪽 끝 이와 나가는 쪽 끝 이가 피니언 이와 겹친다(바깥 물림은 피니언 아래쪽을 왼쪽으로, 안쪽 물림은 오른쪽으로 움직이게 해 맞물림 위상이 안 맞음 — autocheck 침범 0.029 로 확인). 그래서 **링 양 끝 이 하나씩(i 0·24)과 바퀴 양 끝 이 하나씩(j 9·17)을 뺐다** → 링 이 23개(10.8°~169.2°), 바퀴 이 7개(210°~330°). 생긴 빈 틈(주축 80°~86°, 274°~280°)에서는 피니언이 어느 이와도 닿지 않는다. (2) 판화는 가운데 바퀴의 이 없는 부분을 이끝 크기로 그렸지만 그러면 피니언에 박혀 이뿌리 안쪽 원(0.353)으로 했다(링의 이 없는 부분은 1.181). 질문 거리 없음(판화와 차이는 끝 이 몇 개뿐).

## 해석(결정 사항)
- 잇수: 링 50(이는 23개만, i = 1..23), 가운데 바퀴 18(이는 7개만, j = 10..16), 피니언 16. 모듈 0.045. 중심 거리 d = 0.405 + 0.36 = 1.125 − 0.36 = 0.765(바깥 물림·안쪽 물림 둘 다 맞음 — 링 잇수 = 바퀴 잇수 + 2×피니언 잇수).
- 주축이 일정하게 반시계로 돈다(몸 각 φ). 피니언 바로 위가 가운데 바퀴 이 구간일 때(φ ∈ [−60°, 80°) 무렵) 바깥 물림 → 피니언은 **반대(시계) 방향으로 1.125배 = 느린 전진**. 피니언 아래가 링 이 구간일 때(φ ∈ [86°, 274°)) 안쪽 물림 → **같은(반시계) 방향으로 3.125배 = 빠른 후진**. 빠르기 비 2.78.
- 전환: 끝 이를 뺀 빈 틈(주축 80°~86°, 274°~280°)에서 피니언 각을 3차 에르미트 곡선으로 이어 방향을 바꾼다(각·빠르기 모두 이어짐, 틈 동안 피니언은 어느 이와도 닿지 않음). 한 바퀴에 피니언 +405°(이 위상 가족 22.5° 의 정수배라 물림이 늘 맞음). 파이썬으로 주축 0°~720° 를 0.1° 간격 검산 — 피니언 × 바퀴, 피니언 × 링 겹친 넓이 0.
- 판화에 없는 보충: 링과 가운데 바퀴를 잇는 뒤 원판(밝은 색 — 이가 잘 보이게), 주축 손잡이, 피니언 앞 받침 팔, 피니언 색 원판(전진 초록·후진 주황).

## 구동
주축 몸 각 φ(t) = 0.5·t [rad] (반시계, 한 바퀴 12.566 초). t = 0 이 판화 자세(바깥 물림 한가운데).
피니언 각 ψ(φ)[도] — φ 를 도로 바꿔 n = floor((φ + 60)/360), p = φ − 360·n ∈ [−60°, 300°):
- p < 80 (바깥 물림, 느린 전진): ψ = 90 − 1.125·p
- 80 ≤ p < 86 (전환 1, 빈 틈): ψ = H(p; 80, 86, 0, −1.25, −1.125, 3.125)
- 86 ≤ p < 274 (안쪽 물림, 빠른 후진): ψ = 11.25 + 3.125·(p − 90)
- 274 ≤ p < 280 (전환 2, 빈 틈): ψ = H(p; 274, 280, 586.25, 585, 3.125, −1.125)
- p ≥ 280 (바깥 물림): ψ = 900 − 1.125·p
- 마지막에 ψ += 405·n.
H(p; a, b, ya, yb, sa, sb) = 3차 에르미트: s = (p − a)/(b − a), h = b − a, (2s³ − 3s² + 1)·ya + (s³ − 2s² + s)·h·sa + (−2s³ + 3s²)·yb + (s³ − s²)·h·sb. 피니언 `rotation.z = ψ·π/180`.

## 동작 (`state216(t)` — 결정적)
1. φ = 0.5·t(rad), φd = φ·180/π. ψ = 위 구동 식(도). `body.rotation.z = φ`, `pinion.rotation.z = ψ·π/180`.
2. 모드: p ∈ [83, 277) → 'int'(빠른 후진, 피니언 반시계), 아니면 'ext'(느린 전진, 피니언 시계) — 전환 틈 가운데에서 바뀜. `pinionDisc` 재질을 모드로 고름.
3. 수치: t = 0 → φ 0°, ψ 90.000°(ext). t = 1 → 28.648°, 57.771°. t = 2 → 57.296°, 25.542°. t = 2.7925 → 80.0°, 0.0°(전환 시작). t = 2.897 → 83.0°, −3.807°. t = 3.0019 → 86.0°, −1.256°(전환 끝). t = 4 → 114.592°, 88.099°(int). t = 6 → 171.887°, 267.148°. t = 9.5644 → 274.0°, 586.25°. t = 9.7738 → 280.0°, 585.0°. t = 12.566 → 360°, 495.0°(= t 0 + 405°). t = 30 → 859.437°, 975.740°.
4. 위상 검산(파이썬): 물림 구간에서 바깥 물림 (270 − φd)/20 − 0.5 + (90 − ψ)/22.5, 안쪽 물림 (270 − φd)/7.2 − ((270 − ψ)/22.5 − 0.5) 가 정수 — 키트 기본 위상(partialGear·internalGear·spurGear) 그대로. 전환 틈 포함 한 주기 전체(0.1° 간격, 두 주기)를 실제 이 윤곽(involuteOutline)으로 겹침 검사 → 겹친 넓이 0. autocheck 이 윤곽 침범 0.
5. 틈 검산: 링과 물릴 때 피니언 위 이끝은 주축에서 0.765 − 0.405 = 0.360, 가운데 바퀴 이 없는 원 0.353 → 틈 0.007. 바퀴와 물릴 때 피니언 아래 이끝은 주축에서 1.170, 링 이 없는 안쪽 원 1.18125 → 틈 0.011.
