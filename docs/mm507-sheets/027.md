# 027 다중 기어
판화: 비스듬히 본 **큰 바퀴** — 바깥 테두리와 방사형 살 **6개**(살마다 홈이 파여 있고 그 사이는 쐐기 모양 구멍), 중심 축은 왼쪽 위 뒤로 삐져나옴. 그 아래 앞쪽에 **작은 삼각형 바퀴**가 있고 세 꼭짓점마다 **롤러**(너트 달린 핀)가 달려 큰 바퀴의 홈 속에 들어가 있다. 작은 바퀴 축은 오른쪽 아래 앞으로 나옴(두 축은 평행). 원문: 작은 삼각형 바퀴 끝의 마찰 롤러가 큰 바퀴의 방사형 홈을 지나며 큰 바퀴를 돌린다 — 톱니 대신 롤러와 홈.
해석(한 줄): 홈 6개 · 롤러 3개의 **연속 제네바(말타 십자) 구동**으로 만든다. 롤러 반지름 a = C·sin(π/6) = C/2 이면 한 롤러가 홈에 들어가 있는 구간이 구동축 120° = 롤러 간격이라, 다음 롤러가 곧바로 이어 받아 멈춤 없이 돈다(속도는 변함).
구동: 작은 삼각형 바퀴(롤러 달린 쪽). 큰 바퀴가 종동.

## 부품과 치수
- `displayStand()`
- 두 축은 모두 Z 방향(평행), 같은 수직선 위: 큰 바퀴 중심 **O2 = (0.15, 2.00)**, 작은 바퀴 중심 **O1 = (0.15, 1.10)** → 축 간 거리 **C = 0.90**, 롤러 원 반지름 **a = 0.45**(= C/2). O1 → O2 방향 = +Y.
- 큰 바퀴 `multiGenevaWheel(0.90)` (키트 추가): 그룹 위치 (0.15, 2.00, **0.08**) — 로컬 z ∈ [−0.06, 0] 이라 세계 z 0.02 ~ 0.08, **앞면 z = 0.08**. `shaftZ(0.15, 2.00, 0.20, 0.045)`.
- 작은 바퀴 `multiGenevaDriver(0.90)` (키트 추가): 그룹 위치 (0.15, 1.10, **0.13**) — 판은 로컬 z ∈ [0, 0.04] 라 세계 z 0.13 ~ 0.17, 롤러는 판 뒤(−Z)로 0.10 나와 세계 z 0.03 ~ 0.13 에서 큰 바퀴 홈(z 0.02 ~ 0.08)에 들어간다. `shaftZ(0.15, 1.10, 0.30, 0.045)`.
- 두 바퀴 사이 앞뒤 간격: 큰 바퀴 앞면 0.08 과 작은 바퀴 뒷면 0.13 사이 0.05 (롤러 몸통이 보인다).
- 전체: 큰 바퀴 반지름 0.76 → y 1.24 ~ 2.76, 작은 바퀴 최대 반지름 0.51 → y 0.59 ~ 1.61. 모두 전시 영역 안, z ≤ 0.30.

## 키트 추가 (gear.ts 끝에 덧붙임)
연속 제네바(홈 6 · 롤러 3) 전용. 기존 시그니처는 건드리지 않는다.
```ts
/** 홈 달린 큰 바퀴. 로컬 Z = 회전축, 몸통 z ∈ [−thickness, 0](앞면 z = 0), 홈은 로컬 각 j·π/3 (j = 0..5)에서 바깥으로 열려 있다 */
export function multiGenevaWheel(C: number, opts?: { thickness?: number /*0.06*/; driver?: boolean }): THREE.Group;
/** 롤러 3개 달린 삼각 바퀴. 로컬 Z = 회전축, 판 z ∈ [0, 0.04], 롤러는 −Z 쪽으로 0.10. 롤러 로컬 각 π/2 + 2πk/3 (k = 0..2), 반지름 a = C/2 */
export function multiGenevaDriver(C: number, opts?: { driver?: boolean }): THREE.Group;
/** 큰 바퀴의 회전각 Φ(θ) (구동 바퀴 각 θ → +Z 둘레 각). 홈이 롤러 위치를 정확히 지나게 하는 절대 각 */
export function multiGenevaAngle(theta: number, C: number): number;
/** 지금 롤러가 걸려 있는 구간의 각 δ ∈ (−π/3, π/3] (O1→O2 방향 기준 롤러 각) */
export function multiGenevaPhase(theta: number): number;
```
- 상수: a = C·sin(π/6) = C/2, 홈 반폭 hs = 0.045(홈 너비 0.09), 롤러 반지름 pr = 0.035, 바퀴 바깥 반지름 R = C·cos(π/6) − 0.02 (C = 0.9 → **0.7594 ≈ 0.76**), 홈 안쪽 끝 원 중심 반지름 dIn = C − a − 0.03 (**0.42**), 축 구멍(bore) 0.05.
- **큰 바퀴 외곽(반시계 닫힌 점열)** 을 직접 만든다. 홈 j (j = 0..5, 각 aj = j·π/3) 마다 슬롯 로컬 좌표(x = 홈 중심선 방향, y = 왼쪽)로 아래 점을 차례로 만들어 (cos aj·x − sin aj·y, sin aj·x + cos aj·y) 로 돌린다:
  xr = √(R² − hs²) 일 때 (xr, −hs), (dIn, −hs), 이어서 안쪽 끝 반원 — 중심 (dIn, 0), 반지름 hs, 각 t = −90°, −120°, …, −270°(30° 간격 7점)의 (dIn + hs·cos t, hs·sin t), 이어서 (dIn, +hs), (xr, +hs).
  그 다음 림 호: 각 aj + δs → a(j+1) − δs (δs = asin(hs / R)) 를 9점으로 나눠 (R cos, R sin). j 를 0..5 로 돌려 이어 붙인다. 구멍은 `circlePts(0.05, 40)`.
  몸통 = `loft(outline, [hole], [{ z: −t, s: 0.985, hs: 1.2 }, { z: −t + 0.008, s: 1, hs: 1 }, { z: −0.008, s: 1, hs: 1 }, { z: 0, s: 0.985, hs: 1.2 }])` (t = thickness). 재질 driver ? bronze : brass.
  허브: `lathe(tubeProfile(0.05, 0.11, −t − 0.02, 0.03, 0.008), 32)` darkSteel, `rotateX(π/2)`. 표시: paint(0xd8362f) `BoxGeometry(0.07, 0.022, 0.008)` 를 로컬 (0.24, 0, 0.004) 에(홈 0 쪽 살 위, 홈 안쪽 끝 0.375 보다 안).
- **삼각 바퀴 외곽**: 극좌표 rD(φ) = 0.39 + 0.12·cos(3(φ − π/2)) (최대 0.51 = 롤러 위치 각, 최소 0.27), φ 를 96 등분한 점열. `loft(outline, [circlePts(0.05, 40)], …)` (판 두께 0.04, 가장자리 같은 방식의 모따기). 허브 `lathe(tubeProfile(0.05, 0.10, −0.01, 0.07, 0.008), 32)` darkSteel rotateX(π/2). 재질 driver ? bronze : brass.
- **롤러**(k = 0..2): 위치 (a·cos(π/2 + 2πk/3), a·sin(π/2 + 2πk/3)). 판 앞면(z = 0.04) 위에 너트 `lathe(rodProfile(0.05, 0.04, 0.062, 0.006), 24)` rotateX(π/2) steel; 롤러 몸통 `lathe(rodProfile(0.035, −0.10, 0.0, 0.005), 24)` rotateX(π/2) steel(z −0.10 ~ 0); 너트 가운데 흰 점 `CircleGeometry(0.018)` paint(0xffffff) (z = 0.063).
- `multiGenevaPhase(θ)`: `x = θ`(롤러 0 이 O1 위로 똑바로 서는 때가 θ = 0), `N = floor((x + π/3) / (2π/3))`, `δ = x − N·2π/3`.
- `multiGenevaAngle(θ, C)`: a = C/2, `γ = atan2(a·sin δ, C − a·cos δ)`, `Φ = π/6 − γ − (π/3)·N`. (δ 가 π/3 를 넘어 다음 롤러로 넘어가는 순간 γ 가 +30° → −30° 로 뛰고 N 이 1 늘어 Φ 는 이어진다. 최대 점프 0.003 rad/샘플 확인 — 연속.)
  유도: 홈 중심선이 롤러 위치를 지나야 하므로, O2 에서 롤러로 향하는 반직선의 각 = ε + π − γ (ε = O1→O2 방향 각 = π/2), 홈이 θ = 0 에서 세계 270°(아래)를 향하게 Φ(0) = π/6 (홈은 로컬 j·60°이므로 30° + j·60° ∋ 270°). 속도비 dΦ/dθ = −a(C cos δ − a)/(C² + a² − 2aC cos δ): δ = 0 에서 −1, δ = ±60° 에서 0, 평균 −1/2(구동 1 회전 → 큰 바퀴 반 바퀴, 반대 방향).
  (파이썬으로 롤러 중심이 늘 홈 중심선 위에 있음 — 수직 오차 1e-15 — 와 롤러·홈 충돌 면적 0 을 확인했다. R=0.76, hs=0.045, pr=0.035, dIn=0.42 기준.)

## 동작 (theta += OMEGA × speed × dt, OMEGA = 1.6)
- 작은 바퀴(구동): `driver.rotation.z = θ` (반시계, 롤러가 로컬 각 π/2 + 2πk/3 → 세계 각 θ + π/2 + 2πk/3).
- 큰 바퀴: `wheel.rotation.z = multiGenevaAngle(θ, 0.90)` (시계 방향으로 돎, 홈 j 가 로컬 각 j·π/3).
- 속도: 큰 바퀴 각속도 = −ω·a(C cos δ − a)/(C² + a² − 2aC cos δ), δ = multiGenevaPhase(θ). 롤러가 홈 안쪽 끝(O1 에서 가장 가까운 점)을 지날 때(δ = 0) 큰 바퀴가 구동 바퀴와 같은 빠르기, 롤러가 홈 입구에서 들어오고 나갈 때(δ = ±60°) 큰 바퀴는 순간 멈춘 듯 느리다.
- 걸림 순서: 한 롤러가 홈에 들어가 있는 동안(δ −60° → +60°) 큰 바퀴가 한 홈 간격(60°)만큼 돌고, 같은 순간 다음 롤러가 다음 홈 입구로 들어온다. 걸리지 않은 롤러 두 개는 큰 바퀴 밖(중심에서 0.9 이상 — 바퀴 반지름 0.76 바깥)을 지난다.
- 모든 자세는 θ 의 절대 함수.

## 표시
- `rotArrow(0.55, true)` 작은 바퀴 앞(세계 (0.15, 1.10, 0.20)), `rotArrow(0.7, false)` 큰 바퀴 앞(세계 (0.15, 2.00, 0.12)) — 큰 바퀴는 시계 방향.
- tag '작은 삼각 바퀴(구동)' (1.05, 0.75, 0.3), '큰 바퀴(홈 6개)' (1.05, 2.55, 0.25), '롤러' (0.7, 1.45, 0.3).
- notes: `[{ label: '구동 : 종동 (평균)', value: '2 : 1 (롤러 3개 · 홈 6개)' }, { label: '큰 바퀴 순간 속도비', value: (a*(C*cos(δ)-a)/(C*C+a*a-2*a*C*cos(δ))).toFixed(2) }, { label: '회전 방향', value: '서로 반대' }]` (C = 0.9, a = 0.45).
- view: `{ pos: [-1.2, 2.3, 5.2], target: [0.15, 1.6, 0.1] }` (판화의 비스듬한 구도, 롤러가 홈에 들어간 모습이 보이게).

## 확인
- 정면 `cam=0.15,1.6,6.2,0.15,1.6,0` t = 0, 0.5, 1.0 (θ = 0, 0.8, 1.6): 큰 바퀴의 빨간 표시가 t=0 → 0.5 사이 많이 돌고 t=0.5 → 1.0 에는 조금 덜 돌았다(속도가 변함). 작은 바퀴는 일정 각속도로 돌았다.
- 어느 때나 걸려 있는 롤러가 홈 안(홈 벽에 안 닿고 가운데 근처)에 있다. 롤러 3개 중 1개만 홈에 들어가 있고, 홈에 들어가기 직전·직후 롤러가 림 모서리에 부딪히지 않는다. t = 0.65 s(θ = π/3, δ = +60°)와 t = 1.96 s(θ = π)가 롤러가 바뀌는 때 — 그 직전·직후 두 장에서 홈 하나가 비고 다음 홈이 채워진다. (큰 바퀴 표시 각: Φ(0) = 0.52, Φ(0.8) = 0.02, Φ(1.6) = −0.12 rad 이므로 t=0→0.5 에 0.50 rad, t=0.5→1.0 에 0.14 rad 돈다.)
- 큰 바퀴가 작은 바퀴 판과 겹치지 않는다(앞뒤 0.05 간격). 큰 바퀴가 뒤판에 닿지 않는다(뒷면 z = 0.02).
- 해석 불확실: 판화의 큰 바퀴 살 사이 쐐기 구멍은 생략하고 홈 6개짜리 별판으로 단순화했다.

## 검증 후 수정 (Fable, 2026-11-25)
- 판화는 바깥에서 무는 제네바가 아니라 **카르단 직선 운동을 쓰는 2:1 구동**이다: 작은 삼각 바퀴의 롤러 3개가 동시에 이웃한 세 살의 홈에 들어가 있고, 큰 바퀴 중심이 롤러 원 위에 있다. 큰 바퀴는 같은 방향으로 정확히 절반 속도(θ/2), 일정한 속도로 돈다. 위 제네바 해석은 이것으로 대체한다(구현: `src/mm507/models/m027.ts`, 키트 multiGeneva* 는 더 쓰지 않음).
