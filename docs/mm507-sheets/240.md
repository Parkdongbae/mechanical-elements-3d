# 240 래칫의 여러 멈추개
원문: "Represents varieties of stops for a ratchet-wheel." — 래칫 바퀴를 위한 여러 가지 멈추개를 나타낸다. 쉬운 풀이: 톱니 모양 바퀴에 걸리는 폴과 멈추개의 여러 모양을 한 그림에 모아 보여 준다. 폴이 이에 걸려 바퀴가 거꾸로 돌지 못하게 한다.
판화 묘사(원본 479×426 px, [x·y]): 가운데 톱날 이 바퀴(축 [215·205], 이끝 반지름 약 120 px, 이뿌리 약 108 px, 축에 짙은 허브). 극좌표로 펴서 재면 이 약 20개(17.5° 안팎 간격)이고, 각이 반시계로 갈 때 반지름이 **뚝 올라갔다가 서서히 내려간다** = 곧은(가파른) 면이 시계 쪽을 본다. 멈추개 넷: ① 위 오른쪽 곧은 막대 폴 — 받침 구멍 [456·122], 왼쪽 끝 부리가 바퀴 57° 쪽 이골에 걸림. ② 왼쪽 굽은 폴 — 받침 구멍 [77·212], 바퀴 왼쪽 바깥을 따라 굽어 올라가 끝 갈고리가 127° 쪽 이골에 걸림. ③ 아래 짧은 폴 — 받침 구멍 [215·335](바퀴 축 바로 밑), 위 오른쪽 모서리 [232·304](280° 쪽)가 이에 닿고, 왼쪽으로 말린 꼬리(손잡이). ④ 그 밑 S 자 판 스프링 — 나사 구멍 [251·395] 의 발에서 오른쪽으로 갔다가 [350·350] 에서 말려 돌아와, 위 띠가 ③ 폴 밑면을 받친다.

## ★ 판화 읽기
판화 1 px = 0.0068. 바퀴 중심 W = (−0.30, 1.72)(세계). "W 기준" = 세계 좌표 − W.
1. 바퀴는 몇 개이고 크기 차례는? → 래칫 바퀴 1개(이끝 0.80, 이뿌리 0.70, 이 20개). 판화의 12 px 이 높이를 0.10 으로 맞춤.
2. 줄·벨트는? → 없음. (판 스프링은 강철 띠 — 줄·벨트 검사 대상 아님.)
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 바퀴 축 W, 폴 받침 셋 P1 (1.639, 0.564)·P2 (−0.938, −0.048)·P3 (0, −0.884)(W 기준), 스프링 발 나사 (0.245, −1.30)(W 기준). 모두 뒤판에 박은 핀.
5. 추·손잡이·크랭크는? → 판화에 없음. 바퀴를 돌리는 손잡이(팔 + 손잡이)를 바퀴 축 앞에 보충. ③ 폴의 말린 꼬리는 판화 그대로(누르면 폴이 풀리는 손잡이 — 이 모형에서는 따로 움직이지 않음).
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 바퀴 바깥 둘레에 톱날 이. 곧은 면이 **시계 쪽**을 본다 → 세 폴 모두 곧은 면의 시계 쪽 구석에 코가 들어가 **시계 방향 회전을 막고**, 반시계로 돌 때는 비탈을 타고 올라갔다 떨어진다. ①은 받침점 쪽으로 밀리는 '미는 폴', ②는 끝이 갈고리라 당겨지는 '당기는 폴', ③은 스프링이 밀어 올리는 폴.
7. 한 줄에 놓인 것은? → ③ 받침 P3 가 바퀴 축 바로 밑 같은 세로선(x 차 0). ① 폴 막대는 거의 수평.
8. 글자가 가리키는 부품은? → 판화에 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 그대로 돈다. 다만 (가) 세 코 자리(57°·127°·280°)는 이 간격(18°)의 배수로 맞지 않는다 → ①·②는 4 피치(72°) 차로 맞추고(곧은 면 59°·131°), ③은 **반 피치 어긋나게**(곧은 면 284°) 둔다 — 판화 280° 에 가장 가깝고, 바퀴가 9° 마다 ①② 또는 ③ 이 번갈아 잡는다(반 칸 멈춤). (나) ④ 스프링은 휘는 띠라 강체로는 못 만든다 → 아래 띠(발~말린 곳)는 고정, 위 띠는 말린 곳 중심을 축으로 조금 돌게(휘는 것의 근사). → ★질문 거리.

## 해석(결정 사항)
- 바퀴는 손잡이로 **반시계**로 12.5° 돌았다가, 손을 놓아 **시계로 3.5° 되돌아가면 폴에 걸려 멈춘다**(멈춤 0.3 초, 걸린 폴 빨강). 한 박자 1.6 초, 박자마다 9°(반 칸) 앞으로.
- 짝수 박자 끝(바퀴 각 θ = 18° 의 배수)에는 ①·② 가 함께, 홀수 박자 끝(θ = 9° + 18° 의 배수)에는 ③ 이 걸린다.
- 폴 코는 반지름 0.016 둥근 끝 + 앞면·뒷면 모두 둥근 이음(오목 0.012, 볼록 0.006) — "폴이 이 닿는 곳이 각져 보임" 방지. 코는 잠길 때 곧은 면과 이뿌리 비탈이 만드는 구석에 틈 0.0015 로 앉는다.
- 폴 자세는 바퀴 각에서 **표**로 읽는다(동작 절). 표는 파이썬(shapely)으로 폴 윤곽 × 바퀴 윤곽이 닿을 때까지 돌려 구했다(틈 0.0006, 앞 자세에서 이어 따라감).

## 구동
`t` 는 장면 시간(초). 박자 Tb = 1.6, n = floor(t/Tb), u = t − n·Tb, s(x) = x²(3 − 2x)(x 는 0~1 로 자름).
- u < 1.0: θ = 9n + 12.5·s(u/1.0), θmax = 9n + max(3.5, 12.5·s(u/1.0))
- 1.0 ≤ u < 1.3: θ = 9n + 12.5 − 3.5·s((u − 1.0)/0.3), θmax = 9n + 12.5
- 1.3 ≤ u < 1.6: θ = 9(n + 1), θmax = 9n + 12.5 (멈춤)
θ(도)는 반시계 +. 바퀴 `rotation.z = (5 + θ)·π/180`.
