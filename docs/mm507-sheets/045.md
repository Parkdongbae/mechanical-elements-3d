# 045 마찰 홈 기어
원문: 마찰을 이용하는 홈 기어 — 비교적 최근의 발명. 오른쪽 그림은 더 쉽게 이해할 수 있도록 확대한 단면이다.

## ★ 판화 읽기
판화에는 그림이 **둘**: 왼쪽 = 두 바퀴를 옆에서 본 모습(축이 가로), 오른쪽 = 맞닿는 곳을 크게 그린 단면(움직이지 않는 설명 그림).
1. 바퀴는 몇 개이고 크기 차례는? → 바퀴 2개(이가 없는 마찰 바퀴). 위가 작고 아래가 크다(판화 높이 360 : 500, 지름비 약 0.72). 폭은 같다.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다. 축 끝이 좌우로 짧게 나와 있다.
5. 추·손잡이·크랭크는? → 없음. 구동 표시 없음(모형은 위 작은 바퀴를 구동으로).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 이는 없다. 둘레를 한 바퀴 도는 **V 능선·V 홈**이 축 방향으로 줄지어 있고(세로 줄무늬 = 능선의 비탈면, 밝은 면·어두운 면), 가운데 지그재그 선에서 한쪽 능선이 다른 쪽 홈에 끼어 비탈면끼리 눌린다. 위 바퀴는 윗변에 뾰족한 끝이 6개(양 끝 모서리 포함 — 홈 5줄), 아래 바퀴는 아랫변에 뾰족한 끝이 5개(능선 5줄, 양 끝은 홈 쪽) — 아래 바퀴의 능선 5줄이 위 바퀴의 홈 5줄에 들어간다.
7. 한 줄에 놓인 것은? → 두 바퀴의 좌우 끝이 같은 세로선(폭 같음), 두 축은 평행한 가로선. 오른쪽 단면 그림은 바퀴 그림과 같은 높이에 나란히 있고 지그재그 선이 두 바퀴가 맞닿는 높이와 같다.
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없다(없음).
- 오른쪽 그림의 선: 빗금 친 긴 네모 둘(위·아래) = 두 바퀴 테의 단면(빗금 = 잘린 면). 가운데 굵은 지그재그(약 4주기) = 맞닿은 V 면. 네모는 폭보다 높이가 훨씬 크다(폭 270 : 높이 780).

## 구동
위 바퀴 theta += OMEGA·speed·dt.

## 부품과 치수 (키트: `grooveWheel`, `grooveRadius`, 이미 구현됨)
- 위 A(구동, name `wheelA`): 피치 반지름 RA = 0.34, `grooveWheel(0.34, { ridgeAtCenter: false, driver: true })` — 가운데가 홈, 양 끝 모서리가 능선(판화의 위 바퀴). 아래 B(name `wheelB`): 피치 반지름 RB = 0.47, `grooveWheel(0.47, { ridgeAtCenter: true })` — 능선 5줄. 능선 간격 0.09, 깊이 0.07, 능선 끝 깎음 0.008, 폭 0.45.
- 좌표: ZC = 0.27, X0 = −0.55, Y2 = 1.30(B), Y1 = Y2 + 0.34 + 0.47 + **0.0015** = 2.1115(A) (면이 겹쳐 깜박이지 않게 0.0015 틈).
- 축: 반지름 0.045, x = X0 ± 0.42.
- 받침(판화에 없음, 최소): x = X0 ± 0.36 에 뒤판에서 나온 기둥(반지름 0.07, z −0.3 ~ ZC)과 끝 고리, 축마다 2개.
- 확대 단면(정지, 판화 오른쪽 그림): 지그재그 피치 0.17, 깊이 0.13, 4주기(폭 0.68), 지그재그 가운데선 (1.30, 1.72). 위 덩어리(bronze)는 y 1.72 ~ 2.52, 아래 덩어리(brass)는 y 0.87 ~ 1.72(지그재그 선에서 0.004 틈), 위 덩어리의 능선이 아래로 향한다. 두께 0.14 로 뒤판에 붙인다(z −0.30 ~ −0.16 — 떠 있지 않게). `extrude(shapeFrom(...))` 로 만든다(`shots/_verify/g5scene.ts` 에 구현 예).
