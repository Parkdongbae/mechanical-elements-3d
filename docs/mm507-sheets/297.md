# 297 랜턴 바퀴 탈진기
원문(en): "An escapement with a lantern wheel. An arm, A, carries the two pallets, B and C." — 랜턴 바퀴(핀으로 이루어진 바퀴)를 쓴 탈진기. 팔 A 가 두 팔레트 B 와 C 를 지닌다. (원문은 이 두 줄뿐 — 구조는 판화로 읽는다.)
쉬운 풀이: 바퀴 앞면 둘레에 둥근 핀 8 이 박혀 있고, 위에 매달린 팔 A 가 진자처럼 흔들린다. 팔에 붙은 팔레트 B 는 핀 원 **바깥**에서, C 는 핀 원 **안쪽**에서 핀 길로 들어간다. 팔이 오른쪽으로 가면 B 가 빠지며 핀을 놓고 C 가 들어와 다음 핀을 막고, 왼쪽으로 가면 반대. 팔이 한 번 오갈 때 바퀴가 핀 하나만큼(45°) 반시계 방향으로 돈다.
판화 묘사(원본 528×520 px, **정면**): 큰 원판 바퀴(중심 [310·345], 반지름 ≈ 155 px), 가운데 축(검은 원 [310·345], 반지름 ≈ 22 px)과 칼라 고리(≈ 35 px). 원판 둘레 안쪽 반지름 ≈ 137 px 에 둥근 핀 8(반지름 ≈ 18 px, 각 ≈ 4°·49°·94°·136°·180°·225°·279°·320°). 바퀴 왼쪽에 아래로 굽은 화살표(반시계). 오른쪽 위 바퀴 밖 [410·140] 에 둥근 머리(축 구멍)를 가진 팔 A 가 **점선**으로 그려져 아래로 [390·330] 까지 내려옴. 팔에 비스듬한 판 둘: B([400·275]–[460·215], 핀 원을 바깥에서 가로지름), C([350·290]–[420·330], 핀 원 안쪽).

## ★ 판화 읽기
판화 하나(정면). 판화 1 px ≈ 0.00613(핀 원 137 px → 0.84). 판화 바퀴 중심 [310·345] ↔ 세계 Wc (−0.15, 1.40), 팔 머리 [410·140] ↔ P (0.463, 2.657).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 랜턴 바퀴 1(원판 반지름 1.05, 핀 8). 보충한 태엽통(반지름 0.50, 바퀴 뒤 같은 축 — 앞에서는 안 보임).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 팔 A 가 원판·핀 **앞** 층을 지난다(판화의 점선 = 앞을 지나는 윤곽 → 반투명으로).
4. 고정점은? → 바퀴 축 Wc(뒤판 보스), 팔 축 P(뒤판 보스, 원판 밖 — Wc 에서 1.40).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 팔 A 자체가 진자: P 에서 아래로 내려와 끝에 작은 추(보충). 바퀴는 뒤 태엽통이 반시계로 민다(보충).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 이 대신 원판 앞면의 둥근 핀 8. B 는 바깥에서, C 는 안쪽에서 핀이 지나는 길(반지름 0.77~0.91)로 들어가 핀의 **앞쪽(시계 쪽)** 을 막는다.
7. 한 줄에 놓인 것은? → 없음(P 는 바퀴 중심에서 오른쪽 위 64°). B 접점은 바퀴 중심에서 ≈ 33°, C 접점은 ≈ 9°.
8. 판화에 글자(A, B…)가 가리키는 부품은? → A 팔(진자), B 바깥 팔레트, C 안쪽 팔레트. 바퀴·핀은 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 원문이 짧아 판화로만 읽음: 팔이 점선이라 원판 앞을 지나는 것으로 보고 반투명. (나) 판화의 B·C 는 곧은 판인데, 그대로면 핀이 판 끝 모서리에서만 놓여 충격이 없다 → 각 판 끝에 짧은 비탈(충격면)을 깎음. (다) 팔이 P 둘레로 돌아 팔레트 면이 핀에 대해 비스듬히 움직이므로, 핀이 걸린 동안 바퀴가 조금 앞뒤로 움직인다(되튐형, 한 주기 뒤로 5.0°) — 판화대로 두면 생기는 성질이라 그대로. (라) 판화 핀 반지름(0.11)을 0.07 로 줄여 팔레트 사이 틈을 확보. (마) 추·태엽통 보충.

## 해석(결정 사항)
- **진자 각만 시간표, 바퀴 각은 접촉에서**: ψ(t) = 12°·sin(π t)(주기 2 초, P 둘레 반시계 + — 팔 아래끝이 오른쪽으로). 바퀴는 태엽통이 늘 반시계로 미므로, 매 순간 φ = 걸린 핀(원)이 팔레트 윤곽에 닿는 각 — 핀 중심이 지나는 원과 '팔레트 각 변에서 핀 반지름 0.07 만큼 떨어진 캡슐' 경계의 교점 중 먼저 만나는 점.
- shapely 로 핀 원 8 과 팔레트 다각형을 진자 위상 0.1° 간격 3600 자세로 겹쳐 보아 접촉 계산과 같음(차 2×10⁻⁹°, 겹침 0).
- 한 주기(2 초)에 정확히 +45°(반시계 핀 하나). B 를 놓을 때 7.32° 툭, C 를 놓을 때 6.54° 툭.

## 구동

|---|---|---|---|
| 0 ~ 0.15958 | 0 → 5.767° | B 끝 모서리 → 충격 비탈에 핀 0 | 나아감 30.624° → 42.072° |
| 0.15958 | 5.767° | B 가 핀을 놓음 | 7.315° 툭 → 49.387° |
| 0.15958 ~ 0.5 | 5.767 → 12° | C 앞면(잠금면)에 핀 −1 | C 가 밀어 뒤로 → 47.507° |
| 0.5 ~ 1.0 | 12 → 0° | C 앞면 | 앞으로 따라옴 → 51.554° |
| 1.0 ~ 1.11964 | 0 → −4.405° | C 충격 비탈 | 나아감 → 68.715° |
| 1.11964 | −4.405° | C 가 핀을 놓음 | 6.536° 툭 → 75.251° |
| 1.11964 ~ 1.5 | −4.405 → −12° | B 앞면 모서리에 핀 −1 | 앞으로 끌려감 → 78.038° |
| 1.5 ~ 2 | −12 → 0° | B 앞면 → 끝 모서리 | 뒤로 → 75.624°(= 처음 + 45°) |

## 동작 (`state297(t)` — 결정적, 접촉 계산)
1. n = floor(t/2), τ = t − 2n, ψ = 12·sin(π τ)(도).
2. 팔레트 윤곽의 세 변(위 점 차례의 0→1, 1→2, 2→3)을 P 둘레로 ψ 만큼 돌린다. 핀 k 의 중심은 원(Wc, 0.84) 위, 각 α = 4° + 45°·k + φ.
3. 캡슐 교점: 각 변 ab 마다 (가) ab 를 양쪽 법선으로 0.07 옮긴 두 선분과 원(Wc, 0.84)의 교점, (나) a·b 를 중심으로 한 반지름 0.07 원과 원(Wc, 0.84)의 교점을 구하고, 그 가운데 선분 ab 까지 거리가 0.07(±10⁻⁹)인 점만 남긴다. 각 α 를 기준각 근처(ref ± 180°)로 맞추고, 바퀴가 반시계로 돌므로 **α 가 가장 작은 점**(먼저 닿는 점)을 고른다. φ = α − (4° + 45°·k).
4. 구간: τ < 0.5 → B·k = 0(ref 33°), 교점이 없으면 C·k = −1(ref 10°). 0.5 ≤ τ < 1.5 → C·k = −1, 없으면 B·k = −1(ref 33°). τ ≥ 1.5 → B·k = −1. φ 에 45·n 을 더한다.
5. 기대값(파이썬 검산 — 0.002° 안에서 맞아야 함):
   | t | ψ | φ | 닿은 곳 |
   |---|---|---|---|

   | 0.1 | 3.708 | 37.6796 | B 비탈 |
   | 0.15 | 5.448 | 40.9997 | B 비탈 끝 |

## ★ 난도·질문
난도 **C·상** — 비원형 팔레트 + 핀(원)과 윤곽의 캡슐 교점 계산으로 바퀴 각, 팔이 P 둘레로 도는 좌표 변환, 반투명 앞 부품. GLM 금지, Sonnet.
질문 거리(사용자에게) — 기본값으로 진행:
1. 판화의 점선 팔을 원판 앞을 지나는 반투명 팔(진자)로 읽었다. 기본값: 이 해석, 추 보충.
2. 판화의 곧은 판 B·C 끝에 짧은 충격 비탈을 깎았다(없으면 충격 없이 모서리에서만 놓임). 기본값: 깎음.
3. 팔레트 면이 핀에 대해 비스듬히 움직여 걸린 동안 바퀴가 조금 앞뒤로 움직인다(되튐형). 기본값: 판화대로.
