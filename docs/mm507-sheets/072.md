# 072 틸트 해머
원문: 틸트 해머(까딱 망치) 운동이다. 캠 또는 와이퍼 바퀴 B 가 돌면서 해머 A 를 한 바퀴에 **네 번** 들어 올린다.
(들어 올려진 해머는 날개 끝이 지나가면 제 무게로 떨어져 모루 위의 쇠를 친다.)

## ★ 판화 읽기
판화는 그림 하나(옆에서 본 그림). 확대본 `shots/_verify/072-fig-x4.png`. 아래 픽셀 값은 그 확대본을 0.7배(폭 2576)로 본 좌표.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 가운데 아래의 캠(와이퍼 바퀴) B — 날개 **4개**, 날개 끝 반지름 186, 날개 사이 가장 낮은 곳 115, 축 단면(두 겹 원) 반지름 45.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 빗금 친 바닥(아래 긴 띠)과 오른쪽의 빗금 친 높은 받침. 받침 위 사다리꼴 돋움에 U 자 오목한 자리가 있고 거기에 해머 끝의 **공**이 앉아 있다(해머의 축). 왼쪽의 빗금 없는 네모 = 모루. 모루와 받침 사이, 캠 양옆의 가는 가로선 = 캠 뒤에 있는 낮은 대(캠 축받침 대).
5. 추·손잡이·크랭크는? → 없음. 해머 A: 오른쪽 끝에 아래로 내린 발과 공(축), 왼쪽 끝에 큰 머리(아래에 때리는 면의 덧쇠), 자루 가운데 아래로 **돌기**(끝에 작은 덧쇠)가 내려와 캠 바로 위에 있다. 모루 위에는 벼리는 쇠(왼쪽 끝이 잘린 굽은 막대)가 놓였다.
6. 이는 어디에 났고 무엇이 물리는가? → 캠 날개 4개가 90° 간격. 날개마다 한쪽(시계 쪽)은 볼록하게 굽어 다음 날개의 뿌리까지 내려가는 **등**, 다른 쪽(반시계 쪽)은 거의 반지름 방향의 곧은 **절벽**. 화살표(캠 오른쪽 위, 오른쪽 아래를 향함) = 캠 **시계**. 시계로 돌면 돌기 밑으로 등이 점점 높아지며 지나가(들어 올림) 날개 끝에 이르고, 끝이 지나가면 절벽이라 해머가 떨어진다. 판화의 순간은 **가장 들린 때**: 위쪽 날개 끝이 돌기 끝에 닿아 있고, 해머 머리는 쇠에서 약 70 떠 있다.
7. 한 줄에 놓인 것은? → 돌기 끝이 캠 중심의 거의 바로 위(왼쪽으로 15). 바닥선 위에 모루·캠 대·받침이 나란히.
8. 글자가 가리키는 부품은? → A = 해머(자루 위), B = 캠(와이퍼 바퀴).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 날개 4개 = 원문의 '한 바퀴에 네 번'.
- 그 밖의 선: 해머 오른쪽 끝의 굵은 네모 = 자루 끝에 끼운 발(공이 달린 쇠), 머리 아래의 작은 네모 = 때리는 면의 덧쇠, 캠 축 둘레 두 겹 원 = 축과 허브.

## 해석(결정 사항)
- 해머는 **공(축) 둘레로 까딱인다**. 돌기는 축과 머리 사이에 있다(축에서 1.38, 머리 면은 2.3 ~ 2.8) → 캠이 돌기를 0.108 올리면 머리는 약 0.2 올라간다.
- 판화 자세 = 가장 들린 때. 쉬는 자세는 그보다 **4.5°** 내려앉은 자세(판화의 머리–쇠 틈 70픽셀 = 0.17 은 3.7°; 움직임이 보이도록 조금 키움). 쇠의 윗면(때리는 자리)은 쉬는 자세의 해머 면과 꼭 맞게 만든다(판화에서도 면과 쇠 윗면이 같은 기울기 약 15°).
- 캠의 등은 반지름이 각에 비례해 커지는 나선(뿌리 0.276 → 끝 0.446, 90° 에 걸쳐), 절벽은 반지름 방향. 판화의 등은 조금 더 볼록하지만 들림이 고르게 보이도록 곧은 비례로 했다.
- 떨어짐은 캠 각 14°(0.15 s) 동안 포물선으로(제 무게로 떨어지는 느낌). 그 사이 돌기는 다음 날개의 낮은 등 위에 있어 닿지 않는다(수치 확인).
- 돌기 끝은 반지름 0.03 의 둥근 끝. 판화보다 0.023 길다(가장 들린 때 날개 끝과 꼭 닿게).

## 동작 (theta = 누적 각)
- 캠의 시계방향 각 camDeg(도) = theta(도) − 6.173 (= theta + `tiltPeak().deg` − 91.673 → t = 1 에서 85.5°, 가장 들린 때). `camB.rotation.z = −camDeg`(라디안으로).
- 해머 들림각 λ(rad) = `tiltLift(camDeg)` (주기 90°). `hammerA.rotation.z = −λ`(머리가 왼쪽이라 시계로 돌면 머리가 올라간다).
- 주기 시간표(캠 90° = 0.98 s, camDeg 를 90 으로 접은 값): 9.5° ~ 25.5° **쉼**(머리가 쇠 위, λ = 0) → 25.5° ~ 85.5° **들림**(60°, 0.65 s, λ 가 0 → 4.5° 로 거의 고르게: 30° 0.32°, 45° 1.44°, 60° 2.58°, 75° 3.72°) → 85.5° ~ 99.5°(= 9.5°) **떨어짐**(14°, 0.15 s, 포물선).
- 표 `LIFT72`(0.5° 간격 180칸)는 `solveLift72()` 의 접촉 풀이(돌기 원이 캠 다각형을 뚫지 않는 가장 작은 λ)에 떨어짐을 얹어 구운 것. `node shots/_verify/s071bake.mjs` 가 표 = 풀이인지 확인한다.
- 시각: **t = 1.0 (camDeg 85.5°, λ = 4.5° — 판화 자세: 날개 끝이 돌기에 닿음)**, t = 1.1 (4.7°, λ 2.6° — 떨어지는 중), **t = 1.3 (23°, λ = 0 — 머리가 쇠를 친 채 쉼)**, t = 1.6 (50.5°, λ 1.9° — 다음 날개가 들어 올리는 중).
