# 230 데드 포인트를 피하는 연결봉
원문(en): "Circular motion into ditto. The connecting-rods are so arranged that when one pair of connected links is over the dead point, or at the extremity of its stroke, the other is at right angles; continuous motion is thus insured without a fly-wheel." — 원운동을 원운동으로. 연결봉들은 한 쌍의 이어진 링크가 사점(행정의 끝)에 있을 때 다른 한 쌍이 직각에 있도록 배치되어, 플라이휠 없이도 연속 운동이 보장된다.
쉬운 풀이: 위·아래 두 축을 연결봉 두 쌍으로 잇는다. 한 쌍이 힘을 못 쓰는 자리(사점)에 오면 다른 쌍은 90° 어긋나 있어 가장 잘 돌린다. 그래서 막히지 않고 계속 돈다.
판화 묘사(원본 510×447 px, 왼쪽 앞에서 비스듬히 본 그림): 오른쪽에 큰 원판 둘이 위([298·113])·아래([290·355])로 같은 세로줄에 있다. 원판마다 가운데 작은 구멍(축 끝)과 가장자리 가까이 핀([312·75], [310·325] — 둘 다 원판 위쪽)이 있고, 두 핀을 **앞 연결봉**(세로 막대)이 잇는다. 원판 축은 왼쪽 위(= 뒤)로 길게 나가 끝에 **작은 크랭크 팔**([180·45], [180·285])이 있고, 두 크랭크 핀을 **뒤 연결봉**(왼쪽 세로 막대)이 잇는다. 뒤 크랭크는 왼쪽 위를, 원판 핀은 위를 가리켜 두 쌍의 방향이 다르다(90° 어긋남).

## ★ 판화 읽기
판화는 그림 하나(왼쪽 앞에서 비스듬히). 모델은 축을 앞뒤(z) 방향으로 두고, 판화처럼 **왼쪽 앞**에서 비스듬히 본다(뒤 크랭크가 원판 왼쪽으로 비켜 보이게).
1. 바퀴는 몇 개이고 크기 차례는? → 원판 2개(같은 크기, 반지름 0.42). 뒤 크랭크 팔 2개(핀까지 0.30). 기어·풀리 없음.
2. 줄·벨트는? → 없음. 막대(연결봉) 2개: 앞 연결봉(위 원판 핀 ↔ 아래 원판 핀), 뒤 연결봉(위 뒤 크랭크 핀 ↔ 아래 뒤 크랭크 핀).
3. 교차하는 가닥이 있는가? → 없음. 앞 연결봉은 원판 앞면 앞, 뒤 연결봉은 뒤 크랭크 팔 뒤에 있어 축과 만나지 않는다(축이 두 연결봉 사이 층에서 끝난다).
4. 고정점은? → 판화에는 없음. 보충: 오른쪽 받침 기둥 `column`(받침대 위)에서 나온 팔 둘이 두 축의 베어링 고리를 잡는다(축 가운데 층 z 0.20 — 두 연결봉 층과 떨어짐).
5. 추·손잡이·크랭크는? → 크랭크 4개(원판 핀 2, 뒤 크랭크 2). 원문은 어느 축이 돌리는지 말하지 않음 → **위 축이 일정하게 돌고(구동)** 아래 축이 따라 돈다.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 두 축 중심 O1·O2 가 같은 세로선 x = 0(판화도 원판 둘이 한 세로줄). 앞 연결봉·뒤 연결봉은 늘 세로(평행 사변형 — 축 간 거리 1.50 = 연결봉 길이).
8. 글자가 가리키는 부품은? → 글자 없음(번호 230 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없다. 한 쌍만 있으면 크랭크가 중심선(세로)과 나란할 때 사점에서 반대로 꺾일 수 있지만, 다른 쌍이 90° 어긋나 있어 그때 수평(힘 팔 최대)이다. 질문 거리는 받침 모양(판화에 없음)뿐 — ★ 난도·질문.

## 해석(결정 사항)
- 앞 쌍(원판 핀) 각 φ, 뒤 쌍(뒤 크랭크) 각 ψ = φ + 90°. t = 0 에서 φ = 60°(원판 핀이 위·조금 오른쪽), ψ = 150°(뒤 크랭크가 왼쪽 위) — 판화 자세.
- 연결봉이 세로이므로 힘 팔(축에서 연결봉 선까지 거리) = 반지름 × |cos 각|. 앞 쌍 |cos φ|, 뒤 쌍 |cos ψ| = |sin φ|. 합은 늘 1 이상(최소 1.0, φ = 0°·90°·180°·270°) → 둘이 함께 0 이 되는 때가 없다.
- 사점 표시: 크랭크가 세로(각 90°·270°)에서 ±10° 안(|cos| < 0.17)이면 그 쌍의 연결봉을 빨강으로 바꾼다.
- 판화에 없는 보충: 받침 기둥과 팔, 베어링 고리, 뒤판의 흰 세로 **사점 중심선**, 원판 노란 표지, 회전 화살표.

## 구동
위 축 각 φ(t) = π/3 + 0.7·t [rad] (반시계, t = 0 이 판화 자세 60°). 한 바퀴 8.976 초. 아래 축도 같은 φ(평행 사변형이라 늘 같은 각). 뒤 크랭크 각 ψ(t) = φ(t) + π/2.

## 동작 (모델 `update` 안 — 결정적, t 만으로)
1. φ = π/3 + 0.7·t, ψ = φ + π/2.
2. `shaft1.rotation.z = shaft2.rotation.z = disc1.rotation.z = disc2.rotation.z = φ`, `crankB1.rotation.z = crankB2.rotation.z = ψ`.
3. 앞 핀 세계 좌표: 위 (CR·cos φ, 2.45 + CR·sin φ), 아래 (CR·cos φ, 0.95 + CR·sin φ). `rodF.position.set(CR·cos φ, 1.70 + CR·sin φ, 0.59)`.
4. 뒤 핀: 위 (CR·cos ψ, 2.45 + CR·sin ψ), 아래 (CR·cos ψ, 0.95 + CR·sin ψ). `rodB.position.set(CR·cos ψ, 1.70 + CR·sin ψ, −0.15)`. 두 연결봉 모두 늘 세로(같은 변수에서 위치 계산 — 두 핀 사이 1.50 정확).
5. 사점 색: fF = |cos φ|, fB = |cos ψ|(= |sin φ|). fF < 0.17 이면 `rodF` 의 메시 재질을 빨강 paint(0xd8362f), 아니면 brass. `rodB` 도 fB 로 같게. (재질 두 개를 미리 만들어 두고 바꿔 끼운다 — 매 프레임 새로 만들지 않는다.)
