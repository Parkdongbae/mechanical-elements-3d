# 126 벨 크랭크 레버
원문: "A bell-crank lever, used for changing direction of any force." — 벨 크랭크 레버. 어떤 힘이든 그 방향을 바꾸는 데 쓴다(설명은 이 한 줄뿐).

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/126-fig-x4.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 풀리 1개(왼쪽 위). 판화 치수(px): 축 자리 x 134, y 126. 바깥 원 반지름 72, 안쪽 원 54, 허브 원 24, 축(빗금 원) 15. 살은 그려져 있지 않다(민판). 바깥 원과 안쪽 원 사이의 띠(폭 18) = 줄이 앉는 홈 테.
2. 줄·벨트는? → 빗금 친 굵은 줄 2개(굵기 16px, 같은 무늬). ① **풀리 줄**: 왼쪽 아래의 잘린 끝(x 56 ~ 74, y 285 쯤에서 비스듬히 잘림)에서 곧게 올라가 풀리의 왼쪽에 닿고 → 풀리 **위쪽 반 바퀴**를 넘어 → 오른쪽에서 곧게 내려와(x 191 ~ 207) ㄱ자 레버의 가로 팔 끝 핀(195, 297)에 묶인다. ② **가로 줄**: 레버의 세로 팔 아래 끝 핀(334, 419)에서 오른쪽으로 수평하게 뻗다가 x 445 에서 잘린다(더 이어진다는 뜻).
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 풀리의 축(빗금 원 = 잘린 축 단면, 제자리에서 돎)과 레버의 꺾인 곳 핀(341, 297 — 다른 두 핀보다 큰 세 겹 원 = 고정 받침점). 받침 자체는 그리지 않았다.
5. 추·손잡이·크랭크는? → 없음. 줄 두 개의 끝이 모두 잘려 있어 무엇이 당기고 무엇이 끌려가는지는 판화에 없다. 레버는 ㄱ자(벨 크랭크): 받침점에서 **왼쪽으로 가로 팔**(146px), **아래로 세로 팔**(121px). 두 팔 사이 각은 약 90°(세로 팔이 3° 쯤 왼쪽으로 기울어 그려졌으나 그림 오차로 본다).
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 풀리 줄 ↔ 풀리 홈(감김), 줄 끝 ↔ 레버의 두 끝 핀(묶임), 레버 ↔ 받침점 핀(회전).
7. 한 줄에 놓인 것은? → 풀리 오른쪽 가닥(줄 중심 x 198)과 가로 팔 끝 핀(x 195)이 같은 세로선 → 오른쪽 가닥은 수직. 가로 팔 끝 핀과 받침점이 같은 높이(y 297) → 가로 팔은 수평. 세로 팔 끝 핀과 가로 줄이 같은 높이(y 419) → 가로 줄은 수평.
8. 글자가 가리키는 부품은? → 글자 없음(번호 126 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳은 없다. 다만 줄은 당기는 힘만 전하므로, 되풀이해 움직이려면 가로 줄 끝에 되돌려 주는 것이 있어야 한다(판화에서는 잘려 있음) → 모형은 가로 줄 끝에 되돌림 스프링을 단다(판화에 없음). 기구 해석에는 영향이 없어 질문 거리는 아니다. 문제 없음.
- 그 밖의 선: 레버 두 팔은 가운데가 살짝 잘록한 납작 막대, 끝마다 둥근 눈(두 겹 원 = 핀과 눈). 줄의 빗금 = 꼰 줄 무늬.

## 해석(결정 사항)
- 기구: 손이 풀리 줄의 왼쪽 끝을 **아래로** 당기면 풀리를 넘은 줄이 가로 팔 끝을 **위로** 끌어올리고, ㄱ자 레버가 받침점을 중심으로 시계 방향으로 돌아 세로 팔 끝이 **왼쪽으로** 가며 가로 줄을 수평으로 끌어당긴다. 세로로 당긴 힘이 가로로 바뀐다(풀리에서 한 번, 레버에서 한 번). 초인종 줄을 모퉁이에서 꺾던 장치.
- 판화 px × 0.00625 로 옮겼다(줄 중심 반지름 64px → 0.40, 가로 팔 146px → 0.91, 세로 팔 121px → 0.76). 판화의 순간(가로 팔 수평)을 t = 1 로 맞춘다.
- 줄은 둥근 로프 + 홈 풀리 짝으로 만든다(판화의 줄 굵기 16px ÷ 줄 중심 반지름 64px = 키트 로프 반지름 0.045 ÷ 0.40 과 거의 같다).
- 판화에 없는 보충(최소): 왼쪽 줄 끝의 손잡이 매듭, 가로 줄 끝의 되돌림 스프링과 고정 못, 풀리 축·받침점 핀의 뒤판 받침, 공통 받침대.

## 구동
손(왼쪽 줄 끝)이 당겼다 놓는 왕복. theta += OMEGA(1.6)·speed·dt. 레버 각 phi = −15°·sin(theta − 1.6) — 한 번 왕복 3.93 s. (모형에서는 레버 각을 theta 의 식으로 주고 줄 끝·풀리·스프링이 따라가게 계산한다.)

## 부품과 치수 (새 부품은 모두 `kit/k125.ts`, 이미 구현됨. 치수 상수 `K126`)
배치 상수(모두 `K126` 에 있음): 풀리 축 CX = −1.125, CY = 2.45 / 받침점 PX = 0.185, PY = 1.39 / 스프링 고정 못 SX = 1.52, SY = 0.63 / 층 ZP = 0.1(풀리·줄·스프링), ZL = −0.02(레버 판).
- 풀리(name `pulley`): `pulley(K126.r, { width: 0.16, spokes: 0 })` — r 0.39 의 기본 로프 홈 림(줄 중심 반지름 0.40, 플랜지 반지름 0.43), 민판. 위치 (−1.125, 2.45), 층 ZP.
- 풀리 축: `shaftZ(−1.125, 2.45, 0.22, 0.06)` — 뒤판 보스에서 나와 허브를 꿴다(판화의 빗금 원. 받침은 판화에 없음).
- 풀리 줄(name `rope`): `new Rope(ROPE_R)`(반지름 0.045), 경로는 `ropeAround` 로만(아래 줄·벨트 표).
- 손잡이(name `handle`, 판화에 없음 — 잘린 끝의 마감): `ropeEnd()` 를 풀리 줄의 왼쪽 끝점 (−1.525, yL) 층 ZP 에. yL 은 1.235 ~ 1.706.
- 벨 크랭크(name `crank`): `bellCrank126()` — 가로 팔 0.91(−X), 세로 팔 0.76(−Y), 판 두께 0.06, 받침 구멍 반지름 0.042. 위치 (0.185, 1.39), 층 ZL. 두 팔 끝의 핀이 앞으로 솟아 줄 층까지 가고 핀마다 줄 고리가 걸려 있다. 핀 표식 child `pinA`(가로 팔 끝), `pinB`(세로 팔 끝) — 줄 끝이 붙는 자리. 주철.
- 받침점 핀(고정): `shaftZ(0.185, 1.39, 0.075, 0.04)` — 뒤판 보스에서 나와 레버의 받침 구멍을 꿰고 끝 너트(z 0.039 ~ 0.075)가 레버 허브 앞(z 0.02)에 온다(받침은 판화에 없음).
- 가로 줄(name `cord`): `new Rope(0.03)`, 길이 0.6. 경로는 `ropeAround` 로(감는 바퀴 없음 — 두 끝점만).
- 되돌림 스프링(name `spring`, 판화에 없음): `pullSpring126(0.735)` — 원점(고정 고리)을 고정 못 (1.52, 0.63) 층 ZP 에 두고 +X 를 가로 줄 쪽으로 돌린다. 줄이 묶이는 고리 표식 child `springEye`. 길이 0.539 ~ 0.932.
- 스프링 고정 못(판화에 없음): `shaftZ(1.52, 0.63, 0.16, 0.028)` — 뒤판 보스에서 나온 못, 스프링의 고정 고리가 걸린다.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위 −1.56 ~ 1.59, 세로 0.57 ~ 2.88.

## 동작 (모두 theta 의 닫힌 식 — `bell126(theta)` 가 돌려준다)
- 레버 각 phi = −15°·sin(theta − 1.6) (반시계 +). `crank.rotation.z = phi`. phi < 0 이면 손이 당긴 상태.
- 핀 A = (PX − 0.91·cos phi, PY − 0.91·sin phi), 핀 B = (PX + 0.76·sin phi, PY − 0.76·cos phi). A 의 높이 1.154 ~ 1.626, B 의 가로 −0.012 ~ 0.382.
- 풀리 줄: 길이가 일정(3.2966). 오른쪽 접점의 각 at = ∠(A − 풀리 중심) + acos(0.40/거리), 감긴 각 = 180° − at. 왼쪽 끝 높이 yL = CY − (줄 길이 − 0.40·감긴 각 − 오른쪽 직선 가닥 길이). `pose.yL`.
- 풀리: 줄이 미끄러지지 않으므로 `pulley.rotation.z = pose.pulley = (1.47 − yL)/0.40` — 손이 내려가면 반시계. 범위 ±33.7°.
- 가로 줄과 스프링: 핀 B 에서 고정 못 S 쪽으로 곧게. 줄의 스프링 쪽 끝 H = `pose.H`(S 에서 B 쪽으로 스프링 길이만큼), `spring.rotation.z = pose.springAngle`(178.7° ~ 180°), `setSpring126(spring, pose.springLen)`.
- 시각: **t = 1.0 (theta 1.6, phi 0 — 판화 자세: 가로 팔 수평, 손잡이 높이 1.470, 스프링 0.735)**, **t = 1.6 (theta 2.56, phi −12.3° — 손이 0.193 당긴 상태: A 가 0.194 올라가고 B 가 0.162 왼쪽으로, 풀리 +27.7°, 스프링 0.897)**.

## 표시
- rotArrow 2개를 받침점 (0.185, 1.39) z = 0.2 에 겹쳐 두고 **지금 도는 방향 것만 보이게** 한다: `rotArrow(0.2, false)`(시계)와 `rotArrow(0.2, true)`(반시계). d(phi)/dt 의 부호 = −cos(theta − 1.6)·speed 의 부호 → 음수면 시계 것, 양수면 반시계 것을 visible. (반지름 0.2 라 팔의 뿌리만 덮는다.)

## notes

## ★ 깊이 계산
모두 뒤판과 나란한 층이고 깊이로 지름이 나오는 부품은 없다(스프링 코일만 반지름 0.05 가 깊이로 나온다: ZC 0.1, 최대 반지름 0.061 → z 0.039 ~ 0.161). 레버 판 z −0.06 ~ 0.02, 레버 끝 핀 z 0.005 ~ 0.17, 받침점 핀 너트 z ≤ 0.075, 풀리 z 0.02 ~ 0.18(허브 0 ~ 0.2), 풀리 축 끝 z 0.22, 줄 z 0.055 ~ 0.145, 줄 고리 z 0.07 ~ 0.13. 가장 앞 0.22 → −0.25 ~ 0.8 안.
높이: 흔들리는 가로 팔 끝의 최고 = 핀 A 1.626 + 눈 0.062 = 1.69(풀리 아래 2.02 보다 낮다 — 닿지 않음). 가장 높은 곳 = 풀리 플랜지 2.45 + 0.43 = 2.88. 가장 낮은 곳 = 세로 팔 끝 0.63 − 0.062 = 0.568, 스프링 0.63 − 0.061 = 0.569(받침대 윗면 0.18 위). 손잡이 공의 최저 = 1.235 − 0.105 = 1.13. 가로 = 풀리 왼쪽 −1.555 ~ 고정 못 보스 1.59.
