## 동작 (식) — 모든 값은 U 의 함수, 증분 누적 금지
상수: D = π/180, `αt = 6°` (캠이 레버를 가장 높이 들어 올리는 각 = 도약 시작 각, 판화 순간 α = 0 은 그 6° 앞), `J = 110°` (도약 각), `Δs = 0.4 rad` (도약에 걸리는 휠 각), `N = 24`.
- 한 주기(휠 1바퀴, u: 0 → 2π)의 시간표:
  1. **도약** `0 ≤ u < Δs(0.4)`: 캠 α = αt + 2π·n + J·smoothstep(u/Δs). 휠은 계속 돈다(φ = αt + U). 이때 핀은 홈 안에서 휠과 함께 앞서가는 캠에 뒤처져 홈의 뒤쪽 끝으로 간다.
  2. **멈춤(핀이 따라잡는 중)** `Δs ≤ u < J(1.92)`: α = αt + 2π·n + J (고정). 핀(휠)은 계속 돈다.
  3. **밀기** `J ≤ u < 2π`: α = αt + 2π·n + u. 핀이 홈의 앞쪽 끝(선두 벽)을 밀어 캠을 휠과 같은 속도로 돌린다(φ − α = −αt 동안). 달팽이 나선이 레버 고리를 점점 들어 올린다.
  - 연속성: u = J 에서 α = αt + 2πn + J 양쪽 같음, u = 2π 에서 α = αt + 2π(n+1) = 다음 주기 도약 시작각 같음.
  - 따라서 한 주기 동안 캠 = 도약 110° + 밀기 250° = 360°, 휠 = 360°(멈춤+도약 중에도 휠은 돎). 평균 캠 속도 = 휠 속도.
- 휠: `wheel.rotation.z = φ = αt + U` (반시계). 핀 손가락: `finger.rotation.z = φ + 82°`.
  - 홈 검사(식): 손가락의 캠 기준 각 pc = (φ + 82°) − α. 밀기 중 pc = 82°(홈 선두 벽 90° 에 닿음). 도약 직후 pc = 82° − (J − Δs·(휠 진행)) ≈ −5° (홈 안). 홈 범위(−90°~90°)를 벗어나지 않는다.
- 캠 `camGroup.rotation.z = α`, 그룹 z = 0.26, 허브 H. 속 빈 축 조각은 캠 그룹 안에서 함께 돈다.
- 웜: `worm.rotation.x = −N·φ` (mod 2π 하면 됨). 근거(31번과 같은 방법): 오른나사 웜의 나사산 중심은 +Y 쪽 단면에서 x = −p·w/2π (mod p), 휠 맨 아래 이 중심은 x = rp(φ + π/N + π/2) (반시계 휠의 맨 아래는 +X 로 움직임), 이가 나사산 사이 골에 들어가려면 반 피치 어긋나야 하므로 N·φ + N·π/2 ≡ −w (mod 2π), N = 24 에서 N·π/2 = 12π ≡ 0 → **w = −24·φ**(잇수는 4 의 배수여야 이 식이 성립). 웜 중심 x 는 휠 중심 x(0.92) 와 같아야 하고 웜 z = 휠 폭 가운데 z = 0.00.
- 레버: `lever.position = PL = (−1.70, 2.72)`, `lever.rotation.z = γ(α)`. γ 는 **고리가 캠 위에 얹히는 가장 큰 높이를 주는 최소 각**: 고리 중심 C(γ) = PL + 2.87·(cos γ, sin γ), 캠 윤곽을 허브 둘레로 α 만큼 돌린 다각형까지의 부호 거리(`polyDepth`)가 고리 반지름 0.115 이상이 되는 가장 큰 γ(γ 를 0.02 에서 −0.4 로 0.0005 씩 내려 가며 처음 만족하는 값). 매 프레임 풀면 느리므로 시작할 때 α ∈ [0°, 360°) 0.5° 간격 표를 만들고 보간한다(캠 α 는 mod 2π).
  - γ 표(α도 : γ도): −260:−10.20, −180:−11.66, −120:−9.94, −60:−6.07, −30:−2.72, 0:−0.03, **6:+0.34(최대)**, 12:−0.03, 18:−3.15, 24:−6.25, 36:−9.25, 60:−11.14, 110:−10.17. 총 진동 폭 약 12° (0.21 rad). 캠 완전 도약 중 γ 의 최대 변화는 smoothstep 1% 걸음당 0.8°.
- 잎스프링 끝점 `E = PL + Rot(γ)·(1.35, 0.075)`, 매 프레임 `leaf.set(P0, (1,0,0), E, normalize(0.25, −0.97, 0))` (γ 가 바뀔 때만 다시 만들어도 됨). 레버가 내려가면 끝점이 약 0.27 내려가며 잎이 더 펴진다.
- 속도비: 웜 24 : 휠 1 (웜이 24바퀴 도는 동안 휠 1바퀴), 휠 1바퀴에 캠 도약 1번(110°) + 멈춤 110° + 밀기 250°·(휠과 같이).

## 의문점·단순화 (정직하게)
- 웜 휠의 `tanLead` 부호(오른나사 웜 → −tan(리드각) = −0.2083)와 웜이 휠 **아래** 에 있을 때의 위상식은 31번의 (웜이 위) 도출을 뒤집어 적용했다. 근접 캡처로 이가 나사산 옆구리를 파고들지 않는지 반드시 눈으로 확인할 것(안 맞으면 부호나 위상 N·π/2 항부터 의심).
- 캠이 "떨어지는" 힘(스프링 눌림 방향 반전)은 힘 계산 없이 시간표(도약 110°, 0.4 rad)로 표현했다. 도약이 끝나는 자리는 고리가 곧은 변을 다 내려와 둥근 변에 얹히는 각에서 정했다. 홈(반쯤 잘린 속 빈 축)은 홈 폭 180° 로 판화·원문대로 그렸고, 핀은 도약 중 홈 안에서 뒤쪽으로 상대 이동만 하며 벽에 부딪히지 않는다.
- 판화의 아래 직사각형 받침틀은 단순한 벽 블록 두 개로 대신했다. 캠 아랫부분이 판화에서는 웜 휠 이를 일부 가리는데, 모델에서는 캠이 휠 앞 z 층에 있어 같은 모양으로 겹쳐 보인다.
