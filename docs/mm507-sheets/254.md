# 254 체인 스프로킷
원문(en): "A sprocket-wheel to drive or to be driven by a chain." — 체인으로 구동하거나 체인에 의해 구동되는 스프로킷 휠.
쉬운 풀이: 테두리 가운데에 Y자 모양 이(갈래 이)가 한 줄로 솟은 바퀴이다. 체인의 눕는 고리가 Y자 이의 두 갈래 사이에 얹히고, 선 고리가 이와 이 사이를 건너간다. 아래 작은 스프로킷이 돌면 체인이 따라 움직여 위 스프로킷을 돌린다.
판화 묘사(원본 505×452 px, 축이 화면 좌우로 누운 **옆 모습**): 가운데 세로로 선 넓은 테(x 180–268, 폭 ≈ 88 px, 위 y ≈ 45, 아래 y ≈ 395 → 반지름 ≈ 175 px). 테 앞면 가운데 세로줄(x ≈ 224)에 **Y자 무늬 5개**(위 둘은 Y, 가운데 위는 납작한 V, 아래 둘은 거꾸로 된 ⅄) — 테 맨 위(y 10–40)와 맨 아래(y 400–425)에서는 **Y 가 테 밖으로 솟아** 보인다(위는 줄기가 아래·갈래가 위, 아래는 반대) = 지름 방향으로 선 줄기 끝이 두 갈래로 벌어진 **갈래 이**를 옆에서 본 모습, 앞면의 Y 들은 같은 이를 비스듬히 본 것. 갈래는 축 방향(화면 좌우)으로 벌어짐. 양옆 짧은 네모(x 162–180, 268–285, 반지름 ≈ 50 px) = 허브, 바깥 둥근 축(반지름 ≈ 25 px). 체인·다른 바퀴는 없음.

## ★ 판화 읽기
판화는 그림 하나(옆 모습). 판화 1 px ≈ 0.0025(테 반지름 175 px = 0.44).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 스프로킷 1개. 보충: 작은 구동 스프로킷 1개(아래). 크기 차례: 큰 스프로킷(테 0.44, 이 14개, 마디 원 0.535) > 구동 스프로킷(테 0.14, 이 6개, 마디 원 0.229).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에는 없음. 보충: 고리 체인 1개(닫힌 고리, 고리 42개 — 눕는 고리 21·선 고리 21 번갈아). 큰 스프로킷 위쪽을 반시계로 감고 왼쪽 가닥으로 내려와 구동 스프로킷 아래를 감고 오른쪽 가닥으로 올라간다.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 두 축 모두 뒤판 보스에서 나온 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 아래 구동 스프로킷 축이 일정하게 돈다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 테 **바깥** 가운데 한 줄에 Y자 갈래 이(큰 14, 작은 6). 눕는 고리(고리 면이 진행 방향·축 방향을 품음)의 두 옆 철사가 갈래 두 팔 안쪽에 얹히고, 선 고리(고리 면이 바퀴 평면)는 이와 이 사이를 테 위로 건너간다.
7. 한 줄에 놓인 것은? → 두 스프로킷 중심이 x = 0(y 2.12 / 0.83655). 체인·이·테 가운데가 모두 깊이 0.10.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 254 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 원문은 체인 종류를 말하지 않고 판화는 바퀴만 그렸다. 판화의 Y 를 **지름 방향 줄기 + 축 방향으로 벌어진 두 갈래**의 이로 읽고, 거기에 맞는 **보통 고리 체인(눕는 고리·선 고리 번갈아)**을 둔다(★질문 거리 1). 이 수(14)는 판화로는 알 수 없어 체인 마디에서 정함(질문 2). 판화는 옆 모습이고 모델은 축을 깊이(Z)로 두어 45° 시점(질문 3). 이 해석으로 한 바퀴 내내 체인 마디가 이 자리에 맞음을 계산으로 확인(이 각 오차 0.04° 이하).

## 해석(결정 사항)
- 체인: 고리 42개, 마디(이웃 고리가 맞닿는 점) 간격 p = 0.12. 고리 하나 = 둥근 철사(반지름 0.016) 경기장꼴 고리 — 중심선 반길이 0.076(곧은 부분 ±0.04 + 끝 반원 반지름 0.036), 중심선 반폭 0.036(안쪽 구멍 폭 0.04, 바깥 폭 0.104). 짝수 고리 = **눕는 고리**(고리 면 = 진행 방향 × 세계 Z), 홀수 고리 = **선 고리**(고리 면 = XY 평면). 두 고리는 마디에서 철사끼리 맞닿아 서로 꿰인다.
- 체인 경로는 키트 `beltPathAround` 로 만든 닫힌 선(마디 원 반지름 큰 0.53476 = 0.12·28/2π, 작은 0.22918 = 0.12·12/2π, 중심 거리 1.28345 → 길이 42·0.12 = 5.04). 마디는 이 선 위 호장 간격 0.12 의 점, 고리는 이웃 두 마디의 가운데에 마디 방향으로 놓는다(바퀴 위에서는 다각형으로 감김).
- 스프로킷 = 테·웹(회전 대칭, **세계에 고정** — 돌아도 같은 모습이라 지시선이 흔들리지 않게) + 도는 부분(허브 + Y자 이). 이는 테에 0.01 묻혀 테와 붙어 보인다.
- 열린 걸이라 두 스프로킷 같은 방향(반시계), 속도비 = 이 수 비 6/14.

## 구동
구동 스프로킷 φ2(t) = 1.0·t [rad], 정면 반시계. 체인 흐름 s = 0.22918·φ2. 큰 스프로킷 φ1 = s / 0.53476 = 0.42857·φ2(= 6/14).

## 동작 (`state254(t)` — 결정적)
1. φ2 = 1.0·t. `driveShaft`·`driveSprocket` 의 `rotation.z = φ2`.
2. φ1 = 0.42857·φ2. `bigShaft`·`bigSprocket` 의 `rotation.z = φ1`. `bigRim`·`driveRim` 은 그대로.
3. s = 0.22918·φ2. 마디 = `chainJoints254(s)`, 체인 메시 갱신.
4. 맞물림 검산(계산): 눕는 고리(짝수) 가운데가 바퀴 위에 있을 때 그 각 = 이 각 + φ(큰 a0 20.2025° + j·25.714°, 작은 17.1391° + j·60°), 반지름 = 마디 원 가운데 반지름(큰 0.53140, 작은 0.22137). t = 0, 1, 1.6, 7.3, 30 에서 각 오차 ≤ 0.04°, 반지름 오차 ≤ 0.0006.
5. 고리 ↔ 이 검산: 눕는 고리 옆 철사 중심 (r 0.53140, a ±0.036)에서 갈래 중심선까지 0.024 = 철사 0.016 + 갈래 반두께 0.008(맞닿음), 접점 (0.5106, ±0.048). 선 고리 아래 철사 밑 = 0.53140 − 0.052 = 0.4794 > 테 0.44(틈 0.039), 작은 쪽 0.1694 > 0.14(0.029). 선 고리 끝은 이 가운데서 둘레 방향 0.044 이상 떨어져 이(반두께 0.015)에 닿지 않음. 바퀴 위 마디 사이 직선 길이 0.1186 ~ 0.12(작은 바퀴에서 고리끼리 0.0014 겹침 — 보이지 않음).
6. 감긴 각: 큰 207.55°(위쪽, 각 −13.77° → 193.77°), 작은 152.45°(아래쪽). 접선 끝점: 큰 (±0.5194, 1.9927) ↔ 작은 (±0.2226, 0.7820).

## ★ 눈에 보여야 할 동작
- 핵심: 구동 스프로킷이 돌면 체인이 흘러 **큰 스프로킷이 같은 방향으로 6/14 배** 돈다. 바퀴 위에서 **눕는 고리가 Y자 이 갈래에 하나씩 얹혀 이와 함께 돌고, 선 고리가 이 사이를 건너가며**, 바퀴를 떠나는 자리에서 고리가 이에서 빠져 곧은 가닥이 된다.
- 장치: 밝은 강철 체인과 청동 이·황동 테의 색 차이, 구동 스프로킷 앞 화살표.
- 수치: 구동 1.00 rad/s, 큰 스프로킷 0.429 rad/s, 체인 속도 0.229 /s.

## ★ 난도·질문
난도 **A**(하) — 다만 여섯 가운데 가장 손이 많다: 고리 42개 배치(경로 함수 + 호장 보간 + 행렬, 식 모두 주어짐)와 한 메시로 합치기. 새 기하는 상자·관·TubeGeometry 뿐. GLM 가능(실패하면 Sonnet).
질문 거리(사용자에게) — 기본값으로 진행:
1. 판화의 Y 무늬 = 지름 방향 줄기에 축 방향 두 갈래가 난 이로 읽고, 보통 고리 체인(눕는 고리는 갈래에, 선 고리는 이 사이)을 걸었다. 다른 체인(예: 갈고리 체인·판 체인)을 뜻했는지.
2. 이 수: 판화로는 알 수 없어 큰 14·작은 6(마디 0.12)으로 정함.
3. 판화는 옆 모습. 기본값: 축을 깊이 방향으로 두고 45° 시점.
