# 035 슬롯 막대 달린 타원 기어
판화: 타원 기어(가로로 긴 타원)의 축에 끼운 긴 막대가 왼쪽 위로 뻗고, 막대의 홈 안에 작은 피니언 축이 있어 피니언이 타원 기어 위쪽 이에 맞물린다. 막대에 스프링.
구동: 피니언을 일정 속도로 돌린다. 타원 기어는 반대로 돌며 속도가 변한다.

## 부품과 치수
`ellipsePitch`·`ellipticalGear`·`pinionOnEllipse`·`coilSpring`(키트 추가), `spurGear`, `shaftZ`, `rotArrow`, `tag`.
- 타원: a = 0.85, e = 0.55, 잇수 44(피치 0.1116). 축(초점) = 막대 축 = (0.35, 1.75), z = 0.10, 폭 0.12.
- 피니언: `spurGear(12, 0.0355, …)`, 피치 반지름 rp = 12P/2π = 0.213, 같은 높이 z = 0.10.
- 막대: 길이 1.85, 방향 135°(고정), z = 0.215, 두께 0.04, 홈 0.45~1.62. 슬라이더(피니언 축)와 앞 플랜지, 끝 받침, 스프링(길이는 scale.x).
- 막대는 판 앞(z 0.195~0.235)이라 피니언은 막대 뒤에서 홈 양옆으로 이가 보인다.

## 동작 (판화에 막대 움직임 정보가 없어 가정: 막대 각은 고정, 피니언은 홈 위에서 반지름만 변함)
- 피니언 자세 x = x₀ + 2.4·t (일정 속도, 절대값).
- 굴림: 접점의 초점 극각 φ, 피니언 중심 = 피치 곡선 + rp·바깥법선. 타원 기준 피니언 자세 ψrel = S(φ)/rp + ϑ(φ) + π/2 (ϑ = 접선각, S = 호 길이), 세계 자세 ψ = ψrel + θe. 위 π/2 는 이 위상(spurGear 이 중심 (j+½)).
- 막대각 고정 ⇒ 피니언 중심의 타원 좌표 방향각 A(φ) 에 대해 θe = β − A(φ). ψ = x 를 φ 에 대해 풀어(표 + 이분법, 한 주기 = L/rp) 접점 φ, θe, 피니언 중심 거리 ρ 를 얻는다. 타원 각속도 ∝ 1/(ds/dφ) 로 주기적으로 변한다(대략 0.4~1.3 rad/s). 타원은 피니언 반대 방향(시계).
- 스프링: 슬라이더 바깥 면 ~ 끝 받침, 길이 = 1.67 − ρ.

## 표시
rotArrow 피니언 반시계, 타원 시계. tag '타원 기어', '홈 막대', '피니언(일정 속도)'. notes: 잇수, 피니언 속도 일정, 타원 각속도 실시간.

## 확인
- 두 시점에서 막대는 그대로이고, 타원 기어가 시계로 돌며(표시선 약 40° 이동) 피니언 위치(막대 위 ρ)가 바뀐다. 스프링 길이가 변한다.
- 피니언과 타원 이가 박히지 않는다(12초 분량을 훑어 윤곽 겹침 0 확인). 비스듬한 시점 `cam=0.5,2.9,1.0,-0.2,2.4,0.1`.
- 타원 반지름 최대 1.32 + 이 높이 → 초점 (0.35, 1.75) 기준으로 뒤판 안.

## 검증 수정 (Fable)
- 판화의 막대 축은 타원 **한가운데**다 → `centreEllipsePitch(a = 1.0, b = 0.61)`, 잇수 38, 피니언 12(rp = 0.258), 축 (0.15, 1.6). 처음 자세는 판화처럼 타원 긴 축이 가로(θe = 0 이 되는 접점을 이분법으로).
- 피니언 축 위치 ρ = 0.87 ~ 1.26, 막대 길이 1.5, 홈 0.42 ~ 1.4. 타원 각속도는 한 바퀴에 두 번 변한다(약 0.62 ~ 1.02 rad/s).
- 스프링은 판화처럼 피니언 축받이와 막대 축 사이(당기는 스프링): 고정 핀(0.5) ~ 슬라이더 걸이(ρ − 0.07).
- 이 반폭 0.22P 로 한 주기 훑어 윤곽 겹침 0.
