# 153 스터드로 미는 왕복 장치
원문: "Circular motion into alternating rectilinear motion. The studs on the rotating disk strike the projection on the under side of the horizontal bar, moving it one direction. The return motion is given by means of the bell-crank or elbow-lever, one arm of which is operated upon by the next stud, and the other strikes the stud on the front of the horizontal bar." — 도는 원판의 스터드가 가로막대 아랫면의 돌출부를 쳐서 막대를 한쪽으로 민다. 돌아오는 길목에는 벨 크랭크(꺾인 지레)가 서 있어, 다음 스터드가 그 한 팔을 밀면 다른 팔이 막대 앞면의 스터드를 쳐서 막대를 되보낸다.
판화 묘사: 위에 가로막대가 프레임 왼편부터 오른편까지 길게 걸려 있다(두 끝에 빗금 = 프레임 단면). 막대 왼쪽 얼굴에 작은 스터드 원 하나, 가운데쯤 아랫면에서 직사각형 돌출부가 내려와 오른쪽의 큰 원판 위에 얹혀 있다. 원판은 민판이고 가운데에 겹원 허브, 거의 한 세로선 위아래로 스터드 원 둘이 박혀 있다. 왼쪽 아래에는 겹원 받침점에 꺾인 지레(벨 크랭크)가 있어 윗팔은 막대 밑면까지, 아래팔은 원판의 왼아래 테까지 닿는다. 막대 양 끝 아래에는 눈 달린 고정 링 둘이 있다.

## ★ 판화 읽기
판화는 그림 하나(정면, 450×450 px). 원본과 확대 관찰·측정으로 다시 읽었고(아래 px 는 450×450 원본 기준), 세계치는 1 px = 0.0092 로 환산한 값이다.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 줄·기어로 쓰는 바퀴는 없음. 도는 원판 1개(중심 [257·272], 반지름 96, 허브 겹원 바깥 27·안 11)뿐이고 나머지는 막대·돌출부·벨 크랭크·고정 링이다. 스터드 둘은 원판 위 반지름 82 원 위에 거의 한 세로선([238·193]과 [262·355])으로 박혀 있어 지름 양 끝(180°)으로 본다.
2. 줄·벨트는? → 없음. 맞물림은 스터드 원 ↔ 돌출부 옆면, 스터드 원 ↔ 벨 크랭크 아래팔 끝, 벨 크랭크 윗팔 끝 ↔ 막대 앞 스터드, 이렇게 셋이다.
3. 교차하는 가닥이 있는가? → 줄 가닥은 없음. 겹침 차례: 돌출부가 원판 테 앞에 있다(원판 테 선이 돌출부 폭만큼 끊긴다). 벨 크랭크 팔은 막대와 원판 테 앞에 있다(막대 아랫변과 테가 팔에서 끊긴다). 아래팔 끝은 원판 테 선 위에 얹혀 보인다.
4. 고정점은? → 막대 양 끝 아래의 눈 달린 링 둘([43·177], [414·176], 바깥 반지름 17 — 고정 봉의 눈)과 벨 크랭크의 받침점([88·264], 겹원 = 고정 핀), 원판의 축(허브 겹원). 막대 두 끝의 빗금은 프레임 단면이지 막대가 아니다(원문상 막대는 왕복한다).
5. 추·손잡이·크랭크는? → 없음. 구동은 원판 자체(원문 "The studs on the rotating disk").
6. 기어는? → 없음. 스터드(원)와 돌출부·팔 끝의 맞물림이 전부다. 스터드는 원판 앞면에서 앞으로 돌출한 핀이므로 돌출부·팔 끝과 같은 평면에서 민다.
7. 한 줄에 놓인 것은? → 원판 허브와 스터드 둘이 거의 한 세로선([238]·[257]·[262]). 막대 앞 스터드 [75·141]과 윗팔 끝 [164·148]이 같은 높이(막대 밑면 부근). 안내 링 둘이 같은 높이 [177·176].
8. 글자가 가리키는 부품은? → 글자 없음(번호 153 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳은? → 구성은 원문과 같음. 다만 두 가지 보충·보정이 필요하다: ① 막대가 떠 있으니 양 끝 아래 링은 고정 안내 봉의 눈으로 만들고 막대에 러그 구멍을 뚫는다(링이 막대와 닿지 않는 것은 도면상 생략일 뿐, 봉이 구멍을 꿰어야 막대가 받쳐진다) ② 수동으로 흔들리는 지레는 스터드가 지나쳐도 제자리에 돌아와야 다음 스트로크가 같아지므로, 모형은 지레가 쉼 구간에 정해진 식으로 돌아오게 한다(θ 의 닫힌 식 — 5절 참고). 이것은 판화로는 알 수 없는 자리라 ★질문 거리로 남긴다.
- 그 밖의 선: 막대 위 얼굴의 작은 원 [75·141] = 막대 앞면의 스터드(지게차 머리 없는 민핀). 원판 안의 두 작은 원 = 원판에 박힌 스터드(테 안쪽, 닿는 반지름 82). 아래팔 끝의 평평한 끝막음 = 스터드를 받는 패드. 윗팔 끝도 평평하게 끊긴다.

## 해석(결정 사항)
- 기구: 스터드 원판(구동, 시계) + 가로막대(돌출부·앞 스터드·러그가 한 몸, X 왕복) + 벨 크랭크(고정 꼭지 핀, 스터드에 밀려 흔들린 뒤 막대가 돌아올 때 제자리로 돌아옴) + 안내 봉(고정).
- 스트로크가 두 번 일어난다: 스터드 A 가 돌출부를 밀면(원판 위) 막대가 오른쪽으로, 180° 뒤 스터드 B 가 아래팔을 쳐서 윗팔이 앞 스터드를 밀면 왼쪽으로 — 원판 한 바퀴에 막대가 두 번 왕복한다.
- 회전 방향: 판화 순간(A 가 돌출부 왼편에 접촉 시작, B 가 아래 왼쪽에서 접근)은 "A 가 시계로 돌아 돌출부 왼면을 미는 자리"와 정확히 맞는다(접선 검산: 돌출부 왼면 = 스터드 중심 + 반지름, 오차 1 px). 그래서 원판은 시계(위에서 반시계가 아닌, 화면 기준 시계).
- 판화 비를 그대로: 원판 반지름 96 : 스터드 자리 82 : 막대 두께 36 : 축 사이(꼭지 핀→원판 중심) 169 : 윗팔 140 : 아래팔 125. 세계로 1 px = 0.0092 로 옮긴 뒤 반올림(원판 0.88, 스터드 자리 0.75, 막대 두께 0.28, 꼭지 핀 (−1.53, 1.71), 윗팔 1.28, 아래팔 1.08).
- 막대 길이는 전시 폭이 정한다: 왕복 ±0.30 을 내려면 반길이 1.86 이 한계(끝 ±2.16 ≤ 2.2). 판화는 프레임만큼 길게 그렸으나 모형은 여기서 끊는다.
- 돌출부 밑변 y = 2.41 로 정한 것: 밀기 스트로크 0.564 를 내는 감긴 각(±22.1°)이 나오는 깊이. 판화의 돌출부(밑변 2.25)는 스트로크 1.06 이 나와 전시 폭을 넘기므로 0.16 얕게 했다.
- 아래팔 끝을 판화(평평한 끝, 폭 14 px)보다 굴린 원 패드(반지름 0.22)로 한 것: 스터드가 패드를 미끄러지며 지나가는 동안 접촉이 유지되어 닫힌 식으로 풀리기 때문. 끝막음 모양만 다르고 팔 길이·방향은 판화 비를 따른다.
- 벨 크랭크의 귀환은 판화에 그림이 없다(스터드가 지나간 뒤 지레를 제자리로 돌릴 힘이 판화에는 없다). 모형은 쉼 구간에 정해진 식으로 돌려놓는다(중력·스톱 이야기 대신 운동식으로 약속). ★질문 거리.

## 구동
스터드 원판(시계): theta += OMEGA(1.6)·speed·dt, 원판 rotation.z = φ0 − theta(φ0 = 195.17°, t = 1 에 판화 자세). 한 주기 = theta 2π(3.93 s) = 막대 두 왕복. 모든 자세는 `bell153(theta)` 의 닫힌 식.

## 동작 (모두 theta 의 닫힌 식 — `bell153(theta)` 가 돌려준다)
u = 스터드 A 의 각 = mod(195.17° − theta, 360°). 스터드 B 는 u − 180°.
- 밀기: u ∈ [112.08°, 67.92°] 의 구간에서 스터드 원이 돌출부 왼면에 닿아 같이 움직인다: bar = 0.75·cos(u) + 0.075 − 0.0930 (B 의 밀기는 cos(u − 180°) 로 같은 식). 이 u 구간이 "스터드 원이 돌출부 밑변 높이와 겹치는 간격"(sin u ≥ (2.41 − 0.075 − 1.64)/0.75)이라 접촉의 시작·끝이 기하로 정해진다.
- 두드림: u − 180° ∈ [−124.10°, −178.71°] 의 구간(스터드가 아래팔 패드를 스치는 동안)에서 γ = 두원교점(P, 1.08 | 스터드 자리, 0.295) 의 반시계 가지, bar = 윗팔 끝 x − √(0.165² − dy²) + 1.18 (0.264 를 넘지 않게 잘라 두드림 전까지 쉰다). 창의 두 끝도 닫힌 식: 처음 닿는 각 = |S(φ)−TL0| = 0.295 풀이, 끊기는 각 = |P−S(φ)| = 1.08 − 0.295 풀이.
- 쉼과 돌아옴: 두드림이 끝나면 γ = 25.65°(접촉이 끊긴 자리)와 bar = −0.300 으로 멈춘다. 쉼 구간의 처음 25° 동안 γ = 25.65°·(1 − smoothstep) 로 −9° 까지 돌아오고 나머지는 쉰다.
- 구간표(한 주기 360°):
| 구간 | u | 막대 bar | 레버 γ |
|---|---|---|---|
| 밀기 A | 112.08° → 67.92° | −0.300 → +0.264 | −9° (쉼) |
| 쉼 | 67.92° → 55.90° | +0.264 | −9° |
| 두드림 B | 55.90° → 1.29° | +0.264 → −0.300 | −9° → +26.2° → +25.65° |
| 쉼+돌아옴 | 1.29° → −67.92° | −0.300 | +25.65° → −9° (처음 25°) |
| 밀기 B | −67.92° → −112.08° | −0.300 → +0.264 | −9° |
| 쉼 | −112.08° → −124.10° | +0.264 | −9° |
| 두드림 A | −124.10° → −178.71° | +0.264 → −0.300 | −9° → +26.2° → +25.65° |
| 쉼+돌아옴 | −178.71° → −247.92° | −0.300 | +25.65° → −9° |
- 주기 닫힘: u 가 360° 돌면 모든 값이 정확히 제자리(막대 −0.300, γ −9°). 두드림 끝의 0.01 정도 되밀림(γ 26.2° → 25.65°)은 스터드가 패드를 지나치며 밀어 넘긴 뒤 빠지는 실제 운동이다.
- 스트로크: 행정 0.564, 밀기·두드림 모두 같다(rL0 = 0.0930 을 그렇게 풀어 둠).
- 대입: `disk.rotation.z = A.disk`, `bar.position.x = A.bar`, `lever.rotation.z = A.gamma`.
- 시각: **t = 1.0 (u 103.5°, 밀기 A 한가운데 — 판화 자세: bar −0.193, γ −9°)**, **t = 1.6 (u 48.5°, 두드림 B — bar −0.084, γ +13.8°)**, t = 2.2 (u 353.5°, 쉼 — bar −0.300, γ +19.7° 로 돌아오는 중), t = 30 (u 325.0°, 쉼 — 제자리 닫힘).
