# 040 V자 톱니 기어
판화: 가로 축(좌우로 뻗음) 두 개가 위아래로 놓이고 폭 넓은 기어 두 개가 옆에서 보인다. 기어 표면에 V자(화살깃) 모양 이 줄이 보이고 축에 허브 링이 있다. 원문: 회전을 회전으로 바꾼다. 이가 비스듬해 보통 평기어보다 더 연속적으로 물린다.
구동: 위 기어 theta += OMEGA·speed·dt (축 X 둘레).

## 부품과 치수 (키트 추가 `herringboneGear`)
- 잇수 24, 피치 반지름 RP = 0.46(모듈 0.92/24 ≈ 0.0383, 이끝 반지름 약 0.5), 이 폭 0.42, 비틀림 가장자리 ±TWIST(헬릭스각 30°, TWIST = tan30°·(0.21/RP)) — 가운데 z=0 이 V의 꼭짓점.
- 위(구동, 청동색) `herringboneGear(24, m, { width: 0.42, twist, hand: 1, driver: true })` 축 (0, 2.25), 아래 `hand: −1` 축 (0, 1.33). 중심 거리 0.92 = 0.46+0.46. 축 깊이 ZC = 0.27 — 기어 지름이 깊이로 나오므로 이끝이 z −0.23~0.77 안에 든다.
- 축: 반지름 0.047 가로 막대 x ±0.78, 양끝에 뒤판에서 나온 받침 기둥(x ±0.7, z −0.3 ~ ZC)과 링.
- 기어는 로컬 Z → 세계 +X: 쿼터니언 = Rx(각)·Ry(90°). 중심선은 로컬 −y.

## 동작
- 아래 기어 각 = `meshAngle([0,0], 24, theta, [0,−0.92], 24)` (속도비 −1). 맞물리려면 비틀림 방향이 반대(hand 반대)여야 한다 — 각 단면 위상 θ2 + rot2 = const − θ1 − rot1 이므로 rot2 = −rot1.
- 절대 각으로 매 프레임 계산.

## 표시
- rotArrow(0.4) 각 기어 오른쪽(x 0.52)에 YZ 평면으로 눕혀 위 반시계(X 양의 회전), 아래 반대. tag: '구동 기어(V자 이)', '피동 기어(V자 이)', '이가 비스듬해 계속 물린다'.
- notes: 잇수 24:24, 속도비 1:1 반대, 이 모양.

## 확인
- t=1, 1.6: 두 기어의 노란 표시선이 반대 방향으로 같은 각 돈다. V자 이 줄이 옆에서 보이고 맞물림 자리에서 두 기어의 V가 맞는다(박히지 않음). 비스듬히 `cam=2.2,2.0,2.8,0,1.8,0.3`.

## 키트 추가 (gear3.ts)
- `herringboneGear(teeth, module, opts?)` — 가운데 평면이 spurGear 와 같은 위상인 V자 이 기어(로프트 층별 회전).

## 검증 후 수정 (Opus, 2026-11-25)
- 기어 지름이 깊이 방향으로도 나와 처음 치수(피치 반지름 0.5, 축 z 0.33 → 이끝 z 약 0.87)로는 전시 깊이(약 0.8)를 넘었다.
- 피치 반지름 0.5 → 0.46(모듈 0.0417 → 0.0383), 축 y 2.3 / 1.3 → 2.25 / 1.33(중심 거리 1.0 → 0.92), 축 깊이 0.33 → ZC 0.27. 이끝 기준 z −0.23~0.77.
- 운동식·잇수·비틀림각·표시는 그대로(`meshAngle` 의 두 번째 중심만 [0, −0.92]).
