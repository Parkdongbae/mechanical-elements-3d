# 214 멈추개 변형 1
원문: "Other modifications of the stop, the operations of which will be easily understood by a comparison with 212." — 멈추개의 다른 변형으로, 작동은 212와 비교하면 쉽게 이해할 수 있다(태엽을 감는 바퀴 수 제한). 쉬운 풀이: 서로 물린 두 기어 앞면에 손가락이 하나씩 붙어 있다. 잇수가 달라 두 손가락이 마주치는 때가 몇 바퀴에 한 번뿐이고, 마주치면 걸려서 더 못 돈다.
판화 묘사(원본 441×437 px, [x·y]): 물린 스퍼 기어 둘. 왼쪽 기어(축 [137·210], 이끝 반지름 약 85 px, 네모 이 12개), 오른쪽 기어(축 [280·212], 이끝 약 75 px, 이 10개). 두 기어 앞면에 눈물방울꼴 손가락 하나씩: 왼쪽은 네모 축을 감싼 둥근 끝(반지름 약 18 px)에서 위(77°)로 길이 약 88 px(이끝 밖까지), 오른쪽은 위 오른쪽(35°)으로 약 81 px.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0100(축 거리 143 px = 1.43).
1. 바퀴는? → 기어 2개. 왼쪽(이 12, 피치 0.78) > 오른쪽(이 10, 피치 0.65).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 왼쪽 손가락 끝이 오른쪽 기어 앞면 위로, 오른쪽 손가락 끝이 왼쪽 기어 앞면 위로 넘어갈 수 있다(손가락이 기어 앞 층).
4. 고정점은? → 두 축(같은 높이).
5. 추·손잡이·크랭크는? → 판화에 없음. 둘 다 네모 축 — 왼쪽을 태엽 굴대(감는 쪽)로 보고 손잡이 보충.
6. 기어는? → 둘 다 바깥 이, 바깥 물림(왼쪽 오른쪽 가장자리 ↔ 오른쪽 왼쪽 가장자리).
7. 한 줄에 놓인 것은? → 두 축이 한 수평선(y 210~212 px).
8. 글자가 가리키는 부품은? → 글자 없음(번호 214 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 동작은 된다: 잇수 12 : 10 이라 왼쪽 한 바퀴에 오른쪽 손가락이 72° 씩 엇갈려, 두 손가락 끝이 물림 자리 근처에서 동시에 만나는 것은 다섯 바퀴에 한 번뿐이다. 다만 판화의 손가락 각(왼 77°·오 35°)대로면 다섯 가지 엇갈림 중 가장 가까운 것도 19.4° 어긋나 두 손가락이 영원히 만나지 않는다(계산). → 오른쪽 손가락을 기어에 붙이는 각을 19.4° 돌려 판화 자세에서 오른쪽 손가락이 15.6° 가 되게 한다. → ★질문 거리.

## 해석(결정 사항)
- 왼쪽 θ1, 오른쪽 θ2 = `meshAngle(CL, 12, θ1, CR, 10)` = 126° − 1.2·θ1. 왼쪽 손가락 세계 각 = θ1, 오른쪽 손가락 = θ2 + 342.0°(오른쪽 기어 로컬 342.0° 방향에 붙임).
- 두 손가락이 닿는 θ1: 감기 쪽 1405.70°, 풀기 쪽 −325.70°. **양 끝 멈춤 사이 왼쪽 기어 1730.8° = 4.81 바퀴**(멈춤 각은 닿기 0.3° 앞, 틈 0.0042).
- 판화에 없는 보충: 감기 손잡이, 바퀴 수 표시등 4개, 멈춤 빨강.

## 구동
왼쪽 기어를 감는다(반시계) → 손가락끼리 걸려 멈춤 → 풀기(시계) → 반대쪽에서 걸려 멈춤. 2.0 rad/s(114.592°/s). 주기 T = 33.208 초, u = t mod T:
- u ∈ [0, 15.104): θ1 = θb + 114.592·u
- u ∈ [15.104, 16.604): θ1 = θf(멈춤, 빨강)
- u ∈ [16.604, 31.708): θ1 = θf − 114.592·(u − 16.604)
- u ∈ [31.708, 33.208): θ1 = θb(멈춤)
θb = −325.4°, θf = 1405.4°.

## 동작 (`state214(t)` — 닫힌 식)
θ1(t) 는 구동 시간표. θ2 = 126 − 1.2·θ1, 오른 손가락 = θ2 + 342.0(도).
감은 바퀴 수 n = (θ1 − θb)/360(0 ~ 4.808). 켜진 표시등 = min(4, floor(n + 0.001)). 엇갈림(notes) = (θ2 + 342 + 1.2·θ1) 은 일정하므로, "왼 손가락이 물림 쪽(0°)을 지날 때 오른 손가락 각" = (468 − 1.2·360·k) mod 360 을 바퀴마다 보여 준다(108°, 36°, 324°, 252°, 180° …).
수치: t = 0 → θ1 −325.4, 멈춤 직후 / t = 3.512 → θ1 77°, 오른 손가락 15.6°(판화 자세) / t = 15.104 → θ1 1405.4, n 4.808, 멈춤 / t = 30 → 풀기, θ1 −129.7.
