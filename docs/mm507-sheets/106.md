# 106 홈 원통 캠의 등속 왕복
원문: (106 and 107.) "Uniform reciprocating rectilinear motion, produced by rotary motion of grooved cams." — 홈이 파인 캠의 회전으로 **등속** 왕복 직선 운동을 얻는다(106·107 공통 설명. 106 은 원통 겉면에 홈이 파인 캠).

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/106-fig-x4.png`·`106-fig-x4c.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 바퀴 1개 = 가로축에 끼운 굵은 원통(드럼). 판화 치수(4배 px): 원통 지름 640, 폭 290(지름의 0.45배), 축 지름 100. 원통 겉면에 굽은 홈 1줄(폭 약 60).
2. 줄·벨트는? → 없음. 맞닿는 짝: 원통의 홈 ↔ 팔 끝의 핀(홈 속에 듦), 가로 막대 ↔ 걸이 두 개의 구멍(미끄럼 짝).
3. 교차하는 가닥은? → 없음. 홈은 원통 맨 위 왼쪽(x 575~650)에서 시작해 앞면을 따라 오른쪽으로 휘어 맨 아래 가운데 오른쪽(x 715 근처)으로 내려간다 — 원통을 돌아가며 좌우로 비스듬히 난 닫힌 홈의 앞쪽 절반.
4. 고정점은? → 맨 위의 빗금 띠 = 천장. 천장에서 내려온 걸이 2개(좁은 네모, 가운데로 막대가 지나감)가 막대를 받친다. 원통 축의 축받이는 그리지 않았다(축 양 끝이 잘려 있음).
5. 추·손잡이·크랭크는? → 없음. 구동은 원통 축의 회전. 가로 막대 가운데에 블록(보스, 앞면에 작은 원 = 고정 핀)이 있고 거기서 아래로 팔이 내려와 끝이 홈 맨 위에 든다.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 홈은 원통 **겉면(둘레)** 에 파였고(옆면이 아님), 핀은 위에서 아래로(반지름 방향) 든다.
7. 한 줄에 놓인 것은? → 막대·보스·두 걸이의 구멍이 한 가로선. 보스·팔·핀이 한 세로선(x 620~625) — 원통 가운데선(x 680)보다 왼쪽 = 핀이 왕복의 왼쪽 끝에 있는 순간. 두 걸이의 가운데(x 635)도 원통 가운데보다 조금 왼쪽.
8. 글자가 가리키는 부품은? → 글자 없음(번호 106 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 홈이 한 바퀴에 닫히므로 계속 돈다. 문제 없음.
- 그 밖의 선: 원통 아래쪽의 가로 잔줄 = 둥근 면의 그늘 표현. 축 왼쪽 끝의 타원 = 잘린 단면. 걸이·막대의 굵은 아래·오른쪽 선 = 그림자.

## 해석(결정 사항)
- 기구: 원통 캠(가로축, 회전) + 겉면의 닫힌 홈 + 홈에 든 핀이 달린 미끄럼 막대(천장 걸이 두 개가 안내, 좌우로만 움직임).
- "등속(uniform)" → 홈 중심선은 **반 바퀴는 곧은 나선으로 오른쪽으로, 반 바퀴는 같은 기울기로 왼쪽으로**(펼치면 세모 물결). 막대는 일정한 속도로 갔다가 같은 속도로 돌아온다(끝에서 바로 뒤집힘).
- 행정: 판화는 홈 중심이 맨 위 610 → 맨 아래 715 px 쯤 = 원통 폭의 0.36배. 모형은 0.18/0.45 = 0.40배.
- 회전 방향은 판화에 없다 → 오른쪽 끝에서 보아 반시계로 정함(세모 물결이 좌우 대칭이라 어느 쪽이든 운동은 같다).
- 원통 축 축받이 2개는 **판화에 없음**(최소 보충). 천장은 뒤판에 붙은 나무 들보로 만든다.

## 구동
원통 캠(theta 누적). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 막대 한 번 왕복.

## 부품과 치수 (새 부품은 모두 `kit/k104.ts`, 이미 구현됨. 치수 상수 `K106`)
배치 상수: DX = 0 (원통 가운데 x), CY = 1.25 (원통 축 높이), ZC = 0.275 (원통 축·막대의 z), BY = CY + 0.5 + 0.25 = 2.0 (막대 축 높이), CEIL = 2.4 (천장 밑면).
- 원통 캠(name `drum`): `grooveDrum()` — 반지름 0.5, 폭 0.45, 홈 깊이 0.07, 홈 축방향 폭 0.0785(핀 지름 0.07 + 벽에 수직인 틈 0.004 씩), 홈 중심선 진폭 0.09(행정 0.18). 축 = 로컬 X. 위치 (DX, CY, ZC). 주철. 축: `rod(new Vector3(−0.78, 0, 0), new Vector3(0.78, 0, 0), 0.08)` 를 **원통 그룹의 자식**으로(같이 돈다).
- 원통 축받이 2개(판화에 없음): `wallBearingX(ZC, 0.08)` 를 (−0.6, CY, ZC), (0.6, CY, ZC) 에. 고리 구멍이 X 방향(축 방향), 기둥은 고리 뒤쪽 바깥면에서 뒤판으로(축에 박히지 않음).
- 미끄럼 막대(name `bar`): `followerBar()` — 네모 막대 0.07 × 0.07, 길이 1.56, 보스 0.16 × 0.15 × 0.14, 팔(보스 아래 ~ 원통 겉면 위 0.03), 핀 반지름 0.035(홈 바닥 위 0.012 까지 듦). 원점 = 보스 가운데 → 위치 (DX + xb, BY, ZC). child `follower`(겉면 높이의 핀 중심).
- 천장 걸이 2개(고정): `hangerX(0.4)` 를 (−0.58, BY, ZC), (0.44, BY, ZC) 에 — 두께 0.1(X 방향), 깊이 0.17, 네모 구멍(반변 0.039)이 X 방향으로 뚫려 막대가 지나간다. 위 끝이 천장 밑면 CEIL 에 닿는다. 두 걸이의 가운데 x = −0.07(판화처럼 원통 가운데보다 조금 왼쪽).
- 천장(고정): `ceilingSlab(1.9)` — 길이 1.9, 높이 0.14, 뒤판 앞면에서 앞으로 0.8. 위치 (−0.07, CEIL, 0). 가로 범위 −1.02 ~ 0.88, 세로 2.4 ~ 2.54.
- 검사 표식(메시 없음): `grooveProbe()` → `.group`(name `grooveProbe`)을 루트에 더하고 매 프레임 `.set(a, xb)`.
- 받침대·뒤판 `displayStand()`.
- 전체 가로 범위 −1.02 ~ 0.88, 세로 0.75 ~ 2.54.
- 한 줄 정렬: 막대·두 걸이의 구멍은 같은 높이 BY·같은 z. 핀 가운데선은 원통 축 바로 위(z = ZC).

## 동작 (모두 theta 의 닫힌 식)
- 원통 각 a = theta − 1.6 (t = 1 에 a = 0 = 판화 자세: 핀이 왼쪽 끝). `drum.rotation.x = a`.
- 막대 x: xb = `grooveCamX(a)` = 0.09·tri(a), tri(a) = 2·|a 를 (−π, π] 로 접은 값|/π − 1 (a = 0 에서 −1, a = π 에서 +1, 그 사이 곧은 선). `bar.position.x = DX + xb`. 범위 −0.09 ~ +0.09, 속도 일정 ±0.0573·a'(= 초당 0.0917).
- 검사 표식: `probe.set(drum.rotation.x, bar.position.x − DX)` — 실제로 놓은 값을 그대로 넣는다.
- a = 0 일 때 홈은 맨 위에서 왼쪽 끝, 앞면(정면에서 보이는 쪽) 가운데 높이에서 원통 가운데, 맨 아래에서 오른쪽 끝 → 정면에서 왼쪽 위 → 오른쪽 아래로 휘어 보인다(판화와 같음).
- 시각: **t = 1.0 (a = 0, 핀 왼쪽 끝 xb −0.09, 판화 자세)**, **t = 1.6 (a = 0.96, xb −0.035, 오른쪽으로 가는 중)**, t = 2.96 (a = π, 오른쪽 끝 +0.09), t = 30 (a = 46.4 → 접으면 2.42, xb +0.048).

## notes
