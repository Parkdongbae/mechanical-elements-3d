# 178 속도를 바꾸는 홈 크랭크
원문: "Contrivance for varying the speed of the slide carrying the cutting tool in slotting and shaping machines." — 구동 축이 **고정 원판의 구멍**을 지나 끝에 **홈 크랭크**를 달고, 크랭크 홈과 원판의 **원형 홈**에 **미끄럼쇠**가 끼어 있다. 미끄럼쇠 바깥 끝에 연결 막대가 붙어 공구 슬라이드를 민다. 원형 홈의 중심이 축에서 벗어나 있어 미끄럼쇠가 아래로 오면 크랭크가 짧아져 느려진다.
판화 묘사: 큰 동심원 둘(고정 원판의 테와 원형 홈), 그 안의 작은 원(축이 지나는 구멍), 구멍 안 아래쪽의 굵은 점(축). 축에서 위로 곧게 선 길쭉한 크랭크(홈 난 막대), 꼭대기의 작은 원이 미끄럼쇠. 거기서 왼쪽으로 가는 연결 막대(바깥 끝은 판 밖으로 나감). 축은 원형 홈 중심보다 아래.

## ★ 판화 읽기
1. 바퀴는 몇 개? → 바퀴(풀리·기어) 없음. 부품: ① 고정 원판(구멍 + 원형 홈) ② 구동 축과 홈 크랭크 ③ 미끄럼쇠(핀) ④ 연결 막대 ⑤ 공구 슬라이드(판화 밖 — 모형은 레일 위에 보충).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 연결 막대가 원판 테 위를 앞으로 지나감(원판 앞). 크랭크는 원판 앞, 막대는 크랭크 앞.
4. 고정점은? → 고정 원판(뒤판에 기둥으로), 축의 뒤판 받침, 슬라이드의 레일.
5. 추·손잡이·크랭크는? → 크랭크 하나(홈 막대), 손잡이 없음. 공구 슬라이드가 종동.
6. 기어는? → 없음. 미끄럼쇠 ↔ 크랭크 홈(미끄럼), 미끄럼쇠 ↔ 원형 홈(미끄럼).
7. 한 줄에 놓인 것은? → 원판 중심·축·크랭크(위로 섰을 때)·미끄럼쇠가 한 세로선. 축은 홈 중심 e 아래.
8. 글자는? → 번호 178 뿐.
9. 판화와 원문이 다른 곳은? → 판화의 연결 막대는 왼쪽으로 위로 비스듬히 나간다. 모형은 슬라이드를 수평 레일 위에 두어 막대 길이가 변하지 않게 풀었다(막대 눈높이 = 원판 중심 높이). 질문 거리 없음.

## 해석(결정 사항)
- 판화 비: 홈 반지름 145 : 편심 65 = 1 : 0.45 → r 0.70, e 0.30(0.43). 판화 자세(크랭크가 위로 선 때)를 t = 1(θ = 1.6 rad ≈ 92°)로 본다.
- 원형 홈은 원판 윗층이 안·바깥 두 고리로 나뉜 틈(반폭 0.045), 바닥은 아래층. 핀은 홈 바닥 위에서 미끄러진다.
- 핀 위치: 축 S 에서 방향 (cosθ, sinθ) 로 ρ = e·sinθ + √(e²sin²θ + r² − e²) 만큼. 유효 크랭크 길이 ρ 는 r−e = 0.40(아래) ~ r+e = 1.00(위).

## 구동
홈 크랭크(축). theta += OMEGA(1.6)·speed·dt, 크랭크 각 = theta(반시계). 한 바퀴 2π = 3.93 s.

## 부품과 치수 (새 부품은 모두 `kit/k178.ts`, 이미 구현됨, 상수 `K178`)
- 고정 원판(name `disk`): `fixedDisk178()` 를 C (1.05, 1.90) 에. 바깥 0.86, 축 구멍 0.40, 원형 홈 중심선 0.70·반폭 0.045. z −0.25 ~ −0.17, 뒤판에 버팀 기둥 4개(z −0.30 ~ −0.25).
- 축(name `shaft`, 고정): `shaft178()` 를 S (1.05, 1.60) 에. 반지름 0.045, 뒤판(z −0.30)에서 앞 0.09 까지. 구멍(반지름 0.40)을 지나감.
- 홈 크랭크(name `crank`): `crank178()` 를 S 에, rotation.z = θ. 길이 1.20, 반폭 0.10, 두께 0.05(z 0.02 ~ 0.07), 홈 중심 0.37 ~ 1.03(반폭 0.04), 허브 0.115. 표식 밝은 띠.
- 미끄럼쇠(name `slidePin`): `slidePin178()` 를 핀 P 에. 핀 반지름 0.03(z −0.21 ~ 0.15), 크랭크 위 플랜지 반지름 0.065.
- 연결 막대(name `rod`): `rod178()` 를 슬라이드 눈 (xc, 1.90) 에, rotation.z = 눈→핀 각. 길이 2.00, z 0.09 ~ 0.13.
- 공구 슬라이드(name `toolSlide`): `toolSlide178()` 를 (xc, 1.90) 에. 블록 0.30 × 0.18 × 0.13(z −0.04 ~ 0.09), 공구대, 바이트.
- 레일(name `rail`, 고정): `rail178(−2.05, 0.05)` 를 (0, 1.90) 에. z −0.18 ~ −0.04, 두 기둥으로 뒤판에.
- 전체 범위: x −2.1(바이트) ~ 1.91(원판), y 0.9(크랭크 아래) ~ 3.0.

## 동작 (모두 theta 의 닫힌 식 — `kin178(theta)` 가 { rho, P, xc, rodAng } 를 돌려준다)
- P = S + ρ(cosθ, sinθ), 슬라이드 x: xc = P.x − √(L² − (P.y − 1.90)²), L = 2.00. 범위 −1.65 ~ −0.25.
- 핀이 홈 아래(θ ≈ 270°)로 오면 ρ = 0.40 로 짧아져 슬라이드가 느리게, 위(θ ≈ 90°)에서는 빠르다.
- 시각: **t = 1 (판화 자세)**, t = 2.3 (θ ≈ 3.7 rad, 아래쪽 느린 구간).

- tag 이름표 4개: '고정 원판(원형 홈)' (1.05, 0.45, 0.3), '홈 크랭크(구동)' (1.05, 0.8, 0.3), '연결 막대' (xc + 0.75, 2.65, 0.3) 막대를 따라감, '공구 슬라이드' (xc − 0.15, 1.45, 0.3) 슬라이드를 따라감.
