# 300 쌍바퀴 탈진기(앞모습)
원문(en): "300 and 301. A clock or watch escapement ; 300 being a front elevation, and 301 a side elevation. The pallet is acted upon by the teeth of one and the other of two escape-wheels alternately." — 300·301. 시계 또는 회중시계의 탈진기로 300 은 앞모습, 301 은 옆모습이다. 팔레트는 두 탈진 바퀴 가운데 한 바퀴의 이와 다른 바퀴의 이에 번갈아 밀린다.
쉬운 풀이: 같은 축에 똑같은 탈진 바퀴 둘이 앞뒤로 붙어 있고, 뒤 바퀴의 이는 앞 바퀴 이 사이(반 칸)에 온다. 바퀴 아래에 가로축이 있고, 그 축에 박힌 팔레트 판이 진자와 함께 앞뒤로 기울어진다. 앞쪽이 올라가면 앞 바퀴의 이가 팔레트 왼쪽 면에 걸리고, 뒤쪽이 올라가면 뒤 바퀴의 이가 걸린다. 걸린 이가 팔레트 윗모서리의 비탈을 넘어가면 바퀴가 반 칸 툭 돌아 다른 바퀴의 이가 걸린다. 진자가 한 번 오갈 때 바퀴는 이 하나(22.5°)만큼 돈다.
판화 묘사(원본 528×439 px, **앞모습**): 위 가운데 축(작은 두 겹 원 [310·130])에서 두 팔이 아래로 벌어져 큰 둥근 테(반지름 ≈ 110 px)에 이어진 바퀴. 테 바깥으로 길게 꺾인 갈고리 이가 아래·오른쪽 둘레에 줄지어 있고, 이마다 두 획(앞 이와 그 사이에 비치는 뒤 이)으로 보인다. 아래 [130~500·330] 에 가로 막대(축), 그 가운데 [290·315~390] 에 작은 세로 덩이(팔레트) — 막대 위로 좁은 머리가 올라와 바퀴 아래 이 끝에 닿는다. 301(옆모습, 참고): 세로 판 둘(두 바퀴 옆면, 안쪽에 이 자국), 위에 두 판을 꿰는 가로 원기둥(바퀴 축), 아래에 반원 판(팔레트)과 그 중심 작은 원(팔레트 축 끝).

## ★ 판화 읽기
판화 둘(300 앞모습 + 301 옆모습 참고). 300 의 1 px ≈ 0.0041(이끝 반지름 ≈ 183 px → 0.75). 바퀴 축 [310·130] ↔ 세계 Wc (0.15, 1.95), 팔레트 [290·330] ↔ (0.10, 1.14).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 탈진 바퀴 2(같은 크기, 갈고리 이 16, 이끝 반지름 0.75), 같은 축에 앞뒤로(301 의 두 세로 판). 보충한 태엽통(반지름 0.45, 뒤 바퀴 뒤).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 팔레트 축(x 방향)과 바퀴 축(z 방향)이 서로 직각으로 엇갈린다(301 에서 팔레트 축이 원으로 보임).
4. 고정점은? → 바퀴 축 Wc(뒤판 보스), 팔레트 축 양 끝 받침 2(뒤판에서 나온 기둥 — 판화의 가로 막대 양 끝 밖, 보충).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 팔레트 축 오른쪽에 진자(보충 — 판화에 없음, 축이 앞뒤로 흔들리게). 바퀴는 뒤 태엽통이 반시계로 민다(보충).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 두 바퀴 바깥 둘레에 반시계 쪽으로 기운 갈고리 이. 뒤 바퀴는 앞 바퀴에서 11.25°(반 칸) 돌려 붙임. 바퀴 맨 아래 이 끝이 팔레트 머리의 **왼쪽 면**(x = 0.065)에 걸리고, 머리 윗모서리 비탈(충격면)을 넘어 빠져나간다. 앞 바퀴는 머리의 앞쪽(z 0.24~0.28), 뒤 바퀴는 뒤쪽(z −0.04~0)에 닿는다.
7. 한 줄에 놓인 것은? → 팔레트 머리 왼쪽 면 x = 0.065 은 바퀴 중심(0.15)보다 0.085 왼쪽(판화의 팔레트가 축보다 조금 왼쪽). 팔레트 축·진자 축선 y = 1.1408, z = 0.12(두 바퀴 사이 가운데).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 300·301 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 300 만으로는 팔레트가 어떻게 번갈아 닿는지 안 보여 301 옆모습으로 읽음: 팔레트 축이 바퀴 축과 직각, 반원 판이 앞뒤로 기울어 앞·뒤 바퀴에 번갈아 들어간다. (나) 앞뒤로 기우는 움직임은 정면에서 거의 안 보인다 → 시점을 왼쪽 앞 위로(판화 300 과 301 의 중간). (다) 진자·받침·태엽통 보충. (라) 팔레트 왼쪽 면이 진자 축에 나란한 평면이라 걸린 동안 바퀴는 완전히 멈춤(되튐 없음), 충격은 윗모서리 비탈에서만.

## 해석(결정 사항)
- **진자 각만 시간표, 바퀴 각은 접촉에서**: ψ(t) = 20°·sin(π t)(주기 2 초, ψ > 0 = 팔레트 앞쪽이 올라감). 바퀴는 태엽통이 늘 반시계로 미므로, 매 순간 φ = 걸린 이의 끝이 팔레트 머리 윤곽(왼쪽 면 + 비탈 + 윗면)에 닿는 각.
- 팔레트 머리는 축 방향(z′)으로 곧은 기둥이라, 높이가 바뀌는 단면은 정확히 **y = 1.1408 + y′/cos ψ + z·tan ψ**(x 는 그대로) — z 는 이가 닿는 바퀴 면의 깊이(축선 기준). 이 두께 0.04 안에서 팔레트가 가장 높은 면이 먼저 닿는다: 앞 바퀴 z = +0.16(ψ ≥ 0) / +0.12(ψ < 0), 뒤 바퀴 z = −0.12(ψ ≥ 0) / −0.16(ψ < 0).
- shapely 로 두 바퀴 다각형과 팔레트 단면(이 두께 안 5 깊이)을 진자 위상 0.1° 간격 3600 자세로 겹쳐 확인(겹침 0, 규칙과 차 0.0019°).
- 한 주기(2 초)에 정확히 +22.5°(반시계 이 하나). 반 주기마다 비탈 충격 ≈ 3.8° + 드롭 6.23°.

## 동작 (`state300(t)` — 결정적, 접촉 계산)
1. n = floor(t/2), τ = t − 2n, ψ = 20·sin(π τ)(도).
2. 바퀴 면 깊이: 앞 바퀴 ze = (ψ ≥ 0 ? 0.16 : 0.12), 뒤 바퀴 ze = (ψ ≥ 0 ? −0.12 : −0.16)(축선 z 0.12 기준).
3. 팔레트 닿는 꺾은선(묶음 단면): (0.065, −0.20) → (0.065, 0.045) → (0.095, 0.07) → (0.135, 0.07). 세계 xy 로: x 그대로, y = 1.1408 + y′/cos ψ + ze·tan ψ.
4. 각 선분과 원(Wc, 0.75)의 교점 각 α 를 기준각 −96° 근처(±180°)로 맞추고, 바퀴가 반시계로 돌므로 **α 가 가장 작은 점**(먼저 닿는 점)을 고른다. φ = α − θ, θ = −90° − 22.5°·k(앞) 또는 −78.75° − 22.5°·k(뒤).
5. 구간: τ < 0.5 → 뒤·k = 0, 교점이 없으면 앞·k = 0. 0.5 ≤ τ < 1.5 → 앞·k = 0, 없으면 뒤·k = 1. τ ≥ 1.5 → 뒤·k = 1. φ 에 22.5·n 을 더한다.
