# 122 두 기어로 만드는 가변 왕복
원문: "The rotation of the two spur-gears, with crank-wrists attached, produces a variable alternating traverse of the horizontal bar." — 크랭크 핀이 달린 두 평기어가 돌면 수평 막대가 **폭이 변하는** 왕복을 한다. (카탈로그 easy 의 "같은 크기의 두 기어"는 판화와 다르다 — 판화의 두 기어는 크기가 다르고, 크기가 달라야 왕복이 '가변'이 된다.)

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/122-fig-x4.png` 로 다시 읽음(아래 [x·y] 는 4배 확대 그림의 px 자리).
1. 바퀴는 몇 개이고 크기 차례는? → 평기어 2개가 서로 물린다. 위 왼쪽이 큰 기어(중심 [950·650], 이끝 반지름 약 395), 아래 오른쪽이 작은 기어(중심 [1090·1300], 이끝 반지름 약 330). 피치 반지름 비 약 370 : 305 = 1.21 → 잇수 30 : 25(6 : 5)로 정함. 중심 거리 665 ≈ 피치 반지름 합.
2. 줄·벨트는? → 없음. 대신 곧은 막대가 넷: ① 위 연결봉(큰 기어의 핀 [910·440] → 오른쪽 위 핀 [1590·300], 길이 694) ② 아래 연결봉(작은 기어의 핀 [1050·1105] → 오른쪽 아래 핀 [1630·990], 길이 591) ③ 두 연결봉의 오른쪽 끝을 잇는 세로 지레([1590·300] ↔ [1630·990], 길이 691) ④ 지레 한가운데 [1610·650] 에 눈으로 꿰인 수평 막대(오른쪽으로 뻗음, 끝은 둥근 막대).
3. 교차하는 가닥은? → 없음. 두 연결봉은 위아래로 떨어져 나란히 가고, 둘 다 기어의 **앞**을 지난다(기어 이의 선이 봉에서 끊긴다). 지레는 연결봉 끝의 앞, 막대의 눈은 지레의 앞(눈의 원이 지레 선을 덮는다).
4. 고정점은? → 판화에는 두 기어의 축(빗금 원 + 허브 고리)뿐. 막대의 안내(미끄럼 받침)는 그리지 않았다 — 원문이 "horizontal bar" 라 했으므로 막대는 수평으로만 움직인다(안내 필요).
5. 추·손잡이·크랭크는? → 크랭크 = 각 기어의 면에 박힌 핀(crank-wrist, 두 겹 원). 큰 기어의 핀은 중심에서 (−40, −210) = 반지름 214·방향 101°, 작은 기어의 핀은 (−40, −195) = 반지름 199·방향 101.5°(둘 다 중심의 위쪽, 살짝 왼쪽). 손잡이·추 없음. 어느 기어가 구동인지는 판화·원문에 없다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 두 기어 모두 바깥 둘레에 이. 큰 기어의 아래 오른쪽과 작은 기어의 위 왼쪽이 물린다(물림점은 두 중심을 잇는 선 위, 그 선은 수직에서 12° 기울었다). 그 밖의 맞닿는 짝: 핀 ↔ 연결봉 눈(회전 짝 4곳), 지레 가운데 핀 ↔ 막대의 눈(회전 짝), 막대 ↔ 안내(미끄럼 짝 — 판화에 없음).
7. 한 줄에 놓인 것은? → 큰 기어의 축(y 650)과 지레의 가운데 핀·수평 막대(y 650)가 같은 높이. 지레의 가운데 핀은 두 끝 핀의 정확히 한가운데((300 + 990)/2 = 645).
8. 글자가 가리키는 부품은? → 글자 없음(번호 122 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 같다(해석이 갈리지 않음). 다만 **판화 치수 그대로는 계속 돌지 못한다**: 기어가 6 : 5 라 두 핀의 위상이 계속 어긋나 언젠가 서로 반대쪽(큰 기어 핀은 오른쪽, 작은 기어 핀은 왼쪽)에 오는데, 그때 지레가 크게 기울다 넘어가 풀리지 않는다(`shots/_verify/s122b.mjs` — 판화 치수는 주기의 58 % 에서 풀이 실패). 기구는 그대로 두고 크랭크 반지름만 80 % 로, 지레를 1.11배로 고쳐 만든다(아래 해석). 사용자에게 알릴 것으로 적어 둠.
- 그 밖의 선: 지레는 두 줄(안쪽 가는 선 + 바깥 굵은 선)로 그려 두께를 나타낸 것. 막대의 눈 오른쪽 잘록한 곳 = 납작한 목에서 둥근 막대로 바뀌는 어깨. 막대 끝의 타원 = 둥근 막대의 단면. 오른쪽 아래의 점 하나는 인쇄 얼룩.

## 해석(결정 사항)
- 기구: **두 기어의 크랭크 핀 → 연결봉 둘 → 뜬 지레(받침점 없이 세 핀만 있는 지레)의 두 끝**, 지레 한가운데가 수평 막대를 민다. 막대 변위 ≈ 두 연결봉 끝 변위의 평균. 두 기어의 잇수가 달라(30 : 25) 두 핀의 위상차가 계속 변하므로, 같은 쪽으로 움직일 때는 왕복 폭이 크고(최대 0.80) 반대로 움직일 때는 거의 서 있다(지레만 기울어짐). 큰 기어 5바퀴(작은 기어 6바퀴)마다 같은 모양이 되풀이된다.
- 치수(판화 1px = 1/480, 큰 기어 피치 반지름 0.75): 크랭크 반지름 판화 0.45·0.41 → **0.36·0.33**, 지레 판화 1.44 → **1.6**, 연결봉 1.44·1.22(판화 그대로). 이 치수에서 한 주기 내내 풀리고 특이점에서 멀다(야코비안 행렬식 최소 4.0, 지레 기울기 −26° ~ +32°).
- 구동은 큰 기어(위), 반시계로 정함(판화·원문에 없음).
- 판화에 없는 보충: 기어 축의 뒤판 보스, 막대의 안내 고리 1개(뒤판에서 나온 팔), 공통 받침대.

## 구동
큰 기어(위, 30T)가 구동. theta += OMEGA(1.6)·speed·dt, 반시계. 작은 기어(25T)는 시계로 1.2배. 한 주기 = theta 10π = 19.6 s.

## 동작 (모두 theta 의 함수 — `gearAngles122(theta)`, `linkage122(theta)` 가 돌려준다)
- 기어: `{ g1, g2 } = gearAngles122(theta)` → `gear1.rotation.z = g1`(= theta − 1.6), `gear2.rotation.z = g2`(= 이가 맞물리는 위상, 기울기 −1.2).
- `L = linkage122(theta)` — 크랭크 핀 p1·p2, 막대 눈의 x, 지레 각 phi, 지레 끝 A·B, 연결봉 각 rod1·rod2.
  - 핀: p1 = O1 + 0.36·(cos a1, sin a1), a1 = 101° + (theta − 1.6). p2 = O2 + 0.33·(cos a2, sin a2), a2 = 101.5° − 1.2·(theta − 1.6).
  - 지레: 가운데 M = (x, BY), A = M + 0.8·(cos phi, sin phi), B = M − 0.8·(cos phi, sin phi). 미지수 (x, phi) 는 |A − p1| = 1.44, |B − p2| = 1.22 두 식으로 정해진다. 닫힌 식이 없어 **한 주기 시간표**(2400칸, 판화 자세에서 이어 풂)를 출발값으로 뉴턴법으로 다시 푼다 → theta 만의 함수, 누적 오차 없음(주기 끝 = 처음, 오차 1e−15).
- 대입: `rod1.position = (p1, ZR)`, `rod1.rotation.z = L.rod1`; `rod2.position = (p2, ZR)`, `rod2.rotation.z = L.rod2`; `lever.position = (L.x, BY, ZL)`, `lever.rotation.z = L.phi`; `bar.position = (L.x, BY, ZB)`.
- 범위(`node shots/_verify/s122k.mjs`): 막대 눈 x −0.124 ~ 0.677(행정 최대 0.80), 지레 각 63.9° ~ 122.0°, 지레 끝 높이 1.494 ~ 3.094, 연결봉 기울기 위 17° ~ 53°·아래 10° ~ 50°.
- 시각: **t = 1.0 (theta 1.6 — 판화 자세: 두 핀이 위쪽, x = 0.372, phi = 94.4°)**, **t = 1.6 (x = 0.355, phi = 116° — 지레가 기운 모습)**, t = 4 (x 0.442), t = 7 (x 0.075), t = 10 (x −0.101).

## 키트 추가
이미 구현됨: `kit/k122.ts` (122·123·124 공용). 모델은 `'../kit/k122'` 에서 직접 import. `npx tsc --noEmit` 에러 0.
- `K122` — 치수 상수 { z1, z2, m, O2, axisDeg, r1, r2, L1, L2, lever, pose1, pose2, period }, `K122_O1: V2`, `K122_BAR_Y: number`, `K122_PIN1_LOCAL`, `K122_PIN2_LOCAL`
- `gearAngles122(theta: number): { g1: number; g2: number }` — 두 기어의 그룹 회전각(맞물림 위상)
- `linkage122(theta: number): Link122` — { a1, a2, p1, p2, x, phi, A, B, rod1, rod2 }, 주기 시간표 + 뉴턴법
- `crankGear(teeth: number, module: number, crankR: number, pinLocal: number, o?: CrankGearOpts): THREE.Group` — 민판 평기어 + 허브 고리 + 크랭크 핀, 핀 표식 child(name = o.pinName)
- `floatLever(length: number, o?: FloatLeverOpts): THREE.Group` — 구멍 셋 지레, 핀 표식 child `leverA`·`leverB`·`leverM`
- `eyeBar(length: number, o?: EyeBarOpts): THREE.Group` — 눈 달린 미끄럼 막대, 핀 표식 child `barEye`
- `studZ(x: number, y: number, r: number, z1: number, capR?: number, capT?: number): THREE.Group` — 뒤판에서 나온 고정 축(얇은 덮개)
다른 키트에서 그대로 가져다 쓰는 것(고치지 않음): `connectingRod(length, o?)`(k092), `wallBearing(x, y, zc, axis, bore?)`(gear6), `rotArrow`·`tag`·`displayStand`(index).
