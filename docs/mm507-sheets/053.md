# 053 양방향 이중 클러치 (세로축 → 가로축, 정회전·정지·역회전)
판화(Read 로 확인): 위쪽에 세로 구동축 머리(작은 사각 돌기)가 달린 **넓은 베벨 기어 C**(이가 아래를 향함)가 있고, 좌우에 큰 베벨 기어 **A(왼쪽)·B(오른쪽)** 가 마주 보며 C 의 양쪽 모서리와 맞물린다(전체가 ㄷ자를 뒤집은 모양, 가운데 위는 비어 있다). A·B 의 바깥쪽 끝에 가로축 돌출부(짧은 축)가 하나씩 나와 있다. 두 기어 사이 아래쪽에 가로축을 따라 **왼쪽 발톱(톱니 모양 면) → 이중 클러치(양끝에 톱니 면, 가운데 홈) → 오른쪽 발톱** 순으로 늘어서 있고, 클러치 홈에 걸린 핀에서 **막대 → 레버**(왼쪽 아래 받침점 + 아래로 내려간 손잡이 막대)가 이어진다.
원문 요지: 세로축이 가로축을 **원하는 방향으로** 구동한다. 가로축 위의 두 베벨기어는 **헐겁게** 끼워져 있어 세 번째 기어(C)에 의해 **서로 반대로** 돈다. 이중 클러치는 가로축에 고정된 키(깃) 위를 미끄러지며, **맞물리는 쪽에 따라** 가로축이 오른쪽/왼쪽으로 돈다.
★ 판화 읽기 (질문표)
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → **베벨 기어 3개**. 위의 C(세로축, 이가 아래로)가 조금 넓고, 좌우의 A·B(가로축, 이가 서로 마주 봄)는 같은 크기. 그 밖에 가운데 **이중 클러치 1개**(양끝 톱니 면, 가운데 홈)와 A·B 안쪽 허브 끝의 **톱니 면 2개**.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 벨 크랭크의 **받침점(겹원)** 하나 — 클러치 홈 바로 아래. 축 받침은 판화에 없음(팔 베어링 3개는 보충).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → **벨 크랭크(ㄴ자 레버)**: 세로 팔 위 끝의 핀(작은 원)이 클러치 홈에 걸림 → 아래 받침점 → 가로 팔이 **왼쪽**으로 → 끝의 작은 원(핀)에서 **세로 막대**가 아래로 내려가 그림 밖으로 끊김. 곧은 레버 + 공 손잡이가 아니다(옛 설계표의 오독).
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 세 기어 모두 원뿔면(베벨). C 의 왼쪽 가장자리 ↔ A 의 위 가장자리, C 의 오른쪽 가장자리 ↔ B 의 위 가장자리. A 와 B 는 서로 물리지 않는다. 클러치 톱니는 **축 방향 면**(끝면)에 났다 — 판화는 잔 톱니 5~6개의 지그재그, 모델은 발톱 4개.
7. 한 줄에 놓인 것은? → A – 왼쪽 톱니 면 – 클러치 – 오른쪽 톱니 면 – B 가 **가로축 한 줄**. C 와 세로축은 그 한가운데 위(좌우 대칭). 클러치 홈 핀과 받침점은 거의 같은 세로선.
8. 글자가 가리키는 부품은? → 글자 없음(번호 53 뿐). A·B·C 는 이 설계표가 붙인 이름.
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → 없음. 판화는 클러치가 **오른쪽(B)에 물린 상태**(오른쪽 톱니가 맞닿고 왼쪽은 벌어짐)로 그려져 있고 원문과 맞는다.

구동: 세로축(위) 일정 속도 — `theta += OMEGA·speed·dt`. 클러치 레버는 `theta` 의 주기 시간표로 자동 조작(아래).

## 해석(결정 사항)
- 판화에서 위·좌·우의 큰 기어 3개를 **45° 마이터 베벨(잇수 20, 1:1)** 로 만든다(C 는 A·B 와 같은 크기 — 판화에서 C 가 좀 넓어 보인다. C 가 더 커도 A·B 는 같은 속도로 반대로 돌지만, 세 기어 치수를 하나로 두려고 마이터로 한다).
- 판화의 "왼쪽 톱니 조각 / 이중 클러치 / 오른쪽 톱니 조각"은 **발톱(도그) 클러치**: 헐거운 기어 A·B 의 안쪽 면에 발톱 4개(링), 클러치 양끝에 발톱 4개. 판화는 기어 사이 간격이 넓게 그려져 있어 발톱·클러치를 기어 **안쪽 컵(이 난 원뿔 속)** 으로 들여놓아 기어 사이에 들어가게 했다(마이터라 A·B 사이 거리 = 2R 로 정해진다).
- 클러치를 미는 장치는 판화대로 **벨 크랭크(ㄴ자 레버) + 당김 막대**: 세로 팔 끝의 핀이 클러치 홈에 걸리고, 그 아래 받침점(겹원)에서 가로 팔이 **왼쪽**으로 뻗어, 끝 핀(작은 원)에 **세로 막대**가 걸려 아래로 내려간다. 막대를 올리고 내리면 클러치가 좌우로 간다. 홈 아래 반고리 + 슬롯 팔판인 **요크는 판화에 없음(보충)** — 판화는 핀이 홈에 바로 걸리지만, 도는 클러치와 핀의 겹침을 피하려고 둔다.
- 발톱이 서로 도는 동안 억지로 맞물리면 겹쳐 보이므로, 클러치가 들어가는 순간에는 **발톱이 홈 가운데로 정확히 겹치는 각**이 되게 시간표를 짜 두었다(수치 검사 완료, 아래 '확인').
- 이름: "양방향 이중 클러치". 판화는 하나뿐이므로 이것만 만든다.

## 부품과 치수 (전시 영역 안: x ±0.9, y 0.3~3.0, z −0.18~0.74)
공통: 가로축 중심선 (y = 1.55, z = ZC = 0.28), 세로축 중심선 (x = 0, z = 0.28). 마이터 꼭짓점 O = (0, 1.55, 0.28).
- **베벨 기어 3개**: `bevelGear(20, 0.042, { width: 0.10, spokes: 5, bore: 0.05 })`. 피치 반지름 R = 0.42, 이끝 반지름 0.458, 이 높이(원뿔 모선 폭 0.10 → 축 방향 0.0707). C 만 `driver: true`(청동).
  - E6 깊이 검사: 기어 반지름 0.458 → ZC ± 0.458 = −0.178 ~ 0.738 (전시 −0.25~0.8 안). 세로축 C 도 같은 z 범위.
  - **A**(왼쪽): 피벗 그룹 위치 (−0.42, 1.55, 0.28), `rotation.x = ρA`(아래), 자식 기어 `rotation.y = +π/2`(로컬 Z → +X, 이가 O 쪽). 피치원 평면 x = −0.42, 이는 x = −0.349 까지, 뒤판(허브)은 x ≈ −0.51.
  - **B**(오른쪽): 피벗 (0.42, 1.55, 0.28), `rotation.x = ρB`, 자식 기어 `rotation.y = −π/2`(로컬 Z → −X).
  - **C**(위): 피벗 (0, 1.97, 0.28), `rotation.y = ψ`, 자식 기어 `rotation.x = +π/2`(로컬 Z → −Y). 피치원 평면 y = 1.97.
- **세로 구동축**: `rodY(1.80, 2.95, 0.045)` 를 C 피벗 안에 넣어 C 와 함께 돈다(그룹 위치 (0,0,0)이고 피벗이 (0,1.97,0.28)이므로 축 좌표는 피벗 기준 y −0.17 ~ 0.98 로 맞춘다). 위쪽 팔 베어링 `armBearing('y', 0.58)` 위치 (0, 2.45, 0.28).
- **가로 출력축**: `rodX(−0.88, 0.88, 0.045, { x0: −0.29, x1: 0.29 })`, 그룹 위치 (0, 1.55, 0.28), `rotation.x = β`(아래). 양끝 팔 베어링 `armBearing('x', 0.58)` 위치 (±0.68, 1.55, 0.28). 오른쪽 끝(x ≈ 0.80)에 표시 원판(반지름 0.12, 두께 0.02, 가로축에 고정, 밝은 방사 줄 하나)을 얹어 회전이 보이게 한다.
- **헐거운 발톱 링**(A·B 각각 자기 기어의 자식): `clawRing({ teeth: 4, rIn: 0.07, rOut: 0.115, base: 0.12, tooth: 0.04, frac: 0.34, phase: 0 })`, 기어 로컬 원점(피치원 평면)에 둔다. → 목통 x = ∓0.42 ~ ∓0.30, 발톱 끝 ∓0.26. 기어와 같이 돌고(축 위에서 헐겁게), 발톱 중심의 실제 각 ρ(+Y 에서 +Z 쪽으로 잰 각)는 A: **θ + j·π/2**, B: **−θ + j·π/2**.
- **이중 클러치**: `doubleClutch()`(발톱 끝 ±0.20, 몸통 ±0.16, 반지름 0.115, 홈 반폭 0.025·바닥 0.09), 그룹 위치 (s, 1.55, 0.28), `rotation.x = β`. 발톱 중심각 = **β + π/4 + j·π/2** (걸림 링의 발톱 사이 홈 가운데). 가로축의 깃(키) 위를 미끄러진다.
- **요크**(판화에 없음, 보충): `shiftYoke({ grooveR: 0.09, ringW: 0.04, slotDrop: 0.22, slotLen: 0.07 })` 위치 (s, 1.55, 0.28). 반고리가 홈 아래쪽을 두르고, 팔판이 아래로 내려가 슬롯 중심이 y = 1.33.
- **벨 크랭크**(name `bellCrank`): `shiftBellCrank(0.25, 0.25)` 받침점 P = (0, 1.08, 0.31), `rotation.z = −φ`, φ = asin(s / 0.25) (±22.3°). 세로 팔 끝 핀 = (s, 1.08 + 0.25 cos φ) 은 요크 슬롯 속(요크 팔판 z 0.265~0.295, 크랭크 판 z 0.295~0.325 이웃)에서 위아래로 0.019 미끄러진다. 받침점 뒤 받침 보 `pivotBeam(0.54)` 위치 (0, 1.08, 0.24). 판화처럼 받침점이 두 기어 사이, 가로축 조금 아래에 온다.
- **당김 막대**(name `pullRod`): `pullRod(0.6)` 위치 = 가로 팔 끝 핀 E = (−0.25 cos φ, 1.08 + 0.25 sin φ, 0.345) — 크랭크와 **같은 φ 에서 계산**. 늘 세로로 서서 ±0.095 오르내린다(아래 끝 y 0.385~0.575). 막대가 **올라가면**(φ > 0) 클러치가 오른쪽(B 쪽)으로 간다. 아래 끝 가로 손잡이는 판화에 없음(판화는 막대가 끊김).
- 구동 표시: 세로축 위쪽 `rotArrow(0.22, true)`(XZ 평면 눕힘: `rotation.x = −π/2`, 중심 (0, 2.75, 0.28))는 항상 표시(C 는 +Y 둘레로 반시계, 위에서 본 방향). 오른쪽 끝 화살표는 가로축 상태를 나타냄: 표시 위치 중심 (0.80, 1.55, 0.28), `rotation.y = +π/2`(YZ 평면, +X 쪽에서 봄). β 증가(정방향) → `rotArrow(0.2, true)`(반시계), β 감소 → `rotArrow(0.2, false)`, 정지 → 둘 다 숨김.

## 동작식 (모든 값은 theta 의 함수. 이 운동은 상태 누적 없이 닫힌 식으로 계산)
- 주기 Θ = 7π(약 13.7 s @OMEGA). φ = theta mod 7π (음수 theta 면 양의 나머지로).
- **기어**(정확한 1:1, 크기 같음): 세로축 C 는 +Y 둘레 `ψ = theta + π − π/20`. A 는 +X 둘레 `ρA = theta + π/2`, B 는 +X 둘레 `ρB = −theta − π/2`. 속도비 A : C : B = 1 : 1 : 1 이고 A 와 B 는 서로 반대로 돈다.
  - 맞물림 위상(판화 대로 이 맞물림, 침범 0 확인): 중심선 접점에서 **A·B 는 이, C 는 이골**. 위 식이 그 위상이다(반 피치 π/20 을 C 에만 넣음).
  - 접점 속도 일치: C 의 +Y 둘레 ω 가 A 의 +X 둘레 ω 와 같고 B 는 −ω.
- **클러치 위치 s**(x 방향, 중립 0, 왼쪽 걸림 −0.095, 오른쪽 걸림 +0.095), v = 0.095/(π/4) ≈ 0.121 /rad:

| φ 구간 | 하는 일 | s | 가로축 β |
|---|---|---|---|
| 0 ~ 2π | A 걸림(정회전) | −0.095 | A 와 함께 |
| 2π ~ 2.25π | A→중립 이동 | −0.095 + v(φ−2π) | 이동 시작 직후 A 를 놓고 정지 |
| 2.25π ~ 3.25π | **중립(정지)** | 0 | 정지 |
| 3.25π ~ 3.5π | 중립→B 이동 | v(φ−3.25π) | 정지 → B 걸리면 B 와 함께 |
| 3.5π ~ 5.5π | B 걸림(역회전) | +0.095 | B 와 함께 |
| 5.5π ~ 5.75π | B→중립 이동 | 0.095 − v(φ−5.5π) | 놓고 정지 |
| 5.75π ~ 6.75π | **중립(정지)** | 0 | 정지 |
| 6.75π ~ 7π | 중립→A 이동 | −v(φ−6.75π) | A 걸리면 A 와 함께 |

- 걸림 판정: **s ≤ −0.06 이면 A 걸림, s ≥ +0.06 이면 B 걸림, 그 사이는 놓임**(발톱 끝 −0.26·+0.26 에 클러치 끝 ∓0.20 + s 가 닿는 값). 놓이는 순간 가로축은 **즉시 멈춘다**(제동으로 설명).
- **가로축 각 β**(+X 둘레, 닫힌 식. a = 0.035/v = 0.289 rad, b = 0.06/v = 0.496 rad, d1 = 2π + a, y = 3.25π + b, d2 = 5.5π + a, x = 6.75π + b):
  - φ ≥ x (이전 주기 끝 A 걸림): β = φ − 7π
  - φ ≤ d1 (A 걸림): β = φ
  - d1 < φ < y (중립1): β = d1 (고정)
  - y ≤ φ ≤ d2 (B 걸림): β = 5.5π − φ (= d1 + y − φ)
  - d2 < φ < x (중립2): β = −0.0921π (= d1 + y − d2, 고정)
  → β 는 **연속**이고 −0.289 ~ +6.57 rad 안에서 앞뒤로 흔들린다. 이 식이면 클러치가 걸리는 순간 발톱이 정확히 홈 가운데에 겹친다(β − θ 와 β + θ 가 걸릴 때마다 π/2 의 정수배).
  - **방향 정의**: β 가 늘어나는 구간 = **정방향**(A 와 같은 방향), 줄어드는 구간 = **역방향**(B 와 같은 방향).
- 시프트 연동: 클러치·요크 위치 x = s, 벨 크랭크 기울기 `−asin(s/0.25)`(세로 팔 끝 x = s), 당김 막대 위치 = 가로 팔 끝 핀 E. 요크 슬롯 안에서 끝 핀이 위아래로 최대 0.019 미끄러진다(슬롯 길이 0.07 안).
- 부품 자세 한 장 요약: A pivot.x = theta + π/2, B pivot.x = −theta − π/2, C pivot.y = theta + π − π/20, 가로축 rotation.x = β, 클러치 위치 x = s 와 rotation.x = β, 헐거운 링은 기어 자식이라 기어와 함께.
