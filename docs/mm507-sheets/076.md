# 076 회전 수 계수기 (2)
판화(public/mm507/fig/076.png, 4배 확대 shots/_verify/076-fig-x4.png · 탭핏 8배 shots/_verify/076-crop-tappet.png · 바퀴 6배 shots/_verify/076-crop-wheel.png 로 다시 읽음): 그림 하나, 축 방향에서 본 정면. 왼쪽에 톱니(래칫) 바퀴 A(이 약 20개, 깊고 갈고리진 이, 가운데 이중 원 = 축과 허브, 반시계 화살표). 왼쪽 위 바퀴 밖에 고정 핀(이중 원)과 거기서 왼쪽 아래로 누운 굽은 **멈춤 폴**(글자 없음). 오른쪽에 **큰 바퀴의 일부**: 넓은 테의 토막(양 끝이 찢긴 선, 바깥 가장자리는 굵은 선)과, 그 테에서 A 의 중심 쪽으로 곧게 뻗은 **살 하나**(나란한 두 선, A 뒤로 사라짐). 테의 바깥 가장자리 원을 맞춰 보면 중심이 A 의 중심과 겹친다(바깥 가장자리 300점 원 맞춤: 맞춘 원의 가운데가 x 157·y 193 px, A 허브는 x 140·y 190 px, 반지름 296 px ≈ A 의 2.3배) → 큰 바퀴는 A 와 같은 축에 있고 A 는 그 앞에 있다. 테 위에 작은 원 **D**(스터드), 테 아래쪽에 시계 방향 화살표. 살 아래에 양 끝이 둥근 **막대(탭핏의 몸)**: 가운데 오른쪽에 작은 원 **C**(고정 받침), 오른쪽 끝은 테 위까지 겹쳐 나가 있고(스터드가 지나는 자리), 왼쪽 둥근 끝에는 회색 핀과 그 끝을 감싼 **꺾이는 끝 B**(윗변은 막대 윗변과 한 직선, 왼쪽 위 모서리 = 코끝이 A 의 이끝 바로 밑, 아래로 둥근 배가 처짐, 막대 속으로 들어간 혀는 점선)가 달려 있다.
원문 요지: 회전 수를 세는 또 다른 장치. 고정 받침 C 에 얹힌 탭핏 B 를, 큰 바퀴(일부만 그림)에 박힌 스터드 D 가 큰 바퀴 한 바퀴마다 한 번 친다. 그러면 탭핏의 톱니 바퀴 쪽 끝이 들려 바퀴 A 를 이 하나만큼 돌린다. 스터드가 지나가면 탭핏은 제 무게로 돌아오는데, 톱니 바퀴의 이를 지나갈 수 있게 끝이 이음(관절)으로 되어 있다.

★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 2개. 큰 바퀴(테와 살, 일부만 그림, 바깥 반지름 ≈ A 의 2.3배) > 톱니 바퀴 A(이 약 20개, 이 깊이 ≈ 반지름의 15~20%). 둘은 중심이 같다(위 원 맞춤과 살의 방향).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 겹침: A 가 큰 바퀴의 살 앞, 탭핏 막대의 오른쪽 끝이 큰 바퀴 테 앞.
4. 고정점은? → 탭핏의 받침 C(원문 "fixed pivot"), 멈춤 폴의 핀(왼쪽 위). 둘 다 큰 바퀴의 테 안쪽 빈 곳에 있어 큰 바퀴 **앞**에서 받쳐야 한다. 받치는 틀은 판화에 없음.
5. 추·손잡이·크랭크는? → 없음. 구동은 큰 바퀴(등속 회전). 탭핏은 제 무게로 돌아온다(B 의 둥근 배가 추 구실).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → A 의 바깥 둘레에 톱니. 오른쪽(약 −5°)에서 탭핏의 끝 B 가 아래에서 위로 이끝을 들어 올린다 → A 는 반시계(화살표). 왼쪽 위(약 140°)에서 멈춤 폴 끝이 이에 걸려 되돌아가지 않게 한다. 곧은 면은 시계 쪽(오른쪽에서는 아래)을 본다. 큰 바퀴에는 이가 없다.
7. 한 줄에 놓인 것은? → B 의 윗변과 막대의 윗변이 한 직선. 받침 C 는 A 의 중심과 거의 같은 높이의 오른쪽(약 −4°). 큰 바퀴의 살은 A 의 중심을 향한다.
8. 글자가 가리키는 부품은? → A = 톱니 바퀴, B = 탭핏(글자는 꺾이는 끝 위에), C = 고정 받침 핀, D = 큰 바퀴의 스터드(원문과 같다).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 있다(치수만 — 아래 난도·질문 절). 판화의 치수 그대로면 스터드(반지름 267 px 의 원)가 막대의 한가운데(받침에서 32 px, 막대 끝은 52 px)를 지나므로 막대를 약 75° 나 눌러야 빠져나가고 이를 3개쯤 넘긴다 — 원문은 "이 하나". 모형은 스터드가 막대 끝만 스치게 치수를 줄여 정확히 이 하나를 넘긴다. 기구의 구성은 판화 그대로다.
- 그 밖의 선: A 오른쪽 이에서 B 의 코끝으로 내려오는 가는 선 = 이의 비스듬한 등(탭핏의 일부가 아님). 살 아래의 네모난 빈칸 = 살·테 안쪽 가장자리·막대 윗변·이의 등으로 둘러싸인 빈 곳(판이 아님). B 와 막대 사이의 굵은 초승달 = 막대의 둥근 끝을 감싼 이음 자리.

## 구동
큰 바퀴가 시계 방향으로 등속 회전. theta += OMEGA·speed·dt (OMEGA = 1.6 rad/s), **큰 바퀴가 돈 각 ang = theta/2**(0.8 rad/s, 한 바퀴 7.85초 — 스터드가 탭핏을 치는 순간이 짧아 반으로 늦춤). 모든 자세는 `makeCounter(SPEC, TAP).state(ang)` (k074) 한 번으로 정한다.

- 밀리는 이의 면 각: 쉼 −4.54° → 꼭대기 17.51° (22.05° 이동 = 피치 18° + 헛걸음 4.05°). 처음에는 B 의 윗변이 이끝을 들어 올리고(β < 약 7°), 그 뒤로는 코끝 N 이 곧은 면을 민다(N 의 반지름 0.516 → 0.593, 늘 이뿌리와 이끝 사이).
- 침범: 꺾이는 끝 × 톱니 0.0006(풀이 허용값), 멈춤 폴 × 톱니 0.0013, 스터드 × 막대 0.0000. 돌아갈 때 B 가 꺾이는 각 최대 20.2°. 쉬는 동안 꺾임 0°.
- 받침을 반지름 1.02 로 당기면 B 가 돌아갈 때 62° 까지 꺾이고(측정), 막대를 판화처럼 14° 로 세우면 스터드가 막대 끝 아래로 들어와 누르지 못한다(계산: 들어오는 방향이 막대 방향보다 낮아짐) → 위 값으로 정했다.

## 동작 (모든 자세는 ang 의 절대 함수 — `makeCounter(SPEC, TAP)` 가 돌려준 counter.state(ang))
- u = ang mod 2π, 바퀴 수 n = floor(ang/2π). 스터드 극각 st.studAngle = counter.studStart − u (studStart = 33.98° — 위상 0.6 rad 에서 막대에 닿게 맞춤).
- u < 0.6000: 쉼(β = 0, w = 0). 0.6000 ≤ u ≤ 0.6943: 스터드가 막대를 누름 — β = `tappetBeta(TAP, studAngle)`, 톱니 바퀴가 나아간 각 w = max(0, `tappetFaceAngle(TAP, 0.60, β)` − phiRest), 꼭대기(u = 0.6867) 뒤로는 w = q. u > 0.6943: 막대가 0.30 rad 동안 부드럽게(x²(3 − 2x)) 제자리로 — β = 22.0°·(1 − 부드러운 x), w = q.
- phiRest = `tappetFaceAngle(TAP, 0.60, β최대)` − q = −0.4876° 로 잡으므로 **한 바퀴에 정확히 이 하나(18°)** — 누적 오차 없음. st.wheel = phiRest + q·n + w.
- 막대 st.psi = 6° − β. 이음 핀 st.h = c − 0.206·(cos psi, sin psi).
- 꺾이는 끝: st.kappa = `noseFold(SPEC, st.wheel, counter.noseOutline, st.h, st.psi)` — 톱니에 박히지 않는 가장 작은 꺾임 각. 미는 동안은 0(막대와 한 몸), 돌아가는 동안 아래 이의 등에 얹혀 20° 까지 꺾였다가 이끝을 지나면 0 으로 떨어진다.
- 멈춤 폴: 바퀴가 도는 동안 이 등에 밀려 들렸다가 이끝이 지나면 떨어진다(`followerAngle`).
- 모델은 위 경우를 나누어 다시 짜지 않는다 — counter.state(ang) 의 값을 그대로 옮긴다.

★ 난도·질문
난도 B (Sonnet). 접촉 풀이(스터드 × 막대, 윗변·코끝 × 이, 꺾임, 멈춤 폴)와 시간표가 모두 k074 의 `makeCounter` 에 있어 모델은 부품을 놓고 값을 옮기면 된다. 다만 겹친 층이 많아 GLM(A)에는 주지 않는다. 눈 검증은 Opus 가 t = 0.82·1.05 근접을 꼭 본다.
질문: 보류는 아님(기구는 판화·원문으로 확정). 사용자가 보면 좋은 것 두 가지 —
- (가) 큰 바퀴를 톱니 바퀴 A 와 **같은 축**에 두었다(판화의 테 원과 살의 방향으로 판정). 판화가 "일부만" 그렸으므로 큰 바퀴의 축이 A 와 다른 곳(더 왼쪽)일 여지가 조금 있다. 그 경우에도 탭핏·스터드의 동작은 같고 큰 바퀴의 자리만 달라진다.
- (나) 판화 치수대로면 한 번에 이 3개쯤 넘어간다(판화 읽기 9번). 원문 "이 하나"에 맞춰 스터드가 막대 끝만 스치게 줄였다(받침 방향 −4° → −3°, 막대 기울기 14° → 6°, 스터드 반지름 자리 1.23 → 1.38, 테 1.15~1.40 → 1.16~1.45).
