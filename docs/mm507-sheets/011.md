# 011 안내 풀리 없는 직각 전동
판화: 위에 **수평축의 폭 넓은 드럼**(양옆으로 축이 삐죽 나옴, 지름 ≈ 폭), 그 아래 **종이 면에 수직인 축**의 풀리(드럼과 크기 비슷, 중심은 드럼보다 조금 오른쪽). 벨트는 안내 풀리 없이 드럼 왼쪽 부분에서 내려오는데, 왼쪽 가닥은 거의 수직으로 풀리 왼쪽 가장자리에, 오른쪽 가닥은 비스듬히 풀리 오른쪽 가장자리에 닿는다(벨트가 1/4 비틀려 있다). 원문: 004(3번)와 같은 결과(직각인 두 축 사이 전동)를 안내 풀리 없이 얻는다.
구동: 위 드럼(한 방향 회전).
**읽기**: 드럼은 구동, 풀리는 종동. 벨트가 드럼 위 반 바퀴(위쪽 반원)를 감고 두 가닥이 내려가 풀리 아래 반 바퀴를 감는다 — 가장 그럴듯한 해석.

## 부품과 치수
- `displayStand()`
- 드럼 D: 중심 (0, 2.7), z = 0.25, **회전축 X**, 반지름 0.36, 폭 0.72. `pulley(0.36, { width: 0.72, spokes: 4, driver: true })` 를 감싸는 그룹 `drumPivot` 에 `rotation.y = π/2` 를 주어 로컬 Z 가 월드 X 가 되게 한다(007 의 축 X 풀리와 같은 방식). 안쪽 풀리의 `rotation.z` 가 곧 X축 회전.
- 드럼 축: `rod(V3(-0.56, 2.7, 0.25), V3(0.56, 2.7, 0.25), 0.04)`(양 끝이 드럼 밖으로 0.2 삐죽). 받침 `pillow(-0.46, 2.7, 0.25, 'x')`, `pillow(0.46, 2.7, 0.25, 'x')`.
- 풀리 P: 중심 (0.15, 0.72), z = 0.25, 회전축 Z, 반지름 0.40. `pulley(0.40, { spokes: 4 })` + `shaftZ(0.15, 0.72)`.
- 벨트(폭 0.12, 두께 0.02): 3D 점열을 직접 만든다. 벨트 중심선 반지름 Rd = 0.37(드럼), Rp = 0.41(풀리), 드럼 위 벨트 x 위치 bx = −0.26 (= 풀리 왼쪽 접점 x = 0.15 − 0.41 → 왼쪽 가닥이 수직에 가깝다).
  ① 드럼 호(24 구간): φ = π·i/24, i = 0..24 → `(bx, 2.7 + Rd·sinφ, 0.25 + Rd·cosφ)`. i=0 이 앞(z=0.62), i=24 가 뒤(z=−0.12). 위쪽 반원.
  ② 오른쪽 가닥: 뒤 끝점 (−0.26, 2.7, −0.12) → 풀리 오른쪽 점 (0.56, 0.72, 0.25), 사이를 균등 10점(양 끝점 제외).
  ③ 풀리 호(24 구간): ψ = −π·i/24, i=0..24 → `(0.15 + Rp·cosψ, 0.72 + Rp·sinψ, 0.25)`. 오른쪽(0.56, 0.72)에서 아래를 돌아 왼쪽(−0.26, 0.72)까지.
  ④ 왼쪽 가닥: (−0.26, 0.72, 0.25) → 앞 끝점 (−0.26, 2.7, 0.62), 사이 균등 10점(양 끝점 제외).
  닫힌 벨트(앞 → 위 → 뒤 → 오른쪽 가닥 ↓ → 풀리 아래 → 왼쪽 가닥 ↑ → 앞). 뒤 끝 z = −0.12 는 뒤판 앞(−0.30)보다 앞이다.
  **띠 폭 방향**(004 의 `widthDirs`): ① 의 모든 점 (1,0,0), ③ 의 모든 점 (0,0,1). ②는 (1,0,0) → (0,0,1), ④는 (0,0,1) → (1,0,0) 으로 점마다 선형 보간한 뒤, 각 점에서 **그 점의 진행 접선 성분을 빼고 정규화**(그램-슈미트)해서 쓴다 — 이것이 벨트의 1/4 비틀림이다.

## 키트 추가
없음. `BeltOpts.widthDirs` 는 004 에서 선언한 것을 쓴다.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- 드럼: 안쪽 풀리 `rotation.z = −theta` (위쪽 벨트가 앞 → 뒤로 흐른다. 월드 +X 회전은 맨 위 점을 +Z 로 보내므로 부호가 −).
- 풀리 P: `rotation.z = −theta × Rd / Rp` (시계 방향, 벨트 속도 일치).
- 벨트 표시: `belt.setOffset(theta × Rd)` (진행 방향 = ①→②→③→④).

## 표시
- 드럼 옆(x = 0.7)에 `rotArrow(0.45, …)` 을 YZ 평면에 눕혀(`rotation.y = π/2`) 드럼 회전 방향을, 풀리에 `rotArrow(0.55, false)`(시계). tag '구동 드럼', '종동 풀리', '비틀린 벨트'(오른쪽 가닥 중간 근처).
- notes: `[{ label: '축의 관계', value: '직각 (안내 풀리 없음)' }, { label: '벨트', value: '1/4 비틀림' }, { label: '속도비(드럼 : 풀리)', value: '1 : ' + (Rd/Rp).toFixed(2) }]`
- view: `{ pos: [1.4, 2.1, 5.6], target: [0, 1.7, 0] }` (비틀림이 보이도록 약간 비스듬히).

## 확인
- 정면 t=1, t=2.5: 드럼 표시점(옆면)·풀리 스포크가 돌았고 벨트 표시가 두 가닥에서 위 → 아래(오른쪽), 아래 → 위(왼쪽)로 흐른다. 왼쪽 가닥은 거의 수직, 오른쪽 가닥은 비스듬하다.
- 비스듬히 `cam=2.2,1.6,3.6,0,1.7,0`: 띠가 드럼 위에서는 가로(축 방향)로 눕고 풀리 위에서는 세로로 서서 사이에서 비틀린다. 풀리 앞면과 가닥이 겹쳐 박히지 않는다.
