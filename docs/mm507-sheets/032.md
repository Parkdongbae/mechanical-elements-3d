# 032 마찰 바퀴
판화: 맞닿은 매끈한 원판 둘, 왼쪽이 작고 오른쪽이 크다(지름비 약 0.58). 둘 다 테두리에 이중선(타이어)과 가운데 둥근 허브.
구동: 작은 바퀴(반시계). 큰 바퀴는 반대로 돌고 테두리 속도가 같다.

## 부품과 치수
`frictionWheel`(키트 추가), `shaftZ`, `rotArrow`, `tag`.
- 구동: `frictionWheel(0.7, { driver: true, holes: 5 })` 중심 (−1.2, 1.75). 피동: `frictionWheel(1.2, { holes: 7 })` 중심 (0.7, 1.75). 중심 거리 1.9 = 0.7 + 1.2, 접점 x = −0.5. z = 0.15, 폭 0.16(고무 타이어 두께 0.05).
- 축 `shaftZ(…, 0.36, 0.07)`.

## 동작
θ += OMEGA·speed·dt. 작은 바퀴 `rotation.z = θ`, 큰 바퀴 `rotation.z = −θ·0.7/1.2` (속도비 = 지름비, 방향 반대).

## 표시
rotArrow(0.45, ccw), rotArrow(0.75, cw). tag '구동 바퀴', '피동 바퀴', '마찰 접촉'. notes: 지름비, 속도비 1.7배, 방향 반대.

## 확인
- 두 시점에서 노란 표시선: 작은 바퀴는 반시계, 큰 바퀴는 시계로 0.58배만큼.
- 두 타이어가 접점(−0.5, 1.75)에서 정확히 접하고 겹치지 않는다.
