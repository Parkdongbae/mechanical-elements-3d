# 145 빔과 크랭크, 플라이휠
원문: "Reciprocating curvilinear motion Of the beam gives a continuous rotary motion the crank and fly-wheel. The small standard at the left. to which is attached one end of the lever with which the beam is connected by the connecting-rod, has a horizontal reciprocatincr rectilinear movement." — 빔(지렛대)의 왕복 곡선 운동이 크랭크와 플라이휠(관성바퀴)에 연속적인 회전 운동을 준다. 레버 한 끝이 붙는 작은 받침대는 수평 왕복 직선 운동을 한다(reciprocatincr 은 reciprocating 의 오탁).
판화 묘사: 왼쪽에 살 4개의 큰 플라이휠이 서 있고, 바닥의 빗금이 바퀴 아래를 반원으로 파고 든다(구덩이). 바퀴 가운데 허브에서 왼쪽으로 조금 떨어진 자리에 작은 원 하나 = 크랭크 핀. 그 핀에서 오른쪽으로 곧은 **레버**가 수평으로 뻗어 오른쪽의 종 모양 **작은 받침대** 꼭대기 핀에 닿는다. 레버 한가운데(바퀴 오른쪽)에서 **연결봉**이 세로로 서서 위의 **빔** 왼쪽 끝 눈에 닿는다. 빔은 거의 수평으로 오른쪽으로 길고 오른쪽 끝에 빗금 친 굵은 원 = 고정 받침 축. 판 위쪽 가장자리에 번호 145. 글자는 없다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 기준 px, 비 1 px = 0.002 로 읽음(아래 [x·y] 는 4배 그림의 px).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 하나. **플라이휠** 1개(중심 [540·1070], 반지름 440, 넓은 테 두께 약 100, 살 4개, 허브 반지름 약 60). 크기 차례는 묻지 않을 것 — 유일한 바퀴다.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 대신 막대 셋: ① **레버**(크랭크 핀 [390·1075] → 받침대 핀 [1500·1080], 길이 약 1100, 가운데 연결봉 자리가 A 에서 약 630) ② **연결봉**(레버의 가운데 점 [1020·1080] → 빔 끝 눈 [1020·255], 길이 약 825, 판화 순간엔 수직) ③ **빔**(받침 축 [1640·260] → 끝 눈 [1020·255], 팔 약 625, 축 뒤로 꼬리 약 120).
3. 교차하는 가닥이 있는가, 어디서? → 줄 가닥은 없다. 겹침 차례: 레버가 바퀴 오른부분(허브와 테 사이의 살) **앞**을 수평으로 지나간다(레버 선은 이어지고 바퀴 살·테 선이 레버에서 끊긴다). 연결봉은 바퀴 오른 가장자리 밖(불 [1020] 은 테 오른 끝 [980] 보다 오른쪽)을 지나 앞에서 겹치지 않는다.
4. 고정점(천장·벽·바닥)은 어디인가? → 바닥 빗금선과 그 위에 선 받침대, 바퀴 축과 빔 받침 축(둘 다 빗금 원 = 단면으로 그린 고정 축, 틀 뒤에 받혀진다). 바퀴 축 [540·1070], 빔 받침 축 [1640·260].
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 = 바퀴 허브 옆의 핀(바퀴 중심에서 약 150, 판화 순간엔 왼쪽 9시 방향). 추·손잡이 없음. 구동은 빔(원문 "Reciprocating curvilinear motion of the beam") — 빔이 오르내리면 연결봉 → 레버 → 크랭크 핀의 차례로 바퀴가 밀린다.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 물리는 짝은 핀 넷: 크랭크 핀 ↔ 레버 왼 끝 구멍, 받침대 핀 ↔ 레버 오른 끝 구멍, 레버 가운데 핀 ↔ 연결봉 아래 구멍, 빔 끝 핀 ↔ 연결봉 위 구멍. 맞물림 대신 핀 구멍(눈)들이다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 판화 순간: 크랭크 핀 [1075] · 레버 축선 [1075~1080] · 바퀴 중심 [1070] · 받침대 핀 [1080] 이 같은 높이의 한 수평선(레버가 수평). 연결봉 아래 점 [1020·1080] 과 빔 끝 눈 [1020·255] 이 같은 세로선(연결봉이 수직). 빔 받침 축과 끝 눈은 거의 같은 높이([260] vs [255] — 빔이 거의 수평).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 145 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 원문과 같다. 두 가지 읽음: ① 원문은 받침대가 "왼쪽"이라 하나 판화의 받침대는 레버의 **오른쪽**(바퀴의 오른쪽)에 있다 — 좌우가 뒤집혔을 뿐 기구는 같으므로 판화를 따라 오른쪽에 둔다. ② 원문 문장 "받침대는 수평 왕복 직선 운동을 한다"는 판화로는 안 보이지만 꼭 필요한 조건이다 — 받침대 핀이 고정이면 빔·연결봉·레버·크랭크 루프가 4절 구조로 막혀(3n−2j 를 세우면 0) 전혀 움직이지 못하고, 받침대가 가로로 미끄러져야 1자유도가 되어 계속 돈다. 질문 거리 없음.
- 그 밖의 선: 바퀴 아래의 반원 파인 빗금 = 바닥의 구덩이(테가 빠져 들어간다). 허브의 두 겹 원 = 축 끝과 허브. 받침대의 종 모양 윤곽과 넓은 발판 = 미끄럼 받침대. 빔 오른 끝의 빗금 원 = 고정 축 단면(빔이 여기서 흔들린다). 연결봉·레버의 작은 원 = 핀 눈.

## 해석(결정 사항)
- 판화 비(1 px = 0.002): 바퀴 반지름 440 → 0.88, 크랭크 145 → 0.29, 레버 1100 → 2.2, 연결봉 자리 630 → 1.26, 연결봉 825 → 1.65, 빔 팔 625 → 1.25 — 모형은 이 비를 그대로 쓴다(`K145`).
- 판화의 순간(핀이 9시, 레버·연결봉·빔이 모두 수평·수직)을 t = 1 자세로 삼는다.
- 회전 방향은 판화에 없다 → 크랭크·플라이휠 반시계. 구동은 원문대로 빔이지만, 닫힌 루프(1자유도)라 어느 쪽을 등속으로 돌려도 자세가 같다 — 모형은 플라이휠의 관성(등속 반시계)을 구동으로 본다(원문 "플라이휠이 회전을 매끄럽게 유지한다" 뜻과 같다).
- 원문의 "왼쪽 받침대" → 판화대로 오른쪽에 둠(판화 읽기 9번). 받침대가 미끄러지는 것은 원문 문장 그대로.
- 판화에 없는 보충: 뒤판의 두 축 보스, 바닥 단 위의 안내 레일 2줄(왕복 받침대가 떠 있지 않게), 공통 받침대.

## 구동
플라이휠 + 크랭크 팔(등속 반시계). theta += OMEGA(1.6)·speed·dt, 크랭크 각 phi = theta − 1.6 + π(t = 1 에 phi 가 π — 핀이 왼쪽 9시, 판화 자세). 한 주기 2π rad = 3.93 s. 레버·연결봉·빔·받침대가 종동하고 받침대는 한 주기에 한 번 왕복한다. 모든 자세는 `beamCrank145(theta)` 의 닫힌 식 — 한 주기를 정확히 닫는다.

## 동작 (모두 theta 의 닫힌 식 — `beamCrank145(theta)` 가 돌려준다)
A = `beamCrank145(theta)` → { phi, A, B, M, E, leverAngle, rodAngle, beamAngle, s }.
- 크랭크·플라이휠: `flywheel.rotation.z = A.phi`, `crank.rotation.z = A.phi` = theta − 1.6 + π(반시계). 핀 = 바퀴 중심에서 0.29 의 원.

- 연결봉: `rod.position.set(M.x, M.y, 0.21)`, `rod.rotation.z = A.rodAngle`(90°~110.4° — 늘 세로에서 오른쪽으로 기울어진다).
- 빔: `beam.rotation.z = A.beamAngle`(175.5°~187.8° — 수평에서 ±6.2° 오르내린다), 끝 E 의 높이 2.59~2.86(행정 0.27).
- 받침대: `standard.position.x = B.x`(1.06~1.64, 행정 0.58 = 크랭크 반지름의 2배), y 1.1 고정. 핀이 9시(s 0)일 때 왼쪽 끝, 3시(s 1)일 때 오른쪽 끝 — 크랭크 한 바퀴에 한 번 왕복.
- 시각: **t = 1 (핀 180°, 레버 수평, 연결봉 수직, 빔 180.5°, 받침대 왼쪽 끝 — 판화 자세)**, **t = 1.6 (핀 235°, 레버 6.2°, 연결봉 93.9°, 빔 185.3°, 받침대 1.171·s 0.19)**, t = 30 (theta 48 = 7주기 + 0.64주기, 핀 318.5°, 받침대 1.559·s 0.86, 빔 187.7°).
