# 003 안내 풀리로 직각 전동
판화: 오른쪽 위에 수평축 풀리, 왼쪽 위에 안내 풀리(작은 것 2개가 나란히), 왼쪽 아래에 벨트가 감긴 드럼. 원문: 안내 풀리를 써서 한 축의 운동을 그와 직각인 축으로 전달한다. 안내 풀리는 벨트의 두 가닥에 하나씩, 나란히 2개다.
난도: 높음(벨트 경로가 평면이 아니다).

## 부품과 치수
- `displayStand()`
- 풀리 P(구동) r = 0.42, 중심 (1.0, 2.6), 회전축 Z, z = 0.2. `shaftZ(1.0, 2.6)`.
- 안내 풀리 G1, G2: r = 0.16, 회전축 Z, 중심 (-0.75, 2.75), z = 0.10 과 z = 0.30 (나란히 2개, 각자 자유 회전). 공통 축 `shaftZ(-0.75, 2.75, 0.5)`.
- 드럼 D(종동): 반지름 0.38, 길이 0.5 의 원통, **회전축 = X**(P 의 축과 직각), 중심 (-0.85, 1.05, 0.20). 양쪽에 `pillow(...)` 2개로 받치고 받침대에 세운 기둥 2개에 얹는다. 드럼 끝면에 스포크/표시점.
- 벨트(3D 경로, 폭 0.12): P 의 윗가닥이 왼쪽으로 가 G1 을 넘어(z = 0.10) 아래로 내려가 드럼 **앞쪽**(z = 0.20 + 0.38)에서 드럼을 반 바퀴 감고 **뒤쪽**(z = 0.20 − 0.38)으로 올라와 G2(z = 0.30… 뒤쪽 가닥은 G2 대신 z 를 맞춰) 를 넘어 P 의 아랫가닥으로 돌아간다.
  구현: 경로 점열을 직접 만든다 — ① P 둘레 호(오른쪽 반 바퀴) ② P→G 직선 2가닥 ③ G 둘레 1/4 호(수평 → 수직) ④ 수직 하강 구간에서 z 를 0.10→+0.58, 0.30→−0.18 로 부드럽게 벌림 ⑤ 드럼 아래쪽 반원(YZ 평면, 반지름 0.39). 띠가 꼬이는 구간(④)은 `Belt` 가 접선 기준으로 폭 방향을 보간한다.

## 동작
- P.rotation.z = theta. 벨트 속도 v = theta' × 0.42.
- 드럼: 회전축 X, 각 = theta × 0.42 / 0.38 (방향은 벨트 앞가닥이 내려가는 쪽과 일치).
- G1, G2: 각 = ±theta × 0.42 / 0.16 (서로 반대 방향).
- `belt.setOffset(theta * 0.42)`.

## 표시
- tag '구동 풀리', '안내 풀리', '종동 드럼(직각 축)'. notes: `[{ label: '축의 관계', value: '직각' }, { label: '안내 풀리', value: '2개' }]`

## 확인
- 기본 시점 + 옆(cam=4.5,2.2,2.0,0,1.7,0) 캡처에서 벨트가 드럼을 감고 두 가닥이 각각 다른 안내 풀리를 지난다. 드럼이 X축으로 돈다.
