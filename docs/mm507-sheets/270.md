# 270 풀리용 마찰 줄이는 받침
원문(en): "Anti-friction bearing for a pulley." — 풀리를 위한 마찰 방지 베어링.
쉬운 풀이: 풀리 가운데 구멍과 고정 축 사이에 작은 롤러 6개를 둥글게 끼워, 풀리가 축 위에서 미끄러지지 않고 롤러 위에서 구르게 한다. 롤러는 축(고정)과 풀리 구멍 양쪽에 닿아 구르므로, 풀리가 1 돌 때 롤러 묶음(우리)은 0.737, 롤러 하나하나는 1.556 만큼 돈다.
판화 묘사(원본 477×449 px, **정면 두 그림**): 왼쪽 풀리(중심 ≈ [140·240], 바깥 반지름 ≈ 95 px) — 앞판에 작은 구멍 6개가 원(반지름 ≈ 33 px)으로, 가운데에 별 모양(축과 롤러 끝이 보이는 구멍), 왼쪽 위에 반시계 화살표. 오른쪽 풀리(중심 ≈ [360·240], 같은 크기) — 앞판을 뗀 모습: 가운데 축(반지름 ≈ 21 px)을 같은 크기 롤러 6개(반지름 ≈ 21 px, 가운데 점 = 롤러 핀)가 빙 둘러 풀리 구멍(≈ 63~70 px)을 채움. 두 풀리 모두 줄(꼬인 밧줄 무늬)이 양옆으로 곧게 내려감(위를 반 바퀴 감음). 오른쪽 끝 세로선 [460](벽 또는 판화 테두리).

## ★ 판화 읽기
판화 둘(같은 풀리의 앞판 있는 모습·뗀 모습)을 나란히 둔 그림. 판화 1 px ≈ 0.0067(풀리 바깥 95 px = 0.64), 두 중심 거리 220 px → 1.70.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 같은 풀리 2개(바깥 0.64, 홈 바닥 0.578). 풀리마다 롤러 6개(0.1345) + 고정 축(0.15).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 풀리마다 밧줄 1: 왼쪽 가닥(아래 손잡이)에서 올라와 풀리 위를 시계 방향으로 반 바퀴 감고 오른쪽 가닥(아래 추)으로 내려감.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은? → 두 고정 축(뒤판에서 나온 굵은 축, 돌지 않음). 판화 오른쪽 세로선은 판화로는 알 수 없음(모델에 넣지 않음).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에서 줄 끝은 잘려 있음. 보충: 풀리마다 왼쪽 가닥 끝에 손잡이(줄끝), 오른쪽 가닥 끝에 추.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음. 롤러가 안쪽은 고정 축 바깥면(0.15), 바깥쪽은 풀리 구멍 안쪽 면(0.42)에 닿아 구른다. 롤러 핀이 앞·뒤 우리판(케이지)에 꽂혀 롤러 간격(틈 0.016)을 지킴.
7. 한 줄에 놓인 것은? → 두 풀리 중심이 같은 높이 y 2.05(x −0.85, 0.85). 줄 네 가닥이 세로(x −1.465, −0.235, 0.235, 1.465). 롤러 중심이 반지름 0.285 원 위에 60° 간격.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 270 뿐). 왼쪽 화살표 = 풀리가 반시계로 도는 쪽.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) 판화는 축과 롤러가 같은 크기이고 롤러끼리 서로 닿아 보인다 — 서로 닿으면 맞닿은 면이 반대로 움직여 비빈다. → 축 0.15, 롤러 0.1345 로 롤러를 조금 작게 하여 롤러 사이 틈 0.016, 핀과 우리판이 간격을 지킴(판화의 롤러 가운데 점 = 핀). (나) 오른쪽 그림은 앞판을 뗀 모습 — 모델은 앞판을 떼면 우리가 빠지므로 **투명한 앞판**(불투명도 0.25)으로 두어 롤러가 보이게 함. (다) 줄을 움직일 것이 없어 손잡이를 당겼다 놓는 왕복(10 초, ±0.40)으로 보충. 질문 거리 1(투명 앞판), 2(손잡이·추).

## 해석(결정 사항) — 롤러 속도 관계
- 축(반지름 a = 0.15) 고정, 풀리 구멍(R = 0.42 = a + 2b) 각 φ, 롤러(b = 0.135, 구르는 반지름) 중심이 반지름 a + b = 0.285 원 위.
- 축과 닿는 점에서 미끄럼 0, 구멍과 닿는 점에서 미끄럼 0 →
  - 우리(롤러 중심)의 각: **φc = φ·R/(R + a) = 0.736842·φ**
  - 롤러 하나의 절대 회전: **φr = φ·R/(2b) = 1.555556·φ**, 우리에 대한 회전 φr − φc = **0.818713·φ**(= φc·a/b).
  - 파이썬: 축 쪽 접점 속도 φ̇c·0.285 − φ̇r·0.135 = 0, 구멍 쪽 φ̇c·0.285 + φ̇r·0.135 − φ̇·0.42 = 0(둘 다 정확히 0).
- 모양 반지름은 롤러 0.1345(축·구멍 양쪽 틈 0.0005), 계산은 구르는 반지름 0.135.

## 구동
줄 흐름 s(t) = 0.40·sin(2πt/10)(손잡이를 당기면 s > 0). 풀리 φ = s/0.615(반시계 +), 손잡이 끝 y = 1.25 − s, 추 줄끝 y = 1.25 + s. 두 풀리 같은 s.

## 확인
- 정면: 판화처럼 왼쪽 풀리는 앞판에 핀 머리 6개, 오른쪽 풀리는 투명 앞판 너머로 축 둘레 롤러 6개, 두 풀리 위를 밧줄이 반 바퀴 감고 양옆으로 곧게 내려감.

## ★ 난도·질문
난도 **A·하** — 모든 식이 비례(φ 의 상수배), 회전체 단면·점 목록 주어짐, 같은 함수를 두 번 부름. GLM flash 가능(투명 앞판 재질 한 줄 주의).
질문 거리(사용자에게) — 기본값으로 진행:
1. 판화 오른쪽은 앞판을 뗀 그림. 기본값: 앞판을 떼면 우리가 빠지므로 **투명 앞판**(불투명도 0.25)으로 롤러를 보임.
2. 판화의 줄 끝은 잘려 있다. 기본값: 왼쪽 가닥 손잡이, 오른쪽 가닥 추, 손잡이를 당겼다 놓는 왕복(±0.40, 10 초).
3. 판화의 롤러는 축과 같은 크기로 서로 닿아 보이나, 비빔을 피하려 롤러를 0.1345(축 0.15)로 조금 작게 해 틈 0.016.
