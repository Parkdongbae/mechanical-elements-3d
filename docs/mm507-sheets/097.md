# 097 홈이 파인 하트 캠
원문: 96번과 비슷한 하트 캠인데, 홈이 파여 있다는 점만 다르다.
판화 묘사: 정면 그림 하나. 큰 원판, 그 앞면에 **두 줄로 그린 하트**(= 하트 모양으로 한 바퀴 이어진 홈의 안쪽 벽과 바깥쪽 벽), 가운데 두 겹 원(축과 허브), 오른쪽으로 뻗은 가로 막대와 그 왼쪽 끝의 작은 롤러(홈의 오목한 눈 속에 들어 있다).

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/097-fig-x4.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 도는 것은 원판 1개(확대본에서 반지름 약 635)와 막대 끝 롤러 1개(반지름 약 35 — 홈 폭 약 70 과 같다). 홈 가운데 선의 반지름은 눈에서 약 145, 뾰족한 끝에서 약 605.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 받침이 없다(축 단면만). 막대의 안내도 없다(막대 오른쪽 끝은 끊어 그린 둥근 단면).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 원판(96번과 같음). 스프링도 없다 — 홈이 롤러를 양쪽에서 잡으므로 필요 없다.
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝은 **홈의 두 벽 ↔ 롤러**. 나갈 때는 안쪽 벽(가운데 하트 섬)이 롤러를 밀고, 돌아올 때는 바깥쪽 벽이 롤러를 끌어당긴다. 판화의 순간은 롤러가 오른쪽 눈(가장 짧은 반지름)에 있는 때 = 막대가 가장 왼쪽.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 원판 축, 홈의 눈, 뾰족한 끝, 롤러, 막대 중심선이 한 가로선.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 원문과 판화가 같고 그대로 계속 돈다.
- 선 하나하나: **큰 원** = 원판 가장자리(오른쪽 아래가 굵은 것은 그림자 선). **두 줄 하트** = 홈의 두 벽 — 안쪽 하트는 뾰족한 끝이 날카롭고 눈 쪽은 허브 둘레에 닿아 둥글게 파였다, 바깥쪽 하트는 뾰족한 끝이 원판 가장자리에 닿고 눈 쪽은 롤러 바로 오른쪽에서 날카롭게 만난다. **가운데 두 겹 원** = 축과 허브. **막대** = 둥근 봉(끝이 타원 단면), 왼쪽 끝 둥근 눈 안에 롤러의 두 겹 원. 96번의 점선 작도는 없다.
- 판화에서 잰 값: 원판 반지름 635, 허브 110, 홈 가운데 선 145 ~ 605(이동 거리 460), 홈 폭 70, 막대 길이(롤러 → 끝) 725.

## 해석(결정 사항)
- 홈 **가운데 선**이 등속 하트 곡선 r = 0.22 + 0.68·|φ|/π 이고, 두 벽은 그 선을 롤러 반지름 + 틈(0.055 + 0.003)만큼 안팎으로 평행 이동한 것(롤러 지름의 커터로 판 홈과 같다). 그래서 롤러 중심은 **정확히 등속**으로 오간다(96번과 다른 점).
- 평행 이동의 모서리: 안쪽 벽은 뾰족한 끝이 날카롭고 눈 쪽이 반지름 0.058 의 원호, 바깥쪽 벽은 눈 쪽이 날카롭고 뾰족한 끝이 반지름 0.058 의 원호 — 판화의 두 하트 모양과 같다(바깥 하트의 끝은 판화에서 뾰족해 보이지만 롤러가 끝까지 가려면 둥글어야 한다 — 0.058 의 작은 둥글림).
- 판화에 없는 보충(최소): 막대 안내 블록 2개(뒤판에 팔로 붙음). 스프링 없음.
- 도는 방향은 판화에 없다 — 반시계.

## 구동
원판(theta 가 원판의 누적 각, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴(3.927 s)에 막대가 한 번 오간다.

## 부품과 치수 (키트 `kit/k095.ts`, 이미 구현됨. 값은 `HEART97`·`CAM_BAR` 상수)
원판 축 = (−0.7, 1.75), 롤러 가운데 평면 z = 0.1. 아래에서 CX = −0.7, CY = 1.75.
- 원판(name `disc`): `groovedHeartDisc97()` 중심 (−0.7, 1.75), z = 0.1. 들어 있는 것 — 뒤판(반지름 1.0, 두께 0.03, 어두운 홈 바닥), 바깥 둔덕(원판에서 하트 구멍을 뺀 청동 판, 두께 0.08), 가운데 하트 섬(청동), 허브(반지름 0.15, 앞으로 0.03 나옴), 눈 방향 표시점. 홈 폭 0.116, 깊이 0.08, 로컬 +X 가 눈. `userData.outlines = { island, groove }`.
- 원판 축: `shaftZ(−0.7, 1.75, 0.24, 0.055)`.
- 막대(name `bar`): `camBar(1.8, 0.055)` — 원점 = 롤러 중심. 자리 (CX + xr, 1.75, 0.1). 롤러(자식 name `roller`, 반지름 0.055, 폭 0.07, 홈 속), 핀, 끝 눈(반지름 0.065), 둥근 봉(반지름 0.045, 원판 앞 z = 0.215 를 지나 +X 로 1.8).
- 안내 블록 2개(name `guide1`, `guide2`): `barGuide(−0.515)` 를 (0.55, 1.75, 0.215) 와 (1.15, 1.75, 0.215) 에(판화에 없음). 원판 가장자리(x 0.3)의 오른쪽.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 가로 범위: 원판 왼쪽 끝 −1.7, 막대 오른쪽 끝 최대 2.0. 높이 0.75 ~ 2.75.

## 동작 (모두 theta 의 닫힌 식)
- ψ = theta − 1.6 (t = 1 에서 ψ = 0 — 판화 자세: 눈이 롤러 쪽).
- `disc.rotation.z = ψ` (반시계).
- xr = `heartPitch97(ψ)` = 0.22 + 0.68·|ψ 를 (−π, π] 로 접은 값|/π. 범위 0.22 ~ 0.90, 행정 0.68. 반 바퀴 동안 일정한 속도(0.68/π = 0.2165 /rad, 1초에 0.346)로 나가고 반 바퀴 동안 같은 속도로 돌아온다 — 삼각파.
- `bar.position.x = −0.7 + xr`.
- 시각: **t = 1.0 (ψ = 0, xr 0.22 — 판화)**, t = 1.6 (ψ = 55°, xr 0.428, 나가는 중), t = 2.96 (ψ = 180°, xr 0.90 — 가장 멀리).

## notes
① '홈이 롤러를 양쪽에서 잡는다 — 밀기도 하고 당기기도 해서 스프링이 필요 없다' ② 지금 막대 위치(xr − 0.22, 소수 둘째 자리)와 '나감 / 돌아옴'(ψ mod 2π 가 π 보다 작으면 나감) ③ '반 바퀴에 0.68 을 일정한 속도로' ④ 구동 회전수.

## 확인
- t = 1 정면: 판화와 같은 모양 — 하트 홈의 뾰족한 끝 왼쪽, 눈 오른쪽에 롤러. t = 2.96 정면: 원판이 반 바퀴 돌아 끝이 오른쪽, 롤러가 홈의 끝 원호 안, 막대가 0.68 나가 있음.
- 근접 `cam=-0.2,1.95,1.3,-0.45,1.75,0.1`(홈 속 롤러), 옆 `cam=3.2,1.9,0.2,0,1.75,0.1`(+X 에서 — 원판·막대·안내의 층), 위 `cam=0.2,4.4,0.3,0.2,1.75,0.1`.
- 수치: `node shots/_verify/s095.mjs` → 한 바퀴 내내 롤러 ↔ 안쪽 벽 최소 틈 0.00297, 롤러 ↔ 바깥쪽 벽 최소 틈 0.00297(침범 없음), 롤러 중심이 홈 밖으로 나간 시각 0, 홈 폭 0.116 ~ 0.1176(롤러 지름 0.11), 안쪽 벽 최소 반지름 0.162 > 허브 0.15, 바깥쪽 벽 최대 반지름 0.958 < 원판 1.0.
