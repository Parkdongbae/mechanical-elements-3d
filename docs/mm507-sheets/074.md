# 074 간헐 베벨 기어 장치
판화(public/mm507/fig/074.png, 4배 확대 shots/_verify/074-fig-x4.png 로 다시 읽음): 그림 하나. 베벨 기어 셋이 ㄷ자(위가 열린 U)로 놓였다. 왼쪽 A 와 오른쪽 B 는 가로축 위에서 서로 마주 보는 같은 크기의 베벨 기어이고(이가 난 원뿔 면이 안쪽 = 서로를 향함, 뒷면에서 축 토막이 바깥으로 나옴), 아래의 C 는 세로축 위에 누운 더 큰 베벨 기어다(이가 난 면이 위, 축은 아래로 내려가며 턱(칼라)이 하나 있다). C 의 윗면은 **오른쪽 절반쯤에만 이 줄이 그려져 있고 왼쪽 절반은 민 면**(글자 C 가 그 민 면 위에 있다)이다. A·B 사이에는 축이 그려져 있지 않다(따로 도는 두 축).
원문 요지: 이가 일부만 난(mutilated) 베벨 기어 C 가 돌면서 베벨 기어 A 와 B 에 **서로 반대 방향의 고른 간헐 회전**을 준다.

★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 베벨 기어 3개. C(아래, 가장 큼, 지름 ≈ A 의 1.27배) > A = B(같은 크기). A·B 는 이가 온 둘레에 났고(보이는 반쪽에 13개쯤 → 온 둘레 약 26개), C 는 둘레의 절반쯤에만 이가 났다.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음(줄이 없다). 축은 셋: A·B 의 가로축은 한 직선 위에 있고 C 의 세로축이 그 직선과 직각으로 만난다(세 피치 원뿔의 꼭짓점이 한 점).
4. 고정점은? → 판화에는 받침이 없다(축 끝이 잘려 있을 뿐). 모형은 뒤판에서 나온 축받이로 받친다(판화에 없음).
5. 추·손잡이·크랭크는? → 없음. 구동은 C(원문: C 가 A·B 에 운동을 준다).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 셋 다 원뿔 바깥 면에 이가 났다. C 의 왼쪽 가장자리가 A 의 아래쪽과, C 의 오른쪽 가장자리가 B 의 아래쪽과 물린다. C 의 이는 둘레 일부에만 있어서, 이가 난 호가 A 밑을 지날 때는 A 만, B 밑을 지날 때는 B 만 돈다.
7. 한 줄에 놓인 것은? → A 의 축과 B 의 축이 한 수평선. C 의 축은 A·B 의 한가운데 세로선. A·B 의 아래 모서리와 C 의 양 끝 모서리가 맞닿는다.
8. 글자가 가리키는 부품은? → A = 왼쪽 베벨, B = 오른쪽 베벨, C = 아래의 이가 일부만 난 베벨(원문 글자와 같다).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 다만 판화의 이 모양 그대로(끝 이까지 온 높이)는 이가 난 호가 서 있는 기어로 들어가고 나올 때 이끝끼리 부딪친다(측정 0.015) → 이가 난 호의 첫 이·끝 이를 낮게 깎았다(판화에 없는 손질, 아래 "맞물림 측정"). 쉬는 기어를 붙잡는 잠금 장치는 판화에 없다 — 모형도 두지 않는다(쉬는 동안 제자리에 선다고 본다).
- 그 밖의 선: C 아래의 좁은 띠 = C 의 뒷판 테두리, 축의 굵은 마디 = 턱(칼라). A·B 뒷면의 세로 띠 = 뒷판 두께.

## 구동
C(이가 일부만 난 베벨)를 세로축 둘레로 돌린다: theta += OMEGA·speed·dt (OMEGA = 1.6 rad/s). C 는 쉬지 않고 돌고, A·B 는 번갈아 돈다.

## 부품과 치수 (키트: `kit/k074.ts` — 이미 구현됨)
모듈 MOD = 0.03, 축 사이각 90°. 세 피치 원뿔의 꼭짓점 O = (0, 1.75, 0.28).
- A·B: 잇수 24, 피치 반지름 0.36, 피치 원뿔 반각 dA = atan(24/30) = 38.66°. C: 잇수 자리 30칸(피치 반지름 0.45, 원뿔 반각 dC = 51.34°) 가운데 **이 14개만**(k = 0 … 13, 이가 난 호 156°) 있고 나머지 16칸은 이뿌리 원뿔의 민 면. 이 폭(모선 길이) 0.16.
- gearC = `sectorBevelGear(30, 0.03, dC, 14, { face: 0.16, driver: true })`, name `gearC`. 받침 그룹: position (0, 1.39, 0.28), rotation.x = −π/2 (로컬 Z → +Y, 이가 위를 향함). 기어 자체는 그 안에서 rotation.z = psiC.
- gearA = `sectorBevelGear(24, 0.03, dA, 24, { face: 0.16 })`, name `gearA`. 받침 그룹: position (−0.45, 1.75, 0.28), rotation.y = +π/2 (로컬 Z → +X, 이가 오른쪽 = 안쪽을 향함). 기어 rotation.z = spinA.
- gearB = `sectorBevelGear(24, 0.03, dA, 24, { face: 0.16 })`, name `gearB`. 받침 그룹: position (0.45, 1.75, 0.28), rotation.y = −π/2 (로컬 Z → −X). 기어 rotation.z = spinB.
  - 세 기어의 원점은 큰 쪽 피치원 중심이다: A·B 는 꼭짓점에서 가로로 0.45, C 는 꼭짓점 아래 0.36 (= 서로의 피치 반지름).
- A 의 축: `shaftX(−1.30, −0.30, 1.75, 0.28)` (k061), rotation.x = spinA (A 와 한 몸). 축받이 `wallBearing(−0.95, 1.75, 0.28, 'x', 0.052)` (gear6).
- B 의 축: `shaftX(0.30, 1.30, 1.75, 0.28)`, rotation.x = −spinB. 축받이 `wallBearing(0.95, 1.75, 0.28, 'x', 0.052)`.
- C 의 축: `rodY(0.60, 1.50, 0.045)` (k053) 를 position (0, 0, 0.28) 에, rotation.y = psiC. 축받이 둘 `wallBearing(0, 1.02, 0.28, 'y', 0.052)`, `wallBearing(0, 0.70, 0.28, 'y', 0.052)`. 판화의 턱(칼라)은 위 축받이 바로 위에 `tubeZ` 를 쓰지 말고 생략한다(축받이 링이 그 자리).
- 뒤판·바닥 `displayStand()`.
- 판화에 없음(보충 부품): 축받이 4개(뒤판에서 나온 팔 + 링). 그 밖에는 없다.

## 맞물림 측정 (shots/_verify/s074.mjs — 3D 점 대 솔리드, 한 바퀴 720 시각)
- 이 모양 `K74_SHAPE` = { tip 0.12, root 0.25, add 0.9, ded 1.15, endAdd 0.15 }: 이뿌리를 이끝보다 0.25·MOD 깊게 → 서 있는 기어의 이가 C 의 민 면 위에 0.0075 떠서 지나간다.
- C 의 이가 난 호의 **첫 이(k = 0)와 끝 이(k = 13)는 높이를 0.15배로 낮췄다**. 온 높이면 들어갈 때·나올 때 서 있는 이의 끝과 0.015 겹치고(θ = 4~10°, 172~179° 등), 0.4배면 0.007, 0.15배면 0.000.
- 위 식의 위상(psiC 덧값 12°, spinA·spinB 덧값 7.5°)에서 한 바퀴 최대 침범 0.0000, 7바퀴 뒤·역회전(θ < 0)에서도 0.0000. 덧값 7.5°(A·B 의 반 피치)는 구동 구간에서 C 의 이 중심이 A·B 의 이골 중심과 만나는 값이다(측정: 구동 구간 침범 0).

## 동작 (모든 자세는 theta 의 절대 함수)
- `windowAngle(theta, start, span)` (k074): 한 바퀴 가운데 [start, start + span) 구간에서만 따라 도는 유효 구동 각 = N·span + min(u, span), N = floor((theta − start)/2π), u = (theta − start) − 2πN.
- psiC = theta + π/15 (12°).
- spinA = −1.25·`windowAngle(theta, 0, π)` + π/24 (7.5°). — theta 가 0~π 인 반 바퀴 동안 A 가 돈다.
- spinB = −1.25·`windowAngle(theta, π, π)` + π/24. — theta 가 π~2π 인 반 바퀴 동안 B 가 돈다.
- 속도비 1.25 = 30/24. 한 구간(π)에 A 는 225° = 정확히 15이를 가므로 다음 바퀴에 이가 다시 이골로 들어간다(누적 오차 없음). 이 14개가 15피치를 미는 까닭: 끝 이가 상대 이를 물림 영역 끝까지 밀어 주기 때문(구간을 14피치로 하면 서 있는 이와 부딪침).
- 세계 좌표에서의 회전: A 는 +X 축 둘레로 spinA(음수 = 위쪽이 보는 사람 쪽으로), B 는 +X 축 둘레로 −spinB(양수) → **서로 반대 방향**. C 는 +Y 축 둘레로 psiC(위에서 보아 반시계).
- 쉬는 기어는 마지막 자세 그대로 선다(식에서 min(u, span) 이 멈춤).

## 키트 추가
이미 구현됨: `kit/k074.ts` (이 묶음 074·075·076 공용, 모델은 `'../kit/k074'` 에서 직접 import)
- `sectorBevelGear(teeth: number, module: number, delta: number, present: number, opts?: { face?; driver?; bore?; shape? }): THREE.Group` — 이가 k = 0 … present−1 만 난 직선 이 베벨(present = teeth 면 온전한 기어). 회전축 로컬 Z, 원점 = 큰 쪽 피치원 중심, 이 0 의 중심 = 로컬 +X. userData.mm = { kind:'gear', … }, userData.bevel.
- `sectorBevelOutline(teeth, module, delta, present, shape?): V2[]` — 큰 쪽 끝 단면 윤곽(검사용).
- `K74_SHAPE` — 이 모양 상수(위 측정값).
- `windowAngle(theta: number, start: number, span: number): number` — 간헐 구동의 유효 각.
다른 키트에서 그대로 가져다 쓰는 것(고치지 않음): `shaftX(x0, x1, y, z, r?)`(k061), `rodY(y0, y1, r?)`(k053), `wallBearing(x, y, zc, axis, bore?)`(gear6), `tubeZ(…)`(k061, 쓰지 않음).
