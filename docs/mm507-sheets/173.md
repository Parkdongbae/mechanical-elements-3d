# 173 나사로 바뀌는 왕복 거리
원문: 비단 기계에 쓰이는 운동 장치. 원판 뒷면에 한쪽 끝에 태핏 바퀴가 달린 나사가 고정되어 있고, 원판이 한 바퀴 돌 때마다 태핏 바퀴가 핀(태핏)에 닿아 간헐 회전을 한다. 나사의 너트에 고정된 손목(핀)은 비단 안내 막대 끝의 홈 있는 막대 안에서 움직이며, 나사가 조금씩 돌므로 너트 자리가 바뀌어 원판이 한 바퀴 돌 때마다 안내 막대의 행정이 달라진다.

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 px [x·y]).
1. 바퀴는? → 큰 원판 1개(중심 [170·265], 반지름 135). 그 앞 비스듬(약 30°)한 나사 1개(양 끝 [50·325]~[280·190], 중심이 원판 중심 근처를 지남), 나사 위쪽 끝에 태핏 바퀴(톱니바퀴 모양, 중심 [295·160], 반지름 20).
2. 줄·벨트는? → 없음. 나사와 너트가 물림.
3. 교차하는 가닥은? → 없음. 겹침: T자 모양 홈 막대가 원판·나사 앞. 홈(긴 세로 구멍) 안에 너트의 핀 [130·280] 이 있다.
4. 고정점은? → 오른쪽 위의 네모 블록 [340~430·140~190](끝에 태핏 핀이 왼쪽으로 나옴), 오른쪽 아래 블록 [330~440·305~350](안내 막대가 지나가는 안내), 원판 축(오른쪽으로 나온 가로 막대 [330~430·255]).
5. 구동은? → 원판(원문 "원판이 한 바퀴 돌 때마다"). 홈 막대는 안내 막대 끝(가로로 오른쪽으로 나와 아래 블록을 지남).
6. 기어는? → 태핏 바퀴만(둘레 톱니). 태핏 핀이 그 톱니를 민다.
7. 한 줄에 놓인 것은? → 홈 막대의 가로 팔 [y 265] 과 원판 중심 [y 265] 이 같은 높이. 나사 축이 원판 중심을 지난다(어긋남 약 9 px).
8. 글자가 가리키는 부품은? → 글자 없음(번호 173 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 원판을 앞에서, 축은 옆에서 그린 합성이다. 나사는 한 방향으로만 돌아 너트가 끝까지 가면 멈춰야 하므로, 모형은 **너트가 5자리를 4걸음 가고 되돌아오는** 한 주기(8바퀴)로 보여 준다(되돌림 장치는 판화·원문에 없음). 질문 거리 없음.

## 해석(결정 사항)
- 1 px = 0.0075. 원판 반지름 1.0(판화 135 px), 중심 C = (−0.85, 1.7). 나사 축은 원판 중심을 지나고 +30.4° 기울고 원판과 함께 돈다.
- 너트 위치 ρ(나사 축 위 중심에서의 거리): 0.28 ~ 0.52(−쪽), 나사 피치 0.24, 태핏 바퀴 톱니 4개 → 한 걸음 = 1/4 바퀴 = 0.06. 핀 회전 반지름 = |ρ| 이므로 행정 = 2|ρ| = 0.56 ~ 1.04 로 걸음마다 바뀐다.
- 태핏 핀은 원판 위 θ = 0 자세(판화)에서 바퀴 앞에 고정. 걸음은 θ = 2π·n ± 0.06 바퀴 동안(창)에 일어난다.
- 나사 오른나사. 회전 방향 판화에 없음 → 원판 반시계.
- 판화에 없는 보충: 원판 축 보스, 홈 막대 안내 받침 기둥, 태핏 틀 받침 기둥, 나사 받침(레일·귀).

## 구동
원판(theta 누적 반시계). theta += OMEGA·speed·dt. 한 바퀴 3.93 s. 한 주기 8바퀴(31.4 s)에 나사 4걸음 정방향, 4걸음 되돌림. 모든 자세는 `step173(theta)` 의 닫힌 식.

## 동작 (theta 의 닫힌 식 — `step173(theta)` = { tri, rho, phiS })
u = theta/2π. s = floor(u + 0.06) + smooth(frac(u + 0.06)/0.12). tri = 삼각파(s mod 8: 0→4→0). ρ = −(0.28 + 0.06·tri). 나사 각 = −(π/2)·tri.
대입: `disc.rotation.z = theta`, `screw.rotation.x`, `nut.position.x`, 핀 월드 위치 = C + R(theta)·(ρ·cos30.4°, ρ·sin30.4°), `bar.position.x` = 핀 x.
시각: t = 1 (θ 1.6), 1.6, 3, 30.
