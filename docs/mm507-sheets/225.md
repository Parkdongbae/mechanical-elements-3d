# 225 폴이 달린 래칫
원문(en): "Intermittent circular motion of the ratchet-wheel from vibratory motion of the arm carrying a pawl." — 폴을 단 팔의 진동 운동으로 래칫 바퀴에 간헐 원운동(끊어지는 회전)을 만든다.
쉬운 풀이: 팔이 앞뒤로 흔들리면 팔 끝의 폴이 톱니를 한 칸씩 밀어서, 래칫 바퀴가 한 방향으로만 조금씩 돈다.
판화 묘사(원본 470×443 px, [x·y], y 아래로): 왼쪽에 톱날 바퀴 하나(허브 겹원 [196·244], 이끝 원 중심 [198·236], 이끝 반지름 약 122 px, 이뿌리 약 103 px, 이 약 20개). 오른쪽에 거의 세로로 선 **팔**(곧은 막대): 아래 끝이 바닥의 종 모양 받침 [373·400] 에 핀으로, 위 끝 핀 [372·50]. 위 끝 핀에서 **길고 위로 휜 폴**이 왼쪽 아래로 뻗어 끝(코)이 바퀴 위쪽(바퀴 중심에서 약 103°) 이골 [174·128] 에 걸린다. 바닥 선 y ≈ 416.

## ★ 판화 읽기
판화 1 px = 0.007. 세계 x = (px − 285)·0.007, 세계 y = 0.18 + (416 − py)·0.007 (판화 바닥선 = 받침대 윗면 0.18).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 래칫 바퀴 1개(이끝 0.85, 이뿌리 0.72). 이 사이 각을 재면 16.7~19.8° → 20이(18°).
2. 줄·벨트는 몇 개이고 어디서 시작해 어디서 끝나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 폴은 바퀴와 같은 판(z), 팔은 그 앞 층.
4. 고정점(천장·벽·바닥)은 어디인가? → 바닥의 종 모양 받침(팔 아래 핀 [373·400] → 세계 (0.616, 0.292)), 바퀴 축(판화엔 받침 없음 → 뒤판 축).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에 없음("vibratory motion of the arm" 만). 모형: 팔 가운데 위(받침에서 2.0)에 연결봉 → 오른쪽 크랭크 원판(보충, 206 과 같은 방식).
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 바깥 둘레 톱날 이. 반지름이 반시계로 갈수록 서서히 줄다가(비탈) 곧은 면에서 뛰어오름 → **곧은 면이 시계 쪽을 본다**. 폴은 바퀴 위쪽에서 오른쪽(시계 쪽)에서 와서 곧은 면을 **왼쪽으로 민다** → 바퀴 **반시계**.
7. 한 줄에 놓인 것은? → 팔 아래 핀과 위 핀이 같은 세로선(x 차 1 px → 0). 바퀴 중심과 폴 코는 같은 선 아님.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 225 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 동작은 그대로 된다(아래 검산). 다만 판화에는 바퀴를 붙잡는 멈춤 폴이 없어, 폴이 돌아갈 때 바퀴는 **축 마찰로만** 선다 → ★질문 거리(기본값: 판화대로 멈춤 폴 없음).

## 다섯 장 공통 폴·이 규칙 (225·232·235·236·237 같음)
- 폴(태핏·멈춤 폴 포함) **코 끝은 원 반지름 rn = 0.014**, 코와 몸이 만나는 **오목 목은 필릿 0.02**, 나머지 볼록 모서리 0.006 — 아래 점열에 이미 들어 있다(155 "폴 닿는 곳이 각져 보임" 방지). 점열을 고치거나 다시 그리지 말 것.
- **톱날 이(225·236·237)**: 곧은 면이 반지름선(237 은 띠의 수직선)에서 **20° 갈고리꼴**(이끝이 폴 쪽으로 기울어 이골을 덮음 — 206 과 같음), 비탈은 이끝 → 다음 이뿌리 직선, 이끝은 뾰족. 판화가 대칭 이를 그린 232(네모 이)·235(별 이)만 판화를 따른다.
- 폴의 **미는 면은 이 곧은 면에서 여유각**(폴이 이에 대해 도는 만큼 + 여유)을 두어 코 원만 닿는다.
- 침범 판정(들림 계산): 코 원 중심이 바퀴 윤곽 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범(206 과 같음).
- 색: **거는 폴 = 그 폴 재질 emissive 0x7a4a00(주황빛), 쉬는 폴 = 0x000000** — 폴마다 재질을 따로 만든다.
- 재질: 바퀴는 `steel()`(밝음 — 이가 보이게, 검은 재질 금지), 폴은 `brass()`, 팔·레버는 `castIron()`.

## 해석(결정 사항)
- 폴은 팔 위 끝 핀에 헐겁게 걸려 **제 무게로** 바퀴 위에 얹힌다(핀 오른쪽, 몸이 왼쪽으로 늘어져 반시계로 기울려 함 → 코가 바퀴로 눌림). 스프링 없음.
- 한 주기(크랭크 한 바퀴)에 바퀴는 정확히 **1이(18°)** 반시계. 팔이 왼쪽으로 갈 때(앞 반 주기) 폴이 밀고, 오른쪽으로 돌아올 때 폴이 비탈을 타고 넘어 다음 이골로 '툭' 떨어진다.
- 판화의 길게 휜 폴을 그대로: 핀 → 코 거리 L = 1.505342(판화 1.496). 폴 몸은 코에서 0.17 바깥으로 올라간 뒤 위로 불룩(0.16)하게 핀까지 — 이끝 원과 늘 떨어짐(검산).
- 판화에 없는 보충: 크랭크 원판·크랭크 축·연결봉, 바퀴 축.

## 구동
`theta += OMEGA * speed * dt`(크랭크 각, OMEGA 1.6 rad/s, 한 주기 3.92699 s). 모든 자세는 `state225(theta)` 닫힌 식 + 모듈 적재 때 한 번 만든 폴 들림 표.

## 동작 (`state225(theta)` — 각도 rad, 표의 값은 도)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀 P = K + rk·(cos(thF + u), sin(thF + u)).
2. 팔 핀 H = `circleIntersect([0.616, 0.292], 2.0, [P.x, P.y], 0.880427, true)`, γ = atan2(H.y − 0.292, H.x − 0.616) − π/2. (u = 0 → γ = −4.5681°(오른쪽 끝), u = π → +2.9102°(왼쪽 끝), 정확히.)
3. 폴 핀 T = B + 2.45·(−sin γ, cos γ).
4. 가상 구석 C = `circleIntersect(W, Rc, T, L, true)`, U = atan2(C.y − W.y, C.x − W.x). 상수: U_lo = 88.4°(u = 0), U_hi = 111.8°(u = π), 헛걸음 slack = U_hi − U_lo − p = 5.4°.
5. 바퀴 반시계 누적각 Φ: u < π(팔이 왼쪽으로 = **미는 행정**): Φ = n·18° + max(0, U − U_lo − slack), 폴 구동 = (U − U_lo) > slack. u ≥ π(**돌아오는 행정**): Φ = n·18° + 18°, 구동 없음. `ratchet.rotation.z = rho0 + Φ`, rho0 = 95.5065°.
6. 폴 각: 앉은 각 λs = atan2(C.y − T.y, C.x − T.x). `pawl.rotation.z = λs + lift(u)`. 구동 중 lift = 0(코가 0번 구석에 앉음).
7. 들림 표(모듈 적재 때 한 번, 206 과 같은 틀): u_i = 2π·i/1440, 두 주기를 차례로 돌며 둘째 주기 값을 저장. 각 시각 — 구동이면 lift = 0, 아니면 앞 시각의 λ 에서 시작해:
   - 침범 판정 pen(λ): 코 중심 c = T + L·(cos λ, sin λ) 를 바퀴 로컬로(c − W 를 −(rho0 + Φ) 회전), 바퀴 윤곽(40점) 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범.
   - 바깥(들림) 방향 out = −1(시계 = 코가 위로). 침범이면 out 쪽으로 0.02° 씩(최대 2000번) 가다 처음 자유를 찾고, 아니면 −out 쪽으로 0.02° 씩(최대 1500번) 가다 처음 침범을 찾는다. 두 각 사이 이분법 25번, 자유 쪽이 답. lift = λ − λs. 표 사이는 선형 보간.
   - 같은 결과를 내는 계산식(검산용): 쉬는 코는 (가) 비탈 직선(바퀴 로컬 법선 n_s, 원점 거리 d_s)에서 L·cos(λ − ψ_s − φ) = d_s + rn − n_s·R(−φ)(T − W) (ψ_s = n_s 의 각, φ = rho0 + Φ) 의 해, 또는 (나) 이끝 꼭짓점 Tip_w 에서 λ = atan2(Tip_w − T) ± acos((L² + |Tip_w − T|² − rn²)/(2L·|Tip_w − T|)) 중, 침범이 없으면서 가장 큰 λ(중력 쪽).
8. 기대값(구현 검산): 구동 u 60.5° ~ 180°, 들림 범위 −4.97° ~ 0(최대 들림 u 335°), 떨어짐(이 하나 넘어 다음 이골로 툭) u ≈ 349.25°(−4.61° → −0.77°). 한 주기 전체에서 폴 윤곽 × 바퀴 윤곽 겹침 넓이 ≤ 2.0e-7(사실상 0, 파이썬 shapely 1440 시각).
