# 031 웜과 웜기어
판화: 가로 축 위의 웜(나사 3바퀴쯤)이 아래의 큰 웜 휠(이 약 30개, 축은 종이에 수직) 꼭대기를 물고 있다. 휠 가운데에 둥근 허브.
구동: 웜. 웜 1바퀴에 휠은 이 1개만큼 돈다.

## 부품과 치수
`wormScrew`(키트 추가), `spurGear`, `shaftZ`, `rod`, `rotArrow`, `tag`. 모듈 0.05.
- 웜 휠: `spurGear(30, 0.05, { width: 0.16, spokes: 6 })`, 중심 (0, 1.35), z = 0.12, 피치 반지름 0.75.
- 웜: `wormScrew(0.0575, 0.17, π·0.05, 0.9, { driver: true })` — 한 줄 오른나사, 축 = X, 축 높이 y = 1.35 + 0.75 + 0.12 = 2.22, z = 0.12. 웜 피치 반지름 0.12.
- 축: `rod` 길이 2.36, 반지름 0.045, 양쪽에 뒤판에 붙은 축받이 블록(x = ±0.95).

## 동작
- 웜 각 θ += 4.8(= 3·OMEGA)·speed·dt (휠이 너무 느려 보이지 않게 3배). `worm.rotation.x = θ`.
- 휠: φ = θ/30 + π/2 − π/30 (반시계). 근거: 웜 중심축 단면(위치 −Y 쪽)에서 나사산 중심은 x = p/2 − pθ/2π (mod p), 휠 꼭대기 이 중심은 x = −rp(φ + 이 위상 − π/2). 이가 나사산 사이 골에 들어가려면 둘이 반 피치 어긋나야 하므로 위 식. spurGear 이 중심은 (i+½)·2π/30.

## 표시
rotArrow 휠 반시계, 웜 화살표(+X 쪽에서 볼 때 반시계). tag '웜(구동)', '웜 휠 30'. notes: 잇수, 속도비 1:30, 축 직각.

## 확인
- t=1 → 1.6: 웜 나사산이 앞으로 흐르고(0.96 rad), 휠 표시선이 반시계로 약 0.03 rad(조금) 움직인다.
- 휠 꼭대기 이가 나사산 사이에 들어가 있고 겹치지 않는다. 비스듬한 시점 `cam=0.7,2.9,1.1,0,2.15,0.12`.

## 검증 수정 (Fable)
- 웜을 **왼나사**로(`wormScrew(..., { leftHand: true })`): 판화의 나사산은 정면에서 "/" 로 기운다. 그래서 휠은 **시계** 방향: `wheel.rotation.z = −θ/30 + π/2 − π/30`.
- 웜 휠은 `wormWheel(30, 0.05, { width: 0.14, tanLead })`(헬리컬, 리드각 11.8°). 곧은 이(spurGear)는 폭 양끝에서 나사산 옆구리를 약 0.013 파고들었다.
- 웜 길이 0.9 → 0.62(판화: 3바퀴 남짓), 나사산 피치선 반폭 0.23p → 0.215p.
