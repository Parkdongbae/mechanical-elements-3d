# 086 회전으로 펌프 작동(캠과 갈고리 걸쇠)
판화(public/mm507/fig/086.png, 4배 확대 shots/_verify/086-fig-x4.png 로 다시 읽음): 그림 하나, 정면. 가운데에 살 4개짜리 큰 바퀴 A(테가 두껍다)가 축에 끼워져 있고, 그 앞을 A자 받침(꼭대기에 네모 축받이, 밑에 가로대)이 가린다. 축 허브에서 왼쪽 위로 뾰족한 팔 C(캠)가 나와 있다. 바퀴 왼쪽 살 끝(테 안쪽)의 작은 이중 원이 걸쇠의 받침 핀이고, 걸쇠 B 는 이 핀을 지나는 곧은 막대다 — 오른쪽 위 끝은 아래로 굽은 갈고리가 되어 캠 C 의 끝을 덮고, 왼쪽 아래 끝(글자 B)은 바퀴 테 밖으로 길게 나와 왼쪽 기둥 앞에 걸쳐 있다. 왼쪽에 굵은 세로 기둥, 그 위에 가로 들보, 들보 안(바퀴 축 바로 위 조금 오른쪽)에 빗금 친 네모 = 원문의 "위에 있는 멈춤 턱". 바퀴 왼쪽 가장자리에서 빗금 친 띠(줄)가 아래로 늘어져 있다. 바퀴 꼭대기와 바닥 높이에서 오른쪽으로 뻗은 빗금 띠 두 개가 더 있다(정체는 아래 9번).
원문 요지: 회전 운동으로 왕복 펌프를 움직인다. 펌프 대를 매단 줄이 바퀴 A 에 붙어 있고 A 는 축 위에서 헐겁게 돈다. 축에는 캠 C 가 달려 계속 돈다. 한 바퀴마다 캠이 바퀴에 붙은 갈고리 걸쇠 B 를 잡아 바퀴째 끌고 돌아 줄을 끌어올리고, 걸쇠 끝이 위쪽 멈춤 턱에 부딪히면 걸쇠가 풀려 바퀴는 펌프 버킷 무게로 되돌아간다. (원문의 "the cam B" 는 "the cam C" 의 오식.)

★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 1개(바퀴 A, 살 4개, 줄이 감기는 테). 캠 C 는 바퀴가 아니라 축에 박힌 한 팔.
2. 줄·벨트는? → 확실한 것은 1줄: 바퀴 테의 왼쪽 가장자리에서 접선으로 곧게 아래로 내려가는 줄(끝은 판화에서 잘려 있다 — 원문의 펌프 대). 바퀴 테 위쪽에 묶여 왼쪽으로 감겨 내려온다고 읽었다. 오른쪽 위·아래의 가로 빗금 띠 2개는 9번.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → A자 받침(바닥 판 위), 왼쪽 기둥과 위 들보, 들보의 멈춤 턱(빗금 네모). 바닥선.
5. 추·손잡이·크랭크는? → 판화에 추는 없다(줄이 잘려 있음). 원문의 "펌프 버킷 무게"를 줄 끝의 추로 나타낸다. 구동은 축(캠).
6. 기어는? → 없음. 맞닿는 짝: 캠 C 끝 ↔ 걸쇠 B 의 갈고리(캠이 시계 방향으로 밀어 줄 쪽인 왼쪽이 올라간다), 걸쇠 꼬리 ↔ 멈춤 턱.
7. 한 줄에 놓인 것은? → 걸쇠 받침 핀이 축과 거의 같은 높이(왼쪽 살 끝). 멈춤 턱은 축 바로 위쪽(조금 오른쪽). 줄은 바퀴 왼쪽 끝의 세로선.
8. 글자가 가리키는 부품은? → A = 헐거운 바퀴, B = 갈고리 걸쇠(글자는 꼬리 끝 옆), C = 캠(글자는 캠 팔 옆).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 판화와 원문이 같다. 다만 ① 오른쪽 위·아래의 가로 빗금 띠 2개는 원문에 설명이 없고 판화로는 알 수 없음(줄로 보면 한 줄 "A rope" 와 맞지 않는다) — 만들지 않고 질문으로 남긴다(보류 아님). ② 판화 치수 그대로면 캠 끝이 걸쇠 막대 밑을 지나가지 못하므로(막대와 축의 거리 ≈ 캠 끝 반지름) 캠 끝 반지름을 조금 줄였다. ③ 걸쇠가 제자리로 돌아오는 힘(무게·용수철)은 판화에 없다.
- 그 밖의 선: 받침 왼쪽 다리 바깥의 끊긴 선은 다리 윤곽이 인쇄에서 끊긴 것(다른 자세 표시가 아님). 바퀴 테의 가는 안쪽 호는 줄 홈.

## 해석(결정 사항)
- 캠은 시계 방향으로 돈다(갈고리의 굽은 끝이 캠 끝의 오른쪽에 있고, 줄이 왼쪽에 걸려 있어 시계 방향이어야 줄이 올라간다).
- 걸쇠는 받침 핀 둘레로 돈다. 꼬리가 멈춤 턱에 막히면 걸쇠가 바퀴에 대해 반시계로 돌아 갈고리가 **바깥으로** 들려 캠에서 벗어난다.
- 기둥·들보는 걸쇠보다 **뒤쪽 층**이다(판화에서 꼬리 B 가 기둥 앞에 그려져 있고, 꼬리 끝이 도는 반지름 0.92 가 들보 높이보다 크다). 멈춤 턱만 들보에서 앞으로 나와 걸쇠 평면에 닿는다.
- A자 받침은 판화에서는 맨 앞에 있지만 캠·갈고리를 가리므로 **바퀴 뒤쪽**에 하나만 둔다(판화와 다른 점, 일부러).
- 치수·시간표는 키트 `kit/k086.ts` 의 `K86`·`state86` 에 들어 있다(`shots/_verify/s086.mjs`, `t086kit.ts` 로 한 주기 다각형 침범 ≤ 0.001 확인). 함부로 바꾸지 않는다.

## 구동
캠 축(theta, 시계 방향). theta += OMEGA(1.6)·speed·dt. 축·캠은 쉬지 않고 돌고, 바퀴 A 는 헐겁게 끼워져 `state86(theta)` 의 alpha 만큼만 돈다. 한 주기 = 구동각 2π(3.93 초).

## 동작 (모두 `state86(theta)` 의 닫힌 식·시간표, 주기 2π)
tau = theta mod 2π. tau = 0 은 캠이 갈고리에 막 걸린 판화 자세.
- 0 ≤ tau < 2.007(115°) **끌어올림**: alpha = tau (바퀴가 캠과 같이 시계로). 끝 무렵(alpha ≈ 110° ~ 115°) 꼬리 앞변이 멈춤 턱 모서리에 닿아 걸쇠가 들린다: psi = γ + asin(0.028/D) − (β0 − alpha), (D, γ) = 받침 핀 → 모서리 벡터의 길이·각, β0 = −132.67°. alpha = 115° 에서 psi = 8.35°(코가 캠 끝 반지름 0.29 밖으로 다 나옴) → 풀림.
- 2.007 ≤ tau < 3.307 **되돌아감**(1.3 rad): alpha = 115°·(1 − f(u)), u = (tau − 2.007)/1.3, f(x) = x²(3 − 2x). 걸쇠는 11.2°(= 8.35° + 여유 2.9°)로 들린 채 캠 끝을 타고 넘은 뒤(0.55 rad), 0.5 rad 에 걸쳐 0 으로.
- 3.307 ≤ tau < 2π **쉼**: alpha = 0, psi = 0. 캠만 돌아 걸쇠 막대 밑(틈 0.02)을 지나 다시 갈고리에 닿는다(tau = 2π ≡ 0).
- 바퀴 rotation.z = −alpha, 캠 rotation.z = −theta, 걸쇠 rotation.z = psi, 줄·추 lift = 0.51·alpha.
- 누적 오차 없음(모든 자세가 theta 의 함수). 역회전(theta 감소)도 같은 식.
