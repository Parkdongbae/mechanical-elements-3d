# 159 줄과 도르래 발판
원문: "A modification of 158, a cord and pulley being substituted for the connecting rod." — 158 의 변형으로, 연결봉 대신 줄과 도르래를 쓴다. 발판(트레들)의 왕복 운동이 연결봉이 아니라 **줄**을 통해 원판의 크랭크 핀을 당겨 원판을 돌린다. 줄은 가운데의 도르래 위를 넘어 방향을 바꾼다.
판화 묘사: 왼쪽에 종 모양 받침대 위의 큰 민 원판(가운데 허브, 그 밑으로 원판에 가린 받침대 머리가 점선). 원판 앞면 오른쪽 아래 테 안쪽에 이중 원 하나 = 크랭크 핀과 그에 걸린 줄 고리. 가운데 위에 민판 도르래 한 개(허브 눈이 보이고 축 받침은 그리지 않았다). 꼬인 줄(빗금 가닥)이 핀 고리에서 도르래 왼쪽으로 올라가 위를 넘어 오른쪽에서 수직으로 내려와, 발판 막대를 꿴 눈 볼트의 매듭에서 끝난다. 오른쪽에 종 모양 받침대(머리에 받침 핀 눈)에 받쳐 발판 막대가 왼쪽 아래로 기울어 있고 왼쪽 끝은 왼쪽 받침대 받침판 위 하늘에 떠 있다(밟는 자리). 바닥은 빗금.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대로 다시 읽었고 아래 [x·y] 는 원본(452×445) px. 눈금: 원판 반지름 79px = 0.66 → 1px ≈ 0.00835.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 둘. ① 왼쪽의 큰 **민 원판** 1개(중심 [95·231], 반지름 79, 허브 눈 반지름 10 — 살·테 없는 판). ② 가운데 위의 **민판 도르래** 1개(중심 [238·91], 바깥 반지름 40, 허브 눈 반지름 15, 살 없음). 크기: 원판(79) > 도르래(40), 반지름 비 약 2:1. 원판은 줄에 감기지 않는 크랭크 원판, 도르래는 줄을 안내하는 감김 바퀴.
2. 줄·벨트는 몇 개이고, 각각 어디서 시작해 어느 바퀴의 어느 쪽을 차례로 지나 어디서 끝나는가? → 꼬인 줄 1개(빗금 가닥). 시작 = 원판 앞면 핀의 줄 고리(이중 원 [150·261]), 왼쪽 아래에서 도르래로 올라가 도르래 **왼쪽 위**(접점 [202·74])에 얹혀 위를 넘고 **오른쪽**(접점 [276·93])에서 내려와 수직 가닥으로 발판의 눈 볼트 매듭 [271·329] 에서 끝난다. 감긴 각은 판화 순간 약 150° 안팎(왼쪽 위 ~ 위 ~ 오른쪽).
3. 교차하는 가닥이 있는가, 어디서? → 가닥 교차 없음. 겹침 차례: ① 줄이 원판의 오른쪽 위 테 **앞**을 지나간다(테 선이 줄에서 끊긴다). ② 발판 막대가 왼쪽 받침대·받침판 **앞**을 지난다(막대 선이 이어지고 받침 선이 끊긴다). ③ 눈 볼트의 매듭(구슬)은 막대 윗면 위, 아래 고리는 막대 아래에 있다(볼트가 막대를 꿰는 모양).
4. 고정점(천장·벽·바닥)은 어디인가? → 바닥 빗금(전시대 받침 윗면) 위의 주철 받침 둘: 왼쪽 받침대(원판 축을 받침, 받침판 [35~152·380~395])와 오른쪽 받침대(발판 받침 핀을 받침, 받침판 [344~450·380~395], 머리의 핀 눈 [394·307] 이중 원). 도르래의 축 받침은 **그리지 않았다**(도르래가 혼자 떠 보임 — 모형에서는 뒤판 보스 축으로 보충, 해석 절).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 = 원판 앞면에 박힌 핀(축에서 62px = 0.79R, 판화 순간 오른쪽 아래 −29°), 핀에 줄 고리가 걸린다. 발로 밟는 발판 = 긴 막대(오른쪽 끝이 받침 핀에 걸리고 왼쪽 끝 [136~140·350~365] 이 자유 끝 = 밟는 곳). 추·손잡이 없음. 구동은 발판(원문·이름표 기준).
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 도르래는 이 대신 가장자리에 줄 홈이 있고 줄이 홈에 얹혀 마찰로 도르래를 돌린다(물림이 아니라 감김). 맞닿는 짝: 원판 축 ↔ 왼쪽 받침대 구멍(회전), 발판 허브 ↔ 받침 핀(회전), 줄 ↔ 도르래 홈(감김), 줄 고리 ↔ 크랭크 핀(걸림), 눈 볼트 ↔ 발판 막대(조임).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → ① 원판 중심·허브·왼쪽 받침대가 같은 세로선(x 94~95). ② 오른쪽 받침 핀과 받침대 머리가 같은 세로선(x 392~394). ③ 도르래 오른쪽 접점(x 276)과 수직 가닥·매듭(x 269~276)이 거의 같은 세로선. ④ 발판의 받침 핀·눈 볼트·왼쪽 끝이 막대 가운데선 한 직선 위(판화 순간 왼쪽으로 약 10° 기울어짐 — 검산: Q [392·307] → 팁 [136·349] 는 9.6°).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 159 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구 자체는 판화 그대로 계속 돈다. 다만 만들면서 정한 보충·수정 셋: ① 판화의 크랭크(0.79R)를 그대로 쓰면 줄 길이가 고정일 때 발판이 바닥을 뚧는다 → 크랭크를 0.27(0.41R)로 줄였다(실제 발판 기구도 크랭크가 작다). ② 도르래 축 받침이 판화에 없어 뒤판 보스 축으로 보충한다. ③ 판화 순간을 t = 1 로 옮길 때 핀 각 대신 **발판 기울기(약 10°)** 를 판화에 맞춘다 — 줄인 크랭크로는 핀이 −29° 일 때 발판이 수평(−0.3°)이 되어 판화의 기울어진 발판과 어긋나기 때문. 사용자에게 물을 질문은 없다.
- 그 밖의 선: 원판 안의 점선(허브 주위 스트래디움, 폭 52px, 아래로 길게) = 원판에 가린 왼쪽 받침대 머리. 도르래 림의 안쪽 어두운 띠 = 줄이 얹히는 홈. 핀의 이중 원 = 핀과 줄 고리. 매듭 아래의 이중 원 = 눈 볼트의 아래 고리. 바닥 빗금 = 땅(전시대 받침 윗면).

## 해석(결정 사항)
- 판화 좌표를 그대로 모형 좌표로: 원판 축 O = `K159.O` = (−1.1, 1.54), 도르래 중심 C = `K159.C` = (0.08, 2.7), 발판 받침 핀 Q = `K159.Q` = (1.37, 0.91). 눈금 검산 — O ↔ C 거리 1.656 = 138px(예측 [236.5·91.5] vs 측정 [238·91]), Q 예측 [391·306] vs 측정 [392~394·307] : 몇 px 안에서 일치.
- 크랭크만 줄임: 판화 0.515(0.79R) → `K159.crank` = 0.27(0.41R). 이유는 질문 9번 ①.
- 판화의 순간(발판이 왼쪽으로 약 10° 기울어짐)을 t = 1 로 맞춘다 — `K159.pose` = 10° (핀 각은 +10° 가 된다).
- 회전 방향은 판화에 없다 → 원판 반시계(158 과 같은 선택).
- 도르래는 줄에 미끄럼 없이 붙어 돈다고 둔다 — 줄 양쪽 가닥 길이의 변화만큼 앞뒤로 돌고, 원판 한 바퀴(한 주기)마다 정확히 제자리로 돌아온다(누적 회전 없음).
- 층(앞뒤 차례, 판화대로): 받침대 둘(맨 뒤) → 원판 → 발판 막대 → 줄·도르래·줄 고리·눈 볼트(맨 앞, 한 평면).
- 원판 뒤의 점선 머리는 실제 받침대(키트 종 모양 받침대)가 그 역을 한다 — 점선을 따로 만들지 않는다.

## 구동
실제로는 발판을 발로 밟아 줄을 당겨 원판을 돌리지만, 모형의 운동식은 원판 각 theta 로 쓴다(원판의 관성이 사점을 넘긴다 — 158 과 같음). theta += OMEGA(1.6)·speed·dt, 원판 반시계. 한 바퀴 3.93 s 에 발판이 한 번 오르내리고 도르래가 앞뒤로 한 번 흔들린다.

## 동작 (모두 theta 의 닫힌 식 — `treadle159(theta)` 가 돌려준다)
`S = treadle159(theta)` → { a, pin, down, end, pulley, wrapDeg }.
- 원판: `disc.rotation.z = S.a` = theta − 1.6 + 10°. 크랭크 핀 pin = O + 0.27·(cos a, sin a).
- 발판: 기울기 down(왼쪽 끝이 내려간 각)은 **줄 온 길이가 늘 변하지 않는다**는 조건의 해 — `cordLength159()` = 4.1832(핀 고리 중심 ~ 발판 매듭, 핀이 도르래에 가장 가까운 자세에서 정한 온 길이)에 맞추는 이분법 40회. `treadle.rotation.z = S.down`. 범위(측정): −16.0°(위, theta 5.54) ~ +15.0°(아래, theta 2.40 — `K159.low` 기계적 끝점, 흔들림 31°).
- 줄 끝(매듭) end = `cordEnd159(down)` = Q + 1.01·(−cos down, −sin down) + 0.055·(막대 위쪽 법선). 범위 y 0.702 ~ 1.242.
- 도르래: `pulley.rotation.z = S.pulley` = (접점 각 변화) − (발판 쪽 가닥 길이 변화)/rc — 줄 위의 한 점이 도르래에 붙어 미끄럼 없이 따라 돈다. 한 바퀴 동안 0° ~ 94.6° 사이를 앞뒤로 왔다 갔다 하고 한 주기마다 제자리(누적 0).
- 감긴 각 S.wrapDeg = 138.4° ~ 157.2°(도르래 왼쪽 위 접점 각 137°~156°, 오른쪽 접점 각 −20°~+18° — 감긴 호의 한가운데는 거의 위(76°)).
- 빠른 되돌림 없음 — 발판의 오르내림이 원판 한 바퀴에 한 번씩 반반.
- 시각: **t = 1.0 (핀 10°, down 9.5° — 판화의 발판 자세)**, **t = 1.6 (핀 65°, down 14.8° — 발판 최저 근처, 팁 y 0.36)**, t = 2.2 (핀 120°, down 5.2°), t = 2.8 (핀 175°, down −8.8° — 발판이 올라감), **t = 3.4 (핀 230°, down −15.9° — 발판 최고, 팁 y 1.50)**, t = 30 (핀 148°, down −2.4°).

## notes
① 원판 회전수 'N.NN회'(theta/2π) ② 발판 기울기 'NN.N°(−16° ~ 15°)' ③ 도르래 감긴 각 'NNN°(138° ~ 157°)' ④ 줄 온 길이 '4.18(불변)' ⑤ '발판 한 번 왕복 = 원판 한 바퀴' ⑥ '도르래는 줄을 따라 앞뒤로 — 누적 회전 없음'.

## 확인
- t = 1 정면: 판화와 같은 모양(발판이 왼쪽으로 9.5° 기울고 줄이 도르래 왼쪽 위에서 오른쪽으로 감겨 수직으로 내려오며 핀이 원판 오른쪽에 있다 — 판화의 핀 −29° 대신 +10°, 질문 9번 ③). t = 1.6 정면: 발판이 최저 근처(14.8°), 왼쪽 끝 y 0.36. t = 3.4: 발판 최고(−15.9°), 왼쪽 끝이 원판 오른쪽 아래 테 앞(층이 달라 겹치는 것은 정상)까지 올라감.
- 근접 `cam=0.08,2.7,1.3,0.08,2.7,0.15`(도르래 감김·홈), `cam=-0.83,1.6,1.5,-0.83,1.59,0.15`(크랭크 핀·줄 고리), `cam=0.37,0.8,1.4,0.37,0.8,0.15`(눈 볼트 매듭·아래 고리), 옆 `cam=3.6,1.6,0.15,0,1.6,0.15`(층 차례: 받침대 → 원판 → 발판·줄·도르래), 위 `cam=0,4.5,0.5,0,1.6,0.1`.
- 수치(키트 식 검산 — 이 설계표를 쓰며 돌림): down −16.02° ~ +15.00°(아래 끝은 15° 에서 막힘), 감긴 각 138.4° ~ 157.2°, 줄 온 길이 4.1832 한 주기 시작·끝 같음(152.1135° 감긴 간으로 닫힘), 도르래 각 0° ~ 94.6° 앞뒤, 발판 왼쪽 끝 y 0.351(최저 — 막대 아랫면 0.321, 왼쪽 받침판 윗면 0.27 보다 0.05 위) ~ 1.506(최고).
- 눈으로: 줄이 도르래 홈에 앉아 있는가(테에 묻히지 않는가), 너트·매듭이 도르래·막대에 파묻히지 않는가, 발판이 올라갈 때 막대 끝이 원판 앞을 지나는가(층 확인).
