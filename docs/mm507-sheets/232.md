# 232 끌어 당기는 폴
원문(en): "Intermittent circular motion is imparted to the toothed wheel by vibrating the arm, B. When the arm, B, is lifted, the pawl, C, is raised from between the teeth of the wheel, and, traveling backward over the circumference, again drops between two teeth on lowering the arm, and draws with it the wheel." — 팔 B를 진동시켜 톱니바퀴에 간헐 원운동을 준다. 팔 B를 들어 올리면 폴 C가 바퀴의 이 사이에서 들려 올라가 둘레 위를 뒤로 이동하고, 팔을 내리면 다시 두 이 사이로 떨어져 바퀴를 함께 끌고 간다.
쉬운 풀이: 팔을 올리면 폴이 이를 타 넘어 뒤로 물러나고, 내리면 이 사이에 걸려 바퀴를 한 칸 끌어당긴다. 팔이 오르내릴 때마다 바퀴가 조금씩 돈다.
판화 묘사(원본 448×437 px, [x·y]): 큰 **네모 이 톱니바퀴**(중심 약 [193·226], 이끝 반지름 173 px, 이뿌리 151 px, 이 20개, 이 윗면 폭 약 8°·이골 바닥 약 9°). 바퀴 축 [190·229] 에서 오른쪽으로 곧은 **팔 B** 가 판 밖까지. 같은 축에서 위로 굽은 판 **A**: 위 끝 구멍 [196·47](바퀴 이끝 원 바로 밖), 오른쪽 아래가 넓어져 구멍 둘 [277·188]·[277·248](팔 B 의 위·아래 — B 는 아래 구멍에 닿아 있음). B 의 [246·228] 에서 세로 **연결 막대**가 위로 [246·47] 까지. 위쪽 오른쪽에 반달꼴로 휜 **폴 C**: 왼쪽 끝이 A 위 구멍 근처, 몸이 바퀴 둘레를 따라 시계 쪽으로 휘어 끝 코 [303·120] 가 이 둘 사이(이골)에 들어감.

## ★ 판화 읽기
판화 1 px = 0.0055. 세계 x = −0.35 + (px − 193)·0.0055, 세계 y = 1.25 + (226 − py)·0.0055.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 톱니바퀴 1개(이끝 0.95, 이뿌리 0.83, 네모 이 20개).
2. 줄·벨트는 몇 개이고 어디서 시작해 어디서 끝나는가? → 없음. 대신 곧은 연결 막대 하나: B 의 핀 [246·228] → C 꼬리 핀 [246·47](세로).
3. 교차하는 가닥이 있는가? → 없음. 겹침 차례(앞→뒤): 연결 막대 → B → A(멈춤 핀 둘 포함) → 바퀴·C(같은 판).
4. 고정점(천장·벽·바닥)은 어디인가? → 바퀴 축 하나(판화에 받침 없음 → 뒤판 축). A·B·바퀴가 모두 이 축에 따로 끼워져 돈다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → B 의 오른쪽 끝(판 밖)을 흔든다("vibrating the arm, B"). 모형: B 의 반지름 1.2 자리에 연결봉 → 오른쪽 아래 크랭크(보충).
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 바깥 둘레의 대칭 네모 이(판화대로, 갈고리 면 없음). C 의 쐐기 코가 바퀴 위 오른쪽(바퀴 중심에서 44°) 이골에 들어가, B 를 내리면 A·C 가 함께 **시계**로 돌며 코의 시계 쪽 면이 이 옆면을 민다 → 바퀴 **시계**.
7. 한 줄에 놓인 것은? → 연결 막대가 세로(B 핀과 C 꼬리 핀이 같은 x [246]). A 의 두 멈춤 구멍이 같은 x [277]. B·A·바퀴가 같은 축.
8. 판화에 글자(A, B…)가 가리키는 부품은? → A = 위로 굽은 판(폴 C 를 받치는 들보, 원문에는 없음), B = 흔드는 팔, C = 폴. 이름표에 그대로.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문은 A 를 말하지 않는다. 판화를 이렇게 읽었다: **A 는 축에 헐겁게 끼운 들보**, B 는 A 의 두 멈춤 핀 사이에서 **14.72° 만큼 헛돈다**. 그 헛도는 동안 연결 막대가 C 를 들거나 내리고, 멈춤 핀에 닿은 뒤에는 A·C·B 가 한 덩이로 돈다(이 동작이 원문 "들려 올라가 → 뒤로 → 떨어져 → 끌고 감" 과 그대로 맞는다). 또 판화의 C 피벗(바퀴 중심에서 0.985)은 C 허브가 이끝 원(0.95)과 겹쳐 **1.025 로 0.04 바깥**으로 옮겼다. → ★질문 거리.

## 다섯 장 공통 폴·이 규칙 (225·232·235·236·237 같음)
- 폴(태핏·멈춤 폴 포함) **코 끝은 원 반지름 rn = 0.014**, 코와 몸이 만나는 **오목 목은 필릿 0.02**, 나머지 볼록 모서리 0.006 — 아래 점열에 이미 들어 있다(155 "폴 닿는 곳이 각져 보임" 방지). 점열을 고치거나 다시 그리지 말 것.
- **톱날 이(225·236·237)**: 곧은 면이 반지름선(237 은 띠의 수직선)에서 **20° 갈고리꼴**, 비탈은 이끝 → 다음 이뿌리 직선, 이끝은 뾰족. 판화가 대칭 이를 그린 **232(네모 이)**·235(별 이)만 판화를 따른다 — 232 는 C 가 구동 중 A 에 잠겨(B 가 멈춤 핀에 눌림) 빠질 수 없어 갈고리 면이 필요 없다.
- 폴의 **미는 면은 이 옆면에서 여유**를 두어 코만 닿는다(232: 시계 쪽 면 틈 0.0005, 반시계 쪽 0.012, 코 끝은 이뿌리 위 0.012).
- 색: **거는 폴 = 그 폴 재질 emissive 0x7a4a00(주황빛), 쉬는 폴 = 0x000000**.
- 재질: 바퀴는 `steel()`(밝음 — 이가 보이게, 검은 재질 금지), 폴은 `brass()`, 팔·들보는 `castIron()`.

## 해석(결정 사항)
- 크랭크 한 바퀴 = B 가 내렸다 올림. 네 구간: **떨굼**(B 가 A 에 대해 헛돌며 C 가 이골로 떨어짐, A·바퀴 그대로) → **끎**(B 가 아래 멈춤 핀에 닿아 A·C 와 한 덩이로 시계 18°, 바퀴도 함께 — C 주황빛) → **들어올림**(B 가 반대로 헛돌며 C 가 이골에서 들림, A·바퀴 그대로) → **되돌아감**(B 가 위 멈춤 핀에 닿아 A·들린 C 와 반시계 18°, 바퀴는 그대로).
- A 는 헛도는 구간 동안 축의 마찰(가벼운 와셔)로 서 있고, 바퀴도 축 마찰로 선다. 한 주기 정확히 **1이(18°)** 시계.
- C 의 앉은 자리·쐐기는 판화의 코 자리(바퀴 중심에서 반지름 0.840, 방위 43.94°)에 맞췄다. 들린 C 는 이끝 위 0.020 이상 뜬다.
- 판화에 없는 보충: 크랭크 원판·크랭크 축·연결봉(B 의 반지름 1.2 자리), 바퀴 축(A·B 공용).

## 구동
`theta += OMEGA * speed * dt`(크랭크 각, OMEGA 1.6 rad/s, 한 주기 3.92699 s). 모든 자세는 `state232(theta)` 닫힌 식(표 없음).

## 동작 (`state232(theta)` — 닫힌 식, 각 rad, 표는 도)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀 P = K + rk·(cos(thF + u), sin(thF + u)).
2. B 의 크랭크 점 E = `circleIntersect([-0.35, 1.25], 1.2, [P.x, P.y], 0.758043, true)`, β = atan2(E.y − 1.25, E.x + 0.35). (u = 0 → β = 21.5636°(위 끝), u = π → −11.1601°(아래 끝), 정확히.)
3. A 각: u < π(**B 내림**): α = min(9°, β − δlo). u ≥ π(**B 올림**): α = max(−9°, β − δhi). 헛돎 δ = β − α.
4. C 들림 σ(δ): A 기준에서 Bp = 0.2917·(cos δ, sin δ), Ct = `circleIntersect(CpA, 0.275, Bp, 1.035851, true)`, σ = atan2(Ct.y − CpA.y, Ct.x − CpA.x). (σ(δlo) = 0, σ(δhi) = 15.7060°.)
5. 바퀴 시계 누적각 Φ: u < π: Φ = n·18° + (9° − α); u ≥ π: Φ = n·18° + 18°. 끎(구동) = u < π 이고 β − δlo < 9°. `wheel.rotation.z = rho0 − Φ`, rho0 = 44.2900°.
6. 적용: `carrierA.rotation.z = α`, `armB.rotation.z = β`, `pawlC.position = O + R(α)·CpA`, `pawlC.rotation.z = α + σ`. 연결 막대·크랭크 연결봉은 표식 `bPin`·`cTail`·`crankPin`·`bPin2` 의 세계 좌표로.
7. 구간 경계(기대값): 떨굼 u 0° ~ 68.10°, 끎 68.10° ~ 180°, 들어올림 180° ~ 273.95°, 되돌아감 273.95° ~ 360°.
8. 검산(파이썬 shapely, 한 주기 2880 시각): C × 바퀴 겹침 넓이 0. 최소 틈 — 떨굼 0.0005(쐐기 면이 이 옆면을 스침), 끎 0.0003(닿음), 들어올림 0.0003 → 커짐, 되돌아감 0.0203(들린 C 의 가장 낮은 점 반지름 0.970 > 이끝 0.95).
