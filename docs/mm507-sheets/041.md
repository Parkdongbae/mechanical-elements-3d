# 041 비스듬한 톱니 기어
원문: 회전을 회전으로 바꾼다. 이가 비스듬해 보통의 평기어보다 더 연속적으로 물린다(42·43 참조).

## ★ 판화 읽기
판화는 그림 하나(두 기어를 **옆에서 본 모습** — 축이 종이 위에 가로로 누워 있다).
1. 바퀴는 몇 개이고 크기 차례는? → 기어 2개. 위가 작고 아래가 크다(판화 높이 352 : 500, 지름비 약 0.70). 둘 다 폭이 같고 좁다(아래 지름의 약 0.25배).
2. 줄·벨트는? → 없음(기어끼리 직접 물림).
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다. 두 축이 좌우로 잘린 채 나와 있을 뿐(베어링은 그리지 않음).
5. 추·손잡이·크랭크는? → 없음. 어느 쪽이 구동인지도 판화·원문에 없다(모형은 위 작은 기어를 구동으로).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 둘 다 바깥 둘레에 이. 위 기어의 아랫부분과 아래 기어의 윗부분이 한가운데(두 원통이 맞닿는 가로선)에서 물린다. 원통 위의 빗금이 이 줄이다: 위 기어는 `/`(오른쪽으로 올라감), 아래 기어는 `\` — 서로 반대 방향(평행축 헬리컬의 조건). 빗금이 축(가로)과 이루는 각은 위 약 30°, 아래 약 37° → 헬릭스각 35°로 잡는다.
7. 한 줄에 놓인 것은? → 두 기어의 폭 가운데가 같은 세로선(x 같음), 두 축은 서로 평행한 가로선.
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없다(없음).
- 그 밖의 선: 기어 양쪽 면의 두 겹 네모 = 허브 고리(큰 플랜지 + 작은 보스). 위 기어 맨 위·맞닿는 곳·아래 기어 맨 아래의 촘촘한 빗금은 둥근 면의 음영.

## 구동
위(작은) 기어 theta += OMEGA·speed·dt (축 X 둘레).

## 부품과 치수 (키트: `helicalGear`, 이미 구현됨)
- 위 기어 A(구동, bronze, name `gearA`): 잇수 ZA=20, 아래 B(name `gearB`): ZB=28. MOD = 0.92/28 = 0.032857(B 피치 반지름 0.46, A 피치 반지름 0.3286, 이끝 0.361/0.493). 중심 거리 DIST = MOD·48/2 = 0.78857.
- 폭 0.25, 헬릭스각 35°. A: `helicalGear(20, MOD, { width: 0.25, helix: rad(35), hand: -1, driver: true })`, B: `helicalGear(28, MOD, { width: 0.25, helix: rad(35), hand: 1 })`. (hand −1 ⇒ 정면에서 이 줄 `/`, +1 ⇒ `\`.)
- 축 깊이 ZC = 0.27. 중심 y: B 는 Y2 = 1.32, A 는 Y1 = Y2 + DIST = 2.1086. x = 0.
- 축: `rod(v(-0.55,y,ZC), v(0.55,y,ZC), 0.045)` 두 개.
- 받침(판화에 없음, 최소): m040 처럼 x=±0.45 에 뒤판에서 나온 기둥(반지름 0.07, z −0.3 ~ ZC)과 끝 고리, 축마다 2개.
- 허브 고리는 helicalGear 가 `collars` 로 이미 포함.

## 동작
- 자세: A.quaternion = Rx(theta)·Ry(90°), B.quaternion = Rx(meshAngle([0,0],20,theta,[0,−DIST],28))·Ry(90°) (m040 방식, 로컬 Z → 세계 +X).
- 속도비 ωB/ωA = −20/28 = −0.714. 절대 각으로 매 프레임 계산.

## 표시
- rotArrow(0.4): A 는 ccw=true, B 는 false, YZ 평면(rotation.y=π/2), x = 0.52 (m040 과 같음).
- tag 3개: '구동 기어(비스듬한 이)' (−1.3, 2.11, 0.5), '피동 기어(반대로 비스듬)' (−1.3, 1.32, 0.5), '이가 비스듬해 부드럽게 물린다' (1.4, 1.7, 0.5).
- notes: 잇수 `20 : 28`, 속도비 `1 : 0.71 (반대 방향)`, 이 모양 `비스듬한 이(헬릭스각 35°) — 이 하나가 빠지기 전에 다음 이가 물림`.

## 확인
- t=1, 1.6: 위 기어 노란 표시선이 돌고 아래 기어는 0.71배로 반대로 돈다. 정면에서 위 이 줄 `/`, 아래 `\`. 비스듬히 `cam=1.6,1.9,2.2,0,1.7,0.27` 로 물림이 박히지 않음.
