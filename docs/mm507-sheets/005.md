# 005 조임 풀리(벨트 클러치)
판화: 001 과 비슷한 위아래 풀리(아래가 작다)와 느슨한 벨트, 왼쪽에 손잡이 달린 작은 조임 풀리 B. 원문: B 를 벨트에 밀어 느슨함을 없애면 큰 풀리의 운동이 전달되고, 떼면 벨트가 헐거워 전달되지 않는다.

## 부품과 치수
- `displayStand()`
- 풀리 A(구동) r = 0.48, 중심 (0.25, 2.6). 풀리 C(종동) r = 0.30, 중심 (0.25, 0.95). `shaftZ` 2개.
- 조임 풀리 B: r = 0.14. 레버 받침점 F = (-0.95, 1.55) 에 `shaftZ`. `lever(0.75, { handle: true })` 를 F 에 달고, 레버 위 받침점에서 0.45 떨어진 곳에 B 가 자유 회전. 레버 각 a: **떼었을 때 a0 = 2.2 rad**(B 가 벨트에서 떨어짐), **눌렀을 때 a1 = 0.15 rad**(B 가 왼쪽 가닥을 안쪽으로 0.12 밀어 넣음).
- 벨트: 길이를 일부러 길게 — 느슨할 때는 왼쪽 가닥이 바깥으로 불룩한(처진) 경로, 조였을 때는 A → B → C 를 지나는 팽팽한 경로. 두 경로의 점 개수를 같게 만들어 `k`(0~1)로 보간한 점열로 매 프레임 `Belt` 지오메트리를 갱신한다 → **키트 추가**.

## 키트 추가
- `Belt.setPath(path: THREE.Vector3[]): void` — 같은 점 개수의 새 경로로 지오메트리를 갱신(버퍼 재사용). 기존 시그니처는 그대로.

## 동작 (주기 6초, 시간 누적 T += dt × |speed|)
- 0~2s: 떼어 있음(k = 0). A 만 회전, C 정지, 벨트 표시 정지.
- 2~2.6s: 레버가 a0 → a1 (k: 0 → 1).
- 2.6~5s: 조임. C 회전(각속도 = A × 0.48 / 0.30), B 회전, 벨트 표시가 흐름.
- 5~6s: 레버 복귀(k → 0), C 는 관성으로 0.5s 동안 감속 정지.
- A 는 항상 theta 로 회전. C·B·벨트 offset 은 "전달된 벨트 이동량" s 를 따로 누적(s += v × k × dt)해 그 값에서 계산.

## 표시
- tag '구동 풀리', '종동 풀리', '조임 풀리 B'. notes: `[{ label: '조임 풀리', value: 눌림 ? '누름 — 전달' : '뗌 — 미끄러짐' }, { label: '종동 풀리', value: 회전 ? '회전' : '정지' }]`

## 확인
- t=1(뗌): 벨트가 불룩하고 C 의 스포크가 t=0.5 캡처와 같다. t=3.5(조임): 벨트가 팽팽하고 C 가 돈다.
