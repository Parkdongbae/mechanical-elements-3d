# 121 디스크 휠과 클릭
원문 요지: 디스크 휠에 붙은 **막대의 번갈아 하는 직선 운동**이, 디스크 휠에 달린 **클릭(걸쇠)** 을 통해 **코그휠(톱니바퀴)** 에 간헐 회전을 준다. 클릭을 뒤집어 놓으면 방향이 바뀐다. 평삭기 같은 공작 기계의 이송에 쓰인다.
판화(public/mm507/fig/121.png, 4배 확대 `shots/_verify/121-fig-x4.png`, 이 수를 센 그림 `shots/_verify/121-count.png`): 그림 하나(정면). 큰 민 원판(디스크) 앞 가운데에 같은 축의 톱니바퀴, 디스크 위쪽에 못으로 달린 걸쇠(코 끝이 톱니바퀴 윗니 사이에 들어가 있다), 디스크 오른쪽에 못으로 달려 위로 뻗은 막대.

## ★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 2개(같은 축). 디스크 휠(민 원판, 반지름 660px) > 코그휠(이끝 반지름 430px, 이뿌리 ≈ 350px, 네모꼴 이 **약 26개** — 15° 눈금을 겹쳐 세면 90° 에 6.3~6.5개). 가운데 겹원 = 코그휠의 허브와 축(빗금 원).
2. 줄·벨트는? → 없음. 대신 곧은 **막대 1개**: 디스크 오른쪽의 못(축에서 507px, 수평에서 15° 아래)에 눈(고리)으로 걸려 거의 곧장 위로 830px 뻗는다(위 끝은 디스크 위 끝보다 조금 높고 둥글게 끝남 — 더 이어지는 막대).
3. 교차하는 가닥은? → 없음. 겹침: 코그휠·걸쇠·막대가 모두 디스크 **앞**에 있다. 막대의 눈은 코그휠 이끝 바로 옆(닿지 않음).
4. 고정점은? → 판화에는 받침이 없다. 가운데 축 하나뿐(디스크와 코그휠이 같은 축 위에서 따로 돈다).
5. 추·손잡이·크랭크는? → 없음. 구동은 막대(원문: alternating rectilinear motion of the rod). 막대를 오르내리게 하는 것은 판화에 없다.
6. 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 코그휠은 바깥 둘레 전체에 좌우 대칭인 네모꼴 이. 걸쇠의 **아래 갈래 끝**이 위쪽(축에서 62° 방향)의 이골에 **바깥에서** 들어가 있다. 걸쇠의 못은 그보다 왼쪽(100° 방향, 축에서 498px) — 코가 못보다 시계 방향 쪽에 있으므로 디스크가 **시계 방향**으로 돌 때 코가 앞의 이를 밀고, 반시계로 돌아갈 때는 이 위를 타 넘는다.
7. 한 줄에 놓인 것은? → 디스크·코그휠·축이 같은 중심. 막대는 거의 세로(못 x 1360px, 위 끝 x 1400px — 3° 기울기). 걸쇠의 앞면(오른쪽 가장자리)은 위 갈래 끝에서 아래 갈래 끝까지 한 직선.
8. 글자가 가리키는 부품은? → 글자 없음(번호 121 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 같은 기구이고 그대로 돈다. 다만 판화 그대로의 이 폭이면 걸쇠 코가 이골 바닥까지 들어가지 못해(코가 22° 기울어 있다) 이를 조금 좁히고 코를 얕게 앉혔다(아래 "맞물림 측정"). 기구는 같다.
- 그 밖의 선: 걸쇠의 위 갈래(위로 솟은 뿔) = 뒤집었을 때 쓰는 반대쪽 코(걸쇠는 팔을 축으로 위아래 대칭). 막대 아래의 네모 = 눈과 막대 사이의 목. 디스크 오른쪽 위의 직선 = 막대 뒤로 지나는 디스크 테두리(막대에 가려 끊긴 것). 디스크 아래의 굵은 선 = 그림자.

## 해석(결정 사항)
- 판화의 순간 = **미는 행정의 끝**(막대가 가장 내려가고 코가 이골에 깊이 든 순간). 막대가 내려가면 디스크가 시계 방향으로 30° 돌고 코그휠을 이 2개만큼 민다. 막대가 올라가면 디스크만 되돌아가고 걸쇠는 이 2개를 타 넘는다.
- 코그휠은 돌아가는 동안 제자리에 선다고 본다(판화에 멈춤쇠 없음 — 이송 나사의 마찰).
- 걸쇠는 무게(와 누름)로 이에 얹힌다고 본다. 뒤집은 자세(반대 방향)는 만들지 않는다 — notes 로만 알린다.
- 보충(판화에 없음): 막대 위 끝의 미끄럼 블록과 세로 안내틀(막대가 "곧게" 오르내리게 하는 받침), 축 받침 보스.

## 구동
막대의 왕복(theta 누적): theta += OMEGA(1.6)·speed·dt. 주기 위상 v = (theta − 1.6 + π) 를 2π 로 나눈 나머지. 0 ~ π = 미는 행정, π ~ 2π = 돌아가는 행정. 한 주기 3.93 s.

## 부품과 치수 (새 부품은 `kit/k119.ts`, 이미 구현됨. 치수 상수 `K121`)
배치 상수: CX = −0.3, CY = 1.3 (축 중심), ZD = −0.05 (디스크 가운데 평면), ZG = 0.04 (코그휠·걸쇠 평면), ZL = 0.05 (막대 평면), GX = 0.475 (안내틀 가운데선 = CX + 0.775), ZS = −0.16 (안내틀·블록 가운데 평면).
- 디스크(name `disk`): `diskWheel121()` — 반지름 1.0, 두께 0.06, 주철. 앞면에 걸쇠 못(child `clickPivot`, 로컬 (−0.485, 0.578, 0.09) = 반지름 0.755·130°)과 막대 못(child `rodPin`, 로컬 (0.742, 0.199, 0.1) = 반지름 0.768·15°). 위치 (CX, CY, ZD), rotation.z = disk(θ). **디스크 각 0 = 막대가 가장 올라간 자세**, 판화 자세는 −30°.
- 코그휠(name `cog`): `cogWheel121()` — 이 26개, 이끝 0.652, 이뿌리 0.53, 폭 0.08, 황동 + 허브 고리. 위치 (CX, CY, ZG), rotation.z = cog(θ). 그룹이 기어 표식, 몸통에 `userData.outline`.
- 걸쇠(name `click`): `click121()` — 못에서 앞면까지 0.408, 갈래 반길이 0.232, 두께 0.06, 강철. **디스크의 자식**으로 `clickPivot` 자리(로컬 (−0.485, 0.578, 0.09))에 두고 rotation.z = click(θ) (디스크 로컬 각). 판 메시에 `userData.outline`.
- 축: `shaftZ(CX, CY, 0.17, 0.06)`, rotation.z = cog(θ) (코그휠과 한 몸 = 이송 축).
- 막대(name `rod`): `connectingRod(1.25)` (k092) — 원점(한쪽 눈)을 막대 못에 두고 rotation.z = rodAngle(θ). 위치 (CX + pin[0], CY + pin[1], ZL).
- 미끄럼 블록(name `slider`, 판화에 없음): `crosshead(0.3, 0.374, { pinZ: 0.21, pinTop: 0.27 })` (k092) — rotation.z = π/2 (세로로 미끄러짐). 위치 (GX, CY + top(θ), ZS). 핀 표식 child `wristPin` 이 막대 평면에 온다(ZS + 0.21 = ZL).
- 안내틀(고정, 판화에 없음): `guideFrame(0.8, 0.38, { back: 0.14 })` (k092) — rotation.z = π/2 (끝 막이가 아래, 가로대가 위로 0.8). 위치 (GX, 2.17, ZS). 안쪽 홈 세로 2.17 ~ 2.97, 블록 몸통은 2.20 ~ 2.90 을 다닌다. 받침 기둥 4개가 뒤판에 닿는다.
- 받침대·뒤판 `displayStand()`.
- 전체 범위: 가로 −1.3 ~ 0.795, 세로 0.3 ~ 2.97.

## 맞물림 측정 (`shots/_verify/s121.mjs` — 키트 식 그대로, 한 주기 3000 시각)
- 이 꼴: 이끝 폭이 피치의 32 %, 이뿌리 폭 40 %(판화는 반쯤). 걸쇠 코는 이뿌리에서 0.03 떠서 앉는다. 판화 폭 그대로(42~50 %)면 앉은 자리에서 코의 등과 뒤 이가 0.016~0.03 겹쳤다.
- 걸쇠×코그휠 최대 침범 0.0002, 미는 동안 코 앞면과 이 사이 틈 0.0003(닿아 있음), 걸쇠 최대 들림 11.85°.
- 한 주기 코그휠 회전 −27.6923° = 정확히 이 2개(주기 이음 차 0), 막대 위 끝 높이 1.0508 ~ 1.4483(행정 0.3975), 막대 기울기 최대 1.52°.

## 동작 (닫힌 식 + 들림 표 — `feed121(theta)` 가 { v, n, disk, cog, click, pin, top, rodAngle, driving } 을 돌려준다)
- w = 30°·(1 − cos v)/2 (디스크가 위 끝에서 시계 방향으로 돈 각). disk = −w.
- 헛걸음 eps = 30° − 2·(360°/26) = 2.308°. 밀린 각 adv = (v ≤ π) ? min(27.692°, max(0, w − eps)) : 27.692°.
- cog = cog0 − eps − n·27.692° − adv (n = 지난 주기 수, cog0 = 디스크 각 0 에서 코가 이에 닿아 앉는 코그휠 각 — 키트가 접촉을 풀어 구함). 시계 방향으로 주기마다 정확히 이 2개.
- 걸쇠: q = eps + adv − w (코그휠 기준으로 디스크가 앉은 자리에서 물러난 각, 0 ~ 30°). click = `clickBase121()` + `clickLift121(q)`. 들림 표는 한 이 피치를 120 등분해 "닿지 않는 가장 작은 들림 각"을 풀어 둔 것(q = 0 에서 0, 이를 넘을 때 최대 11.85°, 다음 이골로 떨어지며 0).
- 막대 못 pin = 0.768·(cos(15° − w), sin(15° − w)) (축 중심 기준). 위 끝 top = pin[1] + √(1.25² − (0.775 − pin[0])²), rodAngle = atan2(top − pin[1], 0.775 − pin[0]).
- 시각: **t = 1 (v = π, 판화 자세: 디스크 −30°, 코가 이골에 앉음, 막대 맨 아래)**, t = 1.6 (돌아가는 중, 걸쇠가 이 위로 8.9° 들림), t = 2.96 (v = 2π, 디스크 0°, 막대 맨 위), t = 4 (미는 중: 디스크와 코그휠이 함께 돈다), t = 4.93 (다시 판화 자세, 코그휠은 이 2개 나아감).

## notes

## ★ 깊이 계산
