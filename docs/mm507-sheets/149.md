# 149 캠 두 개와 지레 두 개
원문 요지: "고른 원운동이, 캠이 지레에 작용함으로써, 지레에 매단 막대들의 번갈아 하는 직선 운동으로 바뀐다."(이 한 문장이 전부) — 한 축에 꿴 캠 두 개가 지레 두 개를 차례로 들어 올려, 지레 가운데에 매달린 막대 두 개가 번갈아 오르내린다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/149-fig-x4.png` 로 다시 읽음. 치수는 4배 확대 px.
1. 바퀴는 몇 개이고 크기 차례는? → 캠 2개(둥글지 않은 달걀 꼴, 같은 크기로 봄)와 굴림 바퀴 2개(지레 끝, 같은 크기 — 반지름 70~85). 캠 축은 하나(오른쪽 아래의 원, 반지름 90, 중심 x 1730 · y 1030). 앞 캠은 윤곽이 다 보이고 뾰족한 쪽이 왼쪽 살짝 아래(축에서 왼쪽 340, 오른쪽 170, 위 115, 아래 235). 뒤 캠은 뾰족한 쪽이 위(축에서 위로 420)이고 아래쪽은 앞 캠에 가려졌다.
2. 줄·벨트는? → 없음. 대신 곧은 **막대 2개**가 지레 가운데의 핀에서 아래로 매달려 있다(위 지레의 막대는 x 1265 · y 630 에서 y 1410 까지, 아래 지레의 막대는 x 1315 · y 835 에서 y 1460 까지). 두 막대는 나란히 붙어 내려간다.
3. 교차하는 가닥은? → 줄은 없음. 겹침 순서: 위 지레의 막대는 아래 지레 **뒤**로 지나간다(아래 지레의 선이 끊기지 않음). 아래 지레의 굴림 바퀴는 뒤 캠의 **앞**에 그려졌다 → 뒤 평면 = 위 지레 + 뒤 캠(뾰족한 쪽이 위), 앞 평면 = 아래 지레 + 앞 캠(뾰족한 쪽이 왼쪽).
4. 고정점은? → 왼쪽의 큰 고리(두 겹 원, 중심 x 478 · y 815) = 두 지레가 함께 꿰인 받침 축. 캠 축은 제자리에서 돈다. 받침대·막대 안내는 그리지 않았다.
5. 추·손잡이·크랭크는? → 없음. 구동은 캠 축(원문: 캠이 지레에 작용).
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 뒤 캠 윤곽 ↔ 위 지레의 굴림 바퀴(캠 꼭대기 위에 얹힘, 바퀴 중심이 축에서 510 위), 앞 캠 윤곽 ↔ 아래 지레의 굴림 바퀴(캠의 낮은 등에 얹힘, 바퀴 중심이 축에서 195 위). 회전 짝: 지레 ↔ 받침 축, 지레 가운데 핀 ↔ 막대 위 끝의 갈래(작은 두 겹 원 + 네모 꼭지).
7. 한 줄에 놓인 것은? → 두 지레의 받침점이 같은 점. 두 굴림 바퀴는 캠 축의 거의 바로 위(세로선 x 1745·1790 과 축 x 1730). 두 막대는 거의 같은 세로선(x 1265·1315). 받침점에서 굴림 바퀴 중심까지는 두 지레가 같다(1301·1312).
8. 글자가 가리키는 부품은? → 글자 없음(번호 149 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음, 판화대로 계속 돈다(문제 없음). 다만 두 캠의 윤곽이 손그림이라 서로 조금 다르다(앞 캠 긴 반지름 340, 뒤 캠 420) → 같은 캠 두 장으로 만든다(질문 거리는 아님).
- 그 밖의 선: 지레는 가운데(막대 핀 둘레)가 불룩하고 양끝으로 가늘어지는 꼴 — 모형은 곧은 막대에 가운데 보스. 막대의 세로 두 줄 = 둥근 막대의 양쪽 윤곽선.

## 해석(결정 사항)
- 축척 1/520(4배 px → 모형 길이). 받침점 ~ 굴림 바퀴 2.52, 받침점 ~ 캠 축 가로 2.4·세로 0.4(축이 아래).
- 두 캠은 같은 달걀 꼴(바탕 원 0.26, 꼭대기 0.72 = 양정 0.46, 혹의 반각 120°). 판화 자세에서 앞 캠 꼭대기 200°, 뒤 캠 꼭대기 85°(115° 차) — 그대로 한 축에 고정.
- 회전 방향은 판화에 없다 → 반시계로 정함. 판화의 순간(위 지레가 꼭대기, 아래 지레가 바닥)을 t = 1 로.
- 판화의 두 평면을 깊이 0.36 만큼 벌린다(앞·뒤 캠이 서로 닿지 않고, 침범 검사가 층을 구별하게).
- 막대는 받침 없이는 흔들리므로 뒤판에서 나온 안내 고리 2개를 더한다(판화에 없음 — 최소 보충). 받침 축·캠 축은 뒤판 보스가 받친다(판화에 없음).

## 구동
캠 축(반시계). theta += OMEGA(1.6)·speed·dt, 캠이 판화 자세에서 돈 각 a = theta − 1.6. 한 바퀴 3.93 s 에 두 지레가 한 번씩 오르내린다.

## 부품과 치수 (새 부품은 모두 `kit/k149.ts`, 이미 구현됨. 치수 상수 `K149`)
배치 상수: 받침점 P = (−1.5, 1.95), 캠 축 C = (0.9, 1.55). 층: 뒤 지레 판 −0.12, 뒤 캠·뒤 바퀴 0, 앞 캠·앞 바퀴 0.36, 앞 지레 판 0.48.

- 뒤 캠(name `camBack`): `lobeCam(0.26, 0.46, K149.halfW, { thick: 0.1, bore: 0.1 })` 위치 (0.9, 1.55, 0). rotation.z = 뒤 캠 혹 방향(85° + a). 청동, 꼭대기에 노란 점.

- 뒤 지레 = 판화의 위 지레(name `leverBack`): `rollerLever(2.52, { pinAt: 1.44, rollerR: 0.15, rollerW: 0.08, rollerDz: 0.12, pinDz: 0.07 })` 위치 (−1.5, 1.95, −0.12). rotation.z = 뒤 지레 각. 굴림 바퀴(child 'roller' → name `rollerBack`)가 뒤 캠 평면(0)에 온다. 막대 핀 표식(child 'rodPin' → name `pinBack`)은 판 앞쪽 −0.05(뒤 캠과 같은 층이지만 캠은 x 0.18 보다 오른쪽에만 온다).

- 뒤 막대 안내(판화에 없음): `wallBearing(-0.06, 1.35, -0.05, 'y', 0.04)` — 구멍이 세로(막대 방향). 뒤판에서 나온 팔이 받친다.

## 동작 (모두 theta 의 닫힌 식·주기 표 — `camLevers149(theta)` 가 돌려준다)
- a = theta − 1.6. 앞 캠 혹 방향 = 200° + a, 뒤 캠 혹 방향 = 85° + a (둘 다 그 캠의 rotation.z).
- 지레 각 = 굴림 바퀴가 캠에 꼭 닿는 각: `leverAngle149(혹 방향)`(한 바퀴 720칸 주기 표, 이분법으로 미리 풀어 둠 — 누적 오차 없음). 앞·뒤 지레가 같은 표를 쓴다(받침점·길이·캠이 같다). 범위 −0.18° ~ 10.67°(흔들림 10.85°).
- 지레 위의 점: `leverPoint(K149.P, 지레 각, d)` — d = 2.52 가 굴림 바퀴 중심, 1.44·1.66 이 막대 핀.
- 막대: position = 그 지레의 막대 핀(깊이는 −0.05 / 0.55), rotation.z = `rodAim(핀, 안내 구멍)` — 안내 구멍은 `K149.guideBack` (−0.06, 1.35), `K149.guideFront` (0.16, 0.95). 막대는 구멍을 지나 미끄러지며 기울기는 1.7° 이하.
- 굴림 바퀴가 구르는 것은 표시용: `rollerBack.rotation.z = −2·a`, 앞도 같게(미끄럼 없는 정확한 값은 아님 — 표시점이 돌게만).
- 시각: **t = 1 (판화 자세: 뒤 지레 10.67° 꼭대기, 앞 지레 −0.18° 바닥)**, t = 2.2 (둘 다 바닥), **t = 3 (앞 지레 6.1° 오르는 중, 뒤 지레 바닥)**.
- 막대 행정: 뒤 0.271(핀 y 1.945 ~ 2.217), 앞 0.313(핀 y 1.945 ~ 2.257).
