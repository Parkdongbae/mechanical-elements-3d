# 221 타원 기어 구동
원문(en): "Irregular circular motion imparted to wheel, A. C is an elliptical spur-gear rotating round center, D, and is the driver. B is a small pinion with teeth of the same pitch, gearing with C. The center of this pinion is not fixed, but is carried by an arm or frame which vibrates on a center, A, … wheel, C, has attached to it a plate which extends beyond it and is furnished with a groove, g, h, of similar elliptical form, for the reception of a pin or small roller attached to the vibrating arm concentric with pinion, B." — 타원 평기어 C(중심 D 둘레로 돎, 구동)가 같은 피치의 작은 피니언 B 를 돌린다. 피니언 중심은 고정이 아니고 A 를 중심으로 흔들리는 팔에 실려 있어, C 의 맞물림 반지름이 변해도 오르내리며 계속 물린다. C 에 붙은 판의 타원 홈 g·h 에 피니언과 같은 중심의 롤러가 들어가 물림 깊이를 지킨다. 바퀴 A 는 불규칙하게 돈다.
쉬운 풀이: 타원 기어 C 가 일정하게 돌면 맞물린 곳의 반지름이 바뀌어 바퀴 A 가 빨라졌다 느려졌다 한다. 작은 기어 B 는 흔들 팔 위에서 오르내리며 C 와 계속 물린다.
판화 묘사(원본 510×445 px, [x·y]): 왼쪽 위 평기어 **A**(중심 [128·133], 이끝 반지름 약 88 px), 오른쪽 위 큰 평기어 **B**(중심 [298·162], 이끝 약 90 px)와 그 앞에 같은 중심의 작은 **피니언**(이끝 약 37 px). A 중심과 피니언 중심을 잇는 막대(팔). 아래에 비스듬한 **타원 기어 C**(중심 글자 C [228·312], 긴 축이 왼쪽 아래 ↔ 오른쪽 위), 그 안 위쪽에 축 **D**([265·235], 타원 중심에서 위쪽 끝으로 치우침 — 초점 자리). C 를 둘러싼 점선 이중 타원 홈 **h**(왼쪽)·**g**(오른쪽) — 점선이라 C 뒤의 판에 있다. 큰 기어 B 의 원은 C 의 이 뒤로 지나가고(C 가 앞), 점선 홈도 B 뒤로 지나간다(B 가 판 앞). A 중심 아래에도 글자 "B" 가 하나 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.0068.
1. 바퀴는 몇 개이고 크기 차례는? → 4개. 타원 기어 C(피치 반지름 0.49~0.91) > 바퀴 A(피치 반지름 0.65) > 큰 기어 B(0.55) > 피니언 B(0.228). 큰 기어 B 와 피니언은 한 축에 붙은 한 몸.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점(천장·벽·바닥)은? → 축 D(C·판의 축, 뒤판에서), 축 A(바퀴 A 의 축이자 팔의 받침점, 뒤판에서). 피니언 축은 고정이 아님(팔 끝).
5. 추·손잡이·크랭크는? → 판화에 없음. 원문 "C … is the driver" → 축 D 가 일정하게 돈다(구동). 출력은 A.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 모두 바깥 이. 피니언이 C 의 바깥에서 물림(C 위쪽 끝 근처). 큰 기어 B 가 A 와 바깥 물림. 피니언과 C 는 앞 층, 큰 기어 B·A 는 그 뒤 층, 홈 판은 맨 뒤 층(판화의 앞뒤 그대로).
7. 한 줄에 놓인 것은? → 피니언 중심·큰 기어 B 중심·롤러가 한 축. 팔은 A 중심 ↔ 피니언 중심 직선(길이 일정 = A 피치 반지름 + 큰 기어 B 피치 반지름).
8. 판화에 글자(A, B…)가 가리키는 부품은? → A = 출력 바퀴(와 팔의 받침점), B = 큰 기어(위 글자)와 피니언(같은 축), C = 타원 기어, D = C 의 축, g·h = 판의 타원 홈 양쪽. A 중심 아래의 둘째 "B" 는 원문에 대응이 없음 — 이름표에 쓰지 않는다.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문과 판화는 일치(피니언 중심은 고정이 아니라 팔에 실림 — 원문 그대로). 다만 판화 치수 그대로면 (1) 판화의 타원은 이심률이 약 0.7 이라 피니언이 D 에 너무 가까워질 때 큰 기어 B 가 D 축을 쓸고, (2) 홈 판이 A 축까지 닿아 A 축이 판을 뚫어야 한다. 그래서 **이심률을 0.30 으로 줄이고**(D 는 여전히 타원 위쪽 끝으로 치우친 초점), A 를 D 에서 1.32 떨어뜨렸다. 겉모양(A 왼쪽 위, B 오른쪽 위, 비스듬한 타원 C, 그 둘레 홈)은 판화 그대로. 질문 거리 없음.

## 해석(결정 사항)
- C 는 초점 D 둘레로 도는 진짜 타원 피치 곡선(`ellipsePitch(0.70, 0.30)`, 이 30). 피니언 B(이 10, 같은 피치)는 C 바깥을 구른다. 피니언 중심은 C 좌표에서 "피치 곡선을 바깥으로 rp 만큼 민 곡선" 위에 있어야 하는데, 이 곡선이 곧 홈 g·h 의 가운데선이다(롤러 = 피니언 중심).
- 피니언 중심은 동시에 A 중심에서 팔 길이 1.20 떨어진 원 위 → 매 순간 두 조건을 풀어 피니언 자리를 정한다(아래 동작 1). 팔은 −14.31° ↔ +6.10° 흔들린다.
- 큰 기어 B(이 22)가 바퀴 A(이 26)와 늘 물린다(팔 길이 = 0.55 + 0.65). A 의 각은 팔이 흔들려도 맞도록 매 순간 물림 위상 식으로 계산.
- 결과: C 가 일정하게 돌 때 A 는 C 의 **1.80 ~ 3.38 배** 빠르기로 오르내린다(C 한 바퀴에 A 33/13 = 2.538 바퀴).
- 층(앞 → 뒤): 팔(z 0.12~0.16) / C·피니언(z 0~0.08) / 큰 기어 B·A(z −0.10~−0.04) / 홈 판(z −0.22~−0.16).
- 판화에 없는 보충: 축 D·A 의 뒤판 축(`shaftZ`), 롤러, 판의 밝은 색과 어두운 홈 바닥, A 의 빨간 표시 막대.

## 구동
C 의 각 θC(t) = TH0 + 0.4·t [rad] (반시계, 한 바퀴 15.708 초), TH0 = 244° = 4.258604 rad(t = 0 에 C 의 먼 끝(φ = 0)이 D 에서 왼쪽 아래 244° 방향 — 판화 자세).

## 동작 (`state221(t)` — 결정적, 지난 프레임 값을 쓰지 않음)
1. θC = TH0 + 0.4·t. n = floor((θC − TH0)/2π), u = θC − TH0 − 2π·n.
2. 피니언 중심의 C 로컬 곡선 cen(φ) = PIT.pt(φ) + rp·PIT.normal(φ). 세계 Pw(φ) = D + Rot(θC)·cen(φ).
3. φ 풀이: guess = PHI0 − u, PHI0 = 3.2275934 rad(184.9275°). F(φ) = |Pw(φ) − A| − 1.20. φ 를 guess − 0.6 ~ guess + 0.6 에서 60 칸으로 훑어 부호가 바뀌는 곳 가운데 guess 에 가장 가까운 것을 이분법 50 번으로 좁힌다. (한 주기 동안 φ 는 PHI0 에서 PHI0 − 2π 로 내려간다.)
4. 접선각을 잇기: Tc(φ) = φ + π/2 + wrap(PIT.tangent(φ) − φ − π/2), wrap 은 (−π, π] 로. **atan2 값 그대로 쓰면 2π 씩 튀어 A 가 22 이씩 튄다.**
5. 피니언(=큰 기어 B) 각 ψB = PIT.S(φ)/rp + Tc(φ) + π/2 + θC − 8π·n.
6. 바퀴 A 각: a = atan2(Ay − Py, Ax − Px) 를 [0, 2π) 로(값 165.7°~186.4°, 180° 를 지나므로 꼭 [0, 2π)), s1 = 2π/22, s2 = 2π/26, ψA = a + π − s2 − (s2/s1)·(ψB + s1/2 − a).
7. 팔각 α = atan2(Py − Ay, Px − Ax).
8. 적용: `gearC.rotation.z = θC`, `pinionSet.position = (Px, Py, 0)`, `pinionSet.rotation.z = ψB`, `wheelA.rotation.z = ψA`, `arm.rotation.z = α`.
