# 287 피커링 조속기
원문(en): "Pickering's governor. The balls are attached to springs the upper end of each of which is attached to a collar fixed on the spindle, and the lower end to a collar on the sliding sleeve. The springs yield in a proper degree to the centrifugal force of the balls, and raise the sleeve ; and as the centrifugal force diminishes, they draw the balls toward the spindle and depress the sleeve." — 피커링의 조속기. 공들은 스프링에 달려 있고, 각 스프링의 **위 끝은 스핀들에 고정된 칼라**에, **아래 끝은 미끄러지는 슬리브의 칼라**에 붙어 있다. 스프링은 공의 원심력에 알맞게 휘면서 슬리브를 올리고, 원심력이 줄면 공을 스핀들 쪽으로 끌어당기며 슬리브를 내린다.
쉬운 풀이: 세로 축이 돌면 판스프링 가운데에 달린 공이 원심력으로 바깥으로 벌어진다. 스프링이 활처럼 더 휘면 위아래 두 끝 사이가 짧아지는데, 위 칼라는 축에 고정되어 있으므로 아래 칼라(미끄럼 슬리브)가 위로 끌려 올라간다. 축이 느려지면 스프링이 펴지며 공이 안으로 들어오고 슬리브가 내려간다. 슬리브 홈에 끼운 지레가 이 오르내림을 밸브로 전한다.
판화 묘사(원본 508×564 px, **정면**): 가운데 세로 스핀들(두 줄, x [215~235]), 위 [40~55] 에 납작한 원판 칼라(지름 ≈ 160 px)와 그 위 둥근 꼭지 너트([10~40]). 아래 [330~345] 에 같은 크기 칼라, 그 밑에 홈 둘을 가진 슬리브(플랜지 둘 [355~400])와 가는 축 끝([400~435]). 두 칼라 사이에 양쪽으로 활처럼 휜 판스프링 둘(위·아래 끝은 칼라 가장자리에서 거의 수직으로 나와 바깥으로 불룩), 각 스프링 가운데([190] 높이)에 납작한 렌즈 꼴 공(가로 ≈ 60 px, 세로 ≈ 40 px)이 끼워져 있다(스프링이 공 한가운데를 지남).

## 해석(결정 사항)
- **슬리브 높이는 스프링 길이에서**: 판스프링 가운데선 r(s) = 0.15 + b·sin²(π s), y(s) = 2.715 − c·s(s 0~1, 끝은 칼라 가장자리에서 수직). 길이 L(b, c) = ∫₀¹ √(c² + (π b sin 2π s)²) ds 가 늘 **L₀ = 1.30231**(b 0.23 일 때 c 1.20 으로 정함). b 가 주어지면 c 를 이분법으로 구한다 → 아래 칼라 윗면 y_B = 2.715 − c.
- 공의 벌어짐 b = 0.08 + 0.0625·(ω_s² − 0.16)(ω_s 0.4 → 1.6 에서 b 0.08 → 0.23).
- c(b) 표(검산): b 0.08 → 1.29016, 0.09 → 1.28692, 0.10 → 1.28330, 0.11 → 1.27929, 0.12 → 1.27488, 0.13 → 1.27009, 0.14 → 1.26491, 0.15 → 1.25932, 0.16 → 1.25334, 0.17 → 1.24696, 0.18 → 1.24017, 0.19 → 1.23297, 0.20 → 1.22536, 0.21 → 1.21733, 0.22 → 1.20888, 0.23 → 1.20000. 슬리브 오르내림 0.090(y_B 1.4248 ~ 1.515).
- 스프링은 공 한가운데를 지나고(공이 스프링에 끼워짐), 끝은 칼라에 0.012 박힘 — 떠 있는 곳 없음.
