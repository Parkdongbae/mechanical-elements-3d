# 144 레이지 통즈(엇갈린 지렛대)
원문: "A system of crossed levers, termed Lazy Tongs. A short alternating rectilinear motion of rod at the right will give a similar but much greater motion to rod at the left. It is frequently used in children's toys. It has been applied in France to a machine for raising sunken vessels; also applied to ships' pumps, three-quarters of a century ago." — X자로 엇갈린 지렛대 여러 마디('레이지 통즈'). 오른쪽 막대의 짧은 왕복이 왼쪽 막대에 비슷하지만 훨씬 큰 왕복을 만든다. 어린이 장난감·가라앉은 건지기·배 펌프에 쓰였다.
판화 묘사: 왼쪽에 세로 벽선, 아래에 바닥선(틀). 벽의 구멍으로 왼쪽 막대가 들어와 눈 블록에 닿고, 그 눈에서 X 마디 4칸이 사슬처럼 이어져 오른쪽 눈 블록, 다시 오른쪽 자루로 판 밖까지 간다. 가운데 핀들(5개)은 한 수평선 위, 위·아래 핀들(4+4)은 그 위·아래에 찍혀 마름모 넷이 늘어선 모양. 가운데(오른쪽에서 세 번째 마디)에는 바닥까지 서린 네모 틀(기둥)이 있고, 그 꼭대기의 핀으로 통즈의 한 마디가 붙는다 — 틀 안쪽으로 내려가는 막대 둘은 점선(틀 뒤에 감김). 글자는 없고 번호 144 만 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/144-fig-x4.png` 로 다시 읽음(아래 [x·y] 는 4배 그림의 px, [x, y] 는 세계 좌표).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 없음. 바퀴는 하나도 없다. 부품은 ① 왼쪽 눈 막대(벽 구멍을 지나는 몸통 + 눈 블록, 눈 중심 [250, 900]) ② 링크 막대 16개(마름모 넷) ③ 오른쪽 눈 막대 + 자루(눈 중심 [1425, 905], 자루는 [1620~1768, r 25] 로 판 밖까지) ④ 바닥에 선 네모 틀 기둥(x 1007~1210, 윗변 845, 바닥 1422) 과 그 꼭대기 고정 핀 허브 [1108, 890] r 40.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 막대끼리는 핀으로만 이어진다: 가운데 핀 5개 [255·520·800·1108·1425, y≈903] 와 위 핀 4개 [385·655·950·1255, y≈555], 아래 핀 4개 [같은 x, y≈1247]. 핀 사이 가로 반칸 133~160px, 세로 반높이 ≈350px, 막대 한 개 ≈374px.
3. 교차하는 가닥이 있는가, 어디서? → 줄 가닥은 없다. 겹침: 기둥 틀이 아래로 내려가는 두 막대(M3→B3·M3→B4)의 **앞**을 막는다(틀 안쪽 구간이 점선 = 틀 뒤에 감김). 위로 올라가는 막대(T3→M3·M3→T4)는 틀 윗변 앞을 지나 solid. 나머지 막대는 서로 겹치지 않는다(마름모 넷이 이어진 것).
4. 고정점(천장·벽·바닥)은 어디인가? → 왼쪽 벽선(왼쪽 막대가 나오는 구멍), 바닥선(기둥이 선다), 기둥 꼭대기의 고정 핀 [1108, 890] — 통즈의 세 번째 가운데 마디를 바닥 기둥에 붙든다. 기둥이 유일한 중간 고정점이다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 추·크랭크 없음. 오른쪽 막대의 곧은 자루(판 밖으로 나감)가 입력 — 좌우로 밀면 통즈가 접혔다 펼쳐지며 왼쪽 막대가 벽 구멍 속으로 들락거린다(원문 "rod at the right" 가 구동).
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 물리는 짝은 핀 13곳: 막대 눈 구멍(r≈20px)들이 같은 핀에 겹쳐 지나고, 눈 막대의 눈도 그 핀을 건다(눈의 이중원 = 핀 + 눈 테).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 가운데 핀 5개가 같은 높이의 한 수평선(통즈 축선, 바닥에서 519px = 축선). 위 핀 4개·아래 핀 4개도 각각 같은 높이. 두 눈 막대의 몸통도 축선 위를 달린다. 위·아래 핀의 x 는 이웃 가운데 핀 둘의 한가운데.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 144 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 원문과 같다. 다만 판화만으로는 갈리는 해석 하나: 기둥이 고정인지 미끄럼인지 — 바닥까지 서린 틀이므로 **고정**으로 읽는다. 이래야만 원문이 성립한다(오른쪽 Δ → 왼쪽 3Δ 반대 방향; 기둥이 미끄러지면 커지는 것은 왼쪽이 아니라 기둥 자리다). 질문 거리 없음.
- 그 밖의 선: 기둥은 속이 빈 네모 틀(윗변·아랫변 + 양옆 다리)이고 아랫변 밑에 좁은 받침이 바닥선에 닿는다. 왼쪽 막대의 벽 옆 트럼펫 모양 = 벽 구멍(글랜드)의 깔때기. 오른쪽 자루 끝의 잘림 = 판 경계. 위 그제 막대 두께 ≈22px.

## 해석(결정 사항)
- 판화 비(1px = 0.00134, 4배 확대): 막대 한 개 374px = 0.50 — 모형도 L = 0.5 로 그대로. 칸은 265~320px 로 손그림이라 오른쪽으로 갈수록 크지만 모형은 같은 칸으로 쌓는다(막대가 다 같아야 계속 접혔다 펼쳐진다).
- 기구: 왼쪽 눈 막대(출력) + X 마디 4칸 + 오른쪽 눈 막대·자루(입력) + 바닥 기둥의 고정 핀(세 번째 가운데 마디, 오른쪽 끝에서 한 칸). 오른쪽이 Δ 움직이면 왼쪽이 반대 방향으로 3Δ — "짧은 운동 → 훨씬 큰 운동".
- 축선 높이: 판화 비대로면 바닥에서 0.70 — 아래 핀(최저 0.82 내려옴)이 받침 윗면(0.18)에 거의 닿는다 → 모형은 1.3 으로 올렸다(k143.ts 의 K144.CY). 위 핀 최고 1.776.
- 판화의 왼쪽 막대는 벽 바로 옆(≈0.31)에서 끝나지만 모형은 안내를 통과해야 하므로 1.15 로 늘림. 오른쪽은 0.46 ≈ 0.56 + 자루 0.12. 판화의 벽 구멍은 뒤판 없는 전시대에서 바닥에 선 눈 판 안내로 줄였고(왼쪽), 오른쪽 안내는 판화에 없는 보충.
- 판화의 점선(기둥 뒤 막대)을 따라 막대를 두 층(A·B)으로 쌓고 기둥 판은 막대들 앞에 세운다 — 3D 에서 점선이 해소된다.
- 막대 기울기는 판화 순간 ≈69° 를 접힘 72°~펴짐 55° 사이의 t = 1 자세 67° 로 삼음.
- K144.guideL(−1.08)·K144.guideR(1.604) 는 눈 막대의 목 블록이 최대로 펼칠 때 스치는 자리(블록 면 −1.033·1.586)라 그대로 쓰지 않고 −1.14·1.648 에 둔다(블록과 0.057·0.012 틈).

## 구동
오른쪽 눈 막대(rodR)가 좌우로 왕복한다. theta += OMEGA(1.6)·speed·dt, 칸 길이 d = dMid + dAmp·sin(theta − 1.993). 한 주기 2π rad = 3.93 s. 왼쪽 눈 막대(rodL)가 3배로 종동하고 링크 16개는 각자 제 핀 주위로 ±8.5° 흔들린다. 모든 자세는 `lazyTongs144(theta)` 의 닫힌 식.

## 동작 (모두 theta 의 닫힌 식 — `lazyTongs144(theta)` 가 돌려준다)
A = `lazyTongs144(theta)` → { d, alpha, h, mid[5], out[4], s }.
- 칸 길이 d = 0.4413 + 0.1323·sin(theta − 1.993) — 사인이라 한 주기(2π rad = 3.93 s)에 정확히 닫힌다.
- 막대 기울기 alpha = acos(d) (2L = 1.0): 72°(접힘, d 0.309) ~ 55°(펴짐, d 0.574), 판화 자세 67°(d 0.391). 각 막대는 제 핀 주위로 이 범위(전체 17°)를 왕복.
- 핀 자리: 가운데 줄 mid[j] = 0.85 + (j−3)·d(j 0~4, j 3 이 고정 핀), 위·아래 줄 out[i] = 0.85 + (i−2.5)·d, 위 y = 1.3 + h, 아래 y = 1.3 − h(h = 0.5·sin alpha = 0.410~0.476).
- 왼쪽 눈 rodL: x = mid[0] = 0.85 − 3d → −0.077~−0.871(행정 0.795). 오른쪽 눈 rodR: x = mid[4] = 0.85 + d → 1.159~1.424(행정 0.265). 서로 반대 방향(펼 때 두 막대가 바깥으로), 이동량은 정확히 3배.
- 대입: `rodL.position.x = A.mid[0]`, `rodR.position.x = A.mid[4]`, 링크마다 위의 칸 공식, 안내·기둥·받침대는 그대로.
- 시각: **t = 1 (d 0.391, alpha 67° — 판화 자세)**, **t = 1.6 (d 0.512, 59.2°, 펴지는 중 — 오른쪽 +0.122, 왼쪽 −0.365 이동)**, t = 30 (theta 48, 주기 7번 지난 뒤 d 0.560, 55.9°).

- fail(gain): 검사기가 비교하는 값은 당김÷짐 이동거리비이므로 선언 gain 을 3 → 0.333 으로 바로잡았다. 기구·이동비(왼쪽 = 오른쪽 ×3, 반대 방향)는 그대로.
