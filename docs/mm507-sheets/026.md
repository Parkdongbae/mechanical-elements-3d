# 026 크라운 기어
판화: 위쪽에 **수직축의 평기어**(옆에서 본 가로로 넓은 원통, 이 줄무늬가 보이고 축이 위로 솟음), 그 오른쪽 아래에 **가로축의 크라운 휠**(옆에서 본 세로로 긴 원판, 왼쪽 면에 톱니가 줄지어 서 있음, 축 토막이 오른쪽으로 나옴). 평기어의 오른쪽 끝이 크라운 휠 윗부분의 톱니 면에 닿는다. 원문: 톱니가 판 옆면에 선 크라운 휠과 평기어가 맞물리며, 크라운 톱니가 얇아 가벼운 일에만 쓴다. 두 축은 직각으로 만나고 같은 평면에 있다.
구동: 평기어(피니언). 크라운 휠이 종동.

## 부품과 치수
- `displayStand()`
- 공통 수치: 모듈 m = 0.028, 피니언 잇수 Np = 20, 크라운 잇수 Nc = 24. 피니언 피치 반지름 rp = Np·m/2 = 0.28, 크라운 맞물림 반지름 rm = Nc·m/2 = 0.336. 기구 평면 z 는 두 축 모두 **Zc = 0.18**(크라운 반지름 0.41 이라 z −0.23 ~ 0.59 — 전시 영역 안).
- 크라운 축(가로, X 방향): 높이 **Yc = 1.50**, z = Zc. 크라운 이가 난 면(앞 면)의 위치 x_blank = **−0.15**, 이 면에서 이는 **−X 쪽**(왼쪽)으로 서 있다. 이 피치 평면 x_f = x_blank − 1.25m = **−0.185**.
  - `crownGear(24, 0.028, { width: 0.12, bore: 0.045 })` (키트 추가). 그룹 `crown`(피벗) 위치 (−0.15, 1.50, 0.18), 안쪽 자식 `crownMesh` 의 `rotation.y = −π/2`(로컬 Z → 세계 −X, 로컬 x → 세계 +Z, 로컬 y → 세계 +Y).
  - 크라운 축 막대: `rod(V3(0.0, 0, 0), V3(0.95, 0, 0), 0.04)` 를 **crown 피벗의 자식**으로(피벗 로컬 좌표 → 세계 x −0.15 ~ 0.80 에서 크라운과 함께 돈다). 두 받침 사이(로컬 x = 0.60, 세계 0.45)에 표시 깃: `BoxGeometry(0.02, 0.1, 0.02)` paint(0xf2b619) 를 피벗 로컬 (0.60, 0.05, 0) 에. 축이 허브 구멍(0.045)을 지난다. 이가 난 앞면 쪽 축 끝은 앞면과 같은 높이(로컬 x = 0)에서 끝난다.
  - 받침: `pillow(0.25, 1.50 − PILLOW_BOSS_Y, 0.18, 'x')`, `pillow(0.65, 1.50 − PILLOW_BOSS_Y, 0.18, 'x')` (`PILLOW_BOSS_Y` 는 shaft.ts 에서 import).
- 피니언 축(수직, Y 방향): x = **xp = x_f − rp = −0.465**, z = Zc. 피니언 중심 높이 **Yp = Yc + rm = 1.836**. 피니언 `spurGear(20, 0.028, { width: 0.08, spokes: 4, driver: true })`. 그룹 `pin`(피벗) 위치 (−0.465, 1.836, 0.18), 자식 `pinMesh` 의 `rotation.x = −π/2`(로컬 Z → 세계 +Y, 로컬 x → 세계 +X, 로컬 y → 세계 −Z).
  - 피니언 축: `rod(V3(0, −0.64, 0), V3(0, 0.76, 0), 0.035)` 를 **pin 피벗의 자식**으로(세계 y 1.196 ~ 2.596). 위 끝 가까이(로컬 y = 0.70)에 표시 깃 `BoxGeometry(0.1, 0.02, 0.02)` paint(0xf2b619) 를 로컬 (0.06, 0.70, 0) 에.
  - 축 받침 브래킷 2개(뒤판에서 나온 팔 + 고리, 007 의 수직축 브래킷 방식): y = **2.50** 과 **1.40** 에, 각각 `BoxGeometry(0.16, 0.10, 0.44)` castIron 을 중심 (−0.465, y, −0.08)에, 고리 `lathe(tubeProfile(0.04, 0.065, −0.05, 0.05, 0.008), 36)` darkSteel 을 (−0.465, y, 0.18)에(고리 축 = Y, 축 막대가 관통). 아래 브래킷(y = 1.40)은 크라운(x ≥ −0.213)과 떨어져 있다.
- 이 맞물림 점검 수치: 피니언 이끝 반지름 0.308 → 이끝이 x = xp + 0.308 = −0.157, 크라운 앞면(x = −0.15)과 0.007 간격. 피니언 이뿌리 쪽 x = −0.22 가 크라운 이끝 면(x = −0.213)과 0.007 간격.

## 키트 추가 (gear.ts 끝에 덧붙임, index.ts 가 이미 re-export)
`crownGear` — 평기어와 직각으로 맞물리는 페이스(크라운) 기어. 기존 시그니처는 건드리지 않는다.
```ts
export interface CrownGearOpts {
  width?: number;   // 이 반지름 방향 폭(기본 0.12). 이는 r ∈ [rm − width/2, rm + width/2] 에 선다
  driver?: boolean; // true 면 bronze, 아니면 brass
  bore?: number;    // 축 구멍 반지름(기본 max(0.024, rm × 0.14))
}
/** 로컬 Z = 회전축, 이는 +Z 면에 선다. 이가 난 뿌리 면 = 로컬 z = 0, 이끝 면 z = hT = 2.25·module, 피치 평면 z = 1.25·module. 원점 = 회전축 */
export function crownGear(teeth: number, module: number, opts?: CrownGearOpts): THREE.Group;
/** 평기어(피니언) 각 → 크라운 각. 맞물림 위상 포함: (Np / Nc) × thetaPinion + π/2 */
export function crownGearAngle(thetaPinion: number, pinionTeeth: number, crownTeeth: number): number;
```
- 치수: rm = teeth·module/2, r1 = rm − width/2, r2 = rm + width/2, 피치각 s = 2π/teeth, hT = 2.25·module. 바깥 반지름 R_out = r2 + 0.015.
- **이(톱니) j**(j = 0..teeth−1): 가운데 각 c = j·s(이 0 의 가운데 = 로컬 +X 방향). 사다리꼴 쐐기 — 뿌리(z = 0) 반폭 각 hr = 0.35·s, 이끝(z = hT) 반폭 각 ht = 0.10·s(반지름과 상관없이 각도로 고정이라 바깥쪽 이가 굵다). 이 하나는 꼭짓점 8개: 
  0 (r1, c−hr, 0) · 1 (r2, c−hr, 0) · 2 (r2, c+hr, 0) · 3 (r1, c+hr, 0) · 4 (r1, c−ht, hT) · 5 (r2, c−ht, hT) · 6 (r2, c+ht, hT) · 7 (r1, c+ht, hT). 점 (r, a, z) 는 (r cos a, r sin a, z).
  면(법선이 바깥을 향하는 감는 순서 — 검산 완료) 사각형 5개를 각각 (p0,p1,p2),(p0,p2,p3) 로 쪼갠다: (0,1,5,4), (1,2,6,5), (2,3,7,6), (3,0,4,7), (4,5,6,7). 바닥면은 만들지 않는다. 모든 이를 **하나의 비인덱스 `BufferGeometry`** 에 모아 `computeVertexNormals()` 후 `mesh(geo, body)`.
  (피치 평면 z = 1.25m 에서 이 두께 = 2·(0.35 − 0.25×0.556)·s·r ≈ 0.42 피치 — 평기어 이가 0.5 피치 안팎이라 겹치지 않는다.)
- 몸통: 판 `lathe(tubeProfile(bore, R_out, −0.06, 0.002, 0.008), 64)` 를 `rotateX(π/2)`(z ∈ [−0.06, 0.002]), 허브 `lathe(tubeProfile(bore, bore + 0.05, −0.14, −0.04, 0.008), 32)` darkSteel 을 `rotateX(π/2)`. 이가 난 면 위에 표시: paint(0xf2b619) `BoxGeometry(0.04, 0.016, 0.008)` 를 로컬 (r1 − 0.06, 0, 0.004) 에(이 0 과 같은 방향).
- 맞물림 위상(세계 배치와 함께 쓸 때): 크라운 피벗 `rotation.x = −αc`, `αc = crownGearAngle(θ, Np, Nc)`.

## 동작 (theta += OMEGA × speed × dt, OMEGA = 1.6, 피니언 구동)
- 피니언: `pin.rotation.y = θ` (+Y 축 양의 회전 = 위에서 볼 때 반시계). `pinMesh` 는 고정(`rotation.x = −π/2`).
- 크라운: `αc = (Np/Nc)·θ + π/2 = (20/24)·θ + π/2`. `crown.rotation.x = −αc` (세계 −X 축을 중심으로 +αc, 즉 크라운 로컬 Z 둘레 +αc). 속도비 ω크라운 / ω피니언 = 20/24 = 5/6 (같은 부호 — 접촉점이 둘 다 −Z 쪽으로 움직인다).
- **맞물림 위상 근거**: θ = 0 에서 피니언은 접촉 방향(+X)에 이골이 오고(spurGear 의 이골이 로컬 +X), 크라운은 `αc = π/2` 라서 이 0 의 가운데가 맨 위(+Y)의 접촉 위치에 온다 → 피니언 이골에 크라운 이가 들어간다. 이후 접촉점의 선속도가 같아 위상이 계속 유지된다(피치각이 같은 호 길이: rp·2π/Np = rm·2π/Nc = π·m).
- 크라운 축·표시 깃은 크라운 피벗의 자식이라 같이 돈다. 피니언 축·깃도 피니언 피벗의 자식.

## 확인
- 정면 t=0 과 t=1.5: 평기어 표시 깃과 크라운 표시 깃(두 받침 사이)이 돌았고 속도비 5:6 이 맞다(깃 각도 θ vs 0.83θ).
- 비스듬한 기본 시점 t=0: 평기어 이 하나가 크라운 두 이 사이 이골 한가운데 들어가 있고, 이끼리 박히지 않는다(이끝과 반대편 이뿌리 사이에 작은 틈이 보인다). t=0.5, 1.0 에도 같은 맞물림이 유지된다.
- 평기어 이끝이 크라운 앞면(판 면)을 뚫지 않고, 크라운이 뒤판(z = −0.30)과 겹치지 않는다. 전체가 전시 영역 안(피니언 축 위 끝 y ≈ 2.6)에 있다.
- 불확실: 판화에서 두 기어의 크기 비는 비슷해 보여 20:24 로 정했다. 크라운 이는 직선 쐐기(평기어 인벌류트와 정확한 공액은 아님)로 단순화.
