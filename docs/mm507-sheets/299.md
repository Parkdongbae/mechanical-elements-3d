# 299 옛 시계 탈진기(날개형)
원문(en): "An old-fashioned clock escapement." — 옛날 방식의 시계(벽·탁상시계) 탈진기이다. (원문은 이 한 줄뿐 — 구조는 판화로 읽는다.)
쉬운 풀이: 눕힌 왕관 바퀴(위로 톱니가 솟은 바퀴)를 정면에서 보면 띠처럼 보이고, 그 위를 앞뒤로 지나는 굴대(버지)에 팔레트 둘이 120° 벌어져 붙어 있다. 왕관 바퀴 앞쪽 이는 오른쪽으로, 뒤쪽 이는 왼쪽으로 움직이므로, 버지 앞끝의 날개(추를 단 막대)가 좌우로 흔들릴 때 앞 팔레트와 뒤 팔레트가 번갈아 이를 막았다 놓는다. 한 번 오갈 때 바퀴가 이 하나(24°)만큼 돈다.
판화 묘사(원본 528×516 px, **버지 축 방향에서 본 정면**): 아래에 가로로 긴 빗금 띠([15~430·330~410], 위 가장자리가 오목한 호들로 이어짐) — 왕관 바퀴를 옆에서 본 테. 띠 위로 뾰족한 이들이 솟아 있고, 왼쪽에서 오른쪽으로 기운 선과 오른쪽에서 왼쪽으로 기운 선이 엇갈려 X 꼴(앞쪽 이와 뒤쪽 이가 겹쳐 보임). 가운데 위 [250·237] 에 두 겹 원(버지 축 끝), 거기서 왼쪽 아래로 긴 막대 [190·325](팔레트 하나, 이 사이에 깊이 들어감), 오른쪽으로 거의 가로인 막대 [365·245](다른 팔레트, 이 위로 물러남) — 두 막대 사이 ≈ 120°.

## ★ 판화 읽기
판화 하나(버지 축 방향 정면). 판화 1 px ≈ 0.0024(띠 위 이끝 줄 → 세계 y 1.45). 버지 축 끝 [250·237] ↔ 세계 (0, 1.52), 띠 ↔ 왕관 바퀴 테(y 1.25~1.45).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 왕관 바퀴 1(눕힘, 이 15, 테 반지름 0.40). 보충한 태엽통(반지름 0.30, 같은 세로축 아래).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 판화의 X 꼴은 앞쪽 이(오른쪽으로 감)와 뒤쪽 이(왼쪽으로 감)가 겹쳐 보이는 것. 버지(z 방향)와 왕관 바퀴 축(y 방향)이 직각으로 엇갈린다.
4. 고정점은? → 왕관 바퀴 세로축 받침 2, 버지 뒤 받침·앞 받침(뒤판에서 나온 팔 — 판화에 없음, 보충).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에 없음 → 버지 앞끝에 '날개'(양 끝에 추를 단 가로 막대, 옛 시계의 폴리오)를 보충 — 제목의 날개형. 왕관 바퀴는 아래 태엽통이 민다(보충).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 왕관 바퀴 테 윗면에 톱날 이 15(앞면이 세로로 곧고, 등이 비스듬). 앞 팔레트는 앞쪽(z 0.65) 이의 앞면 끝 모서리를, 뒤 팔레트는 뒤쪽(z −0.15) 이를 막는다.
7. 한 줄에 놓인 것은? → 버지 축과 왕관 바퀴 세로축이 같은 x = 0(버지가 바퀴 지름 위를 앞뒤로 지남). 이끝 줄 y 1.45, 버지 y 1.52(0.07 위).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 299 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 원문이 한 줄뿐이라 판화로 읽음: 버지 탈진기를 버지 축 방향에서 본 그림 — 띠 = 왕관 바퀴 옆모습, X = 앞·뒤 이 겹침. (나) 판화 두 막대 사이 120° 를 그대로 — 쉼 자세에서 각 팔레트가 아래로부터 60°, 판화는 날개가 25° 돌아간 순간(왼쪽 35°·오른쪽 85°). (다) 판화의 띠는 곧지만 실제는 바퀴라서 띠 폭(바퀴 지름)은 0.80 으로 판화보다 좁음(깊이 한계 z −0.25~0.8). (라) 날개·받침·태엽통 보충, 날개는 반투명(앞에서 접점을 가림). (마) 되튐이 크다(걸린 동안 8.5° 뒤로) — 버지 탈진기 본디 성질.

## 해석(결정 사항)
- **날개 각만 시간표, 바퀴 각은 접촉에서**: θ(t) = 35°·sin(π t)(주기 2 초, 버지 `rotation.z` +, 앞에서 볼 때 반시계). 바퀴는 태엽통이 늘 앞쪽 이가 +x 로 가게 민다 → 매 순간 φ = 걸린 이의 바깥 끝 모서리가 팔레트 닿는 면에 닿는 각.
- 팔레트는 버지 축(z)을 품은 판이라 닿음은 **정면 xy 평면**에서 풀린다(이 그림이 판화 그대로): 이 끝 모서리는 늘 y = 1.45(톱니 끝 면)에 있고 x 만 움직이며(x = 0.40·sin α), 팔레트 닿는 면이 y = 1.45 을 지나는 가로 위치가 곧 이의 x. 이 끝이 팔레트 끝(길이 0.154)을 지나면 놓인다.
- shapely 로 톱니 투영(반지름 0.36·0.38·0.40 단면)과 팔레트 다각형을 날개 위상 0.1° 간격 3600 자세로 겹쳐 보아 접촉 식과 같음(차 0.00018°, 겹침 0).
- 한 주기(2 초)에 정확히 +24°(이 하나). 반 주기마다 드롭 3.86°, 되튐 8.53°.

## 동작 (`state299(t)` — 결정적, 닫힌 접촉 식)
1. n = floor(t/2), τ = t − 2n, θ = 35·sin(π τ)(도).
2. 닿는 면 가로 위치: w(γ) = 0.07·tan γ − 0.008/cos γ(버지 축선에서, 톱니 끝 면 y 1.45 에서 잰 값). 닿는 점이 판 위 s(γ) = (0.07 − 0.008·sin γ)/cos γ ≤ 0.154 이고 γ < 89.9° 일 때만 닿음.
3. 앞: γf = 60 + θ, α = asin(w(γf)/0.40). 뒤: γb = 60 − θ, α = 180° + asin(w(γb)/0.40). φ = α − 24°·k.
4. 구간: τ < 0.5 → 앞·k = 0, 놓이면 뒤·k = 7. 0.5 ≤ τ < 1.5 → 뒤·k = 7, 놓이면 앞·k = −1. τ ≥ 1.5 → 앞·k = −1. φ 에 24·n 을 더한다. (놓이는 γ = 65.9774°, 즉 θ = ±5.9774°.)
5. 기대값(파이썬 검산 — 0.002° 안에서 맞아야 함):

## 확인
- 판화처럼 정면에서 띠 모양 왕관 바퀴 위에 이들이 X 꼴로 겹쳐 보이고, 버지 축 끝에서 두 팔레트가 120° 로 벌어짐.
- t = 0.05 → 0.06: 앞 팔레트가 앞쪽 이를 놓고 바퀴가 3.9° 툭 → 뒤 팔레트에 뒤쪽 이가 걸림(주황).

- t = 0 → 2: 바퀴 24°(이 하나), 반투명 날개 너머로 접점이 보임.
- 근접 `cam=0.4,1.6,1.5,0.10,1.45,0.62`(앞 팔레트), `cam=-0.4,1.9,0.8,-0.10,1.45,-0.12`(뒤 팔레트).
