# 012 고정 도르래
판화: 위에 가로 들보(빗금), 고리로 매달린 **도르래 하나**(바퀴 속에 큰 구멍). 줄이 도르래 위를 넘어 **오른쪽은 수직으로 내려가 추**(오른쪽 아래, 주머니 모양)에, **왼쪽은 왼쪽 아래로 비스듬히 내려가 손**이 잡고 있다. 원문: 가장 단순한 도르래 — 평형을 이루려면 당기는 힘이 무게와 같아야 한다(1 : 1, 방향만 바뀜).
구동: 손(줄의 왼쪽 끝)이 줄을 당겼다 놓는다 — 줄을 당겨 내리면 추가 같은 길이만큼 올라간다.

## 부품과 치수
- `displayStand()`
- 들보: `BoxGeometry(2.1, 0.12, 0.65)` castIron, 중심 (0.15, 3.02, 0.05). (뒤판 앞면 −0.30 에 거의 붙는다.)
- 도르래 C: 줄 중심 반지름 R = 0.36, 중심 (0.15, 2.35), z = 0.25, 회전축 Z. `pulley(0.34, { width: 0.10, grooved: true, spokes: 4 })`.
- 매달이: 축 막대 `rod(V3(0.15, 2.35, 0.13), V3(0.15, 2.35, 0.37), 0.03)`, 양쪽 옆판(상자 0.03 × 0.52 × 0.03, steel)을 z = 0.25 ± 0.10, x = 0.15, y 2.35 ~ 2.87 에, 위 끝에 고리(`TorusGeometry(0.05, 0.012, 12, 24)` steel, 중심 (0.15, 2.91, 0.25), XY 평면). 들보 아래에 고정 핀(`rod`, 길이 0.1, z 방향) 이 고리를 지난다. 모든 재질은 materials.ts 것(steel, castIron, rope 색은 아래).
- 추: `weight(0.34, 0.40)`, 중심 x = 0.51, z = 0.25, 중심 높이 y_c = 0.62 + d (아래 동작). 위 고리 중심 높이 = y_c + 0.234.
- **줄**: 키트 추가 `ropeAround` 로 점열을 만들고 `new Rope(0.018)` → 매 프레임 `rope.setPath(path)` (삼줄색, 점 개수 일정).
  `ropeAround({ p: E }, [{ c: [0.15, 2.35], r: 0.36, ccw: false }], { p: [0.51, y_c + 0.234] }, { seg: 24 })`, z 는 모두 0.25 (map 기본 사용, w = 0.25).
  진행 방향은 손 → 도르래 위 → 추(시계 방향 감김).
- 왼쪽 줄의 방향: 수직에서 α = 35° 기운 직선. 단위벡터 u = (−sin α, −cos α) = (−0.574, −0.819)(도르래에서 손 쪽으로). 도르래 쪽 접점 T = C + R·(−cos α, sin α) = (−0.145, 2.556). 손(줄 끝) E = T + u × (1.8 + d). (E 가 항상 같은 접선 위에 있으므로 줄이 같은 직선을 유지한다.)
- 손잡이: `rod(E, E + u×0.16, 0.05)`(wood 느낌 brass 아님, 짙은 색) 끝에 구 반지름 0.06 — 줄 끝에 매달린 손잡이. 위치는 E 와 함께 움직인다.

## 키트 추가 (새 파일 `kit/rope.ts`, `index.ts` 에서 re-export)
012~020 이 함께 쓴다(013~020 설계표는 이것을 재정의하지 않는다).
```ts
export interface RopeCircle { c: V2; r: number; ccw: boolean; w?: number }   // 줄 중심 반지름 r. w = 이 원에서의 법선 방향 위치
export interface RopeEnd { p: V2; w?: number }
export interface RopeOpts { seg?: number /*16*/; map?: (u: number, v: number, w: number) => THREE.Vector3 /* 기본 (u,v,w) -> (u,v,w) */ }
/** 줄 경로: start → circles(차례로 감음) → end. 점 개수 = 2 + circles.length × (seg + 1) 로 항상 일정 */
export function ropeAround(start: RopeEnd, circles: RopeCircle[], end: RopeEnd, opts?: RopeOpts): THREE.Vector3[];
```
- (u, v) 평면에서 u 가 오른쪽, v 가 위. `ccw` = 줄이 그 원을 (u,v) 평면에서 반시계로 감으며 지나가는지. s = ccw ? +1 : −1.
- 이웃한 두 항목(점 = 반지름 0 인 원)을 잇는 **방향 있는 접선**: c1→c2, 부호반지름 q1 = s1·r1, q2 = s2·r2. D = c2 − c1, k = q2 − q1, β = atan2(D). 접선 진행각 τ = β − asin(k / |D|), t = (cosτ, sinτ). 각 원 위 접점 = c + r·s·(t_y, −t_x) (진입·이탈 모두 같은 공식, 각각 그 원 앞뒤 접선의 t 사용). (|k| > |D| 이면 null 대신 k 를 ±|D|·0.999 로 클램프.)
- 호: 진입 접점의 각 θin, 이탈 접점의 각 θout (원 중심 기준 `atan2`)일 때 Δ = (((θout − θin)·s) mod 2π + 2π) mod 2π, 점 i = θin + s·Δ·i/seg (i = 0..seg, **seg 구간으로 균등 분할 — 감긴 각이 변해도 점 개수는 같다**).
- 법선 방향 좌표: 호 위 점의 w = circle.w ?? start.w ?? 0, start/end 점의 w = 그 항목의 w ?? 0. 직선 구간은 양 끝 점만 이으므로 w 가 달라도 곧은 선(비스듬히 선 줄)이 된다.
- `map` 이 있으면 최종 점 = map(u, v, w).

같은 파일 `kit/rope.ts` 에 아래도 함께 만든다(016~020 이 쓴다).
- `class Rope` — `readonly group: THREE.Group`; `constructor(radius = 0.014)`; `setPath(points: THREE.Vector3[]): void`. 점열을 호장 0.03 간격으로 선형 재표본하고 `CatmullRomCurve3(pts, false, 'centripetal')` + `TubeGeometry(curve, pts.length − 1, radius, 6, false)` 로 메시를 만든다. 호출할 때마다 이전 지오메트리를 `dispose` 하고 교체(메시는 1개 유지). 재질: `materials.ts` 의 `rubber` 를 `clone()` 해서 색만 `0x8a6a3a`(삼줄) 로. 파일 `materials.ts` 는 건드리지 않는다. castShadow = true. 점이 2개 미만이면 메시를 숨긴다.
- `arcPoints(c: V2, r: number, a0: number, a1: number, z: number, seg = 14): THREE.Vector3[]` — 중심 c, 반지름 r 인 원에서 각 a0 → a1 (라디안, +X = 0, +Y = π/2, a1 < a0 이면 시계방향) 의 호. 양끝 포함, 개수 = ceil(|a1 − a0| / π × seg) + 1. 점 = (c.x + r cos a, c.y + r sin a, z).
- `pulleyBlock(r: number, opts?: { hookUp?: number; hookDown?: number; width?: number /*0.07*/; spokes?: number /*4*/; driver?: boolean }): THREE.Group` — 원점 = 바퀴 중심, 회전축 = 로컬 Z. 내용: `pulley(r, { width, spokes, grooved: true, driver })` 를 하위 그룹 `sheave` 에 넣고 `group.userData.sheave = sheave`(이 그룹의 rotation.z 만 돌린다). 양쪽에 평평한 띠쇠 2개(castIron, 폭 0.025 × 두께 0.012, z = ±(width/2 + 0.012), y 범위 = −(r + hookDown − 0.02) ~ +(r + hookUp − 0.02); hookUp/hookDown 이 0 이면 그쪽은 바퀴 둘레까지만) + 중심 축 못(steel 원통, 반지름 0.02, 길이 width + 0.05). hookUp > 0 이면 (0, r + hookUp) 에, hookDown > 0 이면 (0, −r − hookDown) 에 눈고리(steel 토러스, 반지름 0.028, 관 0.008, 축 = Z). 줄을 맬 점 = 눈고리 중심.
- `ceilingBeam(x0: number, x1: number, yBottom: number, hooksX: number[]): THREE.Group` — wood 상자 폭 (x1 − x0) × 0.12 × 0.72, x 중심 (x0 + x1)/2, y 범위 yBottom ~ yBottom + 0.12, z 중심 0.06(뒤판에 붙음, z −0.30 ~ 0.42). hooksX 마다 steel 토러스 고리(반지름 0.03, 관 0.008, 축 Z)를 (x, yBottom − 0.03, 0.22) 에 매단다 → 고리 아랫점 = (x, yBottom − 0.06, 0.22). 들보 아랫면은 뒤판 위쪽 안에 있어야 한다(전시 영역 상단 3.15 이하).
- `ropeEnd(): THREE.Group` — 원점 = 줄 끝점, 그 아래로 매듭(작은 원통 0.02 × 0.04)과 wood 손잡이 구(반지름 0.035, 중심 y −0.07).
- 줄은 모두 위 `Rope` 로 그린다(`ropeAround` 가 낸 점열을 `rope.setPath(...)`). 표시점이 필요하면 줄 위에 작은 구를 호장 위치로 둔다.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- 추 올림 높이 d(theta) = 0.30 × (1 − cos(0.5 × theta)) (0 ~ 0.6, 주기 ≈ 7.85 s, 양 끝에서 천천히 멈칫).
- 추 중심 y_c = 0.62 + d, 손(줄 끝) E = T + u × (1.8 + d) (손이 d 만큼 더 내려감 — 1 : 1).
- 도르래: `rotation.z = + d / 0.36` (오른쪽 줄이 올라가고 왼쪽 줄이 내려가는 반시계). 도르래·옆판·고리는 위치 고정, 바퀴만 돈다.
- 줄: 위 `ropeAround` 로 매 프레임 `setPath`.

## 표시
- `rotArrow(0.55, true)` 도르래 앞(z = 0.36). tag '고정 도르래'(도르래 오른쪽 위), '추'(추 오른쪽), '당기는 손(힘 = 무게)'(손잡이 옆). 손잡이에서 u 방향의 화살표(원뿔 + 막대, glow)로 당기는 방향 표시.
- notes: `[{ label: '힘의 이득', value: '1 : 1 (방향만 바뀜)' }, { label: '당긴 줄 길이', value: d.toFixed(2) }, { label: '추 올라간 높이', value: d.toFixed(2) }]` — 두 값이 같다.

## 확인
- t=0.5(d ≈ 0.02) 와 t=3.9(d ≈ 0.6): 추가 올라가 있고 손이 아래로 내려가 있다, 도르래 스포크·표시점이 달라졌다. 줄은 어느 때나 도르래 홈에 붙은 채 매끈하고 왼쪽 줄은 같은 기울기의 직선.
- 추가 도르래·뒤판과 겹치지 않고, 손이 바닥(y = 0.2)보다 위에 있다.
