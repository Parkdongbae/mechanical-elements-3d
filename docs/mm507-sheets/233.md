# 233 랜턴 바퀴의 멈추개
원문: "Shows two different kinds of stops for a lantern-wheel." — 랜턴 바퀴(원통 살 바퀴)를 위한 서로 다른 두 가지 멈추개를 보여 준다. 쉬운 풀이: 원판에 박힌 핀들(랜턴 바퀴)에 레버와 판이 걸려 바퀴가 더 돌지 못하게 막는다. 멈추개를 만드는 두 가지 방법이 그려져 있다.
판화 묘사(원본 510×437 px, [x·y]): 둥근 원판(축 [227·257], 두 겹 원 허브, 반지름 약 122 px, 아래쪽은 물결 끊김선). 원판 앞면 둘레에 작은 원(핀) — 반지름 약 100 px 원 위에 25.7° 간격(0°·27°·55°·80°·102°·133°·158°·180° 가 보임 → 14개), 핀 반지름 약 9 px. 멈추개 둘: ① 왼쪽 — 받침 구멍 [46·217] 에서 오른쪽 위로 뻗은 팔 끝에 두 겹 원(롤러, 바깥 반지름 약 20 px, 중심 [173·155]) 이 102°·133° 두 핀 사이에 끼어 있다. ② 오른쪽 — 받침 구멍 [447·170] 의 납작한 막대(높이 약 35 px, 받침 구멍은 위쪽에 치우침)가 왼쪽으로 뻗어, 끝이 비스듬히 깎인 면(아래 왼쪽 [283·200] → 위 오른쪽 [300·165])이 55° 핀의 오른쪽에 닿고, 막대 밑면(y 200)은 27° 핀 위에 얹혀 있다.

## ★ 판화 읽기
판화 1 px = 0.0066. 원판 중심 W = (−0.15, 1.55)(세계). "W 기준" = 세계 − W.
1. 바퀴는 몇 개이고 크기 차례는? → 랜턴 바퀴(핀 박힌 원판) 1개: 원판 반지름 0.805, 핀 14개가 반지름 0.66 원 위, 핀 반지름 0.06. 롤러(반지름 0.12)는 멈추개의 일부.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 원판 축 W, 롤러 레버 받침 PL (−1.195, 0.264), 막대 폴 받침 PR (1.452, 0.574)(W 기준). 둘 다 원판 바깥(1.22, 1.56 > 0.805)에서 뒤판에 박은 핀.
5. 추·손잡이·크랭크는? → 판화에 없음. 원판을 돌리는 손잡이를 축 앞에 보충.
6. 이(핀)는 어디에, 무엇이 어느 쪽에서 무는가? → 핀은 원판 앞면에서 앞으로 솟은 원기둥(랜턴 바퀴의 살). 롤러는 위에서 두 핀 사이 홈에 내려앉아 **양쪽 방향 모두** 붙잡는다(세게 돌리면 핀에 밀려 넘어감 — 위치 잡이). 막대 폴은 비스듬한 끝면이 핀을 막아 **시계 방향은 완전히 막고**, 반시계로 돌면 핀이 막대 밑면을 들어 올리며 지나간다.
7. 한 줄에 놓인 것은? → 롤러 중심이 원판 중심에서 117.86°(두 핀 105°·130.71° 의 가운데). 막대 밑면은 거의 수평(0.93° 기욺).
8. 글자가 가리키는 부품은? → 판화에 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 계속 돈다. 다만 판화의 막대 끝은 핀 반지름 원보다 깊이(끝 모서리가 원판 중심에서 0.53) 들어가 있어, 핀이 막대 끝을 지나가려면 막대가 **13° 까지 들려야** 하고 핀이 끝면을 넘은 뒤 **6° 툭** 떨어진다(이 하나 = 25.71° 보다 8.1° 더 돌아야 떨어짐). 판화 그대로 두고, 손을 놓으면 9° 되돌아가 끝면에 걸리게 한다. → ★질문 거리.

## 해석(결정 사항)
- 손잡이로 원판을 **반시계**로 한 칸(25.714°) + 9° 돌렸다가, 손을 놓아 **시계로 9° 되돌아가면 막대 끝면이 핀에 걸려 멈춘다**(빨강). 롤러는 그 사이 한 핀을 넘어 다음 홈에 앉는다. 한 박자 2.4 초.
- 잠금 자세(박자 끝): 롤러가 두 핀에 각각 틈 0.0016 으로 끼고, 막대 끝면이 핀에 틈 0.0015, 막대 밑면이 아래 핀에 틈 0.0015 로 얹힘.
- 두 멈추개 자세는 원판 각에서 **표**로 읽는다(파이썬 shapely, 앞 자세에서 이어 따라감, 틈 0.0006).
- 막대 끝 모서리는 볼록 0.015, 오목 0.01 둥글림. 롤러는 원.

## 구동
`t` 장면 시간(초). 박자 Tb = 2.4, n = floor(t/Tb), u = t − n·Tb, PIT = 360/14 = 25.7143°, s(x) = x²(3 − 2x)(x 는 0~1 로 자름).
- u < 1.6: θ = PIT·n + 34.714·s(u/1.6), θmax = PIT·n + max(9, 34.714·s(u/1.6))
- 1.6 ≤ u < 2.0: θ = PIT·n + 34.714 − 9·s((u − 1.6)/0.4), θmax = PIT·n + 34.714
- 2.0 ≤ u < 2.4: θ = PIT·(n + 1), θmax = PIT·n + 34.714 (멈춤)
θ(도) 반시계 +. 원판 `rotation.z = θ·π/180`.
