# 257 둥근 홈 풀리
원문(en): "A concave-grooved pulley for a round band." — 둥근 줄(밴드)을 거는, 오목한 홈이 있는 풀리.
쉬운 풀이: 테두리에 반원 모양으로 둥글게 파인 홈이 있어 둥근 줄이 그 속에 들어가 앉는다. 아래 작은 구동 풀리가 돌면 둥근 줄이 홈에서 벗어나지 않고 위 풀리를 돌린다.
판화 묘사(원본 510×437 px, 축이 화면 좌우로 누운 **옆 모습**): 가운데 세로로 선 테(x 190–282, 폭 ≈ 92 px, 위 y ≈ 38, 아래 y ≈ 385 → 반지름 ≈ 174 px). 테의 위·아래 끝에 **반원으로 파인 홈**(x 210–262, 폭 ≈ 52 px, 깊이 ≈ 26 px = 반원) — 홈 양옆에 좁은 턱(각 ≈ 20 px)이 남는다. 테 앞면에 홈 가장자리 세로선 둘. 양옆 짧은 네모(x 172–190, 282–302, 반지름 ≈ 50 px) = 허브, 바깥 둥근 축(반지름 ≈ 22 px). 줄·다른 풀리는 없음.

## ★ 판화 읽기
판화는 그림 하나(옆 모습). 판화 1 px ≈ 0.00357(반지름 174 px = 0.62).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 둥근 홈 풀리 1개. 보충: 같은 홈의 작은 구동 풀리 1개(아래). 크기 차례: 큰 풀리(바깥 0.62, 홈 바닥 0.527) > 구동 풀리(바깥 0.30, 홈 바닥 0.207).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에는 없음. 보충: 둥근 줄 1개(닫힌 고리, 굵기 반지름 0.085) — 큰 풀리 위쪽 홈을 반시계로 감고 왼쪽 가닥으로 내려와 구동 풀리 아래 홈을 감고 오른쪽 가닥으로 올라간다.
3. 교차하는 가닥이 있는가? → 없음(열린 걸이).
4. 고정점(천장·벽·바닥)은 어디인가? → 두 축 모두 뒤판 보스에서 나온 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 아래 구동 풀리 축이 일정하게 돈다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음(줄 전동).
7. 한 줄에 놓인 것은? → 두 풀리 중심이 x = 0(y 2.12 / 0.82). 두 풀리 홈 가운데·줄이 모두 깊이 0.10.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 257 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 어긋남 없음. 홈은 반지름 0.093 의 반원(판화 폭 52 px·깊이 26 px 그대로), 줄은 그 홈에 맞는 굵은 둥근 줄(반지름 0.085)로 둔다. 판화는 풀리 하나뿐이라 구동 풀리·줄을 보충. 판화는 옆 모습이고 모델은 축을 깊이(Z)로 두어 45° 시점(질문 거리 1·2).

## 해석(결정 사항)
- 큰 풀리 = 판화 그대로: 폭 0.33 테, 가운데 반원 홈(반지름 0.093, 반원 중심이 바깥 반지름 0.62 위), 양옆 턱(폭 0.072) + 웹 + 허브.
- 줄 = 둥근 줄(반지름 0.085) — 홈 바닥에 닿아 중심 반지름 0.612(= 0.527 + 0.085), 줄 단면 원이 홈 원 안에 들어간다(홈 원 중심과 0.008, 0.085 + 0.008 = 0.093). 둥근 줄 ↔ 둥근 홈 짝.
- 구동 풀리 = 같은 단면 함수로 바깥 반지름 0.30 인 둥근 홈 풀리(같은 줄이 맞게 홈 크기 같음). 돌아가는 풀리 전체가 한 그룹.
- **단면 보이기**: 큰 풀리 림·웹을 ψ = −90° ~ −25° 만큼 잘라 낸 회전체 + 주홍 단면판 둘. 림·웹·단면판은 세계에 고정(회전 대칭), 돌아감은 허브 표시·너트·줄 표시로. 잘린 자리는 줄이 닿지 않는 구간(줄 접점 ψ −14.25°, 여유 10.75°).

## 구동
구동 풀리 φ2(t) = 1.2·t [rad], 정면 반시계. 줄 흐름 s = 0.292·φ2. 큰 풀리 φ1 = s / 0.612 = 0.47712·φ2.

## 동작 (`state257(t)` — 결정적)
1. φ2 = 1.2t. `driveShaft`·`drivePulley` 의 `rotation.z = φ2`.
2. φ1 = 0.47712·φ2. `bigShaft`·`bigPulley` 의 `rotation.z = φ1`. `bigRimGroup` 은 그대로.
3. `rope.setOffset(0.292·φ2)`.
4. 방향: 반시계 고리 — 두 풀리 반시계.
5. 감긴 각: 큰 풀리 208.50°(위쪽, ψ −14.25° → 194.25°), 구동 풀리 151.50°(아래쪽, ψ 194.25° → 345.75°). 접선 끝점: 큰 (±0.5932, 1.9694) ↔ 구동 (±0.2830, 0.7481).
6. 틈 검산: 줄(반지름 0.085, 중심 0.612)이 홈 바닥 0.527 에 닿고, 홈 원(중심 0.62, 반지름 0.093)과 중심 거리 0.008 이라 홈 벽 안. 줄 꼭대기 0.697(테 위로 0.077 드러남). 잘린 첫 면 ψ −25° 에서 줄 중심 0.623 — 줄 단면이 홈 원 안(0.0029 + 0.085 < 0.093)이라 단면판과 닿지 않음. 화살표(깊이 0.38) ↔ 줄 앞(0.185): 0.195.
