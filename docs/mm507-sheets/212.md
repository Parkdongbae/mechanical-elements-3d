# 212 제네바 스톱
원문: "What is called the \"Geneva-stop,\" used in Swiss watches to limit the number of revolutions in winding-up; the convex curved part, a, b, of the wheel, B, serving as the stop." — '제네바 스톱'이라 부르는 것으로, 스위스 시계에서 태엽을 감을 때 돌릴 수 있는 바퀴 수를 제한한다. 바퀴 B 의 볼록하게 굽은 부분 a, b 가 멈추개 역할을 한다. 쉬운 풀이: 태엽을 감을 때 별 모양 바퀴가 둥근 바퀴에 한 칸씩 밀려 돌다가, 볼록한 부분에 막히면 더는 돌 수 없다.
판화 묘사(원본 506×445 px, [x·y]): 아래 둥근 바퀴 A(축 [207·318], 반지름 약 115 px). A 의 위 오른쪽 둘레에 뾰족한 손가락 이 하나(끝 [252·195], 축에서 약 131 px)와 그 양옆의 오목한 파냄 두 개. 위 별 바퀴 B(축 [195·118], 끝 반지름 약 108 px): 곧은 벽의 네모 홈 5개(B 중심에서 15°·92°·166°·238°·301°, 약 72° 간격, 홈 바닥 반지름 65 px), 홈 사이 옆면 4개는 오목(A 의 둥근 테에 맞는 곡선), 나머지 하나(15°~92° 사이, 위 오른쪽)는 볼록한 호 — 그 양 끝에 글자 a(위 홈 오른쪽 모서리), b(오른쪽 홈 위 모서리). 지금 A 의 손가락이 B 의 아래 오른쪽 홈(301°) 입구에 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0062(축 거리 200 px = 1.24).
1. 바퀴는? → 2개. A(손가락 바퀴, 잠금 원판 반지름 0.75, 손가락 끝 0.88) ≈ B(별 바퀴, 끝 반지름 0.622).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. A 의 손가락이 B 의 홈 위에 겹쳐 보인다.
4. 고정점은? → A 축 [207·318], B 축 [195·118] — 거의 같은 세로선(x 차 12 px 는 같은 세로선으로 본다).
5. 추·손잡이·크랭크는? → 판화에 없음. A 가 태엽 굴대(감는 쪽) → A 축 앞에 감기 손잡이 보충.
6. 기어는? → 기어 이 대신 A 의 손가락 하나가 B 의 홈에 들어가 B 를 72° 씩 민다(제네바). 손가락이 없을 때는 A 의 둥근 테가 B 의 오목 옆면을 받쳐 B 를 잠근다.
7. 한 줄에 놓인 것은? → A 축·B 축이 한 세로선. B 의 오목 옆면 하나가 그 선 위(아래쪽)에서 A 를 마주 본다.
8. 글자가 가리키는 부품은? → A = 아래 손가락 바퀴, B = 위 별 바퀴, a·b = B 의 볼록한 호의 두 끝(멈추개).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음. (가) 판화는 손가락이 B 와 같은 판에 있는데, 같은 판이면 손가락 몸통(목)이 홈에 비스듬히 들어간 동안 B 의 홈 모서리와 부딪친다(계산: 목 폭 허용 0.008). → 손가락 판은 B 바로 앞 층에 두고, 끝의 **핀만** B 의 층으로 내려 홈을 민다. (나) 판화의 파냄은 손가락 오른쪽이 크게 그려졌지만 감기·풀기 양쪽으로 돌아야 하므로 양쪽 같은 원(대칭)으로 판다. → ★질문 거리.

## 해석(결정 사항)
- 별 바퀴 B: 홈 5개(72° 간격) + 오목 옆면 4개 + 볼록 옆면 1개(a~b). 손가락(핀) 한 번 지날 때 B 가 72° 돈다. B 가 오목 옆면으로 잠기는 자리는 4곳 → 그 사이 3번 + 양 끝에서 손가락이 볼록 옆면 쪽 홈에 들어가다 볼록한 호가 A 의 테에 걸려 멈춤. **양 끝 멈춤 사이 A 는 1443.0° = 4.01 바퀴**.
- 손가락 핀이 홈에 들어가는 반지름 Re = 0.655, 핀 반지름 0.07, 핀 회전 반지름 rf = √(d² + Re² − 2·d·Re·cos36°) = 0.8077, 물린 구간 A 각 ±aw = ±28.466°(B 쪽을 가리키는 방향 기준).
- 판화에 없는 보충: 감기 손잡이, 바퀴 수 표시등 4개, 볼록 호의 빨간 띠.

## 구동

- u ∈ [12.592, 14.092): 멈춤 α = αf(볼록 a·b 가 A 에 걸림, 빨강)

- u ∈ [26.684, 28.184): 멈춤 α = αb(반대쪽 걸림, 빨강)

j = floor((α − 90 + 180)/360), αc = 90 + 360·j, base = 144 − 72·j.
α < αc − 28.466 → β = base. α > αc + 28.466 → β = base − 72. 그 사이 → 핀 점 (x, y) = (0.8077·cos α, −1.24 + 0.8077·sin α)(B 중심 기준), β = base + atan2(y, x)(도) + 54.
