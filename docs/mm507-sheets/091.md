# 091 삼각 편심
원문: **간헐적인** 왕복 직선 운동을 주는 삼각 편심. 프랑스에서 증기 기관의 밸브 운동에 쓰였다. (글자·수치 없음)

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/091-fig-x4.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 기어·풀리는 없다. **삼각 편심(캠) 1개**와 그것을 둘러싼 **네모 틀 1개**. 캠은 세 변이 모두 바깥으로 볼록한 삼각형(뢸로 삼각형)이고, **축(빗금 원)은 캠의 한가운데가 아니라 아래 꼭짓점에 꿰여 있다**. 축 둘레에 허브 고리(반지름 65 px)가 꼭짓점 밖으로 불거져 있다. 판화에서 잰 값: 축 중심에서 맞은편 큰 호까지 430 px, 축 중심에서 위 두 모서리까지 438 px(방향은 세로에서 ±35°), 위 두 모서리는 살짝 둥글다.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 없다. 축 단면만 그렸다(축은 제자리에서 돈다). 위·아래 막대의 안내는 그리지 않았다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 축에 고정된 삼각 캠.
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 이는 없다. 맞닿는 짝은 **캠 윤곽 ↔ 틀 안쪽의 위·아래 곧은 가로 막대(닳음 띠)**. 판화의 순간에는 캠의 위쪽 큰 호가 윗 띠에, 축 둘레 허브 고리가 아랫 띠에 닿아 있다(두 띠의 간격 495 px, 430 + 65 와 같다). 틀의 좌우 안벽은 캠에 닿지 않는다(옆변은 바깥으로 볼록하게 굽어 캠이 옆으로 누울 자리를 준다). 틀의 위·아래 한가운데에서 세로 막대가 하나씩 뻗는다(위는 둥근 끝, 아래는 잘린 끝 — 밸브 쪽).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 축 중심, 캠의 대칭축, 위·아래 막대가 한 세로줄. 두 닳음 띠는 서로 평행한 가로선.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 판화 치수가 "폭이 일정한 꼴"과 맞는다: 뢸로 삼각형의 폭 w 를 365 px, 모서리 둥글림(허브 고리와 같음) ρ 를 65 px 로 두면 큰 호 반지름 w + ρ 는 430, 띠 간격 w + 2ρ 는 495, 위 모서리 가로 끝 ±247 px 이 모두 판화와 일치한다. 그래서 어느 각도에서나 두 띠에 동시에 닿아 계속 돈다.
- 그 밖의 선: 틀의 두 겹 윤곽 = 테의 안·밖. 띠의 가는 두 줄 = 띠의 두께. 축 둘레 겹 원 = 허브 고리와 축.

## 해석(결정 사항)
- 캠 윤곽 = 폭 w 인 뢸로 삼각형(꼭짓점 V0 = 축, V1·V2 = 위 두 모서리)을 ρ 만큼 부풀린 꼴: 꼭짓점 둘레 작은 호(반지름 ρ) 셋 + 맞은편 꼭짓점 중심 큰 호(반지름 w + ρ) 셋. 어느 방향으로 재도 폭 w + 2ρ.
- **간헐 운동의 까닭**: 축을 중심으로 하는 호(축 둘레 작은 호, 맞은편 큰 호)가 띠에 닿는 동안은 닿는 높이가 변하지 않는다 → 틀이 선다. 한 바퀴 = 위에서 멈춤 60° → 내려감 120° → 아래에서 멈춤 60° → 올라감 120°. 행정 = w.
- 전시 높이(y ≤ 3.3)에 위·아래 막대와 안내를 넣어야 하므로 w = 0.5 로 잡는다(2w + ρ ≤ 1.15 가 한계).

## 구동
축. theta += OMEGA(1.6)·speed·dt, θe = theta − 1.6 (t = 1 에서 θe = 0 — 판화 자세: 캠 대칭축이 위, 위 멈춤의 한가운데). 반시계.

## 동작 (모두 θe 의 닫힌 식 — 누적 오차 없음)
- `cam.rotation.z = θe`.
- `frame.position.y = 1.75 + triCamLift(0.5, θe) − 0.25`.
- `triCamLift(w, θe)` 가 돌려주는 h: ψ 는 θe 를 −180°~180° 로 접은 절댓값.
  - ψ ≤ 30°: h = w (위 멈춤)
  - 30° ~ 90°: h = w·cos(ψ − 30°)
  - 90° ~ 150°: h = w·cos(ψ + 30°) + w
  - ψ ≥ 150°: h = 0 (아래 멈춤)
- 주기 시간표(한 바퀴 3.927 s, θe 기준): 330°~30° **위 멈춤**(0.654 s) → 30°~150° 내려감(1.309 s, 90° 에서 한가운데) → 150°~210° **아래 멈춤**(0.654 s) → 210°~330° 올라감(1.309 s).
- 틀 중심 변위(h − w/2): 0° +0.25, 30° +0.25, 60° +0.183, 90° 0, 120° −0.183, 150° −0.25, 180° −0.25.
- 시각: **t = 1.0 (θe 0°, 판화 — 위 멈춤 한가운데)**, **t = 1.6 (θe 55°, 내려가는 중, 변위 +0.203)**, t = 2.96 (θe 180°, 아래 멈춤 한가운데).
