# 239 기어의 멈추개
원문: "An arrangement of stops for a spur-gear." — 평기어를 위한 멈추개 배열이다. 쉬운 풀이: 레버 두 개가 기어의 이 사이에 끼어 기어가 돌지 못하게 막는다. 한쪽 레버를 빼면 기어가 돌 수 있다.
판화 묘사(원본 485×439 px, [x·y]): 아래쪽이 끊긴 선(물결)으로 그려진 평기어(축 [190·292], 두 겹 원 허브, 이끝 반지름 약 138 px, 이뿌리 약 106 px, 윗면이 납작한 사다리꼴 이 — 극좌표로 펴서 재면 25.5° 간격 = 14개, 맨 위 이 92°). 위쪽에 긴 레버 둘: 왼쪽 레버는 받침 구멍 [17·231] 에서 오른쪽 위로 올라가 끝이 뾰족한 코가 되어 92° 이 **왼쪽**(105° 쪽) 이골에 꽂힌다 — 코의 오른쪽 면이 거의 세로로 92° 이 왼쪽 옆면에 붙음. 오른쪽 레버는 받침 구멍 [425·205] 에서 왼쪽으로 뻗어 끝 코가 66° 이 **오른쪽**(53° 쪽) 이골에 꽂힌다 — 코의 왼쪽 면이 66° 이에 붙음.

## ★ 판화 읽기
판화 1 px = 0.0068. 기어 중심 W = (−0.20, 1.45)(세계). "W 기준" = 세계 − W.
1. 바퀴(기어)는 몇 개이고 크기 차례는? → 평기어 1개(이 14, 이끝 반지름 0.94, 이뿌리 0.72).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 기어 축 W, 왼쪽 레버 받침 PL (−1.173, 0.415), 오른쪽 레버 받침 PR (1.598, 0.592)(W 기준). 뒤판에 박은 핀.
5. 추·손잡이·크랭크는? → 판화에 없음. 기어를 돌리는 손잡이를 기어 축 앞에 보충, 레버를 드는 손은 노란 화살표로 나타낸다.
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 기어 바깥 둘레에 사다리꼴 이. 왼쪽 코는 92° 이의 반시계 쪽 옆면에 붙어 **기어의 반시계 회전을 막고**, 오른쪽 코는 66° 이의 시계 쪽 꼭짓점에 붙어 **시계 회전을 막는다**. 둘 다 내려 있으면 기어는 어느 쪽으로도 못 돈다. 반대쪽으로 돌 때 코의 뒷면(비탈)은 이에 밀려 들렸다가 다음 이골로 떨어진다.
7. 한 줄에 놓인 것은? → 두 레버가 거의 같은 높이(받침 y 차 0.18), 두 코 사이에 이 둘(92°·66°)과 이골 하나.
8. 글자가 가리키는 부품은? → 판화에 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → (가) 판화처럼 오른쪽 코 면을 66° 이 옆면에 붙이면, 받침점이 코와 거의 같은 높이라 레버를 들 때 코가 옆면 위로 기운 이 밑으로 파고든다(계산: 들자마자 겹침). → 오른쪽 코의 앞면을 **받침점 중심 원호**(반지름 1.1912)로 깎아 66° 이의 **이끝 꼭짓점**에만 닿게 한다(옆면과는 아래로 갈수록 틈이 벌어짐). 모양 차이는 코 아래쪽 0.02 정도. (나) 판화엔 레버를 드는 것이 없다 → 손 화살표. → ★질문 거리.

## 해석(결정 사항)
- 한 주기 9.6 초: 오른쪽 레버를 손으로 들고(20°) → 손잡이로 기어를 **시계로 이 2개 + 2.5°** 돌리면 왼쪽 레버가 이를 타고 두 번 넘음 → 손을 놓으면 기어가 2.5° 되돌아가다 **왼쪽 코에 걸려 멈춤**(빨강) → 오른쪽 레버를 내려 다시 양쪽 잠금 → 이번엔 왼쪽 레버를 들고(16°) 반시계로 이 2개 + 2.5° → 되돌아가다 **오른쪽 코에 걸림** → 왼쪽 내림. 기어는 주기마다 제자리로.
- 레버 각 = (손이 든 각)과 (이에 얹힌 각) 가운데 **더 들린 쪽**. 이에 얹힌 각은 기어 각에서 표로 읽는다(파이썬 shapely, 앞 자세에서 이어 따라감, 틈 0.0006).
- 코 끝 반지름 0.016, 오목 이음 0.015, 볼록 0.006 — 각져 보이지 않게. 레버는 이끝 원보다 0.025 바깥(반지름 1.04 중심선, 폭 0.15)으로 지나 코 밖에서는 이에 닿지 않는다.
