# 002 엇걸이(교차) 벨트
판화: 001 과 같은 배치인데 벨트가 가운데에서 X자로 교차한다. 원문: 두 풀리의 회전 방향이 반대가 된다.

## 부품과 치수
- 001 과 같은 풀리·축 배치(A 구동 (0, 2.55), B 종동 (0, 0.95), r = 0.52).
- 벨트: `crossedBeltPath([0,2.55], 0.53, [0,0.95], 0.53)`. 교차부에서 두 가닥이 서로 뚫고 지나가 보이지 않게 **한 가닥은 z = 0.22, 다른 가닥은 z = 0.28** 로 살짝 띄운다 — 평면 경로를 만든 뒤 교차 구간(두 직선부)에만 z 를 선형으로 달리 준 3D 점열로 `Belt` 를 만든다.

## 동작
- A.rotation.z = theta, **B.rotation.z = -theta** (반대 방향, 같은 속도).
- `belt.setOffset(theta * 0.53)`.

## 표시
- `rotArrow` A 는 반시계, B 는 시계(서로 반대). tag '구동 풀리' / '종동 풀리'.
- notes: `[{ label: '회전 방향', value: '서로 반대' }, { label: '속도비', value: '1 : 1' }]`

## 확인
- t=1 과 t=1.6 사이에 A 와 B 의 스포크가 **반대 방향**으로 돈다. 벨트가 X자로 보이고 교차부에서 가닥이 겹쳐 깜빡이지 않는다.
