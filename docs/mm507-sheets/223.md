# 223 부채꼴 기어 배열
원문(en): "An arrangement for obtaining variable circular motion. The sectors are arranged on different planes, and the relative velocity changes according to the respective diameters of the sectors." — 변하는 원운동을 얻는 장치. 부채꼴(섹터) 기어들을 서로 다른 평면에 놓아, 맞물리는 부채꼴의 지름에 따라 상대 속도가 달라진다.
쉬운 풀이: 이가 달린 부채꼴 조각들을 서로 다른 층에 겹쳐 놓았다. 맞물리는 반지름이 바뀌어 한쪽이 일정하게 돌 때 다른 쪽은 속도가 변한다.
판화 묘사(원본 444×516 px, [x·y]): 같은 세로선 위에 축 둘 — 위 축 U [211·162], 아래 축 L [209·365](거리 203 px). 위 축에 부채꼴 넷이 사분면마다 하나씩: 오른쪽 위(0°~90°) 큰 부채꼴(반지름 약 144 px, 맨 앞), 왼쪽 위(90°~180°) 중간(약 93 px), 왼쪽 아래(180°~270°) 작은 것(약 38 px, 대부분 가려짐 — 위 축 바로 아래 왼쪽의 작은 이들), 오른쪽 아래(270°~360°) 중간(약 88 px). 아래 축에도 넷: 위쪽 좁은 부채꼴(90°~116°, 반지름 약 165 px — 끝 이가 위 축 바로 밑까지 옴), 왼쪽 위(120°~180°, 약 113 px), 오른쪽 위(23°~82°, 약 118 px), 아래쪽 반원(약 190°~372°, 약 73 px). 지금 자세는 위 축의 아래쪽(270°)과 아래 축의 위쪽(90°)이 부채꼴 경계.

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.0059(축 거리 203 px = 1.20).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 부채꼴 기어 8개(위 4, 아래 4). 피치 반지름: 위 U1 0.80 > U2 0.56 = U3 0.56 > U4 0.24 / 아래 L1 0.96 > L2 0.64 = L3 0.64 > L4 0.40. 짝(같은 층): U1↔L4, U2↔L2, U3↔L3, U4↔L1 — 짝마다 반지름 합 = 축 거리 1.20.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점(천장·벽·바닥)은? → 위 축 U = (0, 2.42), 아래 축 L = (0, 1.22) — 둘 다 뒤판에서 나온 축.
5. 추·손잡이·크랭크는? → 판화에 없음. 위 축이 일정하게 돈다(구동), 아래 축이 출력(원문 "variable circular motion").
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 모든 부채꼴은 바깥 호에만 이. 두 축 사이 세로선(x = 0) 위에서, 같은 층의 짝끼리만 물린다. 층이 다르면 반지름 합이 1.20 보다 커도 서로 지나간다(원문 "different planes").
7. 한 줄에 놓인 것은? → 두 축이 같은 세로선 x = 0. 물리는 점은 늘 그 세로선 위.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 223 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문과 판화는 일치. 판화 크기(반지름 비 0.71·0.46·0.43·0.19)를 그대로 쓰면 아래 부채꼴 넷의 각 합이 386° 가 되어 한 바퀴에 맞지 않는다 → 각 합이 정확히 360° 가 되는 가장 가까운 잇수(위 40·28·28·12, 아래 20·32·32·48, 짝마다 합 60)로 맞췄다(아래 반원 L4 = 정확히 180° — 판화의 반원 그대로). 또 짝이 바뀌는 순간 들어오는 짝의 첫 이가 나가는 짝의 빠르기로 움직여 부딪히므로(216 과 같은 문제), **부채꼴 끝 이를 몇 개 빼고** 경계 앞뒤 ±4°(위 축 각) 동안 아래 축을 매끄럽게 이어 돌린다(그 사이 이는 닿지 않음 — 파이썬 검산). 질문 거리 없음.

## 해석(결정 사항)
- 짝 넷이 각자 다른 층. 위 축의 사분면 하나(90°)가 지나가는 동안 그 사분면의 짝만 물린다. 위 축 반시계 일정(ω 0.5 rad/s) → 아래 축은 시계 방향, 빠르기 비가 짝마다 다름: U4/L1 0.25, U2/L2 0.875, U1/L4 2.0, U3/L3 0.875(한 바퀴 안에서 8 배 차). 아래 각 합: 22.5° + 78.75° + 180° + 78.75° = 360° → 위 한 바퀴에 아래 정확히 한 바퀴, 다음 바퀴에도 같은 자리에서 물림.
- 물리는 차례(위 반시계): U4↔L1 → U2↔L2 → U1↔L4 → U3↔L3 → (반복). 판화의 앞뒤·자리 그대로.
- 층(앞 → 뒤, 두께 0.05, 사이 0.015): 짝1 U1/L4 z 0.205 / 짝2 U2/L2 z 0.140 / 짝3 U3/L3 z 0.075 / 짝4 U4/L1 z 0.010(z 는 가운데).
- 짝을 알아보게 짝마다 색 띠(짝1 빨강, 짝2 파랑, 짝3 초록, 짝4 주황) — 판화에 없는 보충.

## 동작 (결정적)
1. θU(°) = 0.5·t·180/π.
2. θL(°): n = floor(θU/360), x = θU − 360·n. 경계 B = [0, 90, 180, 270, 360], 기준값 V = [0, −22.5, −101.25, −281.25, −360], 빠르기 비 r = [0.25, 0.875, 2.0, 0.875](구간 [0,90), [90,180), [180,270), [270,360)).
   - 어느 경계 B[i] 에 대해 |x − B[i]| < 4 이면(이음 구간): rp = r[(i − 1) mod 4], rn = r[i mod 4], θL = −360·n + H(x; B[i] − 4, B[i] + 4, V[i] + 4·rp, V[i] − 4·rn, −rp, −rn).
   - 아니면 k = floor(x/90): θL = −360·n + V[k] − r[k]·(x − 90·k).
   - H(x; a, b, ya, yb, sa, sb) = 3차 에르미트: s = (x − a)/(b − a), h = b − a, (2s³ − 3s² + 1)·ya + (s³ − 2s² + s)·h·sa + (−2s³ + 3s²)·yb + (s³ − s²)·h·sb.
3. `upper.rotation.z = θU·π/180`, `lower.rotation.z = θL·π/180`.
4. 수치(파이썬):
