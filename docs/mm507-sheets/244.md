# 244 마찰식 동력계
원문(en) 요지: "A dynamometer … A is a smoothly-turned pulley, secured on a shaft as near as possible to the motive-power. Two blocks of wood are fitted to this pulley, or one block of wood and a series of straps fastened to a band or chain, as in the drawing … made to bite or press upon the pulley by means of the screws and nuts on the top of the lever, D. … At the end of the lever, D, is hung a scale, B, in which weights are placed. The two stops, C, C′, are to maintain the lever as nearly as possible in a horizontal position. Now, suppose the shaft to be in motion, the screws are to be tightened and weights added in B, until the lever takes the position shown in the drawing … the useful effect would be equal to the product of the weights multiplied by the velocity at which the point of suspension of the weights would revolve if the lever were attached to the shaft." — (프로니 브레이크) A 는 동력 가까운 축에 박힌 매끄러운 풀리. 그림처럼 위에는 나무 블록 하나, 아래에는 띠(체인)에 단 나무 조각들을 풀리에 대고, 레버 D 위의 나사·너트로 죄어 풀리를 문다. 레버 D 끝에 저울 접시 B 를 걸어 추를 올린다. 멈추개 C·C′ 는 레버를 되도록 수평으로 둔다. 축이 도는 동안 나사를 죄고 B 에 추를 더해 레버가 그림 자리(수평)에 오게 하면, 일 = 추 무게 × (레버가 축에 붙어 돈다면 추 매단 점이 도는 빠르기).
쉬운 풀이: **도는 것은 풀리 A(축)뿐**이다. 나무 블록·띠·레버 D·접시 B 는 풀리를 물고 있지만 돌지 않고, 마찰이 레버를 들어 올리려는 힘과 추의 무게가 맞서 레버가 C 와 C′ 사이에 수평으로 떠 있다. 그때의 추 무게와 회전수로 기계의 힘을 잰다.
판화 묘사(원본 445×454 px, 정면): 위에 긴 가로 막대 **D**(레버, x 10~398, y 203~220). 왼쪽 아래에 풀리 **A**(흰 고리, 중심 [76·257], 반지름 25 px, 가운데 빗금 축). 풀리 위 레버 밑에 빗금 친 **나무 블록**(풀리 꼭대기를 오목하게 받음), 풀리 아래 반쪽에 **띠에 단 나무 조각들**(점 = 이음 핀), 양옆 띠 끝이 레버 위 **나사 두 개**(너트 [35·195], [118·195])로 올라감. 오른쪽 레버 위에 **C′**, 아래에 **C**(작은 네모 멈추개, x ≈ 297). 레버 오른쪽 끝 밑 고리 [372·228] 에서 줄 네 가닥이 내려와 네모 **저울 접시 B**(y 410~425) — 위에 원통 추와 종 모양 추.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.009.
1. 바퀴는 몇 개이고 크기 차례는? → 풀리 A 하나(반지름 0.25). 다른 바퀴 없음.
2. 줄·벨트는? → (가) 풀리 아래를 감싼 쇠띠(U 자) — 양 끝이 나사(볼트)가 되어 레버를 뚫고 위로, 너트로 죔. 띠 안쪽에 나무 조각 5 개. (나) 접시 줄 4 가닥: 고리 → 접시 네 귀. 둘 다 바퀴를 따라 도는 줄이 아님(고정 모양).
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은? → 축(뒤판, 동력 쪽), 멈추개 C·C′(뒤판에서 나온 받침 블록 — 판화에는 받침이 안 보임). 레버·블록·띠는 고정점이 없다 — 풀리를 물고 있을 뿐.
5. 추·손잡이·크랭크는? → 추 = 접시 B 위 원통 추·종 추. 손잡이는 너트 둘(사람이 돌림). 구동 = 축(풀리 A 가 일정하게 반시계로 돎).
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 레버 D 가 수평(그림 자리). 풀리 중심 · 블록 · 나사 둘의 가운데가 같은 세로선 x −1.16. 고리 · 접시 가운데가 같은 세로선 x 1.55. 멈추개 C · C′ 가 같은 세로선 x 0.83.
8. 글자가 가리키는 부품은? → A = 풀리, B = 저울 접시, C = 레버 아래 멈추개, C′ = 레버 위 멈추개, D = 레버.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없다. 무엇이 도는지: **풀리 A 만 돈다**(원문 "suppose the shaft to be in motion", "if the lever were attached to the shaft" — 레버는 축에 붙어 있지 않다). 레버 쪽은 마찰과 추가 맞서 거의 가만히 있다. 원문의 "추를 더해 간다"는 접시 위에 추가 떠서 내려오는 장면이 되므로 모델에서는 **추는 그대로 두고 너트를 죄는 쪽**으로 균형을 보인다(질문 거리).

## 해석(결정 사항)
- 풀리 중심 O = (−1.16, 1.76). 레버·블록·띠·볼트·너트·고리는 한 묶음 `brake`(원점 O)로 O 둘레를 α 만큼만 기운다(풀리를 물고 도는 마찰 브레이크이므로 풀리 축이 곧 기울기 중심).
- 풀리 회전 방향: 추가 오른쪽 끝을 내리려 하므로 마찰은 오른쪽 끝을 들어야 한다 → **풀리는 반시계**(정면에서).
- 시간표(12 초): 너트가 풀려 있으면 마찰이 작아 레버가 C 에 얹힘(α = −2.188°) → 너트를 2 바퀴 죄면(아래 띠가 0.03 올라와 풀리를 묾) 레버가 떠올라 수평(그림 자리)에서 C·C′ 어느 쪽에도 닿지 않음 → 너트를 풀면 다시 C 로.
- 판화에 없는 보충: 멈추개 받침(뒤판에서 나온 블록 자체), 풀리 노란 표지, 회전 화살표.

## 구동
τ = t mod 12, s(u) = u²(3 − 2u)(u 는 0~1 로 자름).
- 풀리 각 θA(t) = 1.6·t(반시계, 일정).
- 너트 각 ν(t): τ < 1.5 → 0 / 1.5 ≤ τ < 3.5 → 4π·(τ − 1.5)/2 / 3.5 ≤ τ < 9 → 4π / 9 ≤ τ < 11 → 4π·(1 − (τ − 9)/2) / τ ≥ 11 → 0. (2 바퀴 죄고 2 바퀴 풂.)
- 아래 띠 처짐 σ = 0.03·(1 − ν/4π)(나사 피치 0.015).
- 레버 기울기 α(t): τ < 2.5 → αC / 2.5 ≤ τ < 3.5 → αC·(1 − s(τ − 2.5)) / 3.5 ≤ τ < 9.5 → 0 / 9.5 ≤ τ < 10.5 → αC·s(τ − 9.5) / τ ≥ 10.5 → αC. αC = −0.0381948 rad(−2.188°, 레버 밑면이 C 의 오른쪽 위 모서리에 닿는 각 — 검산).

## ★ 난도·질문
난도 **B**(중) — 부품이 많지만(블록 오목 윤곽, U 자 띠, 나무 조각 5, 너트·볼트, 줄 4) 움직임은 풀리 회전·묶음 기울기·띠 내림·접시 이동뿐. 각 단계 식이 닫힌 꼴. Sonnet 이 짠다(GLM 도 가능하나 부품 수가 많아 Sonnet 권장). 키트 추가 없음.
질문(사용자에게):
1. 원문은 "나사를 죄고 **추를 더해**" 수평을 맞춘다. 추를 더하는 장면은 추가 공중에서 내려와야 해 떠 보이므로, 기본값 = **추는 그대로, 너트를 죄어** 수평에 이르게 함. 추를 하나씩 접시에 놓는 장면을 원하면 손(또는 위에서 내려오는 갈고리)이 필요하다.
2. 멈추개 C·C′ 의 받침이 판화에 없다 — 기본값 = 뒤판에서 나온 블록(바닥 기둥은 이름표·접시 줄과 겹쳐 뺌).
