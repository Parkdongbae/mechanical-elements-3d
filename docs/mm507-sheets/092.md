# 092 보통의 크랭크 운동
원문: "Ordinary crank motion." — 일반적인 크랭크 운동(설명은 이 한 줄뿐). 바퀴의 크랭크 핀과 미끄럼 블록을 연결봉이 이어, 회전 ↔ 직선 왕복을 서로 바꾼다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/092-fig-x4.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 왼쪽의 살 6개짜리 큰 바퀴(테·허브가 있는 플라이휠 꼴). 살은 0°·60°·120°… 방향이고 살 사이 창은 모서리가 둥글다. 판화 치수(px): 바깥 반지름 145, 테 안쪽 125, 허브 42, 축(빗금 원) 22.
2. 줄·벨트는? → 없음. 대신 곧은 **연결봉 1개**가 바퀴의 크랭크 핀(오른쪽 아래 살 위, 중심에서 87px = 바퀴 반지름의 0.60배, −60° 방향)에서 오른쪽 블록의 핀까지 이어진다. 핀 사이 길이 289px = 바퀴 반지름의 2.0배(크랭크 반지름의 3.3배).
3. 교차하는 가닥은? → 없음. 연결봉이 바퀴 테와 안내틀의 왼쪽 끝 막이 **앞**을 지나간다(봉의 선이 끊기지 않고 테·틀 선이 봉에서 끊긴다).
4. 고정점은? → 오른쪽의 ㄷ자 안내틀(위·아래 가로대 두 개가 왼쪽 끝에서 세로 막이로 이어짐). 오른쪽 끝은 톱니 모양 파단선 — 더 길게 이어진다는 뜻. 바퀴 축의 받침은 그리지 않았다.
5. 추·손잡이·크랭크는? → 크랭크 = 바퀴의 살 위에 박힌 핀(두 겹 원: 핀과 봉 끝 고리). 손잡이·추 없음. 어느 쪽이 구동인지는 판화·원문에 없다(모형은 바퀴를 구동으로).
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 크랭크 핀 ↔ 연결봉 왼쪽 고리(회전 짝), 블록 핀 ↔ 연결봉 오른쪽 고리(회전 짝), 블록 ↔ 안내틀 위·아래 면(미끄럼 짝).
7. 한 줄에 놓인 것은? → 바퀴 축 중심(y 207px)과 블록 가운데(y 205px)·안내틀 가운데선이 같은 높이 — 치우침 없는 크랭크.
8. 글자가 가리키는 부품은? → 글자 없음(번호 92 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳이 없고 판화 치수 그대로 계속 돈다(블록 왕복 범위가 안내틀 안). 문제 없음.
- 그 밖의 선: 살마다 가운데 두 줄 = 살의 보강 줄(리브) — 모형은 생략. 블록은 네모(가로 95px × 세로 80px)이고 안내틀 안쪽 틈(65px)보다 높아 가로대를 살짝 덮는다 = 앞 덮개판. 블록 뒤로 보이는 안쪽 네모 선 = 틀의 안쪽 가장자리.

## 해석(결정 사항)
- 판화 비를 그대로: 크랭크 반지름 0.6R, 연결봉 2.0R, 블록은 축과 같은 높이. 판화의 순간(핀이 −60°)을 t = 1 로 맞춘다.
- 회전 방향은 판화에 없다 → 반시계로 정함(연결봉이 판화 자세에서 블록을 오른쪽으로 미는 중).
- 축 받침·안내틀 받침 기둥은 판화에 없음(공통 받침에 붙이기 위한 최소 보충).

## 구동
바퀴(theta 누적, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 블록 한 번 왕복.

## 부품과 치수 (새 부품은 모두 `kit/k092.ts`, 이미 구현됨. 치수 상수 `K92`)
배치 상수: CX = −1.08, CY = 1.7 (바퀴 축), ZW = 0.05 (바퀴·안내틀·블록의 가운데 평면), ZR = 0.24 (연결봉 평면), GX = −0.11 (안내틀 끝 막이 안쪽 면의 x).
- 바퀴(name `wheel`): `crankWheel(K92.R, K92.crank)` — 바깥 반지름 0.85, 크랭크 반지름 0.51, 테 폭 0.12, 살 6개. 위치 (CX, CY, ZW). 핀은 로컬 +X 살 위에서 앞으로 솟아 로컬 z 0.25 까지. 키트가 핀 표식 child 에 name `crankPin`(연결봉 평면)을 붙여 둔다. 주철 테 + 강철 핀.
- 축: `shaftZ(CX, CY, 0.155, 0.08)` — 뒤판에서 허브 앞까지(끝 너트 z ≤ 0.155 라 연결봉 아래로 지나간다). 받침은 shaftZ 의 뒤판 보스(판화에 없음).
- 연결봉(name `rod`): `connectingRod(K92.rod)` — 핀 사이 1.74, 끝 고리 반지름 0.08, 두께 0.06. 원점(한쪽 고리)을 크랭크 핀에 두고 +X 를 블록 핀 쪽으로 돌린다. z = ZR.
- 안내틀(name `guide`, 고정): `guideFrame(2.0, K92.gap, { back: 0.35 })` — 안쪽 틈 0.38, 가로대 높이 0.13, 끝 막이 0.08, 길이 2.0. 위치 (GX, CY, ZW). 가로 범위 −0.19 ~ 1.89, 세로 1.38 ~ 2.02. 뒤판까지 받침 기둥 4개(판화에 없음).
- 블록(name `block`): `crosshead(K92.blockW, K92.gap − 2·K92.clear, { faceH: 0.47 })` — 가로 0.48, 몸통 높이 0.374(위아래 틈 0.003), 앞 덮개판 높이 0.47. 위치 (CX + x(θ), CY, ZW). 키트가 핀 표식 child 에 name `wristPin` 을 붙여 둔다. 청동.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위 −1.93 ~ 1.89, 세로 0.85 ~ 2.55.

## 동작 (모두 theta 의 닫힌 식 — `sliderCrank92(theta)` 가 돌려준다)
- 핀 각 a = theta − 1.6 − 60° (t = 1 에서 −60° = 판화 자세). `wheel.rotation.z = a`.
- 크랭크 핀 P = (CX + 0.51·cos a, CY + 0.51·sin a).
- 블록 핀의 x: x(θ) = 0.51·cos a + √(1.74² − (0.51·sin a)²) → 블록 위치 (CX + x, CY). 범위 CX + 1.23 ~ CX + 2.25 = 0.15 ~ 1.17, 행정 1.02 = 크랭크 반지름의 2배.
- 연결봉: 위치 = P, `rod.rotation.z = rodAngle = atan2(−0.51·sin a, x − 0.51·cos a)`. 기울기 최대 ±17.0°.
- 시각: **t = 1.0 (a = −60°, 판화 자세, 블록 핀 x = 0.858)**, **t = 1.6 (a = −5°, 블록이 오른쪽 끝 근처 1.167)**, t = 2.96 (a = 120°), t = 3.45 (a = 165°, 왼쪽 끝 근처).

## 표시
- rotArrow: `rotArrow(0.33, true)` 를 바퀴 중심 (CX, CY) z = 0.32 에(반시계).
- tag 4개: '크랭크 바퀴(구동)' (−1.08, 2.8, 0.3), '크랭크 핀' (−1.6, 0.65, 0.3), '연결봉' (−0.15, 2.45, 0.35), '미끄럼 블록과 안내틀' (1.0, 2.3, 0.35).

## notes
① 크랭크 반지름 '0.51 → 행정 1.02(반지름의 2배)' ② 연결봉 '길이 1.74(크랭크의 3.4배), 기울기 최대 17°' ③ 블록 위치 '행정의 NN %'((x − 1.23)/1.02) ④ 바퀴 회전수.

## 확인
- t = 1 정면: 판화와 같은 모양(핀이 오른쪽 아래, 봉이 오른쪽 위로 올라가 블록에 닿음). t = 1.6 정면: 블록이 오른쪽 끝 근처.
- 근접 `cam=-0.6,2.3,1.6,-0.6,1.5,0.2`(크랭크 핀·봉 끝 고리), `cam=0.9,2.4,1.5,0.9,1.7,0.1`(블록·안내틀), 옆 `cam=3.5,1.7,0.2,0,1.7,0.1`(층 겹침: 바퀴 → 봉).
- 수치: `node shots/_verify/s092.mjs`(키트 식 그대로) → 블록 몸통 x −0.09 ~ 1.41 이 안내 홈 −0.11 ~ 1.89 안, 홈 밖으로 나감 0, 위아래 틈 0.003, 연결봉 길이 오차 0, 기울기 최대 17.04°. `node shots/_verify/s092b.mjs` 로 부품 메시 생성·상자 확인.
