# 203 굽은 홈 팔의 진동
원문: "A regular vibrating movement of the curved slotted arm gives a variable vibration to the straight arm." — 굽은 홈이 있는 팔의 규칙적인 진동(흔들림)이 곧은 팔에 변하는 진동을 준다. 쉬운 풀이: 굽은 홈 팔이 일정하게 흔들리면 홈 속 핀이 곧은 팔을 밀어, 곧은 팔이 흔들리는 속도가 고르지 않게 변한다.
판화 묘사(원본 499×436 px, [x·y]): 왼쪽 아래 축 [108·300](짙은 원 + 둥근 허브) 둘레에서 판이 왼쪽 위로 크게 휘어 올라가 위쪽에서 오른쪽으로 뻗은 갈고리(J·6자) 모양 팔. 판 속에 그 모양을 따라 긴 굽은 홈(아래 끝 [52·292] → 왼쪽 세로 x 48 → 둥글게 꺾여 → 위쪽 가로 y 160 → 오른쪽 끝 [190·158]). 오른쪽 축 [405·150](짙은 원 + 둥근 보스)에서 왼쪽으로 뻗은 곧은 팔, 그 왼쪽 끝은 굽은 팔 **뒤**에 숨어(점선) 끝의 핀 [143·157](두 겹 고리)이 위쪽 가로 홈에 들어 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 x = (px − 245)·0.0085, y = 1.75 + (225 − py)·0.0085.
1. 바퀴는? → 없음(바퀴·기어 없음). 회전하는 판 두 개: 굽은 홈 팔, 곧은 팔.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 곧은 팔의 왼쪽 끝이 굽은 팔의 위쪽 가로 부분 뒤를 지난다(점선 = 가려짐). 서로 다른 층.
4. 고정점은? → 굽은 팔 축 [108·300] = O1, 곧은 팔 축 [405·150] = O2. 둘 다 짙은 원(고정 축).
5. 추·손잡이·크랭크는? → 판화에 없음. 원문 "규칙적인 진동"을 주는 쪽 = 굽은 팔(구동). 보충: 굽은 팔 허브의 흔들 손잡이.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 홈의 위쪽 가로 부분·핀·곧은 팔 축이 거의 같은 높이(y 150~160 px). 홈의 왼쪽 세로 부분은 x 48 px 세로선. 핀은 곧은 팔이 그리는 원의 가장 왼쪽 점 근처.
8. 글자가 가리키는 부품은? → 글자 없음(번호 203 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 핀은 곧은 팔 끝에 고정되어 굽은 홈 안을 미끄러지고, 굽은 팔이 ±40° 흔들리는 동안 핀이 홈 끝에 닿지 않는다(아래 계산). 질문 거리 없음.

## 해석(결정 사항)
- **210 과 다른 점**: 210 은 굽은 홈 팔이 축과 함께 **계속 돌고** 홈 속 핀이 **세로 막대(안내 속 직선 운동)** 를 민다. 203 은 굽은 홈 팔이 **흔들리기만**(규칙적 사인 흔들림) 하고, 핀은 **고정 축 O2 를 도는 곧은 팔** 끝에 있어 출력도 **흔들림(각 운동)** 이다. 210 의 키트·모델을 쓰지 않는다.
- 변하는 속도의 까닭: 핀이 홈의 곧은 부분에 있을 때는 홈이 핀이 갈 길(세로)과 거의 직각이라 곧은 팔이 조금씩 밀리고(비 0.05~0.15), 홈의 굽은 부분으로 들어가면 홈이 기울어 크게 밀린다(비 0.27). 그 사이 θ1 ≈ −10° 근처에서 곧은 팔이 거의 멈춘다.
- 판화에 없는 보충: 흔들 손잡이(구동 표시), 뒤판의 흔적 점(속도 표시).

## 구동
굽은 팔 각 θ1(t) = −0.5236 + 0.6981·sin(0.8·(t − 1) + 0.8481) [rad] — 가운데 −30°, 진폭 40°, 주기 7.854 초. t = 1 에서 θ1 = 0(판화 자세). 반시계 양수. 곧은 팔 각 θ2 는 아래 동작의 풀이.

## 동작 (`pose203(theta1)` — 결정적)
- 홈 점의 세계 위치: q(u) = O1 + Rot(θ1)·(S(u) − O1).
- 핀 = 곧은 팔 원 위: |q(u) − O2| = LS = 2.2318 을 u ∈ [0, 2.0382] 에서 이분법 60 회로 푼다(이 범위에서 근은 하나 — θ1 ∈ [−70°, +10°] 확인). f(u) = |q(u) − O2| − LS.
- θ2 = atan2(q.y − O2.y, q.x − O2.x). 핀 세계 위치 = q(u) = O2 + LS·(cos θ2, sin θ2) — 두 식이 같아야 한다(같은 변수에서 그린다).

## ★ 눈에 보여야 할 동작
- 핵심: 굽은 팔은 고르게(사인) 흔들리는데 곧은 팔은 빠르기가 변한다 — 빨랐다가 거의 멈췄다가 다시 빨라짐.
- 장치: 흔적 점 두 줄(0.5 초 간격) — 흰 점(굽은 팔 끝)은 사인 간격으로 고르게 늘어서고, 노란 점(핀)은 거의 겹치는 곳(멈춤)과 듬성한 곳(빠름)이 뚜렷이 갈린다. 굽은 팔 위쪽 가로 부분 윗면에 노란 띠(길이 0.5), 곧은 팔 윗면 노란 띠(길이 1.0). 곧은 팔 화살표는 거의 멈출 때(|dθ2/dt| < 0.01 rad/s) 숨는다.
- 수치: 굽은 팔 진폭 ±40°, 주기 7.85 초(최대 각속도 0.56 rad/s). 곧은 팔 비 0.046 ~ 0.266(5.8배 차), 곧은 팔 진폭 15.1°, 핀 이동 0.58(노란 점 간격 0 근처 ~ 약 0.12).
