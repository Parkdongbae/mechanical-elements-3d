# 268 크랭크와 흔들막대
원문(en): "Circular into reciprocating motion by means of a crank and oscillating rod." — 크랭크와 흔들리는 막대로 원운동을 왕복 운동으로 바꾼다.
쉬운 풀이: 오른쪽 원판이 돌면 크랭크 핀이 원을 그리며 긴 막대의 오른쪽 끝을 끌고 다닌다. 막대는 왼쪽의 작은 도르래(받침 롤러) 위에 얹혀 미끄러지며 시소처럼 기울어지므로, 막대 왼쪽 끝이 오르내리고 앞뒤로 왕복한다. 도르래는 막대가 미끄러지는 대로 굴러 마찰을 줄인다.
판화 묘사(원본 448×427 px, **정면**): 오른쪽 큰 원판(중심 ≈ [382·220], 반지름 ≈ 57 px). 원판 앞에 크랭크 팔(중심 → 핀 [396·179], 길이 ≈ 42 px). 긴 막대(두께 ≈ 13 px)가 왼쪽 끝 [8·195] 에서 오른쪽 끝 크랭크 핀까지. 왼쪽 아래에 작은 도르래(중심 ≈ [94·225], 반지름 ≈ 26 px, 가운데 축 구멍 작은 원) — 막대 밑면이 도르래 꼭대기에 얹혀 있음(막대 밑 [95·201.7] ≈ 도르래 꼭대기 199). 점선: 크랭크가 아래로 간 자세(핀 ≈ [375·260])의 막대 — 도르래 꼭대기를 지나 왼쪽 끝이 위로 올라감([5·160~170]).

## ★ 판화 읽기
판화 하나(정면). 1 px ≈ 0.008, 세계 x = (px − 224)·0.008 + 0.10, y = 1.60 + (220 − py)·0.008.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 2개: 크랭크 원판(반지름 0.456) > 받침 도르래(홈 바닥 0.208, 테두리 0.24).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은? → 뒤판에서 나온 두 축: 원판 축 (1.36, 1.60), 도르래 축 (−0.94, 1.56). 도르래는 **자기 축에서 돌기만** 하고 자리는 고정(판화의 도르래 가운데 작은 원 = 고정 축).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 팔이 원판 앞면에 붙어 함께 돌고, 팔 끝 핀에 막대 오른쪽 끝 눈(구멍)이 꿰임. 막대 왼쪽은 도르래 위에 얹힐 뿐(무게로 눌림).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음. 막대 밑면이 도르래 홈(두 테두리 사이)에 얹혀 구른다.
7. 한 줄에 놓인 것은? → 원판 중심과 도르래 중심이 거의 같은 높이(1.60 / 1.56). 막대·크랭크 핀·도르래 홈이 같은 깊이(z 0.17~0.23).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 268 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) **카탈로그 쉬운 풀이는 "막대에 달린 작은 도르래"라고 했지만 판화의 도르래는 막대에 달리지 않았다** — 도르래는 자기 축 구멍(작은 원)을 가진 따로 선 바퀴이고, 실선·점선 두 자세 모두 막대 밑면이 도르래 꼭대기에 얹혀 있다. → 판화대로 **고정 축 도르래 위를 막대가 미끄러지며 흔들림**으로 정함(★질문 거리 1). (나) 막대가 크랭크 원판 앞을 지나므로 막대를 원판 축 너트보다 앞(z 0.17~0.23)에 둠. (다) 막대 무게중심(핀에서 1.55)이 핀과 도르래 접점(핀에서 1.95~2.62) 사이라 늘 도르래를 누름 — 떨어지지 않음. (라) 도르래 양옆에 테두리를 두어 막대가 옆으로 빠지지 않게 함(판화의 바퀴 테).

## 해석(결정 사항)
- 막대 중심선은 크랭크 핀 A 를 지나고, 도르래 중심 O 에서 ρ = 0.208 + 0.048 + 0.002 = **0.258** 떨어진 위쪽 접선(막대 밑면이 홈 바닥에 틈 0.002 로 닿음).
- 도르래는 막대에 대해 **미끄러지지 않고 구른다**: 도르래 각 θr = (ψ − ψ0) − (λ − λ0)/0.208. ψ = O 에서 막대로 내린 수선 방향 각, λ = 핀 A 에서 접점까지 막대를 따라 잰 거리(파이썬으로 미끄럼 속도 3×10⁻⁷ 확인).

## 구동
원판·크랭크 일정 회전: φ(t) = 71° + 60°·t(= 1.2392 + 1.0472·t rad, 반시계). 한 주기 6 초. t = 0 은 판화 실선 자세(핀이 중심 위 오른쪽 71°).

## 동작 (`state268(t)` — 결정적, 닫힌 식)
1. φ = 1.2392 + 1.0472·t. A = D + 0.336·(cos φ, sin φ).
2. v = O − A, d = |v|, σ = asin(0.258/d), β = atan2(v.y, v.x) − σ(핀에서 도르래 쪽으로 가는 막대 방향 각, 위쪽 접선).
3. 막대 `rotation.z = α = atan2(−sin β, −cos β)`(로컬 +x 가 핀 쪽), 위치 A.
4. λ = √(d² − 0.258²), 접점 C = A + λ·(cos β, sin β), ψ = atan2(C.y − O.y, C.x − O.x), θr = (ψ − ψ0) − (λ − λ0)/0.208(ψ0, λ0 = t = 0 값: 92.36°, 2.4221).
5. 막대 끝 = A + 3.10·(cos β, sin β).
6. 수치(파이썬 검산):
