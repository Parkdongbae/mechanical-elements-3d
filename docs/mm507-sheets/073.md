# 073 스프링 래칫 간헐 회전
원문: 구동 바퀴 D 에 굽은 스프링 B 가 고정되어 있고, 또 다른 스프링 C 는 고정된 받침에 붙어 있다. D 가 돌면 스프링 B 가 **센 스프링 C 밑으로 지나가고**, C 가 B 를 래칫 바퀴 A 의 이 속으로 **눌러** A 를 돌린다. 걸쇠 스프링 B 가 C 에서 **빠져나오면 풀려서**, D 가 한 바퀴 더 돌 때까지 A 는 쉰다. 스프링 C 는 **정지구(되돌림 막이)** 구실도 한다.

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/073-fig-x4.png`, 바퀴 부분 `073-zoom.png`.
1. 바퀴는 몇 개이고 크기 차례는? → 2개, **같은 축**. 큰 원판 D(4배 확대에서 반지름 545)와 그 앞 가운데의 래칫 바퀴 A(이끝 반지름 약 355, 이뿌리 약 280). 가운데 두 겹 원 = 축과 허브.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. (스프링 C 가 D 의 둘레를 가로질러 들어오고, 판스프링 B 와 C 는 D 가 돌 때 서로 겹쳐 지나간다 — C 가 앞.)
4. 고정점은? → 왼쪽 아래의 빗금 친 받침. 스프링 C 가 그 오른쪽 면을 따라 세로로 붙어 올라온다.
5. 추·손잡이·크랭크는? → 없음. 구동은 D(원문). D 아래쪽의 화살표가 왼쪽을 향함 = D **시계**.
6. 이는 어디에 났고 무엇이 물리는가? → A 둘레에 톱니 **10개**(이끝의 각 107°, 73°, 33°, −4°, −38°, −72°, −108°, −140°, 180°, 144° — 간격 약 36°). 이마다 **반시계 쪽이 반지름 방향의 곧은 절벽**, 시계 쪽이 긴 등. 물리는 것은 둘: ① 스프링 **C 의 끝**이 왼쪽 위(148°, 반지름 319 — 이끝 원 안쪽)에서 이의 절벽을 뒤에서 받친다(A 가 반시계로 되돌지 못함) ② 스프링 **B**: D 의 면 위, 둘레 가까이(반지름 약 495)를 따라 굽은 띠. 오른쪽 끝(6°)은 넓적하게 덧대어 D 에 고정됐고, 위쪽 끝(95°)에는 안쪽으로 내린 **ㄷ 자 걸쇠 머리**(반지름 400 ~ 490)가 달렸다 — 자유 끝. D 가 시계로 돌면 고정 끝이 앞서고 걸쇠 머리가 뒤따른다. 걸쇠 머리 아랫끝(400)은 이끝(355)보다 바깥 → **그대로는 이에 닿지 않는다**, C 가 안으로 눌러야 닿는다.
7. 한 줄에 놓인 것은? → D 와 A 의 중심이 같다(동심). 받침의 오른쪽 면과 C 의 뿌리가 한 세로선.
8. 글자가 가리키는 부품은? → A = 래칫 바퀴, B = 굽은(걸쇠) 스프링, C = 센 스프링, D = 구동 원판(글자는 원판 아래쪽).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 원문과 같다, 질문 없음. 다만 판화의 C 는 치수가 대강이다: C 가 D 안으로 들어와 끝까지 가는 구간이 49° 뿐이라 걸쇠가 눌려 이끝 아래로 내려가는 것이 C 끝의 약 30° 앞 — 한 이(36°)보다 짧아 그대로면 걸쇠가 '이미 지나간 이'의 등에만 얹혀 A 를 밀지 못한다. 그래서 C 를 길고 완만하게 고쳤다(아래 해석).
- 그 밖의 선: B 의 고정 끝 쪽 겹선 = 덧댄 판, B 가운데의 살짝 벌어진 가는 선 = 띠의 두께, 걸쇠 머리의 ㄷ 자와 둥근 고리 = 띠 끝을 말아 걸쇠 판을 붙인 모양. 왼쪽 세로선·아래 가로선 = 판 테두리.

## 해석(결정 사항)
- **B 의 어느 끝이 고정인가**: 오른쪽 끝(덧댄 판)이 고정, 위쪽의 걸쇠 머리가 자유 끝(뒤따르는 끝)으로 읽었다 — 머리가 안쪽으로 내려와 있고(걸쇠), 오른쪽 끝은 둘레에 붙어 있어서다. 걸쇠의 **앞면(시계 쪽 면)**이 이의 절벽을 뒤에서 밀어 A 를 D 와 함께 시계로 끈다.
- **층**(C 가 B 의 띠와 겹쳐 지나가려면 깊이가 달라야 한다 — 원문 'B 가 C 밑으로 지나간다'): 원판 D z 0 ~ 0.05 / B 의 띠 0.05 ~ 0.11(D 면에 붙어 C 밑을 지난다) / 래칫 A·센 스프링 C 0.12 ~ 0.20 / 걸쇠 머리 0.05 ~ 0.20(두 층에 걸쳐 서 있어 C 에 눌리고 A 의 이에 걸린다).
- **한 바퀴의 일**: 걸쇠 머리 꼭대기가 C 의 안쪽 가장자리에 닿음(C 끝의 56° 앞) → C 를 따라 안으로 눌려 내려감(47° 앞에서 이끝 아래로) → 31.4° 앞에서 쉬던 이의 절벽을 만나 **밀기 시작** → 이 바닥에 앉은 채 A 를 끌고 감, 이때부터는 C 가 걸쇠 등에 얹혀 **바깥으로 휜다**(끝이 최대 0.13 들림, 받침 쪽 뿌리 둘레로 4.7°) → C 끝을 4.5° 지나면 걸쇠가 C 에서 벗어나 튕겨 나오고(풀림) A 는 선다. A 의 전진은 정확히 **36°(한 이)**, 그동안 D 는 35.9° — 거의 1 : 1.
- **C 의 모양을 고친 것**: 끝을 148° → **120°** 로 옮기고(받침은 판화 자리 그대로), 안쪽 가장자리 반지름을 r(u) = 0.66 + 0.00155·u + 0.000065·u² (u = 끝에서 반시계로 잰 각, 0 ~ 70°)로 완만하게 했다. 걸쇠가 이끝 아래로 내려가는 곳이 '쉬는 절벽(31.4° 앞)과 그 뒤의 절벽(67.4° 앞) 사이'에 있어야 한 바퀴에 꼭 한 이를 민다.
- **C 의 정지구 구실**: 쉴 때 C 끝(반지름 0.66)은 이끝 원(0.69) 안쪽, 절벽 바로 뒤(4.6° 뒤)에 있다 → A 가 반시계로 4.6° 넘게 되돌 수 없다. A 가 끌려갈 때는 이의 등과 걸쇠가 C 끝을 들어 올리며 지나간다.
- 이 높이 0.13(판화 약 0.15), 이의 등은 곧은 비례(판화는 살짝 오목). 걸쇠 머리는 폭 0.05·높이 0.21 의 판(꼭대기 둥글게) — 판화의 ㄷ 자·고리는 줄였다.
- 치수를 바꾸면 `node shots/_verify/s071bake.mjs --write` 로 표를 다시 굽고 `s073.mjs` 로 침범을 본다(걸쇠·C·래칫 세 윤곽을 서로 뚫지 않게 차례로 푼 표).

## 구동
D(시계) theta += OMEGA(1.6)·speed·dt. A 는 D 한 바퀴(3.93 s)에 한 이(36°)만 시계로 돌고(0.39 s 동안) 나머지 때는 쉰다. 평균 속도비 D : A = 10 : 1.

## 부품과 치수 (키트 `kit/k071.ts`, 이미 구현됨. 값은 `K73` 상수. 바퀴 중심 O = (0.3, 1.9), 키트 그룹은 모두 z = 0 에 둔다)
- D(name `discD`): `driveDisc73()` 위치 (0.3, 1.9, 0). 원판 반지름 1.05, z 0 ~ 0.05. 판스프링 고정 블록(D 로컬 각 93.7° ~ 101.7°, 반지름 0.90 ~ 1.00, z 0.046 ~ 0.11), 둘레 표시 4개. 청동색(구동).
- B(스프링 + 걸쇠): `new CatchSpring73()` — `group` 을 **D 의 자식**으로 넣는다(D 와 함께 돈다). 띠: 반지름 0.95(두께 0.022), D 로컬 각 98.67°(고정) → 188.17°(걸쇠), z 0.05 ~ 0.11. 걸쇠 머리(`head`, name `catchHead`): 앞면이 D 로컬 각 186.67°, 폭 0.05, 높이 0.21, z 0.05 ~ 0.20. 풀렸을 때 아랫면 반지름 0.75(꼭대기 0.96), 이에 걸렸을 때 0.5638. `set(headR)` 로 자유 끝 반지름을 준다.

## 동작 (theta = 누적 각)
- `discD.rotation.z = −theta`. 걸쇠 앞면의 세계 각 = 186.67° − theta(도).
- 한 순간의 상태 s = `ratchet73State(theta(도))`: `ratchetA.rotation.z = s.aRot`, `catch.set(s.headR)`, `springC.rotation.z = s.bladeRot`. (`s.advDeg` = A 의 누적 전진, `s.pushing` = 미는 중, `s.u` = 걸쇠 앞면이 C 끝에서 떨어진 각.)
- u(도) = 180 − ((theta(도) + 113.33) mod 360). 표는 u 64° → −10°(0.5° 간격 149칸) 세 개: A 전진 `ADV73`, 걸쇠 아랫면 반지름 `RB73`, C 의 휨 `PSI73`. 그 밖의 u 에서는 전진 0 또는 36, 반지름 0.75, 휨 0. 쉬는 절벽 면의 세계 각 = 120° − 4.62° + 36°·k (`ratchet73Eps()` = 4.62).
- 주기 시간표(D 한 바퀴 = 3.93 s, theta 를 360° 로 접은 값): 0° ~ 10.7° 걸쇠 풀림·A 쉼 → **10.7°(u 56) 걸쇠가 C 에 닿아 눌리기 시작** → **35.3° ~ 71.1°(u 31.4 → −4.5) 밀기**: A 가 36° 전진(u 24 에서 7.5°, 12 에서 19.5°, 0 에서 31.5°), C 는 u 3 에서 가장 많이(4.72°) 휜다 → 72.7°(u −6) 걸쇠가 튕겨 나옴, C 끝이 절벽 뒤로 내려앉음 → 72.7° ~ 360° 쉼.
- 시각: t = 0.3 (u 39, 걸쇠가 눌려 이끝 아래로 내려온 때), **t = 0.55 (u 16.2, 밀기 한가운데 — A 15.3° 전진, C 3.1° 휨)**, t = 0.75 (u −2.1, 풀리기 직전), **t = 1.0 (u −25 — 판화 자세: 걸쇠가 위쪽(세계 95°)에 풀려 있고 C 끝이 이 사이에 놓임)**.

사용자에게 물을 질문: 없음. (보류 아님 — 원문이 동작을 차례대로 적었다. 참고: B 의 고정 끝을 오른쪽으로 읽은 것, C 를 길게 고친 것은 위 '해석'에 적은 대로 설계자의 판단이다. 눈 검증에서 판화와의 차이로 지적되면 그때 묻는다.)
