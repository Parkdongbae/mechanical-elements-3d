# 164 무릎 지레
원문: "A knee-lever, differing slightly from the toggle-joint shown in 40. It is often used for presses and stamps, as a great force can be obtained by it. The action is by raising or lowering the horizontal lever." — 40번 토글 이음과 조금 다른 무릎 지레. 프레스·스탬프에 쓰며 큰 힘을 얻는다. 수평 팔을 올리고 내려서 움직인다.

판화 묘사: 위에 빗금 천장, 그 아래 짧은 지게대의 핀(위 작은 원)에 무릎 지레가 걸려 있다. 지레는 한 몸으로 위 눈 — 아래로 조금 왼쪽에 둔 무릎 핀(두 번째 작은 원) — 오른쪽으로 뻗어 조금 내려가는 긴 수평 팔(끝 둥긂). 무릎 핀에 방추형(가운데 위쪽이 굵은) 긴 봉이 걸려 아래로 내려가 바닥 위 작은 네모 블록에 얹힌다. 아래는 빗금 바닥.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 없음. 핀(돌쩌귀)만 둘: 위 핀 A(지게대), 아래 핀 B(무릎).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 겹침: 봉 위 끝이 지레 무릎 뒤로 들어간다(지레 허브가 앞) — 모델은 봉을 지레 앞 층에 두고 핀 B 가 둘을 꿴다.
4. 고정점(천장·벽·바닥)은 어디인가? → 천장(지게대·핀 A), 바닥(블록 아래 빗금).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 손잡이 = 수평 팔의 둥근 끝(손으로 올리고 내림). 추·크랭크 없음.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 핀 A·핀 B·봉·블록이 거의 한 세로선(핀 B 가 A 보다 조금 왼쪽, 봉 아래 끝이 블록 가운데).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음. 설계표에서 위 핀 = A, 무릎 핀 = B, 봉 아래 핀 = P 로 부른다.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 판화대로면 블록이 바닥에 고정이고 봉 아래 끝이 블록에 얹혀만 있어, 팔을 움직이면 봉이 블록 위에서 미끄러지거나 뜬다. 프레스로 동작하게 **블록을 세로 안내 사이를 미끄러지는 누름 블록(램)** 으로, 봉 아래 끝을 램의 핀 P 에 건다(판화에 없는 보충: 안내 볼 둘·모루 판). 해석으로 정했으므로 사용자에게 물을 것은 없다.

## 해석(결정 사항)
- 판화 비: 목(A→B) 0.52, 팔 1.98, 봉 ≈1.80. 판화 자세(팔 6° 내려감, 목 18° 왼쪽)를 t = 1 로.
- 팔을 올리면(지레 반시계) B 가 아래로 돌아 거의 일직선(무릎 각 → 180°)이 되며 램이 내려가 모루를 누른다. 팔을 내리면 램이 들린다.
- 구동은 사람 손 → theta 로 지레 각을 사인 왕복시킨다.

## 구동
theta += OMEGA(1.6)·speed·dt. 지레 각 u = 12°·sin(theta − 1.6). 한 주기 3.93 s 에 한 번 누르고 한 번 들림.

## 동작 (모두 theta 의 닫힌 식 — `pose164(theta)`)
- u = 12°·sin(theta − 1.6); B = A + 0.52·(cos(−108°+u), sin(−108°+u)).
- 핀 P: x = −0.41, y = B.y − √(L² − (−0.41 − B.x)²). 봉 rotation.z = atan2(−0.41 − B.x, B.y − P.y).
- 램 바닥 = P.y − 0.26: u = +12° 에서 0.262(모루 위 0.002 — 누름), u = −12° 에서 0.328. 행정 0.066.
- t = 1: u = 0 (판화 자세, 램 0.03 들림), t = 1.6: u = +9.9° 쯤(거의 누름), t = 3: u ≈ −7.7°.
