# 084 엔진 조속기용 이중 랙 틀
판화(public/mm507/fig/084.png, 4배 확대 shots/_verify/084-fig-x4.png 로 다시 읽음): 그림 하나(정면). 가로로 긴 타원꼴 틀 B — 창의 **윗변에는 아래로 난 톱니, 아랫변에는 위로 난 톱니**(각각 9개쯤)가 있고, 틀 양 끝에서 가로 막대가 뻗어 좌우의 안내 블록(빗금 친 위·아래 턱 사이의 세로로 넉넉한 틈)을 지난다. 틀 위에는 가로 긴 구멍 두 개가 난 막대가 붙어 있고, 위에서 내려온 막대 A 가 반원 멍에로 갈라져 두 끝의 핀이 그 구멍에 걸려 있다. 창 한가운데에 축이 있고, 축 허브에서 **위로 솟은 손가락 하나**(글자 D 바로 옆)가 윗랙 이 사이에 닿아 있다. 틀 뒤로는 살 4개짜리 큰 바퀴(테가 창 좌우와 틀 아래로 보임)가 같은 축에 있다.
원문 요지: 이중 랙 틀 B 는 막대 A 에 매달려 있다. 캠 D 는 계속 돈다. 캠 축이 두 랙의 한가운데 있으면 캠은 어느 랙에도 닿지 않는다. 막대 A 를 올리거나 내리면 아래 또는 위 랙이 캠이 닿는 범위로 들어와 틀이 왼쪽이나 오른쪽으로 움직인다. 막대 A 는 조속기에, 틀은 스로틀 밸브에 이어 썼다.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 큰 바퀴 하나(살 4개, 반지름 ≈ 창 반높이의 2.2배, 틀 **뒤**). 그 축 앞쪽에 손가락 하나짜리 캠 D(끝까지의 길이 ≈ 큰 바퀴 반지름의 0.47배).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음(큰 바퀴에 걸릴 벨트는 그려지지 않았다. 만들지 않는다).
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 좌우 안내 블록(빗금 = 고정된 몸의 단면) 둘, 캠 축. 막대 A 의 위쪽은 끊겨 있다(조속기로 감).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 틀은 막대 A 의 멍에 핀 둘에 매달려 있다(핀이 틀 윗막대의 가로 긴 구멍에 걸림 — 틀은 핀에 대해 좌우로 미끄러질 수 있다).
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 틀 창의 **안쪽** 위·아래 가장자리에 랙 이(서로 마주 봄). 캠 D 의 손가락이 안에서 위 또는 아래 랙의 이를 한 번에 하나씩 민다. 판화의 순간은 손가락이 위를 향해 윗랙 이 사이에 든 때.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 캠 축 — 틀 좌우 막대 — 두 안내 블록의 틈이 한 가로선. 막대 A — 멍에 가운데 — 캠 축이 한 세로선.
8. 판화의 글자가 가리키는 부품은? → A = 위의 막대(멍에), B = 랙 틀(창 왼쪽에 글자), D = 캠(허브 위 손가락 옆). 원문 글자와 같다.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 다만 원문은 캠의 생김새를 말하지 않고 판화는 작다 — 허브 위의 손가락 하나를 캠 D 로 읽었다(큰 살 바퀴는 반지름이 랙 간격보다 커서 틀과 같은 평면일 수 없다 → 캠 축을 돌리는 뒤쪽 바퀴).
- 그 밖의 선: 틀 아래로 내려간 세로 가는 선 둘 = 판화로는 알 수 없음(캠 축 받침의 모서리로 보이나 만들지 않는다). 큰 바퀴 가로 살의 굽은 윤곽 = 주물 살. 축 둘레 겹 원 = 허브. 안내 블록 아래의 굽은 선 = 받침대 몸.

## 해석(결정 사항)
- 캠 D = **한 손가락 캠**. 한 바퀴에 한 번 랙 쪽을 지나며, 물린 랙의 이 하나를 한 피치(0.2)만큼 민다. 다 밀린 이는 언제나 같은 자리(캠 축에서 x = ∓0.1575)에 남으므로 다음 바퀴에는 그다음 이가 밀린다 → 한 바퀴에 정확히 한 피치.
- 캠은 반시계: 손가락이 **위**를 지날 때는 왼쪽으로 간다 → 틀이 내려와 윗랙이 물리면 **왼쪽**으로. 손가락이 **아래**를 지날 때는 오른쪽으로 → 틀이 올라가 아랫랙이 물리면 **오른쪽**으로. 원문과 같다.
- 랙 이는 미는 쪽이 곧은 톱니꼴(윗랙은 곧은 면이 오른쪽, 아랫랙은 왼쪽 — 아랫랙은 윗랙을 180° 돌린 것). 중립에서 이끝과 손가락 끝의 틈 0.03, 물리면 0.04 겹친다(막대 A 의 오르내림 ±0.07).
- 시연 시간표는 조속기를 흉내 낸 것이다(판화에 없음): 내림(왼쪽 두 피치) → 중립 → 올림(오른쪽 두 피치) → 중립.

## 구동
캠 축(큰 바퀴와 한 몸, 반시계). theta += OMEGA(1.6)·speed·dt, 캠 각 α = thetaE = theta + 0.15. 한 주기 = 캠 6바퀴(12π rad = 23.56 s).

## 동작 (모두 thetaE 의 함수 — `k84State(thetaE)` 가 { x, y, alpha, mode } 를 돌려준다)
- r = (thetaE / 2π) mod 6 (캠 바퀴 수). 캠·큰 바퀴 `rotation.z = alpha = thetaE`.
- 세로 y(막대 A·틀이 같이): r 0 ~ 1.45 → −0.07(내림) / 1.45 ~ 1.55 → 0 으로 / 1.55 ~ 2.45 중립 / 2.45 ~ 2.55 → +0.07 / 2.55 ~ 4.45 올림 / 4.45 ~ 4.55 → 0 / 4.55 ~ 5.45 중립 / 5.45 ~ 5.55 → −0.07 / 5.55 ~ 6 내림. 옮기는 구간은 손가락이 옆(0° 또는 180°)을 가리킬 때라 랙에 닿지 않는다. 보간은 x²(3 − 2x).
- 가로 x = 0.2 − (왼쪽으로 민 거리) + (오른쪽으로 민 거리). 왼쪽 밀기는 r 0 ~ 0.5 와 1 ~ 1.5 의 위 반 바퀴, 오른쪽 밀기는 r 2.5 ~ 3 과 3.5 ~ 4 의 아래 반 바퀴. 한 번에 0 → 0.2: 손가락이 78° ~ 118.5°(아래에서는 258° ~ 298.5°)를 지나는 동안만 움직인다(표 721점 보간 — 손가락 윤곽이 이의 곧은 면을 민 자리).
- 틀 자리 차례: +0.2 → 0 → −0.2(왼쪽 두 번) → 중립으로 쉼 → 0 → +0.2(오른쪽 두 번) → 쉼. 한 주기에 정확히 제자리(누적 오차 없음).
- 중립(r 1.55 ~ 2.45, 4.55 ~ 5.45): 손가락이 위·아래를 다 지나도 닿지 않는다(틈 0.03).
- 시각: **t = 1 (thetaE 1.75 = 100°)** 내림, 손가락이 윗랙 이를 미는 중(판화 자세, x ≈ 0.09). **t = 1.6 (155°)** 첫 밀기 끝, x = 0. t = 8 (thetaE 12.95, r 2.06) 중립. t = 11.5 (r 2.95) 올림, 아랫랙을 오른쪽으로 민 직후.
