# 029 원판 나선 기어
판화: 정면에서 본 **큰 원판**(바깥 테두리 + 가운데 허브 + 축 단면). 원판 면 위에 **나선형 능선(홈 줄) 한 줄**이 약 한 바퀴 감겨 있다(위쪽에서 시작해 반시계로 돌며 반지름이 조금씩 줄어 한 바퀴 뒤 출발점 안쪽에서 끝). 원판 오른쪽에는 **작은 평기어**가 옆으로 서 있다 — 판화에서는 가로로 넓은 톱니 띠(평기어를 옆에서 본 모습)이고, 기어의 **축은 세로(수직) 막대**로 원판 위를 가로지른다. 기어의 톱니가 나선 능선에 걸린다. 원문: 한 축에서 직각 축으로 회전을 전달하고, 원판이 한 바퀴 돌 때마다 평기어를 톱니 한 개 거리만큼 움직인다.
해석(한 줄): 한 줄 나선 능선이 **랙**(톱니 하나짜리 홈 간격 = 평기어 피치)처럼 평기어 톱니 사이에 들어가 밀어 주는 스크롤 기어. 능선이 평기어 접촉선을 훑고 지나가는 동안 기어가 연속으로 돌고, 한 바퀴가 끝나는 순간 능선 끝에서 다음 줄 시작점으로 바뀌는데 그 위치가 정확히 한 피치 어긋나 있어 평기어는 끊김 없이 이어서 돈다.
구동: 원판(축 Z). 평기어(축 Y)가 종동.

## 부품과 치수
- `displayStand()`
- 원판 중심 **D = (Dx, Yd) = (−0.35, 1.75)**, 앞면 z = **0.10**, 반지름 R = **0.62**.
  - `scrollDisc(0.62, 0.5257, 0.0942, { driver: true })` (키트 추가). 그룹 위치 (−0.35, 1.75, 0.10)(로컬 z = 0 이 앞면, 판은 z 0.04 ~ 0.10). `shaftZ(−0.35, 1.75, 0.28, 0.045)`가 허브 구멍(0.05)을 지난다.
- 평기어: `spurGear(16, 0.03, { width: 0.10, spokes: 4 })` — 피치 반지름 rg = 0.24, 피치 π·m = 0.0942, 이끝 반지름 0.27.
  - 기어 축은 **세로(Y 방향)**, x = **Gx = Dx + 0.455 = 0.105**, z = **Zg = 0.3775**(= 앞면 0.10 + 랙 피치선 높이 1.25m(0.0375) + rg 0.24). 중심 높이 y = Yd = 1.75. 이끝 맨 아래 z = 0.1075 (원판 앞면 위 0.0075), 맨 위 0.6475 (전시 영역 안, 받침 z ±0.8 위).
  - 피벗 그룹 `gear` 위치 (0.105, 1.75, 0.3775), 자식 `gearMesh` 의 `rotation.x = −π/2`(로컬 Z → 세계 +Y, 로컬 x → 세계 +X, 로컬 y → 세계 −Z).
  - 기어 축 막대: `rod(V3(0, −0.66, 0), V3(0, 0.66, 0), 0.03)` 를 **gear 피벗의 자식**으로(세계 y 1.09 ~ 2.41). 표시 깃: `BoxGeometry(0.1, 0.02, 0.02)` paint(0xf2b619) 를 로컬 (0.06, 0.60, 0) 에.
  - 브래킷 2개(뒤판에서 나온 팔 + 고리): y = **Yd + 0.58 = 2.33** 과 **Yd − 0.58 = 1.17** 에 각각 `BoxGeometry(0.10, 0.07, 0.4125)` castIron 중심 (0.105, y, −0.09375)(z −0.30 ~ 0.1125), 고리 `lathe(tubeProfile(0.03, 0.055, −0.05, 0.05, 0.008), 36)` darkSteel 중심 (0.105, y, 0.3775) 축 = Y(뒤쪽 팔 끝은 z 0.1125 에서 끝나고 고리까지는 얇은 연결 막대 `rod(V3(0.105, y, 0.10), V3(0.105, y, 0.3775), 0.025)` 로 이음). 팔은 원판 밖(원판 중심에서 거리 > 0.62)에 있다.
- 접촉 위치: 능선이 기어 이 사이로 들어가는 곳 = 원판 중심에서 오른쪽(+X)으로 0.455 떨어진 점(θ = 0 에서). 나선 반지름 범위 0.4314 ~ 0.5257(한 피치 0.0942 차이).

## 키트 추가 (gear.ts 끝에 덧붙임)
```ts
export interface ScrollDiscOpts {
  thickness?: number;   // 판 두께(기본 0.06)
  ridgeH?: number;      // 능선 높이(기본 0.716·pitch)
  ridgeBase?: number;   // 능선 밑 너비(기본 0.50·pitch)
  ridgeTop?: number;    // 능선 위 너비(기본 0.26·pitch)
  turns?: number;       // 감긴 횟수(기본 1)
  start?: number;       // 능선 시작 각 β0 (기본 π/2 = 판 위쪽)
  bore?: number;        // 축 구멍 반지름(기본 0.05)
  driver?: boolean;     // bronze / brass
}
/** 나선 능선이 있는 원판. 로컬 Z = 회전축, 앞면 z = 0(판 z ∈ [−thickness, 0]), 능선은 z ∈ [0, ridgeH]. 원점 = 회전축 */
export function scrollDisc(R: number, rStart: number, pitch: number, opts?: ScrollDiscOpts): THREE.Group;
```
- **나선(능선 중심선)**: β ∈ [β0, β0 + 2π·turns], `r(β) = rStart − pitch·(β − β0) / (2π)` (반시계로 갈수록 반지름 감소). 점 (r cos β, r sin β). (0.62, 0.5257, 0.0942 → 시작 반지름 0.5257, 끝 0.4314.)
- 능선 몸통: β 를 `160 × turns` 구간으로 나눈 단면 위치 i = 0..n. 각 단면에서 u = (cos β, sin β), 점 4개:
  a = (r − base/2)·u, z = 0 − 0.002 · b = (r − top/2)·u, z = ridgeH · c = (r + top/2)·u, z = ridgeH · d = (r + base/2)·u, z = −0.002 (base = ridgeBase, top = ridgeTop).
  t = (−sin β, cos β)(진행 방향). 사각형(바깥을 향하는 감는 순서, 검산 완료) — 구간 i→i+1: 안쪽 옆면 (a_i, b_i, b_{i+1}, a_{i+1}), 윗면 (b_i, c_i, c_{i+1}, b_{i+1}), 바깥 옆면 (c_i, d_i, d_{i+1}, c_{i+1}); 시작 마개(i = 0) (a_0, d_0, c_0, b_0); 끝 마개(i = n) (a_n, b_n, c_n, d_n). 각 사각형 (p0,p1,p2,p3) → 삼각형 (p0,p1,p2), (p0,p2,p3). 하나의 비인덱스 `BufferGeometry` 에 모아 `computeVertexNormals()`.
- 판: `lathe(tubeProfile(bore, R, −thickness, 0.002, 0.008), 72)` rotateX(π/2). 앞 허브 보스: `lathe(tubeProfile(bore, bore + 0.05, 0, 0.03, 0.006), 32)` darkSteel rotateX(π/2). 뒤 허브: `lathe(tubeProfile(bore, bore + 0.05, −thickness − 0.03, −thickness, 0.006), 32)` darkSteel rotateX(π/2).
- 재질: 능선·판 모두 driver ? bronze({ roughness: 0.34 }) : brass().
- 랙 단면 근거: 평기어 모듈 m 일 때 pitch = π·m, ridgeH = 2.25m, 피치선 높이 1.25m(앞면 위), 밑 너비 0.5 피치 / 윗 너비 0.26 피치 — 평기어 이 사이 홈(피치원에서 약 0.5 피치)에 여유 있게 들어간다.

## 동작 (theta += OMEGA × speed × dt, OMEGA = 1.6, 원판 구동)
- 원판: `disc.rotation.z = θ` (정면에서 반시계).
- 평기어: **`gear.rotation.y = π/2 − θ/16`**. (α_g = π/2 − θ/Nz, Nz = 16. 원판 1 회전 → 기어 1/16 회전 = 톱니 1 개, 부호 음 = +Y 둘레 시계 방향.)
- 근거: 접촉선(y = Yd, 기어 맨 아래점, 세계 (Gx, Yd, 피치선 높이))에서 능선 중심의 x 위치는 `x(θ) = Gx + (pitch/2π)·θ` (0 ≤ θ < 3π/2; θ = 3π/2 에서 능선 끝이 지나가고 다음 능선 시작이 정확히 한 피치 안쪽(−pitch)에서 이어 받는다 — 그 순간 전후에 두 능선 끝이 기어 폭 안에 같이 보임). 기어가 +Y 둘레로 α 돌면 맨 아래 접촉점은 −X 로 rg·dα 움직이므로, 접촉점이 +X 로 가려면 α 가 줄어야 하고 rg·|dα| = (pitch/2π)·dθ → |dα| = dθ/16 (pitch = π·m, rg = 8m).
  위상: 기어 로컬 각 0 은 spurGear 의 **이골**(이 가운데는 반 피치 뒤). 세계에서 기어 중심 → 접촉점 방향은 −Z 이고, 이것을 로컬 각으로 재면 `pinMesh` 의 `rotation.x = −π/2` 때문에 +X 에서 −Z 쪽으로 재는 각 π/2 에 해당한다. `gear.rotation.y = α` 일 때 로컬 각 0 의 이골은 그 각 α 에 와 있으므로 θ = 0 에서 α = π/2 이면 이골이 접촉점에 있고, 그때 능선 중심 x = Gx 라서 능선이 이골 한가운데에 있다. 이후 θ 가 늘어도 이골(x = Gx + rg·θ/16 = Gx + pitch·θ/2π)과 능선이 계속 같은 위치(검산: 이골 위치 x = Gx + rg·cos(α) = Gx + rg·sin(θ/16)).
- 기어 축·깃은 기어 피벗의 자식이라 같이 돈다.
- 모든 자세는 θ 의 절대 함수.

- tag '원판(나선 능선)' (−0.9, 1.2, 0.3), '평기어(축은 세로)' (0.95, 2.1, 0.55), '능선이 톱니를 한 개씩 민다' (0.1, 2.55, 0.4).

## 확인
- 정면 t = 0, 1.0, 2.0, 3.0: 원판의 나선 끝(위쪽 두 줄 끝)이 반시계로 이동하고, 능선이 오른쪽 기어 접촉선을 바깥쪽으로 지나가며(반지름 늘어남) 평기어 깃은 천천히(원판의 1/16) 돈다. t ≈ 2.95 s(θ = 3π/2 = 4.71 rad) 전후로 능선 끝이 기어 폭을 지나 다음 줄이 이어받는다 — 그 전후 두 장에서 기어 깃 각도는 연속이다.
- 비스듬한 기본 시점: 능선이 평기어 이 사이 홈 가운데에 있고 이와 능선이 박히지 않는다(이끝과 원판 앞면 사이 0.0075, 능선 윗면과 기어 이뿌리 사이 틈). 평기어 이 하나가 능선을 따라 한 번에 한 개씩 지나간다.
- 기어 축 막대·브래킷이 원판·능선에 닿지 않는다. 전체 z ≤ 0.65, 뒤판과 안 겹침.
- 불확실: 판화 능선이 한 바퀴 남짓이라 turns = 1 로 했고, 기어가 연속 회전하는 것으로 해석했다(능선이 끊기는 지점은 시작 마개·끝 마개로 보인다).
