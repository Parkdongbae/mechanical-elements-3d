# 016 스페인 바턴 (1)
판화: 천장 들보에 걸이 2개(왼쪽 작은 고리, 오른쪽 갈고리). 오른쪽 갈고리에 위 도르래 A 가 매달리고, A 의 오른쪽 줄 끝에 오른쪽 아래 도르래 B 가 매달린다. A 의 왼쪽 줄 끝에는 맨 아래 도르래 M 이 매달리고, M 에 추(위가 좁은 통)가 걸린다. 왼쪽 고리에서 내려온 줄은 M 의 왼쪽을 지나 M 밑을 돌아 올라가 B 를 넘어 오른쪽으로 늘어진다(자유 끝, 손으로 당기는 곳). 원문: 16·17 은 '스페인 바턴'. 이득은 3~4배.
구동: 오른쪽 줄 끝(자유 끝)을 아래로 당긴다 → 추가 오른다. 이 운동에서 theta 는 "당김 주기의 위상"이다.

읽기(한 줄): 판화의 줄 연결은 A 위로 걸친 줄 Y(M 과 B 를 서로 매닮)와 들보 고리 → M 밑 → B 위 → 자유 끝으로 이어지는 줄 X, 둘로 읽는다. 이 읽기에서 이득은 정확히 4배다. 줄은 모두 수직으로 그린다(판화의 미세한 기울기는 무시).

## 부품과 치수
모든 도르래 반지름 r = 0.2, 두께 0.07, 중심 z = 0.22, 회전축 Z. 줄 반지름 0.014, 줄 z = 0.22.
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [-0.4, 0.0])` → 걸이 고리 아랫점 (−0.4, 2.94, 0.22), (0.0, 2.94, 0.22).
- 위 도르래 A: `pulleyBlock(0.2, { hookUp: 0.06 })`, 중심 (0, 2.55). 윗 눈 (0, 2.81) 과 걸이 고리 (0, 2.94) 를 `rod` 로 잇는다.
- 움직도르래 M: `pulleyBlock(0.2, { hookUp: 0.06, hookDown: 0.06 })`, 중심 (−0.2, yM).
- 움직도르래 B: `pulleyBlock(0.2, { hookUp: 0.06 })`, 중심 (+0.2, yB).
- 추: `weight(0.44, 0.30)`(원점 = 상자 중심), 중심 (−0.2, yM − 0.51). M 의 아랫 눈 (−0.2, yM − 0.26) 에서 추 윗면 (−0.2, yM − 0.36) 까지 `rod`(반지름 0.008).
- 줄 X, 줄 Y: `Rope` 각 1개. 줄 끝 X 의 자유 끝에 `ropeEnd()`(손잡이 구) 를 달아 줄 끝점에 둔다.
- 주철 표시: 도르래 중심마다 `shaftZ` 는 쓰지 않는다(공중에 매달린 도르래라 뒤판 축 없음). 도르래 A 의 걸이 막대만 들보에 닿는다.

### 변수
`p = (1 − cos(theta × 0.5)) / 2` (0~1), `h = 0.25 × p`.
- yM = 0.92 + h (M 중심 높이)
- yB = 2.00 − h (B 중심 높이; yM + yB = 2.92 로 항상 일정)
- yF = 1.78 − 4h (자유 끝 높이)

### 줄 경로(매 프레임 `setPath`; `arcPoints(c, r, a0, a1, z)` 는 a1 < a0 이면 시계방향)
- 줄 X (z = 0.22): (−0.4, 2.94) → (−0.4, yM) → `arcPoints([−0.2, yM], 0.2, π, 2π)` (M 밑을 반시계로 감음) → (0.0, yM) → (0.0, yB) → `arcPoints([0.2, yB], 0.2, π, 0)` (B 위를 시계로 넘음) → (0.4, yB) → (0.4, yF).
- 줄 Y (z = 0.22): M 윗 눈 (−0.2, yM + 0.26) → (−0.2, 2.55) → `arcPoints([0, 2.55], 0.2, π, 0)` (A 위를 시계로 넘음) → (0.2, 2.55) → B 윗 눈 (0.2, yB + 0.26).
- 점 사이 직선은 양끝 점만 줘도 된다(Rope 가 재표본).

## 키트 추가
- 없음. `kit/rope.ts`(`ropeAround`, `Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)는 012 설계표에서 이미 추가된다 — 그것을 쓴다(파일이 없으면 012 설계표의 '키트 추가'대로 먼저 만든다).

## 동작
- 구동 각 theta 는 `theta += OMEGA(1.6) × speed × dt` 로 누적하고 매 프레임 p, h 를 theta 에서 다시 계산한다(주기 ≈ 7.85초, p 가 0 → 1 → 0).
- 도르래 각(반시계 +, `userData.sheave.rotation.z`):
  - θ_A = −h / 0.2 (시계)
  - θ_M = +h / 0.2 (M 이 올라가며 왼쪽 가닥(고정 끝)을 타고 구름)
  - θ_B = −3h / 0.2
- 줄 위의 표시: 줄에 표시 없음. 도르래 스포크가 돌기 때문에 구분된다.
- 위치: M·추는 yM, B 는 yB, 자유 끝·손잡이는 yF 로 옮긴다(B 와 M 은 서로 반대로 움직인다).

## 표시
- `rotArrow(0.3, false)` 를 A 앞 (0, 2.55, 0.40) 에(A 는 시계로 돈다). 판화 위 도르래에 해당.
- tag: 'A 고정 도르래'(A 오른쪽 위), 'B 움직도르래'(B 오른쪽), 'M 움직도르래'(M 왼쪽), '추'(추 왼쪽), '당기는 곳'(자유 끝 오른쪽). 위치는 각 부품에서 0.35 바깥, 매 프레임 따라 움직이게 갱신.
- notes: `[{ label: '이득', value: '4배' }, { label: '당긴 줄 : 오른 높이', value: (4h).toFixed(2) + ' : ' + h.toFixed(2) }, { label: '움직도르래', value: '2개(M, B)' }]`

## 확인
- t=0.4 (p ≈ 0): 추가 아래, B 가 위(A 바로 아래), 자유 끝이 높다. t=3.9 (p ≈ 1): 추가 0.25 올라가 있고 B 는 0.25 내려와 있으며 자유 끝은 1.0 아래로 내려와 있다.
- 두 캡처에서 A·M·B 스포크가 다르고, M 과 B 의 회전 방향이 반대다. 줄이 늘어지거나 끊기지 않는다.
