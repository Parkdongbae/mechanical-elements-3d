# 083 톱니 부채꼴 두 개로 돌리기
판화(public/mm507/fig/083.png, 4배 확대 shots/_verify/083-fig-x4.png 로 다시 읽음): 그림 하나(정면). 아래에 **옆에서 본 원판 D** — 윗면에 톱니가 위로 솟은 면 래칫(크라운 래칫) 바퀴이고, 밑에 허브와 세로축, 축 둘레에 회전 화살표. 그 위에 세모꼴 부채꼴 C 가 꼭짓점의 축 B 에 달려 있고, 둥근 아래 가장자리에 톱니가 나 있어 가장 낮은 이 몇 개만 바퀴 톱니와 물린다. B 에서 위로 짧은 레버가 서고, 레버 끝 핀에서 막대 A 가 오른쪽 아래로 뻗다가 끊긴다.
원문 요지: 래칫 톱니가 난 부채꼴 호 C 두 개가 래칫 바퀴 D 의 **양쪽에서 하나씩** 작용해 D 를 거의 연속으로 돌린다. 두 호는 같은 로커 축 B 에 고정되고(그림에는 하나만 보임) 톱니 방향이 서로 반대다. 로커 축은 막대 A 의 왕복 직선 운동으로 흔든다. 호에는 스프링을 달아, 반대로 갈 때 바퀴 톱니 위로 들려 넘어가게 한다.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 D 하나(세로축, 옆에서 보아 납작한 띠로 보임, 지름 ≈ 부채꼴 반지름의 1.5배). 부채꼴 C 는 판화에 하나, 원문으로는 둘(뒤쪽 것은 앞쪽 것에 가려 안 보임).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 받침이 없다. 로커 축 B(검게 칠한 축 단면)와 바퀴의 세로축(아래로 끊김)이 제자리에서 도는 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 추·크랭크 없음. 구동은 막대 A — B 위로 선 레버(길이 ≈ 부채꼴 반지름의 0.45배) 끝의 핀에 달려 오른쪽으로 뻗는다.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 바퀴 D 는 **윗면(축 방향)** 에 톱니(면 래칫, 보이는 반 둘레에 약 20개 → 온 둘레 약 30개). 부채꼴 C 는 아래 둥근 가장자리에 톱니 약 9~10개. 부채꼴이 바퀴의 **위에서** 내려와, 바퀴 축을 비켜 앞쪽(보는 사람 쪽) 톱니 고리와 물린다. 원문의 또 하나는 축 뒤쪽 톱니 고리와 물린다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 레버 끝 핀 — 로커 축 B — 부채꼴 가운데 살 — 바퀴 세로축이 한 세로선(판화는 부채꼴이 가운데에 온 순간).
8. 판화의 글자가 가리키는 부품은? → A = 막대(레버 끝 핀에서 오른쪽으로), B = 로커 축, C = 톱니 부채꼴(창 안에 글자), D = 래칫 바퀴. 원문 글자와 같다.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 판화에 안 그린 것만 원문대로 보탠다: 뒤쪽 부채꼴(원문 "하나만 보인다"), 들림을 허용하는 스프링(원문 "달아야 한다"). 바퀴 회전 방향은 화살표가 흐려 판화로는 알 수 없음 → 위에서 보아 반시계(앞면이 오른쪽으로)로 정했다(기구는 같다).
- 그 밖의 선: 부채꼴 안 굵은 고리 둘 = 무게를 던 세모 창, 가운데 세로 띠 = 살. 바퀴 옆면의 세로 줄무늬 = 원통면 음영. 축의 굽은 화살표 = 바퀴 회전. B 의 두 겹 원 = 허브와 축 단면.

## 해석(결정 사항)
- "양쪽에서 하나씩" = 바퀴 축의 **앞(+z)과 뒤(−z)**. 같은 축 B 에 달려 같이 흔들리므로 두 부채꼴의 아래 가장자리는 같은 쪽(예: +x)으로 간다. 그런데 바퀴는 도니까 앞 고리는 +x, 뒤 고리는 −x 로 흐른다 → 오른쪽으로 흔들 때는 **앞** 부채꼴이, 왼쪽으로 흔들 때는 **뒤** 부채꼴이 민다. 그래서 톱니 방향이 서로 반대이고, 어느 쪽으로 흔들어도 바퀴는 한 방향으로 돈다.
- 미는 부채꼴은 바퀴 톱니 위를 **굴러** 간다(피치 반지름 RP 의 호가 바퀴 고리 위를 구름). 쉬는 부채꼴은 바퀴와 반대로 가므로 톱니 비탈을 타고 들렸다 내려앉기를 되풀이한다(딸깍딸깍).
- 들림 구조(판화에 없음, 원문의 스프링): 로커 축에 사각 키를 달고, 부채꼴 허브에는 키가 지나는 세로 긴 구멍(키 아래로 0.07)을 냈다. 돌림힘은 키 옆면이 전하고, 부채꼴은 제 축 방향으로 최대 0.034 들린다. 긴 구멍 속 키 밑에 코일 스프링.
- 부채꼴 이 윤곽은 바퀴 톱니(세 깊이 z 0.375·0.40·0.425)가 굴러 지나가며 깎아 낸 **창성 윤곽**이다(공식 톱니가 아님) — 틈 0.004 를 남겼다. 수치를 바꾸면 `shots/_verify/s083.mjs 83` 을 다시 돌린다.

## 구동
막대 A 의 왕복(판화의 구동). theta += OMEGA(1.6)·speed·dt. 로커 각 φ = −Φ·cos(theta), Φ = 15.484°. 한 주기(theta 2π = 3.93 s)에 바퀴는 톱니 8개(= 96°).

## 동작 (모두 theta 의 함수 — `k83State(theta)` 가 한꺼번에 돌려준다)
- φ = −Φ·cos θ (Φ = 0.27024 rad). k = ⌊θ/π⌋, w = θ − kπ.
- 바퀴 ψ = (RP/ZR)·Φ·(2k − cos w) (RP 0.62, ZR 0.40). 한 번 흔들 때(π)마다 정확히 톱니 4개(48°), 끝에서 속도 0 으로 이어진다(누적 오차 없음).
- k 짝수(φ 증가, 아래 가장자리가 +x 로): 앞 부채꼴이 민다 — liftFront = 0, 뒤 부채꼴은 liftBack = 0 ~ 0.034 를 톱니 8개만큼 오르내린다. k 홀수: 반대.
- 들림 = 부채꼴을 제 축 방향으로 올려 바퀴 톱니와 틈 0.002 가 되는 가장 작은 값(매 프레임 이분법 16회 — theta 만의 함수라 결정적). liftBack(θ) = liftFront(θ + π).
- 레버 끝 핀 = B + 0.28·(−sin φ, cos φ). 크로스헤드 = (핀 x + √(1.3² − (핀 y − 1.74)²), 1.74).
- 속도비: 미는 동안 바퀴 각속도 = (0.62/0.40)·|φ′| = 1.55·|φ′|.
- 시각: **t = 1 (θ 1.6)** φ ≈ +0.5°, 앞 부채꼴이 미는 한가운데(판화 자세). **t = 2.5 (θ 4.0)** φ ≈ +10.1° 에서 왼쪽으로 가는 중, 뒤 부채꼴이 밀고 앞 부채꼴은 0.021 들려 넘어감. t = 1.96 (θ π) 오른쪽 끝, 둘 다 내려앉음.
