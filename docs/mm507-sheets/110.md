# 110 양쪽 나사 안내 롤러
원문 요지: 고른 회전 → 고른 직선 운동. 실패 감는 기계에서 실을 실패 위로 이끄는 데 쓴다. 롤러는 두 부분으로 나뉘고 각각 가는 나사가 났는데 하나는 오른나사, 하나는 왼나사다. 롤러와 나란한 축(spindle)에 팔들이 있어 **반너트 두 개**를 든다 — 하나는 롤러 위, 하나는 롤러 아래. 한쪽 반너트가 물리면 다른 쪽은 풀린다. 레버를 오른쪽·왼쪽으로 누르면 막대(rod)가 어느 쪽으로든 간다.

## ★ 판화 읽기
판화는 그림 하나. 4배 확대 `shots/_verify/110-fig-x4.png` 로 다시 읽음(치수는 4배 그림의 px).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없다. 가로로 누운 **나사 롤러 1개**(위쪽, 빗금 친 굵은 부분 둘 + 가운데 가는 민 부분)와 그 아래 나란한 **가는 축 1개**. 롤러 나사부 지름 140px, 가운데 민 부분 85px, 아래 축 60px. 두 축 사이 세로 거리 410px.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 대신 아래 축에 **팔 2개**가 끼워져 위로 뻗는다. 왼팔(x 375~515)은 롤러 **앞**을 지나 롤러 높이 전체를 덮는 네모 덩이(반너트, y 610~810)로 끝난다 — 롤러 선이 덩이에서 끊긴다. 오른팔(x 950~1010)은 롤러 **뒤**로 들어가 롤러 아래로 T 꼴 머리(y 790~810)만, 롤러 위로 작은 턱(y 610~640)만 내민다 — 팔·너트 선이 롤러에서 끊긴다.
3. 교차하는 가닥이 있는가? → 없음. 겹침은 2번의 두 곳뿐: 왼 반너트는 롤러 앞, 오른 반너트는 롤러 뒤.
4. 고정점(천장·벽·바닥)은 어디인가? → 양쪽의 세로 **옆판 2개**(왼 x 120~260, 오른 x 1140~1280, y 580~1240). 롤러 양 끝과 아래 축이 여기에 걸린다. 바닥·받침은 그리지 않았다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 아래 축이 오른 옆판 밖으로 나와 그 끝에 **레버**(허브 x 1465~1560 + 끝 너트)가 달렸다. 레버는 축에 수직인 긴 막대로 위로 500px, 아래로 450px, 양 끝이 고리 꼴 손잡이. 롤러를 돌리는 풀리·크랭크는 그리지 않았다.
6. 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 롤러 바깥에 나사산 — 왼쪽 나사부(x 260~620)와 오른쪽 나사부(x 780~1140). 왼 반너트는 왼쪽 나사부에 앞에서, 오른 반너트는 오른쪽 나사부에 뒤에서 닿는다. 반너트 안쪽 나사는 가려져 보이지 않는다. 나사산 빗금이 가늘어 어느 쪽이 오른나사인지는 판화로는 알 수 없음.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 롤러 축과 아래 축이 평행(둘 다 수평). 팔 허브 2개와 레버 허브가 아래 축 한 줄 위. 왼팔은 왼쪽 나사부 한가운데, 오른팔은 오른쪽 나사부의 가운데보다 조금 오른쪽.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 110 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 같다. 말만 다르다 — 원문은 반너트가 "롤러 위와 아래", 판화는 "롤러 앞과 뒤"로 보인다. 판화를 위에서 내려다본 그림으로 읽으면 같은 것이고(축 둘레로 90° 돌린 차이), 어느 쪽이든 "두 반너트가 롤러의 서로 반대편에 있고, 아래 축을 살짝 돌리면 하나가 붙고 하나가 떨어진다"는 기구는 하나로 정해진다 → 판화 모양 그대로(앞·뒤) 만든다. 문제 없음.
- 그 밖의 선: 아래 축의 굵은 아랫선은 그림자 선. 왼 반너트 안의 세로 긴 홈 선은 팔이 덩이 속으로 들어간 윤곽. 레버 허브 오른쪽의 작은 덩이는 축 끝 너트.

## 해석(결정 사항)
- **기구**: 아래 축 + 팔 2개 + 반너트 2개 + 레버가 한 몸("흔들 축"). 이 한 몸이 옆판 구멍에서 **좌우로 미끄러지고(이것이 원문의 rod — 실 안내 막대)** 또 **제 축 둘레로 조금 돈다**. 레버로 한쪽으로 기울이면 앞 반너트가 왼나사에 물려 롤러 회전이 막대를 한쪽으로 밀고, 반대로 기울이면 뒤 반너트가 오른나사에 물려 반대쪽으로 민다.
- 왼쪽 나사부 = 왼나사, 오른쪽 나사부 = 오른나사로 정함(판화로는 알 수 없음. 원문은 "하나는 오른, 하나는 왼"뿐).
- 원문은 "가는 나사"이나 리드가 작으면 움직임이 보이지 않아 **3줄 나사**(피치 0.08, 리드 0.24)로 한다 — 산은 가늘게 보이고 한 바퀴에 0.24 간다.
- 레버 넘기기는 사람이 하는 일이므로 주기 시간표로 자동 재생한다(막대가 끝에 오면 레버가 넘어간다).
- 판화에 없음: 옆판 아래 받침 다리 2개(공통 받침대에 세우기 위한 최소 보충). 롤러 구동 수단은 판화에 없으므로 만들지 않는다(롤러가 스스로 돈다).

## 구동
롤러(theta 누적). theta += OMEGA(1.6)·speed·dt. 롤러 한 바퀴 3.93 s. 한 주기 = 롤러 11/3 바퀴 = 14.4 s(오른쪽으로 0.36 → 레버 넘김 → 왼쪽으로 0.36 → 레버 넘김).

## 부품과 치수 (새 부품은 모두 `kit/k110.ts`, 이미 구현됨. 치수 상수 `K110`)
배치 상수(모델에 그대로): 롤러 가운데 x = −0.35, 흔들 축 높이 1.32, 롤러 축 높이 2.22(= 1.32 + `K110.D` 0.9), 두 축의 깊이 ZC = 0.28.
- 틀(name `frame`, 고정): `frame110(0.9)` 를 (−0.35, 2.22, 0.28) 에. 옆판 2개 — 안쪽 면이 롤러 가운데에서 ±0.97, 두께 0.3, 세로 1.08~2.53, 깊이 0.44. 바깥 면의 축받이 고리 4개는 **구멍이 축 방향(X)**. 받침 다리 2개(판화에 없음)는 옆판 아랫면 1.08 에서 받침대 윗면 0.18 까지 = 0.9. 주철.
- 롤러(name `roller`): `roller110()` 을 (−0.35, 2.22, 0.28) 에. 축 = X. 왼쪽 나사부(롤러 가운데 기준 −0.97~−0.18, 왼나사), 가운데 민 부분(−0.18~0.18, 반지름 0.095, 노란 표시 줄), 오른쪽 나사부(0.18~0.97, 오른나사). 골 반지름 0.125, 산 반지름 0.155, 3줄 피치 0.08. 양 끝 저널(반지름 0.06)이 옆판을 꿴다. 황동.
- 흔들 축 한 몸(name `rock`): `rockShaft110()` 을 (−0.35 + x, 1.32, 0.28) 에. 들어 있는 것:
  - 축: 반지름 0.06, 롤러 가운데 기준 −1.22 ~ 1.98 (양 옆판 구멍을 지나 오른쪽으로 나옴).
  - 팔 A(앞): 허브(반지름 0.15, 폭 0.31) + 앞으로 13° 기운 팔 + **반너트 A** — 롤러 앞면을 ±50° 감싸는 부채꼴 껍질(폭 0.29, 두께 0.08, 안쪽에 왼나사 산, 틈 0.006). 가운데 x = −0.565(왼쪽 나사부 한가운데). 청동.
  - 팔 B(뒤): 같은 꼴을 뒤로 뒤집은 것, 안쪽에 오른나사 산. 가운데 x = +0.62. 정면에서는 롤러에 가려 위아래 끝만 보인다(판화의 T 머리와 작은 턱).
  - 레버: 허브(x = 1.79) + 세로 막대(위로 1.1, 아래로 1.0) + 양 끝 손잡이 알 + 축 끝 너트.
  - 키트가 붙여 둔 child: `nutA`·`nutB`(반너트 가운데, 롤러 축 위 — 이름표가 따라갈 자리이자 침범 검사 윤곽), `leverTop`(레버 위 끝).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 −1.75 ~ 1.81(막대가 끝까지 갔을 때), 세로 0.18 ~ 2.54.

## 동작 (모두 theta 의 닫힌 식 — `traverse110(theta + K110.pose)` 가 돌려준다)
`const T = traverse110(theta + K110.pose)` → { spin, x, phi, engaged, v }. `K110.pose` 는 t = 1 에서 판화 자세(막대 가운데)가 되게 하는 위상.
- `roller.rotation.x = T.spin`
- `rock.position.x = −0.35 + T.x`, `rock.rotation.x = T.phi`
- 주기 안 위치 v(롤러 회전수, 0 ~ 11/3):
  - v 0 ~ 1.5: A 물림, 막대가 오른쪽으로 −0.18 → +0.18 (롤러 1.5바퀴 × 리드 0.24 = 0.36). phi = −7°.
  - v 1.5 ~ 1.833: 둘 다 풀림, 막대 멈춤. 레버는 v 1.19 ~ 2.143 에 걸쳐 −7° → +7°(부드럽게).
  - v 1.833 ~ 3.333: B 물림, 막대가 왼쪽으로 +0.18 → −0.18. phi = +7°.
  - v 3.333 ~ 3.667: 둘 다 풀림. 레버는 v 3.023 ~ 3.977(다음 주기 0.31)에 걸쳐 +7° → −7°.
- 주기가 닫히는 까닭: 한 주기에 롤러가 11/3 바퀴 → 나사산이 0.24 × 11/3 = 0.88 = 피치 11개만큼 지나가므로, 다시 물릴 때 산과 골이 정확히 같은 자리(누적 오차 없음). 반너트 안쪽 나사의 위상은 키트 `nutPhase110` 이 이 시간표에 맞춰 넣어 두었다.
- 레버가 넘어가기 시작해도 반너트는 산을 다 빠져나올 때까지 막대와 함께 가므로 나사를 긁지 않는다(아래 수치).
- 시각: **t = 1.0 (v 0.75, 막대 가운데 x = 0, A 물림 — 판화 자세)**, **t = 1.6 (x = +0.037, A 물림)**, t = 4.6 (v 1.667, 오른쪽 끝, 레버 한가운데 phi 0° — 둘 다 풀림), t = 8.2 (v 2.583, 막대 가운데, B 물림 phi +7°), t = 15.4 = 다시 t 1 과 같음.

## 표시

- tag 이름표 4개: '양쪽 나사 롤러(구동)' (−0.35, 3.12, 0.3) 고정, 'A 앞 너트' (−1.3 + x, 2.72, 0.5), 'B 뒤 너트' (0.2 + x, 2.72, 0.5), '레버' (1.44 + x, 2.72, 0.4). 뒤의 셋은 막대를 따라 좌우로 움직인다 — x 는 `T.x`, update 에서 position.x 만 바꾼다('레버' 는 레버 위 끝 바로 위).
- view: 전시대 전체가 보이게, 앞 너트와 뒤 너트가 구별되도록 조금 오른쪽 위에서 — pos (0.9, 2.9, 6.3), target (0, 1.55, 0.2).

## ★ 깊이 계산
