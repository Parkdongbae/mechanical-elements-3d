# 115 두 바퀴로 움직이는 이중 랙
원문: "Rotary motion of the toothed wheels produces rectilinear motion of the double rack and gives equal force and velocity to each side, both wheels being of equal size." — 톱니바퀴 두 개의 회전이 이중 랙을 직선으로 움직이고, 두 바퀴의 크기가 같아서 위·아래 양쪽에 같은 힘과 속도를 준다. (원문 끝의 "the top" 은 옆 칸 글이 스캔에 섞인 것.)

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/115-fig-x4.png` 로 다시 읽음(px 는 4배 그림 기준).
1. 바퀴는 몇 개이고 크기 차례는? → 2개, **크기가 같다**. 틀 안에 위아래로 놓인 평기어 둘(이 14개 안팎, 이끝 반지름 약 225px, 가운데에 빗금 친 축 단면). 중심 사이 거리 약 400px = 피치 지름.
2. 줄·벨트는? → 없음. 대신 **긴 고리 꼴 틀 1개**(바깥 길이 약 1660px × 높이 1000px, 띠 두께 약 80px)의 안쪽 윗변에 아래로 난 이 8개, 안쪽 아랫변에 위로 난 이 8개쯤(랙 두 줄, 길이 약 860px). 양 끝은 반원이 아니라 반지름이 큰 납작한 호. 틀의 좌우 끝 가운데에 작은 네모 귀(높이 약 100px)가 하나씩 튀어나와 있다(막대가 이어지는 자리).
3. 교차하는 가닥은? → 없음. 물리는 곳은 세 군데: 위 기어 ↔ 위 랙, 위 기어 ↔ 아래 기어(틀 가운데 높이), 아래 기어 ↔ 아래 랙.
4. 고정점은? → 판화에는 없다. 두 기어의 축(빗금 단면)은 제자리에서 돌고, 틀은 좌우로만 움직인다(양 끝 귀가 안내에 끼이는 것으로 읽음 — 안내는 그리지 않음).
5. 추·손잡이·크랭크는? → 없음. 어느 기어가 구동인지는 판화·원문에 없다(모형은 위 기어를 구동으로).
6. 이는 어디에 났고 무엇이 물리는가? → 랙의 이는 틀 **안쪽** 위·아래 변에(서로 마주 봄). 위 기어는 위 랙에 아래에서, 아래 기어는 아래 랙에 위에서 물리고, 두 기어는 서로 바깥끼리 물린다. 두 기어가 서로 반대로 도므로 위 기어의 꼭대기와 아래 기어의 밑바닥이 **같은 쪽으로** 움직여 두 랙을 한 방향으로 민다.
7. 한 줄에 놓인 것은? → 두 기어의 중심이 같은 세로선(틀의 가운데에서 조금 왼쪽 — 왕복 도중의 한 순간). 두 기어가 물리는 점이 틀의 가운데 높이. 좌우 귀도 그 높이.
8. 글자가 가리키는 부품은? → 글자 없음(번호 115 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 다만 랙이 유한하므로 기어가 한 방향으로 계속 돌 수는 없다(랙 끝에서 되돌아야 한다) — 모형은 좌우로 흔들리는 구동으로 틀을 왕복시킨다. 기구는 판화 그대로이므로 질문 거리 없음.
- 그 밖의 선: 틀 바깥선·안쪽선 두 줄 = 띠의 두께. 귀의 안쪽 세로선 = 귀가 틀에 붙는 턱. 기어 가운데 빗금 원 = 축 단면(허브 고리는 그리지 않음).

## 해석(결정 사항)
- 판화 비: 같은 기어 둘(이 14개, 모듈 0.04, 피치 반지름 0.28)이 위아래로 물림, 틀 안쪽 길이 2.0·높이 1.22(1.63배), 끝은 납작한 호(반지름 1.0).
- 랙 이 수: 위 8개, **아래 9개**. 잇수가 같은 두 기어가 서로 물리면 위 랙과 아래 랙의 이 자리가 반 피치 어긋난다(계산·모의로 확인) → 아래 랙을 8개로 하면 한쪽으로 반 피치 치우치므로 9개로 해 좌우 대칭으로 둔다. 판화는 8개쯤으로 보이나 한 개 차이라 눈에 띄지 않는다.
- 랙 이끝은 모듈의 0.8배로 낮춤(잇수 14 짜리 인벌류트 이의 뿌리 간섭 방지 — 모의에서 침범 0).
- 구동은 위 기어, 좌우 흔들림 ±61.4°. t = 1 에 틀이 가운데.
- 양 끝 귀는 납작 막대로 길게 잇고(판화의 귀 = 막대가 이어지는 자리) 납작 막대 안내 2개로 받친다(안내는 판화에 없음 — 최소 보충). 두 축의 뒤판 보스도 판화에 없음.

## 구동
위 기어(name `gearA`). theta += OMEGA(1.6)·speed·dt 로 누적하고, 위 기어 각은 phiA = 1.0714·sin(theta − 1.6) (rad) — 3.93 s 에 한 번 왕복. `k115State(theta)` 가 돌려준다.

## 부품과 치수 (새 부품은 모두 `kit/k113.ts`, 이미 구현됨. 치수 상수 `K115`)
배치 상수: CY = 1.75 (틀 가운데선 = 두 기어가 물리는 높이, x 는 0), ZF = 0.2 (기어·틀의 가운데 평면).
- 위 기어(name `gearA`, 구동): `spurGear(14, 0.04, { width: 0.1, spokes: 4, driver: true })` — 피치 반지름 0.28, 이끝 0.32. 위치 (0, 2.03, 0.2).
- 아래 기어(name `gearB`): `spurGear(14, 0.04, { width: 0.1, spokes: 4 })` — 위치 (0, 1.47, 0.2). 중심 거리 0.56.
- 축 2개: `shaftZ(0, 2.03, 0.3, 0.035)`, `shaftZ(0, 1.47, 0.3, 0.035)` — 뒤판 보스에서 틀의 빈 안쪽을 지나 기어 앞까지(기어 구멍 반지름 0.039).
- 고리 틀(name `frame`): `rackFrame113(k115Frame())` — 위치 (x(θ), 1.75, 0.2). 피치선은 가운데선에서 ±0.56, 안쪽 반높이 0.61, 안쪽 반길이 1.0(끝 호 반지름 1.0), 띠 두께 0.09 → 바깥 반길이 1.09·반높이 0.70, 두께 0.1. 위 랙 이 8개(범위 ±0.488), 아래 랙 이 9개(범위 ±0.551), 피치 0.1257. 양 끝 납작 막대: 높이 0.09, 끝 x = ±1.87(틀 좌표). `k115Frame()` 이 두 랙의 위상을 기어 각 0 에 맞춰 준다. 강철.
- 납작 막대 안내 2개(고정): `barGuide113(−1.48, 1.75, 0.2, 0.09, 0.1)`, `barGuide113(1.48, 1.75, 0.2, 0.09, 0.1)` — 길이 0.14(x 1.41~1.55).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위: 막대 끝 ±1.87 → 왕복 때 ±2.17. 세로 1.05 ~ 2.45.

## 동작 (모두 theta 의 닫힌 식 — `k115State(theta)` 가 { phiA, phiB, x, ccw } 를 돌려준다)
- 위 기어: `gearA.rotation.z = phiA`, phiA = (0.3 / 0.28)·sin(theta − 1.6).
- 아래 기어: `gearB.rotation.z = phiB = k115LowerAngle(phiA)` = −phiA − 0.6732 (반대 방향, 같은 빠르기 — 이와 이골이 엇갈리는 위상 포함).
- 틀: `frame.position.x = x = −0.28·phiA`. 위 기어가 반시계로 돌면 그 꼭대기가 왼쪽으로, 아래 기어(시계)의 밑바닥도 왼쪽으로 가므로 두 랙이 함께 왼쪽으로 밀린다. 범위 ±0.3.
- 시각: **t = 1.0 (phiA = 0, 틀 가운데 = 판화 자세, 위 기어가 반시계로 도는 중)**, **t = 1.6 (phiA = +50.3°, x = −0.246)**, t = 1.98 (왼쪽 끝 −0.3), t = 3.95 (오른쪽 끝 +0.3).
