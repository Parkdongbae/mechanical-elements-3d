# 194 맹글 휠 3
원문: 이 맹글 휠은 이의 줄이 하나뿐이라 두 방향의 속도가 같다. 피니언 축은 휠의 홈이 안내하고 유니버설 조인트로 흔들리며 맞물림을 유지한다. 판화: 큰 원판, 가운데 허브, 허브를 감싼 물방울꼴 이중선, 바깥의 C자 이중선(안내 홈, 끝이 위에서 반원으로 이어짐), 두 홈 사이에 타원 구멍 한 줄(약 25개), 아래에 피니언.

## ★ 판화 읽기
1. 바퀴는? → 휠 1개(반지름 215px), 피니언 1개(잇수 약 12).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 휠 중심축과, 피니언 축을 붙드는 세운 막대(보충).
5. 구동은? → 피니언(한 방향 일정 회전).
6. 기어는? → 이 줄이 하나: 타원 구멍 고리(피치 반지름 약 120px)가 위쪽이 열린 C자로 늘어섰다. 피니언 이가 구멍에 들어간다. 피니언은 바깥에서 물다가 끝을 돌아 안쪽에서 문다.
7. 한 줄에 놓인 것은? → 휠 중심·피니언 중심이 같은 세로선.
8. 글자는? → 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화의 두 이중선은 하나의 닫힌 안내 홈(바깥 팔·안쪽 팔·양끝 반원)으로 읽었다. 구멍판 앞쪽 층에 피니언 판을 두고 이 못(핀)이 구멍에 들어가게 풀었다(피니언 몸통이 판을 파고들지 않게).

## 구동
피니언 일정 각속도 3.2 rad/s. 휠은 `mangleTrack(rib).solve` 의 닫힌 식(R1−R2 = 2rp 라 두 팔이 같은 고리를 문다).

## 부품과 치수 (새 부품은 `kit/k194.ts`, 이미 구현됨. 상수 `K194`)

- 세운 막대: 폭 0.14, y 0.33~1.62, z 0.34, 홈 y 0.95~1.44, 받침 상자.
