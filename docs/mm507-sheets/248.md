# 248 유니언 이음
원문(en): "Union coupling. A is a pipe with a small flange abutting against the pipe, C, with a screwed end; B a nut which holds them together." — 유니언 이음. A 는 작은 플랜지가 달린 관으로, 나사 끝을 가진 관 C 에 맞닿아 있고, B 는 이 둘을 붙들어 주는 너트이다.
쉬운 풀이: A 관의 플랜지를 C 관 끝에 맞대고, 큰 너트 B 를 C 의 바깥 나사에 돌려 조이면 너트 안쪽 턱이 플랜지를 눌러 두 관이 단단히 이어진다. 풀면 쉽게 뗄 수 있다.
판화 묘사(원본 501×450 px, **세로 단면도**): 위에서 내려오는 관 A(바깥 x 143~302, 점선 = 안지름 163~280, 잘리지 않은 겉모양). A 아래 끝에 둥근 테 플랜지(y 165~195, x 95~335)와 그 밑으로 조금 굵은 꽂이(x 135~308, y 197~257). 아래 관 C(빗금, 단면): 위쪽 바깥에 나사(x 98~110, 330~345 의 톱니, y 197~297), 위 끝 안쪽은 넓은 구멍(꽂이가 들어감), 아래는 좁은 구멍(x 168~283)으로 y 422 까지. 너트 B(빗금, 단면): 꼭대기 y 133, 바깥 x 68~378, 아래쪽에 바깥 턱(x 48~400, y 257~290), 안쪽 위 턱(안지름 x 138~308)이 플랜지 윗면을 누르고, 그 밑은 플랜지가 들어가는 빈 곳, 그 밑 안쪽 나사가 C 의 나사와 물림.

## ★ 판화 읽기
판화 하나(세로 단면, A 만 겉모양). 세계 1 px = 0.004, 관 축 x 0 = px 222.5. 높이: 플랜지 밑면(= C 윗면, py 195)이 세계 y 1.50.
1. 바퀴는 몇 개이고 크기 차례는? → 바퀴 없음. 관 A·관 C·너트 B 세 개(모두 같은 세로 축의 회전체). 크기: 너트 바깥 턱 반지름 0.70 > 너트 몸 0.62 > C 나사 산 0.488 > 플랜지 0.432 > A 바깥 0.318.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → C(아래 끝을 받침대 위 바닥 플랜지로 세움). A 는 C 위에 플랜지로 얹히고 꽂이가 C 의 넓은 구멍에 들어가 곧게 선다.
5. 추·손잡이·크랭크는? → 없음. 너트 B 를 손(렌치)으로 돌린다고 보고 너트 윗면 노란 표지와 회전 화살표로 보인다.
6. 기어는? → 기어 없음. 나사: C 바깥 수나사, B 안 암나사(오른나사, 피치 0.04 = 판화 10 px, 산 높이 0.04).
7. 한 줄에 놓인 것은? → A·B·C 가 한 세로 축(x 0). 플랜지 밑면 = C 윗면(y 1.50), 너트 턱 밑면 = 플랜지 윗면(조였을 때 y 1.62).
8. 글자가 가리키는 부품은? → A = 위 관(플랜지 달림), B = 너트, C = 아래 관(나사 끝).
9. 판화와 원문이 다르거나 판화대로는 동작할 수 없는 곳은? → 판화의 플랜지 반지름(약 122 px)이 너트 암나사 안지름(112 px)보다 커서, 너트를 풀어 올리면 나사산이 플랜지에 걸려 **너트가 올라갈 수 없다**. → 플랜지를 108 px(0.432)로 줄여 너트 나사산 안(0.451)을 지나게 함 → ★질문 거리. 그 밖에는 판화대로.

## 해석(결정 사항)
- 단면 평면 z 0.465(관 축의 z). **A 는 통째**(판화처럼 겉모양), **B 와 C 는 뒤 반쪽만**(앞 반쪽을 잘라 냄, 잘린 면 = 판화의 빗금).
- 나사는 진짜 나선: 위상 u(φ, y) = frac(y/0.04 − φ/2π)(y 는 플랜지 밑면 기준, φ = atan2(−z, x), φ 0 = +x, π/2 = 뒤, π = −x). 톱니 높이 tri(u) = 1 − |2u − 1|. C 산 표면 반지름 0.448 + 0.04·tri, 너트 암나사 표면 0.451 + 0.04·tri(틈 0.003 어디서나).
- 너트가 각 α 돌고 0.04·α/2π 오르면 너트 나사 표면은 세계에서 그대로다(오른나사: 위에서 보아 반시계 = 풀림·올라감). 그래서 **너트 암나사 면은 돌리지 않고 세계에 고정한 채, 너트가 덮는 y 범위만 매 프레임 다시 만든다.** 너트 몸(둥근 회전체)은 돌려도 모양이 같으므로 올리고 내리기만, 돌아가는 것은 윗면 노란 표지 6개.
- 풀린 자리 = 4 바퀴 = 0.16 위(턱–플랜지 틈 0.16), 조인 자리 = 판화(틈 0).
