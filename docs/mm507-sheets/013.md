# 013 움직도르래
판화: 위에 들보(빗금). 왼쪽 들보에 매달린 **고정 도르래**(그림 왼쪽 가장자리에 잘림), 들보 오른쪽 고리에 **줄 한쪽 끝이 묶여** 있고, 그 줄이 수직으로 내려가 **아래의 움직도르래**(고리로 추를 매닮 — 추는 원통형)를 아래에서 돌아 올라와 다시 수직으로 올라가 고정 도르래를 넘어간다(넘어간 끝은 그림 밖의 손). 두 수직 줄 사이 간격 = 움직도르래 지름. 원문: 줄 한쪽 끝이 고정되어 있으므로 다른 쪽 끝은 추보다 **두 배 빨리** 움직여야 하고, 그만큼 힘의 이득이 생긴다(1/2).
구동: 손(줄의 자유단)이 줄을 당겼다 놓는다 — 줄을 2d 당기면 추(움직도르래)가 d 올라간다.

## 부품과 치수
- `displayStand()`
- 들보: `BoxGeometry(1.9, 0.12, 0.65)` castIron, 중심 (0.05, 3.02, 0.05).
- 고정 도르래 F: 줄 중심 반지름 RF = 0.36, 중심 (−0.26, 2.35), z = 0.25, `pulley(0.34, { width: 0.10, grooved: true, spokes: 4 })`. 매달이는 012 와 같은 방식(축 막대 + 옆판 2 + 고리, 고리 중심 (−0.26, 2.91)).
- 움직도르래 M: 줄 중심 반지름 RM = 0.30, 중심 (0.40, y_m), z = 0.25, `pulley(0.28, { width: 0.10, grooved: true, spokes: 4 })`. y_m = 1.25 + d. 매달이: 축 막대 + 옆판 2(M 중심 위아래로 ±0.36 정도) — 아래쪽 옆판 끝이 고리 ring(중심 (0.40, y_m − 0.38), `TorusGeometry(0.04, 0.011, …)`)로 이어진다. 고리 아래에 `weight(0.36, 0.40)`, 중심 (0.40, y_m − 0.664, 0.25) (위 고리 중심 = y_m − 0.43 쯤에서 갈고리 막대로 이음).
- 들보 고정단: 고리(`TorusGeometry(0.05, 0.012, …)`) 중심 (0.70, 2.91, 0.25) 에 줄 한쪽 끝이 묶인다.
- 줄 정렬 조건(수직이 되도록): F 오른쪽 접점 x = −0.26 + 0.36 = 0.10, M 왼쪽 접점 x = 0.40 − 0.30 = 0.10, M 오른쪽 접점 x = 0.70 = 고정단 x. F 왼쪽 접점 x = −0.62(자유단 줄도 수직).
- 줄: 012 의 `ropeAround` + `new Rope(0.018)`, 매 프레임 `setPath`. 모두 w = 0.25.
  `ropeAround({ p: [0.70, 2.91] }, [{ c: [0.40, y_m], r: 0.30, ccw: false }, { c: [-0.26, 2.35], r: 0.36, ccw: true }], { p: [-0.62, y_E] }, { seg: 24 })`
  진행: 고정단 → 아래로 → M 오른쪽 → M 아래를 돌아(시계) → M 왼쪽을 올라(교차 접선: 두 원의 감는 방향이 달라 수직선이 두 원 사이를 지난다) → F 오른쪽 → F 위를 넘어(반시계) → 아래 자유단.
- 자유단 손잡이: `rod(V3(−0.62, y_E, 0.25), V3(−0.62, y_E − 0.16, 0.25), 0.05)` + 아래 구 반지름 0.06. 줄 끝은 손잡이 위에서 끝난다.

## 키트 추가
없음 — 012 의 `kit/rope.ts`(`ropeAround`)를 쓴다.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- 추 올림 d(theta) = 0.30 × (1 − cos(0.5 × theta)) (0 ~ 0.6).
- 움직도르래·추: y_m = 1.25 + d (x 고정). 자유단 y_E = 1.90 − 2d (**추의 두 배 속도**, 손잡이가 y_E 에 같이 움직임).
- M 회전: `rotation.z = −d / 0.30` (왼쪽 줄이 올라가는 쪽이 시계 방향 — 오른쪽 줄은 고정이라 M 이 그 줄을 타고 구르듯 돈다). F 회전: `rotation.z = + 2d / 0.36` (오른쪽 줄이 올라가므로 반시계).
- 줄: 위 `ropeAround` 로 매 프레임 갱신. 각 직선부는 수직을 유지한다.

## 표시
- `rotArrow(0.5, false)` M 앞, `rotArrow(0.55, true)` F 앞. tag '고정 도르래', '움직도르래', '추', '줄 묶은 곳'(고정단 고리), '당기는 끝(추의 2배 이동)'.
- notes: `[{ label: '힘의 이득', value: '2배 (힘 1/2)' }, { label: '추 올라간 높이', value: d.toFixed(2) }, { label: '당긴 줄 길이', value: (2 * d).toFixed(2) }]`

## 확인
- t=0.5(d ≈ 0.02) 와 t=3.9(d ≈ 0.6): 추·움직도르래가 올라가 있고, 손잡이는 그 두 배(1.2)만큼 내려가 있다. M 과 F 의 스포크가 서로 반대 방향으로 돌아 있다.
- 두 수직 줄 간격이 M 의 지름과 같고 오른쪽 줄(고정단)은 길이가 줄어 있다. 줄이 도르래·들보를 뚫지 않고 M 이 F 와 닿지 않는다(M 은 x 0.10 ~ 0.70, F 는 x −0.62 ~ 0.10 이라 가장 높을 때도 두 바퀴가 겹치지 않는다).
