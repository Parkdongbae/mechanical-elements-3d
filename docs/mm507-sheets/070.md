# 070 스터드 원판 간헐 회전
원문: 구동 바퀴 C 에는 점선으로 보인 테가 있는데, 그 **바깥쪽**은 탭핏 B 가 스터드에 닿지 않는 동안 다른 바퀴 A 의 스터드를 받치고 멈추게 한다. 이 테의 틈은 **스터드 하나가 들어가고 다른 하나가 나가게** 한다. 탭핏은 이 틈의 가운데 맞은편에 있다.

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴는 몇 개이고 크기 차례는? → 2개. 왼쪽 원판 A, 오른쪽 구동 바퀴 C 가 A 를 조금 덮으며 겹쳐 있다(C 가 앞). C 반지름은 A 의 약 1.04배, 중심 거리는 A 반지름의 약 1.65배.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(두 축의 단면만).
5. 추·손잡이·크랭크는? → 없음. 구동은 C(원문).
6. 이(스터드)는 어디에 있고 무엇이 물리는가? → A 의 면에 스터드 **10개**가 반지름 0.82·A 인 원 위에 36° 간격(실선 8개 + C 둘레에 걸친 것 1개 + C 뒤에 가려 점선인 것 1개). C 에는 둘레 바로 안쪽에 점선 원 = **테의 안쪽 가장자리**(테는 C 의 뒷면, 둘레를 따라 붙어 있어 테의 바깥면 = C 의 둘레). 테는 A 쪽으로 틈이 나 있다(점선 원이 중심선 위아래 약 31° 에서 끊김). C 의 허브에서 틈 가운데로 뻗은 두 점선 = **탭핏 B**(끝으로 갈수록 좁아지고 끝이 C 둘레까지 닿음). C 안에서 세로로 휜 점선 호 = C 에 가려진 A 의 둘레. 판화의 순간은 **미는 중**: 틈 안의 스터드(점선)가 탭핏 바로 아래에서 밀려 내려가고, 위쪽 스터드는 C 둘레에 걸쳐 막 들어오는 중, 아래쪽 스터드는 이미 둘레에서 떨어져 나갔다.
7. 한 줄에 놓인 것은? → 두 축이 같은 높이.
8. 글자가 가리키는 부품은? → A = 스터드 원판, B = 탭핏, C = 구동 바퀴. 화살표(C 위쪽, 왼쪽을 향함) = 반시계.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 판화 치수로 계산하면 원문과 꼭 맞는다: 중심선 ±36° 스터드의 중심에서 C 중심까지 576(4배 확대 픽셀) − 스터드 반지름 35 = 541 ≈ C 둘레 반지름 545 → **쉬는 동안 스터드 하나는 테 안(중심선 위), 양옆 두 스터드가 테 바깥면에 닿는다.**
- 그 밖의 선: 축 둘레 두 겹 원 = 허브 고리. 틈 양 끝의 비스듬한 짧은 점선 = 테 끝의 모따기.

## 해석(결정 사항)
- **쉬는 자세**: 스터드 하나가 테 안쪽(중심선 위, C 중심에서 0.895)에 있고, 그 위·아래 이웃(±36°) 두 스터드가 테 바깥면(반지름 1.1144)에 닿는다 → A 는 어느 쪽으로도 못 돈다(양쪽 잠금, 흔들림 0). (앞 설계표는 테 바깥면에 ±15°·−21° 두 스터드가 한쪽으로만 받치고 테 안에는 아무것도 없게 했다 — 원문 "하나가 들어가고 다른 하나가 나간다"·판화 치수와 달라 고침.)
- **미는 동안**: 틈이 A 쪽으로 오면 탭핏의 앞 옆면이 테 안의 스터드를 쳐서 아래로 밀어 틈으로 내보내고(하나가 나감), 그 뒤를 따라 위쪽 스터드가 틈으로 들어와 중심선에 선다(하나가 들어옴). A 는 36°(시계).
- **탭핏 끝 = 테 바깥 반지름**(판화대로 C 둘레까지). 그래야 나가는 스터드가 정확히 테 바깥면에 접하는 자리(−36°)에서 탭핏 끝 모서리가 떠나고, A 의 속도가 0 으로 줄며 끝난다.
- 틈 반각 34°(판화 약 31°. 31° 이상이면 들어오고 나가는 스터드가 테 끝에 걸리지 않음을 수치로 확인, 28° 는 걸림).
- 판화의 점선은 'C 의 앞판 뒤에 숨은 것' → C = 앞판(반투명) + 둘레에서 뒤로 뻗은 테 + 탭핏. A 판은 그보다 뒤, 스터드·테·탭핏만 같은 깊이에서 만난다.
- 탭핏이 오기 직전·직후(틈이 두 이웃 스터드 위에 와 있는 동안)에는 A 가 잠깐 풀려 있다 — 판화대로의 성질이며, 모형에서 A 는 그 사이 가만히 있다.

## 구동
C(반시계) theta += OMEGA(1.6)·speed·dt. A 는 C 한 바퀴에 스터드 하나(36°)만 시계로 돌고 나머지 때는 테에 잠겨 선다.

## 부품과 치수 (키트 `kit/k069.ts`, 이미 구현됨. 값은 `K70` 상수)
- A(name `discA`): `studDisc(1.08, 10, 0.885, 0.07, 0, 0.22)` — 판 반지름 1.08(두께 0.06), 스터드 10개(링 반지름 0.885, 스터드 반지름 0.07, 판 앞으로 0.22), 스터드 k 의 로컬 각 = k·36°. 중심 (−0.91, 1.75), z = 0.03(스터드 끝 z 0.28).
- C(name `wheelC`): `rimDriver(K70.rimR, 0.085, 34, 0.045, 0.12, 0.12, 0.195)` — 앞판 반지름 = 테 바깥 반지름 = 1.1144(반투명, 두께 0.05), 판 둘레에서 뒤로 0.195 뻗은 테(두께 0.085 → 안쪽 반지름 1.029, 틈 ±34°), 틈 가운데 탭핏(뿌리 반지름 0.12·반폭 0.12 → 끝 반지름 1.1144·반폭 0.045). 틈·탭핏 방향 = 로컬 +X. 중심 A + (1.78, 0) = (0.87, 1.75), z = 0.34(앞판 0.315 ~ 0.365, 테·탭핏 0.12 ~ 0.315). 청동색(구동).
- 테 바깥 반지름 = √(1.78² + 0.885² − 2·1.78·0.885·cos 36°) − 0.07 = 1.1844 − 0.07 = 1.1144 (`K70.rimR` 이 같은 식으로 계산).
- 축: `shaftZ(−0.91, 1.75, 0.45)`, `shaftZ(0.87, 1.75, 0.5)`.
- 전시 영역: x −1.99 ~ 1.984, y 0.636 ~ 2.864, z −0.30 ~ 0.5.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).

## 동작 (theta = 누적 각)
- C 의 탭핏(틈 가운데) 방향각 chi(도) = 84 + theta(도). `C.rotation.z = chi`(라디안). chi = 180° 일 때 탭핏이 A 를 향한다.
- A 의 시계방향 누적 회전 a(도) = `studWheelAngle(chi 누적)` = q·36 + 표(chi 접은 값), q = ⌊chi/360⌋. `A.rotation.z = −a`(라디안).
- 주기 시간표(한 바퀴 = 3.93 s): chi 0 ~ 171.5° 정지(테가 잠금) → chi 171.5° ~ 203.75°(32°, 9%) A 가 36° 전진 → 203.75° ~ 360° 정지. 미는 동안 A 의 속도는 C 의 약 1.0 ~ 1.7배로 점점 빨라지다가 마지막 6° 에서 0 으로 줄어든다. 속도비 평균 C : A = 10 : 1.
- 표 `PUSH70`(0.5° 간격, chi 171 ~ 204)은 `shots/_verify/s070b.mjs` 의 접촉 풀이: 탭핏 다각형이 스터드 원을 뚫지 않는 가장 작은 a. 한 바퀴 전진이 정확히 36.000° 로 닫힌다(탭핏 끝 = 테 바깥 반지름이라서).
- 시각: **t = 1.0 (chi 175.7°, a ≈ 4.2° — 판화 자세: 탭핏이 A 를 향해 틈 안의 스터드를 밀기 시작)**, t = 1.2 (chi 194°, a ≈ 24.6°, 나가는 스터드가 틈을 지나는 중), **t = 1.6 (chi 230.7°, a = 36°, 다시 잠김: 새 스터드가 테 안, 양옆 스터드가 테 바깥면)**.
