# 119 미끄럼 홈의 이중 랙 피니언
원문 요지: 한 방향으로 고르게 도는 피니언이 **길쭉한(타원꼴) 무한 랙**의 위쪽과 아래쪽을 번갈아 물어, 랙을 실은 막대를 곧게 왕복시킨다. 피니언 축은 홈이 파인 막대(홈 막대) 안에서 오르내리며 그 홈에 안내된다.
판화(public/mm507/fig/119.png, 4배 확대 `shots/_verify/119-fig-x4.png` 로 다시 읽음): 그림 하나(정면). 위아래에 가로 들보 두 개, 그 사이에 세로 막대 하나(가운데에 위가 열린 U 꼴의 긴 홈), 가운데 높이에 가로로 긴 타원 톱니판(둘레 전체에 **바깥으로** 이가 났다)과 그 양끝에서 좌우로 나온 둥근 막대, 톱니판 위 가운데(세로 막대 뒤)에 점선으로 그린 작은 피니언.

## ★ 판화 읽기
1. 바퀴(풀리·기어)는 몇 개이고 크기 차례는? → 기어 1개(작은 피니언, 점선). 판화 치수(4배 px): 이끝 반지름 ≈ 90, 이 수는 6~7개로 보인다. 그 밖에 바퀴가 아닌 **타원 무한 랙** 1개(길이 1120, 높이 400 — 곧은 변 위·아래 각각 이 9~10개, 양끝 반원에 7~8개씩).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 겹침만 있다: 세로 홈 막대가 랙 **앞**을 지나고(막대 두 세로선 사이에서 랙의 이가 끊겨 그려짐), 피니언은 그 막대 **뒤**(점선)에 있다. 축 끝만 홈을 지나 앞으로 나와 있다(홈 위쪽의 작은 원과 좌우로 삐져나온 가로 핀).
4. 고정점은? → 위 들보(양끝 물결선 = 더 이어지는 틀)와 아래 들보, 그리고 두 들보를 잇는 세로 홈 막대. 랙 막대의 안내(받침)는 그려져 있지 않다.
5. 추·손잡이·크랭크는? → 없음. 구동은 피니언(원문: uniform rotary motion of the pinion). 피니언 축을 돌리는 것은 판화에 없다.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 랙은 타원 고리의 **바깥 가장자리 전체**(위 변은 위로, 아래 변은 아래로, 양끝 반원은 바깥으로)에 이가 났다. 피니언은 판화에서 위 변의 한가운데를 **위에서** 문다. 랙이 끝까지 가면 피니언이 끝 반원을 타고 아래로 내려가 아래 변을 **아래에서** 문다.
7. 한 줄에 놓인 것은? → 세로 홈 막대의 가운데선 위에 피니언 축·홈이 놓인다(홈 위 끝 ≈ 피니언이 위 변에 있을 때의 축 자리, 홈 아래 끝 = 랙 아래 변 밑 — 피니언이 아래 변에 있을 때의 축 자리). 랙의 가운데선과 좌우 둥근 막대의 축선이 같은 높이. 판화 순간에는 피니언이 랙의 한가운데 위.
8. 글자가 가리키는 부품은? → 아래 들보에 작은 'c' 하나가 보이지만 원문에 글자 설명이 없다(인쇄 번짐이나 옆 그림 글자로 본다). 모형에는 쓰지 않는다.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 판화·원문이 같은 기구이고 그대로 계속 돈다. 치수만 손봤다(기구는 같다): 피니언 이 6~7개 → 8개(인벌류트 물림), 좌우 막대 끝 토막을 짧게(전시 폭), 홈 막대를 좁게(피니언 이가 보이게).
- 그 밖의 선: 랙 양끝의 작은 원 두 개씩 = 랙을 뒤의 막대에 고정하는 리벳(좌우 둥근 막대는 랙 뒤로 이어진 한 막대의 양끝 = 원문의 "랙을 싣는 막대"). 왼쪽 막대 끝의 타원 = 둥근 막대의 단면, 오른쪽 끝 사선 = 잘린 자리. 세로 막대의 오른쪽 굵은 선 = 그림자 쪽 모서리. 아래 들보의 겹선 = 들보 윗면(비스듬히 본 두께).

## 해석(결정 사항)
- 랙은 가로로만, 피니언 축은 세로(홈)로만 움직인다. 피니언이 끝 반원을 돌 때 축이 홈을 따라 내려가고(또는 올라가고) 그동안에도 랙은 계속 밀려 나갔다 돌아온다.
- 회전 방향: 반시계로 정함(판화에 없음). 피니언이 위에 있을 때 랙은 오른쪽으로, 아래에 있을 때 왼쪽으로 간다.
- 보충(판화에 없음): 랙 막대를 받치는 안내 받침 1개(랙 뒤 한가운데, 거의 가려짐). 그 밖에는 없다.

## 구동
피니언(theta 누적, 반시계): theta += OMEGA(1.6)·speed·dt. 한 주기 = 32.99 rad = 20.62 s (피니언이 이 42개 = 5.25바퀴).

## 부품과 치수 (모두 `kit/k119.ts`, 이미 구현됨. 치수 상수 `K119`)
배치 상수: CY = 1.72 (랙 가운데선 높이 = 홈 가운데), ZR = 0.1 (랙·피니언의 가운데 평면). 홈 막대의 가운데선은 x = 0.
- 모듈 0.04. 피니언 이 8개(피치 반지름 0.16, 이끝 0.2). 랙: 곧은 변 이 9개씩(길이 1.131), 끝 반원 이 8개씩(피치 반지름 0.32 = 이 16개 기어의 반쪽), 온 둘레 34개. 랙 이끝 높이 0.8·모듈(낮춤), 이뿌리 1.25·모듈.
- 랙(name `rack`): `oblongRack119()` — 랙 판(두께 0.08, 황동) + 뒤에 붙은 랙 막대(강철, 반높이 0.07, 두께 0.1, 랙 끝에서 0.2 씩 더 나옴) + 리벳 4개. 위치 (X(θ), CY, ZR). 판 윤곽 가로 ±0.914, 세로 ±0.352, 막대 끝 ±1.117. 랙 판 메시에 `userData.outline`.
- 피니언(name `pinion`): `manglePinion119(0.12, 0.18)` — 피니언(청동) + 축(반지름 0.045) + 홈 막대 앞뒤의 턱 고리 + 축 끝 가로 핀. 위치 (0, CY + y(θ), ZR), rotation.z = spin(θ). 돌려받은 그룹이 곧 기어 표식 — name 을 이 그룹에 붙인다.
- 홈 막대(고정): `slottedBar119(0.94, 0.94, 0.48, 0.22)` — 폭 0.22, 두께 0.06, 홈 반폭 0.048, 홈 양끝 반원 중심이 ±0.48. 위치 (0, CY, 0.25). 세로 범위 0.78 ~ 2.66. 위아래 끝의 볼트 머리가 들보 앞면에 놓인다.
- 들보 둘(고정): `frameBeam119(2.3, 0.22, 0.52)` — 위 들보 위치 (0, 2.58, −0.04), 아래 들보 위치 (0, 0.86, −0.04). 뒤판 앞면에 붙어 앞면이 홈 막대 뒷면(0.22)에 닿는다. 위 들보 아랫면 2.47 > 피니언 이끝 최고 2.40, 아래 들보 윗면 0.97 < 피니언 이끝 최저 1.04.
- 랙 막대 안내(고정, 판화에 없음): `barGuide119(0.304)` 위치 (0, CY, 0.004) — 뒤판에서 나온 받침 + 막대 위아래 턱. 가로 ±0.15. 랙 막대는 가로 ±0.07 구간을 항상 덮으므로 늘 받쳐진다.
- 받침대·뒤판 `displayStand()`.
- 전체 범위: 가로 −2.163 ~ 2.163(랙 막대 끝), 세로 0.75 ~ 2.69.

## 동작 (모두 theta 의 닫힌 식 — `mangle119(theta)` 가 { x, y, spin, phase, n } 을 돌려준다)
- 구간 각: 곧은 변 A = 길이/피치 반지름 = 7.069 rad, 끝 반원 B = π·(0.32 + 0.16)/0.16 = 9.425 rad. 주기 = 2A + 2B.
- u = (theta − 1.6 + A/2) 를 주기로 나눈 나머지. spin = (theta − 1.6 + A/2) − π/2 (u = 0 에서 이 하나가 곧장 아래 = 이음 자리의 이골).
- 0 ≤ u < A (위 변, phase 0): 랙 x = −0.565 + 0.16·u, 피니언 y = +0.48.
- A ≤ u < A + B (왼쪽 끝을 돎, phase 1): β = π/2 + (u − A)/3, 랙 x = 0.565 − 0.48·cos β, y = 0.48·sin β. β = π 에서 랙이 오른쪽 끝 +1.045.
- A + B ≤ u < 2A + B (아래 변, phase 2): 랙 x = 0.565 − 0.16·(u − A − B), y = −0.48.
- 그 뒤 (오른쪽 끝을 돎, phase 3): β = 3π/2 + (u − 2A − B)/3, 랙 x = −0.565 − 0.48·cos β, y = 0.48·sin β. 랙 왼쪽 끝 −1.045.
- 구간이 바뀌는 자리에서 랙 속도가 0.16·ω 로 이어진다(끝 반원에서도 피치원끼리 미끄럼 없이 구른다). 한 주기에 피니언 이 42개 = 랙 34개 + 피니언 한 바퀴 8개 → 정확히 닫힘.
- 시각: **t = 1 (판화 자세: 피니언이 위 변 한가운데, 랙 x = 0)**, t = 2 (랙 x = 0.256, 오른쪽으로 가는 중), t = 6.15 (왼쪽 끝 반원의 한가운데: 랙 x = 1.045, 피니언 y ≈ 0), t = 11.3 (아래 변 한가운데), t = 16 (오른쪽 끝을 도는 중).

## notes
① 상태 '위 변을 묾 → 랙 오른쪽으로 / 왼쪽 끝을 도는 중 / 아래 변을 묾 → 랙 왼쪽으로 / 오른쪽 끝을 도는 중' ② 랙 위치 'x = NN (행정 2.09 중)' ③ 잇수 '피니언 8, 랙 34(곧은 변 9 + 9, 끝 8 + 8)' ④ '피니언 5.25바퀴에 랙 한 번 왕복' ⑤ 피니언 축 높이(홈 안) 'NN %'.

## 확인
- t = 1 정면: 판화와 같은 모양(랙 한가운데 위에 피니언, 홈 막대가 랙 앞). t = 6.15: 랙이 오른쪽 끝, 피니언이 랙 왼쪽 끝 옆(홈 가운데). t = 11.3: 피니언이 랙 아래.
- 근접: 위 물림 `cam=0.9,2.5,1.6,0,2.1,0.1`, 끝 반원 물림(t = 6.15) `cam=-0.9,2.0,1.6,0.1,1.72,0.1`, 옆 `cam=3.6,1.7,0.3,0,1.7,0.1`(층: 랙 막대 → 랙·피니언 → 홈 막대 → 축 끝).
- 수치: `node shots/_verify/s119.mjs`(키트 식 그대로, 한 주기 4000 시각) → 피니언×랙 최대 침범 0.0000(네 구간 모두), 랙 x −1.0455 ~ 1.0455, 주기 닫힘 오차 6e−16, 피니언 이 42.000개. `s119b.mjs`: 위상을 0.02 rad 만 틀어도 침범 0.0017, 반 피치 틀면 0.042(검사가 살아 있음), 물림 틈 최대 0.0026.
- 눈으로: 축 끝(가로 핀)이 홈을 따라 오르내리는가, 랙이 끝에서 멈칫하지 않고 부드럽게 되돌아오는가.

모두 뒤판과 나란한 층이고 깊이로 지름이 나오는 부품은 없다. 랙 막대 z −0.046~0.054, 막대 안내의 턱 z −0.05~0.04, 랙 판·피니언 z 0.06~0.14, 홈 막대 z 0.22~0.28, 축 z 0.06~0.40(끝 가로 핀 z 0.36, 가로 길이 0.2). 들보는 뒤판 앞면에서 앞면 0.22 까지. 가장 앞 0.40 ≤ 0.8. 흔들리는 팔 없음 — 가장 높은 것은 위 들보 윗면 2.69, 랙 막대 끝은 가로 ±2.163 까지.
