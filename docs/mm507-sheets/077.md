# 077 두 개의 폴 래칫 구동 (핀 바퀴)
원문: 받침점 A 를 축으로 레버 C 가 흔들리면, **번갈아 작용하는 두 폴**이 바퀴 B 를 돌린다. 거의 연속적인 운동이다.
판화(public/mm507/fig/077.png, 4배 `shots/_verify/077-fig-x4.png`, 폴 끝 8배 `shots/_verify/077-pawls-x8.png`): 정면 그림 하나. 왼쪽에 큰 바퀴 B(테 + 십자 살 4개 + 허브, **테 앞면에 둥근 핀 24개**), 오른쪽에 세로 막대 C(레버), 그 가운데 A 가 받침점. 레버의 A 위·아래 두 구멍에서 가는 막대(폴) 두 개가 왼쪽으로 뻗어 바퀴 오른쪽 위의 핀 두 개(두 칸 떨어진 핀)를 끝의 갈고리 모양 자리로 덮고 있다. 바퀴 위의 화살표는 왼쪽(반시계).

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 1개(B). 이가 아니라 **테 앞면에 박힌 둥근 핀 24개**(판화에서 위 반 바퀴 13개 = 12칸, 아래 11개를 세었다 — 간격 15°)를 폴이 민다. 테 바깥 반지름 : 핀 원 : 테 안쪽 = 560 : 505 : 430(4배 판화 픽셀).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 두 폴은 레버 쪽에서 벌어져(위·아래 핀) 바퀴 쪽으로 가며 서로 닿지 않는다.
4. 고정점(천장·벽·바닥)은 어디인가? → 받침점 A(레버 가운데의 두 겹 원 = 고정 핀)와 바퀴 축. 판화에는 받침대가 없다(아래 가로선은 판 테두리).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 레버 C 가 아래로 길게 내려가 잘려 있다(손으로 잡고 흔드는 쪽). 추·크랭크 없음.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 이 없음. 핀은 테의 **앞면**에서 종이 앞으로 튀어나왔고, 두 폴이 **오른쪽 위(바퀴 중심에서 약 50° 와 25° 방향)** 에서 핀 위에 얹혀 왼쪽으로 민다. 폴 끝은 핀의 위와 왼쪽을 감싸고 오른쪽 아래가 트인 갈고리꼴 — 핀이 오른쪽 아래에서 들어와 앉는 **자리(오목한 미는 면 + 지붕)** 로 읽는다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 레버의 세 구멍(위 폴 핀, A, 아래 폴 핀)이 한 세로선. A 는 바퀴 중심보다 위(바퀴 반지름의 약 0.5배)에 있다.
8. 판화에 글자(A, B…)가 가리키는 부품은? → A = 레버 받침점, B = 바퀴, C = 레버. 화살표 = 바퀴 회전 방향(위에서 왼쪽 = 반시계).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문과 어긋나는 곳은 없음. 두 가지를 적어 둔다. (가) 폴 끝이 갈고리처럼 보여 "당기는 폴"로 읽을 수도 있으나, 당기면 바퀴가 시계로 돌아 화살표와 반대가 되고, 돌아갈 때 갈고리가 더 높은 다음 핀을 타고 넘을 수 없다(수치로 확인: 다음 핀이 갈고리보다 0.13 높다). 화살표대로 **미는 폴**이어야 계속 돈다. (나) 판화는 레버가 수직인데 두 폴이 다 핀에 앉아 있다 — 실제로는 두 폴이 함께 앉는 때는 행정이 바뀌는 순간(레버가 끝까지 기운 때)뿐이다. 모형은 그 순간을 t = 1 로 둔다.
- 그 밖의 선: 테의 두 겹 원 = 테의 안팎 가장자리, 살의 겹선 = 살의 모서리, 폴 막대의 겹선 = 납작한 막대의 두 모서리, A 의 겹원 = 받침 핀과 보스.

## 해석(결정 사항)
- 미는 폴 2개가 핀을 **번갈아 한 칸씩** 민다. 레버가 왼쪽으로 기울 때(위쪽이 왼쪽으로) 위 폴이 밀고, 돌아올 때 아래 폴이 민다. 한 왕복에 바퀴는 **정확히 핀 2칸(30°)**, 반시계.
- 쉬는 폴은 핀 위에 얹혀 물러난다: 밑면이 다음 핀을 타고 넘다가 핀이 자리에 들어오면 내려앉는다(핀에서 다음 핀으로 내려앉는 폭이 0.11 rad 로 크다 — 폴이 핀 원과 45° 로 만나기 때문. 키트가 떨어지는 속도만 제한해 한 프레임에 튀지 않게 한다).
- 헛걸음(LOST = 핀 간격의 0.1): 폴이 핀보다 조금 더 물러났다가 돌아오며 닿는다. 그래서 행정이 바뀔 때 바퀴가 잠깐(주기의 약 18%) 선다 — 원문의 "거의 연속".
- 레버 진폭과 아래 폴 길이는 "한 주기에 정확히 2칸 + 두 폴의 위상"을 만족하도록 키트가 푼다(`solve77`): **진폭 ±16.90°, 아래 폴 길이 0.8791**(판화 비 0.87 과 1% 차).

## 구동
레버 C(theta 가 왕복 위상). theta += OMEGA(1.6)·speed·dt, 레버 각 φ = 16.90°·sin(theta). 한 왕복 = 2π(3.93 s).

## 부품과 치수 (모두 키트 `kit/k077.ts`, 이미 구현됨. 값은 `K77` 상수)
바퀴 중심 O = (−0.55, 1.55). 아래 좌표에서 "O 기준"이라고 쓴 것은 여기에 더한다.
- 바퀴 B(name `wheelB`): `pinWheel77(0.2)` 를 (−0.55, 1.55, 0) 에. 테 바깥 반지름 0.95, 안쪽 0.73, 핀 원 반지름 0.86, 핀 반지름 0.04, 핀 24개(로컬 각 i·15°), 핀은 z 0.03 → 0.2 로 튀어나옴. 황동, 핀은 강철(6개마다 노란 표시).
- 바퀴 축: `shaftZ(-0.55, 1.55, 0.12, 0.05)` (뒤판에서 나온 축, 판화에 없음 — 받침).
- 레버 C(name `leverC`): `rockLever77(1.25, 0.11)` 를 받침점 A = (1.04, 2.025) 에, z = 0.06. 위 폴 핀은 A 에서 0.305 위, 아래 폴 핀은 0.34 아래, 손잡이는 1.25 아래까지(나무). 청동(구동).
- 받침 핀 A: `shaftZ(1.04, 2.025, 0.11, 0.03)` (뒤판에서 나온 핀, 판화에 없음 — 받침).
- 위 폴(name `pawlU`): `notchPawl77(K77.LU)` — 길이 1.132. z = 0.13.
- 아래 폴(name `pawlL`): `notchPawl77(solve77().LL)` — 길이 0.8791. z = 0.13.
- 폴 모양(둘 다 같음): 피벗 고리 → 곧은 막대(두께 0.04) → 끝에 핀 자리(반지름 0.04 의 오목한 1/4 원 = 미는 면, 그 위 지붕이 핀 중심 너머 0.05 까지). 강철.
- 받침대·뒤판 `displayStand()`.
- 가로 범위 x −1.50 ~ 1.45(레버 손잡이 끝이 흔들릴 때), 세로 y 0.60 ~ 2.50(바퀴 위 끝). 흔들리는 팔 끝의 최고 높이: 레버 위 끝 2.40, 손잡이 아래 끝은 y 0.78 ~ 0.83.

## 동작 (모두 theta 의 함수 — `state77(theta)` 가 한 번에 돌려준다)
`const s = state77(theta)`:
- 레버: rotation.z = s.phi (반시계 +, 0 = 수직).
- 바퀴: rotation.z = s.wheel (반시계로 쌓임. 한 주기에 정확히 30°).
- 위 폴: position = O + s.pivotU, rotation.z = s.psiU (약 179° ~ 186°). 아래 폴: position = O + s.pivotL, rotation.z = s.psiL (약 155° ~ 171°).
- s.pushing = 'U' | 'L' | null (지금 미는 폴), s.steps = 지금까지 넘긴 핀 칸 수.
- 주기 시간표(theta + 90° 를 한 주기 0 ~ 360° 로): 0° ~ 36° 헛걸음(바퀴 정지) → 36° ~ 180° **위 폴이 밂**(12.97°) → 180° ~ 207.5° 헛걸음 → 207.5° ~ 360° **아래 폴이 밂**(17.03°). 한 주기의 약 82% 동안 바퀴가 돈다.
- 폴 자세는 닫힌 식: 폴 각 = min(핀마다 [피벗에서 핀을 본 각 + 그 핀 때문에 들려야 하는 각]) — 미는 동안에는 핀 중심이 정확히 자리(피벗에서 폴 길이)에 있다.
- 시각: **t = 1.0**(theta 1.6, φ = +16.9° — 위 폴이 막 다 밀었고 아래 폴이 핀에 앉은 교대 순간. 판화처럼 두 폴이 다 핀에 걸림), **t = 1.6**(theta 2.56, φ = +9.3° 로 돌아오는 중, 아래 폴이 미는 한가운데), t = 3.0(반대쪽 교대 순간).

## 확인
- t=1 정면: 두 폴 끝이 다 핀을 덮고 있고 레버가 왼쪽으로 16.9° 기울어 있다. t=1.6 정면: 아래 폴이 핀을 밀고, 위 폴은 핀 위에 얹혀 오른쪽으로 물러나는 중. 바퀴 표시 핀이 반시계로 간다.
- 근접 `cam=0.3,2.3,1.6,0.15,2.1,0.1`(두 폴 끝과 핀), 옆 `cam=2.6,1.9,0.1,0.2,1.9,0.1`(층: 바퀴 테 → 핀 → 폴, 레버).
- 수치(이미 돌림): `npx esbuild src/mm507/kit/k077.ts --bundle --format=esm --external:three --outfile=shots/_verify/k077.bundle.mjs` 뒤 `node shots/_verify/s077b.mjs 77` → 핀 ↔ 폴 윤곽 최대 침범 0.0002(허용 0.004), 미는 동안 핀이 자리에서 벗어난 거리 0(1e-15), 한 주기에 바퀴 30.000°. `node shots/_verify/s077c.mjs` → 폴 각이 1/4000 주기에 0.0017 rad 넘게 튀지 않음(떨어짐 속도 제한 전 기하 자세는 0.11 rad 한 번에 떨어짐).
