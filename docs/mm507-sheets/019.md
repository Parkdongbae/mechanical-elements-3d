# 019 도르래 배열 (19)
판화: 들보 갈고리에 위쪽 큰 고정 도르래 F, 그 왼쪽 아래로 층층이 작은 도르래들이 계단식으로 내려가고(맨 왼쪽 도르래에서 비스듬한 줄이 바닥 쪽으로 늘어짐), 맨 아래에는 넓은 추 막대가 있고 막대 위에 작은 걸이들이 나란히 있다. 줄이 도르래마다 따로 감긴다. 원문: 줄마다 한 끝은 고정점에, 다른 끝은 앞 움직도르래의 중심에 매인 도르래 계에서는 이득이 2 를 움직도르래 수만큼 거듭 곱한 값이다(움직도르래 3개 → 8배).
구동: 오른쪽 줄 끝(F 를 넘어 내려온 자유 끝)을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 책의 규칙에 맞는 고전 연결로 읽는다. 움직도르래 m1, m2, m3 가 오른쪽 위에서 왼쪽 아래로 계단식으로 달리고, 줄 셋의 왼쪽 끝은 모두 들보에 매이고, 줄 2·3 의 오른쪽 끝은 바로 위 움직도르래의 아랫 눈에 맨다. 줄 1 은 m1 을 감은 뒤 F 를 넘어 자유 끝으로 간다. 짐(넓은 추 막대)은 m3 에 걸린다. 판화 아래의 작은 걸이들은 단순화해 추 막대만 둔다.

## 부품과 치수
016 의 `rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)를 쓴다. 파일이 없으면 016 의 '키트 추가' 대로 만든다. 줄 반지름 0.012, 줄 z = 0.22, 도르래 중심 z = 0.22, 모든 줄 3개와 별도 `Rope` 인스턴스.
- `displayStand()`
- 들보: `ceilingBeam(-0.8, 0.8, 3.0, [-0.48, -0.35, -0.22, 0.26])` → 고리 아랫점 y = 2.94. 앞 세 고리는 줄 3, 2, 1 의 고정 끝, 마지막은 F 걸이.
- 고정 도르래 F: `pulleyBlock(0.22, { hookUp: 0.06 })`, 중심 (0.26, 2.62). 윗 눈 (0.26, 2.90) 과 고리 (0.26, 2.94) 를 `rod`.
- 움직도르래(모두 반지름 0.13, 두께 0.05, spokes 3):
  - m1 `pulleyBlock(0.13, { hookDown: 0.06 })`, 중심 (−0.09, y1)
  - m2 `pulleyBlock(0.13, { hookDown: 0.06 })`, 중심 (−0.22, y2)
  - m3 `pulleyBlock(0.13, { hookDown: 0.06 })`, 중심 (−0.35, y3)
  (줄이 아랫 눈에 매이므로 윗 눈은 없다. 줄이 바퀴 위쪽을 지나지 않는다.)
- 추 막대: `weight(0.70, 0.20)`, 중심 (−0.35, y3 − 0.37). m3 아랫 눈 (−0.35, y3 − 0.19) 에서 막대 윗면 (−0.35, y3 − 0.27) 까지 `rod`.
- 자유 끝에 `ropeEnd()`.

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `u = 0.08 × p` (짐이 오른 높이).
- y3 = 0.80 + u
- y2 = 1.40 + 2u
- y1 = 1.80 + 4u
- yF = 1.95 − 8u (자유 끝; 시작 1.95, 끝 1.31)

### 줄 경로 (z = 0.22, `arcPoints(c, r, a0, a1, 0.22)`, a1 < a0 이면 시계방향)
- 줄 3: (−0.48, 2.94) → (−0.48, y3) → `arcPoints([−0.35, y3], 0.13, π, 2π)` → (−0.22, y3) → (−0.22, y2 − 0.19) [m2 아랫 눈].
- 줄 2: (−0.35, 2.94) → (−0.35, y2) → `arcPoints([−0.22, y2], 0.13, π, 2π)` → (−0.09, y2) → (−0.09, y1 − 0.19) [m1 아랫 눈].
- 줄 1: (−0.22, 2.94) → (−0.22, y1) → `arcPoints([−0.09, y1], 0.13, π, 2π)` → (0.04, y1) → (0.04, 2.62) → `arcPoints([0.26, 2.62], 0.22, π, 0)` → (0.48, 2.62) → (0.48, yF).

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, u, y1~y3, yF 재계산.
- 도르래 각(`userData.sheave.rotation.z`, 반시계 +):
  - θ_m3 = +u / 0.13
  - θ_m2 = +2u / 0.13
  - θ_m1 = +4u / 0.13
  - θ_F = −8u / 0.22 (시계)
  (각 줄의 왼쪽 가닥이 들보에 고정이라 움직도르래가 그 가닥을 타고 구르며 오른다. 위로 갈수록 두 배씩 빠르다.)
- 힘의 이득 8 = 2³: 자유 끝이 8u 내려갈 때 짐이 u 오른다.

## 표시
- `rotArrow(0.3, false)` 를 F 앞 (0.26, 2.62, 0.40).
- tag 'F 고정 도르래', 'm1', 'm2', 'm3'(각 움직도르래 왼쪽 0.3 바깥), '짐', '당기는 곳'. 매 프레임 따라감.
- notes: `[{ label: '이득', value: '8배 (2×2×2)' }, { label: '움직도르래', value: '3개' }, { label: '당긴 줄 : 오른 높이', value: (8u).toFixed(2) + ' : ' + u.toFixed(2) }]`

## 확인
- t=0.4 (p ≈ 0): m1~m3 가 계단식으로 낮고 간격이 좁다. t=3.9 (p ≈ 1): m3 가 0.08, m2 가 0.16, m1 이 0.32 올라가 간격이 벌어지고 자유 끝은 0.64 내려간다.
- 각 줄의 오른쪽 올라가는 가닥이 위 움직도르래 아랫 눈에 정확히 이어진다. 줄이 서로 겹쳐 박히지 않는다(모든 수직 가닥의 x 가 다르다).
