# 019 도르래 배열 (19)

판화(`public/mm507/fig/019.png`, 확대해 줄을 하나씩 따라간 결과):
- 천장 고리에 큰 고정 도르래 **A** 가 매달려 있다. 그 왼쪽 아래로 **B**, 다시 왼쪽 아래로 **C** 가 층층이 놓인다(A > B > C).
- 맨 아래에는 **넓은 추 하나** 위에 작은 도르래 3개(**D1·D2·D3**, 왼쪽부터)가 짧은 자루로 나란히 서 있다.
- 줄은 3개이고 모두 같은 방식으로 걸린다: **위 블록의 아랫 눈(띠쇠 끝)에 매여 → 곧게 내려와 짐 도르래 밑을 왼쪽에서 오른쪽으로 감고 → 올라가 그 위 도르래를 오른쪽에서 왼쪽으로 넘어 → 왼쪽 가닥이 다음 블록의 중심(윗 눈)에 매인다.**
  - 줄 1: A 아랫 눈(고정점) → D3 밑 → A 위 → B 윗 눈
  - 줄 2: B 아랫 눈 → D2 밑 → B 위 → C 윗 눈
  - 줄 3: C 아랫 눈 → D1 밑 → C 위 → 왼쪽 아래로 비스듬히 나가 손(당기는 곳)
- 판화의 세로 가닥 7개(왼쪽부터): C 아랫 눈–D1 왼쪽, D1 오른쪽–C 오른쪽, B 아랫 눈–D2 왼쪽, D2 오른쪽–B 오른쪽, A 아랫 눈–D3 왼쪽, D3 오른쪽–A 오른쪽, 그리고 위쪽의 A 왼쪽–B, B 왼쪽–C.

원문(19~22 공용 문단): "각 도르래가 줄에 감싸이고 그 줄의 한 끝은 고정점에, 다른 끝은 움직도르래의 중심에 매인 계에서는 효과가 2 를 움직도르래 수만큼 거듭 곱한 값." — 줄마다 한 끝이 도르래 중심(B·C 의 윗 눈)에 매인다는 구조는 판화와 같다. 다만 19번 판화는 줄의 다른 끝이 들보가 아니라 **자기 블록의 아랫 눈**에 매이고 가운데가 **짐 도르래**를 감으므로 한 단마다 3배가 된다(20·21번이 2ⁿ − 1 인 것과 같은 사정).

## 힘과 속도 (곧게 내려 당길 때)
- 줄 3 의 힘 T. C 는 줄 3 의 세 가닥(손 쪽, 오른쪽, 아랫 눈)에 끌리므로 줄 2 의 힘 = 3T. 같은 이유로 줄 1 = 9T.
- 짐: D1 이 2T, D2 가 6T, D3 가 18T → **26T = 3³ − 1**.
- 짐이 u 오를 때: B 는 2u 내려오고, C 는 8u 내려오고, 줄 3 은 C 를 18u 지나간다 → 손은 26u.
- 도르래를 지나간 줄 길이: D3 u, A 2u, D2 3u, B 6u, D1 9u, C 18u (모두 반시계).
- 판화처럼 손 줄이 수직에서 25° 기울면 손이 줄 방향으로 움직인 거리 = (18 + 8·cos25°)u = 25.25u → 이득 약 25배. (비스듬히 당기면 C 가 옆으로 끌리지만, 판화처럼 C 는 제자리에서 오르내리는 것으로 그린다.)

## 부품과 치수 (줄·도르래 중심 면 z = 0.22, 줄 반지름 0.012, 줄 중심선 반지름 = 도르래 반지름)
