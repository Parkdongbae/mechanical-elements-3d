# 090 편심 요크 변형
원문: 89번을 바꾼 것. 둥근 띠 대신 **길쭉한 요크**를 써서, 고정 안내 안에서 움직이는 막대가 옆으로 흔들릴(vibrating) 필요를 없앤다. (글자·수치 없음)

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/090-fig-x4.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 기어·풀리는 없다. 둥근 **편심 원판 1개**(판화에서 반지름 305 px, 살을 파지 않은 민짜)와 세로로 긴 **요크(틀) 1개**. 축(빗금 원, 반지름 95 px)은 원판 중심에서 왼쪽으로 155 px 어긋남(편심량 : 원판 반지름 = 0.51). 축 둘레 허브 고리 반지름 125 px.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 없다. 축 단면만 그렸고, 원문의 "고정 안내(fixed guides)"는 그리지 않았다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 축에 고정된 편심 원판.
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 이는 없다. 맞닿는 짝은 **원판 둘레 ↔ 요크 긴 구멍의 왼쪽·오른쪽 안벽**(원판이 구멍의 가로 폭에 꼭 맞는다: 구멍 안쪽 폭 600 px, 원판 지름 610 px). 구멍의 위·아래는 원판에서 멀리 떨어져 있다(구멍 안쪽 반높이 562 px, 원판은 위아래로 ±155 px 만 오르내림). 요크 좌우 한가운데에서 가로 막대가 하나씩 뻗는다(왼쪽은 짧은 끝, 오른쪽은 잘린 끝 — 밸브 쪽으로 이어짐).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 축 중심, 원판 중심, 좌우 막대가 한 가로줄. 원판 중심과 요크 중심이 같은 세로선(판화의 순간은 편심이 오른쪽, 곧 요크가 가장 오른쪽).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음(기구는 같다). 판화의 구멍 옆벽은 살짝 굽은 타원처럼 그려졌는데, 굽으면 원판이 오르내릴 때 끼므로 옆벽은 곧은 세로선(스타디움 꼴)으로 만든다 — 그림 솜씨의 차이로 본다.
- 그 밖의 선: 요크의 두 겹 윤곽 = 테의 안·밖 가장자리. 축 둘레 두 겹 원 = 허브 고리.

## 해석(결정 사항)
- 스카치 요크의 편심판 꼴: 원판 중심의 가로 성분만 요크에 전해지고 세로 성분은 긴 구멍 안에서 헛돈다 → 요크와 막대는 흔들림 없이 **가로로만** 단순 조화 왕복(x = e·cos θ).
- 원문의 고정 안내는 좌우 막대에 하나씩 보충(판화에 없음).

## 구동
축. theta += OMEGA(1.6)·speed·dt, θe = theta − 1.6 (t = 1 에서 θe = 0 — 판화 자세). 반시계.

## 부품과 치수
공통: 기구 평면 z = ZP = 0.1. 축 중심 O = (0, 1.75). 편심량 e = 0.25, 원판 반지름 R = 0.5.
- 축: `shaftZ(0, 1.75, 0.3, 0.13)`.
- 편심 원판(name `sheave`): `eccentricSheave(0.5, 0.25, { rim: 0, bore: 0.13, hubR: 0.19 })` 위치 (0, 1.75, 0.1). 민짜 원판, 두께 0.12, 청동.
- 요크(name `yoke`): `slotYoke(0.502, 0.42)` — 긴 구멍 반폭 0.502(틈 0.002), 곧은 옆벽 반길이 0.42(≥ e 0.25), 구멍 반높이 0.922, 테 폭 0.15(바깥 반폭 0.652, 반높이 1.072), 왼 막대 끝 로컬 x −1.5, 오른 막대 끝 +1.65, 막대 높이 0.14·두께 0.096. 황동 테 + 강 막대. 위치 (xY, 1.75, 0.1).
- 안내 2개(name `guideL`, `guideR`, **판화에 없음** — 원문 fixed guides): `rodGuide('x', { w: 0.14, h: 0.096 }, 0.1)` 위치 (−1.1, 1.75, 0.1), (1.1, 1.75, 0.1) — x ±1.03~±1.17, 기둥이 뒤판까지.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통).
- 범위: 요크 테 바깥 x ±0.902 이내(안내 1.03 앞), 왼 막대 끝 −1.75~−1.25(항상 안내 −1.17 밖), 오른 막대 끝 1.4~1.9(항상 안내 1.17 밖, ≤ 2.2), 높이 y 0.678~2.822.

## 동작 (모두 θe 의 닫힌 식)
- `sheave.rotation.z = θe`.
- `yoke.position.x = 0.25·cos θe` (y·z 고정, 회전 없음). 원판 중심의 요크 로컬 좌표 = (0, 0.25·sin θe) — 긴 구멍 안에서 ±0.25 오르내림.
- 한 바퀴 3.927 s 에 왕복 한 번, 행정 0.5 = 2e. 시각: **t = 1.0 (θe 0°, 판화 — 요크 가장 오른쪽 +0.25, 원판이 구멍 한가운데 높이)**, **t = 1.6 (θe 55°, 요크 +0.143, 원판이 구멍 안에서 0.205 위)**, t = 2.96 (θe 180°, 가장 왼쪽).

## 표시

- tag 4개: '편심 원판' (−0.75, 2.95, 0.3), '길쭉한 요크(원판이 안에서 위아래로 미끄러짐)' (0.6, 3.05, 0.3), '막대(흔들림 없이 가로로만 왕복)' (1.55, 2.1, 0.3), '고정 안내' (−1.3, 1.3, 0.3).
- notes: ① '요크 위치 = 편심량 × cos(회전각)' ② 지금 요크 위치(±0.25) ③ '행정 0.5 = 편심량의 2배' ④ 구동 회전수.

## 확인
- t=1 정면: 판화와 같은 모양 — 축이 원판 왼쪽, 원판이 긴 구멍 가로 폭에 꼭 맞고 위아래는 빔, 좌우로 가로 막대. t=1.6 정면: 원판이 구멍 안에서 위로 올라가고 요크는 왼쪽으로 조금 옴.
- 근접 `cam=0,1.75,2.6,0,1.75,0.1`(원판·구멍 옆벽), `cam=1.4,2.2,1.4,1.1,1.75,0.1`(막대·안내), 옆 `cam=3.5,1.75,0.1,0,1.75,0.1`.
- 수치: `node shots/_verify/s089.mjs` → 원판–긴 구멍 최소 여유 0.0020(침범 0).
