# 028 브러시 휠 (마찰 바퀴)
판화: 가운데에 **수평 원판**(옆에서 본 얇고 넓은 판), 그 밑이 나팔처럼 벌어진 허브를 거쳐 **수직축**이 아래로 내려감. 원판 위 오른쪽에 **작은 바퀴**가 올라앉아 있고, 그 바퀴를 **수평 축**(판화에서 좌우 방향)이 꿰뚫어 양쪽으로 나와 있다. 작은 바퀴의 아랫가장자리가 원판 윗면에 눌려 닿고, 닿는 점은 원판 중심에서 오른쪽으로 떨어져 있다. 원문: 윗바퀴를 원판 중심에서 떨어뜨리는 거리를 바꾸면 상대 속도가 바뀐다. 마찰로 구동되며 원판에 고무를 씌우면 마찰이 커진다.
구동: 수평 원판(수직축). 작은 바퀴가 마찰로 따라 돈다. 작은 바퀴는 **자기 축을 따라 미끄러져**(축은 고정, 바퀴가 키 홈으로 미끄러짐) 원판 중심에서의 거리 ρ 를 바꾼다. ρ 가 0 이 되면 작은 바퀴가 멈추고, 중심 반대쪽(ρ < 0)으로 넘어가면 반대로 돈다.

## 부품과 치수 (키트 추가 없음 — 부품은 모델 파일에서 geom 도구로 직접 만든다)
- `displayStand()`
- 기구 평면 z = **Zd = 0.17**(원판 중심선 z). 원판 반지름 0.42 라 z −0.25 ~ 0.59.
- **원판 피벗 `disc`**: 위치 (Dx, 0, Zd) = (**−0.30**, 0, 0.17), `rotation.y = θ`. 자식(피벗 로컬, y 는 세계 높이 그대로):
  - 판: `lathe(tubeProfile(0.047, 0.42, 1.53, 1.59, 0.006), 64)` bronze({ roughness: 0.34 }) (구동이라 bronze).
  - 고무 덮개: `lathe(tubeProfile(0.09, 0.405, 1.59, 1.60, 0.002), 64)` `rubber()` — 윗면이 정확히 y = 1.60.
  - 나팔 허브: `lathe(profile, 40)` darkSteel, profile(반지름, y) = [[0.05, 1.28], [0.085, 1.28], [0.09, 1.36], [0.13, 1.47], [0.19, 1.53], [0.05, 1.53], [0.05, 1.28]].
  - 수직축: `rod(V3(0, 0.28, 0), V3(0, 1.50, 0), 0.04)` (허브 구멍 0.05 안, 위 끝은 판 안).
  - 고무 위 표시줄 4개: `BoxGeometry(0.30, 0.004, 0.014)` paint(0xf2b619)(k = 0 인 것은 paint(0xd8362f)), 중심 로컬 (0.25·cos(kπ/2), 1.602, −0.25·sin(kπ/2)), `rotation.y = kπ/2` (k = 0..3). 반지름 0.10 ~ 0.40 에 걸쳐 방사형.
- 아랫받침(고정): 계단 베어링 `BoxGeometry(0.20, 0.10, 0.20)` castIron 중심 (−0.30, 0.23, 0.17)(받침 윗면 0.18 에서 0.28 까지, 축 아래 끝 0.28 이 얹힘). 가운데 브래킷(y = 0.95): `BoxGeometry(0.20, 0.12, 0.405)` castIron 중심 (−0.30, 0.95, −0.0975)(z −0.30 ~ 0.105) + 고리 `lathe(tubeProfile(0.045, 0.075, −0.06, 0.06, 0.01), 36)` darkSteel 중심 (−0.30, 0.95, 0.17) (축 = Y).
- **작은 바퀴 축**(수평, X 방향): 높이 **y = 1.75**, z = 0.17. 그룹 `axle` 위치 (−0.30, 1.75, 0.17), `rotation.x = φw`. 자식: `rod(V3(−0.55, 0, 0), V3(0.60, 0, 0), 0.04)`(세계 x −0.85 ~ 0.30), 표시 깃 `BoxGeometry(0.02, 0.10, 0.02)` paint(0xf2b619) 로컬 (−0.31, 0.05, 0). 받침: `pillow(−0.75, 1.75 − PILLOW_BOSS_Y, 0.17, 'x')`, `pillow(0.25, 1.75 − PILLOW_BOSS_Y, 0.17, 'x')` (`PILLOW_BOSS_Y` 는 shaft.ts 에서 import). 축 끝 0.30 은 오른쪽 필로를 지나 0.05 나온다.
- **작은 바퀴 `wheel`**: `pulley(0.15, { width: 0.08, spokes: 4, flat: true })` + 미끄럼 슬리브(허브) `lathe(tubeProfile(0.04, 0.06, −0.06, 0.06, 0.005), 24)` darkSteel 을 `rotateX(π/2)` 해서 같은 그룹에 넣는다(길이 0.12, 바퀴 가운데). 그룹 위치 (Dx + ρ, 1.75, 0.17), 방향(쿼터니언) = `setFromAxisAngle(X, φw) × QY90` — QY90 = Y 축 +90° 회전(007 처럼, 로컬 Z → 세계 +X).
  - 바퀴 아랫점 y = 1.75 − 0.15 = 1.60 = 고무 윗면 — 눌려 닿는다.

## 동작 (theta += OMEGA × speed × dt, OMEGA = 1.6, 원판 구동)
- 원판: `disc.rotation.y = θ` (+Y 둘레 양의 회전 = 위에서 볼 때 반시계).
- 윗바퀴 위치(원판 중심에서 오른쪽(+X)으로의 거리, 부호 있음): `ρ(θ) = 0.07 + 0.25·cos(κθ)`, **κ = 0.4** → ρ ∈ [−0.18, 0.32](한 주기 θ = 2π/0.4 = 15.7 rad ≈ 9.8 s). 바퀴 가운데 x = Dx + ρ ∈ [−0.48, 0.02] (바퀴가 원판 가장자리 0.42 안에 머문다: 0.32 + 0.04 < 0.42, 반대쪽 −0.18 − 0.04 > −0.42).
- 작은 바퀴 각: 접촉점에서 원판 표면 속도 = ω·ρ(−Z 방향, ρ > 0 일 때), 바퀴 아랫점 속도 = ωw·rw(−Z) 이므로 ωw = ω·ρ / rw, rw = 0.15, 부호 같음(+X 둘레 양의 회전). 적분 닫힌 형태(절대 각):
  `φw(θ) = [0.07·θ + (0.25/κ)·sin(κθ)] / 0.15`.
  `axle.rotation.x = φw`, wheel 의 쿼터니언도 같은 φw. 바퀴·축은 같은 각으로 함께 돈다(키로 연결).
- 속도비(윗바퀴 / 원판) = ρ/0.15: ρ = 0.32 → 2.13, ρ = 0.07 → 0.47, ρ = 0 → 0(멈춤, θ ≈ 4.6 rad, t ≈ 2.9 s), ρ = −0.18 → −1.2(역회전, t ≈ 4.9 s).
- 모든 자세 θ 의 절대 함수(상태 없음). speed 음수면 역으로 되돌아간다.

## 표시
- `rotArrow(0.30, true)` — 윗바퀴(꼭대기 y 1.90)보다 위에 띄운 수평 화살표(세계 (−0.30, 2.10, 0.17)), `rotation.x = −π/2` (로컬 +Z → +Y: 위에서 보아 반시계 = 원판 구동 방향). 바퀴와 겹치지 않게 반드시 y ≥ 2.0.
- tag '수평 원판(구동)' (−0.30, 1.30, 0.62), '윗바퀴(미끄러짐)' (0.45, 1.95, 0.4), '고무 덮개' (−0.95, 1.55, 0.5), '수직축' (−0.30, 0.65, 0.5).
- notes: `[{ label: '윗바퀴 위치 ρ', value: ρ.toFixed(2) }, { label: '속도비 (윗바퀴 : 원판)', value: (ρ/0.15).toFixed(2) }, { label: '윗바퀴 방향', value: ρ > 0.01 ? '원판과 같은 쪽' : ρ < -0.01 ? '반대로 돎' : '멈춤' }]`.
- view: `{ pos: [0.9, 3.2, 3.8], target: [-0.2, 1.4, 0.17] }` — 위에서 비스듬히 원판 윗면(고무 · 표시줄)과 접촉점이 보이게. 판화의 옆모습은 `cam=0,1.5,6.5,0,1.5,0`.

## 확인
- t = 0(ρ = 0.32), t = 2.9(ρ ≈ 0), t = 4.9(ρ = −0.18) 세 장: 윗바퀴가 축을 따라 오른쪽 → 중심 위 근처 → 왼쪽으로 옮겨 가 있다. 원판 표시줄은 매번 달라지고, t=2.9 근처에서는 윗바퀴 깃이 거의 제자리에 있다가 t=4.9 에는 반대 방향으로 돈 흔적(`φw` 가 줄어듦)이 있다.
- 윗바퀴 아랫점이 고무 윗면에 닿되 파고들지 않는다(1.60). 윗바퀴가 판 가장자리 밖으로 나가지 않는다. 슬리브가 오른쪽 필로(x 0.188 ~ 0.312)나 왼쪽 필로(−0.812 ~ −0.688)에 닿지 않는다(바퀴 슬리브 범위 x −0.54 ~ 0.08).
- 원판이 뒤판(z = −0.30)과 필로에 안 닿는다(원판 z −0.25 ~ 0.59). 화살표가 윗바퀴와 겹치지 않는다(y 2.10).
- 불확실: 판화에서 윗바퀴를 미는 장치(포크)는 보이지 않아 생략하고 윗바퀴가 키 달린 축 위를 미끄러진다고 보았다.
