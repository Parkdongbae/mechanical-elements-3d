# 234 버지 탈진기
원문: "Represents a verge escapement. On oscillating the spindle, S, the crown-wheel has an intermittent rotary motion." — 버지 탈진기를 나타낸다. 스핀들 S 를 흔들면 크라운 휠이 간헐 회전 운동(멈췄다 돌기)을 한다. 쉬운 풀이: 막대(스핀들)가 앞뒤로 흔들리면서 왕관 모양 톱니바퀴의 이를 하나씩 놓아 주거나 막는다. 그래서 바퀴는 한 칸씩 끊어지며 돈다. 옛 시계에 쓰인 장치이다.
판화 묘사(원본 479×454 px, [x·y]): 위에서 비스듬히 내려다본 그림. 가운데 납작한 원판(크라운 휠, 타원으로 보임, 가로 약 240 px) 둘레에 위로 솟은 톱날 이(옆으로 기운 톱니 — 한쪽 면이 곧고 한쪽이 비탈), 원판 가운데 구멍, 밑으로 곧은 축이 내려감. 원판 위를 가로질러 긴 막대 S(스핀들, 위 왼쪽 [105·105] → 아래 오른쪽 [415·268], 원판 이끝보다 위)가 지나고, 막대에 붙은 작은 판 둘(둘 다 글자 A)이 아래로 내려와, 하나는 원판 **뒤 왼쪽** 이([190·150] 근처)에, 다른 하나는 **앞 오른쪽** 이([310·210] 근처)에 닿는다 — 원판 지름의 양 끝.

## ★ 판화 읽기
판화는 비스듬한 그림이라 길이는 비율로만 읽는다. 크라운 휠 이끝 반지름을 0.495 로 정함. 크라운 휠 축은 **세로(Y)**, 스핀들은 **수평**. 장치 묶음(name `verge`)의 원점 = 크라운 휠 축과 받침대 윗면 아래 연장선의 만남, 세계 위치 (−0.05, 0, 0.27), `rotation.y = −20°`(스핀들이 왼쪽 뒤 → 오른쪽 앞으로 비스듬히 — 판화와 같은 방향). 아래 좌표는 이 묶음의 로컬(X = 스핀들 방향, Y = 위, Z = X 에 수직 수평).
1. 바퀴는 몇 개이고 크기 차례는? → 크라운 휠 1개(이 13개 — 버지는 홀수여야 두 팔레트가 번갈아 문다, 이끝 반지름 0.495, 이 높이 0.12).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 스핀들이 크라운 휠 위 0.10 높이로 지름을 가로지름.
4. 고정점은? → 크라운 휠 축(받침대 위 태엽 상자에 꽂힘), 스핀들 양 끝 근처의 기둥 둘(로컬 x ±0.72, 받침대에 섬).
5. 추·손잡이·크랭크는? → 판화에 없음. 스핀들을 흔드는 것으로 **흔들이 막대(폴리오트: 세로 막대 + 양 끝 추)** 를 스핀들 왼쪽 끝(로컬 x −0.86)에, 바퀴를 늘 돌리려는 **태엽 상자**를 축 밑에 보충.
6. 이는 어느 가장자리에, 무엇이 어느 쪽에서 무는가? → 크라운 휠 테 **윗가장자리**에 위로 솟은 톱날 이. 곧은 면이 바퀴가 도는 쪽(앞)을 본다. 두 팔레트(A)는 스핀들에서 아래로 내려온 판으로, 앞 오른쪽 팔레트(로컬 x +0.48)는 그 자리에서 +Z 로 움직이는 이를, 뒤 왼쪽 팔레트(x −0.48)는 −Z 로 움직이는 이를 막는다(지름 양 끝의 이는 서로 반대로 움직임). 두 팔레트는 스핀들 둘레로 100° 벌어져 있다.
7. 한 줄에 놓인 것은? → 두 팔레트와 크라운 휠 축이 스핀들 한 직선 위(지름 양 끝). 스핀들은 휠 축 바로 위를 지남.
8. 글자가 가리키는 부품은? → S = 스핀들, A = 팔레트(둘 다 A).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 판화엔 스핀들을 받치는 것·흔드는 것·바퀴를 돌리는 것이 없다 → 기둥 둘, 흔들이 막대, 태엽 상자 보충. 이 수는 판화로 셀 수 없어(앞쪽 절반에 6~7개) 홀수 13. → ★질문 거리.

## 해석(결정 사항)
- 스핀들 각 σ(t) = 40°·sin(πt)(주기 2.0 초). 팔레트 1(앞 오른쪽)은 스핀들 둘레 +50°, 팔레트 2(뒤 왼쪽)는 −50° 에 붙어 함께 돈다(둘 사이 100°).
- 바퀴는 태엽에 늘 밀리는 것으로 보고, 매 순간 **팔레트에 닿을 때까지 가장 많이 나아간 각**을 쓴다(밀려나면 밀린 만큼 뒤로). 파이썬(shapely)으로 이 끝 자리를 (Z, Y) 평면에 펴서(테 안쪽 0.465 와 바깥쪽 0.495 두 반지름 모두) 0.01 초마다 따라가 한 주기를 표로 만들었다: 한 주기에 정확히 **이 하나 27.692°** 나아가고, 반 주기마다 '툭' 10.35° 떨어진 뒤 약 9.7° **되밀린다**(버지 탈진기의 특징).
- 팔레트 판 모서리는 0.006 둥글림.

## 구동
σ = 40·sin(π·t)(도), 스핀들 `rotation.x = −σ·π/180`(로컬 X 축 둘레, +σ 이면 팔레트 아래끝이 +Z 쪽으로). 크라운 휠 각 φ(t) = 13.9 + f(t mod 2) + 27.6923·floor(t/2)(도, 로컬 +X 에서 +Z 쪽으로 +), 크라운 휠 `rotation.y = −φ·π/180`.
