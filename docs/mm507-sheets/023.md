# 023 움직이는 풀리 전동
판화: 왼쪽에 큰 구동 풀리 D, 오른쪽 아래에 중간 크기의 움직이는 풀리 P(위아래로 위치를 바꿈). 벨트는 D 와 P 를 잇는데, 두 풀리 사이 위쪽 가운데에 작은 풀리 A 가 있어 벨트가 A 윗점에서 만나는 것처럼 그려져 있다. A 의 가운데에서 줄이 위로 올라가 작은 안내 풀리 B 를 지나 가로로 건너가 또 하나의 B 를 넘어 아래로 내려와 균형추 C(어두운 상자)를 매단다.
구동: D 를 일정하게 돌린다(시계). P 는 느리게 위아래로 오가고, 그때마다 A 가 오르내려 벨트가 늘 팽팽하다.

읽기(한 줄): 판화는 두 줄이 모두 A 윗점에서 만나게 그렸지만 풀리 하나가 서로 반대로 가는 두 가닥을 한꺼번에 굴릴 수 없으므로, A 를 D–A–P 세 풀리를 감아 도는 볼록한 삼각형 벨트의 위 꼭짓점에 놓인 장력 풀리로 읽는다(세 풀리 모두 시계, 벨트는 바깥을 감는다). 균형추 C 가 A 를 위로 당기므로 P 가 움직여 벨트 경로 길이가 변해도 A 가 스스로 오르내려 벨트 길이가 일정하다.

## 부품과 치수
`beltPathAround`, `Belt`, `planar`, `pulley`, `shaftZ`, `Rope`, `arcPoints`, `weight`, `rotArrow`, `tag`, `rod`. 상수 `Z = 0.22`(벨트·풀리 중심 z), `ZR = 0.40`(A 의 줄·B 풀리·C 의 z). 벨트 경로 반지름 = 풀리 r + 0.01.
- `displayStand()`
- D: `pulley(0.37, { driver: true, spokes: 6 })`, 중심 (−1.31, 1.98, Z). 축 `shaftZ(−1.31, 1.98, 0.36, 0.055)`. 벨트 반지름 rbD = 0.38.
- P: `pulley(0.30, { spokes: 5 })`, 중심 (0.82, yP, Z), yP = 1.08 + 0.16·sin(theta × 0.5). 축 `shaftZ(0.82, 0, 0.36, 0.045)` 의 그룹 position 을 (0.82, yP, 0) 으로 매 프레임 옮긴다. 안내 홈: castIron 상자(`BoxGeometry(0.03, 0.9, 0.04)`) 두 개를 x = 0.82 ± 0.13, 중심 y = 1.08, z = −0.24 에 세워 둔다(축 보스 반지름 0.108 이 닿지 않는다). rbP = 0.31.
- A: `pulley(0.155, { spokes: 4 })`, 중심 (0.33, yA, Z). 축 `shaftZ(0.33, 0, 0.36, 0.024)` 의 그룹 position 을 (0.33, yA, 0) 으로 매 프레임 옮긴다. 안내 홈: 같은 상자 두 개를 x = 0.33 ± 0.08, 중심 y = 2.2, z = −0.24 (길이 0.9). rbA = 0.165.
- 벨트: `new Belt(planar(beltPathAround(circles, 24), Z))` (기본 로프 벨트), `circles = [{c:[−1.31,1.98], r:0.38, ccw:false}, {c:[0.33,yA], r:0.165, ccw:false}, {c:[0.82,yP], r:0.31, ccw:false}]` (D→A→P 순서, 전부 시계 = 바깥 접선). 매 프레임 `belt.setPath(planar(beltPathAround(circles, 24), Z))`, 점 개수는 항상 같다.
- B 풀리 2개(고정): `pulley(0.09, { width: 0.06, spokes: 3, grooved: true })`, 중심 B1 (0.42, 2.85, ZR), B2 (1.38, 2.85, ZR). 축 `shaftZ(0.42, 2.85, 0.46, 0.025)`, `shaftZ(1.38, 2.85, 0.46, 0.025)`.
- 줄: `new Rope(0.014)`, z = ZR. C: `weight(0.30, 0.26)` 중심 (1.47, yC), z = ZR. (줄 끝은 추 윗면 위 (1.47, yC + 0.22).)

### 변수와 A 의 높이 풀이 (벨트 길이 일정)
- 벨트 둘레 `perim(yA, yP)` = `beltPathAround(circles, 8)` 점열의 닫힌 길이(이웃 점 거리 합 + 마지막→처음). 시작 길이 L0 = perim(2.19, 1.08) (한 번만 계산).
- 매 프레임: yP 를 구한 뒤 `perim(y, yP) = L0` 가 되는 y 를 [1.70, 2.75] 에서 이분법(30회)으로 찾아 yA 로 쓴다(y 가 오르면 둘레가 늘어나는 단조 구간). 못 풀면 구간 끝값으로 클램프.
- yC = 4.17 − yA (줄 길이 보존: 줄의 A 쪽 수직 (2.85 − yA)와 C 쪽 수직 (2.85 − yC − 0.22)의 합이 일정 → A 가 δ 오르면 C 가 δ 내려간다. 시작 yA = 2.19 → yC = 1.98).

### 줄 경로 (z = ZR)
(0.33, yA, ZR) → (0.33, 2.85, ZR) → `arcPoints([0.42, 2.85], 0.09, π, π/2, ZR)` → `arcPoints([1.38, 2.85], 0.09, π/2, 0, ZR)` → (1.47, 2.85, ZR) → (1.47, yC + 0.22, ZR). (두 호 사이는 y = 2.94 의 수평선이 된다.)

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 yP → yA → yC, 벨트·줄·위치를 다시 계산한다.
- 회전(`rotation.z`, 반시계 +, 전부 시계): D = −theta, P = −theta × rbD / rbP (= −1.226 theta), A = −theta × rbD / rbA (= −2.303 theta). B1, B2 = −(yA − 2.19) / 0.09 (A 가 오르면 줄이 위로 가므로 시계).
- 벨트 표시: `belt.setOffset(theta × rbD)` (벨트가 D→A→P 방향으로 흐름).
- A 가 올라갈 때(P 가 올라갈 때) C 는 내려가고, 반대도 같다. yA 범위는 1.93(P 최저)~2.40(P 최고), yC 는 2.24~1.77.

## 표시
- `rotArrow(0.45, false)` 를 D 앞 (−1.31, 1.98, 0.40).
- tag(z 0.4, 전시 영역 밖으로 나가지 않게 위치 조정 허용): 'D 구동 풀리'(−1.20, 1.35), 'P 움직이는 풀리'(0.82, yP − 0.46), 'A'(−0.45, yA + 0.55), 'B 안내'(0.90, 3.05), 'C'(1.47, yC − 0.38).
- notes: `[{ label: 'P 높이', value: yP.toFixed(2) }, { label: 'A 높이 / 추 C 높이', value: yA.toFixed(2) + ' / ' + yC.toFixed(2) }, { label: '속도비 D : P', value: '0.31 : 0.38 (P 가 1.23배 빠름)' }]`

## 확인
- t=2.0 (sin ≈ 1, P 가 가장 높음, yP ≈ 1.24): A 가 가장 높고(2.40) C 가 가장 낮다(1.77). t=6.0 (sin ≈ −1, P 가 가장 낮음, yP ≈ 0.92): A 가 낮고(1.93) C 가 높다(2.24). 두 장 모두 벨트가 느슨해 처지지 않고 세 풀리에 팽팽히 감겨 있다.
- 표시점·벨트 마디가 시계로 흐른다(D 가 가장 느리고 A 가 가장 빠름). 줄이 A 앞(z 0.40)에서 올라가 B1 왼쪽 접점에 닿고, C 가 두 B 사이를 건너온 줄에 정확히 매달린다. 벨트가 A 나 P 풀리 홈에서 벗어나지 않는다.
