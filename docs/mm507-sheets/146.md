# 146 요크 막대 왕복 장치
원문 요지: 원판이 계속 돌면, 원판의 손목(크랭크 핀)이 **요크의 홈(groove)** 안에서 움직여 요크 막대를 곧게 왕복시킨다. 홈의 모양을 알맞게 만들면 일정한 속도의 왕복도 얻을 수 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/146-fig-x4.png` 로 다시 읽음(아래 px 는 4배 그림 기준).
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 굵은 실선의 큰 원 = 원판(가운데 px (1235, 1035), 반지름 405px). 한가운데 두 겹 원(반지름 150·80px) = 허브와 축. 원판 위쪽의 작은 원(반지름 42px, 가운데 (1195, 722)) = 크랭크 핀(축에서 315px = 원판 반지름의 0.78배, 꼭대기에서 왼쪽으로 7°).
2. 줄·벨트는? → 없음. 대신 **요크** 하나: 원판 **뒤**에 놓인 가로로 긴 판(바깥 px x 700 ~ 1820, y 590 ~ 1110, 양끝이 둥글다). 원판 밖으로 나온 부분만 굵은 실선이고 원판에 가린 부분은 **점선**이다. 요크 윗변 가운데에서 위로 막대(폭 100px, y 170 까지), 아랫변에서 아래로 막대(원판 뒤는 점선, 원판 아래로 y 1640 까지 실선)가 뻗는다.
3. 교차하는 가닥은? → 없음. 겹침 차례: 원판이 앞, 요크·아래 막대가 뒤(점선). 축·허브의 원 안으로 요크 아랫변 점선과 아래 막대 점선이 지나간다 = 요크가 축 자리 **뒤**를 가로지른다 → 축은 원판에서 **보는 쪽(앞)** 으로 나와야 한다.
4. 고정점은? → 판화에 없다(축받이도, 막대 안내도 그리지 않았다).
5. 추·손잡이·크랭크는? → 크랭크 = 원판의 핀. 원판 앞면에 핀의 원이 실선으로 보인다 = 핀이 원판을 꿰어 **뒤로** 솟아 요크 홈에 든다.
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 핀 ↔ 요크 홈의 위·아래 벽. 홈은 **닫힌 고리 꼴**이다 — 바깥 벽(실선·점선, px x 800 ~ 1700, y 690 ~ 1025)과 그 안의 섬(px x 890 ~ 1620, y 770 ~ 960, 원판 밖으로 나온 두 모서리만 실선) 사이의 길. 길의 폭(윗길 80px)이 핀 지름(84px)과 같다. 핀은 **윗길**(y 700 ~ 770 의 곧은 가로 길)에 있다.
7. 한 줄에 놓인 것은? → 위 막대·아래 막대·축 중심이 같은 세로선. 핀의 높이 = 홈 윗길의 높이.
8. 글자가 가리키는 부품은? → 글자 없음(번호 146 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 핀의 좌우 움직임(±315px)이 윗길의 곧은 구간(±350px) 안이라, 핀은 한 바퀴 내내 윗길만 오가고 요크는 정확한 사인 운동을 한다. 고리 홈의 양옆·아랫길은 이 그림의 치수에서는 쓰이지 않는다(원문의 "홈 모양을 바꾸면 등속도 가능" 과 이어지는 모양으로 읽고, 판화대로 파 둔다).
- 그 밖의 선: 원판 안의 가로 점선 5줄 = 위에서부터 홈 바깥 벽 윗변(700), 섬 윗변(770), 섬 아랫변(960, 양끝이 위로 굽음), 홈 바깥 벽 아랫변(1025), 요크 아랫변(1110). 세로 점선 2줄 = 아래 막대. 위 막대 뿌리가 살짝 넓어짐 = 이음 깃.

## 해석(결정 사항)
- 93번(홈 요크 크랭크)과 다른 점을 그대로 살린다: **요크가 원판 뒤**에 있고, 뚫린 홈 테가 아니라 **판에 판 고리 홈**이며, 핀은 뒤로 솟는다.
- 원판의 판(web)은 반투명으로 만든다 — 판화가 가려진 요크를 점선으로 보여 주는 것과 같은 뜻(뒤의 홈과 핀이 비쳐 보인다). 테·허브·핀은 불투명.
- 판화 비: 크랭크 반지름 = 원판 반지름의 0.78배, 요크 가로 = 원판 지름의 1.38배, 홈 윗길이 요크 윗변 가까이(요크는 위아래 비대칭).
- 보충(판화에 없음): 앞 축받이(A 꼴 다리 둘 + 고리), 막대 안내 고리 2개. 안내가 요크 위·아래 밖에 있어야 하므로 **두 막대를 판화보다 길게** 했다.
- 회전 방향은 판화에 없다 → 반시계.

## 구동
원판(theta 누적, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 요크 한 번 왕복.

## 동작 (모두 theta 의 닫힌 식 — `scotchYoke146(theta)` 가 돌려준다)
- 핀 각 a = theta − 1.6 + 97° (t = 1 에서 97° = 판화 자세). `disc.rotation.z = a`.
- 핀 P = (0.342·cos a, CY + 0.342·sin a).
- 요크 원점 높이 = CY + y, y = 0.342·sin a (정확한 사인 운동). 요크의 x 는 늘 0 — 핀이 홈 윗길 안에서 좌우 ±0.342 로 미끄러질 뿐이다.
- 범위: 요크 원점 1.478 ~ 2.162, 행정 0.684 = 크랭크 반지름의 2배.
- 시각: **t = 1.0 (a = 97°, 판화 자세, 요크 2.159 — 거의 맨 위)**, **t = 1.6 (a = 152°, 요크 1.981, 핀이 홈 왼쪽으로)**, t = 2.6 (a = 244°, 1.513), t = 3.6 (a = 335°, 1.677).
