# 087 스스로 뒤집히는 운동(베벨 기어·클러치·넘어가는 추)
판화(public/mm507/fig/087.png, 4배 확대 shots/_verify/087-fig-x4.png · 087-fig-x4-left.png · 087-fig-x4-right.png 로 다시 읽음): 그림 하나, 정면. 왼쪽에 큰 베벨 기어(이가 난 넓은 고리가 정면으로 보인다 — 축이 보는 사람 쪽)가 있고, 그 왼쪽·오른쪽 가장자리에 모서리로 선 베벨 기어 B(왼쪽)·C(오른쪽)가 물려 있다. B·C 는 가로축 위에 있고 서로 마주 본다(좁은 끝이 안쪽). 두 기어 사이 가로축 위에 클러치 D: 양 끝에 톱니 턱, 가운데 잘록한 홈. 그림에서는 D 의 오른쪽 턱이 C 의 턱에 물려 있고 왼쪽 턱은 B 의 턱과 떨어져 있다. 큰 베벨 아래쪽에 빗금 친 받침 축(흔들 축)이 있고 거기서 세 가지가 올라온다: ① 클러치 홈으로 곧게 올라간 가는 막대(포크), ② 포크에 붙은 **원호 모양의 홈 난 가로대**(받침 축을 중심으로 한 호, 포크 좌우로 대칭), ③ 오른쪽 위로 기운 막대 끝의 둥근 추 F — 이 막대는 가로대 홈의 오른쪽 끝을 지난다(작은 고리). 추 레버의 받침 가까운 점(작은 원)에서 긴 가로 막대(연결 막대)가 오른쪽으로 뻗어 꺾쇠 G 의 아래 팔 끝에 이어진다. 꺾쇠 G: 받침(이중 원)에서 오른쪽 위로 뻗은 긴 팔과 오른쪽 아래로 뻗은 짧은 팔. 오른쪽에 살 4개짜리 바퀴 E(반시계 화살표), 그 왼쪽 가장자리에 가로축 끝의 작은 베벨과 물리는 이가 보인다. E 의 허브에서 왼쪽으로 나온 짧은 팔 끝의 작은 원 = 스터드, 바로 그 밑에 꺾쇠의 긴 팔 끝이 와 있다.
원문 요지: 저절로 방향이 바뀌는 장치. B 와 C 사이의 베벨 기어가 구동. B·C 는 축에 헐겁고, 축의 깃 위를 미끄러지는 클러치 D 에 걸린 쪽만 축을 돌린다(그림은 C 에 걸림). 오른쪽 바퀴 E 는 그 축에서 베벨 기어로 돌려지며, 이제 막 꺾쇠 G 를 치려 한다. 그러면 연결 막대가 추 달린 레버 F 를 수직 너머로 넘기고, 레버는 갑자기 왼쪽으로 넘어가며 클러치를 B 에 물려 축의 방향을 바꾼다. E 의 스터드가 반대 방향으로 돌아와 추 레버를 다시 수직 너머로 되돌리면 또 방향이 바뀐다.

8. 글자가 가리키는 부품은? → B·C = 헐거운 베벨, D = 클러치, E = 스터드 바퀴, F = 추 달린 레버, G = 꺾쇠(벨 크랭크). 화살표 = E 의 방향(반시계).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 같다. 원문에 없는 **원호 홈 가로대**는 "추가 넘어간 뒤에야 클러치를 옮기는" 헛돎(lost motion) 장치로 읽었다(추 레버의 핀이 홈 끝에 닿아야 포크를 민다 — 그림에서 추가 오른쪽·핀이 홈 오른쪽 끝·클러치가 오른쪽 C). 판화 치수와 다르게 한 곳(전시 깊이 0.8 안에 넣으려고): 추 레버를 짧게(받침 → 추 0.58, 판화 비례로는 0.73)·기울기 ±30°(판화 약 42°), 흔들 축을 조금 낮게. 질문 없음.

## 해석(결정 사항)
- 구동 베벨은 **가로축 뒤쪽**에 있고 이가 앞을 본다(판화에서 클러치·포크가 고리 안쪽 앞에 그려짐). 반시계로 돌린다 → C 는 +X 둘레 양의 방향, B 는 반대. C 에 걸리면 바퀴 E 는 반시계(판화 화살표).
- 스터드는 E 의 왼쪽을 내려오며 꺾쇠 위 팔을 **위에서 눌러** 내린다 → 아래 팔·연결 막대가 왼쪽으로 → 추 레버가 왼쪽으로 선다. 수직을 4° 넘기면 추가 저 혼자 넘어가고(스터드보다 빨리), 핀이 가로대 홈 끝에 닿아 포크·클러치를 B 쪽으로 넘긴다. 축이 거꾸로 돌면 스터드는 올라가 한 바퀴 가까이 되돌아와 이번에는 꺾쇠 팔을 **밑에서 밀어** 올린다 → 추가 오른쪽으로 넘어가 다시 C.
- 바퀴 E 는 −146.1° ~ +210.7°(356.8°)를 오간다. 한 주기 = 구동각 16.755 rad(10.47 초), 반 주기마다 좌우가 바뀐다.
- 클러치가 물리는 순간 턱이 서로의 홈 가운데에 오도록 주기를 턱 피치에 맞췄다(k·T = 48 피치). 발톱 링의 phase 는 `D87.phaseB`·`D87.phaseC`.
- 치수·4절 링크·시간표는 키트 `kit/k086.ts` 의 `K87`·`D87`·`reverse87` 에 들어 있다(`shots/_verify/s087.mjs`, `t086kit.ts` 로 확인: 스터드↔팔 틈 ≥ 0, 연결 막대 길이 오차 1e-15, 턱 어긋남 0, 자세 연속). 치수를 바꾸면 다시 돌린다.

## 구동
가운데 큰 베벨(theta, 반시계, 축 Z). theta += OMEGA(1.6)·speed·dt. 가로축은 클러치가 걸린 기어를 따라 ±1.5·theta 빠르기로 돌고(27:18), 바퀴 E 는 가로축의 0.5 배(10:20).

## 동작 (모두 `reverse87(theta)` 의 시간표, 주기 T = 16.7552 rad, 반 주기 H = 8.3776 rad)
반 주기 안의 시각 t(구동각). 앞 반 주기(C 쪽, 부호 +) 기준이고 뒤 반 주기는 phi·x·chi 의 부호와 E 의 방향이 반대다. theta = 0 은 t = 6.585(스터드가 꺾쇠를 치기 0.6 rad 전 — 판화 자세).
- 0 ≤ t < 7.185 **run**: 클러치가 물려 가로축 sigma 가 1.5·t 로 돌고 바퀴 E 는 0.75·t 로 돈다(스터드가 한 바퀴 가까이 돌아온다). phi = +30°, x = +0.105.
- 7.185 ≤ t < 8.072 **push**: 스터드가 위 팔을 누른다 — psi = γ − asin(0.065/D), (D, γ) = 받침 G → 스터드 중심의 길이·각(뒤 반 주기는 γ + asin). phi 는 4절 링크(받침 P–핀 0.20, 막대 1.6606, 받침 G–핀 0.44)로 psi 에서 푼다. phi 가 +30° → −4°.
- 8.072 ≤ t < 8.258 **fall**(0.1855 rad): 추가 넘어간다. phi = −4° − v0·u − a·u², u = t − 8.072, v0 = 0.903(스터드가 밀던 빠르기에서 이어짐), a = 2.21. 끝에서 phi = −17.94°(핀이 홈 왼쪽 끝에 닿음). 클러치는 아직 +0.105.
- 8.258 ≤ t < 8.378 **shift**(0.12 rad): x 가 +0.105 → −0.105 로 곧게, chi = asin(x/1.0), phi = chi − 23.97° → −30°. 그 가운데 |x| < 0.065 인 0.0743 rad 동안 중립(가로축·E 정지). t = 8.2804 에서 C 가 풀리고 t = 8.3547 에서 B 에 물린다.
- 가로축 각 sigma: 물려 있는 동안만 ±1.5·(구동각)으로 쌓인다(한 주기에 +12.45 rad 갔다가 그만큼 돌아와 0). 바퀴 E 세계 각 eps = e0 + 0.5·sigma.
- 기어: 구동 rotation.z = theta, rollB = −1.5·theta, rollC = −1.5·theta + π/18(구동의 이와 이골이 만나는 위상), rollPinion = sigma, rollE = −0.5·sigma + π/20.
- 속도비: bevelB/driveBevel = −1.5, bevelC/driveBevel = −1.5(각자 로컬 축 기준. 세계에서는 서로 반대 방향).
- 누적 오차 없음(모든 자세가 theta 의 함수, 주기 끝에서 값이 처음과 같다).
