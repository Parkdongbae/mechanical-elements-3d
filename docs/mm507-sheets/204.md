# 204 비스듬한 축의 구름 접촉
원문(en): "An illustration of the transmission of rotary motion from one shaft to another, arranged obliquely to it, by means of rolling contact." — 한 축에서 그에 비스듬히(엇갈리게) 놓인 다른 축으로 회전을 구름 접촉으로 전한다.
쉬운 풀이: 가운데가 잘록한 두 원통(쌍곡면)이 닿은 채 구르며 돈다. 평행하지 않고 엇갈린 두 축 사이에서도 회전을 전한다.
판화 묘사: 가운데가 잘록한 장구 모양 롤러 두 개가 위아래로 포개져 있다. 위 롤러는 왼쪽 뒤에서 오른쪽 앞으로(오른쪽 끝면이 보임), 아래 롤러는 왼쪽 앞에서 오른쪽 뒤로(왼쪽 끝면이 보임) 놓였다 — 두 축이 **엇갈린(꼬인) 축**이다. 두 롤러는 길이 방향으로 한 줄을 따라 맞닿는다. 양끝에 짧은 축 토막. 받침은 그리지 않았다.

## ★ 판화 읽기
판화 492×502 px. 위 롤러 축 [45·138]→[450·177], 아래 롤러 축 [65·300]→[455·245]. 끝면 타원: 위 롤러 오른쪽 끝(세로 155 px), 아래 롤러 왼쪽 끝(세로 205 px, 앞쪽이라 크게 보임). 두 롤러의 잘록한 목은 x 230~250 근처.
1. 바퀴는 몇 개이고 크기 차례는? → 쌍곡면 롤러 2개, 같은 크기(앞뒤 원근으로 다르게 보일 뿐). 목 반지름 : 끝 반지름 ≈ 1 : 1.4.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 두 축이 위에서 볼 때 X 자로 엇갈린다(같은 평면에 있지 않음).
4. 고정점은? → 판화에는 없음(축 토막만). 모형: 축마다 벽걸이 축받이 2개(보충).
5. 손잡이·크랭크는? → 없음. 구동은 위 롤러 축(정함) — 왼쪽 끝에 작은 손잡이 크랭크를 보충.
6. 기어 이는? → 이 없음. 매끈한 두 곡면이 **곧은 접촉선 하나**를 따라 맞닿아 마찰로 구른다.
7. 한 줄에 놓인 것은? → 두 롤러의 목(가장 잘록한 곳)이 같은 세로선 x = 0. 접촉선은 수평(x 방향).
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 돌 수 없는 곳은? → 없음. 쌍곡면 두 개가 공통 모선(직선)에서 서로 접하면 계속 구른다(접촉선 방향으로는 미끄럼이 함께 생김 — 엇갈린 축 구름의 성질). 질문 거리 없음.

## 해석(결정 사항) — 접촉선이 맞는 식
- 공통 수선을 세로(y)로 둔다. 접촉선 L: 점 (0, YL, ZC) 를 지나는 x 방향 직선. YL = 1.60, ZC = 0.28.
- 위 롤러 축: 점 (0, YL + A, ZC) 를 지나고 방향 d1 = (cos α, 0, sin α). 아래 롤러 축: 점 (0, YL − A, ZC), 방향 d2 = (cos α, 0, −sin α). A = 0.22(목 반지름), α = 15°(두 축 사이 각 2α = 30°, 위에서 볼 때).
- 각 롤러 = L 을 자기 축 둘레로 돌린 쌍곡면. 반지름 r(u) = √(A² + u²·tan²α)(u = 축 방향 거리, 목에서 0). 두 곡면이 L 전체를 따라 **접하는 조건** tanα1/A1 = tanα2/A2 — 두 롤러가 같으므로 저절로 성립(수치 확인: 법선 차 2e-16).
- 롤러 길이: u ∈ [−0.815, 0.815], 끝 반지름 R_E = √(0.0484 + 0.815²·0.0717968) = 0.30998.
- 회전: 위 롤러 θ1, 아래 롤러 θ2 = −θ1(각자 축 d1·d2 둘레, 오른손). 접촉선 위 모든 점에서 L 에 수직인 속도 성분이 같다(검산 완료). L 방향으로는 일정한 미끄럼 2·A·ω·sin α 가 있다.

## 구동
`theta += OMEGA * speed * dt`(1.6 rad/s). 위 롤러 θ1 = theta, 아래 롤러 θ2 = −theta.

## 부품과 치수
상수: `A204 = 0.22`, `AL204 = 15°`(0.261799 rad), `UE204 = 0.815`, `YL = 1.60`, `ZC = 0.28`.
- `displayStand()`.
- 위 롤러 받침틀(name 없음, 회전하지 않는 피벗) `pivotU`: 위치 (0, 1.82, 0.28), `rotation.y = -AL204`(로컬 +X → d1). 그 자식 `rollerU`(name `rollerU`): `rotation.x = θ1`.
- 아래 롤러 피벗 `pivotL`: 위치 (0, 1.38, 0.28), `rotation.y = +AL204`(로컬 +X → d2). 자식 `rollerL`(name `rollerL`): `rotation.x = θ2`.
- 롤러 몸(둘 다 같음, `hyperRoller204()`): `lathe(profile, 72)` 후 `rotateZ(-Math.PI / 2)`(축 → 로컬 X). profile = u = −0.815..0.815 를 48 등분한 [r(u), u] + 양끝 [0, ±0.815]. 끝 모서리는 profile 의 끝 두 점 사이에 [R_E − 0.012, ±0.815] 를 넣어 0.012 모따기. 재질: 위 brass(), 아래 bronze().
- 모선 줄무늬(롤러마다 12개, 롤러 자식): k = 0..11, 각 φk = k·30°. 로컬 직선 — 위 롤러: P(s) = (s·cos α, −A, −s·sin α) 를 로컬 X 축 둘레로 φk 돌린 것, 아래 롤러: P(s) = (s·cos α, +A, s·sin α) 를 φk 돌린 것, s ∈ [−0.8438, 0.8438](= UE/cos α). 바깥으로 0.006 띄운다(목 쪽 법선 = 로컬 (0, ∓1, 0) 을 φk 돌린 방향으로 직선 전체를 0.006 평행이동). `rod(a, b, 0.006)`. k = 0 은 paint(0xffcc00)(노랑), 나머지 darkSteel().
- 축(롤러 자식, 같이 돎): `rod(new THREE.Vector3(-1.15, 0, 0), new THREE.Vector3(1.10, 0, 0), 0.035)` steel(왼쪽 끝을 0.05 더 길게 — 크랭크 자리).
- 축받이 4개(고정, `wallBearing` from '../kit/gear6', bore 0.042): 위 축 u = ±1.0 → (0.9659, 1.82, 0.5388)·(−0.9659, 1.82, 0.0212), 방향 `new THREE.Vector3(Math.cos(AL204), 0, Math.sin(AL204))`. 아래 축 u = ±1.0 → (0.9659, 1.38, 0.0212)·(−0.9659, 1.38, 0.5388), 방향 (cos α, 0, −sin α). name: `bearingU1`(+x)·`bearingU2`·`bearingL1`(+x)·`bearingL2`.
- 손잡이 크랭크(name `crank`, 위 롤러 자식이라 같이 돎): 로컬 x = −1.12 자리에 팔 `BoxGeometry(0.03, 0.20, 0.04)` 중심 로컬 (−1.12, 0.10, 0)(축받이 보스 끝 −1.07 과 0.035 떨어짐) + 손잡이 `CylinderGeometry(0.022, 0.022, 0.10)` 를 `rotateZ(Math.PI/2)` 해 로컬 (−1.17, 0.19, 0)(축과 나란한 손잡이, 바깥쪽으로). 재질 castIron / wood.
- 접촉선 표시(name `contactLine`, 고정): `rod(new THREE.Vector3(-0.79, 1.60, 0.28), new THREE.Vector3(0.79, 1.60, 0.28), 0.005)` 재질 paint(0xffcc00) — 두 롤러가 맞닿는 틈에 노란 선.
- 전체 범위: x −1.23~1.07, y 1.07(아래 롤러 밑)~2.13(위 롤러 위), 크랭크 끝 y ≤ 2.03.

## 동작
- `rollerU.rotation.x = theta`, `rollerL.rotation.x = -theta`. 피벗은 움직이지 않는다.
- theta = 0, 30°, 60°… 마다 위 롤러의 모선 −m 번과 아래 롤러의 모선 +m 번이 접촉선 위에서 **겹친다**(theta = 0 에는 두 노란 모선이 접촉선에 함께). 한 바퀴 = 3.93 s.
- 시각: t = 1 → theta 1.6 rad, t = 1.6 → 2.56, t = 30 → 48.

## 표시
- `rotArrow(0.36, true)` 를 위 롤러 오른쪽 끝 밖에 — 피벗 `pivotU` 의 자식으로 로컬 (0.88, 0, 0), `rotation.y = Math.PI / 2`(축 둘레 회전 표시). `rotArrow(0.36, false)` 를 `pivotL` 자식으로 로컬 (−0.88, 0, 0), `rotation.y = Math.PI / 2`.
- 이름표(모두 `leaderTo`): tag '위 쌍곡면 롤러(구동)', tag '아래 쌍곡면 롤러', tag '접촉선(곧은 선)', tag '축받이(고정)'.
- view: `{ pos: [1.5, 2.9, 4.9], target: [0, 1.6, 0.28] }`(위·오른쪽 앞 — 두 축이 엇갈린 것이 보임).

## 확인
- t = 0 정면: 두 롤러가 위아래, 노란 두 모선이 접촉선에서 겹침. view 시점: 위 롤러 오른쪽 끝면, 아래 롤러 왼쪽 끝면이 보여 판화와 같은 엇갈림.
- 근접 `cam=0.0,1.75,1.4,0,1.6,0.28`(접촉선), 위에서 `cam=0,4.0,0.3,0,1.6,0.28`(두 축이 30° X 자).

## ★ 눈에 보여야 할 동작
- **엇갈린 두 축**: 위·오른쪽 앞 시점(view), notes ①.
- **곧은 선을 따라 닿아 구른다**: 노란 `contactLine` + 롤러마다 모선 12개. 30° 마다 두 롤러의 모선이 접촉선에서 한 직선으로 겹쳤다 갈라진다 — 곡면이 곧은 선으로 이루어져 있고 그 선으로 맞닿는 것이 보인다.
- 방향: 두 화살표가 서로 반대. 노란 모선 둘이 3.93 s 마다 접촉선에서 다시 만난다(속도 같음).

## ★ 깊이 계산
축이 앞뒤로 기울어 깊이가 생긴다. 롤러 끝 중심 z = 0.28 ± 0.815·sin15° = 0.28 ± 0.211, 끝면 반지름 0.31 의 z 성분 0.31·cos15° = 0.299 → 합 0.510. ZC = 0.28, 최대 반지름 0.51(z 반폭으로 잼), z −0.23~0.79. 축 끝 z 0.28 ± (1.10·0.259 + 0.034) = −0.039~0.599, 축받이 보스 z 최대 0.539 + 0.092 = 0.631, 크랭크 z −0.10~0.11.
