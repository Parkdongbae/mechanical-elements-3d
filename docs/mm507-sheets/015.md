# 015 화이트 도르래
판화: 위에 들보에 고리로 매달린 **큰 원반 블록**, 아래에 같은 모양의 **움직이는 원반 블록**(아래 갈고리). 둘 다 정면(축 방향)에서 본 모습이라 **지름이 다른 동심원 홈**(가운데 구멍 + 안쪽 고리 + 바깥 테)이 보이고, 두 블록 사이에 **수직에 가까운 줄 일곱 가닥 안팎**이 서로 다른 x 위치에 걸려 있다. 맨 왼쪽의 줄 하나는 블록 바깥으로 길게 늘어진다(당기는 끝). 원문: 한 덩어리 블록에 줄의 속도에 비례하는 지름으로 홈을 파 두면(한 블록에는 1·3·5, 다른 블록에는 2·4·6 …) 따로 떨어진 헐거운 도르래 없이 한 몸 블록으로 같은 일을 한다. 힘의 비 1 : 7.
**읽기**: 판화 홈 개수는 흐릿해 정확히 세기 어렵다. 줄 7가닥(1 : 7)을 만족하는 가장 간단한 짜기를 쓴다 — 줄 한쪽 끝을 아래 블록에 묶고, 위 블록 홈 4개(속도비 1·3·5·7)와 아래 블록 홈 3개(2·4·6)를 번갈아 감은 뒤 자유단은 위 블록 가장 큰 홈에서 아래로 늘어진다.
구동: 줄의 자유단(손)을 당겼다 놓는다. 아래 블록이 d 올라가면 자유단은 7d 내려온다. 두 블록은 같은 각도로 돌고(홈 반지름이 속도에 비례하므로) 줄은 항상 거의 수직이다.

## 부품과 치수
- `displayStand()`
- 들보: `BoxGeometry(1.9, 0.12, 0.65)` castIron, 중심 (0, 3.07, 0.05).
- 줄 중심 반지름 R (홈 4개 / 3개): k = 0.065
  - 위 블록 U: A1 = 0.065, A2 = 0.195, A3 = 0.325, A4 = 0.455 (= 1, 3, 5, 7 × k)
  - 아래 블록 L: B1 = 0.13, B2 = 0.26, B3 = 0.39 (= 2, 4, 6 × k)
- 블록 U: 중심 (0, 2.55), 회전축 Z. `steppedPulley([0.435, 0.305, 0.175, 0.045], 0.09)` (= R − 0.02, 큰 쪽이 −Z). 그룹 위치 z = 0.20 → 단 중심 z: 0.065(A4), 0.155(A3), 0.245(A2), 0.335(A1). 키트는 반지름을 내림차순으로 정렬하고 단 j(0 = 가장 큼)의 중심 z = 그룹 z − W/2 + (j+0.5)×0.09 로 쌓는다(W = 단수 × 0.09) — 다르게 쌓이면 이 값대로 줄 z 를 다시 계산한다.
- 블록 L: 중심 (0, y_L), y_L = 1.30 + d. `steppedPulley([0.37, 0.24, 0.11], 0.09)`, 그룹 z = 0.20 → 단 중심 z: 0.110(B3), 0.200(B2), 0.290(B1).
- 매달이(U): 축 막대 `rod(V3(0,2.55,0.03), V3(0,2.55,0.37), 0.03)`, 위로 옆판 2(상자 0.03 × 0.45 × 0.03, x = 0, z = 0.03 과 z = 0.37 두 곳, y 2.55 ~ 3.00)와 고리(중심 (0, 3.00, 0.20), `TorusGeometry(0.03, 0.011, …)`). 위치 고정.
- 매달이(L): 축 막대 같은 방식(중심 y_L), 아래로 막대 `rod((0, y_L−0.39, 0.20), (0, y_L−0.47, 0.20), 0.03)`, 고리 중심 (0, y_L − 0.50, 0.20), 아래 추 `weight(0.30, 0.34)` 중심 (0, y_L − 0.75, 0.20) 에 매닮. 묶는 핀(줄 끝): `rod(V3(0.065, y_L, 0.335), V3(0.065, y_L, 0.37), 0.02)`.
- **줄**: 012 의 `ropeAround`(map 기본: u = x, v = y, w = z) + `new Rope(0.018)`, 매 프레임 `setPath`. 모든 원 ccw: 오른쪽 가닥은 올라가고 왼쪽 가닥은 내려온다.
  ```
  ropeAround(
    { p: [0.065, y_L], w: 0.37 },                              // 묶는 점
    [ A1, B1, A2, B2, A3, B3, A4 ],                            // 이 순서
    { p: [-0.455, y_E], w: 0.065 },                            // 자유단 (A4 왼쪽 접선 위)
    { seg: 12 })
  // A_i = { c:[0, 2.55], r:A_i, ccw:true, w: z_A_i },  z: A1 0.335, A2 0.245, A3 0.155, A4 0.065
  // B_i = { c:[0, y_L],  r:B_i, ccw:true, w: z_B_i },  z: B1 0.290, B2 0.200, B3 0.110
  ```
  가닥 7개: ① 묶는 점 → A1 오른쪽(↑) ② A1 왼쪽 → B1 왼쪽(↓) ③ B1 오른쪽 → A2 오른쪽(↑) ④ A2 → B2(↓) ⑤ B2 → A3(↑) ⑥ A3 → B3(↓) ⑦ B3 오른쪽 → A4 오른쪽(↑) 그리고 A4 왼쪽에서 자유단(↓). 반지름이 달라 가닥이 조금씩 기울고 z 가 단마다 한 단씩 뒤로(z−) 이동한다. 줄이 가장 작은 단 허브 위를 지날 때의 미세한 겹침(≈0.006)은 허용.
- 자유단 손잡이: `rod(V3(−0.455, y_E, 0.065), V3(−0.455, y_E − 0.16, 0.065), 0.05)` + 구 반지름 0.06.

## 키트 추가
없음 — 012 의 `kit/rope.ts`(`ropeAround`)와 기존 `steppedPulley` 를 쓴다.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- 올림 d(theta) = 0.11 × (1 − cos(0.5 × theta)) (0 ~ 0.22).
- 아래 블록 y_L = 1.30 + d. 자유단 y_E = 2.05 − 7d (0.51 ~ 2.05).
- 두 블록 회전: **둘 다** `rotation.z = + d / 0.065` (반시계, 같은 각 — 블록 올림 속도 v 일 때 위 A1 의 줄 속도는 v, 아래 B1 의 줄 상대 속도는 2v 이고 반지름이 0.065 : 0.13 이라 둘 다 ω = v/0.065. 모든 단이 한 몸이므로 큰 단일수록 줄이 빨리 달린다).
- 줄: 매 프레임 `ropeAround` → `setPath`.

## 확인
- t=0.5(d ≈ 0.01) 와 t=3.9(d ≈ 0.22): 아래 블록이 0.22 올라가 있고 자유단 손잡이는 그 7배(≈ 1.54) 내려가 있다. 두 블록의 표시점(가장 작은 단 앞면)이 같은 방향으로 같은 각 돌아 있다.
- 정면에서 일곱 가닥이 x = ±0.065, ±0.13 … ±0.455 에 퍼져 거의 수직으로 보인다. 줄이 단 표면에 붙어 있고 블록 위·아래 끝에서 매끈하게 방향을 바꾼다. 추가 바닥(y = 0.18)과 닿지 않는다.
