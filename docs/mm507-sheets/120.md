# 120 집게형 기어 장치
원문 요지: 두 턱(집게발)이 각각 **부채꼴 조각** 하나씩에 붙어 있다. 한 조각은 **바깥쪽**에, 다른 조각은 **안쪽**에 이가 났다. 피니언 두 개가 달린 축을 돌리면 한 피니언은 한 조각과, 다른 피니언은 다른 조각과 물려 두 턱이 큰 힘으로 서로 다가온다.
판화(public/mm507/fig/120.png, 4배 확대 `shots/_verify/120-fig-x4.png` 로 다시 읽음): 그림 하나(정면). 위에 초승달 꼴 턱 두 개가 마주 보고, 그 아래 둥근 피벗(겹원), 피벗 아래로 부채꼴 틀(아래 가장자리에 아래를 향한 이)과 그것을 감싸는 물방울 꼴 큰 활 틀(바닥 안쪽에 위를 향한 이), 가운데에 한 축 위의 크고 작은 피니언 둘(축은 빗금 친 원).

## ★ 판화 읽기
1. 바퀴(기어)는 몇 개이고 크기 차례는? → 4개. 안쪽 이 활 틀(피치 반지름 ≈ 905px, 피벗 중심) > 바깥 이 부채꼴(≈ 465px, 피벗 중심) > 큰 피니언(≈ 270px, 이 약 20개) > 작은 피니언(≈ 170px, 이 약 12개). 두 피니언은 같은 축(빗금 원) 위에 겹쳐 있다. 피벗 ~ 축 거리 ≈ 635px.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 줄은 없다. 두 조각이 피벗에서 **가위처럼 엇갈린다**: 왼쪽 위 턱은 피벗을 지나 오른쪽 아래로 뻗은 부채꼴의 팔로, 오른쪽 위 턱은 피벗을 지나 왼쪽 아래로 휘어 내려가는 활 틀의 다리로 이어진다.
4. 고정점은? → 판화에는 받침이 없다(손에 드는 공구). 두 조각이 함께 도는 피벗 핀 하나와 피니언 축 하나뿐. 모형은 이 둘을 뒤판에 세운다.
5. 추·손잡이·크랭크는? → 없음. 구동은 두 피니언의 축(원문: On turning the shaft). 축을 돌리는 손잡이·열쇠는 판화에 없다.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 부채꼴은 호의 **바깥(아래)** 가장자리에 이가 났고 **작은 피니언의 위쪽**과 물린다. 활 틀은 바닥 띠의 **안쪽(위)** 가장자리에 이가 났고 **큰 피니언의 아래쪽**과 물린다. 부채꼴의 창(팔 사이 빈 곳)으로 뒤의 큰 피니언 윗니가 보인다 — 부채꼴·작은 피니언이 앞 층, 활 틀·큰 피니언이 뒤 층.
7. 한 줄에 놓인 것은? → 피벗과 피니언 축이 거의 한 세로선(판화는 축이 7° 쯤 오른쪽). 두 물림 자리(부채꼴↔작은 피니언, 활 틀↔큰 피니언)가 그 선 위에 위아래로 놓인다. 부채꼴과 활 틀의 이는 모두 피벗을 중심으로 한 원호.
8. 글자가 가리키는 부품은? → 글자 없음(번호 120 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 원문과 판화가 같은 기구다. 다만 축은 한없이 돌 수 없고(이가 난 호가 끝난다) 벌림~다묾 사이를 오간다 — 모형도 그렇게 오간다. 어느 턱이 어느 조각에 붙었는지는 3번처럼 읽었다(엇갈린 짝이라야 한 축으로 둘이 함께 오므라든다. 반대로 읽어도 기구와 움직임은 같다).
- 그 밖의 선: 피벗의 겹원 = 핀과 와셔. 오른쪽 아래로 가는 두 줄 = 부채꼴의 오른팔과 활 틀의 곧은 버팀 다리가 나란히 겹친 것. 활 틀 왼쪽의 겹선 = 다리의 두께. 축의 빗금 = 잘린 단면.

## 해석(결정 사항)
- 피니언 축이 제자리에서 돌면 작은 피니언(12)이 부채꼴(온 둘레 32 꼴)을 축과 **반대** 방향으로 12/32 배, 큰 피니언(20)이 활 틀(온 둘레 64 꼴, 안쪽 이)을 축과 **같은** 방향으로 20/64 배 돌린다 → 두 조각이 서로 반대로 돌아 턱이 함께 오므라든다(유성 기어의 태양·링과 같은 배치).
- 축 거리 조건: 모듈·(32 + 12)/2 = 모듈·(64 − 20)/2 = 22·모듈 — 한 축에서 둘 다 맞물린다.
- 피벗과 축을 한 세로선에 둠(판화의 7° 기울기는 버림). 손잡이는 없음(판화에 없음).
- 보충(판화에 없음): 피벗 핀과 피니언 축을 뒤판에 받치는 보스(shaftZ 에 포함)뿐.

## 구동
피니언 축이 오간다: 다문 정도 c = (1 − cos(theta − 1.6))/2, 축 각 = +64°·c (반시계가 다무는 쪽). theta += OMEGA(1.6)·speed·dt, 한 번 오가는 데 3.93 s.

## 부품과 치수 (새 부품은 `kit/k119.ts`, 이미 구현됨. 치수 상수 `K120`)
배치 상수: PY = 2.2 (피벗 높이), SY = 1.144 (피니언 축 높이 = PY − 1.056), 둘 다 x = 0. 뒤 층 가운데 ZB = 0, 앞 층 가운데 ZF = 0.1 (층 두께 0.07, 사이 틈 0.03).
- 모듈 0.048. 작은 피니언 12(피치 반지름 0.288), 큰 피니언 20(0.48), 부채꼴 피치 반지름 0.768(온 둘레 32 꼴, 이 8개), 활 틀 피치 반지름 1.536(온 둘레 64 꼴, 이 12개).
- 바깥 이 부채꼴 + 왼쪽 턱(name `sectorJaw`): `sectorJaw120()` — 허브(반지름 0.12) + 두 팔 + 이 난 테(황동, 앞 층 두께) + 왼쪽 턱(강철, 두 층에 걸친 두께). 위치 (0, PY, ZF), rotation.z = sector(θ).
- 안쪽 이 활 틀 + 오른쪽 턱(name `ringJaw`): `ringJaw120()` — 허브 + 굽은 왼쪽 다리 + 곧은 오른쪽 버팀 다리 + 바닥의 안쪽 이 띠(청동, 뒤 층 두께) + 오른쪽 턱(강철, 두 층 두께). 위치 (0, PY, ZB), rotation.z = ring(θ).
- 작은 피니언(name `pinionSmall`): `pinion119(12, 0.048, { width: 0.07, bore: 0.045, driver: true })` 위치 (0, SY, ZF), rotation.z = shaft + π/2.
- 큰 피니언(name `pinionBig`): `pinion119(20, 0.048, { width: 0.07, bore: 0.045, driver: true })` 위치 (0, SY, ZB), rotation.z = shaft − π/2.
  - `pinion119` 는 이 0 의 중심이 로컬 +X 다(spurGear 와 다름). 벌린 자세(shaft = 0)에서 작은 피니언은 이가 곧장 위, 큰 피니언은 이가 곧장 아래를 향해 각각 부채꼴·활 틀의 이골에 든다.
- 피니언 축: `shaftZ(0, SY, 0.2, 0.045)`, rotation.z = shaft. 두 피니언 사이 띄우개 `spacer119(0.045, 0.1, 0.037, 0.063)` 를 (0, SY, 0) 에.
- 피벗 핀(고정): `shaftZ(0, PY, 0.2, 0.05)` (조각의 구멍 반지름 0.052). 두 조각 사이 띄우개 `spacer119(0.052, 0.1, 0.037, 0.063)` 를 (0, PY, 0) 에.
- 받침대·뒤판 `displayStand()`.
- 전체 범위(벌림~다묾): 가로 −1.08 ~ 1.41, 세로 0.53 ~ 3.18.

## 동작 (모두 theta 의 닫힌 식 — `pincer120(theta)` 가 { c, shaft, sector, ring } 을 돌려준다)
- c = (1 − cos(theta − 1.6))/2. shaft = 64°·c.
- sector = −shaft·12/32 = −24°·c (시계 방향 → 왼쪽 위 턱이 오른쪽으로).
- ring = +shaft·20/64 = +20°·c (반시계 → 오른쪽 위 턱이 왼쪽으로).
- 조각의 윤곽은 모두 벌린 자세(c = 0) 좌표라 rotation.z 에 위 값을 그대로 넣는다. c = 1 에서 두 턱 끝이 피벗 바로 위에서 만난다(틈 0.004).
- 시각: **t = 1 (c = 0, 벌린 자세 = 판화)**, t = 2 (c = 0.51, 다무는 중), t = 2.96 (c = 1, 다묾), t = 4.93 (다시 벌림).

## ★ 깊이 계산
모두 뒤판과 나란한 층이고 깊이로 지름이 나오는 부품은 없다. 뒤 층(활 틀 판·큰 피니언) z −0.035~0.035, 앞 층(부채꼴 판·작은 피니언) z 0.065~0.135, 두 턱 z −0.035~0.135, 피벗 핀·피니언 축의 끝 z 0.2. 가장 앞 0.2 ≤ 0.8. 흔들리는 팔의 최고 높이: 턱 끝이 피벗에서 0.983 → 다문 자세에서 2.2 + 0.983 = 3.183 ≤ 3.3. 가장 낮은 곳은 활 틀 바닥 2.2 − 1.671 = 0.529. 가로는 다문 자세의 활 틀 오른쪽 끝 1.412.

## ★ 난도·질문
난도 **B** (Sonnet). 부품·운동식이 모두 키트에 있고 모델은 두 층의 z 와 rotation.z 네 줄을 옮기면 된다. 층이 겹치고 위상(±π/2)이 걸려 있어 GLM(A)에는 주지 않는다.
사용자에게 물을 질문: 없음. (묻지 않고 정한 것: 왼쪽 턱 = 바깥 이 부채꼴, 오른쪽 턱 = 안쪽 이 활 틀, 피벗과 축을 한 세로선에, 손잡이 없음, 잇수 12·20·32·64.)
