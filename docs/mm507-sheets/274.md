# 274 포물선 팔 조속기
원문(en): "An engine-governor. The rise and fall of the balls, K, are guided by the parabolic curved arms, B, on which the anti-friction wheels, L, run. The rods, F, connecting the wheels, L, with the sleeve move it up and down the spindle, C, D." — 기관 조속기. 공 K 의 오르내림은 포물선으로 굽은 팔 B 가 안내하고, 그 위를 마찰 방지 바퀴 L 이 구른다. 바퀴 L 과 슬리브를 잇는 막대 F 가 슬리브를 스핀들 C·D 위에서 위아래로 움직인다.
쉬운 풀이: 스핀들 꼭대기에 사발 모양으로 굽은 팔 B 한 쌍이 달려 함께 돈다. 팔 안쪽 면(포물선)에 롤러 L 이 얹혀 있고, 롤러 축에 막대 F 와 공 K 가 한 몸으로 달려 있다. 빨리 돌면 공이 바깥으로 벌어지며 롤러가 포물선을 타고 올라가고, 막대 F 가 아래 슬리브를 끌어올린다(기관의 증기 밸브를 조임). 느려지면 반대.
판화 묘사(원본 436×445 px, 정면): 가운데 세로 스핀들 [219 · 15~440](위 끝 C, 아래 끝 D). 꼭대기 [219·50] 에 아치꼴 가로대, 그 양 끝 핀 [140·78]·[298·78] 에서 두 줄 선의 굽은 팔 B 가 바깥 아래로 휘어 나갔다가(가장 바깥 ±115 px, y ≈ 150) 안쪽으로 돌아와 롤러 L [185·213]·[252·213] 근처에서 끝난다. 롤러 축에서 바깥 아래로 공 K(반지름 ≈ 35 px, 가운데 [150·275]·[290·275])에 짧은 막대 두 개(V), 아래로 막대 F 가 내려가 슬리브 핀 [190·355]·[250·355] 에. 슬리브 아래 [219·385] 에 두 겹 깃(밸브 레버 홈). 롤러 사이 스핀들에 작은 블록.

## ★ 판화 읽기
판화 하나(정면, 팔 평면이 화면과 나란한 순간). 판화 1 px ≈ 0.0062(스핀들 425 px ≈ 2.66). 스핀들 [219··] ↔ 세계 x 0.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 롤러 L 2개(작음, 반지름 0.045 — 판화처럼 한 쪽에 하나씩; 모형은 팔 판 두 장 위를 구르도록 한 롤러를 두 바퀴로 나눔). 공 K 2개(반지름 0.11)는 바퀴가 아님.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 막대 F 와 공 팔은 팔 B 의 두 판 **사이** 틈(깊이 −0.035~0.035)을 지나 정면에서 팔과 겹쳐 보인다.
4. 고정점은? → 판화에는 받침 없음. 보충: 아래 받침대(스핀들 D 끝 베어링, 받침 위), 위 베어링(뒤판 팔, 스핀들 C 끝).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 공 K = 원심 추. 롤러 축에 막대 F 와 한 몸(V 막대 두 개로 고정). 구동은 기관(판화 밖) → 스핀들이 시간표로 돎.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음. 롤러 L 이 팔 B 의 **안쪽(오목한 쪽) 가장자리**에 위에서 얹혀 구른다.
7. 한 줄에 놓인 것은? → 스핀들·위 가로대 가운데·슬리브·아래 받침이 한 세로선 x = 0(깊이 0.275). 좌우 팔·롤러·공·막대 F 는 스핀들에 대해 거울 대칭. 위 가로대 핀 둘이 한 높이(2.80), 슬리브 핀 둘이 한 높이.
8. 판화에 글자(A, B…)가 가리키는 부품은? → K = 공, B = 포물선 팔, L = 롤러(마찰 방지 바퀴), F = 막대 F(롤러 ↔ 슬리브), C = 스핀들 위 끝, D = 스핀들 아래 끝. 롤러 사이 블록의 글자(흐림)는 읽을 수 없음 — 모형에서 생략.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) 판화의 팔 B 는 두 줄 선 띠라 한 판인지 두 판인지 알 수 없다 → 두 판(앞·뒤) 사이로 막대 F 가 지나고 롤러는 두 바퀴로 두 판 가장자리를 함께 구르게 함(막대가 팔을 뚫지 않음). (나) 공 K 가 무엇에 달렸는지 — 판화의 V 막대가 롤러 축 쪽에서 나오므로 공·V 막대·막대 F 를 한 몸으로(롤러 축에 핀). (다) 원문의 포물선 조속기는 이론상 모든 높이에서 같은 속도로 평형(등시성)이라 속도로 높이가 정해지지 않는다 → 높이와 속도를 시간표로 함께 바꾸고 notes 로 설명. (라) 깊이 한도(±0.525) 때문에 판화보다 팔 폭을 조금 좁힘. 질문 거리 1, 2.

## 해석(결정 사항)
- 회전 묶음(스핀들과 한 몸으로 도는 모든 것)의 평면 좌표: 가로 r(스핀들에서 거리, 오른쪽 +), 세로 y(세계 높이). 왼쪽은 오른쪽을 스핀들 둘레 180° 돌린 복사본.
- 롤러 중심 경로 = 포물선 **y = 1.9489 + r²/(2·0.22)**. 팔 B 안쪽 가장자리 = 이 포물선을 바깥 아래 법선으로 0.045(롤러 반지름) 옮긴 곡선 → 롤러가 늘 틈 0 으로 닿음.
- 막대 F(길이 0.70)가 롤러 축 L 과 슬리브 핀 S(r 0.12)를 잇는다. 슬리브는 스핀들을 따라 미끄러진다: **ys = yL − √(0.70² − (r − 0.12)²)**.
- 공 K = 막대 F 에 고정: K = L + 0.30·d + 0.15·o (d = L→S 단위벡터, o = d 에 수직이며 바깥쪽).

## 구동
tc = t mod 16. 들림 s(tc): 0 (0~2) / (1 − cos(π(tc−2)/4))/2 (2~6) / 1 (6~10) / (1 + cos(π(tc−10)/4))/2 (10~14) / 0 (14~16).
롤러 r = 0.15 + 0.18·s. 스핀들 각속도 ω = 1.2 + 0.6·s rad/s, 각 ψ(t) = 24·n + 1.2·tc + 0.6·I(tc) (n = floor(t/16)), I = ∫s: 0 (tc ≤ 2) / 4·(u/2 − sin(πu)/(2π)), u = (tc−2)/4 (≤ 6) / 2 + (tc − 6) (≤ 10) / 6 + 4·(u/2 + sin(πu)/(2π)), u = (tc−10)/4 (≤ 14) / 8 (> 14).
