# 043 엇각 기어 (2)
원문(42·43 공통): 한 축에서, 그와 비스듬하게 놓인 다른 축으로 회전을 전하는 여러 종류의 기어.

## ★ 판화 읽기
판화는 그림 하나(비스듬한 투시). 원뿔(베벨) 기어 둘이 직각이 아닌 각으로 물린다.
1. 바퀴는 몇 개이고 크기 차례는? → 베벨 기어 2개. 큰 기어 G1(왼쪽 위, 허브에서 이 줄이 부채꼴로 퍼짐, 반지름 약 200)과 그보다 조금 작은 기어 G2(왼쪽 아래, 모서리로 서 있어 긴 직선으로 보임, 지름 약 287). 지름비 G2/G1 ≈ 0.72. (작은 피니언이 아니다.)
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 줄은 없음. 두 **축**이 그림에서 X 자로 엇갈리고, G1 의 축(왼쪽 위 → 오른쪽 아래)이 G2 의 축(왼쪽 아래 → 오른쪽 위) **앞**을 지나가게 그려져 있다.
4. 고정점은? → 판화에는 받침이 없다(축 끝이 잘려 있을 뿐).
5. 추·손잡이·크랭크는? → 없음. 구동 표시 없음(모형은 작은 쪽 G2 를 구동으로).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → G1 은 보는 사람 쪽(오른쪽 앞)을 향한 원뿔 면에 이가 났고 이 줄이 허브(흰 고리) 쪽으로 모인다. G2 는 뒷면(허브 띠가 붙은 평평한 쪽)이 왼쪽 아래를 향하고, 이가 난 원뿔 면은 오른쪽 위(두 축이 엇갈리는 점 쪽)를 향한다 — 오른쪽 아래에 그 이의 끝이 부채꼴로 조금 보인다. 물리는 곳은 G1 의 아랫부분과 G2 의 윗면 사이(G1 부채꼴 아래쪽에 가려 있다).
7. 한 줄에 놓인 것은? → 두 원뿔의 꼭짓점이 두 축이 엇갈리는 한 점(그림 오른쪽 가운데)으로 모인다: G2 는 반지름 약 143 에 꼭짓점까지 약 205(원뿔 반각 약 35°), G1 은 반지름 약 200 에 꼭짓점까지 약 180(반각 약 46°), 합 약 80° ≈ 두 축의 3D 사이각(그림에서 잰 값 약 75°).
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 있다(★질문 거리). 두 축이 **서로를 지나쳐 계속 이어지게** 그려져 있다. 축이 한 점에서 만나는 보통 베벨이라면 두 축이 그 점을 함께 지날 수 없다. (가) 화가가 축을 길게 그렸을 뿐인 보통의 비스듬한 베벨이거나, (나) 축이 서로 비켜 가는 스큐 베벨이다 — 아래 난도·질문 절.
- 그 밖의 선: G1 허브의 흰 타원 고리 = 허브 보스(앞면이 보이므로 G1 축은 보는 사람 쪽으로 약 50° 기울어 있다). G1 부채꼴은 온 원이 아니라 오른쪽 위가 잘려 약 3/4 만 그려져 있다(그림 생략으로 보고 모형은 온전한 기어). G2 의 가는 긴 네모 = 뒷면 허브 띠.

## 부품과 치수 (키트: `coneBevelGear`, `bevelPitchAngle`, 이미 구현됨)
아래는 (가) 축이 한 점 O 에서 만나는 베벨로 적은 것이다. 구도는 판화대로: G2 의 축은 화면 평면 안, G1 의 축은 보는 사람 쪽으로 50° 기울인다.
- 축 사이각 Σ = 75°, 잇수 Z1=36(큰 G1, name `gearG1`), Z2=26(작은 G2, 구동, name `gearG2`). MOD = 0.023 → 피치 반지름 0.414 / 0.299. δ1 = bevelPitchAngle(Σ,36,26) = 44.56°, δ2 = Σ − δ1 = 30.44°. 슬랜트 길이 0.590(둘 다 같음). 이 폭 0.16(슬랜트).
- G1 = `coneBevelGear(36, 0.023, δ1, { face: 0.16 })`, G2 = `coneBevelGear(26, 0.023, δ2, { face: 0.16, driver: true })`.
- 꼭짓점 O = (0.40, 1.80, 0.42). 축 방향(꼭짓점에서 몸통 쪽 단위 벡터):
  - a1 = (cos50°·cos160°, cos50°·sin160°, −sin50°) = (−0.6040, 0.2198, −0.7660) — 왼쪽 위·뒤쪽.
  - a2 = (cos226.26°, sin226.26°, 0) = (−0.6914, −0.7224, 0) — 왼쪽 아래, 화면 평면 안. (226.26° = 160° + acos(cos75°/cos50°), a1·a2 = cos75°.)
  - 두 축이 놓인 평면의 법선 n = normalize(a1 × a2) = (−0.573, 0.548, 0.609).
- 꼭짓점에서 중심까지: G1 은 0.4205, G2 는 0.5087. C1 = O + 0.4205·a1 = (0.146, 1.892, 0.098), C2 = O + 0.5087·a2 = (0.048, 1.433, 0.42).
- 축 1(G1, 반지름 0.045): `rod(O + 0.94·a1, O − 0.42·a1, 0.045)` — 뒤 끝 (−0.168, 2.007, −0.30) 은 뒤판에 닿고, O 를 지나 앞 끝 (0.654, 1.708, 0.742) 까지(판화처럼 G2 의 축 앞으로 지나감).
- 축 2(G2, 반지름 0.045): `rod(O + 0.12·a2, O + 1.20·a2, 0.045)` — 꼭짓점 0.12 앞에서 끝난다(축 1 과 부딪치지 않게. **판화에는 축 1 뒤로 계속 이어져 있음 — 판화와 다름**). 아래 끝 (−0.430, 0.933, 0.42).
- 받침(판화에 없음, 최소): 축 1 은 뒤판에 닿는 자리에 a1 방향의 짧은 보스(반지름 0.08, O + 0.74·a1 ~ O + 0.96·a1). 축 2 는 O + 0.86·a2 = (−0.195, 1.179) 와 O + 1.12·a2 = (−0.374, 0.991) 두 곳에 뒤판에서 나온 기둥(반지름 0.07, z −0.3 ~ 0.42)과 끝 고리.

## 동작
- 로컬 Z = 꼭짓점 쪽(−a). 자세 `basis(a)`: x축 = n, z축 = −a, y축 = z × x 로 Matrix4.makeBasis → quaternion. 그 뒤 Rz(roll) 을 곱한다(quaternion = basis(a)·Rz(roll)). 위치 = C1, C2.
- G2 roll = theta, **G1 roll = −(Z2/Z1)·theta** (속도비 −26/36 = −0.722, 위상 덧값 0). 절대 각.
- (위상 근거: 물림점이 G1 로컬 +Y(이 9칸째 — 이 중심), G2 로컬 −Y(19.5칸째 — 이골)에 오므로 덧값 없이 이와 이골이 만난다. 잇수를 바꾸면 다시 구해야 한다.)

## 검증 후 수정 — 판화 교차 읽기(Fable, 지시서 20 S1b)
