# 009 원뿔 풀리 변속
판화: 위아래 두 축에 원뿔(원뿔대) 풀리가 서로 반대 방향으로 놓이고 벨트가 걸려 있다. 원문: 008 과 같은 목적. 면직 기계 등 속도를 점차 올리거나 내려야 하는 기계에 쓴다.
구도: 008 과 같은 옆모습(축이 X 방향).

## 부품과 치수
- 축·받침은 008 과 같다(y = 2.5 구동, y = 1.0 종동, 길이 1.6).
- `conePulley(0.50, 0.22, 0.9)` 위: 큰 쪽이 왼쪽(x −0.45 → +0.45 로 가늘어짐). 아래: 반대(큰 쪽이 오른쪽).
- 벨트 위치 x ∈ [−0.35, 0.35]. 그 위치의 반지름: Ru(x) = 0.36 − 0.311·x, Rl(x) = 0.36 + 0.311·x (원뿔의 선형 보간, 두 반지름의 합이 일정해 벨트 길이가 거의 일정).
- 벨트 폭 0.10, 경로는 008 과 같은 방식(x 위치의 YZ 평면 열린 벨트).

## 동작
- 벨트 위치 x(T) = 0.35 · sin(2π T / 10) — 천천히 좌우로 이동(T 는 |speed| 로 누적한 시간).
- 구동각 = theta, 종동각 += omega · Ru/Rl · dt. 매 프레임 `Belt.setPath`.

## 표시
- tag '구동 원뿔 풀리', '종동 원뿔 풀리'. notes: `[{ label: '속도비(종동/구동)', value: (Ru/Rl).toFixed(2) }, { label: '변속', value: '연속(무단)' }]`

## 확인
- t=2.5(x 최대, 종동 느림) 와 t=7.5(x 최소, 종동 빠름) 캡처에서 벨트 위치와 속도비가 다르다. 벨트가 원뿔 표면에 붙어 있다.
