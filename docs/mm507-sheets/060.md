# 060 벨트 두 단 속도
판화(public/mm507/fig/060.png, 확대 shots/_verify/060-fig-x4.png — Fable 교차 읽기 2026-11-25): 축을 옆에서 본 그림 하나. 위쪽 가로 축에 통 풀리가 둘: 왼쪽은 크고(반지름 ≈ 260 픽셀) 오른쪽은 작다(≈ 148). 아래 가로 축에 풀리가 네 개 — 왼쪽에 둘, 오른쪽에 둘이 붙어 있고(묶음마다 가운데에 세로 금 1줄), **네 개 모두 폭과 지름이 거의 같다**(반지름 ≈ 255~262, 위 왼쪽 큰 통과 같은 크기). 위 통 하나의 폭 = 아래 풀리 두 개의 폭. 세로 벨트(꺾임 표시로 끊어 그림)가 두 줄, 벨트 폭은 풀리 폭의 절반쯤: 왼쪽 벨트는 위 큰 통의 왼쪽 끝 → 아래 왼쪽 묶음의 **바깥(왼쪽) 풀리**, 오른쪽 벨트는 위 작은 통의 왼쪽 끝 → 아래 오른쪽 묶음의 **안쪽(왼쪽) 풀리**에 걸려 있다.
원문 요지: 아래 축 풀리 넷 중 바깥 둘은 헐겁고 안쪽 둘은 고정. 왼쪽 벨트는 헐거운 풀리, 오른쪽 벨트는 고정 풀리 위에 있어 아래 축에 **느린** 운동. 오른쪽 벨트를 헐거운 풀리로, 왼쪽 벨트를 고정 풀리로 옮기면 **더 빠른** 운동.

★ 판화 읽기
1. 바퀴: 풀리 6개. 위 축 2개(왼쪽 큰 통, 오른쪽 작은 통 — 지름비 약 1 : 0.57), 아래 축 4개(모두 위 큰 통과 같은 지름, 폭은 위 통의 절반).
2. 줄·벨트: 2개(둘 다 열린 평벨트, 닫힌 고리, 가운데는 끊어 그림). 왼쪽 벨트: 위 큰 통(왼쪽 끝) → 아래 왼쪽 묶음의 바깥 풀리. 오른쪽 벨트: 위 작은 통(왼쪽 끝) → 아래 오른쪽 묶음의 안쪽 풀리.
3. 교차 가닥: 없음.
4. 고정점: 판화에 축받이가 그려져 있지 않다(판화로는 알 수 없음). 두 축은 제자리에서 도는 축.
5. 추·손잡이·크랭크: 없음.
6. 기어: 없음.
7. 한 줄에 놓인 것: 두 축이 평행(가로). 위 큰 통 바로 아래에 왼쪽 묶음, 위 작은 통 바로 아래에 오른쪽 묶음(통의 양 끝 = 묶음의 양 끝, 같은 세로선). 두 벨트 모두 저마다 통의 왼쪽 끝 칸.
8. 글자: 판화에 글자 없음.
9. 판화와 원문이 다른 곳: 없음. (오른쪽 벨트 = 작은 통 → 큰 풀리 = 느림, 왼쪽 벨트 = 큰 통 → 같은 크기 풀리 = 빠름. 원문의 느림·빠름과 맞다.)

## 구동
위 축(각 θ += OMEGA·speed·dt). 벨트 두 줄이 함께 옆(+X)으로 한 칸 옮겨 가 상태가 바뀐다.

- 위 축 U: y = 2.85, `rod` x −1.65…1.25, 반지름 0.045. name `upperShaft`(두 통과 한 그룹).
  - 큰 통 풀리 UL: `pulley(0.42, { width: 0.76, spokes: 6, flat: true, driver: true })` x 중심 −1.02(x −1.40…−0.64) + `rimStripes(0.42, 0.76, 6)`.
  - 작은 통 풀리 UR: `pulley(0.24, { width: 0.76, spokes: 6, flat: true, driver: true })` x 중심 0.50(x 0.12…0.88) + `rimStripes(0.24, 0.76, 6)`.
  - 둘 다 U 에 고정, 같은 각 θ.
- 아래 축 S: y = 1.30, x −1.65…1.25, 반지름 0.045. name `lowerShaft`(고정 풀리 둘과 한 그룹).
  - 아래 풀리 넷은 모두 `pulley(0.42, { width: 0.37, spokes: 4, flat: true })` + `rimStripes(0.42, 0.37, 6)` (판화: 같은 지름·같은 폭).
  - 왼쪽 묶음: 헐거운 풀리 LL x 중심 −1.215(x −1.40…−1.03), name `looseLeft`; 고정 풀리 FL x 중심 −0.825(x −1.01…−0.64).

- 판화에 없음(보충): `wallBracket` 4개(U·S 축 양 끝 x −1.65·1.25, z = 0.28, backZ = −0.30)뿐. 예전의 벨트 포크는 판화에 없어 뺐다.
- 전시 영역: x −1.7…1.3, y 0.88…3.27, z −0.15…0.71.

## 동작
θ = 구동 누적각, 주기 14 rad(약 8.8초). `acc(θ, segs)` = 주기마다 구간에 머문 θ 길이의 누적.
| θ mod 14 | 상태 | 벨트 이동 u (0→1, smoothstep) |
|---|---|---|
| 0–6 | 느림: 왼 벨트 LL(헐거움), 오른 벨트 FR(고정) — 판화의 상태 | 0 |
| 6–7 | 이동(전달 없음) | 0→1 |
| 7–13 | 빠름: 왼 벨트 FL(고정), 오른 벨트 LR(헐거움) | 1 |
| 13–14 | 되돌림(전달 없음) | 1→0 |
- 벨트 x = 시작 + 0.39·u (왼 −1.215 → −0.825, 오른 0.305 → 0.695).
- 구동: φU = θ. 벨트 표시 `setOffset`: 왼 0.43·θ, 오른 0.25·θ.
- 속도비(위 축 대비): 느림 = 0.24/0.42 = 0.571, 빠름 = 0.42/0.42 = 1.0 ⇒ 빠름/느림 = 1.75배.
- Ds = acc(θ, [[0, 6]]), Df = acc(θ, [[7, 13]]).
- 아래 축: φS = 0.5714·Ds + 1.0·Df (S, FL, FR 의 로컬 rotation.z).
- 헐거운 풀리: φLL = 1.0·Ds(왼 벨트가 걸린 느림 구간에만 구동), φLR = 0.5714·Df. 구동 안 될 때는 멈춘 각 유지.
- 모두 +X 회전(벨트 앞쪽 가닥이 내려감), 방향 같음. 속도 차는 위 통 반지름 / 아래 풀리 반지름 비로만 생긴다.

## 확인
- t=1(θ=1.6), t=1.6(θ=2.56): 느림 상태(판화). 왼 벨트는 왼쪽 묶음의 바깥 풀리 위(그 풀리만 위 축과 같은 속도로 헛돈다), 오른 벨트는 오른쪽 묶음의 안쪽 고정 풀리 위(아래 축이 0.57배로 돈다). 풀리 줄무늬로 회전이 보인다.
- t=6(θ=9.6): 빠름 상태, 벨트 두 줄이 오른쪽으로 한 칸 옮겨 있고 아래 축이 위 축과 같은 속도로 돈다.
- 벨트가 풀리 폭 안(벨트 0.18, 풀리 0.37)인지, 오른 벨트의 두 가닥이 아래로 벌어지는지(위 0.25, 아래 0.43).

## 판화 대조 후 고친 것 (Fable 교차 읽기 2026-11-25)
- 구성(위 통 2, 아래 풀리 4, 바깥 둘 헐겁고 안쪽 둘 고정, 왼 벨트 = 헐거운 쪽·오른 벨트 = 고정 쪽에서 시작)은 판화·원문과 일치.
- 아래 풀리 폭: "좁은 것(0.24) + 넓은 통(0.50)" → 판화대로 **네 개 모두 같은 폭(0.37)**. 판화에서 좁아 보이던 것은 풀리가 아니라 그 위에 걸린 벨트다.
- 아래 풀리 지름: 왼쪽 묶음 0.30·오른쪽 묶음 0.40 → 판화대로 **네 개 모두 위 큰 통과 같은 0.42**, 작은 통 0.25 → 0.24. 속도비 0.625/1.4 → **0.571/1.0**(판화의 지름비대로. 원문은 수치를 주지 않는다).
- 판화에 없는 벨트 포크를 뺌(이름표 '벨트 포크'도).

## 검증 후 수정 (Opus, 2026-11-25)
- 판화와 같은 기구(위 통 2, 아래 풀리 4, 바깥 헐겁고 안쪽 고정, 평벨트 2줄)이고, t=1·4.06(이동 중)·6(빠름) 정면 촬영에서 두 벨트가 한 칸 옮겨 가며 림 폭 안에 앉음을 확인.
