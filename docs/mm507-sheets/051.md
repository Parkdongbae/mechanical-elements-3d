# 051 유니버설 조인트 (2) — 두 고리 맞걸이형
판화: 비스듬히 마주 기운 굵은 막대 두 개가 위에서 만나 "∧"(약 150°)를 이룬다. 두 막대의 끝은 각각 길쭉한 타원 고리가 되어 사슬 고리처럼 서로 꿰어 걸려 있고, 맞닿는 꼭대기에 작은 핀 두 개가 보인다. 왼쪽 고리는 정면으로 열린 면이 보이고 오른쪽 고리는 거의 모서리로 서 있다(서로 수직). 원문(50번과 함께 있는 짧은 글): 두 가지 유니버설 조인트 — 이 그림은 그중 고리형. 쉬운 풀이: 50번과 같은 목적의 다른 모양 이음으로, 서로 걸린 두 고리로 비스듬한 두 축을 잇는다.

판화 해석: 한 판에 그림이 하나뿐이라 그것을 만든다(50번의 십자형은 050 설계표 몫). 두 고리가 서로 수직인 평면에 꿰어 걸리면 두 축이 꺾여 있어도 한 축의 회전이 다른 축으로 전달되는데, 이것이 훅 조인트(십자 조인트)와 같은 구속이다 — 고리 평면 법선 두 개가 항상 수직. 따라서 피동 고리의 자세는 구동 고리에서 식으로 구한다.

## 부품과 치수 (전시 영역: x ±2.2, y ≤ 3.3, z −0.25~0.8)
- 조인트 중심 O = (0, 2.2, ZC = 0.2). 기울기 b = 15°. 왼쪽 축 방향(조인트에서 멀어지는 쪽) d1 = (−cos b, −sin b, 0), 오른쪽 d2 = (cos b, −sin b, 0). 두 축 사이각 150°(꺾임 30°). e1 = −d1, e2 = −d2(조인트 쪽).
- 고리 A(구동, 청동) `ovalRing(0.5, 0.2, 0.025, { driver: true })`, 고리 B(피동, 황동) `ovalRing(0.5, 0.2, 0.025)`: 긴 반축 La = 0.5, 짧은 반축 wa = 0.2, 관 반지름 0.025. 고리 A 의 앞 끝이 O 를 e1 쪽으로 δ = 0.28 넘어가고(B 도 e2 쪽으로 0.28), 고리 중심은 로컬 x = δ − La = −0.22(x 는 e1 방향). 두 고리가 서로의 구멍을 지나 꿴다.
- 축 막대: 반지름 0.045, 고리 뒤 끝(O 에서 2La − δ = 0.72)부터 1.5 까지(끝 x = ±1.449, y = 1.812). 회전 표시용 청동 칼라(반지름 0.07, 폭 0.06) s = 1.0 에 노란 표시선. 고리 앞끝 안쪽에 조임 핀 2개(판화의 꼭대기 핀, 작은 원기둥 반지름 0.03).
- 베어링: 각 축에 2곳 s = 1.05, 1.4 — 뒤판(z −0.30)에서 나온 `castIron` 기둥(반지름 0.07)이 z = ZC 까지 와서 축을 둘러싼 링(tubeProfile 안 0.045 바깥 0.085 폭 0.07). 4곳.
- 깊이: 고리 폭 ±0.2 + 관 0.025 → z −0.025~0.425, 영역 안. 위쪽 y 최대 약 2.6.
- 고리 간격 검증(`shots/_verify/s051.mjs`): 위 치수에서 한 바퀴 360 자세 전부 두 고리 중심선 최소 거리 0.060(구동각 φ = 0, 90°, 180°, 270° 근처) ≥ 2×0.025 + 0.01. 서로 뚫지 않는다. (La 0.45, wa 0.16, δ 0.2 은 0.058, La 0.5, wa 0.22, δ 0.3 은 0.069 — 위 값 0.5/0.2/0.28 사용.)

## 동작식 (모든 자세 = theta 의 함수)
- φ = theta. z = (0,0,1). 고리 A 평면 법선 n1 = cos φ·z + sin φ·(d1 × z). 로컬 기저(x = e1, y = n1 × e1, z = n1)를 그룹 G1(원점 O)의 회전으로 준다 — `Matrix4.makeBasis` → quaternion. 고리·축·칼라·표시선은 G1 의 자식.
- 피동: n2 = normalize(d2 × n1). 기저(x = e2, y = n2 × e2, z = n2)를 G2(원점 O)에. 매 프레임 절대 자세 계산. n2 ⟂ n1 이 항상 성립 → 두 고리는 서로 수직 평면.
- 피동각 ψ = atan2(n2·(d2 × z), n2·z), 속도비 = −dψ/dφ = cos 30° / (1 − sin²30°·sin²φ) = 0.866 / (1 − 0.25 sin²φ) → 0.866(φ = 0) ~ 1.155(φ = 90°). 한 바퀴 평균 1. (s051 수치와 일치: φ = 30° 에서 ψ 가 26.6° 변해 0.887, φ = 90° 근처 1.12~1.155)
- 회전 방향: 입력은 d1 둘레 +φ, 출력은 e2 둘레 +|ψ| (일직선 축이라면 같은 방향).
- 시작 φ = 0: 고리 A 평면 = XY 평면(정면으로 열려 보임), 고리 B 는 z 방향을 포함해 모서리로 보임 — 판화와 같다.

## 표시
- rotArrow(0.3, true): 구동축 O + d1·0.6 위치, `Quaternion.setFromUnitVectors(Z, d1)`. rotArrow(0.3, true): 피동축 O + d2·0.6 위치, `setFromUnitVectors(Z, e2)`. 둘 다 G1·G2 밖에 고정.
- tag: '구동축(회전)', '고리 맞걸이 조인트(두 고리가 서로 수직)', '피동축(속도가 오르내림)'. 위치는 각 축 아래(y −0.45)와 조인트 위(y + 0.55).
- notes: 축 사이각 '150° (30° 꺾임)', 구동각(°), 피동각(°), 지금 속도비(0.87~1.15), 한 바퀴 평균 '1 : 1'.

## 확인
- t=1(theta 1.6), t=1.6(2.56): 구동 표시선이 55° 돌고 고리 A 가 면에서 모서리 쪽으로 기운다. 피동 고리 B 도 따라 도는데 구동 55° 와 같은 각이 아니다(notes 속도비가 변함). 두 고리 평면은 항상 수직, 서로 뚫지 않는다.
- 근접 `cam=0.6,2.5,1.5,0,2.2,0.2`(꿴 자리) 두 시점 이상, 옆 `cam=3.2,2.2,0.2,0,2.2,0.2`, 위 `cam=0,4.4,1.0,0,2.2,0.2`: 고리끼리 관통 없음, 축이 베어링 링을 지남.
- 수치: theta 0~2π 를 0.05 간격으로 두 고리 중심선 최소 거리 ≥ 0.05, 속도비 최소·최대 0.866·1.155.

## 키트 추가
이미 구현됨: kit/k051.ts 의 `ovalRing(a: number, b: number, tube: number, opts?: { driver?: boolean }): THREE.Group` — 로컬 XY 평면의 타원 관(긴 반축 a 가 X). 모델은 `import { ovalRing } from '../kit/k051'`. 나머지는 기존 키트(`displayStand`, `rod`, `rotArrow`, `tag`)와 geom 의 lathe·tubeProfile 로 충분.

## 의문점
- 판화의 오른쪽 고리는 완전히 모서리가 아니라 비스듬히 열려 보인다(시작 자세 φ = 0 보다 φ ≈ 30° 쯤이 판화와 가장 비슷). 시작 자세는 φ = 0 그대로 두고 t=1 캡처로 대조한다.
- 판화는 두 번째 종류의 조인트를 따로 그리지 않아(50번 참조) 이 번호는 고리형 하나만 만든다.
- 판화의 꼭대기 핀 두 개는 고리 앞끝을 맞잡는 조임 핀으로 해석했다(고리가 서로 꿰는 구조는 변하지 않음).
