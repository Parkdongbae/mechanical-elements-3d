# 088 연속 회전을 간헐 회전으로(달팽이 캠과 멈춤쇠 원판)
판화(public/mm507/fig/088.png, 4배 확대 shots/_verify/088-fig-x4.png 로 다시 읽음): 그림 하나, 정면. 큰 원(원판 B)과 그 안의 조금 작은 닫힌 곡선(캠 A), 가운데 축(검은 원 + 테). 안쪽 곡선은 원이 아니다 — 왼쪽(멈춤쇠 C 바로 아래)에 **가로로 짧은 턱**이 하나 있고, 턱 아래쪽의 반지름이 가장 크며(축에서 약 580), 거기서 아래 → 오른쪽 → 위로 돌아가며 반지름이 줄어(아래 560, 오른쪽 470, 위 410) 턱 바로 위에서 가장 작다(430). 곧 한 바퀴에 턱이 하나뿐인 **달팽이 캠**이다. 원판 B 위에 빗금 친 작은 네모 둘: C(왼쪽, 턱 바로 위에 얹혀 있다)와 D(오른쪽, 캠 곡선 밖에 떨어져 있다). 아래쪽 화살표는 왼쪽을 가리킨다(아래가 왼쪽으로 = 시계 방향).
원문 요지: 연속 회전을 간헐 회전으로 바꾼다. 멈춤쇠 C, D 가 달린 원판 B 는 캠 A 의 중심과 **어긋난 중심**에서 돈다. 캠 A 를 계속 돌리면 B 가 간헐적으로 돈다. 멈춤쇠는 반 바퀴마다 캠의 턱(offset)에서 저절로 벗어나고, B 는 캠이 한 바퀴를 마칠 때까지 쉬었다가 같은 운동을 되풀이한다.

★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 2개. 원판 B(큰 원, 반지름 약 745) > 캠 A(턱 끝 반지름 약 580, 가장 작은 곳 410). 같은 축 근처에 겹쳐 있다(캠이 앞).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(축의 단면뿐). 위·왼쪽의 곧은 선은 판 테두리.
5. 추·손잡이·크랭크는? → 없음. 구동은 캠 A(원문).
6. 기어는? 무엇이 무엇을 미는가? → 이는 없다. 캠 A 의 턱 면(왼쪽, 위를 보는 짧은 가로 면)이 멈춤쇠 C 의 아랫변을 밀어 올린다(시계 방향). 멈춤쇠 D 는 캠 둘레 밖에 있어 닿지 않는다.
7. 한 줄에 놓인 것은? → 멈춤쇠 C — 축 — 멈춤쇠 D 가 한 수평선. 턱은 C 바로 아래.
8. 글자가 가리키는 부품은? → A = 캠(가운데), B = 멈춤쇠 달린 원판(바깥 고리 부분의 글자), C·D = 멈춤쇠(네모). 화살표 = 캠의 회전 방향(시계).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화의 큰 원은 축과 거의 같은 중심으로 그려졌지만 원문은 "어긋난 중심"이라고 한다. 판화에서도 C 는 축에서 가깝고(중심 거리 약 532) D 는 멀어(약 590) 원판 중심이 축보다 **오른쪽으로 약 30** 치우쳐 있다고 읽힌다 — 같은 기구다. 다만 판화 치수(치우침 4%)로는 멈춤쇠가 턱에서 벗어나지 못하므로(먼 쪽에서도 멈춤쇠 안쪽 변 530 < 턱 끝 580) 치우침을 0.08(8%)로 키웠다. 질문 없음.
- 그 밖의 선: 축 둘레의 겹 원 = 축과 허브(깃). 캠 곡선의 굵은 쪽(오른쪽·아래)은 음영.

## 해석(결정 사항)
- 원판 B 의 중심은 캠 축에서 오른쪽(+x)으로 e = 0.08. 멈춤쇠는 B 중심에서 반지름 0.70 의 마주 보는 두 자리에 있어, 왼쪽(가까운 쪽)에 오면 축에서 0.62, 오른쪽(먼 쪽)에 가면 0.78 떨어진다.
- 턱 끝 반지름 0.70, 턱 뿌리 0.52. 가까운 쪽 멈춤쇠(안쪽 변 0.55 ~ 바깥 변 0.69)는 턱에 걸리고, 밀려서 먼 쪽으로 가는 동안 축에서 멀어져 안쪽 모서리가 0.70 을 넘는 순간 턱 끝에서 벗어난다(벗어나는 자리 = B 중심에서 본 각 +29.9°, 오른쪽 위).
- 그때 반대쪽 멈춤쇠는 −150.1°(왼쪽 아래)에 와 있다. 캠이 나머지를 돌아 턱이 그 멈춤쇠에 닿으면 다시 민다. 그래서 **원판은 캠 한 바퀴마다 정확히 180°** 돈다(캠 188.6° 동안 돌고 171.4° 동안 쉰다) — 원문의 "반 바퀴마다 벗어나고 한 바퀴를 마칠 때까지 쉰다".
- 캠 둘레는 턱 끝(0.70)에서 뒤로 200° 에 걸쳐 0.52 까지 매끄럽게(코사인) 줄어들고 나머지는 0.52. 쉬고 있는 먼 쪽 멈춤쇠 밑(≥ 0.70)과 기다리는 가까운 쪽 멈춤쇠 밑(≥ 0.55)을 닿지 않고 지나간다.
- 원판 B 는 뒤판에 박힌 **치우친 보스**(판화에 없음) 위에서 돌고, 캠 축은 그 보스의 치우친 구멍을 지나 앞으로 나온다. 쉬는 동안 B 를 잡아 두는 것은 마찰(판화·원문에 따로 없음).
- 치수·접촉 식은 키트 `kit/k086.ts` 의 `K88`·`state88` 에 들어 있다(`shots/_verify/s088.mjs`, `t086kit.ts` 로 두 주기 다각형 침범 0.0006 확인). 치수를 바꾸려면 다시 돌린다(턱 끝 0.705 만 돼도 걸림 순서가 깨진다).

## 동작 (모두 `state88(theta)` 의 닫힌 식, 주기 2π)
- u = theta + 33.74°(처음 자세는 걸린 뒤 33.74° 지난 때), N = floor(u / 360°), τ = u − 360°·N.
- τ < 188.62° **밀기**: 턱 면(축에서 나가는 반직선)이 멈춤쇠 뒷변(아랫변)의 모서리에 닿는다는 조건으로 원판 각을 푼다 — 거울 평면(반시계)에서 모서리의 B 중심 반지름 ri, 턱 면 각 φ 일 때 모서리 각 β = φ + asin(e·sin φ / ri). 두 뒷모서리와 "턱 끝점이 뒷변 위" 경우 가운데 가장 앞선 값을 쓴다. 이번 주기에 돈 각 adv 는 0 → 180°(캠 48° 에 43.6°, 96° 에 85.8°, 144° 에 130.6° — 거의 같은 빠르기).
- 188.62° ≤ τ < 360° **쉼**: adv = 180°.
- 원판 rotation.z = −(N·180° + adv − 29.90°) (라디안으로, theta = 0 에서 0). 캠 rotation.z = −theta.
- 한 주기에 정확히 −180°(누적 오차 없음: 0, 2π, 4π 에서 0°, −180.000°, −360.000°). 역회전(theta 감소)은 같은 식을 거꾸로 읽는다(실제 기구는 거꾸로 돌리면 턱이 밀지 못한다 — 표시용).
