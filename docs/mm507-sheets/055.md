# 055 두 속도 기어 (피니언 B — 원문은 D)
판화(public/mm507/fig/055.png, 4배 확대 shots/_verify/055-fig-x4.png 로 다시 읽음): 정면 그림 하나. 바깥에 **안쪽 이가 난 큰 링 기어 C**, 그 한가운데 검은 축 위의 **중간 기어 A**(바깥 이, C 와 같은 중심), 왼쪽 안에 **작은 피니언 B**(가운데 축 점)가 A(오른쪽에서)와 링 C(왼쪽에서) **둘 다에 동시에** 물린다. 원문은 피니언을 "D"라고 부르지만 판화에는 D 가 없고 그 자리에 **B** 가 찍혀 있다(507movements.com 도 B 로 바로잡음) → 이름표는 "B 피니언(원문은 D)".
원문 요지: 같은 축에 있는 두 기어 A·C 에 피니언이 서로 다른 속도를 준다. 해석: 피니언 하나가 바깥 이(A, 외접)와 안쪽 이(C, 내접)에 동시에 물리므로 A 와 C 는 **서로 반대 방향**, 속도는 이 수에 반비례.

★ 판화 읽기 (질문표)
1. 바퀴는 몇 개이고 크기 차례는? → 기어 3개. 링 C(가장 큼, 안쪽 이) > A(가운데, 바깥 이) > B(피니언). 4배 확대에서 잰 바깥지름 비 C 안쪽 이끝 ≈ 870 : A ≈ 430 : B ≈ 280(픽셀), 이 간격 ≈ 62픽셀 → 잇수 약 **44 : 20 : 12**(옛 설계표의 40 : 16 : 12 는 A 가 너무 작았다).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에 받침은 그려져 있지 않다. A 의 축(검은 원)과 B 의 축(작은 검은 점)이 뒤판에 받쳐진다고 본다. 링 C 의 받침은 판화에 없음.
5. 추·손잡이·크랭크는? → 없음. 구동은 피니언 B(원문 "by the pinion").
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → C 는 **안쪽** 가장자리(바깥은 매끈한 테두리 선 한 겹), A·B 는 바깥. B 가 A 의 **왼쪽**에서 외접, C 의 **왼쪽 안벽**에서 내접. A 와 C 는 직접 물리지 않는다(사이에 빈 틈).
7. 한 줄에 놓인 것은? → A 중심 = C 중심(동심). B 중심은 그 **왼쪽 같은 높이**(판화는 아주 조금 아래 — 무시).
8. 글자가 가리키는 부품은? → A = 가운데 기어(축 옆), B = 왼쪽 피니언(아래), C = 링(아래쪽 빈 곳).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → 원문의 "D" 가 판화에는 "B". 기구는 같으므로 질문 거리 아님(없음).

## 구동
피니언 B. theta += OMEGA·speed·dt (1.6 rad/s). 반시계.

## 부품과 치수 (모듈 m = 0.045, 키트만 사용, 키트 추가 없음)
- 잇수 B 12, A 20, C 44. 동심 조건 z_C = z_A + 2·z_B (20 + 24 = 44) → 피니언이 A 와 C 에 같은 중심 거리로 물린다.
- 피치 반지름: B 0.27, A 0.45, C 0.99. 피니언 중심과 링 중심의 거리 0.72 = r_A + r_B = r_C − r_B.
- 링·A 중심 O = (0, 1.85). 피니언 중심 P = (−0.72, 1.85) (링 안 왼쪽, α = π). 기어 z = 0.12.
- C(name `ringC`): `internalGear(44, 0.045, { width: 0.12, wall: 0.11 })`, `ringRoot(44, 0.045)` = 1.0395, 테두리 바깥 R_OUT = 1.0395 + 0.11 + 0.012 = 1.1615.
- A(name `gearA`): `spurGear(20, 0.045, { width: 0.12, spokes: 4 })` + `shaftZ(0, 1.85, 0.34, 0.05)`.
- B(name `pinionB`): `spurGear(12, 0.045, { width: 0.14, spokes: 3, driver: true })` + `shaftZ(−0.72, 1.85, 0.36, 0.05)`.
- **판화에 없음(보충)**: 링 C 를 받치는 바깥 롤러 3개(30°, 150°, 270°) — 판화의 링에는 축·살이 없어 034 와 같은 방식으로 받친다. 롤러 중심 = O + (R_OUT + 0.07)(cos, sin) = 반지름 1.2315, 롤러 반지름 0.07, 폭 0.15, 각 롤러는 `shaftZ(x, y, 0.2, 0.025)` 에 얹고 표시점 1개, 롤러 각 = −θ_C·R_OUT/0.07. 가장 아래 롤러 바닥 y = 1.85 − 1.2315 − 0.07 = 0.548, 링 위 y = 3.01.

## 동작 (모든 자세는 theta 의 절대 함수, H1)
- B.rotation.z = θ (반시계).
- A.rotation.z = `meshAngle([−0.72, 1.85], 12, θ, [0, 1.85], 20)` (외접, dθ_A/dθ = −12/20 = −0.6, 시계).
- C.rotation.z = π − (S_C/S_B)(π − θ − S_B/2), S_B = 2π/12, S_C = 2π/44 (034 와 같은 내접 식, α = π). dθ_C/dθ = +12/44 = +0.2727, 반시계.
- 두 식은 같은 피니언 위상 θ 에서 나오므로 A·C 가 동시에 맞물림. 속도비 A : C = −0.6 : +0.273 (크기 2.2 : 1, 방향 반대).

## 표시
- rotArrow: B 반시계(r 0.2, 피니언 위 z 0.3), A 시계(r 0.3), C 반시계(r 0.8, 링 오른쪽 위 z 0.26). 구동 B 만 bronze.
- tag 이름표: 'B 피니언(구동, 원문은 D)' (−1.55, 1.85), 'A 안쪽 기어 20' (0.55, 3.2), 'C 링 기어 44' (−0.6, 3.2), '받침 롤러(판화에 없음)' (1.45, 0.75). 모두 링 바깥.
- notes: 잇수(B 12 / A 20 / C 44), 속도비 A = −0.6·B, C = +0.27·B, 'A 와 C 는 반대 방향', 지금 각도(A·C 회전수).

## 확인 (t=1, t=1.6 정면 + cam)
- t=1(θ 1.6) → t=1.6(θ 2.56): 피니언 표시선이 0.96 rad 반시계, A 는 0.576 rad 시계, C 는 0.262 rad 반시계.
- 접점 근접 두 곳: 피니언 오른쪽(A 쪽) `cam=−0.25,2.0,1.2,−0.45,1.85,0.12`, 피니언 왼쪽(링 쪽) `cam=−1.1,2.0,1.2,−0.99,1.85,0.12`. 이가 이골에 들어가고 겹침 없음.
- G6 대조: 링 안쪽에 이, 한가운데 A, **왼쪽 같은 높이**에 피니언, A 와 링 사이는 비어 있음. A 지름이 링 안지름의 절반쯤.
