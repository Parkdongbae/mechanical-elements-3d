# 135 삼각 편심 변형
원문 요지(글자가 일부 깨짐): 삼각 편심(91번)의 **변형**으로 파리 조폐국의 증기 기관에 쓰였다. **뒤쪽의 둥근 원판이 삼각 태핏(밀대)을 달고 있고**, 이 태핏이 밸브 막대에 번갈아 왕복 직선 운동을 준다. 밸브는 한 행정이 끝날 때마다 잠깐 쉬었다가, 재빨리 증기구를 가로질러 다음 끝으로 밀려 간다. (글자·수치 없음)

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/135-fig-x4.png` 로 다시 읽음. 잰 값(확대본 px): 큰 원의 한가운데 x 902·y 808, 반지름 688 / 삼각 태핏 위 꼭짓점 (905, 800), 아래 두 모서리 (620, 1370)·(1230, 1370), 아래 볼록 변의 맨 아래 y 1445 / 틀 창 x 240~1590, y 800~1445 / 틀 바깥 x 90~1750(옆변 볼록), y 685~1555 / 작은 겹 원(안에 네모)의 한가운데 x 910·y 1135.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 기어·풀리는 없다. 도는 것은 **큰 원판 1개**와 그 앞면에 붙은 **삼각 태핏 1개**(세 변이 볼록한 뢸로 삼각형, 폭 645 px). 원판 반지름(688)이 태핏 폭(645)보다 조금 크다. **원판의 중심이 태핏의 위 꼭짓점과 같은 점이다**(잰 차이 3~8 px) — 91번처럼 축이 삼각형의 꼭짓점에 있다는 뜻.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 겹침 차례만 있다: 원판(맨 뒤) → 태핏·틀(같은 층) . 원판의 윤곽이 틀 가로대·윗 막대 뒤를 지나는 곳은 **점선**(가려진 선)으로 그렸다 — 윗 막대 꼭대기, 틀 위 가로대의 좌우 끝, 아래 가로대 가운데의 세 군데.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 없다. 축은 원판 뒤에 가려 보이지 않고(제자리에서 돈다), 위·아래 막대의 안내도 그리지 않았다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 축에 고정된 원판(+태핏).
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 이는 없다. 맞닿는 짝은 **태핏 윤곽 ↔ 틀 창의 윗면·아랫면**(곧은 가로면). 판화의 순간에는 태핏의 위 꼭짓점이 창 윗면에, 아래 볼록 변이 창 아랫면에 닿아 있다(창 높이 645 = 태핏 폭). 창의 좌우 안벽(곧음)은 태핏에 닿지 않는다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 원판 중심 = 태핏 위 꼭짓점 = 창 윗면의 한가운데, 그리고 태핏 대칭축·작은 겹 원·위아래 막대가 한 세로줄. 창 윗면·아랫면은 평행한 가로선.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 135 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 원문("뒤의 원판이 태핏을 달고 있다", "행정 끝마다 쉰다")과 판화(원판 중심 = 꼭짓점)가 맞고, 폭이 일정한 꼴이라 어느 각도에서나 두 면에 닿은 채 계속 돈다(측정: 침범 0, 틈 0.002).
- **오독하기 쉬운 선**: 태핏 한가운데의 작은 겹 원 + 네모는 **축이 아니다**. 태핏을 원판에 죄는 네모 머리 볼트와 와셔다(위치가 삼각형의 도심 — 꼭짓점에서 폭의 0.52배, 계산 0.577배 근처). 여기를 축으로 삼으면 틀이 거의 움직이지 않고 쉬는 구간도 없어 원문과 맞지 않는다.
- 그 밖의 선: 틀 위·아래의 세 칸으로 나뉜 덩어리 = 육각 너트(막대를 틀에 죔). 윗 막대는 굵고 길며(끝이 그림 위로 이어짐) 아랫 막대는 너트 아래 짧은 토막(끝이 잘림). 틀 옆변의 겹선 = 바깥으로 볼록한 테.

## 해석(결정 사항)
- 91번과 같은 원리(뢸로 삼각형이 꼭짓점 둘레로 돈다)이고, 다른 점은 **태핏을 축에 직접 꿰지 않고 축 끝의 원판 앞면에 볼트로 달았다**는 것. 그래서 축이 틀을 뚫고 나오지 않고(앞에서 축이 안 보임) 틀·막대가 한 평면에 놓인다.
- 태핏 윤곽 = 폭 w = 0.5 인 뢸로 삼각형을 ρ = 0.03 만큼 부풀린 꼴(판화의 아래 두 모서리가 살짝 둥글다). 축 = 부풀리기 전 삼각형의 꼭짓점 V0. 행정 = w.
- 한 바퀴 = 아래 멈춤 60° → 올라감 120° → 위 멈춤 60° → 내려감 120°. 판화는 아래 멈춤의 한가운데(태핏이 아래로 늘어진 자세).
- 회전 방향은 판화에 없다 → 반시계로 정함(어느 쪽이든 틀 운동은 같다).

## 구동
축(원판). theta += OMEGA(1.6)·speed·dt, θe = theta − 1.6 + π (t = 1 에서 θe = 180° — 판화 자세). 반시계. 한 바퀴 3.927 s.

## 동작 (모두 θe 의 닫힌 식 — 누적 오차 없음)
- `cam.rotation.z = θe`.
- `frame.position.y = yF = 1.75 + tappetLift135(θe) − 0.25`.
- `tappetLift135(θe)` 가 돌려주는 h (ψ = θe 를 −180°~180° 로 접은 절댓값):
  - ψ ≤ 30°: h = 0.5 (위 멈춤)
  - 30° ~ 90°: h = 0.5·cos(ψ − 30°)
  - 90° ~ 150°: h = 0.5·cos(ψ + 30°) + 0.5
  - ψ ≥ 150°: h = 0 (아래 멈춤)
- 주기 시간표(θe 를 0~360° 로 접어): 150°~210° **아래 멈춤**(0.654 s) → 210°~330° 올라감(1.309 s) → 330°~30° **위 멈춤**(0.654 s) → 30°~150° 내려감(1.309 s).
- 시각: **t = 1.0 (θe 180°, 판화 — 아래 멈춤 한가운데, yF = 1.5)**, **t = 1.6 (θe 235°, 올라가는 중, yF = 1.547)**, t = 2.96 (θe 359.7°, 위 멈춤 한가운데, yF = 2.0).

## 키트 추가
이미 구현됨: `kit/k134.ts` (134·135·136 공용, 모델은 `'../kit/k134'` 에서 직접 import. `npx tsc --noEmit` 에서 이 파일 에러 0)

- `tappetDisc135(): THREE.Group` — 원판 + 삼각 태핏 + 볼트(원점 = 축, 로컬 z 0 = 원판 앞면), `userData.outline`

- `plainShaftZ(x: number, y: number, z1: number, r?: number): THREE.Group` — 끝 너트 없는 Z 축(뒤판 ~ z1)
다른 키트에서 그대로 가져다 쓰는 것(고치지 않음): `rodGuide(axis, hole, zc, len?)`(k089 — 91번과 같은 안내). 공용: `displayStand()`, `rotArrow(r, ccw)`, `tag(text, pos)`.
