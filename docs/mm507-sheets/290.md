# 290 또 다른 추 탈진기
원문(en): "Another kind of pendulum escapement." — 추시계에 쓰이는 또 다른 종류의 탈진기이다. (원문은 이 한 줄뿐 — 구조는 판화로 읽는다.)
쉬운 풀이: 진자에 둥근 고리 틀이 달려 있고, 탈진 바퀴는 그 고리 한가운데에 고정된 축으로 돈다. 고리 안쪽 왼쪽·오른쪽에 팔레트(B·A)가 하나씩 붙어 있다. 진자가 오른쪽으로 가면 고리가 오른쪽으로 밀려 오른쪽 팔레트 A 는 바퀴에서 빠지고 왼쪽 팔레트 B 는 바퀴 이 사이로 들어간다. 그래서 A 에 걸려 있던 이가 풀리고 바퀴가 반 칸쯤 툭 돌아 다음 이가 B 에 걸린다. 진자가 왼쪽으로 가면 반대로. 진자가 한 번 오갈 때 바퀴는 이 하나(7 이 바퀴라 51.4°)씩 시계 방향으로 나아간다.
판화 묘사(원본 508×520 px, **정면**): 위 가운데 작은 매단 곳 C([208·125], 작은 덩이와 옆 돌기) 에서 가는 막대가 내려와 큰 고리 틀(중심 [212·318], 바깥 반지름 ≈ 97 px, 안 반지름 ≈ 82 px)의 꼭대기 [212·215] 에 붙고, 고리 바닥 K([212·412])에서 다시 막대가 아래로 판화 끝까지 내려간다. 고리 안쪽 오른쪽 [290·312] 에 작은 쐐기 팔레트 A, 왼쪽 [135·312] 에 작은 네모 팔레트 B. 고리 안 가운데 축 D([212·318], 두 겹 원)를 가진 바퀴에 갈고리 이 7(이끝 반지름 ≈ 65 px, 시계 방향으로 굽은 갈고리; 글자 E 가 A 옆 이, H 가 왼쪽 아래 이), 바퀴 위에 오른쪽을 가리키는 굽은 화살표(시계 방향).

## ★ 판화 읽기
판화 하나(정면). 판화 1 px ≈ 0.009(바퀴 이끝 65 px → 0.585). 판화 D [212·318] ↔ 세계 (0, 1.36), C [208·125] ↔ (0, 3.10).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 탈진 바퀴 D 1(갈고리 이 7, 이끝 반지름 0.585). 보충한 태엽통(반지름 0.45, 바퀴 뒤 같은 축 — 이 사이로 보임).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 고리 틀과 바퀴는 같은 층이지만 고리 안 반지름(0.755)이 이끝(0.585)보다 커서 겹치지 않음.
4. 고정점은? → 매단 곳 C(뒤판에 붙은 받침과 핀), 바퀴 축 D(뒤판 보스). 고리 틀은 바퀴 축과 닿지 않고 C 에만 매달림.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 고리 틀 자체가 진자: C 에서 막대 → 고리 → K 에서 막대 → 아래 끝 추(판화 밖 — 보충, 세계 y 0.33). 바퀴는 태엽통이 시계 방향으로 돌림(보충).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 바퀴 바깥 둘레에 시계 방향으로 굽은 갈고리 이. 팔레트 A(오른쪽)는 위에서 내려오는 이를 **윗면**으로, B(왼쪽)는 아래에서 올라오는 이를 **아랫면**으로 막는다. 이 수가 홀수(7)라 마주 보는 두 팔레트가 반 칸 어긋나 번갈아 문다.
7. 한 줄에 놓인 것은? → C·D·K·추가 세로선 x = 0(쉼). 팔레트 A·B 는 D 와 같은 높이 y 1.36.
8. 판화에 글자(A, B…)가 가리키는 부품은? → A 오른쪽 팔레트, B 왼쪽 팔레트, C 매단 곳, D 바퀴 축(바퀴), E·H 바퀴 이(이름만), K 고리 바닥에서 아래 막대가 나가는 곳.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 원문이 한 줄뿐이라 판화로만 읽음: 고리 틀이 진자와 한 몸이고 바퀴 축은 고정 — 다르게 읽을 여지(고리가 바퀴 축에 매달린 경우)는 진자 막대가 C 로 올라가므로 버림. (나) 고리가 C 둘레로 돌기 때문에 팔레트 면이 조금 기울고 오르내려, 이가 잡힌 동안 바퀴가 3.5° 앞뒤로 움직인다(되튐형) — 판화대로 두면 생기는 성질이라 그대로 두고 메모로 설명. (다) 판화의 진자 아래 끝·추·태엽통은 보이지 않음 → 보충. (라) 드롭(놓은 뒤 다음 팔레트에 닿기까지)이 21° 로 크다 — 마주 보는 두 팔레트·7 이 바퀴라는 판화 구성에서 나오는 값.

## 해석(결정 사항)
- **진자 각은 시간표로, 바퀴 각은 접촉에서**: ψ(t) = 4.5°·sin(π t)(주기 2 초, C 둘레 반시계 + — 고리가 오른쪽으로 감). 바퀴는 태엽통이 늘 시계 방향으로 미므로, 매 순간 φ = 이 끝이 팔레트 면(윗면·비탈·끝면)에 닿는 각(원·선분 교점)이다.
- shapely 로 바퀴·고리·팔레트 전체 다각형을 0.1° 간격 3600 자세로 겹쳐 보아 이끝 접촉 계산과 같음을 확인(차 0.0002°, 겹침 0, 닿는 동안 틈 ≤ 10⁻¹⁵).
- 팔레트 끝 안쪽 모서리를 0.035 비탈로 깎아 충격면을 만듦 — 이 끝이 비탈을 밀며 빠져나가 진자에 힘을 줌.
- 한 주기(2 초)에 정확히 −51.4286°(시계 방향 이 하나). 반 주기마다 21.3° 툭.

## 동작 (`state290(t)` — 결정적, 접촉 계산)
1. n = floor(t/2), τ = t − 2n, ψ = 4.5·sin(π τ)(도).
2. 접촉 계산. 이 k 의 끝은 D 중심 반지름 0.585 원 위, 각 α_k = 90° − 51.4286°·k + φ. 팔레트의 닿는 면(꺾은선)을 C 둘레로 ψ 만큼 돌려 세계로 옮긴다:
   - A: (0.775, 0.045) → (0.575, 0.045) → (0.540, 0.010) → (0.540, −0.045) (D 기준, 세계 y 에 +1.36)
   - B: (−0.775, −0.045) → (−0.575, −0.045) → (−0.540, −0.010) → (−0.540, 0.045)
   각 선분과 원(D, 0.585)의 교점(근의 공식, 매개변수 0~1)을 구해 각 α 를 잰다(A 는 −180°~180°, B 는 −360°~0° 로 맞춤). 바퀴는 시계 방향으로 돌므로 **α 가 가장 큰 교점**(먼저 닿는 점)을 고르고 φ = α − (90° − 51.4286°·k).
3. 구간별 팔레트·이: τ < 0.5 → A 와 k = 0, 교점이 없으면(이끝이 비탈 끝을 지남) B 와 k = 3. 0.5 ≤ τ < 1.5 → B 와 k = 3, 없으면 A 와 k = −1. τ ≥ 1.5 → A 와 k = −1. φ 에서 51.4286·n 을 뺀다.
4. 기대값(파이썬 검산 — 0.002° 안에서 맞아야 함):

## ★ 난도·질문
난도 **C·상** — 비원형 갈고리 이·팔레트 + 이끝 접촉 계산(원·선분)으로 바퀴 각, 고리가 C 둘레로 도는 좌표 변환. GLM 금지, Sonnet.
질문 거리(사용자에게) — 기본값으로 진행:
1. 원문이 한 줄뿐이라 판화로만 읽었다: 고리 틀 = 진자(C 에 매달림), 바퀴 축 고정. 기본값: 이 해석.
2. 고리가 C 둘레로 돌아 걸린 동안 바퀴가 3.5° 앞뒤로 움직인다(되튐형). 팔레트 면을 C 중심 원호로 깎으면 멈추게 할 수 있으나 판화는 평평한 네모 팔레트. 기본값: 판화대로 평평.
3. 판화 밖으로 이어지는 진자 아래 끝에 작은 추를 단다(받침대 때문에 짧음). 기본값: 추 반지름 0.11, y 0.33.
