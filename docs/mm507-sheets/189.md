# 189 분리 장치 변형 3
원문: "Another modification of 186." — 186(편심 막대를 밸브 장치에서 떼어 내는 장치)의 또 다른 변형. 186 은 "스프링 손잡이를 잡아 올려 노치에 걸리게 하면 핀이 편심 막대의 갭(홈)에서 빠져나와 분리된다."
판화 묘사: 아래쪽에 긴 가로 막대(편심 막대). 왼쪽 끝은 두 가닥으로 갈라진 홈(gab), 가운데는 위로 불룩한 허브(받침점 핀이 아래 공 모양으로 보임), 허브에서 위로 굽은 팔이 올라가 끝에 큰 눈 고리(속에 짙은 원판)를 이룬다. 막대 오른쪽 끝의 작은 눈에서 가는 링크가 위로 올라가 작은 눈(D)에 닿고, D 에서 왼쪽으로 짧은 팔이 이중 원(C1)에 이어지며 C1 에서 아주 긴 가는 막대가 위로 올라간다(판화 위가 잘림 = 손잡이까지 더 이어짐).

## 해석(결정 사항)
- 186 과 같은 원리로 다시 읽는다: 판화 위의 눈 고리(짙은 원판) [300·272] 는 **밸브 쪽 흔들 축**이고, 거기서 아래로 굽어 내려온 팔 끝에 **핀** [312·378] 이 있다(막대 아래로 보이는 둥근 판 = 팔의 핀 보스). 가로 막대 허브 아래의 반원 홈이 **갭** — 핀을 위에서 문다.
- 막대 왼쪽 갈라진 끝은 판화 밖 편심으로 이어진다 → 186 처럼 **편심(축 C = (−1.5, 0.95), 편심량 0.12)과 띠쇠**를 보충. 편심이 막대를 왕복시키는 원인.
- 당김 막대를 끌어올리면 링크가 막대 오른쪽 눈 R 을 들어 올려 막대가 편심 중심 둘레로 기울고 갭이 핀에서 위로 0.20 빠진다.
- 좌표: X = (px − 245)·0.0075, Y = (470 − py)·0.0075 + 0.26. 갭(핀) P0 = (0.5, 0.95), 흔들 축 O = (0.41, 1.75), 팔 길이 0.805, 편심 중심 ↔ 갭 2.0, 갭 → R 0.85, 링크 1.06, D.x = 1.31 고정.

## 구동
편심 축 theta += OMEGA·speed·dt (계속 돈다). 8π 주기(편심 4 바퀴, 15.7 s):
① 연결 (0 ~ 3π): 갭이 핀을 물고 편심 왕복이 팔을 −2°~15° 흔든다.
② 분리 (3π ~ 7π): 편심 위상 π(막대 왼쪽 끝 멈칫)에서 당김 막대를 들어 h 0→1, 갭이 핀 위 0.08~0.10 로 떠서 막대는 왕복을 계속하고 팔·핀은 그 자리(−2.1°)에 멈춘다.
③ 다시 연결 (7π): 같은 위상에서 내려 갭이 멈춰 있던 핀을 정확히 다시 문다.

## 동작 (닫힌 식 — `gear189(theta)`)
E = C + 0.12(cos θ, sin θ). 연결 때 P = 원(O, 0.805) ∩ 원(E, 2.0) 의 아래 해, 분리 때 P = 같은 식에 E = C − (0.12, 0). 갭 G.y = P.y + 0.2·h, G.x = E.x + √(2.0² − (G.y − E.y)²). R = G + rot(막대각)(0.85, 0.03), D = (1.31, R.y + √(1.06² − (1.31 − R.x)²)). h = smooth 계단(3π, 7π, 폭 0.7).
