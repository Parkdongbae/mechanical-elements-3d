# 189 분리 장치 변형 3
원문: "Another modification of 186." — 186(편심 막대를 밸브 장치에서 떼어 내는 장치)의 또 다른 변형. 186 은 "스프링 손잡이를 잡아 올려 노치에 걸리게 하면 핀이 편심 막대의 갭(홈)에서 빠져나와 분리된다."
판화 묘사: 아래쪽에 긴 가로 막대(편심 막대). 왼쪽 끝은 두 가닥으로 갈라진 홈(gab), 가운데는 위로 불룩한 허브(받침점 핀이 아래 공 모양으로 보임), 허브에서 위로 굽은 팔이 올라가 끝에 큰 눈 고리(속에 짙은 원판)를 이룬다. 막대 오른쪽 끝의 작은 눈에서 가는 링크가 위로 올라가 작은 눈(D)에 닿고, D 에서 왼쪽으로 짧은 팔이 이중 원(C1)에 이어지며 C1 에서 아주 긴 가는 막대가 위로 올라간다(판화 위가 잘림 = 손잡이까지 더 이어짐).
