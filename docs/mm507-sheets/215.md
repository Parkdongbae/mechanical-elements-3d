# 215 멈추개 변형 2
원문: "Other modifications of the stop, the operations of which will be easily understood by a comparison with 212." — 멈추개의 다른 변형으로, 작동은 212와 비교하면 쉽게 이해할 수 있다(태엽을 감는 바퀴 수 제한). 쉬운 풀이: 둥근 원판의 핀이 별 바퀴의 홈에 들어갔다 나오며 한 칸씩 돌리고, 사이에는 잠금 원판이 별 바퀴를 잡는다. 별 바퀴의 볼록한 옆면이 오면 더는 돌지 못하고 멈춘다.
판화 묘사(원본 506×437 px, [x·y]): 왼쪽 큰 원판(축 [148·200], 네모 축, 반지름 약 95 px — 오른쪽 별 바퀴 뒤로 점선이 지나감 = 뒤 층). 그 앞에 잠금 원판(반지름 약 68 px)이 오른쪽이 크게 오목하게 파여 C 모양. 파인 곳 오른쪽, 큰 원판 테 가까이에 핀 [232·198](왼쪽 축에서 약 85 px). 오른쪽 별 바퀴(축 [303·198], 끝 반지름 약 88 px): 둥근 바닥의 좁은 홈 6개(60° 간격 — 0°·60°·120°·180°·240°·300°), 지금 핀이 왼쪽(180°) 홈 속 깊이 들어가 있다. 홈 사이 옆면은 대부분 조금 오목한데, 아래 오른쪽(300°~360°) 옆면만 볼록하게 부풀어 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0084(축 거리 155 px = 1.30).
1. 바퀴는? → 3장. 큰 원판(핀, 0.82) > 별 바퀴(0.7465) > 잠금 원판(0.69).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 큰 원판 테가 별 바퀴 뒤를 지난다(큰 원판이 뒤 층, 별 바퀴·잠금 원판이 앞 층, 핀은 큰 원판에서 앞 층까지 나옴).
4. 고정점은? → 왼쪽 축 [148·200], 오른쪽 축 [303·198](같은 높이).
5. 추·손잡이·크랭크는? → 판화에 없음. 네모 축 = 태엽 굴대 → 왼쪽 원판이 감는 쪽(손잡이 보충).
6. 기어는? → 기어 이 대신 핀 하나가 별 바퀴 홈에 들어가 한 번에 60° 민다(제네바). 핀이 없을 때는 잠금 원판의 둥근 테가 별 바퀴의 오목 옆면을 받쳐 잠근다. 잠금 원판의 오목한 파냄은 별 바퀴가 도는 동안 끝을 비켜 준다.
7. 한 줄에 놓인 것은? → 두 축과 핀(판화 자세)이 한 수평선 위.
8. 글자가 가리키는 부품은? → 글자 없음(번호 215 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 212 와 같은 원리(볼록 옆면이 잠금 원판에 걸려 멈춤)이고 홈이 6개라 오목 옆면이 5곳 → 212 보다 한 바퀴 더 감긴다. 판화 비율 그대로(핀 회전 반지름 √(1.30² + 0.805² − 2·1.30·0.805·cos30°) = 0.725 = 판화 85 px)로 된다. 잠금 원판은 판화(0.57)보다 조금 큰 0.69 로 해야 별 바퀴 끝(0.7465)과 오목 옆면이 이어진다(겉모습 차이뿐). 질문 거리 없음.

## 해석(결정 사항)
- 별 바퀴: 홈 6개(60° 간격), 오목 옆면 5개 + 볼록 옆면 1개. 핀 한 번에 60°. 잠기는 자리 5곳 → 그 사이 4번 + 양 끝에서 볼록 옆면이 잠금 원판에 걸려 멈춤. **양 끝 멈춤 사이 구동 원판 1804.4° = 5.01 바퀴**.
- 핀이 홈에 들어가는 반지름 Re = 0.805, 핀 반지름 0.06, rf = 0.7249, 물린 구간 ±aw = ±33.730°.
- 계산은 "B 중심 원점, A 가 (0, −1.30)" 틀에서 하고 세계에서는 이 틀을 −90° 돌려 A 가 왼쪽에 오게 한다: A rotation.z = α − 90°, B rotation.z = β − 90°.
- 판화에 없는 보충: 감기 손잡이, 바퀴 수 표시등 5개, 볼록 옆면 빨간 띠.

- u ∈ [0, 15.747): α = αb + 114.592·u
- u ∈ [15.747, 17.247): α = αf(멈춤, 빨강)
- u ∈ [17.247, 32.994): α = αf − 114.592·(u − 17.247)

## 동작 (`state215(t)` — 닫힌 식)
α(t) 는 구동 시간표(틀 각). 별 바퀴 틀 각 β(α)(도):
j = floor((α − 90 + 180)/360), αc = 90 + 360·j, base = 120 − 60·j.
α < αc − 33.730 → β = base. α > αc + 33.730 → β = base − 60. 그 사이 → (x, y) = (0.7249·cos α, −1.30 + 0.7249·sin α), β = base + atan2(y, x)(도) + 60.
세계: 큰 원판 rotation.z = α − 90°, 별 바퀴 rotation.z = β − 90°.
감은 바퀴 수 n = (α − αb)/360(0 ~ 5.012). 켜진 표시등 = min(5, floor(n + 0.001)).
수치: t = 0 → α −272.22, β 152.79(반대쪽 걸림), n 0 / t = 9.444 → α 810, β −30(판화 자세: 핀이 왼쪽 홈 깊이, 볼록 옆면이 아래 오른쪽 330°) / t = 15.747 → α 1532.22, β −152.79, n 5.012, 멈춤 / t = 30 → 풀기, α 70.83, β 111.15, n 0.953.
