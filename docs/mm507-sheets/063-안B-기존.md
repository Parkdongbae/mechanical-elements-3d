# 063 점프(간헐) 회전 장치 — 핀 원판 · 드롭 · 폴 · 별 바퀴
판화(Read 로 열어 본 결과, 가로 468×세로 445): 오른쪽에 큰 둥근 원판(해칭 친 큰 허브 하나, 판 가장자리 안쪽 핀(작은 흰 원) 3개 — 위 약간 왼쪽·오른쪽 약간 아래·왼쪽 아래, 대략 120° 간격). 왼쪽 아래에 **별 모양 바퀴**(뾰족한 이 12개, 가운데 해칭 허브). 위쪽에 **드롭 레버**: 왼쪽 위 큰 고리(가운데 슬롯 나사 머리 = 피벗), 오른쪽으로 길게 뻗은 둥근 혹, 혹 오른쪽 끝에서 **폴(갈고리 칼날)** 이 아래로 곧게 내려와 별 바퀴 윗부분 틈에 뾰족한 끝이 들어가 있다(점선 삼각형 = 가려진 부분). 드롭 왼쪽 아래로는 둥근 꼬리 혹, 그 위를 가로지르는 가는 막대(= 스프링, 왼쪽 끝이 고정). 작은 핀 둘(고리 오른쪽 아래의 짧은 핀, 꼬리 아래 핀). 원판과 별 바퀴는 판화에서 겹쳐 보이며 별 쪽이 앞이다.
원문 요지: 미터기·회전수 계수기용 도약 운동. 원판의 핀이 드롭(과 폴)을 들어 올리다가 핀이 빠져나가면 폴이 별 바퀴의 다음 틈에 앉고, 핀이 드롭에서도 빠지면 스프링이 드롭을 갑자기 아래로 던져 폴이 별 바퀴를 한 이만큼 순식간에 돌린다. 핀이 지나갈 때마다 되풀이.
**만들 그림**: 판화에 그림이 하나뿐이다. 이유 없이 단순화하지 않고 **전체 기구 하나**를 그대로 만든다(원판 + 드롭 + 폴 + 별 바퀴 + 스프링).

## 구동
- 핀 원판이 구동. **시계 방향**(판화에서 핀이 드롭 아랫면 쪽으로 위로 올라오며 오른쪽으로 빠지는 방향). 원판 누적각 θ(라디안) += 0.9·speed·dt (핀 한 개당 120° = 2.33초).
- 변수: `ud = (θ를 도로 바꾼 값) mod 120` (도, 0~120), `k = floor(θ도 / 120)` (지금까지 지나간 핀 수). 한 주기(핀 하나) 안의 시간표가 아래 5단계로 반복된다.

## 동작 (식) — 모든 값은 θ 의 함수, 증분 누적 금지
상수: 도→라디안 D = π/180. P = 30°(별 이 간격), `aR = 42°`, 별 접촉 반지름 `rc = 0.52`, 접촉 보정 `KOFF = −0.013`, `ue = 54°`(핀이 드롭에서 빠지는 시점), `de = 0.299`(그때 드롭 각), 스냅 길이 `DU = 19°`.
- 폴 쉬는 끝점 R0 = S + rc·(cos aR, sin aR) = (0.2584, 1.4599), 들어가는 끝점 R3 = S + rc·(cos(aR+P), sin(aR+P)) = (0.0327, 1.6065).
- 드롭 각 δ(피벗 Pd 둘레 반시계, 0 = 판화의 쉬는 자세). 폴 힌지 위치 `Qof(δ) = Pd + Rot(δ)·(1.2807, −0.3364)`. 폴 절대각 `abs`(힌지에서 끝으로 향하는 각), 폴 끝 `tip = Qof(δ) + Lq·(cos abs, sin abs)`.
- 폴 쉬는 절대각 `eps0 = atan2(R0 − Q0) = −115.61°`.
- 광선 풀이 `ray(δ, a)`: 별 중심에서 극각 a 로 나가는 반직선과 원(중심 Qof(δ), 반지름 Lq)의 교점 중 **별 중심에 가까운 쪽**: u=(cos a, sin a), w = S − Qof(δ), b = w·u, c = |w|² − Lq², r = −b − √(b² − c), 점 = S + r·u.
- 별 이끝각 `Bt(a, r) = a − 15°·(ro − r)/(ro − ri) − KOFF/r` (a 는 폴 끝 극각, r 은 그 반지름). 한 이의 이끝이 이 각에 온다.
- `phiStart = Bt(72°, rc)` = 62.29° (푸시 직전 별 자세, k=0).

### 주기 시간표 (ud = 0 → 120)
1. **올림** `0 ≤ ud < 54`: 핀이 드롭 아랫면(L0→L1)을 민다. δ = 아래 표를 선형 보간, `abs = eps0 + δ`(폴이 드롭에 붙어 같이 오름), 별은 정지 = `phiStart − 30°·k`.
   δ 표(ud:δ): 0:0 2:.017 4:.030 6:.042 8:.055 10:.068 12:.080 14:.093 16:.106 18:.119 20:.131 22:.144 24:.156 26:.168 28:.180 30:.191 32:.202 34:.213 36:.223 38:.234 40:.243 42:.253 44:.261 46:.270 48:.278 50:.285 52:.292 54:.299.
   (근거: 드롭 아랫면 직선 L0 = (0.0, 2.2) → L1 = (0.65, 1.70) 을 Pd 둘레로 δ 돌렸을 때, 핀 중심이 선에서 핀 반지름 0.055 이상 떨어지게 하는 최소 δ. 핀 각 ψ = 157.25° − ud. ud = 54° 에서 핀이 선 끝 L1 을 지나 빠진다.)
2. **뒤로 휘두름(핀이 폴에서 빠짐)** `54 ≤ ud < 54 + 0.3·DU`: δ = de 고정. f1 = (ud − 54)/(0.3·DU), s = smoothstep(f1). `abs = (eps0 + de) + (aEnd − (eps0 + de))·s`, 여기서 aEnd = Qof(de) 에서 `ray(de, 72°)` 점으로 향하는 각(≈ −125.6°). 끝은 별 이끝 위(반지름 ≥ 0.855)를 지난다.
3. **떨어짐** `… < ud < 54 + 0.62·DU`: g = smoothstep((f − 0.3)/0.32) (f = (ud − 54)/DU), δ = de·(1 − g), 폴 끝 = `ray(δ, 72°)` 점(광선 = 별 틈 가운데를 따라 곧게 내려앉음, abs = 힌지→끝). 별 정지.
4. **밀기(스프링이 던진 드롭의 핀이 폴을 침)** `… < ud < 54 + DU` (73°까지): s = smoothstep((f − 0.62)/0.38), δ = 0, 끝 극각 a = 72° − 30°·s, 폴 끝 = `ray(0, a)` 점, abs = 힌지(Q0)→끝, **별 이끝각 = Bt(a, r) − 30°·k** (별이 시계 방향으로 30° 돈다. 접촉 간격 ≤ 0.006).
5. **쉼** `73 ≤ ud < 120`: δ = 0, abs = eps0, 폴 끝 = R0, 별 이끝각 = `phiStart − 30°·(k+1)` (정지). 다음 핀이 120° 에서 올림 단계로 이어진다.
- 별 바퀴 `rotation.z = 위에서 구한 이끝각`(starWheel 의 이끝이 로컬 0° 이므로 그대로). 별은 시계 방향으로만 돈다(되돌아가지 않음).
- 드롭 `rotation.z = δ` (피벗 Pd 에 놓인 그룹), 폴은 드롭의 자식이 아니라 세계 좌표에 따로: `position = Qof(δ)`, `rotation.z = abs`.
- 원판 `rotation.z = 57.25°(= 1.0007 rad) − θ` (θ = 누적각, 시계 방향이라 −). 핀 로컬각 100°, −20°, −140° → 처음(θ = 0)에는 핀이 157.25°, 37.25°, −82.75° 에 있어 첫 핀이 막 드롭 아랫면에 닿는 순간.
- 스프링: 코일 길이 `|T(δ) − A|` (0.825 ~ 0.982 로 변함), `T(δ) = Pd + Rot(δ)·(−0.34, −0.50)`. coilSpring 은 +X 방향 길이 1 이므로 `position = A`, `rotation.z = atan2(T − A)`, `scale.x = |T − A|`.
- 속도비: 원판 120° 에 별 바퀴 30°(핀 1개당 이 1개) → 원판 4 : 별 1. 원판 한 바퀴에 별은 90°, 한 바퀴 안에 도약 3번.

## 의문점·단순화 (정직하게)
- 판화의 폴은 드롭과 한 덩어리처럼 보이지만 원문은 "드롭과 거기에 붙은 폴"이라 힌지로 연결된 두 물체로 만들었다(드롭이 들어 올리면 폴이 같이 오르고, 풀리면 폴이 뒤로 휘돌았다가 별 틈으로 내려앉아 민다).
- 원문의 "드롭에 붙은 핀이 폴을 침"은 폴이 핀에 밀려 돌아가는 접촉을 풀이하기보다 시간표(밀기 단계에서 폴 끝이 별 옆면을 따라 이동)로 표현했고, 때리는 핀은 장식이다.
- 판화의 스프링은 가는 직선 막대 하나이지만 코일 스프링으로 그려 늘어남이 보이게 했다.
- 별 바퀴 역회전 방지 멈춤쇠는 판화에 없어 넣지 않았다(실제로는 마찰·스프링).
