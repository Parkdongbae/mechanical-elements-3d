# 042 엇각 기어 (1)
원문(42·43 공통): 한 축에서, 그와 비스듬하게 놓인 다른 축으로 회전을 전하는 여러 종류의 기어.

## ★ 판화 읽기
판화는 그림 하나. 위 기어는 **옆에서**(축이 종이 위 가로), 아래 기어는 **비스듬히 돌려서**(앞면이 오른쪽 앞을 향함) 그려져 있다.
1. 바퀴는 몇 개이고 크기 차례는? → 기어 2개. 지름이 거의 같다(판화 높이 위 355 : 아래 340, 아래가 조금 작다 — 비 0.96). 폭도 비슷하게 좁다.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 다만 두 **축**이 평행하지도 만나지도 않고 위아래로 어긋나 엇갈린다.
4. 고정점은? → 판화에는 받침이 없다. 위 축은 좌우로, 아래 축은 왼쪽 끝이 잘린(톱니 모양 단면) 채 바퀴 뒤로, 오른쪽 끝은 앞으로 나온다.
5. 추·손잡이·크랭크는? → 없음. 구동 쪽 표시 없음(모형은 위 기어를 구동으로).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 둘 다 바깥 둘레. 위 기어의 맨 아랫점이 아래 기어의 맨 윗점에 한 점으로 닿아 물린다. 위 기어의 빗금(이 줄)은 `/`, 축과 약 28~30° → **헬리컬**. 아래 기어의 이 줄은 제 축과 나란하다(테두리 띠에 가로줄, 원근 때문에 부채처럼 살짝 벌어질 뿐) → **곧은 이(평기어)**.
7. 한 줄에 놓인 것은? → 두 기어 중심이 같은 세로선 위(위 기어 바로 밑에 아래 기어). 두 축의 공통 수직선이 세로(y).
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없다(없음). 아래 바퀴 앞면 타원의 납작한 정도(짧은 지름/긴 지름 ≈ 0.33~0.5)에서 아래 축이 위 축에서 약 20~35° 돌아가 있고, 이것이 위 기어의 헬릭스각(약 30°)과 같다 — 헬리컬 기어가, 헬릭스각만큼 돌려 놓은 평기어를 돌리는 배치다.
- 그 밖의 선: 위 기어 양쪽의 네모 = 허브 고리. 아래 바퀴 앞면의 작은 타원 두 겹 = 허브와 축 구멍.

## 구동
위 기어 A theta += OMEGA·speed·dt.

## 부품과 치수 (키트: `helicalGear`, 이미 구현됨)
- 축 사이각 Σ = 30°(두 축은 XZ 평면에서 30°, 높이로 어긋남). 위 A 는 헬릭스각 30°, 아래 B 는 헬릭스각 0°(곧은 이). 이직각 모듈 MN = 0.04 를 둘이 같이 쓴다.
- A(구동, bronze, name `gearA`): 잇수 ZA=18, 단면 모듈 MTA = MN/cos30° = 0.046188, 피치 반지름 0.41569(이끝 0.4619). `helicalGear(18, MTA, { width: 0.2, helix: rad(30), hand: -1, driver: true })` — hand −1 ⇒ 정면에서 `/`.
- B(name `gearB`): 잇수 ZB=20, 단면 모듈 0.04, 피치 반지름 0.40(이끝 0.44). `helicalGear(20, 0.04, { width: 0.22, helix: 0 })`.
- 좌표: ZC = 0.30, YB = 1.30, YA = YB + 0.41569 + 0.40 = 2.1157. A 중심 (0, YA, ZC), B 중심 CB = (0, YB, ZC). 피치점 P = (0, 1.70, 0.30).
- A 축 = 세계 X: `rod(v(-0.62,YA,ZC), v(0.62,YA,ZC), 0.045)`.
- B 축 방향 u2 = (cos30°, 0, sin30°) = (0.866, 0, 0.5) — 오른쪽 끝이 보는 사람 쪽. `rod(CB − 1.2·u2, CB + 0.85·u2, 0.045)`: 뒤 끝 (−1.039, 1.30, −0.30) 은 뒤판에 닿고, 앞 끝 (0.736, 1.30, 0.725) 은 자유.
- 받침(판화에 없음, 최소): A 축은 x=±0.55 에 뒤판에서 나온 기둥(반지름 0.07, z −0.3 ~ ZC)과 끝 고리. B 축은 뒤판에 닿는 자리에 u2 방향의 짧은 보스(반지름 0.08, CB − 1.2·u2 ~ CB − 1.05·u2)와, CB − 0.62·u2 = (−0.537, 1.30, −0.01) 에서 축을 감싸는 고리 + 뒤판에서 그 고리까지 오는 기둥(반지름 0.06, z −0.3 ~ −0.07).

## 동작
- A.quaternion = Ry(90°)·Rz(theta) (로컬 Z → 세계 +X).
- B.quaternion = Ry(90° − Σ)·Rz(rollB) = Ry(60°)·Rz(rollB) (로컬 Z → u2), **rollB = −(ZA/ZB)·theta** (속도비 −18/20 = −0.9, 위상 덧값 0).
- 자세 모두 절대 각으로 매 프레임 계산.

## 표시
- rotArrow: A = rotArrow(0.35,true), rotation.y=π/2, 위치 (0.3, YA, ZC). B = rotArrow(0.35,false), quaternion = Ry(60°), 위치 CB + 0.25·u2.
- tag 3개: '구동 기어(비스듬한 이)' (−1.25, 2.12, 0.5), '곧은 이 기어(축이 30° 돌아감)' (−1.25, 0.9, 0.5), '두 축이 평행하지 않다(30°)' (1.35, 1.7, 0.5).
- notes: 잇수 `18 : 20`, 속도비 `1 : 0.9 (반대 방향)`, 축 사이각 `30° (엇각) — 위 기어 이의 비스듬한 각과 같다`.

## 확인
- t=1, 1.6: 위 기어 표시선이 돌고 아래 바퀴가 0.9배로 돈다. 정면에서 위 기어는 모서리(이 줄 `/`), 아래 기어는 앞면 타원이 오른쪽 앞을 향해 보인다(판화와 같은 구도). 물림 근접 `cam=0.8,1.9,1.6,0,1.7,0.3` 두 시점에서 박힘 없음.

## 검증 후 수정 — 판화 교차 읽기(Fable, 지시서 20 S1b)
- 처음 설계표는 "둘 다 헬릭스 30°, 축 사이각 60°, 잇수 20:24(아래가 큼)" 이었다. 판화를 다시 읽으니 ① 아래 기어의 이는 곧고 ② 아래 바퀴 앞면이 납작한 타원이라 축이 약 30° 만 돌아가 있으며 ③ 두 기어 지름이 거의 같다(아래가 조금 작음). 그래서 **헬리컬(30°) + 평기어, 축 사이각 30°, 잇수 18:20** 으로 바꾸고 위상을 다시 구했다(c: π/ZB → 0). 60° 로 만들면 아래 바퀴가 정면에서 거의 둥근 원판으로 보여 판화와 다르다.
- B 축은 30° 로 눕기 때문에 뒤 끝이 뒤판(x −1.04)에 닿는다 — 받침을 그에 맞게 바꿈.
