# 033 타원 기어
판화: 같은 타원 기어 둘. 왼쪽은 세로로 긴 타원, 오른쪽은 가로로 긴 타원, 서로 이가 맞물린다. 각각 가운데 근처에 축.
구동: 왼쪽 기어를 일정 속도로 돌린다. 오른쪽 기어는 반대로, 속도가 주기적으로 변한다.

## 부품과 치수
`ellipsePitch`·`ellipseRoll`·`ellipticalGear`(키트 추가), `shaftZ`, `rotArrow`, `tag`.
- 피치 타원: 긴반지름 a = 0.8, 이심률 e = 0.55 (b = 0.668), 둘레 4.62, 잇수 36(피치 0.128, 모듈 0.041). 압력각 20° 직선 측면 이.
- 두 기어는 각자의 **초점**을 축으로 한다. 축 중심 (−0.8, 1.75), (0.8, 1.75): 중심 거리 d = 2a = 1.6. z = 0.12, 폭 0.14.
- 기어 2 는 이를 반 피치 어긋나게(`halfOffset`) — 첫 접촉에서 이 ↔ 이골.

## 굴림 공식 (미끄럼 없음)
초점 극좌표 r(φ) = p/(1 − e cosφ), p = a(1−e²), φ = 0 이 근일점. 중심선 위 접점에서 r₁ + r₂ = 2a 이면 두 곡선이 구른다(호 길이도 같음: S(φ₁) + S(φ₂) = L/2 를 수치 확인).
- 기어 1 의 근일점 축 세계각 θ₁ (구동). φ₁ = −θ₁, r₁ = r(φ₁).
- 기어 2: cosφ₂ = (1 − p/(2a − r₁))/e, sinφ₂ 의 부호 = sinφ₁ 의 부호(연속 이어붙임), θ₂ = π − φ₂. 방향 반대.
- 속도비 |ω₂/ω₁| = r₁/r₂ = r₁/(2a − r₁), 범위 (1−e)/(1+e) = 0.29 ~ 3.44.
- θ₁ = π/2 + θ (처음 기어 1 의 긴 축이 세로), θ += 0.8·speed·dt. g1.rotation.z = θ₁, g2.rotation.z = θ₂.
- 이 윤곽: 피치 곡선 위 호 길이 s = s₀ + iP 에 이 중심, 법선으로 이끝 +m, 이뿌리 −1.2m (m = P/π).

## 표시
rotArrow(0.3) 기어 1 반시계, 기어 2 시계. tag '구동/피동 타원 기어'. notes: 잇수, 속도비 범위, 지금 속도비.

## 확인
- 두 시점에서 두 타원이 모두 돌고 기어 2 의 속도가 달라진다. 이끼리 박히지 않는다(θ를 0.01 간격으로 2바퀴 훑어 윤곽 겹침 점 최대 2/수천 — 표본 오차 수준).
- 전시 영역 안: 가장 길게 뻗을 때도 초점에서 1.32 + 이 높이.

## 검증 수정 (Fable) — 위의 "초점 축 타원(e = 0.55)" 설계를 대체
- 판화는 두 기어 모두 **가운데에 축**이 있고 왼쪽 세로·오른쪽 가로다(축간 거리 ≈ 긴반지름 + 짧은반지름). 초점 축 타원은 이 구도가 될 수 없다.
- 피치 곡선을 2차 타원(오벌 기어) `ovalPitch(a = 0.95, b = 0.59)`: r(φ) = 2ab/((a+b) − (a−b)cos2φ), 축간 거리 a + b = 1.54, 축 (−0.8, 1.75)·(0.74, 1.75). 수치 확인: |r₁ + r₂ − d| < 3·10⁻⁸.
- 굴림: `pitchRoll(pitch, θ₁, L/4)` — S(φ₂) = L/4 − S(−θ₁), θ₂ = π − φ₂. 속도비 r₁/(d − r₁) = 0.62 ~ 1.61, 한 바퀴에 두 번.
- 잇수 26(판화와 비슷, 4k+2 라 같은 기어 둘이 90° 어긋나 이 ↔ 이골), 이 반폭 0.22P. 한 바퀴 0.01 rad 간격 훑어 윤곽 겹침 0.
