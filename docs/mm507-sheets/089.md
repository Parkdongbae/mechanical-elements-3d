# 089 증기 기관 밸브용 편심
원문: 크랭크 축에 흔히 다는 편심(중심이 어긋난 원판). 증기 기관의 밸브에 왕복 직선 운동을 전하는 데 쓰고, 때로는 펌프질에도 쓴다. (원문에 글자·수치 없음)

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/089-fig-x4.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 기어·풀리는 없다. 둥근 **편심 원판 1개**(판화에서 반지름 388 px)와 그것을 감싼 **띠(스트랩) 고리 1개**(바깥 반지름 445 px). 축(빗금 친 원, 반지름 80 px)은 원판 중심에서 왼쪽으로 210 px 어긋나 있다(편심량 : 원판 반지름 = 0.54). 축 둘레에 허브 고리(반지름 145 px).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에는 받침이 없다. 축의 단면(빗금 원)만 그렸다 — 축은 제자리에서 돈다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 축(크랭크 축)이고, 편심 원판이 축에 고정되어 함께 돈다.
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 이는 없다. 맞닿는 짝은 **원판의 둥근 둘레 ↔ 띠 고리의 안쪽 면**(온 둘레 미끄럼 접촉). 띠는 위·아래의 네모난 귀에서 좌우 두 쪽으로 갈라지고(귀 가운데의 세로 가는 선 = 이음선), 귀 양옆의 작은 네모 = 가로로 꿴 볼트의 머리와 너트. 띠 오른쪽에 짧은 목, 그 끝에 플랜지 두 장(가운데 세로선 = 두 장이 맞닿은 면, 위아래 작은 네모 넷 = 볼트), 그 오른쪽으로 가늘어지는 편심 막대(오른쪽 끝은 그림 밖으로 잘림).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 축 중심, 원판 중심, 목, 플랜지, 막대가 한 가로줄(판화의 순간은 편심이 막대 쪽을 향한 때 = 막대가 가장 오른쪽으로 나간 때). 위 귀와 아래 귀는 원판 중심의 세로선 위.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 다만 판화는 막대의 오른쪽 끝(밸브 쪽)을 그리지 않았다 — 막대 끝을 받을 핀·곧은 밸브 막대·안내를 보충한다(판화에 없음, 원문의 "왕복 직선 운동").
- 그 밖의 선: 원판 안쪽의 D 꼴 굵은 선 = 살(web)을 얇게 판 자리의 테두리(둘레 테와 허브만 온 두께). 띠 고리의 두 겹 원 = 띠의 안·밖 가장자리.

## 해석(결정 사항)
- 기구 = 편심 원판(팔 길이 e 인 크랭크와 같다) + 띠·막대(연접봉) + 곧게 안내되는 밸브 막대 = 슬라이더 크랭크.
- 막대는 띠와 한 몸이라 원판 중심 둘레로 조금 흔들린다(±7.76°) — 90번 원문이 말하는 "막대의 흔들림".
- 판화 자세(편심이 오른쪽)를 t = 1 로 둔다.

## 구동
축(크랭크 축). theta += OMEGA(1.6)·speed·dt, θe = theta − 1.6 (t = 1 에서 θe = 0 — 판화 자세). 반시계.

## 부품과 치수
공통: 기구 평면 z = ZP = 0.1. 축 중심 O = (−1.15, 1.75). 편심량 e = 0.27, 원판 반지름 R = 0.5, 막대 길이 L = 2.0(원판 중심 ↔ 핀).
- 축: `shaftZ(−1.15, 1.75, 0.3, 0.1)` (뒤판에서 z 0.3 까지, 고정 받침 = 뒤판 보스).
- 편심 원판(name `sheave`): `eccentricSheave(0.5, 0.27, { bore: 0.1, hubR: 0.19 })` 위치 (−1.15, 1.75, 0.1). 원점 = 축, 원판 중심 = 로컬 (0.27, 0). 두께 0.12, 청동.
- 띠 + 편심 막대(name `strap`): `eccentricStrap(0.502, 2.0)` — 안반지름 0.502(틈 0.002), 바깥 0.577, 귀 가로 폭 0.482·끝 높이 ±0.703, 플랜지 x 0.697~0.777, 막대 끝 눈 로컬 (2.0, 0)(자식 `rodEye`). 원점 = 원판 중심, 주철. 두께 0.14.
- 밸브 막대(name `valveRod`, **판화에 없음**): `valveRod(0.95)` — 원점 = 핀, 포크 + 핀 + 한 변 0.09 네모 막대가 +X 로 0.95. 위치 (Px, 1.75, 0.1).
- 안내(name `guide`, **판화에 없음**): `rodGuide('x', { w: 0.09, h: 0.09 }, 0.1)` 위치 (1.42, 1.75, 0.1) — x 1.35~1.49, 받침 기둥이 뒤판까지.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통).
- 범위(`shots/_verify/s089.mjs`): 띠 왼쪽 끝 x ≥ −1.997, 귀 y 0.754~2.746, 핀 x 0.58~1.12(행정 0.54 = 2e), 포크 오른쪽 끝 ≤ 1.29(안내 1.35 앞), 밸브 막대 끝 x 1.53~2.07(항상 안내 1.49 를 지나 있음, ≤ 2.2).

## 동작 (모두 θe 의 닫힌 식)
- `sheave.rotation.z = θe`.
- 원판 중심 C = (−1.15 + 0.27·cos θe, 1.75 + 0.27·sin θe).
- 핀 Px = −1.15 + 0.27·cos θe + sqrt(2.0² − (0.27·sin θe)²), 높이 1.75 고정.
- `strap.position = (C.x, C.y, 0.1)`, `strap.rotation.z = −asin(0.27·sin θe / 2.0)` (= atan2(1.75 − C.y, Px − C.x)). 띠의 눈과 밸브 막대의 핀은 **같은 변수 Px** 에서 나온다.
- `valveRod.position.x = Px`.
- 한 바퀴 3.927 s 에 왕복 한 번. 시각: **t = 1.0 (θe 0°, 판화 — 막대가 가장 오른쪽, Px 1.12)**, **t = 1.6 (θe 55°, 원판 중심이 오른쪽 위, 막대가 6.3° 아래로 기욺, Px 0.993)**, t = 2.96 (θe 180°, 가장 왼쪽 Px 0.58).

## 표시
- rotArrow: `rotArrow(0.3, true)` 를 축 중심 (−1.15, 1.75, 0.34) 에(반시계).
- tag 4개: '편심 원판(축에서 중심이 어긋남)' (−1.15, 2.95, 0.3), '띠(스트랩)' (−0.35, 0.75, 0.3), '편심 막대' (0.35, 2.15, 0.3), '밸브 막대(곧게 왕복)' (1.5, 1.35, 0.3).
- notes: ① '행정 = 편심량의 2배(0.54)' ② 지금 밸브 막대 위치(가운데에서 ±) ③ 막대의 기운 각(최대 ±7.8°) ④ 구동 회전수.

## 확인
- t=1 정면: 판화와 같은 모양 — 축이 원판의 왼쪽, 위아래 귀, 오른쪽에 플랜지와 막대가 가로로. t=1.6 정면: 원판 중심이 오른쪽 위로 돌고 막대가 약간 기욺.
- 근접 `cam=-0.9,2.2,2.2,-0.9,1.75,0.1`(원판·띠), `cam=1.2,2.1,1.5,1.1,1.75,0.1`(핀·포크·안내), 옆 `cam=3.5,1.75,0.1,0,1.75,0.1`(띠와 원판이 같은 평면, 안내 기둥이 뒤판에 닿음).
- 수치: `node shots/_verify/s089.mjs` → 링크 길이 일정, 핀 x 0.580~1.120, 흔들림 ±7.76°.
