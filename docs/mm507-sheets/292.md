# 292 스터드(핀 바퀴) 탈진기
원문(en): "Stud escapement, used in large clocks. One pallet, B, works in front of the wheel and the other at the back. The studs are arranged in the same manner, and rest alternately upon the front or back pallet. As the curve of the pallets is an arc described from F, this is a repose or dead-beat escapement."
— 큰 시계에 쓰이는 스터드 탈진기. 팔레트 B 하나는 바퀴 앞에서, 다른 하나는 뒤에서 작용한다. 스터드도 같은 방식(앞면·뒷면 번갈아)으로 박혀 있어 앞 팔레트와 뒤 팔레트에 번갈아 얹힌다. 팔레트 곡면이 F 를 중심으로 그린 호이므로 정지(데드비트) 탈진기이다.
쉬운 풀이: 바퀴 테의 앞면과 뒷면에 스터드(핀)가 하나씩 번갈아 박혀 있다. 닻은 F 에 매달려 진자와 함께 흔들리고, 다리 끝의 팔레트 B 는 바퀴 앞에서, 팔레트 A 는 바퀴 뒤에서 핀 길을 가로막는다. 앞 핀은 B 에만, 뒷 핀은 A 에만 얹힌다. 팔레트 윗면(잠금면)이 F 중심 호라서 핀이 얹혀 있는 동안 바퀴는 꼼짝 않는다. 닻이 기울어 팔레트가 비켜나면 핀이 팔레트 끝 비탈을 미끄러져 내려가며 진자를 밀고(충격), 툭 떨어져 다음 핀이 다른 팔레트에 얹힌다. 진자가 한 번 오갈 때 바퀴는 같은 면 핀 한 칸(24°)씩 나아간다.
판화 묘사(원본 456×451 px, **정면**): 위 가운데 F([195·30], 둥근 축 머리, 옆 글자 G·H). F 에서 다리 둘이 내려옴 — 왼다리(G 쪽)는 아래로 [300·350] 의 팔레트 A(삼각 R 표시)까지, 오른다리(H 쪽)는 오른쪽 아래 B([415·290])에서 꺾여 c·d 쪽 팔레트까지. 큰 바퀴(중심 [170·425], 테 바깥 반지름 ≈ 210 px, 안 ≈ 175 px, 살 셋)의 오른쪽 위 1/4 만 보이고, 테 위에 작은 삼각 스터드가 줄지어 있음. 팔레트는 바퀴 중심에서 약 30° 자리(테 [330·340])에서 핀 길을 가로지름. u 는 그 위 핀, d 는 팔레트에 얹힌 핀. 오른쪽 아래 [400·390] 에 아래를 가리키는 화살표(오른쪽이 내려감 = 시계 방향).

## ★ 판화 읽기
판화 하나(정면). 판화 1 px ≈ 0.0047(테 210 px → 1.02). 바퀴 중심 [170·425] ↔ 세계 (−0.55, 1.25), 맞물림 자리 E(바퀴 중심에서 30°) ↔ (0.2727, 1.725), F [195·30] ↔ (−0.3523, 2.8075).

2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 팔레트 B·앞 다리는 바퀴 앞 층(z 0.08~0.14), 팔레트 A 는 바퀴 바로 뒤(z −0.08~−0.02), 뒤 다리는 더 뒤(z −0.19~−0.13) — 판화의 두 다리가 겹쳐 보이는 것은 층이 달라서.
4. 고정점은? → 닻 축 F(뒤판 보스), 바퀴 축(뒤판 보스).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 판화에 진자 없음 → F 앞 보스에 진자(막대 + 추) 보충. 바퀴는 뒤 태엽통이 시계 방향으로 돌림(보충).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 이 대신 테 앞면·뒷면에 번갈아 박힌 원기둥 핀(같은 면 간격 24°, 앞뒤 사이 12°). 맞물림 자리 E 에서 핀 길이 F 쪽 선과 접선이 되게 F 를 놓아(판화처럼 F 가 바퀴 중심 거의 위), 팔레트는 바퀴 반지름 방향으로 비켜난다. B 는 핀 길 바깥에서, A 는 안쪽에서 들어온다(판화: A 는 테 안쪽, B 는 바깥).
7. 한 줄에 놓인 것은? → F·E 가 E 의 핀 길 접선 위(F = E + 1.25·(−sin 30°, cos 30°)). 두 팔레트의 잠금면은 같은 반지름(F 에서 1.28) — 앞뒤로 같은 자리.
8. 판화에 글자(A, B…)가 가리키는 부품은? → F 닻 축, G·H 닻 다리 위끝(이름만), A 뒤 팔레트(R 은 그 면), B 앞 팔레트 다리 꺾인 곳, c·d 앞 팔레트와 얹힌 핀, u 위에서 내려오는 핀.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 판화는 바퀴 1/4 만 그림 → 바퀴 전체를 만든다(바닥이 받침 위 0.23). (나) 판화 스터드는 촘촘(≈ 7°) → 앞뒤 번갈아 30(앞뒤 12°)으로 줄여 팔레트 두께가 핀 사이에 들어가게. (다) 뒤 팔레트 A 는 바퀴 테 뒤에 숨으므로 테를 반투명(0.55)으로. (라) 진자·태엽통 보충.

## 해석(결정 사항)
- **진자(닻) 각만 시간표, 바퀴 각은 접촉에서**: ψ(t) = 5°·sin(π t)(주기 2, 반시계 +). 바퀴는 늘 시계 방향으로 밀리므로, 매 순간 φ = 정해진 핀(원)이 팔레트 윤곽에 처음 닿는 각.
- 잠금면은 F 중심 반지름 1.28 원호 → 핀 중심은 F 에서 1.25 원 위에 머물러 **바퀴가 정확히 멈춤(데드비트)**. 닻이 돌면 팔레트가 E 에서 바퀴 반지름 방향으로 비켜난다(반시계 ψ > 0 → 바깥, B 가 빠짐 / ψ < 0 → 안쪽, A 가 빠짐).
- 팔레트 두께 0.11 < 핀 간격 0.199 − 핀 지름 − 틈: 떠난 핀과 다음 팔레트가 부딪히지 않음(검산).
- 한 주기(2)에 정확히 −24°(앞 핀 하나 + 뒷 핀 하나).

## 동작 (`state292(t)` — 결정적, 접촉 계산)
1. n = floor(t/2), τ = t − 2n, ψ = 5·sin(π τ)(도).
2. 핀 j 의 중심은 바퀴 중심 반지름 0.95 원 위, 각 30° + 12°·j + φ. 핀 반지름 0.03. 팔레트 윤곽은 F 둘레로 ψ 만큼 돌린다.
3. 접촉 계산(핀 j, 팔레트 X): 핀 중심 후보 =
   - 잠금면 원호 → 원 (F, 1.25) 과 핀 길 원 (WC, 0.95) 의 교점, 아랫면 원호 → 원 (F, 1.42) 과의 교점(원·원),
   - 꼭짓점마다 원 (꼭짓점, 0.03) 과 핀 길 원의 교점,
   - 곧은 변(비탈·끝면)마다 양쪽으로 0.03 평행이동한 선분과 핀 길 원의 교점(원·선분, 매개변수 0~1).
   후보 가운데 팔레트 다각형(원호 200 등분) 바깥이고 거리가 0.03 ± 10⁻⁶ 인 것만 남기고, 바퀴 중심에서 잰 각(30° 둘레 ±180°)이 **가장 큰 것**(시계 방향으로 돌다 먼저 닿는 점)을 고른다. φ = 그 각 − (30° + 12°·j).
4. 구간: τ < 0.5 → B·앞 핀 j = 0, 없으면 A·뒷 핀 j = 1. 0.5 ≤ τ < 1.5 → A·j = 1, 없으면 B·j = 2. τ ≥ 1.5 → B·j = 2. φ 에서 24·n 을 뺀다.
