# 187 분리 장치 변형 1
원문: "Modifications of 186." — 186 의 변형. 쉬운 풀이: 186 과 같은 원리로 손잡이 모양만 다르다. 스프링 손잡이로 핀을 편심 막대에서 빼낸다.
판화 묘사: 위에 흔들 축(단면, 검은 원)과 짧은 팔, 팔 끝에 둥근 원판과 핀. 왼쪽에서 온 가로 편심 막대(왼쪽 끝에 긴 홈)가 갭으로 핀을 물고 오른쪽으로 길게 이어진다. 핀 바로 위 막대 위에 둥근 혹 모양 머리(작은 원 = 받침, 점선 호 = 핀 위로 가려진 머리 아랫면)가 있고, 머리에서 오른쪽으로 납작한 손잡이가 막대와 나란히(집게처럼) 뻗는다.

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 446×460 px, [x·y]).
1. 바퀴는? → 바퀴 없음. 흔들 축 허브 [268·95](반지름 30), 팔 끝 원판 [268·225](반지름 35).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 손잡이 머리가 핀 앞을 덮는다(점선 호). 막대는 팔 끝 원판 앞.
4. 고정점은? → 흔들 축 [268·95](뒤판). 나머지는 움직인다.
5. 추·손잡이·크랭크는? → 손잡이 = 머리에서 오른쪽으로 뻗은 납작 막대 [300~435·150~175], 받침 [275·165] 은 막대 위(혹). 구동은 편심 막대.
6. 기어는? → 없음. 갭 = 막대 끝 아래로 열린 반원 홈.
7. 한 줄에 놓인 것은? → 흔들 축·핀·받침이 한 세로선(x 268~275). 막대와 손잡이가 나란한 수평.
8. 글자가 가리키는 부품은? → 글자 없음(번호 187 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 원문은 "186 의 변형" 뿐이라 작동은 186 과 같다고 본다. 받침이 핀 바로 위라 레버 끝으로 핀을 누를 수 없으므로, 머리 아랫면을 캠(받침에서 멀어지는 나선)으로 읽어 손잡이를 들면 캠이 핀을 눌러 막대가 들리게 한다. 편심은 판화 밖이라 보충. 질문 거리 없음.
