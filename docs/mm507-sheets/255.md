# 255 플랜지 풀리
원문(en): "A flanged pulley to drive or be driven by a flat belt." — 평벨트로 구동하거나 평벨트에 의해 구동되는, 가장자리 턱(플랜지)이 있는 풀리.
쉬운 풀이: 풀리 양쪽 가장자리가 솟아 있어서(플랜지) 납작한 벨트가 옆으로 벗어나지 않는다. 아래 작은 구동 풀리가 돌면 평벨트가 흘러 위의 플랜지 풀리를 돌린다.
판화 묘사(원본 463×435 px, 축이 화면 좌우로 누운 **옆 모습**): 가운데 세로로 선 풀리 테(위 y ≈ 45, 아래 y ≈ 392 → 반지름 ≈ 173 px). 양쪽 세로 띠 둘(x 197–218, 273–293, 두께 ≈ 20 px) = **플랜지**, 그 사이(x 218–273, 폭 ≈ 55 px)는 플랜지보다 낮은 **드럼면**(위 y ≈ 65 → 반지름 ≈ 155 px) — 위·아래 윤곽에서 플랜지가 드럼면보다 ≈ 18 px 솟아 보인다. 양옆 짧은 네모(x 180–197, 293–313, 반지름 ≈ 49 px) = 허브, 그 바깥으로 둥근 축(반지름 ≈ 27 px, 오른쪽 끝이 잘린 원통). 벨트·다른 풀리는 그려져 있지 않다.

## ★ 판화 읽기
판화는 그림 하나(축이 좌우로 누운 옆 모습). 판화 1 px ≈ 0.00358(플랜지 반지름 173 px = 0.62).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 플랜지 풀리 1개. 보충: 이 풀리를 돌릴 작은 구동 풀리 1개(아래). 크기 차례: 플랜지 풀리(플랜지 반지름 0.62, 드럼면 0.555) > 구동 풀리(0.22).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에는 없음. 보충: 평벨트 1개(닫힌 고리) — 큰 풀리 위쪽을 반시계로 감고 왼쪽 가닥으로 내려와 구동 풀리 아래를 반시계로 감고 오른쪽 가닥으로 올라간다(열린 벨트).
3. 교차하는 가닥이 있는가? → 없음(열린 벨트, 두 가닥이 나란히 비스듬).
4. 고정점(천장·벽·바닥)은 어디인가? → 두 축 모두 뒤판에서 나온 축(뒤판 보스). 판화의 축 = 큰 풀리 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 아래 구동 풀리 축이 일정하게 돈다(구동).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음(벨트 전동).
7. 한 줄에 놓인 것은? → 두 풀리 중심이 같은 세로선 x = 0(큰 풀리 y 2.12, 구동 풀리 y 0.82). 두 풀리·벨트의 가운데 평면이 모두 깊이 0.10.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 255 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 어긋남 없음. 판화는 풀리 하나만 그린 옆 모습이라, 돌아가게 하려고 아래 구동 풀리와 평벨트를 보충한다. 판화는 축이 좌우로 누운 옆 모습이고 모델은 축을 깊이(Z) 방향으로 두어(벨트 경로를 화면 평면에 놓기 위해) 판화와 같은 모습은 오른쪽(+X)에서 보인다 — 시점을 45° 비스듬히 두어 판화의 플랜지·드럼 윤곽과 벨트를 함께 보이게 한다(질문 거리 1). 단면은 앞 오른쪽 아래 65° 를 잘라 보인다.

## 해석(결정 사항)
- 큰 풀리 = 판화 그대로의 플랜지 풀리(플랜지 둘 + 낮은 드럼면 + 허브). 평벨트(폭 0.16, 두께 0.02)는 드럼면 위, 두 플랜지 사이(양쪽 틈 0.02)에 앉는다.
- 아래 구동 풀리 = 키트 납작 림 풀리(평벨트 ↔ 납작 림 짝). 열린 벨트라 두 풀리는 같은 방향(반시계)으로 돈다.
- **단면 보이기**: 큰 풀리 림·웹(회전 대칭)을 평면각 ψ = −90° ~ −25° 만큼 잘라 낸 회전체로 만들고, 잘린 두 면에 주홍 단면판을 붙인다. 림·웹·단면판은 **세계에 고정**(단면도처럼 잘린 자리가 늘 앞 오른쪽 아래에 있다) — 림은 회전 대칭이라 돌지 않아도 같은 모습이다. 돌아감은 허브·노란 표시·축 너트와 벨트 표시로 보인다. 잘린 자리 ψ −90° ~ −25° 는 벨트가 닿지 않는 구간(벨트 접점 ψ = −14.93°, 여유 10°).

## 구동
구동 풀리 φ2(t) = 1.2·t [rad], 정면에서 반시계(`rotation.z = φ2`). 벨트 흐름 s = 0.23·φ2. 큰 풀리 φ1 = s / 0.565 = 0.40708·φ2.

## 부품과 치수 (새 함수는 `kit/k255.ts`, 상수 `K255`)
세계 좌표. 큰 풀리 중심 C1 = (0, 2.12), 구동 풀리 중심 C2 = (0, 0.82), 두 풀리 가운데 깊이 zc = 0.10. 단면 (r, a) 는 r = 축에서의 반지름, a = 축방향(세계 z − 0.10).
- `displayStand()`.
- **큰 풀리 축**(name `bigShaft`, φ1 로 돎): `shaftZ(0, 2.12, 0.384, 0.06)` — 뒤판 보스(깊이 −0.30 부터 −0.20 까지)·축 몸통·끝 너트(깊이 0.330 ~ 0.384, 너트 뒷면 = 허브 앞면 0.33). 그룹 `rotation.z = φ1`.
  - 축 칼라(축 그룹의 자식, steel): `lathe(tubeProfile(0.06, 0.09, -0.20, -0.13, 0.004), 36)` 를 rotateX(π/2) — 깊이 −0.20(보스 앞면) ~ −0.13(허브 뒷면). 허브가 뒤로 밀리지 않게 받친다.
- **큰 풀리 회전부**(name `bigPulley`, 그룹 위치 (0, 2.12, 0.10), `rotation.z = φ1`):
  - 허브(darkSteel): `lathe(tubeProfile(0.06, 0.16, -0.23, 0.23, 0.006), 48)` 를 rotateX(π/2) — 구멍 0.06(= 축), 바깥 0.16, a −0.23 ~ 0.23(림 옆면 밖으로 0.06 씩, 판화 허브).
  - 노란 표시 paint(0xf2b619): BoxGeometry(0.05, 0.014, 0.006) 를 로컬 (0.11, 0, 0.233) 에(허브 앞면 위, 너트 바깥 0.076 보다 밖).
  - 검사 표식: `setMM(bigPulley, { kind: 'wheel', fn: 'flangedPulley255', axis: 'z', r: 0.555, width: 0.20, span: [-0.10, 0.10], rim: 'flat', bottom: 0.555, outer: 0.62 })`.
- **큰 풀리 림(고정, 잘린 회전체)**: `cutRim255()` → 그룹(name `bigRimGroup`, 위치 (0, 2.12, 0.10), 돌지 않음). 안에:
  - 림·웹 메시(name `bigRim`, brass): 단면 `RIM255`(아래, 반시계 차례, 끝에 첫 점을 한 번 더) 를 `lathe(RIM255, 72, 65°, 295°)` (라디안으로) 한 뒤 rotateX(π/2). 이렇게 하면 재료가 평면각 ψ = atan2(y, x) 기준 **−25° → 270°(반시계)** 에 있고, ψ 270° ~ 335°(= −90° ~ −25°) 가 비어 있다. (LatheGeometry 각 φ 와 ψ 의 관계: rotateX(π/2) 뒤 ψ = φ − 90°.)
  - 단면판 둘(paint(0xd2552e), side = THREE.DoubleSide): `polygonFace(RIM255 의 14점, 닫는 점 없이)` → rotateX(π/2) → rotateZ(ψ). name `bigCutFace` 는 ψ = −90°(아래쪽, 면이 +X 를 향함 — 시점에서 보이는 면), name `bigCutFace2` 는 ψ = −25°.
  - `RIM255` (r, a) 14점: (0.156, −0.04) (0.47, −0.04) (0.47, −0.17) (0.612, −0.17) (0.62, −0.162) (0.62, −0.10) (0.555, −0.10) (0.555, 0.10) (0.62, 0.10) (0.62, 0.162) (0.612, 0.17) (0.47, 0.17) (0.47, 0.04) (0.156, 0.04). → 웹(두께 0.08, r 0.156 ~ 0.47, 허브 바깥 0.16 속으로 0.004 겹침) + 림 띠(r 0.47 ~ ) + 플랜지 둘(r 0.62, 두께 0.07, 모따기 0.008) + 드럼면(r 0.555, 폭 0.20).
- **구동 풀리 축**(name `driveShaft`, φ2 로 돎): `shaftZ(0, 0.82, 0.2605, 0.045)` — 끝 너트 깊이 0.22 ~ 0.2605(너트 뒷면 = 허브 앞면 0.22). 그룹 `rotation.z = φ2`. 칼라(자식, steel): `lathe(tubeProfile(0.045, 0.07, -0.20, -0.02, 0.004), 32)` rotateX(π/2), 깊이 −0.20 ~ −0.02(허브 뒷면).

  - 폭 방향 +Z(풀리 축과 나란) — 띠가 누워 림에 앉는다. 반시계 고리라 표시 상자가 띠 바깥면에 붙는다(B = T × Z 가 바깥쪽).
- 회전 표시: `rotArrow(0.30, true)` 를 (0, 0.82, 0.30) 에(구동 풀리 앞, 반시계).

## 동작 (`state255(t)` — 결정적)
1. φ2 = 1.2t. `driveShaft`·`drivePulley` 의 `rotation.z = φ2`.
2. φ1 = 0.40708·φ2. `bigShaft`·`bigPulley` 의 `rotation.z = φ1`. `bigRimGroup` 은 그대로.
3. `belt.setOffset(0.23·φ2)`.
4. 방향 검산: 반시계 고리에서 벨트가 구동 풀리 아래를 +X 로 지나며 큰 풀리 위를 −X 로 지난다 → 두 풀리 모두 반시계(ωz > 0).
5. 감긴 각: 큰 풀리 209.87°(위쪽, ψ −14.93° → 194.93°), 구동 풀리 150.13°(아래쪽, ψ 194.93° → 345.07°). 접선 끝점: 큰 풀리 (±0.5459, 1.9744) ↔ 구동 풀리 (±0.2222, 0.7607).
6. 틈 검산: 벨트(폭 ±0.08) ↔ 플랜지 안쪽 면(a ±0.10) 0.02. 벨트 안쪽 면 r 0.555 = 드럼면. 벨트 바깥 면 0.575 < 플랜지 0.62(0.045 아래). 잘린 자리 첫 면 ψ −25° 에서 벨트 중심 반지름 0.574(드럼면 위 0.019) — 단면판과 닿지 않음. 오른쪽 가닥(x 0.546 → 0.222)은 단면판(x = 0 평면)에서 0.2 이상 떨어짐. 화살표(깊이 0.30) ↔ 벨트(깊이 0.02 ~ 0.18): 0.12.

## ★ 눈에 보여야 할 동작
- 핵심: 구동 풀리가 돌면 평벨트가 흘러 **플랜지 풀리가 같은 방향으로 0.407배** 돈다. 벨트가 **두 플랜지 사이 드럼면에 누워** 위쪽 209.9° 를 감고, 잘린 면에서 플랜지가 벨트보다 솟은 凹 단면이 보인다(판화의 위·아래 윤곽과 같은 꼴).
- 장치: 벨트 노란 표시 8개(흐름), 큰 풀리 허브 노란 표시·축 너트(회전), 구동 풀리 앞 화살표, 주홍 단면판.

## ★ 난도·질문
난도 **A**(하) — 키트 풀리·경로 함수·평벨트 그대로, 새 것은 잘린 회전체 하나(점 목록·각 모두 주어짐). GLM 가능.
질문 거리(사용자에게) — 기본값으로 진행:
1. 판화는 축이 좌우로 누운 옆 모습. 기본값: 모델은 축을 깊이 방향으로 두고 45° 시점으로 판화 윤곽과 벨트를 함께 보임(판화와 같은 모습은 +X 옆에서).
2. 판화에 없는 구동 풀리·평벨트를 보충, 단면은 앞 오른쪽 아래를 잘라 보임(잘린 자리는 세계에 고정).
