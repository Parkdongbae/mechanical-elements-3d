# 080 갈고리 폴로 올리는 홈 랙
판화(public/mm507/fig/080.png, 확대 shots/_verify/080-fig-x4.png · 080-mid-x8.png 로 다시 읽음): 그림 하나(정면). 세로로 선 막대 A 는 양쪽 가장자리에 톱니가 나 있고 가운데에 긴 홈이 뚫렸으며, 위 끝은 나팔처럼 벌어진 머리, 아래 끝은 톱니 없는 자루(끊긴 선 = 더 이어짐)다. 막대 뒤로 가로 레버 C 가 지나간다 — 양 끝에 둥근 공(손잡이), 가운데가 두껍다. 레버의 받침 핀은 막대의 긴 홈 꼭대기에 보이는 작은 원이고, 그 바로 아래의 작은 네모는 홈 속 안내 블록이다. 레버에서 받침 핀 양옆(막대 바깥)에 핀이 하나씩 있고, 거기에 긴 폴이 하나씩 매달려 **X 자로 엇갈려** 내려가 반대쪽 톱니에 걸린다(왼쪽 핀의 폴 → 오른쪽 톱니, 오른쪽 핀의 폴 → 왼쪽 톱니). 폴 끝은 톱니 바깥을 돌아 안쪽 위로 굽은 갈고리다.
원문 요지: 레버 C 가 흔들리면 갈고리 폴 두 개가 번갈아 홈 랙 막대 A 의 톱니에 떨어져 걸리면서 막대 A 에 직선 운동을 준다.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 부품은 막대 A 1, 레버 C 1, 갈고리 폴 2, 받침 핀 1, 안내 블록 1.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가, 어디서? → 줄은 없고, 두 폴이 막대 앞에서 X 자로 엇갈린다(받침 핀 아래 약 0.5, 막대 가운데선 위). 서로 다른 층이라 닿지 않는다.
4. 고정점은 어디인가? → 받침 핀(홈 꼭대기의 원)과 그 아래 안내 블록(네모). 판화에는 이 둘을 붙든 틀이 그려져 있지 않다. 막대 A 는 이 둘에 끼워져 세로로만 미끄러진다.
5. 추·손잡이·크랭크는 어디에 달렸는가? → 레버 C 양 끝의 둥근 공이 손잡이. 추·크랭크 없음.
6. 이는 어느 가장자리에 났고 무엇이 어느 쪽에서 물리는가? → 막대 A 의 왼쪽·오른쪽 바깥 가장자리에 톱니(좌우 같은 높이, 한쪽에 약 15개, 피치 ≈ 레버 반길이의 1/10). 갈고리는 **바깥에서 안쪽 위로** 굽어 들어와 톱니의 아래를 보는 면을 받친다 → 폴이 올라갈 때 막대를 끌어 올린다.
7. 한 줄에 놓인 것은? → 레버의 두 폴 핀과 받침 핀이 한 가로선(판화 순간 레버는 거의 수평). 두 갈고리 끝이 같은 높이. 받침 핀·안내 블록·긴 홈·막대가 한 세로선.
8. 글자가 가리키는 부품은? → A = 홈 랙 막대(아래 자루에 적힘), C = 레버(오른쪽 팔 위). B 는 없다.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳은? → 기구는 같다. 다만 막대가 한 방향으로만 가므로 끝없이 돌릴 수 없다 → 전시용으로 "두 번 왕복해 올린 뒤 폴을 젖히고 막대를 내려 되돌리는" 구간을 넣었다(판화에 없음, ★질문 거리 아님 — 아래 해석).
- 그 밖의 선: 톱니의 방향(어느 면이 평평한가)은 판화 해상도로는 가릴 수 없다. 갈고리가 아래에서 위로 굽어 들어간 모양에서 "아래를 보는 평평한 면 + 그 위 비탈"로 정했다. 폴 핀 둘레의 겹원 = 폴의 눈(고리). 머리의 오목한 옆선 = 나팔 모양.

## 해석(결정 사항)
- 막대 A 는 **위로** 올라간다(갈고리가 끌어 올림). 레버가 흔들릴 때 올라가는 쪽 폴이 막대를 올리고, 내려가는 쪽 폴은 톱니 비탈을 타고 미끄러지다 다음 톱니 밑으로 떨어진다(원문 drop). 두 폴이 번갈아 받치므로 막대는 레버의 두 행정 모두에서 올라간다.
- 레버(뒤) — 막대(가운데) — 폴(앞)의 세 층. 폴 핀은 레버에서 막대 옆을 지나 앞으로 나온다. 갈고리 코만 막대와 같은 층으로 내려온다.
- 한 반 행정에 톱니 2개(0.18), 헛걸음 0.012(갈고리가 톱니 밑으로 0.012 더 내려가 확실히 걸리게). 뒤집힐 때 막대가 0.005 내려앉았다가 올라간다(짐이 누르는 실제 거동).
- 치수를 바꾸면 `shots/_verify/s080.mjs` 를 다시 돌린다.

## 구동
레버 C(손으로 흔듦). theta += OMEGA(1.6)·speed·dt. 레버 한 번 왕복 = 2π(3.93 s), 한 주기 = 6π(11.78 s): 0 ~ 4π 는 올림(두 번 왕복, 톱니 8개 = 0.72), 4π ~ 6π 는 되돌림.

## 부품과 치수 (모두 `kit/k080.ts`, 이미 구현됨. 값은 `K80` 상수)
받침 핀 O = (0, 2.13). 모든 층의 z 는 아래 깊이 계산 절.
- 받침 핀: `shaftZ(0, 2.13, 0.21, 0.03)` — 뒤판에서 나와 레버 구멍·막대 홈·덮개 판을 꿴다(고정).
- 레버 C(name `leverC`): `rockLever80(0.262)` 위치 (0, 2.13, 0). 팔 반길이 0.9, 가운데 반높이 0.09 → 끝 0.04, 양 끝 공(반지름 0.1, 중심 ±0.96), 폴 핀 ±0.45(반지름 0.02, z 0.262 까지). 두께 0.05. `userData.pins[0]`(왼쪽)에 name `pinL`, `[1]` 에 name `pinR`.
- 막대 A(name `rackA`): `slottedRack80(0.07)` 위치 (0, 2.13 + barY, 0.09). 막대 좌표 v(톱니 격자): 이뿌리 반폭 0.21, 이끝 반폭 0.255, 피치 0.09, 톱니 번호 −5 … 10(한쪽 16개, v 0.54 ~ −0.90). 머리 v 1.0 → 1.2(반폭 0.21 → 0.30), 자루 반폭 0.16, v −0.93 ~ −1.07. 긴 홈: 반폭 0.036, 가운데선 v −0.40 ~ 0.85. 처음 자리 barY = −0.8408 → 받침 핀이 홈 꼭대기(v 0.841)에 있다(판화). 황동, 머리 아래 밝은 눈금.
- 폴 1(name `pawl1`, 왼쪽 핀 → 오른쪽 톱니): `hookPawl80(false, 0.165, 0.09)` 위치 = 왼쪽 핀 (−0.45 cos φ, 2.13 − 0.45 sin φ, 0). 길이(핀 → 갈고리 끝) 1.14. 판은 z 0.165 층, 갈고리 코는 z 0.09(막대 층).
- 폴 2(name `pawl2`, 오른쪽 핀 → 왼쪽 톱니): `hookPawl80(true, 0.225, 0.09)` 위치 = 오른쪽 핀 (0.45 cos φ, 2.13 + 0.45 sin φ, 0). 판은 z 0.225 층.
- 덮개 판 + 안내 블록(name `keeper`, 고정): `slotKeeper80(0.145, 0.05)` 위치 (0, 2.13, 0). 블록은 핀 아래 0.12, 반높이 0.035, 홈 속(z 0.05 ~ 0.145)에 들어가 막대가 돌지 않게 잡는다(판화의 네모).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 판화에 없음(보충 부품): 덮개 판(안내 블록을 받침 핀에 붙드는 작은 판) 하나. 그 밖에 없음.
- 가로 범위: 공 바깥 ±1.06. 세로: 머리 꼭대기 2.489(처음) → 3.209(다 올림) → 3.259(되돌림 때 잠깐 든 순간), 자루 바닥 0.219(처음).

## 동작 (모두 `k80State(theta)` 의 값 — theta 의 절대 함수)
- τ = theta mod 6π. 레버 각 φ = −Φ·cos τ, Φ = asin(S / 2a) = 12.32°(S = 2·0.09 + 0.012 = 0.192, a = 0.45). `leverC.rotation.z = φ`.
- 걸린 폴의 끝 높이(받침 핀 기준): h1 = −a sin φ − g(φ), h2 = +a sin φ − g(φ), g(φ) = √(L² − (0.21 + a cos φ)²), L = 1.14.
- 올림(τ < 4π): barY = max(h1 + 0.36·⌊(τ + π)/2π⌋, h2 + 0.18·(1 + 2⌊τ/2π⌋)). 큰 쪽이 지금 받치는 폴(`holder`).
- 되돌림(τ ≥ 4π, u = τ − 4π): 막대를 0.05 들어 갈고리를 풀고(u 0 ~ 0.2) → 두 폴을 0.085 rad 젖히고(u 0.12 ~ 0.42) → 막대를 0.72 내리고(u 0.6 ~ 5.28) → 폴을 놓고(u 5.58 ~ 5.93) → 막대를 갈고리 위에 얹는다(u 6.0 ~ 6.24). 끝 자세 = 처음 자세(주기가 정확히 닫힘).
- 폴 기울기 ψ(세로에서 잰 각): 받치는 폴은 끝이 이뿌리 구석에 있는 각(약 35°), 미끄러지는 폴은 끝이 톱니 비탈에 닿는 각(이분법, 최대 +2°). `pawl1.rotation.z = +psi1`, `pawl2.rotation.z = −psi2`.
- `rackA.position.y = 2.13 + barY`. 이름표 '홈 랙 막대 A' 는 막대를 따라가지 않는다(자루 옆 고정).
- 시각: **t = 1.0 (τ 1.6, φ ≈ 0° — 판화 자세: 레버 수평, 두 갈고리 같은 높이, 오른쪽 핀이 올라가는 중, lift 0.094)**, **t = 1.6 (φ 10.3°, lift 0.167, 폴 1 이 비탈 위)**, t = 5 (lift 0.465), t = 8.2 (되돌림 시작: 폴 젖힘), t = 10 (내려오는 중, lift 0.30), t = 11.78 = 0.

## notes
- ① 지금 상태 '올림 / 되돌림(폴을 젖히고 내림)' ② 받치는 폴 '왼쪽 핀의 폴 / 오른쪽 핀의 폴 / 없음' ③ 올라간 높이(lift, 0 ~ 0.72)와 넘긴 톱니 수(0 ~ 8) ④ 레버 각 φ(±12.3°) ⑤ '레버 한 번 왕복에 톱니 4개'.

## 확인
- t=1 정면: 판화와 같은 모양(레버 수평, X 자 폴, 갈고리 둘이 같은 높이, 받침 핀이 홈 위쪽). t=1.6 정면: 레버가 오른쪽 위로 기울고 막대가 0.07 더 올라감.
- 근접 `cam=0.9,1.3,1.6,0.25,1.2,0.09`(오른쪽 갈고리와 톱니), `cam=0,2.3,1.5,0,2.1,0.1`(받침 핀·안내 블록·홈), 옆 `cam=3,1.8,0.3,0,1.8,0.1`(세 층).
- 수치: `node shots/_verify/s080.mjs`(키트 윤곽·자세 함수로 한 주기 6000 걸음) → 갈고리 코 ↔ 막대 최대 침범 0.0000(허용 0.004), 한 주기 뒤 자세 차 0, lift −0.005 ~ 0.770.

## ★ 깊이 계산
