# 113 랙과 피니언
원문: "Circular into rectilinear motion, or vice versa, by means of rack and pinion." — 랙과 피니언으로 회전 운동을 직선 운동으로, 또는 그 반대로 바꾼다(설명은 이 한 줄뿐).

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/113-fig-x4.png` 로 다시 읽음(아래 px 는 4배 그림 기준).
1. 바퀴는 몇 개이고 크기 차례는? → 3개. 아래 가운데의 **피니언 1개**(이 18개 안팎, 이끝 반지름 약 215px, 가운데에 빗금 친 축 단면과 허브 고리) + 판 양 끝 밑의 **두 겹 원 2개**(바깥 반지름 약 90px — 판을 받치는 굴림 바퀴. 속이 빈 고리로 그려졌다). 크기: 피니언 > 굴림 바퀴 둘(서로 같음).
2. 줄·벨트는? → 없음. 대신 **랙 1개**: 긴 판(길이 약 1700px, 두께 약 50px, 양 끝이 비스듬히 잘려 윗변이 더 김) 밑면 가운데에 붙은 네모 덩어리(길이 약 1130px = 판의 0.66배, 높이 약 140px)의 아랫면에 네모꼴 이가 14개쯤 아래로 나 있다. 피니언이 그 이에 아래에서 물린다.
3. 교차하는 가닥은? → 없음. 겹치는 곳은 피니언 윗부분의 이 3~4개가 랙 이 사이로 들어간 자리뿐(물림).
4. 고정점은? → 판화에는 받침이 하나도 그려져 있지 않다. 피니언 축(빗금 = 축 단면)과 두 굴림 바퀴의 축은 제자리에서 돌기만 하는 것으로 읽는다. 맨 아래 가로선은 그림 칸의 테두리.
5. 추·손잡이·크랭크는? → 없음. 어느 쪽이 구동인지는 원문이 "회전 → 직선, 또는 그 반대"라고만 한다(모형은 피니언을 구동으로).
6. 이는 어디에 났고 무엇이 물리는가? → 랙의 이는 덩어리 **아랫면**(바깥으로, 아래를 향함). 피니언은 바깥 둘레 전체에 이. 피니언이 **아래에서 위로** 랙에 물린다. 굴림 바퀴에는 이가 없다(판 밑면에 닿아 구르는 마찰 접촉).
7. 한 줄에 놓인 것은? → 두 굴림 바퀴의 중심이 같은 높이(둘 다 판 밑면에 닿음)이고 그 높이는 랙 덩어리의 중간. 굴림 바퀴는 랙 덩어리의 양 끝 바로 밖(틈 30~50px). 피니언 중심은 랙 가운데에서 조금 오른쪽(x 920px, 덩어리 가운데 865px).
8. 글자가 가리키는 부품은? → 글자 없음(번호 113 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 원문과 다른 곳 없음. 다만 판화대로 굴림 바퀴가 랙과 같은 깊이에 있으면 랙 덩어리가 50px(판 길이의 3 %)만 가도 바퀴에 부딪힌다. 판화는 정면만 보여 주므로, 굴림 바퀴를 **랙의 앞·뒤(깊이 방향)** 에 한 쌍씩 두어 랙이 그 사이로 지나가게 한다 — 정면에서는 판화와 같은 모양. 기구가 달라지지 않으므로 질문 거리는 없음.
- 그 밖의 선: 굴림 바퀴의 안쪽 원 = 테 안쪽 턱(또는 속 빈 굴대). 피니언 가운데의 빗금 원 = 축 단면, 그 둘레 원 = 허브. 판의 윗변·아랫변 두 줄 = 판의 두께.

## 해석(결정 사항)
- 판화 비를 따른다: 피니언 이 18개, 랙 이 14개, 랙 덩어리가 판의 약 0.6배, 굴림 바퀴는 덩어리 양 끝 바로 밖, 굴림 바퀴 중심이 랙 덩어리 높이의 중간.
- 랙이 유한하므로 피니언은 한 방향으로 계속 돌 수 없다 → **좌우로 흔들리는 구동**(±42.4°)으로 탁자를 왕복시킨다. t = 1 에 가운데(판화 자세).
- 판화에 없는 보충(최소): 피니언 축의 뒤판 보스(`shaftZ` 에 포함), 굴림 바퀴를 받치는 벽 굴대 받침 2개(뒤판에서 나온 팔 + 볼 두 장). 굴림 바퀴는 정면에서 2개로 보이지만 깊이 방향으로 한 쌍씩 모두 4개다(9번 답).

## 구동
피니언(name `pinion`). theta += OMEGA(1.6)·speed·dt 로 누적하고, 피니언 각은 phi = 0.7407·sin(theta − 1.6) (rad) — 3.93 s 에 한 번 왕복. `k113State(theta)` 가 돌려준다.

## 부품과 치수 (새 부품은 모두 `kit/k113.ts`, 이미 구현됨. 치수 상수 `K113`)
배치 상수: PY = 1.4 (피니언 축 높이, x 는 0), ZR = 0.25 (피니언·랙의 가운데 평면), 피치선 높이 = PY + 0.405 = 1.805.
- 피니언(name `pinion`): `spurGear(18, 0.045, { width: 0.12, spokes: 4, driver: true })` — 피치 반지름 0.405, 이끝 0.45. 위치 (0, 1.4, 0.25).
- 피니언 축: `shaftZ(0, 1.4, 0.36, 0.05)` — 뒤판 보스에서 피니언 앞까지.
- 랙 달린 탁자(name `table`): `rackTable113()` — 그룹 원점 = 랙 피치선 위의 점. 위치 (x(θ), 1.805, 0.25). 랙 이 14개(모듈 0.045, 피치 0.1414, 20° 직선 측면, 이 범위 ±0.973), 랙 덩어리 길이 2.23·높이 0.2(이뿌리선 위)·폭 0.14, 판 길이 3.6·두께 0.08·깊이 0.54(양 끝 비스듬). 판 밑면 높이 2.061, 윗면 2.141. 랙은 강철, 판은 주철.
- 벽 굴대 받침 2개: `wallYoke113(−1.36, 1.901, 0.25)`, `wallYoke113(1.36, 1.901, 0.25)` — 돌려주는 값 { group, rollers }. 굴대 높이 1.901 = 판 밑면 2.061 − 바퀴 반지름 0.16(모델은 `K113` 과 탁자의 mm.plateBottom 에서 계산). 굴림 바퀴(반지름 0.16, 폭 0.1)는 랙의 뒤(z = 0.05)·앞(z = 0.45)에 하나씩, 볼(세운 판) 두 장은 랙 옆면에서 0.02 떨어져 z 0.11~0.16, 0.34~0.39. 팔은 랙 이끝(1.76)보다 아래(윗면 1.711)로 뒤판에서 나온다. 앞 바퀴에 name `rollerL`(왼쪽)·`rollerR`(오른쪽)을 붙인다(rollers[1]).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위: 판 끝 ±1.8 → 왕복 때 ±2.1. 세로 0.95(피니언 아래) ~ 2.14(판 윗면).

## 동작 (모두 theta 의 닫힌 식 — `k113State(theta)` 가 { phi, x, roll, ccw } 를 돌려준다)
- 피니언: `pinion.rotation.z = phi`, phi = (0.3 / 0.405)·sin(theta − 1.6).
- 탁자: x = −0.405·phi (피니언이 반시계로 돌면 윗면이 왼쪽으로 가므로 탁자는 왼쪽). `table.position.x = x`. 범위 ±0.3.
- 굴림 바퀴 4개: `rotation.z = roll = −x / 0.16` (판 밑면에서 미끄럼 없이 구름 — 피니언과 같은 방향, 2.53배 빠름).
- 랙 위상: `rackTable113` 안에서 `k113RackX0()` 로 x = 0·phi = 0 에 맞춰 두었다(모델은 따로 맞출 것 없음).
- 시각: **t = 1.0 (phi = 0, 탁자 가운데 = 판화 자세, 반시계로 도는 중)**, **t = 1.6 (phi = +34.8°, 탁자 x = −0.246)**, t = 1.98 (왼쪽 끝 −0.3), t = 3.95 (오른쪽 끝 +0.3).

## 표시
- rotArrow 2개를 피니언 앞 (0, 1.4) z = 0.38 에 겹쳐 두고 하나만 보인다: `rotArrow(0.2, true)` 는 ccw 가 참일 때, `rotArrow(0.2, false)` 는 거짓일 때(흔들리는 구동이라 실제 방향을 따라 바뀜). 반지름 0.2 라 이(0.35 바깥)를 가리지 않는다.
- tag 이름표 4개: '피니언(구동, 좌우로 흔들림)' (0, 0.7, 0.35) 고정, '랙(판 밑에 붙음)' (x − 0.8, 2.45, 0.3) 탁자를 따라감, '탁자 판' (x + 0.9, 2.45, 0.3) 탁자를 따라감, '굴림 바퀴' (1.36, 1.3, 0.5) 고정.

## notes
① 피니언 '이 18개, 피치 반지름 0.405' ② 랙 '이 14개, 피치 0.141' ③ 탁자 이동 'NN mm'(x·1000, 부호 포함) = 피치 반지름 × 피니언 각 ④ 피니언 각 'NN°' ⑤ '피니언이 한 바퀴 돌면 랙은 2.54(피치원 둘레) 만큼 간다'.

## 확인
- t = 1 정면: 판화와 같은 모양(탁자 가운데, 피니언이 랙 가운데 밑에서 물림, 굴림 바퀴가 덩어리 양 끝 밖). t = 1.6 정면: 탁자가 왼쪽으로 0.246.
- 근접 `cam=0,2.0,1.6,0,1.75,0.25`(물림 자리), `cam=2.4,2.3,1.8,1.36,1.9,0.25`(굴대 받침 — 랙이 두 볼 사이로 지나감), 옆 `cam=3.6,1.9,0.25,0,1.9,0.25`(깊이 층: 뒤 바퀴 · 볼 · 랙 · 볼 · 앞 바퀴), 아래 `cam=0,0.5,2.2,0,1.8,0.25`(랙 이가 팔 위로 지나감).
