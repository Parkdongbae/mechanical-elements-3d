# 111 마이크로미터 나사

> **결정(2026-11-26, 사용자):** 나사산 **모양은 원문·판화대로 반대 방향**(위 오른나사, 아래 왼나사, diffScrew111(-1)), **움직임은 원문 설명대로 피치의 차**(한 바퀴에 0.1, diff111(theta, 1))로 만든다. 아래의 보류 문구는 무시한다.


> **보류(사용자 확인 필요)** — 두 나사의 감긴 방향을 어느 쪽으로 만들지 정해야 한다.
> 판화와 원문은 둘 다 "두 나사가 **서로 반대 방향**"이라 하면서, 원문은 결과를 "한 바퀴에 두 피치의 **차**만큼만 간다"고 적었다. 그런데 반대 방향 나사는 실제로 **합**만큼 간다(차가 나오려면 같은 방향이어야 한다). 판화·원문대로는 원문이 말한 동작이 나오지 않는다.
> - **안 가 (추천)** — 두 나사를 **같은 방향(둘 다 오른나사)** 으로. 한 바퀴에 0.2 − 0.1 = 0.1(차). "마이크로미터·큰 힘"이라는 제목과 원문의 결론에 맞는다. 판화와 다른 점: 아래 가는 나사의 산 기울기(판화는 "\", 모형은 "/").
> - **안 나** — 판화 그대로 **반대 방향**(위 오른나사, 아래 왼나사). 한 바퀴에 0.2 + 0.1 = 0.3(합). 판화 모양과 같지만 "차만큼만 간다"는 설명과 어긋나고, 미세 이동 장치가 아니라 빠른 이송 장치가 된다.
> 키트는 두 안을 모두 지원한다(`hand2` = +1 / −1 하나만 바꾸면 됨). 이 설계표의 수치는 안 가 기준이고, 안 나일 때 달라지는 값은 괄호로 적었다. **답이 오기 전에는 모델을 만들지 않는다.**

원문 요지: 마이크로미터 나사. 이 장치로 큰 힘을 얻는다. 나사산의 피치가 서로 다르고 방향도 다르게 났으므로, 안쪽의 더 작은 나사에 끼운 다이(또는 너트)는, 바깥의 속 빈 나사가 너트 안에서 한 바퀴 돌 때마다 두 피치의 차만큼만 나아간다. (원문 영어에 섞인 낱말 rate·are·fast·a·it·one·set 는 옆 단의 글자가 스캔에 끼어든 것.)

7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 머리·굵은 나사·가는 나사·아래 끝(둥근 민 끝)이 한 세로 중심선 위(x 1262px).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 111 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 있다 — ★질문 거리. 판화·원문 모두 "반대 방향 나사"인데 그러면 이동량이 피치의 합이 되어 원문의 "차만큼만"과 모순(머리의 보류 참고). 또 한 방향으로 계속 돌리면 나사가 너트를 빠져나가므로 모형은 ±1바퀴를 되돌려 돌린다.
- 그 밖의 선: 굵은 나사와 가는 나사가 만나는 곳의 세모꼴은 굵은 나사 마지막 산의 끝자락. 원문의 "속 빈 바깥 나사·안쪽 나사"는 두 겹 구조로도 읽을 수 있으나(속 빈 굵은 나사 안에서 가는 나사가 드나드는 꼴), 판화는 한 몸으로 그렸고 이동량 식은 두 구조가 같다 → 판화대로 **한 몸**으로 만든다.

## 해석(결정 사항)
- 한 몸 나사(머리 + 굵은 나사 + 가는 나사). 굵은 나사는 **고정 너트** 안에서 돌며 오르내리고, 가는 나사에 끼운 **이동 너트**(다이)는 돌지 못하게 잡혀 오르내리기만 한다.
- 피치는 판화 비 2 : 1 → 굵은 나사 0.2, 가는 나사 0.1. 한 바퀴에 나사는 0.2, 이동 너트는 0.1(안 나: 0.3).
- 판화에 없음(원문에는 있음): 고정 너트, 이동 너트. 판화·원문에 없음(최소 보충): 고정 너트를 뒤판에 붙이는 받침 팔, 이동 너트가 돌지 못하게 하는 안내 막대 2개, 돌림이 보이게 하는 머리의 손잡이 막대.

나사(theta 누적 → 되돌이 회전). theta += OMEGA(1.6)·speed·dt, 나사 회전각 psi = 2π·sin(theta / 2) — ±1바퀴 사이를 7.85 s 주기로 오간다.

## 동작 (모두 theta 의 닫힌 식 — `diff111(theta, 1)` 가 돌려준다. 안 나는 `diff111(theta, -1)`)
`const D = diff111(theta, 1)` → { psi, turns, screwY, nutY, dir }.
- turns = sin(theta / 2) (지금까지 돈 바퀴 수, −1 ~ +1), psi = 2π·turns.
- `screw.rotation.y = D.psi`, `screw.position.y = 1.82 + D.screwY` — screwY = 0.2·turns (±0.2). 굵은 오른나사가 고정 너트 안에서 위에서 보아 반시계로 돌면 올라간다.
- `travelNut.position.y = 1.37 + D.nutY` — nutY = (0.2 − 0.1)·turns = 0.1·turns (±0.1). 나사가 0.2 올라가는 동안 돌지 않는 너트는 가는 나사 위에서 0.1 내려가므로 실제로는 0.1 만 올라간다. (안 나: nutY = 0.3·turns, ±0.3.)
- 범위 확인(s110.mjs): 고정 너트는 굵은 나사 0.03 ~ 0.73 구간 안(나사부 0 ~ 0.76), 이동 너트는 가는 나사 −0.65 ~ −0.25 구간 안(나사부 −0.9 ~ 0). 이동 너트 윗면 최고 1.57 < 고정 너트 아랫면 2.05, 아랫면 최저 1.17 > 멈춤 너트 0.90 (안 나: 1.77 < 2.05, 0.97 > 0.90).
- 시각: **t = 1.0 (turns 0.717, 나사 +0.143, 너트 +0.072)**, **t = 1.6 (turns 0.958, 나사 +0.192, 너트 +0.096)**, t = 2.95 (내려오는 중 turns 0.704), t = 30 (turns −0.906, 나사 −0.181, 너트 −0.091).
