# 249 관용 볼 앤드 소켓 이음
원문(en): "Ball-and-socket joint, arranged for tubing." — 관(튜브)용으로 만든 볼 앤드 소켓(구형) 이음.
쉬운 풀이: 위 관 끝에 속이 빈 공이 붙어 있고, 아래 관에 붙은 오목한 소켓(위·아래 두 쪽을 볼트로 죔)이 그 공을 감싼다. 위 관을 기울여도 공이 소켓 속에서 돌 뿐이라 관 속 물길은 끊기지 않는다.
판화 묘사(원본 470×461 px, **세로 단면도**): 위에서 관(바깥 x 228~302, 벽 안선 243·287)이 내려와 가운데 큰 원(공, 중심 약 [263·252], 반지름 87)의 꼭대기에 붙는다. 공 아래쪽은 가로 현(y 320)으로 잘려 열려 있다. 공을 두께 약 14 px 의 고리(소켓, 바깥 반지름 약 101)가 감싸고, 소켓은 공 가운데 높이에서 위·아래 두 쪽으로 나뉘어 좌우 귀(x 92~165, 360~425, y 228~272)에 볼트·너트 두 개로 죄인다. 귀 위에 작은 혹(보강). 소켓 아래쪽 바닥에서 아래 관(바깥 x 218~305, 안 240~285)이 내려간다.

## 해석(결정 사항)
- 단면 평면 z 0.55. 공+위 관·소켓 두 쪽·귀·아래 관은 **뒤 반쪽만**(잘린 면 = 판화의 단면). 공은 z 축(단면에 수직)으로만 돌아 잘린 면이 늘 평면 z 0.55 에 남는다. 볼트·너트·안내 핀은 통째.
- 공: 바깥 0.6786, 안 0.6006(벽 0.078), 아래를 y −0.5304 에서 잘라 연 구멍(바깥 반지름 0.4233). 위 관: 바깥 0.2886, 안 0.1716, 공 중심에서 위로 1.4586 까지(판화 길이).
- 소켓: 안 반지름 0.6864(공과 틈 0.0078), 바깥 0.7956. 위 반쪽 = 적도(y 0)에서 위 구멍(반지름 0.546; 안 구면 y 0.416, 바깥 구면 y 0.5787)까지. 아래 반쪽 = 적도에서 아래 관(바깥 0.3354, 안 0.1716)까지.
- 위 관 기울기 β(t) = 16°·sin(2πt/8)(오른쪽 + = 반시계 → 관 윗끝이 왼쪽으로). 검산(파이썬): ±16° 에서 관 바깥–위 구멍 테 틈 ≥ 0.077, 공 아래 구멍이 0.318 밀려도 아래 관 안지름(0.1716)을 늘 덮음(0.318 < 0.4233) → 물길이 이어짐. 공은 소켓 구면 안(0.6786 < 0.6864)에서만 돎.

## 구동
β(t) = (16·π/180)·sin(2π·t/8). 위 관+공 그룹 `rotation.z = β`.
