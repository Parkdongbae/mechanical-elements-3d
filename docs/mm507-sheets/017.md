# 017 스페인 바턴 (2)
판화: 16 과 같은 종류. 위에 도르래 A(들보 갈고리에 매달림), 오른쪽 아래에 도르래 B(A 의 오른쪽 줄 끝에 매달림), 맨 아래 왼쪽에 움직도르래 M(추 걸림). 왼쪽 들보 고리에서 내려온 줄이 M 의 왼쪽을 지나 밑을 돌아 올라가 A 를 넘어 B 로 내려간다. 그리고 **M 의 중심(윗 눈)에서 B 쪽으로 비스듬히 올라가는 줄**이 B 위를 넘어 오른쪽으로 늘어진다(자유 끝). 원문: 16 과 17 은 스페인 바턴. 16 과 달리 M 에 줄이 비스듬히 맨다.
구동: 오른쪽 줄 끝(자유 끝)을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 줄 P(들보 → M 밑 → A 위 → B 매닮)와 줄 Q(M 윗 눈 → B 위 → 자유 끝)의 두 줄로 읽는다. Q 가 비스듬해서 이득은 수직 줄의 이상식(5배)보다 작고 위치에 따라 조금 변한다(끝에서 약 4배). notes 는 실제 값을 계산해 보여 준다.

## 부품과 치수
016 의 `rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)를 쓴다. 파일이 없으면 016 의 '키트 추가' 대로 만든다.
도르래 반지름 모두 0.2, 두께 0.07, 중심 z = 0.22. 줄 반지름 0.014.
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [-0.5, 0.1])` → 고리 아랫점 (−0.5, 2.94, 0.22), (0.1, 2.94, 0.22).
- A: `pulleyBlock(0.2, { hookUp: 0.06 })`, 중심 (0.1, 2.55). 윗 눈 (0.1, 2.81) 과 고리 (0.1, 2.94) 를 `rod`.
- M: `pulleyBlock(0.2, { hookUp: 0.06, hookDown: 0.06 })`, 중심 (−0.3, yM).
- B: `pulleyBlock(0.2, { hookUp: 0.06 })`, 중심 (0.3, yB).
- 추: `weight(0.44, 0.30)`, 중심 (−0.3, yM − 0.51), M 아랫 눈 (−0.3, yM − 0.26) 에서 추 윗면까지 `rod`.
- 줄 P, 줄 Q: `Rope` 2개. P 는 z = 0.19, Q 는 z = 0.25(둘이 X 로 엇갈리는 곳에서 서로 안 박히게). Q 자유 끝에 `ropeEnd()`.

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `h = 0.25 × p`.
- yM = 0.92 + h
- yB = 2.00 − 2h (줄 P 가 일정 길이이므로 M 이 h 오르면 B 는 2h 내려온다)
- Q 의 첫 구간 길이 s1 = hypot(0.4, yB − (yM + 0.26)), 처음 값 s1_0 = hypot(0.4, 2.00 − 1.18) = 0.9124
- 자유 구간 길이 free = 0.25 − (s1 − s1_0), 자유 끝 높이 yF = yB − free (시작 1.75, 끝 약 0.74)

### 줄 경로 (`arcPoints(c, r, a0, a1, z)`, a1 < a0 이면 시계방향)
- 줄 P (z = 0.19): (−0.5, 2.94) → (−0.5, yM) → `arcPoints([−0.3, yM], 0.2, π, 2π)` → (−0.1, yM) → (−0.1, 2.55) → `arcPoints([0.1, 2.55], 0.2, π, 0)` → (0.3, 2.55) → B 윗 눈 (0.3, yB + 0.26).
- 줄 Q (z = 0.25): M 윗 눈 (−0.3, yM + 0.26) → (0.1, yB) [B 의 왼쪽 끝점] → `arcPoints([0.3, yB], 0.2, π, 0)` → (0.5, yB) → (0.5, yF).
  (Q 의 첫 구간은 접선 근사: B 의 왼쪽 끝점에 곧장 닿게 하며, 이음새의 작은 꺾임은 무시한다.)

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, h, yM, yB, s1, yF 를 재계산.
- 도르래 각(반시계 +, `userData.sheave.rotation.z`):
  - θ_M = +h / 0.2
  - θ_A = −2h / 0.2 (A 의 왼쪽 줄이 M 오른쪽 가닥을 따라 2h 만큼 올라감 → 시계)
  - θ_B = (s1 − s1_0) / 0.2 (s1 이 줄어드니 시계; 줄이 B 의 왼쪽 끝점으로 들어간 길이)
- M·추 = yM, B = yB, 손잡이 = yF.

## 표시
- `rotArrow(0.3, false)` 를 A 앞 (0.1, 2.55, 0.40).
- tag 'A 고정 도르래', 'B 움직도르래', 'M 움직도르래', '추', '당기는 곳'. 위치는 부품에서 0.35 바깥, 매 프레임 따라감.
- notes: `ratio = (1.75 − yF) / h` (h > 0.01 일 때) → `{ label: '이득', value: ratio.toFixed(1) + '배' }` (h 가 0.01 이하면 '—'), `{ label: '당긴 줄 : 오른 높이', value: (1.75 − yF).toFixed(2) + ' : ' + h.toFixed(2) }`, `{ label: '줄', value: '두 가닥(P, Q)' }`.

## 확인
- t=0.4 (p ≈ 0): B 가 A 바로 아래, Q 가 M 에서 B 로 가파르게 올라간다. t=3.9 (p ≈ 1): 추가 0.25 올라가고 B 는 0.5 내려와 M 쪽 높이에 가까워지며 Q 가 거의 수평으로 눕는다. 자유 끝은 약 1.0 내려간다.
- 줄 P 와 Q 가 M 오른쪽 위에서 서로 엇갈리되 박히지 않는다.
