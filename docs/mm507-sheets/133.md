# 133 피니언·부채꼴 프레스
원문: "A simple press motion is given through the hand-crank on the pinion-shaft; the pinion communicating motion to the toothed sector, which acts upon the platen, by means of the rod which connects it therewith." — 간단한 프레스 운동. 피니언 축의 손 크랭크로 돌리면 피니언이 이 부채꼴에 운동을 전하고, 부채꼴은 연결봉으로 이어진 누름판을 움직인다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/133-fig-x4.png` 로 다시 읽음(아래 [x·y] 는 4배 확대 그림의 px 자리).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 둘. ① 오른쪽 가운데의 작은 **피니언** 1개(중심 [1290·1000], 피치 반지름 약 110, 이 10개). ② 아래의 큰 **이 부채꼴** 1개(축 = 빗금 원 [800·1650], 피치 반지름 약 700 — 온 바퀴가 아니라 4분의 1쯤, 위(90°)에서 오른쪽 아래(−3°)까지 이가 17개쯤). 크기 비 110 : 700 = 10 : 64.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 대신 곧은 **연결봉** 1개: 부채꼴 아래쪽 살 위의 핀 [1070·1660](고리 눈, 축에서 270 — 판화의 순간에는 거의 3시 방향 −2°)에서 왼쪽 위로 올라가 누름판 밑 귀의 핀 [800·790] 에 닿는다. 핀 사이 길이 911.
3. 교차하는 가닥이 있는가? → 가닥은 없다. 겹침 차례(앞 → 뒤): 손 크랭크 → 연결봉(부채꼴의 살·테 앞을 끊김 없이 지나간다) → 부채꼴·피니언(같은 평면에서 물림) → 오른쪽 기둥(부채꼴 뒤로 가는 선으로 비쳐 보인다)·누름판.
4. 고정점(천장·벽·바닥)은 어디인가? → 기둥 둘 [440~555], [1045~1165] 과 그 위의 머리(처마 달린 윗보 [350~1265·120~320])로 된 틀, 왼쪽 기둥의 밑받침, 바닥(빗금 [1760]). 부채꼴 축(빗금 원 = 고정 축의 단면)과 피니언 축의 받침은 그리지 않았다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → **손 크랭크**: 피니언 축 [1290·1000] 에서 오른쪽으로 팔(길이 330)이 나가 끝에 둥근 손잡이 [1610·1000]. 부채꼴의 크랭크 핀은 2번에 적은 것. 추 없음.
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 부채꼴: 둥근 **바깥 둘레**에 이(곧은 두 변 — 왼쪽 세로 변과 아래 가로 변 — 에는 없다). 피니언: 바깥 둘레 온 바퀴. 피니언이 부채꼴의 **오른쪽 위 53° 방향** 바깥에서 물린다(바깥 물림).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 부채꼴 축 [800], 누름판 귀의 핀 [800], 누름판 한가운데 [807], 두 기둥의 한가운데 [802] 가 같은 세로선 — 부채꼴 축이 프레스 가운데선 바로 아래에 있다. 부채꼴 축과 크랭크 핀은 거의 같은 높이(1650·1660).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 133 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 다른 곳은 없다. 한 방향으로 계속 도는 기구가 아니라 **왔다 갔다** 하는 프레스다: 부채꼴의 이가 95° 뿐이고, 판화의 순간이 가장 낮은 자세(핀이 더 내려가면 바닥에 닿는다)라 여기서 반시계로 48° 까지 돌았다가 돌아온다(이 난 호의 끝 여유 이 1.7개). 질문 거리 없음.
- 그 밖의 선: 부채꼴 안의 굵은 선 두 덩이 = 살 셋(왼쪽 세로 살·가운데 비스듬한 살·아래 가로 살) 사이의 뚫린 창 둘. 축 둘레의 큰 원 = 허브. 누름판 [505~1110·650~710] 은 두 기둥 사이에 걸친 가로 판이고 그 밑 가운데의 Y 꼴 = 연결봉 핀을 무는 귀. 연결봉 양 끝의 작은 마디 = 눈(고리)과 봉을 잇는 목. 머리 안의 세로 음영 둘 = 기둥이 머리에 박힌 자리.

## 해석(결정 사항)
- **누르는 방향은 위**: 누름판은 기둥을 타고 오르내리고, 연결봉이 아래에서 밀어 올려 고정된 머리 아랫면에 대고 누른다. 판화 치수로 핀이 축 바로 위(90°)에 오면 누름판 윗면이 머리 아랫면에 꼭 닿는다(270 + 911 − 861 = 320 ≈ 판화의 틈 330) — 크랭크 핀과 연결봉이 곧게 펴지는 토글 자리에서 힘이 가장 크다.
- 판화의 길이 비를 그대로(1 px = 0.001646): 부채꼴 64T·모듈 0.036(피치 반지름 1.152) 가운데 이 17개, 피니언 10T(0.18), 축 사이 1.332(53° 방향), 크랭크 핀 반지름 0.444, 연결봉 1.5, 손 크랭크 팔 0.54. 판화의 순간(부채꼴 가장 낮음, 손 크랭크 3시)을 t = 1 로 맞춘다.
- 흔들림 48°: 부채꼴이 반시계로 0 ~ 48° → 크랭크 핀 −2° ~ 46° → 누름판 0.37 오름. 손 크랭크는 시계로 307°(48° × 6.4) 돌았다가 되돌아온다.
- 판화에 없는 보충: ① 누름판 위의 **누를 물건**(나무 토막, 두께 0.16 — 가장 올라갔을 때 머리와의 틈 0.013; 없으면 판이 머리에 닿지 않아 무엇을 누르는지 보이지 않는다) ② 부채꼴 축·피니언 축의 뒤판 보스 ③ 오른쪽 기둥의 밑받침(판화는 부채꼴에 가려 안 보임), 공통 받침대.

## 구동
손 크랭크(피니언 축). theta += OMEGA(1.6)·speed·dt. 부채꼴이 더 돈 각 sigma = 24°·(1 − cos(theta − 1.6)) — 3.93 s 에 한 번 왕복(내림 → 누름 → 내림).

## 동작 (모두 theta 의 닫힌 식 — `press133(theta)` 가 돌려준다)
`A = press133(theta)` → { sigma, sector, pinion, crank, pin, eyeY, rodAngle, rise }.
- 부채꼴: `sector.rotation.z = A.sector` = −5° + sigma, sigma = 24°·(1 − cos(theta − 1.6)) (0 ~ 48°, 반시계가 오름).
- 피니언: `pinion.rotation.z = A.pinion` = `meshAngle(P, 64, A.sector, Q, 10)` — 이가 맞물리는 위상, 기울기 −6.4(부채꼴과 반대 방향).
- 손 크랭크: `crank.rotation.z = A.crank` = A.pinion − (판화 자세의 피니언 각) → t = 1 에 3시, 다 올렸을 때 −307°.
- 크랭크 핀: A.pin = P + 0.444·(cos, sin)(A.sector + 3°). 누름판 핀: (−0.2, A.eyeY), eyeY = 핀.y + √(1.5² − (핀.x + 0.2)²) = 1.837 ~ 2.207.
- 연결봉: 위치 = (A.pin, ZR), `rod.rotation.z = A.rodAngle` = atan2(eyeY − 핀.y, −0.2 − 핀.x) (107.2° ~ 101.9°).
- 누름판: `platen.position.y = A.eyeY`. `A.rise` = 판화 자세에서 오른 높이(0 ~ 0.37).
- 시각: **t = 1.0 (sigma 0, 부채꼴 −5°, 손 크랭크 3시, 누름판 가장 낮음 — 판화 자세)**, **t = 1.6 (sigma 10.2°, 손 크랭크 −65.5°, 0.08 오름)**, t = 2.96 (sigma 48°, 손 크랭크 −307°, 0.37 오름 — 물건이 머리에 눌림).

① 손 크랭크 'NNN° 돌림 (한 번에 307°)' ② 부채꼴 'NN.N° (피니언의 1/6.4)' ③ 누름판 'N.NN 오름 (행정 0.37)' ④ 힘 배율 '약 NN배' = 손잡이 이동 / 누름판 이동 = 0.54·6.4 / (d eyeY / d sigma) (시작 7.9배, 가운데 7.5배, 끝 9.2배 — 핀이 축 바로 위로 갈수록 커진다).
