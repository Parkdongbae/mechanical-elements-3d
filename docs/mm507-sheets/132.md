# 132 프레스의 비스듬한 막대
원문(글자가 깨진 채 실려 있음): "This is a motion which has been used in presses to produce the necessary pressure upon the platen. Horizontal motion is given to the arm of the lever which turns the upper disk. Between the top and bottom disks are two bars which enter holes in the disks. These bars are in oblique positions, as shown in the drawing, when the press is not in operation; but when the top disk is made to rotate, the bars move toward perpendicular positions and force the lower disk down. The top disk must be firmly secured in a stationary position, except as to its revolution." — 프레스의 누름판에 필요한 압력을 내려고 쓰던 운동. 지레의 팔을 수평으로 움직여 윗 원판을 돌린다. 위·아래 원판 사이에 막대 둘이 있고 막대 끝은 원판의 구멍에 들어가 있다. 쉬고 있을 때 막대는 그림처럼 비스듬하지만, 윗 원판을 돌리면 막대가 곧게 서면서 아래 원판을 아래로 민다. 윗 원판은 도는 것 말고는 제자리에 단단히 붙들려 있어야 한다.

## 해석(결정 사항)
- **운동**: 막대 길이 L 은 변하지 않는다. 윗 원판이 아래 원판에 대해 비틀린 각 φ 일 때 막대 양 끝의 가로 어긋남 = 2·rb·sin(φ/2) (rb = 구멍 원 반지름) → 두 구멍 평면 사이 높이 H = √(L² − (2·rb·sin(φ/2))²). φ 가 줄면(막대가 서면) H 가 커지고, 윗 원판은 못 올라가므로 아래 원판·누름판이 내려간다. φ = 0(막대가 곧게 섬)에 가까울수록 같은 지레 움직임에 내려가는 거리가 작아져 힘이 커진다(토글).
- 치수: rb = 0.3, L = 0.72, φ = 110°(쉬는 자세 — 막대 기울기 43°, 판화의 약 45°) ↔ 30°(눌렀을 때). H = 0.526 ↔ 0.703, 누름판 행정 0.177.
- 막대 끝은 공(반지름 0.045)으로 하고 공 중심을 원판 면에 둔다(공이 구멍에 반쯤 묻힌 공 이음 — 막대가 기울기를 바꿀 수 있다). 공이 원판에 반쯤 묻혀 보이는 것이 정상 맞춤이다.
- 아래 구멍의 방위 35°(와 215°): 쉬는 자세에서 두 막대가 정면에서 좌우 대칭 X 로 보이는 값(90° − 110°/2). 판화처럼 앞 막대가 왼쪽 아래 → 오른쪽 위.
- 누름판 아래에 누를 물건은 두지 않는다(판화에도 없다 — 바닥 받침대와 누름판 사이가 넓게 비어 있다).
- 판화에 없는 보충: 공통 받침대뿐(틀이 받침 위에 선다).

## 구동
지레(윗 원판). theta += OMEGA(1.6)·speed·dt. 지레 각 psi = 40°·cos(theta − 1.6) — 3.93 s 에 한 번 왕복(쉼 → 누름 → 쉼).

## 동작 (모두 theta 의 닫힌 식 — `twist132(theta)` 가 돌려준다)
`A = twist132(theta)` → { psi, phi, H, drop, top[2], bot[2] }. top·bot 은 프레스 축 기준 [x, y, z](y 는 윗 원판 아랫면이 0) — 세계 좌표는 (x, YT + y, ZC + z).
- 윗 원판·지레: `head.rotation.y = A.psi` = 40°·cos(theta − 1.6). 비틀림 phi = 70° + psi (110° ↔ 30°).
- 누름판: `platen.position.y = YT − A.H`, H = √(0.72² − (0.6·sin(phi/2))²) = 0.526 ↔ 0.703. `A.drop` = 쉬는 자세에서 내려간 거리(0 ↔ 0.177).
- 막대: `aimBar132(barA, base + A.bot[0], base + A.top[0])`, `aimBar132(barB, base + A.bot[1], base + A.top[1])`, base = (0, YT, ZC). 아래 구멍은 방위 35°·215° 에 고정(높이만 −H), 위 구멍은 방위 35° + phi, 215° + phi. 방위 b 의 자리 = (0.3·cos b, · , −0.3·sin b) — rotation.y 와 같은 방향.
- 시각: **t = 1.0 (psi +40°, 비틀림 110°, H 0.526 — 판화 자세: 막대가 X 로 비스듬)**, **t = 1.6 (psi +22.9°, 비틀림 92.9°, 0.048 내려감)**, t = 2.96 (psi −40°, 비틀림 30°, 0.177 내려감 — 막대가 거의 섬).
