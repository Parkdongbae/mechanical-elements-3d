# 100 급속 귀환 크랭크(홈 지레)
원문: 급속 귀환 크랭크 운동. 형삭기(셰이핑 머신)에 쓸 수 있다.
판화: 왼쪽 아래에 빗금 친 축과 보스, 거기서 왼쪽 위로 뻗은 크랭크 팔 끝에 빗금 친 핀. 핀은 길쭉한 홈이 난 지레 안에 들어 있다. 지레는 오른쪽의 빗금 친 축(받침축, 보스 고리)에 꿰여 있고, 받침축 너머 오른쪽 아래로 둥근 막대(끝이 비스듬히 잘려 그려짐)가 이어진다. 크랭크 축 둘레에 점선 원.

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/100-fig-x4.png`(px 는 4배 확대본 기준).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없다. 부품은 **크랭크 팔 1개**(축 (545, 1030), 핀 (420, 700) — 크랭크 반지름 353 px), **홈 지레 1개**, 고정 축 2개.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥이 있는가? → 없음(크랭크 팔과 지레가 겹쳐 보일 뿐, 서로 다른 층).
4. 고정점은 어디인가? → 크랭크 축(왼쪽 아래 빗금 원)과 지레 받침축(오른쪽 빗금 원 (1210, 950)). 받침축은 크랭크 축에서 오른쪽으로 665 px, 위로 80 px(거리 670 px = 크랭크 반지름의 1.90배).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 팔이 크랭크 축에 달려 돌고(구동), 팔 끝의 핀이 지레의 긴 홈에 들어 있다.
6. 기어는? → 없음. 맞닿는 짝은 **크랭크 핀 ↔ 지레 홈의 두 벽**.
7. 한 줄에 놓인 것은? → 지레의 홈·받침축·꼬리 막대가 한 직선(판화에서 오른쪽으로 19.5° 내려감). 두 축은 같은 높이가 아니다(받침축이 조금 높다).
8. 판화에 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 받침축이 크랭크 원 **밖**에 있으므로(670 > 353) 지레는 한 바퀴 돌지 않고 ±31.6° 흔들린다(크랭크-홈 지레식 급속 귀환).
- 그 밖의 선: **점선 원**(크랭크 축 중심, 반지름 약 345 px) = 핀이 도는 길. 홈 안에 보이는 짧은 굽은 줄도 같은 원의 일부(홈 사이로 보이는 부분은 실선). 크랭크 축 둘레 두 겹 원 = 축과 보스. 받침축 둘레 두 겹 원 = 지레의 보스. 꼬리 끝의 타원 = 둥근 막대가 잘린 단면(막대는 그림 밖으로 이어져 공구대에 닿는다 — 그리지 않음).
- 층: 크랭크 팔의 두 줄이 지레 아래쪽 테를 가로질러 보이고 지레의 줄도 팔 위로 이어져 있어 앞뒤가 판화만으로는 갈리지 않는다. 모델은 **크랭크가 뒤, 지레가 앞**(핀이 앞으로 솟아 홈에 든다 — 홈과 핀이 보이는 쪽).

## 해석(결정 사항)
- 축척 1 px = 0.00164: 크랭크 반지름 0.58, 받침축 = 크랭크 축 + (1.10, 0.13) (거리 1.1077). 흔들림 반각 asin(0.58/1.1077) = 31.58°.
- 지레가 한쪽으로 가는 데 크랭크 243.2°, 돌아오는 데 116.8° → 시간 비 **2.08 : 1**(느린 쪽 = 핀이 받침축에서 먼 쪽을 도는 동안).
- 홈: 받침축에서 0.285 ~ 1.855(끝 반원 중심 0.34·1.80, 반폭 0.055). 핀은 받침축에서 0.528 ~ 1.688 사이를 미끄러진다(끝 여유 0.19·0.12).

## 구동
크랭크 축(반시계). theta += OMEGA(1.6)·speed·dt. 위상 θe = theta + 0.4 (t = 1 에서 θe = 114.6° — 핀이 왼쪽 위, 지레 −16.5°: 판화 자세(핀 110.7°, 지레 −19.5°)).

## 부품과 치수 (키트 `kit/k098.ts`, 이미 구현됨. 값은 `QUICK100` 상수)
- 크랭크(name `crank`): `crankArmPin()` 축 중심 (−0.55, 1.5), 그룹 z = 0.03(팔 면 z 0 ~ 0.06). 축 쪽 보스 반지름 0.15 → 핀 쪽 0.08 로 좁아지는 팔, 청동. 핀(name `pin100`, 키트가 붙임)은 크랭크 로컬 (0.58, 0), 반지름 0.05, z 0.05 ~ 0.21.
- 크랭크 축: `shaftZ(−0.55, 1.5, 0.09, 0.06)` — 뒤판에서 나와 크랭크 보스 앞에서 끝난다(지레 뒷면 z 0.12 보다 뒤 — 지레가 축 앞을 지나간다).
- 지레(name `lever`): `slottedLever()` 받침점 (0.55, 1.63), 그룹 z = 0.15(지레 면 z 0.12 ~ 0.18, 보스 0.105 ~ 0.195). 황동. 로컬 −x 쪽으로 길이 1.8 + 끝 반원 0.1(반폭 0.1), 홈(로컬 x −1.8 ~ −0.34, 반폭 0.055), 보스 반지름 0.15, +x 쪽 둥근 꼬리 막대(반지름 0.05, 길이 0.88, 끝에 밝은 띠).
- 받침축: `shaftZ(0.55, 1.63, 0.24, 0.05)` — 뒤판에서 나와 지레 보스를 꿴다.
- 핀이 도는 길(점선 원): 반지름 0.58 의 가는 고리(`ghost()` 재질, 굵기 0.006)를 크랭크 축 중심 z = −0.02 에 — 고정. 판화의 점선 원.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 범위(`s100.mjs`): 지레 x −1.35 ~ 1.431, y 0.436 ~ 2.477(먼 끝의 최저·최고 포함). 크랭크 x −1.21 ~ 0.11, y 0.84 ~ 2.16.

## 동작 (모두 theta 의 닫힌 식)
- `crank.rotation.z = θe` (반시계).
- `lever.rotation.z = slottedLeverAngle(θe)` = atan2(0.13 − 0.58·sin θe, 1.10 − 0.58·cos θe) (핀 → 받침축 방향이 지레 로컬 +x).
- 한 주기 = 크랭크 한 바퀴(3.93 s). 누적 없음.
- 시간표(θe): 65.2°(지레 −24.84°, 꼬리 끝이 가장 낮음) → 308.3°(지레 +38.32°, 꼬리 끝이 가장 높음)까지 **243.2° 동안 천천히**, 308.3° → 65.2°(+360°)까지 **116.8° 동안 빠르게** 돌아온다.
- 시각: t = 0.6 (θe 77.9°, 지레 −24.1°), **t = 1.0 (θe 114.6°, 지레 −16.5° — 판화)**, **t = 1.6 (θe 169.6°, 지레 +0.9°)**, t = 2.2 (θe 224.6°, 지레 +19.6°), t = 3.0 (θe 297.9°, 지레 +37.8°).

## 확인
- t=1 정면: 판화와 같은 모양 — 크랭크 팔이 왼쪽 위, 지레가 오른쪽으로 내려가고 받침축 너머 꼬리. t=1.6: 크랭크가 왼쪽, 지레가 거의 수평.
- 근접 `cam=-0.6,1.9,1.4,-0.6,1.9,0.12`(핀과 홈), 옆 `cam=3.0,1.6,0.2,0,1.6,0.1`(크랭크·지레의 층, 크랭크 축 끝이 지레 뒤에서 끝나는지).
