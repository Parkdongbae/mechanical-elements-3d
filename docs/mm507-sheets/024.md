# 024 평기어
판화: 축이 종이에 수직인 평기어(스퍼 기어) 한 쌍을 정면에서 본 모습. 왼쪽이 작고 오른쪽이 큰 두 기어가 가운데서 맞물린다. 각 기어는 이 바깥에 가는 고리선이 하나 있고, 가운데에는 축 끝의 짙은 둥근 허브가 보인다. 이 수는 판화를 세어 보면 약 28 : 34.
구동: 왼쪽 작은 기어를 돌린다(반시계). 큰 기어는 반대(시계)로 돈다. theta 는 작은 기어의 회전각.

## 부품과 치수
`spurGear`, `meshAngle`, `shaftZ`, `rotArrow`, `tag`. 모듈 0.05. 기어 중심 z = 0.12, 폭 0.16(z 0.04~0.20). 키트 추가 없음.
- `displayStand()`
- G1(구동, 작은): `spurGear(28, 0.05, { width: 0.16, spokes: 0, driver: true })` — 피치 반지름 0.70, 이끝 반지름 0.75. 중심 c1 = (−0.85, 1.75), z = 0.12.
- G2(큰): `spurGear(34, 0.05, { width: 0.16, spokes: 0 })` — 피치 반지름 0.85, 이끝 반지름 0.90. 중심 c2 = (0.70, 1.75), z = 0.12.
- 중심 거리 1.55 = 0.70 + 0.85 (피치원이 정확히 접함). 전체 폭 x −1.60 ~ 1.60, 높이 y 0.85 ~ 2.65 로 전시 영역 안.
- 축: 축 구멍이 spokes 0 일 때 민판에 뚫린다(구멍 반지름 = max(0.024, 피치반지름×0.14) → G1 0.098, G2 0.119). 축 반지름을 구멍의 0.95배로: `shaftZ(−0.85, 1.75, 0.34, 0.093)`, `shaftZ(0.70, 1.75, 0.34, 0.113)`. (끝 육각 너트가 판화의 짙은 허브처럼 보인다.)

## 동작
- 구동: `theta += OMEGA(1.6) × speed × dt`.
- G1.rotation.z = theta (반시계 +).
- G2.rotation.z = `meshAngle(c1, 28, theta, c2, 34)` (이가 이골에 정확히 물리는 위상, 방향은 반대). 속도비 dθ2/dθ1 = −28/34 = −0.8235.
- 두 기어는 모두 절대 각으로 매 프레임 설정(역회전·누적 오차 없음).

## 표시
- `rotArrow(0.55, true)` 를 G1 앞 (−0.85, 1.75, 0.30), `rotArrow(0.65, false)` 를 G2 앞 (0.70, 1.75, 0.30).
- tag(z 0.4): '구동 28'(−0.85, 0.68), '피동 34'(0.70, 0.68).
- notes: `[{ label: '잇수', value: '28 : 34' }, { label: '속도비', value: '1 : 0.82 (작은 쪽이 더 빠름)' }, { label: '회전 방향', value: '서로 반대' }]`

## 확인
- t=0.5 와 t=2.0: 두 기어의 표시점이 모두 돈다. 작은 기어는 약 0.8 → 3.2 rad(46° → 183°), 큰 기어는 반대로 0.82 배만큼 돈다.
- 맞물림 점에서 한 기어의 이 사이에 다른 기어의 이가 들어가 있고 이끼리 박히지 않는다(두 시점 모두). 비스듬한 시점 `cam=1.2,2.2,3.2,-0.07,1.75,0.12` 에서 두 기어 이의 앞뒤 끝이 맞는다.
