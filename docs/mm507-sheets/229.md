# 229 체인과 체인 풀리 3
원문(en): "Another variety." — 또 다른 종류(체인과 체인 풀리).
쉬운 풀이: 둘레에 작은 톱니 홈이 난 바퀴에, 안쪽 가장자리에 갈고리 이가 달린 판 고리 체인이 걸려 있다. 바퀴가 돌면 홈이 고리의 갈고리를 하나씩 걸어 끌어 올린다.
판화 묘사(원본 448×447 px, 정면): **바퀴**(중심 약 [244·202], 반지름 ≈ 150 px)는 거의 둥글지만 실은 **14각형**에 가깝고, 꼭짓점마다 작은 **톱니 홈**(깊이 ≈ 14 px, 한쪽이 가파름) — 홈 사이 각 25.7°(파이썬으로 판화 윤곽을 재어 26°·52°·78°·104°·128°·154° 에 홈). 가운데 두 겹 동그라미(허브). 체인은 **곧은 판 고리**들이 둥근 끝의 핀(동그라미 + 점)으로 이어진 것: 핀은 바퀴 중심에서 ≈ 157 px, 핀 사이 ≈ 69 px(= 14 고리에 한 바퀴), 12시에 핀 하나. 고리마다 **안쪽 가장자리 가운데에 뾰족한 갈고리 이**(왼쪽 늘어진 가닥에서 잘 보임)가 있어 바퀴의 홈에 들어간다. 체인은 위쪽을 감고 왼쪽은 아래 왼쪽으로, 오른쪽은 아래 오른쪽으로 비스듬히 내려가 그림 밖으로 잘림.

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.004.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 홈 바퀴(14각형 꼭짓점 반지름 0.60, 홈 14).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 체인 1개. 왼쪽 가닥(아래 끝 = 짐 추) → 바퀴 위쪽 → 오른쪽 가닥(아래 끝 = 반대쪽 추). 판화는 끝이 잘림.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 바퀴 축(뒤판에 박은 고정 축, 판화의 두 겹 동그라미).
5. 추·손잡이·크랭크는? → 판화에 없음. 보충: 양 끝 추, 바퀴 왕복.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 바퀴는 **바깥** 꼭짓점마다 오목한 홈, 체인 고리는 **안쪽** 가장자리 가운데에 갈고리 이. 고리 이가 바퀴 홈에 들어간다(고리 하나 = 홈 하나, 핀은 두 홈 사이 평평한 변 위).
7. 한 줄에 놓인 것은? → 12시 핀이 바퀴 중심 바로 위. 두 가닥은 핀 원의 9시·3시 접선(x = ±0.63)에서 세로로(기본값, 질문 1).
8. 판화의 글자가 가리키는 부품은? → 글자 없음(번호 229 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 원문은 한 줄뿐. 판화의 두 가닥은 바깥쪽으로 15 ~ 20° 벌어져 내려가는데, 끝에 추를 달면 세로가 된다 → **세로 가닥**으로(★질문 거리 1). 고리 판이 바퀴 면 위에 겹쳐 그려진 것은 **앞뒤 두 장 판**(바퀴를 사이에 끼움)으로, 갈고리 이는 두 판을 잇는 **가로 덩이**로 해석(질문 2). 이 모양으로 한 주기 내내 갈고리가 홈에 박히지 않음을 파이썬으로 검산(최소 틈 0.008).

## 해석(결정 사항)
- 마디(핀) 17개 i = −8 … 8, 고리 16개(k = −8 … 7, 마디 k ↔ k+1). 바퀴 위 마디각 2π/14 = 25.714°, 핀 원 반지름 Rp = 0.63 → 고리 길이(핀 사이) p = 2·0.63·sin(12.857°) = **0.2804**.
- 바퀴 꼭짓점(홈) = 이웃 핀 사이 가운데 각. 고리 가운데가 꼭짓점 바로 위에 오고, 고리의 갈고리 덩이가 홈에 들어간다.
- 고리: 앞판·뒷판(바퀴를 사이에 둠) + 갈고리 덩이. 이웃 고리끼리 핀 자리에서 겹치므로 **짝수 k 는 안쪽 판(z0 ± 0.060), 홀수 k 는 바깥 판(z0 ± 0.080)**.
- 짐(왼쪽)을 끌어 올리는 쪽(바퀴 시계 방향)에서 홈의 **가파른 면이 갈고리를 민다** → 홈의 가파른 면은 반시계 쪽.
- 굳은 사슬(`chainJoints229`), 바퀴 왕복 θ(t) = −(π/3)·sin(0.5t).

## 동작 (`state229(t)` — 결정적)
1. `chainJoints229(θ)`: 마디 i = −8 … 8, step = 2π/14, chord = 0.2804.

   - 바퀴 위 가장 작은 번호 lo, 큰 번호 hi. i < lo: J[i] = (−0.63, J[i+1].y − √(0.2804² − (J[i+1].x + 0.63)²)). i > hi: J[i] = (0.63, J[i−1].y − √(0.2804² − (0.63 − J[i−1].x)²)).
