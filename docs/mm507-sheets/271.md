# 271 래칫 막대 이송
원문(en): "On vibrating the lever to which the two pawls are attached, a nearly continuous rectilinear motion is given to the ratchet-bar." — 두 개의 폴이 달린 지렛대를 흔들면 래칫 막대가 거의 끊임없이 곧게 나아간다.
쉬운 풀이: 기둥 꼭대기의 지렛대에 긴 폴 둘이 지렛대 핀(받침점)의 **위와 아래**에 하나씩 달려 있다. 손잡이를 올리면 위 폴이 왼쪽으로 나가며 막대 이를 밀고 아래 폴은 이 등을 타고 오른쪽으로 물러나고, 손잡이를 내리면 그 반대 — 두 폴이 번갈아 밀어 막대가 거의 쉬지 않고 왼쪽으로 간다.
판화 묘사(원본 436×449 px, 정면): 바닥 위 긴 받침 틀 [95~345 · 245~330](아래에 발 두 개 [110~145]·[258~295]) 위에 톱니 막대 [95~300 · 240~250](이가 위로, 작은 톱니 약 20개). 막대 왼쪽은 틀 밖으로 나가 왼쪽 원 [20·280](가운데 점이 있는 롤러) 쪽으로. 오른쪽에 세로 기둥 [355~365 · 210~330]. 기둥 꼭대기에 겹원 셋이 비스듬히 [343·197]·[350·210]·[358·222] 놓인 짧은 판, 거기서 손잡이가 오른쪽 위로 [425·155]. 위 겹원에서 긴 폴이 왼쪽 아래로 내려가 [155·240] 에서 끝이 아래로 굽어 이골에 들어감, 아래 겹원에서 또 한 폴이 [235·240] 에서 굽어 들어감.

## ★ 판화 읽기
판화 하나(정면). 판화 1 px ≈ 0.0075(틀 길이 250 px ≈ 1.9 → 모형 틀 2.0). 판화 기둥 [360··] ↔ 세계 x 1.10.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 왼쪽 받침 롤러 1개(반지름 0.08). 그 밖에 바퀴 없음(래칫은 곧은 막대).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 줄 없음. 두 폴이 정면에서 비스듬히 나란하다(깊이가 달라 닿지 않음 — 위 폴 뒤층, 아래 폴 앞층).
4. 고정점은? → 받침 틀(바닥), 기둥(바닥·뒤판), 롤러 받침(바닥).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 지렛대 손잡이(기둥 꼭대기 받침점에서 오른쪽 위). 손으로 흔듦 → 시간표 φ(t). 폴 둘은 지렛대 핀에 매달려 제 무게로 막대 이 위에 얹힘.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 막대 **윗면**에 톱니(왼쪽이 선 면, 오른쪽이 비탈). 두 폴 끝(아래로 굽은 발끝)이 **위에서** 이골에 들어가 선 면을 왼쪽으로 민다.
7. 한 줄에 놓인 것은? → 막대·틀 윗면·롤러 꼭대기가 한 높이(막대 밑면 1.08). 지렛대 받침점 P 와 두 폴 핀이 한 비스듬한 선(받침점 위·아래, 120° / −60° 방향). 두 폴 끝의 발끝이 같은 이 높이에 닿음.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) 막대가 한쪽으로만 가 판을 벗어나므로 두 번 흔든 뒤 "폴을 손으로 젖히고 막대를 되돌리는" 구간을 넣었다(판화에 없음, 080 번과 같은 방식). (나) 겹원 셋 가운데 것을 받침점, 위·아래 것을 두 폴 핀으로 읽음. (다) 판화의 작은 이 약 20개를 모형은 피치 0.12·높이 0.07(이 19개)로 키움 — 폴이 이를 넘고 떨어지는 것이 보이게. 질문 거리 1, 2.

## 해석(결정 사항)
- **두 폴이 번갈아 민다**: 지렛대 각 φ 가 늘 때(손잡이 올림) 위 핀 Q1 이 왼쪽으로 가며 위 폴(폴 1)이 막대를 민다. φ 가 줄 때 아래 핀 Q2 가 왼쪽으로 가며 아래 폴(폴 2)이 민다. 한쪽이 미는 동안 다른 폴은 이 등(비탈)을 타고 오른쪽으로 물러나 이 둘을 넘는다.
- 한 번 밀 때 막대 이동 = 정확히 한 피치 0.12 가 되도록 핀 거리 e1·e2 를 풀었다 → 지렛대 한 번 왕복에 0.24, 되돌림 순간마다 물러난 폴이 바로 다음 이골에 떨어진다(헛움직임 없음).
- **이 선 면을 16.8989° 기울임**: 폴은 핀 Q 둘레로 도는 강체라 발끝이 떨어지는 길이 원호다. 선 면을 그 원호(밀기 시작 자세에서 폴 선에 수직)와 나란히 기울여야 발끝이 이골 구석까지 걸림 없이 떨어지고, 밀 때 힘이 폴 선을 따라 곧게 전해진다(폴이 들리지 않음).
- 막대가 받는 힘은 미는 동안뿐, 멈춰 있을 때는 틀 위 마찰로 선다.

## 구동
한 주기 10 초. tc = t mod 10.
- 이송(0 ≤ tc < 6, 지렛대 두 번 왕복): φ = −25°·cos(2π·tc/3). 막대 X(위 식 ↓ 동작 2).
- 되돌림(6 ≤ tc < 10, u = tc − 6): φ = −25°(멈춤). 폴 젖힘 λ(u) = ss(u/0.6)(u < 0.6), 1(0.6~3.4), ss((4 − u)/0.6)(3.4~4). 막대 X = −0.48 + 0.48·ss((u − 0.6)/2.8). ss = smoothstep(0~1 밖은 잘라냄).

## 동작 (`state271(t)` — 이송은 닫힌 식 + 발끝 1차원 찾기, 되돌림은 닫힌 식)

2. 막대 X(이송, n = floor(tc/3), τ = tc − 3n): yc = 1.21942(밀 때 발끝 중심 높이).
   x1(φ) = Q1.x − √(1.86016² − (Q1.y − yc)²), x2(φ) = Q2.x − √(1.11501² − (Q2.y − yc)²).
   τ ≤ 1.5: X = −0.24n − (x1(−25°) − x1(φ)) / 1.5 < τ < 3: X = −0.24n − 0.12 − (x2(25°) − x2(φ)). (각 반 왕복에 정확히 0.12.)
3. 폴 i 의 γ(이송): 끝 중심 c(γ) = Q − L·(cos γ, sin γ)(γ = 폴이 왼쪽 아래로 내려간 각). γ 를 2° 에서 0.25° 씩 키우며 c 가 막대 이 윤곽(세계, 막대 X 만큼 옮김 — 둘레 ±0.3 안의 선분만)에 rt 0.012 보다 가까워지는 첫 γ 를 찾고, 그 앞 0.25° 구간을 이분법 50 번 → 닿는 γ. (밀고 있는 폴은 이 방법으로 정확히 이골 구석 (선 면 + 0.0279, 1.21942) 에 놓임.)
