# 273 마름모 링크
원문(en): "Rectilinear into rectilinear motion. When the rods, A and B, are brought together, the rods, C and D, are thrust further apart, and vice versa." — 직선 운동을 직선 운동으로. 막대 A 와 B 를 서로 가까이 모으면 막대 C 와 D 가 더 멀리 밀려 벌어지고, 반대로 하면 반대가 된다.
쉬운 풀이: 같은 길이 막대 넷을 핀으로 이어 마름모를 만들고, 네 꼭짓점에 곧은 막대 A·B(가로)·C·D(세로)를 핀으로 달았다. 막대마다 고정된 안내 부시 속을 미끄러진다. A·B 를 안쪽으로 모으면 마름모가 홀쭉해져 C·D 가 위아래로 벌어진다.
판화 묘사(원본 477×445 px, **정면**): 마름모 네 막대(한 변 ≈ 159 px), 꼭짓점 핀 A [155·245]·B [348·240]·C [245·118]·D [243·370]. A 에서 왼쪽으로, B 에서 오른쪽으로 가로 막대가 나가고 각각 작은 네모 블록(안내) [100·245]·[405·240] 을 지난다. C 에서 위로, D 에서 아래로 세로 막대가 나가 안내 블록 [245·45]·[245·420] 을 지난다. 핀은 겹원(핀 머리).

## 해석(결정 사항)
- 마름모 한 변 LB = 0.70(핀 사이). 가운데 O = (0, 1.75). A = (−a, 1.75), B = (a, 1.75), C = (0, 1.75 + c), D = (0, 1.75 − c), c = √(LB² − a²).
- A·B 막대는 가로 안내 속, C·D 막대는 세로 안내 속에서만 움직인다(돌지 않음). 네 막대 끝의 눈과 마름모 두 변이 같은 핀 하나에 꿰인다.
- C·D 는 중력이 있어도 마름모(→ A·B 막대 → 안내)에 매달려 있어 떨어지지 않는다.

## 구동
반폭 a(t) = 0.46 − 0.14·cos(2πt/6) [세계 단위]. 한 주기 6 초(a 0.32 → 0.60 → 0.32). 반높이 c(t) = √(0.49 − a²) (0.6226 → 0.3606 → 0.6226).

## ★ 눈에 보여야 할 동작
