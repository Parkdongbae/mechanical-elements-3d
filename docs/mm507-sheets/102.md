# 102 볼트와 너트
원문: "Common screw bolt and nut; rectilinear motion obtained from circular motion." — 보통의 나사 볼트와 너트. **돌리는 운동에서 직선 운동**을 얻는다. (catalog 의 en 은 옆 단의 글자가 섞여 "recin tilinear … to" 로 깨져 있다 — 뜻은 위와 같다.)
판화 묘사: 세로로 선 볼트 하나. 위에 육각 머리(세 면이 보임), 그 아래로 굵은 네모 나사산이 6바퀴 반쯤 감긴 몸통, 맨 아래에 육각 너트가 끼워져 있고 너트 밑으로 볼트의 둥근 끝이 조금 나와 있다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/102-fig-x4.png` 로 다시 읽음(px 는 4배 확대본 기준).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 부품은 둘: ① 볼트(육각 머리 + 나사 몸통 + 둥근 끝, 한 몸) ② 육각 너트. 머리와 너트는 같은 크기(맞모 440px), 나사 바깥지름 280px, 골지름 200px.
2. 줄·벨트는? → 없음. 대신 나사산 한 줄: 머리 밑 (y 630) 에서 너트 (y 1340) 까지 보이는 산이 7줄, 간격(피치) 105px. 산은 두 겹 선(네모 나사산의 두께)으로 그렸다.
3. 교차하는 가닥은? → 없음. 나사산은 정면에서 **왼쪽 위 → 오른쪽 아래("\")** 로 기운다 = 세로로 세운 **왼나사**의 모습(오른나사는 정면에서 "/" 로 보인다).
4. 고정점은? → 판화에는 받침이 없다(볼트와 너트만). 오른쪽 세로선·아래 가로선은 판 테두리.
5. 추·손잡이·크랭크는? → 없음. 어느 쪽을 돌리는지도 판화·원문에 없다(모형은 볼트 머리를 돌리고 너트를 못 돌게 잡는다).
6. 이(나사산)는 어디에 났고 무엇이 물리는가? → 볼트 몸통 바깥에 수나사, 너트 구멍 안에 암나사(보이지 않음). 너트가 볼트의 맨 아래 나사산에 물려 있다.
7. 한 줄에 놓인 것은? → 머리·몸통·너트·둥근 끝이 한 세로 축. 머리와 너트의 좌우 끝이 같은 세로선(같은 크기).
8. 글자가 가리키는 부품은? → 글자 없음(번호 102 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 원문과 같고 질문할 것은 없음. 판화에는 받침이 없어서, 볼트를 제자리에서 돌게 받치는 선반과 너트가 따라 돌지 못하게 하는 레일을 보탰다(판화에 없음, 최소). 나사 방향은 원문에 말이 없으므로 판화대로 왼나사.
- 그 밖의 선: 머리·너트 안의 세로선 두 줄 = 육각의 모서리(가운데 넓은 면이 정면). 머리 위쪽 모서리의 작은 삼각 = 모따기. 너트 밑의 반달 = 볼트의 둥근 끝. 나사산 왼쪽·오른쪽 끝의 둥근 마디 = 산이 뒤로 돌아 넘어가는 곳.

## 해석(결정 사항)
- 판화 비: 머리 맞모 0.83, 나사 바깥지름 0.53, 골지름 0.38, 피치 0.20, 머리 높이 0.40, 너트 높이 0.42, 머리 밑 ~ 너트 밑 1.78, 둥근 끝 0.07.
- **볼트를 돌리고(구동) 너트는 돌지 못하게 잡는다** → 너트가 볼트를 따라 오르내린다. 볼트는 머리가 선반에 얹혀 제자리에서만 돈다.
- 너트가 나사 끝에서 빠지지 않게 **3바퀴 올라갔다가 3바퀴 내려오는 왕복**(삼각파 시간표, 누적 오차 없음). 판화 자세(너트가 맨 아래) = t = 1.
- 왼나사(`K102.leftHand = true`): 위에서 보아 반시계로 돌리면 너트가 올라온다. 오른나사로 바꾸려면 이 상수 하나만 바꾸면 된다(운동식·화살표가 따라 바뀜).
- 판화에 없음(보충): 머리 받침 선반(구멍 난 판 + 삼각 받침 둘), 너트 돌림 막이 레일(뒤판의 세로 막대). 그 밖에는 없다.

## 구동
볼트(theta 누적). theta += OMEGA(1.6)·speed·dt. 볼트 각 beta 는 theta 의 삼각파: 0 → 3바퀴(6π) → 0, 주기 12π rad = 23.56 s. 너트가 종동(직선).

배치 상수: 볼트 축 x 0, ZC = 0.3 (볼트 축의 깊이), HB = 2.65 (볼트 머리 밑면 = 선반 윗면의 높이).

## 동작 (모두 theta 의 닫힌 식 — `bolt102(theta)` 가 { a, beta, rise, dir } 를 돌려준다)
- a = `triWave(theta − 1.6, 6π)` 의 a: 0 → 6π → 0 (주기 12π). 삼각파라 여러 주기 뒤에도 어긋나지 않는다.
- beta = +a (왼나사) → `bolt.rotation.y = beta`.
- rise = `screwAdvance(0.2, beta, true)` = 0.2·beta/2π = 0 ~ 0.60 → `nut.position.y = 1.08 + rise` (너트 중심 1.08 ~ 1.68). 볼트 한 바퀴에 너트가 정확히 피치 0.20 만큼 간다.
- 나사산과 너트의 관계: 볼트가 beta 만큼 돌면 정면에 보이는 나사산 무늬가 세로로 rise 만큼 옮겨 간다 — 너트도 같은 양을 가므로 **너트에서 보면 나사산이 흐르지 않는다**(물려 있다는 뜻). 부호가 틀리면 산이 너트를 뚫고 흐르는 것처럼 보인다.
- dir = 볼트가 지금 도는 방향(+1 = rotation.y 가 느는 쪽 = 위에서 보아 반시계 = 너트가 올라가는 중, −1 = 반대).
- 시각: **t = 1 (a = 0, 판화 자세: 너트가 맨 아래, 이제 올라가기 시작)**, **t = 4 (a = 4.8 rad, rise 0.153)**, t = 12.78 (a = 6π, 맨 위 rise 0.60, 여기서 방향이 바뀜), t = 24.56 (다시 맨 아래).

## 키트 추가
이미 구현됨: `kit/k101.ts` (101·102·103 공용). 모델은 `'../kit/k101'` 에서 직접 import. `npx tsc --noEmit` 에러 0.

- `hexNut102(): THREE.Group` — 육각 너트, 원점 = 중심, `outline`
- `boltShelf102(back: number, front: number, halfW?: number): THREE.Group` — 머리 받침 선반, 원점 = 구멍 중심 윗면, `outline`
- `nutRail102(len: number, depth: number, halfW?: number): THREE.Mesh` — 돌림 막이 레일, 원점 = 뒷면 아래 가운데
- `turnArrows(r: number, axis: 'x' | 'y' | 'z'): { group: THREE.Group; set(dir: number): void }` — 방향이 바뀌는 회전 화살표 한 쌍
