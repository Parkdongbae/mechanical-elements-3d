# 030 사각 기어
판화: 가로로 나란한 **정사각형에 가까운 기어 두 개**(모서리가 둥글고 둘레 전체에 톱니). 왼쪽 것은 45° 돌려서 **마름모**(모서리가 위·아래·좌·우를 향함), 오른쪽 것은 **네모**(변이 위·아래·좌·우를 향함). 둘 다 가운데에 안쪽 둥근 네모 테두리와 축 구멍(축 단면)이 있고, 왼쪽 기어의 오른쪽 모서리가 오른쪽 기어의 왼쪽 변 가운데에 맞물려 있다. 원문: 직사각형(사각) 기어로 피동 기어가 변하는 속도로 돈다.
구동: 왼쪽 기어 1(마름모) 을 일정 속도로 돌린다 → 오른쪽 기어 2(네모)는 한 바퀴(90° 마다)에 두 번 빨라졌다 느려졌다 한다.

## 키트 추가 (gear.ts 끝에 덧붙임)
미끄럼 없이 구르는 두 **같은 4엽(사각) 비원형 기어**. 기존 시그니처는 건드리지 않는다.
```ts
export interface SquareGearSpec {
  C: number; e: number; P: number; rMax: number; rMin: number;
  L: number;         // 피치곡선 둘레
  teeth: number;     // 잇수(8 의 배수)
  pitch: number;     // L / teeth
  module: number;    // pitch / π
}
/** e 기본 3 − 2√2 (rMax/rMin = √2, 최대/최소 속도비 2) */
export function squareGearSpec(C: number, teeth: number, e?: number): SquareGearSpec;
/** 기어 몸 좌표(원점 = 회전축)에서 외곽 점열(반시계). phase 0: 피치곡선 시작점(몸 +X 방향 모서리)에 이골 가운데, 0.5: 반 피치 어긋남 */
export function squareGearOutline(spec: SquareGearSpec, phase: 0 | 0.5): V2[];
/** 로컬 Z = 회전축, 몸통 z ∈ [−width/2, width/2] */
export function squareGear(spec: SquareGearSpec, phase: 0 | 0.5, opts?: { width?: number /*0.12*/; driver?: boolean }): THREE.Group;
/** 기어 1 이 θ 돌 때 기어 2 가 피치곡선 위에서 더 구른 각 F(θ) — 아래 공식 */
export function squareGearAngle(theta: number, e?: number): number;
```
- **피치곡선**(몸 극좌표): `r(φ) = P / (1 − e·cos 4φ)`, `P = C(1 − e²)/2`. φ = 0, 90°, 180°, 270° 가 모서리(r 최대 = P/(1−e)), 45° + k·90° 가 변 가운데(r 최소 = P/(1+e)). rMax + rMin = C(어떤 두 기어든 이 합이 축 간 거리).
- `squareGearSpec`: P, rMax, rMin 위 식. L 은 φ = 0..2π 를 **4096 등분**한 점 (r cos φ, r sin φ) 들의 현 길이 합. 누적 호 길이 s[0..4096](s[0] = 0, s[4096] = L).
- `squareGearOutline(spec, phase)`: 이 i = 0..teeth−1, 아래 표의 각 (u, h) 마다 점 하나, 호 길이 위치 `ss = ((i + phase + u)·pitch) mod L` 를 s[] 에서 선형 보간해 φ 를 구하고(φ 도 선형 보간), 위치 Q = (r cos φ, r sin φ), 접선 t = (r′cos φ − r sin φ, r′sin φ + r cos φ)(r′ = dr/dφ = −4eP·sin 4φ / (1 − e cos 4φ)²), 바깥 법선 n = (t_y, −t_x)/|t|, **외곽 점 = Q + n·h·module**.
  표(u, h/module) — 이 가운데 u = 0.5, 이골 가운데 u = 0 (mod 1):
  `[[0, −1.25], [0.14, −1.25], [0.41, 1.0], [0.59, 1.0], [0.86, −1.25]]` (i 가 바뀌면 이어서 u = 1.0 ≡ 다음 이의 0). 이는 피치곡선 위 이 두께 ≈ 0.42 피치, 이끝 0.18 피치의 사다리꼴, 이끝 높이 +1.0m, 이뿌리 −1.25m.
- `squareGear`: 몸통 = `loft(outline, [circlePts(0.06, 40)], [{ z: −w/2, s: 0.985, hs: 1.2 }, { z: −w/2 + 0.008, s: 1, hs: 1 }, { z: w/2 − 0.008, s: 1, hs: 1 }, { z: w/2, s: 0.985, hs: 1.2 }])` (w = width). 안쪽 둥근 네모 테두리(판화의 안쪽 선): 피치곡선 점열 `pc = 160 점, φk = 2πk/160 의 (r cos, r sin)` 을 쓰고 `loft(pc × 0.80, [pc × 0.74], [{ z: w/2 − 0.002, s: 1, hs: 1 }, { z: w/2 + 0.012, s: 1, hs: 1 }])`(몸통과 같은 재질). 허브 `lathe(tubeProfile(0.06, 0.12, −w/2 − 0.02, w/2 + 0.025, 0.008), 32)` darkSteel `rotateX(π/2)`. 표시: paint(0xd8362f) `BoxGeometry(0.10, 0.02, 0.008)` 를 로컬 (0.30, 0, w/2 + 0.004)(몸 +X 방향 = 모서리 방향).
- `squareGearAngle(θ, e = 3 − 2√2)`: `k = (1 + e)/(1 − e)`, `w = 2θ`, `a = atan2(k·sin w, cos w)`, `n = round((w − a)/(2π))`, **`F = 0.5·(a + 2π·n)`** (연속으로 펼친 값, 홀함수).

## 동작 (theta += OMEGA × speed × dt, OMEGA = 1.6, 기어 1 구동)
- 기어 1: `g1.rotation.z = θ` (반시계). θ = 0 에서 몸 +X 의 모서리가 O2 쪽(+X)을 향한다 → 마름모.
- 기어 2: **`g2.rotation.z = 3π/4 − squareGearAngle(θ)`** (시계 방향으로, 속도가 변하며 돎). θ = 0 에서 `3π/4` → 모서리가 45°+k·90° → 네모, 변 가운데(r 최소)가 O1 쪽(−X)을 향함.
- 각속도비 `ω2/ω1 = r(φ1)/(C − r(φ1))|φ1 = θ = (1 − e²)/(1 + e² − 2e·cos 4θ)`: θ = 0 에서 √2 ≈ 1.414(기어 2 가 빠름), θ = π/4 에서 1/√2 ≈ 0.707(느림), 평균 1. 변화 주기 θ = π/2(≈ 0.98 s).
- 유도(구현자는 검산만): 접촉점은 항상 중심선 위. 기어 1 의 접촉점 몸 각 φ1 = −θ, 기어 2 의 접촉점 몸 각 φ2 = π − θ2. 미끄럼 없는 구름 ⇔ r1 + r2 = C 와 ω2/ω1 = r1/r2. r2 = C − r1 이면 dφ2/dθ = r/(C − r) = (1 − e²)/(1 + e² − 2e cos 4θ) → 적분 `F(θ) = (1/2)·arctan(k·tan 2θ)`(k = (1 + e)/(1 − e) = √2), φ2 = π/4 + F(θ) (θ = 0 에서 기어 2 쪽 접촉점이 변 가운데 φ2 = π/4), θ2 = π − φ2 = 3π/4 − F(θ). F(π/4) = π/4, F(π/2) = π/2(주기 닫힘).
- **맞물림 위상**: 기어 1 은 phase 0(θ = 0 의 접촉점, 곧 몸 +X 모서리에 이골 가운데), 기어 2 는 phase 0.5(접촉점 = 변 가운데, 이 가운데). 두 피치곡선의 호 길이 증가량이 같아(검산: σ(π/4 + F(θ)) − σ(π/4) = σ(θ), θ = 0.1…3.0 에서 1e-8 일치) 이 위상이 계속 유지된다. 잇수 40 이 8 의 배수라 변 가운데까지 호 길이 L/8 = 5p(정수 피치).
- (파이썬 shapely 로 θ ∈ [0, π/2] 181~361 구간에서 두 외곽 다각형 교차 면적 0, 최소 간격 0.0035 를 확인했다. 위 표·잇수 40·C = 1.2 기준.)
- 모든 자세는 θ 의 절대 함수.

## 검증 후 수정 (사용자 결정: 곧은 변)
사용자 결정: "30번은 판화처럼 변을 곧게 바꿔". 위의 r = P/(1 − e·cos4φ) (e = 3 − 2√2) 는 변 가운데가 뚜렷이 오목해 네 꼭짓점 별처럼 보였다. 피치곡선을 **곧은 변 4개 + 모서리 곡선 4개**로 바꿨다. 위 '키트 추가'·'동작'의 e·P 식과 C = 1.20, 속도비 0.71 ~ 1.41 은 이 절로 대체한다.

### 유도
- 같은 기어 두 개, 중심 거리 C, 접촉점은 늘 중심선 위 → 미끄럼 없는 구름 ⇔ **r1 + r2 = C**, **ds1 = ds2**(같은 호 길이), ω2/ω1 = r1/r2.
- 곧은 변: 중심에서 거리 a(= rMin). 변 가운데에서 ψ 만큼 돈 점은 r = a/cos ψ, 호 길이 s = a·tan ψ, dr/ds = sin ψ.
- 그 변과 맞물리는 맞은편 기어의 곡선(모서리) = r = **C − a/cos ψ**, 같은 호 길이 s = a·tan ψ. dφ = √(1 − (dr/ds)²)/r·ds 를 적분하면
  **G(ψ) = ∫₀^ψ a/(C cos t − a) dt = (2α/√(1−α²))·artanh( tan(ψ/2)·√((1+α)/(1−α)) )**, α = a/C (모서리 끝에서 잰 극각). 역함수 ψ = 2·atan(√((1−α)/(1+α))·tanh(φ√(1−α²)/(2α))).
- 같은 기어이므로 한 곡선이 두 역할을 다 해야 한다: 모서리 끝(s = 0)이 맞은편 변 가운데(s = L/8)와 닿을 때 **r(s) + r(L/8 − s) = C**. 변 부분(변 가운데에서 b 이내)과 모서리 부분(모서리 끝에서 b 이내)이 겹치지 않고 빈틈없이 이어지려면 b = L/16, 그 이음점에서 r = C/2 → **cos ψ0 = 2α**, b = a·tan ψ0. 이음점에서 두 식의 기울기 dr/ds = −sin ψ0 가 같아 곡선이 매끄럽게(C¹) 이어진다.
- 4겹 대칭이 닫히는 조건(모서리 끝 → 변 가운데 = π/4): **ψ0 + G(ψ0) = π/4** → **α = 0.4575552** (C 와 무관). ψ0 = 23.78°, 모서리 곡선 반쪽 극각 G0 = 21.22°.
- 결론: **완전히 곧은 변이 수학적으로 가능하다.** 변 길이 2b 와 모서리 곡선 호 길이 2b 가 같다(둘레 L = 16b). 단, 모서리 끝은 뾰족할 수 없다: 끝의 곡률 반지름 ρ = α(1−α)C = 0.248C(= 0.46·rMax). 맞은편 변 가운데(곡률 0)와 짝이기 때문이며, 같은 두 기어가 구르는 한 판화처럼 각진 모서리는 불가능하다. 그래서 판화보다 모서리가 둥근 '둥근 네모'다.
- 각도 관계(닫힌 식, 홀함수, F(θ + π/2) = F(θ) + π/2):
  |θ| ≤ G0 (기어 1 모서리 ↔ 기어 2 변): **F = ψ, θ = G(ψ)** / G0 ≤ |θ| ≤ π/4 (기어 1 변 ↔ 기어 2 모서리): **F = π/4 − G(π/4 − |θ|)**.
  `g2.rotation.z = 3π/4 − F(θ)` 는 그대로. 속도비 ω2/ω1 = F′(θ) = r1/(C − r1).
