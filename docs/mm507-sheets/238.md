# 238 탈진기
원문: "An escapement. D is the escape-wheel, and C and B the pallets. A is the axis of the pallets." — 탈진기이다. D 는 탈진 바퀴(이스케이프 휠)이고, C 와 B 는 팔레트이다. A 는 팔레트의 축이다. 쉬운 풀이: 별 모양의 바퀴가 한 칸씩만 돌도록 갈고리(팔레트)가 이를 번갈아 걸고 놓는다. 시계에서 시간을 일정하게 나누는 부분이다.
판화 묘사(원본 446×439 px, [x·y]): 위 왼쪽에 끝이 뾰족한 6 각 별 바퀴 D(축 [173·168], 끝 반지름 약 53 px, 골 반지름 약 36 px, 끝이 대략 46°·106°·166°·226°·286°·346°), 그 위에 반시계를 가리키는 굽은 화살표. 아래에 갈고리 모양 틀(팔레트 틀): 축 A [217·293](두 겹 원)를 품은 둥근 아랫부분에서, 왼쪽 팔은 위로 올라가 끝 B(윗면 [125·212] → [170·198], 별의 226° 끝이 얹힘), 오른쪽 팔은 크게 돌아 올라가 끝 C [277·128] 에서 왼쪽으로 굽고, 그 끝 [243·148] 에서 별 오른쪽([200·145])까지 **점선**이 이어진다. 틀 가운데는 위가 트인 큰 만(灣) — 별의 아래 이가 그 안에 들어온다.

## ★ 판화 읽기
판화 1 px = 0.008. D 세계 (−0.3496, 2.45), A 세계 (0, 1.4476)(A − D = (0.3496, −1.0024), 판화 [44·125] px 그대로). "A 기준" = 세계 − A.
1. 바퀴는 몇 개이고 크기 차례는? → 탈진 바퀴 D 1개(6 각 별, 끝 반지름 0.424, 골 반지름 0.288). 보충한 태엽통(반지름 0.18)은 D 뒤 같은 축.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 틀(팔레트 틀)의 판은 별 **뒤** 층, 팔레트 B·C 의 닿는 부분만 별 층까지 앞으로 솟음.
4. 고정점은? → D 축, A 축(둘 다 뒤판).
5. 추·손잡이·크랭크는? → 판화에 없음. 틀을 흔드는 **진자**(A 에서 아래로 길이 1.0, 추 반지름 0.11)와 D 를 늘 반시계로 돌리려는 **태엽통**(D 뒤)을 보충.
6. 이는 어디에, 무엇이 어느 쪽에서 무는가? → 별의 뾰족한 끝 6개. D 는 반시계로 돌려 한다. B 는 별 아래 왼쪽(232° 쪽)에서 내려오는 끝을 **윗면으로 받치고**, C 는 별 오른쪽(20° 쪽)에서 올라오는 끝을 **아랫면으로 막는다**. 틀이 반시계로 기울면 B 가 아래 왼쪽으로 빠지며 끝을 놓고 C 가 들어오고, 시계로 기울면 C 가 오른쪽으로 빠지며 놓고 B 가 들어온다.
7. 한 줄에 놓인 것은? → 판화에서 B 윗면 왼쪽 끝 [125·212] 과 별의 226° 끝이 거의 같은 높이. C 날의 아랫면은 수평.
8. 글자가 가리키는 부품은? → D = 별 바퀴, B = 왼쪽 팔 끝 팔레트, C = 오른쪽 팔 끝 팔레트, A = 틀의 축.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 있음. (가) 판화의 B 윗면은 오른쪽 끝([170·198])이 별 중심에서 0.24 까지 깊이 들어가 있어 그대로면 틀이 12° 넘게 흔들려야 끝이 빠진다 → B 의 닿는 판(팔레트 B)은 윗면 왼쪽 끝 [125·212] 에서 반지름 0.40 지점(232°)까지만 솟게 하고 나머지 판은 별 뒤 층에 둔다(겉모양은 판화 그대로). (나) 점선은 C 팔레트 날로 보고 실체로 만든다(판화의 C 팔 끝에서 별 오른쪽까지, 끝은 반지름 0.40·20° — 점선 끝보다 0.16 오른쪽). (다) 이 배치는 '되밀림(recoil)' 탈진기라, 팔레트가 끝을 잡은 뒤 진자가 더 가면 바퀴가 약 10° 뒤로 밀린다. → ★질문 거리.

## 해석(결정 사항)
- 진자 각 ψ(t) = 5°·sin(πt)(주기 2.0 초, 반시계 +), 틀·진자가 A 에서 한 몸으로 돈다.
- 바퀴는 늘 반시계로 밀리는 것으로 보고, 매 순간 **팔레트에 닿을 때까지 가장 많이 나아간 각**을 쓴다(뒤로 밀리면 밀린 만큼). 파이썬(shapely)으로 0.005 초마다 따라가 한 주기를 표로 만들었다: 한 주기에 정확히 **60°(이 하나)** 나아가고, 반 주기마다 한 번씩 '툭' 떨어진다(B 놓음 → 24.8°, C 놓음 → 28.9°).
- 팔레트 B·C 의 닿는 모서리는 반지름 0.008 둥글림, 별 끝은 반지름 0.012 둥글림 — 각져 보이지 않게.

## 구동
ψ = 5·sin(π·t)(도). 바퀴 각 φ(t) = f(t mod 2) + 60·floor(t/2)(도, 반시계 +), f 는 동작 절의 표. 별 `rotation.z = φ·π/180`, 틀 그룹 `rotation.z = ψ·π/180`.
