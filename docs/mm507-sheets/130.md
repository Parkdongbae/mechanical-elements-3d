# 130 쇠판 자르는 가위
원문(글자 인식이 깨진 곳을 바로잡음): "Shears for cutting iron plates, etc. The jaws are opened by the weight of the long arm of the upper one, and closed by the rotation of the cam." — 쇠판 따위를 자르는 가위. 위 날의 긴 팔 무게로 날이 벌어지고, 캠이 돌면서 날이 닫힌다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/130-fig-x4.png` 로 다시 읽음. px 는 4배 그림 기준.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없고 왼쪽 아래에 **둥근 원판 캠 1개**(반지름 182px). 빗금 친 작은 원(축, 반지름 28px)이 원판 중심보다 95px **위**에 있다 = 편심 캠(축이 중심에서 벗어남).
2. 줄·벨트는? → 없다. 맞닿는 짝: ㉠ 캠의 꼭대기 ↔ 위 날의 긴 팔 밑면(미끄럼 접촉), ㉡ 위 날 ↔ 받침 핀(회전 짝), ㉢ 위 날 선 ↔ 아래 날 선(스치며 엇갈림).
3. 교차하는 가닥은? → 없다. 겹침: 위 날(지레)이 받침 기둥 **앞**을 지난다(기둥의 왼쪽 세로선이 긴 팔 밑면에서 끊긴다) — 위 날과 아래 날은 가위처럼 앞뒤로 나란한 두 판.
4. 고정점은? → 빗금 친 바닥(받침) 위에 선 **기둥과 아래 날**(한 몸: 왼쪽 세로선에서 올라가 오른쪽으로 C 꼴로 휘어 나온 아래 턱). 기둥 꼭대기의 두 겹 원 = 받침 핀. 캠 축은 받침의 왼쪽 끝 바깥, 바닥 선 높이 근처에 있다(축받이는 그리지 않음).
5. 추·손잡이·크랭크는? → 없다. 위 날은 받침 핀에서 왼쪽으로 길게 뻗은 팔(핀에서 끝까지 1125px, 날 길이 650px 의 1.7배)과 오른쪽의 부리 꼴 날이 한 몸인 지레. 긴 팔 자체가 추 구실(원문: 긴 팔의 무게로 벌어진다).
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 날: 위 날의 **아랫변**(핀을 지나는 곧은 선, 수평에서 16.5° 위)과 아래 날의 **윗변**(거의 수평, 핀보다 조금 위)이 자르는 선. 판화는 벌어진 상태.
7. 한 줄에 놓인 것은? → 긴 팔 밑면이 수평(y 1222px)이고 캠 꼭대기가 그 선에 닿아 있다. 받침 윗면(y 1455px)은 수평. 원판 중심은 축 바로 아래(= 캠의 낮은 쪽이 위 → 긴 팔이 가장 낮음 → 날이 가장 벌어짐).
8. 글자가 가리키는 부품은? → 글자 없음(번호 130 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → 원문과 다른 곳은 없음. 치수 두 곳만 조정: ㉠ 판화의 편심량(95px = 원판 반지름의 0.52배)으로는 날이 12.3° 만 움직여 16.5° 벌어진 날이 다 닫히지 않는다 → 편심량을 0.64배(0.232)로 키워 15.8° 움직이게 했다. ㉡ 판화대로면 캠이 돌 때 원판이 받침의 왼쪽 위 모서리를 파고든다(판화는 가장 낮은 자세에서 겨우 닿아 있다) → 받침 왼쪽 끝을 0.46 오른쪽으로 물렸다. 기구 자체는 바뀌지 않으므로 질문 거리는 아님.
- 그 밖의 선: 왼쪽 가장자리의 짧은 가로선(y 1450px) = 바닥 선의 연장. 받침 핀의 두 겹 원 = 핀과 그 머리.

## 해석(결정 사항)
- 캠이 긴 팔을 들어 올리면(원판 중심이 축 위로) 위 날이 핀 둘레로 시계 방향으로 돌아 오른쪽 날이 내려와 닫힌다. 캠이 지나가면 긴 팔 무게로 내려앉아 벌어진다 — 긴 팔 밑면은 늘 캠 꼭대기에 얹혀 있다.
- 회전 방향은 판화·원문에 없다 → 시계 방향으로 정함(어느 쪽이든 같은 운동).
- 자를 쇠판은 그리지 않는다(판화에 없음). 캠 축의 받침은 뒤판 보스(판화에 없음).

## 구동
편심 캠(theta 누적, 시계 방향). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 한 번 자른다.

## 부품과 치수 (새 부품은 모두 `kit/k128.ts`, 이미 구현됨. 치수 상수 `K130`)
배치: 받침 핀 P = (0.46, 1.62). 뒤 층(아래 날·기둥) z 0 ~ 0.1, 앞 층(위 날·캠) z 0.1 ~ 0.2 — 두 날이 z = 0.1 면에서 스친다.
- 받침(고정, name `base`): `shearBase130(0.7)` 을 (0.46, 1.62, 0.05) 에. x −0.72 ~ 1.71, 윗면 y 0.88, 밑면 0.18(받침대 윗면에 앉음), z −0.2 ~ 0.3. 주철.
- 아래 날 + 기둥(고정, name `lower`): `shearLower130(0.1)` 을 (0.46, 1.62, 0.05) 에. 밑변(y 0.88)이 받침 윗면에 앉는다. 아래 날 선 (0.87, 1.71) → (1.77, 1.66). 주철.
- 위 날(지레, name `upper`): `shearUpper130(0.1)` 을 (0.46, 1.62, 0.15) 에. 긴 팔 끝 x −1.81, 밑면은 핀보다 0.274 아래의 곧은 선(판화 자세에서 y 1.346), 날 끝 x 1.78. 강. `upper.rotation.z = gamma`.
- 받침 핀(name `pivot`): `pivotPin130(0.26)` 을 (0.46, 1.62, 0.1) 에(z −0.03 ~ 0.23, 두 판을 꿴다).
- 편심 캠(구동, name `cam`): `eccentricCam130(0.1)` — 원판 반지름 0.364, 편심 0.232, 축 구멍 0.055. 축 자리 (−1.3, 1.214), z 0.15. 청동. `cam.rotation.z = psi`.
- 캠 축: `shaftZ(−1.3, 1.214, 0.29, 0.055)` — 뒤판 보스에서 캠 허브(z 0.08 ~ 0.22)를 지나 앞으로.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위 −1.81 ~ 1.79, 세로 0.18 ~ 2.21.

## 동작 (모두 theta 의 닫힌 식 — `shear130(theta)` 가 { psi, gamma, bladeDeg } 를 돌려준다)
- 원판 중심의 방향각 psi = −90° − (theta − 1.6) (라디안으로, 시계 방향). 원판 중심 C = 축 + 0.232·(cos psi, sin psi).
- 위 날의 각: D = C − P 라 할 때 gamma = atan2(D.y, D.x) − 180° − asin((0.274 + 0.364)/|D|) — 긴 팔 밑면(핀에서 0.274 떨어진 곧은 선)이 원판에 접하는 조건. `leverAngle130(psi)`.
- 범위: gamma 0°(psi = −90°, 벌어짐) ~ −15.8°(닫힘). 윗날 선의 각 bladeDeg = 16.5 + gamma(도): 16.5 → 0.7. 아래 날 선(핀 위 0.09 ~ 0.04)과는 목 쪽에서 12°, 끝에서 1.8° 에 엇갈린다 — 목에서 끝으로 차례로 잘린다.
- 맞닿는 자리는 긴 팔 밑면 위를 x −1.94 ~ −1.44(팔 좌표)로 오간다 — 곧은 밑면(−2.22 ~ 0.09) 안.
- 시각: **t = 1.0 (psi −90°, gamma 0 — 판화 자세, 벌어짐)**, **t = 2.96 (psi −270°, gamma −15.5° — 닫힘, 긴 팔이 가장 높음)**, t = 2.0 (gamma −7.0°, 닫히는 중), t = 4.0 (gamma −8.1°, 벌어지는 중).

## notes
① 지금 '닫히는 중 / 벌어지는 중'(gamma 가 줄어드는지 늘어나는지 — psi 를 접어 −90° → −270° 구간이면 닫히는 중) ② 날 벌어진 각 'NN° (16.5° ~ 0.7°)'(bladeDeg) ③ '긴 팔 : 날 = 약 1.7 : 1 — 긴 팔 무게로 벌어진다' ④ 캠 회전수.
