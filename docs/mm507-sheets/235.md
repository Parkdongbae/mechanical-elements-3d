# 235 태핏 팔 래칫
원문(en): "The oscillation of the tappet-arm produces an intermittent rotary motion of the ratchet-wheel. The small spring at the bottom of the tappet-arm keeps the tappet in the position shown in the drawing as the arm rises, yet allows it to pass the teeth on the return motion." — 태핏 팔의 진동이 래칫 바퀴에 간헐 회전 운동을 만든다. 태핏 팔 아래쪽의 작은 스프링은 팔이 올라갈 때 태핏을 그림에 나타난 위치에 있게 하면서도, 돌아올 때는 태핏이 이 위를 지나가게 해 준다.
쉬운 풀이: 팔이 올라갈 때는 작은 돌기(태핏)가 이를 밀어 바퀴를 한 칸 돌리고, 내려올 때는 스프링 덕분에 돌기가 접히며 이를 타 넘어 돌아온다.
판화 묘사(원본 446×454 px, [x·y]): 왼쪽 위에 **별 모양 바퀴**(뾰족한 대칭 이 6개, 축 구멍 [134·204], 이끝 반지름 약 63 px, 이뿌리 약 40 px). 그 왼쪽 위에 **갈고리 모양 조각**(꼭대기 둥근 눈 [127·136] 에 핀, 꼬리가 바퀴 왼쪽으로 휘어 내려와 끝이 이골에 [102·210]). 오른쪽 아래에 가로로 긴 **태핏 팔**: 오른쪽 끝 핀 [383·290](받침), 왼쪽으로 뻗어 [267·286] 에 핀이 하나 더, 그 핀에 걸린 **태핏**(갈고리 턱 모양)이 왼쪽으로 나가 끝 [160·258] 이 바퀴 오른쪽 아래 이의 아랫면에 닿음. 팔 밑에 **작은 스프링**(곱슬한 판) [270·323]이 태핏 꼬리를 받침. 점선 원호 둘: 태핏 끝이 지나는 길(팔 받침점 둘레, 반지름 약 225 px)이 바퀴 오른쪽을 아래에서 위로 가로지른다.

## 다섯 장 공통 폴·이 규칙 (225·232·235·236·237 같음)
- 폴(태핏·멈춤 폴 포함) **코 끝은 원 반지름 rn = 0.014**, 코와 몸이 만나는 **오목 목은 필릿 0.02**, 나머지 볼록 모서리 0.006 — 아래 점열에 이미 들어 있다(155 "폴 닿는 곳이 각져 보임" 방지). 점열을 고치거나 다시 그리지 말 것.
- **톱날 이(225·236·237)**: 곧은 면이 반지름선에서 **20° 갈고리꼴**. 판화가 대칭 이를 그린 232(네모 이)·**235(별 이)** 는 판화를 따른다 — 235 는 태핏이 이 아랫면을 밑에서 밀어 올리는 구조라 갈고리 면이 필요 없다.
- 침범 판정: 코 원 중심이 바퀴 윤곽 안이거나 윤곽까지 거리 < rn − 0.0002 이면 침범(태핏). **멈춤 폴만 rn + 0.0003**(늘 0.0003 띄움).
- 색: **거는 폴(밀고 있는 태핏) = emissive 0x7a4a00(주황빛), 쉬는 것 = 0x000000** — 재질은 부품마다 따로.
- 재질: 바퀴는 `steel()`(밝음 — 이가 보이게, 검은 재질 금지), 태핏·멈춤 폴은 `brass()`, 팔은 `castIron()`, 스프링은 `steel()`.

## 해석(결정 사항)
- 팔이 올라갈 때(u 0 ~ π) 태핏은 멈춤 핀에 기대 팔과 한 몸 — 바퀴 이의 아랫면(시계 쪽 옆면)을 밀어 바퀴를 반시계로 돌리고, 코가 이끝을 지나면 놓는다. 놓는 자리가 늘 같아 **한 번에 정확히 60°(1이)** 씩 스스로 맞춰진다(바퀴 쉬는 각: 이끝이 17.0878° + 60k).
- 팔이 내려올 때(u π ~ 2π) 태핏 코가 다음 이의 윗면에 닿아 **접히고**(태핏 핀 둘레로 코가 위로, 최대 21.4°), 이끝을 지나면 스프링이 **툭** 되돌린다(u 320.75°). 그동안 바퀴는 접힌 태핏에 눌려 시계로 밀리지만 **멈춤 폴이 막아** 서 있다.
- 멈춤 폴은 제 무게로 바퀴 왼쪽 이골에 얹혀, 바퀴가 반시계로 돌 때 이를 타 넘고(최대 17.9° 들림) 다음 이골로 떨어진다.
- 판화에 없는 보충: 크랭크 원판·크랭크 축·연결봉(팔 뒤), 팔의 턱(멈춤 핀 받이), 스프링 받침 덩이.

## 구동
`theta += OMEGA * speed * dt`(크랭크 각, OMEGA 1.6 rad/s, 한 주기 3.92699 s). 바퀴 각은 닫힌 식, 태핏 접힘·멈춤 폴 들림은 적재 때 만든 표.

## 동작 (`state235(theta)`)
1. u = theta mod 2π, n = floor(theta/2π). 크랭크 핀 P = K + rk·(cos(thF + u), sin(thF + u)).
2. 팔 연결봉 핀 E = `circleIntersect([1.292, 1.199], 0.55, [P.x, P.y], 0.702483, false)`, ζ = atan2(E.y − 1.199, E.x − 1.292) 를 0 ~ 360° 로. (u = 0 → 181.0383°(아래 끝), u = π → 148.8471°(위 끝), 정확히.)
3. 접히지 않은 태핏 코 N = A + R(ζ)·(Pt + Lt·(cos lt0, sin lt0)) = A + 1.870060·(cos ζ, sin ζ).
4. **바퀴(닫힌 식)**: 주기 시작 바퀴 각 RHO0 = 77.0878°(이 0 이끝 방위). 밀리는 이 = 이끝 세계 방위 RHO0 − 120°(= −42.91°)인 이. 밀린 양 δ(N): v = N − W, rv = |v|, av = atan2(v).
   - (가) 옆면: 그 이의 시계 쪽 옆면(이끝 → 시계 쪽 이뿌리)은 이 0 기준 로컬에서 바깥 법선 각 −54.6704°, 원점 거리 dl = 0.318053. ph = av + 54.6704° ∓ acos((dl + 0.014)/rv). 법선 발이 옆면 선분 안에 들 때만.
   - (나) 이끝 꼭짓점: |rv² + 0.55² − 0.014²|/(2·rv·0.55) ≤ 1 이면 ph = av ∓ acos((rv² + 0.3025 − 0.000196)/(1.1·rv)).
   - δ = ph − (RHO0 − 120°)(−180°~180°), 유효 후보 가운데 가장 큰 값(|δ| < 70° 만).
   - u < π: φrel(u) = max(0, u 까지의 δ 최댓값)(올라가는 동안 줄지 않음 — 적재 때 1440 걸음으로 표를 만들거나 매번 0 ~ u 를 0.25° 걸음으로 훑음). u ≥ π: φrel = 60°.
   - `wheel.rotation.z = RHO0 + n·60° + φrel`. 밂(구동) = u < π 이고 φrel 이 그 시각에 늘고 있음(대략 u 85.0° ~ 153.25°).

(같은 식: 다음 이 윗면 직선까지 거리 = rn 또는 이끝 꼭짓점 원 교차의 해 중 f 가 가장 작은 것.)
