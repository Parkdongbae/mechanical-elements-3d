# 025 베벨기어
판화: 원뿔 모양 기어 두 개가 직각으로 만난다. 위쪽 기어는 수평으로 놓여 축이 위로 곧게 솟고(축에 깃(칼라)이 보임), 왼쪽 기어는 수직으로 서서 축이 왼쪽으로 뻗는다. 두 기어는 같은 크기(마이터 기어)이며 이가 왼쪽 위 모서리에서 맞물린다. 정면에서 보면 위 기어와 왼쪽 기어가 각각 얇은 띠로 보이는 것이 판화와 같다.
구동: 위 기어(수직 축)를 돌린다. theta 는 위 기어의 회전각. 속도비 1 : 1.

## 부품과 치수
`bevelGear`(007 에서 추가, 키트에 있음), `rod`, `rotArrow`, `tag`, 재질 `steel`·`darkSteel`·`paint`(`../../models/materials`). 키트 추가 없음.
`bevelGear(20, 0.038, { width: 0.24, spokes: 0, driver: true })`(A)와 `bevelGear(20, 0.038, { width: 0.24, spokes: 0 })`(B): 피치 반지름 R = 20×0.038/2 = 0.38, 이끝 반지름 0.414, 뿌리 반지름 0.346, 뒷판 두께 0.168. 기어 안쪽 구멍 반지름 0.0532.
- **맞물림 꼭짓점** O = (0.30, 1.35, 0.18). 두 기어의 축이 만나는 점이고, 그 z 면은 0.18(뒤판에서 0.48 떨어짐). 위 기어 이끝 지름이 z 에서 0.18 ± 0.414 = −0.234 ~ 0.594 로 전시 영역(z −0.25~0.6) 안에 든다.
- **A (위, 축 = 세로 Y)**: 피치원 중심 (0.30, 1.73, 0.18), 이가 아래(−Y)를 향해 O 에서 만난다. 배치: 피벗 그룹 `pivA.position = (0.30, 1.73, 0.18)`, `pivA.rotation.x = +π/2` (로컬 +Z → 세계 −Y). 이 안에 회전 그룹 `spinA`(= 기어 + 축)를 두고 `spinA.rotation.z` 만 돌린다.
- **B (왼쪽, 축 = 가로 X)**: 피치원 중심 (−0.08, 1.35, 0.18), 이가 오른쪽(+X)을 향해 O 에서 만난다. 배치: `pivB.position = (−0.08, 1.35, 0.18)`, `pivB.rotation.y = +π/2` (로컬 +Z → 세계 +X). 이 안에 `spinB`(= 기어 + 축).
- 축(기어와 함께 도는 부품, 각 spin 그룹의 자식, 기어 로컬 좌표): `CylinderGeometry(0.045, 0.045, 0.6, 24)` 를 로컬 Z 방향(`rotateX(π/2)`)으로 눕혀 `steel` 재질. 중심을 로컬 z = −0.45 에 둔다(기어 뒷면 쪽으로 −0.15 ~ −0.75 구간. A 에서는 위로, B 에서는 왼쪽으로 뻗음). 회전이 보이도록 축에 밝은 키 `BoxGeometry(0.03, 0.03, 0.12)`(`paint(0xf2b619)`)를 로컬 (0.05, 0, −0.65) 에 붙인다. 판화의 칼라: 로컬 z = −0.30 에 `darkSteel` 짧은 원통(반지름 0.075, 길이 0.04)을 하나씩.
- 축 받침(고정, 회전하지 않음):
  - A 쪽: 세계 (0.30, 2.18, 0.18) 에 `darkSteel` 원통 베어링(반지름 0.085, 길이 0.12, 축 Y). 뒤판까지 `rod(new Vector3(0.30, 2.18, 0.10), new Vector3(0.30, 2.18, −0.28), 0.04)`.
  - B 쪽: (−0.53, 1.35, 0.18) 에 같은 베어링(축 X). `rod(new Vector3(−0.53, 1.35, 0.10), new Vector3(−0.53, 1.35, −0.28), 0.04)`.
- 전체: x −0.83 ~ 0.71, y 1.0 ~ 2.48 (전시 영역 안). 세계 좌표로 A 축은 y 1.88 ~ 2.48, B 축은 x −0.23 ~ −0.83.

## 동작
- 구동: `theta += OMEGA(1.6) × speed × dt`. 세계 기준 회전각 φ = theta.
- 마이터 베벨의 구름 조건에서 A(+Y 축으로 φ, 반시계로 위에서 봄)이면 B 는 **+X 축으로 같은 φ** (세계 각속도 벡터 ω_A = (0, φ', 0), ω_B = (φ', 0, 0) — ω_A − ω_B 가 접촉선 (−1, 1, 0)/√2 와 평행). 크기는 같고 속도비 1 : 1.
- 각 spin 그룹의 로컬 Z 회전은 축 방향에 맞게 부호를 바꾼다(위 기어는 로컬 Z 가 세계 −Y, 왼쪽 기어는 +X):
  - `spinA.rotation.z = −φ`
  - `spinB.rotation.z = +φ + π/20` (맞물림 위상: 접점이 A 의 로컬 각 π(= 이의 중심), B 의 로컬 각 π/2(= 이의 중심, 잇수가 4 의 배수)에 오므로 B 를 반 피치 π/20 어긋나게 해 이 ‑ 이골이 마주 물리게 한다)
- 모두 절대 각, 매 프레임 재계산.

## 표시
- `rotArrow(0.3, true)` 를 A 축 위 (0.30, 2.58, 0.18) 에 놓고 `rotation.x = −π/2` 로 눕힌다(로컬 Z → +Y, 위에서 보아 반시계). `rotArrow(0.3, true)` 를 B 축 왼쪽 (−0.95, 1.35, 0.18) 에 `rotation.y = +π/2` 로 세운다(로컬 Z → +X, 오른쪽에서 보아 반시계).
- tag(z 0.4): '구동 베벨 A'(1.05, 2.00), '베벨 B'(−0.95, 1.00), '수직 축'(0.9, 2.45), '가로 축'(−0.60, 1.70), '맞물림'(0.55, 1.15).
- notes: `[{ label: '속도비', value: '1 : 1 (마이터)' }, { label: '축 사이 각도', value: '90°' }, { label: '회전 방향', value: '위에서 보아 반시계 ↔ 오른쪽에서 보아 반시계' }]`
- view: `{ pos: [2.6, 3.0, 3.6], target: [0.2, 1.6, 0.18] }` (기본 정면은 두 기어가 얇은 띠로만 보이므로 위·오른쪽에서 비스듬히).

## 확인
- t=0.5 와 t=2.0: 두 기어 이가 맞물린 채 모든 이와 축 키가 돈다. A 의 키는 수평으로, B 의 키는 수직 평면(YZ)으로 돈다.
- 비스듬히 `cam=-1.6,2.2,1.6,0.3,1.35,0.18` 에서 접점 (−0.08, 1.73, 0.18) 근처로 A 의 이와 B 의 이가 서로 이골에 들어가 있고 박히지 않는다(두 시점 모두). 두 화살표는 각 축 끝에서 보아 반시계이고, 실제 기어 회전과 같은 방향인지 확인한다.
- 정면 기본 시점: 위쪽 가로 띠(A)와 왼쪽 세로 띠(B)가 판화의 ㄱ자 구도로 보인다.
