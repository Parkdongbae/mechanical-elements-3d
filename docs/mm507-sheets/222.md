# 222 편심 중심 기어
원문(en): "If for the eccentric wheel described in the last figure an ordinary spur-gear moving on an eccentric center of motion be substituted, a simple link connecting the center of the wheel with that of the pinion with which it gears will maintain proper pitching of teeth in a more simple manner than the groove." — 앞 그림(221)의 타원 바퀴 대신, 중심에서 벗어난 축으로 도는 보통 평기어를 쓰면, 그 바퀴의 중심과 맞물린 피니언의 중심을 잇는 링크 하나가 홈보다 간단하게 알맞은 맞물림을 지켜 준다.
쉬운 풀이: 앞 장치의 타원 기어를 중심이 어긋난 보통 기어로 바꾸었다. 홈 대신 두 기어의 중심을 막대(링크)로 이으면 이가 늘 알맞게 맞물린다.
판화 묘사(원본 470×516 px, [x·y]): 왼쪽 위 평기어(중심 [158·165], 이끝 약 86 px), 오른쪽 위 작은 평기어(중심 [300·178], 이끝 약 67 px), 오른쪽 아래 평기어(기어 원의 중심 [318·318], 이끝 약 86 px). 아래 기어 안에 빈 원(축 자리) [285·316] — 기어 중심에서 왼쪽으로 33 px 벗어난 **편심 축**. 막대 둘: 왼쪽 위 기어 중심 → 작은 기어 중심(팔), 작은 기어 중심 → 아래 기어의 **기어 중심** [318·318](링크). 아래 기어 둘레에 점선 큰 원(중심 ≈ 편심 축, 반지름 약 112 px) — 아래 기어가 편심 축으로 돌며 쓸고 지나가는 자리. 작은 기어는 왼쪽 위 기어와 아래 기어 둘 다와 물려 있다. 글자 없음.

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.0075.
1. 바퀴는 몇 개이고 크기 차례는? → 3개. 바퀴 A(왼쪽 위, 이 24, 피치 반지름 0.60) = 구동 기어 C(오른쪽 아래, 이 24, 0.60) > 피니언 B(오른쪽 위, 이 18, 0.45).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점(천장·벽·바닥)은? → 바퀴 A 의 축(뒤판), 구동 기어 C 의 편심 축 D(뒤판). 피니언 B 의 축은 고정이 아님(두 막대 끝).
5. 추·손잡이·크랭크는? → 판화에 없음. 앞 그림(221)처럼 편심 기어 C 가 구동(일정하게 돎), A 가 출력.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 모두 바깥 이. 피니언 B 가 A 의 오른쪽과, C 의 위쪽과 물림(한 피니언이 두 기어에).
7. 한 줄에 놓인 것은? → 팔 = A 중심 ↔ B 중심(길이 0.60 + 0.45 = 1.05 일정), 링크 = B 중심 ↔ C 의 기어 중심(길이 0.45 + 0.60 = 1.05 일정). C 의 기어 중심과 편심 축 D 는 거리 0.25.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 222 뿐). 이름표는 원문 낱말로.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문과 판화는 일치. 다만 판화 자리 그대로면 C 의 중심이 A 쪽으로 가장 가까워질 때(A–C 중심 164 px) A 와 C 의 이끝(합 172 px)이 부딪힌다 → **편심 축 D 를 A 에서 1.62 떨어뜨렸다**(판화 1.48). 방향(A 에서 오른쪽 아래 −49.9°)은 판화 그대로. 질문 거리 없음.

## 해석(결정 사항)
- 구동 기어 C 는 보통 평기어. 그 기어 중심 Cc 가 편심 축 D 둘레를 반지름 e = 0.25 로 돈다(기어 몸이 통째로 D 둘레로 돎).
- 피니언 B 의 중심은 두 원의 교점: A 중심에서 1.05, Cc 에서 1.05. 그래서 B 는 늘 A 와 C 둘 다에 알맞은 깊이로 물린다(링크가 홈을 대신함).
- 각은 모두 "물림 위상 식"으로 매 순간 계산 — 막대가 흔들려도 이가 정확히 맞는다. 결과: C 가 일정하게 돌 때 A 는 C 의 **0.338 ~ 1.662 배** 빠르기로 오르내린다(C 한 바퀴에 A 정확히 한 바퀴).
- 층(앞 → 뒤): 링크(z 0.20~0.24) / 팔(z 0.15~0.19) / 기어 셋(z 0~0.10).
- 판화에 없는 보충: 축 A·D 의 뒤판 축, B 의 축 핀, C 의 중심 핀, A 의 빨간 표시 막대.

## 동작 (`update` 안에서 매 프레임 — 결정적)
1. θC = 0.4·t. Cc = (0.45 + 0.25·cos θC, 1.15 + 0.25·sin θC).
2. B = `circleIntersect([Ax, Ay], 1.05, [Ccx, Ccy], 1.05, true)`(A→Cc 기준 왼쪽 = 오른쪽 위 해). null 이 나올 일 없음(A–Cc 1.37 ~ 1.87 < 2.10).
3. 물림 위상 함수(직접 쓴다 — 키트 `meshAngle` 은 atan2 가 ±180° 를 지날 때 튐):
   `mesh2(c1, z1, th1, c2, z2)`: a = atan2(c2y − c1y, c2x − c1x), a < 0 이면 a += 2π. s1 = 2π/z1, s2 = 2π/z2. 반환 a + π − s2 − (s2/s1)·(th1 + s1/2 − a).
4. ψB = mesh2(Cc, 24, θC, B, 18). ψA = mesh2(B, 18, ψB, A, 24). (B→A 방향 a 는 155.0° ~ 183.3° 로 180° 를 지나므로 [0, 2π) 가 꼭 필요. Cc→B 는 76.9° ~ 105.2°.)
5. α = atan2(By − Ay, Bx − Ax), γ = atan2(By − Ccy, Bx − Ccx).
6. 적용: `gearC.position = (Ccx, Ccy, 0.05)`, `gearC.rotation.z = θC`, `pinionB.position = (Bx, By, 0.05)`, `pinionB.rotation.z = ψB`, `wheelA.rotation.z = ψA`, `arm.rotation.z = α`, `link.position = (Ccx, Ccy, 0.22)`, `link.rotation.z = γ`, B 축 핀 위치 (Bx, By).
