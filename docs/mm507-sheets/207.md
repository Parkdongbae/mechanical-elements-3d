# 207 웜 두 개로 구동
원문: "A modification of 195 by means of two worms and worm-wheels." — 195 의 변형으로, 웜 두 개와 웜 휠 두 개를 쓴다. 쉬운 풀이: 한 축에 웜 두 개를 달아 두 웜 휠을 돌린다. 195 처럼 한 축으로 두 바퀴를 한꺼번에 돌릴 수 있다.
판화 묘사(원본 479×456 px, [x·y]): 가로로 놓인 긴 축 하나 [50~460·320~370](약간 기울어짐). 그 위에 같은 크기의 웜 휠 두 개가 나란히(왼쪽 중심 [148·255], 오른쪽 [370·250], 바깥 반지름 약 78 px, 아래쪽 절반에만 이가 그려지고 위는 테 두 겹). 각 휠 바로 아래 축에 웜(나사산 3줄)이 하나씩: 왼쪽 웜 [145~190] 의 산은 "\"(위가 왼쪽), 오른쪽 웜 [345~385] 의 산은 "/"(위가 오른쪽) — 서로 반대 나사. 왼쪽 휠 화살표는 허브 오른쪽에서 아래로(시계), 오른쪽 휠 화살표는 허브 왼쪽에서 아래로(반시계). 축 가운데 회전 표시 화살표.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0085.
1. 바퀴는? → 웜 휠 2개(같은 크기, 나란히), 웜 2개(같은 크기, 한 축). 웜 휠 ≫ 웜.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 두 휠은 서로 떨어져 있다(이끝 사이 약 65 px).
4. 고정점은? → 두 휠 축(허브의 짙은 원), 웜 축의 받침(그림에 없음 — 보충).
5. 추·손잡이·크랭크는? → 판화에 없음. 구동 = 웜 축(195 와 같음).
6. 기어는? → 웜 휠 둘 다 바깥 이, 각 휠의 **아랫면**에서 그 아래 웜에 물림. 왼쪽 웜 = 오른나사("\"), 오른쪽 웜 = 왼나사("/").
7. 한 줄에 놓인 것은? → 두 휠 중심이 같은 높이(y 250~255 px), 두 웜이 같은 축 위, 각 웜이 제 휠 바로 아래 같은 세로선(x 148, 370 px).
8. 글자가 가리키는 부품은? → 글자 없음(번호 207 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 반대 나사 두 웜이 같은 축으로 돌아 두 휠이 같은 빠르기로 **서로 반대로** 돈다(판화 화살표와 같음). 195 의 이송 롤러(앞 층)를 붙일지는 판화·원문에 없어 ★질문 거리로 둔다(기본: 붙이지 않음).

## 해석(결정 사항)
- 195 와 다른 점: 195 는 웜 **하나**가 위·아래 휠 사이에 있어 두 휠이 반대로 돈다. 207 은 웜 **둘**(반대 나사)이 한 축에 있고 두 휠이 **나란히 위**에 있다. 두 휠은 거울처럼 반대로 돈다 — 마주 보는 안쪽 가장자리(왼쪽 휠의 오른쪽, 오른쪽 휠의 왼쪽)가 둘 다 아래로 움직인다.
- 판화에 없는 보충: 웜 축 받침 셋(양 끝·가운데), 휠 축.

## 구동
웜 축 각 θ, θ += 4.8·speed·dt (= OMEGA·3, 195 와 같음). 축은 x 축으로 rotation.x = θ (θ 증가 → 정면에서 축 앞면이 아래로 감).

## 부품과 치수 (키트 추가 없음 — 195 와 같은 `wormScrew`·`wormWheel`·`shaftZ`·`wallBearing`)
- 모듈 MOD 0.044, 휠 잇수 NW 28 → 휠 피치 반지름 RW = 28·0.044/2 = 0.616. 웜 피치 반지름 RWP 0.15, 웜 리드 = π·0.044 = 0.1382, 리드각 탄젠트 TANLEAD = 0.1382/(2π·0.15) = 0.1467.
- 축 높이 YS 1.40, 축·휠 가운데 z ZW 0.10. 휠 중심 높이 YC = 1.40 + 0.15 + 0.616 = 2.166, 휠 x = ∓0.95(XW 0.95).
- 왼쪽 웜(name `wormL`): `wormScrew(0.095, 0.194, 0.1382, 0.55, { driver: true })` (오른나사), 위치 (−0.95, 1.40, 0.10), rotation.x = θ.
- 오른쪽 웜(name `wormR`): `wormScrew(0.095, 0.194, 0.1382, 0.55, { driver: true, leftHand: true })` (왼나사), 위치 (0.95, 1.40, 0.10), rotation.x = θ.
- 웜 축(name `shaft`): `rod(v(-1.75, 1.40, 0.10), v(1.75, 1.40, 0.10), 0.06)`, rotation.x 표시는 노란 줄(축 위 길이 3.3, 폭 0.012)로 — 축 그룹에 넣고 rotation.x = θ.
- 왼쪽 휠(name `wheelL`): `wormWheel(28, 0.044, { width: 0.14, spokes: 6, tanLead: 0.1467 })`, 중심 (−0.95, 2.166, 0.10), rotation.z = −θ/28 − π/2. 노란 표지 막대(로컬 −X 쪽 반지름 0.12~0.45, 폭 0.04, z 0.172) — t = 0 에 위를 가리킴.
- 오른쪽 휠(name `wheelR`): `wormWheel(28, 0.044, { width: 0.14, spokes: 6, tanLead: -0.1467 })`, 중심 (0.95, 2.166, 0.10), rotation.z = θ/28 − π/2. 같은 노란 표지.
- 휠 축: `shaftZ(-0.95, 2.166, 0.25, 0.045)`, `shaftZ(0.95, 2.166, 0.25, 0.045)` (고정, 휠이 헐겁게 — 회전 없음).
- 웜 축 받침(name `bearingL`·`bearingM`·`bearingR`): `wallBearing(-1.55, 1.40, 0.10, 'x', 0.066)`, `wallBearing(0, 1.40, 0.10, 'x', 0.066)`, `wallBearing(1.55, 1.40, 0.10, 'x', 0.066)`. 가운데 받침은 두 웜 안쪽 끝(x ±0.675) 사이.
- 위상 근거: 195 의 위 휠(웜이 아래, 왼나사)이 rotation.z = θ/NW − π/2 → 오른쪽 휠 그대로. 왼쪽은 그 거울(x → −x): 각 a → π − a 이므로 −θ/28 − π/2, 오른나사·tanLead 부호 반대.

## 동작
θ 하나로 모두: wormL.rotation.x = wormR.rotation.x = shaft.rotation.x = θ, wheelL.rotation.z = −θ/28 − π/2(시계), wheelR.rotation.z = θ/28 − π/2(반시계). 웜 28바퀴에 휠 각 1바퀴. 휠 각속도 4.8/28 = 0.171 rad/s(한 바퀴 36.7 초). 수치: t = 30 → θ 144 rad, 휠 각 변화 ∓5.14 rad.
