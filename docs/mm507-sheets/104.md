# 104 웜(나사)과 미끄럼대 위의 톱니바퀴
원문: "In this, rotary motion is imparted to the wheel by the rotation of the screw, or rectilinear motion of the slide by the rotation of the wheel. Used in screw-cutting and slide-lathes." — ① 나사를 돌리면 바퀴가 돈다. ② **또는** 바퀴를 돌리면 미끄럼대(슬라이드)가 곧게 간다. 나사 절삭 선반·슬라이드 선반에 쓴다.
(catalog 의 ko·easy 는 ① 만 적었다. 판화에는 ② 의 미끄럼대가 분명히 그려져 있으므로 둘 다 보여 준다.)

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/104-fig-x4.png`·`104-fig-x4c.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 톱니바퀴 1개(살 없는 민판, 네모진 이가 20개쯤 — 손 판화라 간격이 고르지 않다. 20개로 만든다). 그 위에 가로로 긴 나사(웜) 1개. 판화 치수(4배 px): 바퀴 바깥 지름 620, 나사 바깥 지름 약 190, 나사 길이 1260(바퀴 지름의 2.0배), 나사산 12개.
2. 줄·벨트는? → 없음. 맞물리는 짝은 **나사산 ↔ 바퀴 맨 위의 이** 하나뿐(나사가 바퀴 위에 얹혀 맨 위의 이 2~3개가 나사 골에 든다).
3. 교차하는 가닥은? → 없음. 겹침 차례: 브래킷(받침 기둥)이 바퀴 **앞**에 있다(브래킷 선이 끊기지 않고 바퀴의 이·원이 브래킷에서 끊긴다). 나사와 바퀴는 같은 깊이에서 물린다.
4. 고정점은? → 맨 아래의 가로 막대(양 끝이 톱니 모양 파단선 = 더 길게 이어지는 베드). 나사의 축받이는 그리지 않았다(왼쪽 끝은 잘렸고 오른쪽 끝은 둥글게 끝남). 나사는 제자리에서 돌기만 한다.
5. 추·손잡이·크랭크는? → 없음. 구동 손잡이는 그리지 않았다(원문: 나사를 돌리거나, 바퀴를 돌린다).
6. 이는 어디에 났고 무엇이 물리는가? → 바퀴는 바깥 가장자리 전체에 이. 나사는 한 줄 나사이고 정면에서 산이 "\" 로 기운다(위가 왼쪽) = **오른나사**. 나사의 아래쪽 산이 바퀴 맨 위 이골에 물린다.
7. 한 줄에 놓인 것은? → 바퀴 축 중심·브래킷 가운데·받침 블록 가운데가 한 세로선. 나사 가운데도 그 세로선 근처(판화에서 바퀴 중심 x 640, 나사 가운데 x 700). 나사 축과 베드는 서로 나란한 가로선.
8. 글자가 가리키는 부품은? → 글자 없음(번호 104 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 판화대로 두 가지가 모두 된다(나사가 돌면 바퀴가 제자리에서 돌고, 나사가 서 있을 때 바퀴를 돌리면 바퀴가 나사산을 랙처럼 타고 미끄럼대째 옮겨 간다). 문제 없음.
- 그 밖의 선: 바퀴 가운데 빗금 원 = 잘린 축 단면(축이 보는 쪽으로 나와 있음). 그 둘레의 고리 + 아래로 벌어지는 두 겹 선 = 브래킷(위는 축을 감싼 둥근 보스, 아래는 넓은 발)과 그 가운데 보강 줄. 브래킷 발 아래의 네모 = 베드를 감싸 타고 앉은 받침 블록(새들) — 블록 앞면이 베드 윗모서리를 덮는다. 베드 아래의 굵은 선 = 그림자.

## 해석(결정 사항)
- 기구: 가로 나사(웜, 제자리 회전) + 톱니바퀴(축이 브래킷에 꽂힘) + 브래킷이 선 받침 블록(미끄럼대) + 곧은 베드(고정).
- 두 쓰임을 한 주기에 번갈아 보여 준다: 나사 구동(바퀴가 제자리에서 돎) → 바퀴 구동(나사 정지, 미끄럼대가 오른쪽으로) → 나사 구동 → 바퀴 구동(미끄럼대가 왼쪽으로 돌아옴).
- 물림식 하나로 두 쓰임이 다 나온다: 접점에서 "바퀴 이의 속도 = 나사산이 흐르는 속도" → x' − R·β' = −p·φ'/2π.
- 회전 방향은 판화에 없다 → 나사는 오른쪽 끝에서 보아 반시계(오른나사라 아래쪽 산이 왼쪽으로 흐름 → 바퀴는 반시계)로 정함.
- 나사 축받이 2개, 베드 다리 2개는 **판화에 없음**(떠 있지 않게 하는 최소 보충).
- 판화 비: 나사 길이 = 바퀴 지름의 2.0배(모형 2.4/1.21 = 1.98), 나사 지름 = 바퀴 지름의 0.31배(모형 0.37/1.21). 나사산 수는 판화 12개, 모형 14개(이 20개 바퀴와 피치를 맞춘 결과).

## 구동
theta 누적: theta += OMEGA(1.6)·speed·dt. 한 주기 = theta 4π(7.854 s). 구동 부품은 구간마다 다르다(나사 → 바퀴 → 나사 → 바퀴). 모든 자세는 `wormDrive104(theta)` 의 닫힌 식.

## 부품과 치수 (새 부품은 모두 `kit/k104.ts`, 이미 구현됨. 치수 상수 `K104`)
배치 상수: CY = 1.45 (바퀴 축 높이), ZW = 0.1 (바퀴·나사의 가운데 평면), WY = CY + 0.68 = 2.13 (나사 축 높이), BEDY = 0.62 (베드 윗면).
- 나사(웜, name `worm`): 공용 키트 `wormScrew(0.061, 0.185, K104.pitch, 2.4, { driver: true })` — 뿌리 반지름 0.061, 바깥 반지름 0.185, 피치 0.1728(= π·0.055), 길이 2.4, 오른나사. 위치 (0, WY, ZW). 양 끝 축: `rod(new Vector3(−1.47, 0, 0), new Vector3(1.47, 0, 0), 0.045)` 를 **나사 그룹의 자식**으로(같이 돈다).
- 나사 축받이 2개(판화에 없음): `wallBearingX(ZW, 0.045)` 를 (−1.33, WY, ZW), (1.33, WY, ZW) 에. 고리의 구멍이 X 방향(축 방향)이고, 기둥은 고리 **뒤쪽 바깥면**에서 뒤판으로 뻗는다(축에 박히지 않는다).
- 바퀴(name `wheel`): `solidWormWheel(20, 0.055, { width: 0.1, tanLead: K104.tanLead })` — 이 20개, 모듈 0.055, 피치 반지름 0.55, 바깥 반지름 0.605, 폭 0.1, 살 없는 원판. 이는 나사 리드각만큼 비스듬(tanLead −0.2115). 위치 (xs, CY, ZW) — **루트에 두고** x 만 미끄럼대와 같은 xs 로 맞춘다(미끄럼대 그룹의 자식으로 넣지 않는다 — 회전각 검사가 바퀴만 보게). 미끄럼대의 축 표식 `wheelAxis` 와 같은 자리.
- 미끄럼대(name `carriage`): `wheelCarriage(0.83)` — 받침 블록(가로 0.86 × 높이 0.2, 베드 앞뒤를 0.07 덮는 턱) + 브래킷(발 폭 0.5, 보스 반지름 0.15, 두께 0.06, 바퀴 앞쪽 로컬 z 0.09~0.15) + 바퀴 축(반지름 0.07, 로컬 z −0.085~0.19, 브래킷 보스에 꽂힘). 원점 = 블록 바닥 가운데 → 위치 (xs, BEDY, ZW). 바퀴 축 중심 = (xs, 1.45, ZW).
- 베드(name `bed`, 고정): `slideBed(3.6, { h: 0.16, depth: 0.3, legH: 0.28 })` — 길이 3.6, 높이 0.16, 깊이 0.3, 다리 2개(판화에 없음, 받침대 윗면 0.18 까지). 위치 (0, BEDY, ZW). 가로 범위 −1.8 ~ 1.8, 세로 0.18 ~ 0.62.
- 검사 표식(메시 없음, name `wormSection`): `wormSection(0.061, 0.185, K104.pitch, 2.4)` — 나사의 축 단면 다각형. 루트에 더하고 매 프레임 위치를 맞춘다(동작 절).
- 받침대·뒤판 `displayStand()`.
- 전체 가로 범위 −1.8 ~ 1.8, 세로 0.18 ~ 2.32.
- 한 줄 정렬: 나사 가운데 x = 0 = 미끄럼대 왕복의 가운데. 바퀴 축·브래킷·블록은 같은 x(xs).

## 동작 (모두 theta 의 닫힌 식 — `wormDrive104(theta)` 가 { phi, x, beta, mode, s } 를 돌려준다)
한 주기 u = theta mod 4π:
| 구간 | u | 나사 각 phi | 미끄럼대 x | 구동 |
|---|---|---|---|---|
| 가 | 0 ~ 1.5π | 2u (1.5바퀴) | −0.1728 (왼쪽 끝) | 나사 |
| 나 | 1.5π ~ 2π | 3π 에서 정지 | −0.1728 → +0.1728 (smoothstep) | 바퀴 |
| 다 | 2π ~ 3.5π | 3π + 2(u − 2π) | +0.1728 (오른쪽 끝) | 나사 |
| 라 | 3.5π ~ 4π | 6π 에서 정지 | +0.1728 → −0.1728 | 바퀴 |
- 주기마다 phi 는 6π(3바퀴)씩 쌓인다 → 바퀴는 한 주기에 이 3개(54°)만큼 더 돌아 있고 물림 모양은 똑같다(정확히 닫힘). 행정 = 나사산 2개 = 0.3456.
- 바퀴 각: beta = π/2 + (x − pitch/2)/R + phi/N (R = 0.55, N = 20, pitch = 0.1728). 나사 구동 구간: beta' = phi'/20(속도비 1/20, 반시계). 바퀴 구동 구간: Δx = R·Δbeta(바퀴가 36° 돌면 0.3456 이동).
- 대입: `worm.rotation.x = phi`, `carriage.position.x = x`, `wheel.position.x = x`, `wheel.rotation.z = beta`, `wormSection.position.set(−pitch·frac(phi/2π), WY, ZW)` (frac = 소수 부분).
- 시각: **t = 1.0 (theta 1.6, 구간 가, 판화 자세 — 미끄럼대 왼쪽 끝 x −0.17)**, **t = 1.6 (theta 2.56, 구간 가)**, t = 3.3 (theta 5.28, 구간 나 한가운데 — 미끄럼대가 가는 중), t = 5 (theta 8.0, 구간 다, 오른쪽 끝), t = 30 (theta 48 → u 10.30, 구간 다).
