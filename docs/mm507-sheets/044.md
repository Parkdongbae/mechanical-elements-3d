# 044 계단식 톱니 기어
원문: 큰 힘을 전하고 이를 연속적으로 물리게 하는 기어. 각 바퀴는 둘·셋 또는 그 이상의 서로 다른 평기어를 합친 것이며, 이가 일직선이 아니라 계단 모양으로 배열된다(스크루 추진기 구동, 비슷한 랙으로 큰 대패 기계의 받침대 구동 등).

## ★ 판화 읽기
판화는 그림 하나(두 기어를 **옆에서 본 모습** — 축이 종이 위에 가로로 누워 있다).
1. 바퀴는 몇 개이고 크기 차례는? → 기어 2개. 위가 작고 아래가 크다(판화 높이 340 : 505, 지름비 약 0.67 = 2 : 3). 폭은 둘이 같고 넓다(아래 지름의 약 0.93배).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다. 축 끝이 좌우로 짧게 나와 있다.
5. 추·손잡이·크랭크는? → 없음. 구동 표시 없음(모형은 위 작은 기어를 구동으로).
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 둘 다 바깥 둘레. 위 기어의 아랫부분과 아래 기어의 윗부분이 가운데 가로선에서 물린다. 각 기어는 폭 방향으로 **네 층**(굵은 세로선 셋으로 구분)이고, 층마다 축과 나란한 짧은 가로줄(= 곧은 이)이 옆 층과 조금씩 어긋나 있다 — 평기어 넷을 조금씩 돌려 겹친 것.
7. 한 줄에 놓인 것은? → 두 기어의 폭이 같고 좌우 끝이 같은 세로선. 층의 경계선도 위아래 기어가 같은 세로선(층끼리 짝지어 물림). 두 축은 평행한 가로선.
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없다(없음). 원문은 "둘·셋 또는 그 이상", 판화는 넷.
- 그 밖의 선: 좌우 끝의 가는 띠 = 끝 판(플랜지). 허브 고리는 그려져 있지 않다.

## 구동
위(작은) 기어 theta += OMEGA·speed·dt.

## 부품과 치수 (키트: `steppedGear`, 이미 구현됨)
- 위 A(구동, name `gearA`): 잇수 ZA=20, 아래 B(name `gearB`): ZB=30. MOD = 0.032 → 피치 반지름 0.32 / 0.48(이끝 0.352 / 0.512). 중심 거리 DIST = 0.80.
- 층 4개, 층 폭 0.2, 틈 0.012(전체 폭 0.836, x ±0.418). 층 어긋남: A 는 피치각/4 = 4.5°, B 는 −(ZA/ZB)·4.5° = −3°(B 의 피치각/4, 반대 부호).
- A: `steppedGear(20, MOD, { sections: 4, sectionWidth: 0.2, gap: 0.012, step: +2π/20/4, driver: true })`. B: `steppedGear(30, MOD, { sections: 4, sectionWidth: 0.2, gap: 0.012, step: −2π/30/4 })`.
- 좌표: ZC = 0.27, Y2 = 1.30(B), Y1 = Y2 + DIST = 2.10(A), x = 0.
- 축: 반지름 0.045, x ±0.72.
- 받침(판화에 없음, 최소): x=±0.58 에 뒤판에서 나온 기둥(반지름 0.07, z −0.3 ~ ZC)과 끝 고리, 축마다 2개(m040 방식).

## 동작
- A.quaternion = Rx(theta)·Ry(90°), B.quaternion = Rx(meshAngle([0,0],20,theta,[0,−DIST],30))·Ry(90°). 층 어긋남은 steppedGear 내부(층 rotation.z)가 처리.
- 속도비 ωB/ωA = −20/30 = −0.667. 절대 각.

## 표시
- rotArrow(0.4): A ccw=true, B false, (x 0.56, rotation.y=π/2).
- tag 3개: '구동 기어(계단식 이)' (−1.4, 2.1, 0.5), '피동 기어' (−1.4, 1.3, 0.5), '이가 계단처럼 어긋나 차례로 물린다' (1.5, 1.78, 0.5).
- notes: 잇수 `20 : 30`, 속도비 `1 : 0.67 (반대 방향)`, 층 수 `4층, 층마다 1/4 피치 어긋남`.
