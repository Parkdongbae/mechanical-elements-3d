# 037 원뿔 스터드 기어
판화: 평행한 두 세로축. 왼쪽은 위가 넓고 아래가 뾰족한 원뿔(모선 방향 홈이 쭉 난 베벨 피니언), 오른쪽은 아래가 넓고 위가 좁은 원뿔대로, 면에 작은 돌기(스터드)가 왼쪽 아래에서 오른쪽 위로 올라가는 나선 모양으로 박혀 있다. 마주 보는 두 모선은 평행하다. 원문: 균일한 회전을 변하는 회전으로 바꾼다.
구동: 왼쪽 홈 원뿔 theta += OMEGA·speed·dt.

## 부품과 치수 (키트 추가 `flutedCone`)
- 두 축 x = −0.328, +0.328(D = 0.656), 깊이 ZC = 0.3(원뿔 반지름이 깊이 방향으로 나오므로 앞으로), 원뿔 바닥 y = 1.1, 높이 H = 1.25. (처음 설계 D 0.82·z 0.33 의 0.8배 — 전시 깊이 안에 들게 줄임.)
- 왼쪽(구동, 청동색): `flutedCone(18, 0.136, 0.456, 1.25, { driver: true, bore: 0.05 })` — 피치 반지름 pL: 0.136(아래) → 0.456(위), 홈 18개. 리브 끝 1.05·pL, 홈 바닥 0.93·pL.
- 오른쪽: 매끈한 원뿔대 + 반지름 0.016 돌기 18개. pR = D − pL(마주 보는 모선 평행). 몸통 반지름 = pR − 0.06·pL − 0.004(왼쪽 리브 끝이 닿지 않게), 돌기 끝 = pR + 0.055·pL(홈 바닥에 닿지 않게).
- 돌기 높이: 번호 순으로 12개 올라가고 6개 내려오는 비대칭 닫힌 나선(반코사인 두 토막). u = j/18, RISE = 12/18, AMP = 0.33 일 때 y_j = ym + AMP·h(u), h = −cos(πu/RISE) (u < RISE), cos(π(u−RISE)/(1−RISE)) (그 밖).
- 축·받침: 반지름 0.045 세로 막대(y 0.62~2.7), 아래 주철 기둥, 위 뒤판에서 나온 막대와 링.
- 깊이: 왼쪽 원뿔 리브 끝 최대 0.479 → z −0.18~0.78. 오른쪽 몸통 바닥 반지름은 0.508 이라 z −0.21~0.81 로 0.8 을 조금 넘는다(아래 "검증 후 수정" 참조).

## 동작
- δ = 2π/18(홈 피치각). 구간 w = floor(theta/δ), 돌기 번호 i = w mod 18, 구간 안 위상 u = theta − wδ.
- 돌기 i 가 물려 있는 동안 속도비 ratio_i = pL(y_i)/pR(y_i) (출력/입력, 서로 반대 방향).
- 오른쪽 원뿔 각 Ψ = −( q·2π + Σ_{j<i} ratio_j·δ + ratio_i·u ) (q = floor(w/18)). 돌기 방위 ψ_i = π + δ(Σ_{j<i} ratio_j + ratio_i/2) 로 놓아 구간 한가운데에서 돌기가 정확히 두 축 사이 선에 오며 홈 사이에 있다.
- ym 은 Σ ratio_j = 18 이 되도록 이분법으로 정해 오른쪽 원뿔이 입력 한 바퀴(18구간 = 18/18 바퀴)에 정확히 1회전, 속도는 구간마다 바뀐다.
- 왼쪽 rotation.y = theta, 오른쪽 rotation.y = Ψ (방위각은 +X 에서 −Z 쪽으로).

## 표시
- tag: '홈 원뿔(구동, 일정 속도)', '돌기 원뿔(피동, 속도 변함)', '나선 모양 돌기'.
- notes: 입력 '일정한 속도', 지금 속도비, 맞물린 돌기 번호.

## 확인
- t=1 / 1.6: 왼쪽 표시점(윗면)이 돌고 오른쪽 돌기 위치가 이동. 속도비가 구간마다 달라 오른쪽이 일정하지 않게 돈다. 비스듬히 봐서 돌기가 홈 사이에 있고 원뿔 표면끼리 닿지 않는다.
- 판화와 다른 점: 판화는 돌기가 올라가는 나선 한 줄이지만, 모델은 연속 운전이 되도록 앞면 12개는 판화처럼 올라가고(왼쪽 아래 → 오른쪽 위) 뒤쪽 6개가 내려와 닫힌다.

## 검증 후 수정 (Opus, 2026-11-25)
- **나선**: 처음 설계는 y_j = ym + 0.30·cos(2πj/18)(오르내림 대칭). 검증 중 판화처럼 한 방향 나선만 두는 안도 따졌으나, 맨 위 → 맨 아래로 한 번에 넘어갈 때 속도비가 1.8 → 0.46 으로 뛰어 뒤 리브가 막 빠져나가는 돌기를 약 2.5 cm 뚫고 지나가 연속 운전이 안 된다(수치 검사). 그래서 12개 오르고 6개 내려오는 비대칭 닫힌 나선(RISE 2/3, AMP 0.33)으로 정했다 — 보이는 앞면은 판화와 같은 방향으로 올라간다.
- **돌기·몸통**: 돌기 끝 = 피치선 + 0.055·pL, 오른쪽 몸통 = pR − 0.06·pL − 4 mm(처음 0.92·pR).
- **크기·깊이**: 원뿔 0.8배 — pL 0.17~0.57 → 0.136~0.456, D 0.82 → 0.656, 축 x ±0.328. 깊이 z 0.33 → ZC 0.3. 코드 주석의 "z −0.18~0.78"은 왼쪽 원뿔(리브 끝 0.479) 기준이다.
- **남은 점(설계표 정리 중 계산)**: 오른쪽 몸통 바닥 반지름 pR(0) − 0.06·pL(0) − 0.004 = 0.508 → z 최대 0.808 로 전시 깊이 0.8 을 0.008 넘는다(낮은 자리 돌기 끝은 조금 더 나온다). 캡처·`flags` 로 다시 확인할 것.
