# 047 마찰 클러치
원문: 아래쪽 레버로 맞물렸다 풀렸다 하는 마찰 클러치 상자. 무거운 기계를 연결하고 끊는 데 쓴다. 오른쪽 원판의 구멍(눈)에는 축에 고정된 긴 깃(키)에 미끄러지는 홈이 있다.

★ 판화 읽기 (질문표) — 판화 `public/mm507/fig/047.png`, 확대 `shots/_verify/047-fig-x4.png`·`047-top-x8.png` 를 설계표보다 먼저 보고 적음. 판화는 **축을 지나는 단면도**다(검은 빗금 = 왼쪽 부품, 회색 빗금 = 오른쪽 부품, 흰 곳 = 빈 곳·축).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 꼴 부품 2개가 한 축 위에 마주 본다. ① 왼쪽 **상자**(검정): 세로 판 + 축 둘레의 짧은 보스(판 안쪽) + **안쪽 턱(링)** + **바깥 테**. 안쪽 턱과 바깥 테 사이가 오른쪽으로 열린 **고리 홈**이다. ② 오른쪽 **원판**(회색): 세로 판 + 가장자리에서 **왼쪽으로 뻗은 고리 테** + 오른쪽으로 긴 계단 보스(끝에 목 홈). 원판 바깥 지름 < 상자 바깥 지름(원판의 고리 테가 상자의 바깥 테 **안쪽**으로 들어감).
2. 줄·벨트는? → 없음.
3. 교차하는(서로 끼워진) 곳은? → 원판의 고리 테가 상자의 고리 홈에 **깊이 들어가 있다**(테 끝이 홈 바닥 가까이). 상자 오른쪽 끝면과 원판 판 사이에는 흰 틈이 있다. 마찰면은 홈의 두 벽과 고리 테의 안팎 면이다.
4. 고정점은? → 판화에 받침 없음. 레버의 아래 핀(꺾이는 곳)이 받침점. 축받이 2개·받침 기둥 1개는 **판화에 없음(보충)**.
5. 추·손잡이·크랭크는? → ㄴ자 **꺾쇠 레버** 하나. 위 끝 핀이 원판 보스의 목 홈(축 아래쪽)에 걸리고, 팔이 아래로 내려와 받침 핀에서 꺾여 오른쪽으로 긴 수평 손잡이가 뻗는다.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 상자·원판·보스가 모두 한 가로 축 위. 축은 왼쪽 끝이 한 단 가늘어지고(저널) 오른쪽은 끊겨 그려짐.
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 알 수 없는 곳은? → ① 어느 쪽이 구동인지 판화·원문 모두 말하지 않는다 → 원문("원판이 축의 깃에 미끄러진다")에 따라 원판+축을 피동, 상자를 헐겁게 도는 구동으로 둔다. ② 판화의 자세(테가 홈에 깊이 든 채 판 사이에 틈)가 붙은 상태인지 뗀 상태인지는 **판화로는 알 수 없음** → 뗀 상태에서도 테 끝이 홈 안에 남게 만든다. ③ 단면도라 3D 겉모습은 판화에 없다 → 회전체로 만들고 상자만 1/4 을 잘라 단면을 보인다.

구동: 구동 상자(청동)가 늘 돈다. `theta += OMEGA·speed·dt`, 상자 각 = theta(+X 둘레). 축·원판은 시간표대로 따라 돈다.

## 해석(결정 사항)
- **(S1b 에서 고침)** 처음 표는 판화의 흰 세로 띠를 "얇은 원판", 상자를 "판 + 네 기둥 + 끝 링의 새장"으로 읽었다. 판화를 다시 보면 흰 띠는 **틈**이고, 회색 부품 전체가 원판이며 그 **고리 테가 상자의 고리 홈에 박히는 홈식(쐐기) 마찰 클러치**다. 새장·가죽 라이닝·구멍 5개는 판화에 없어 없앴다.
- 3D 로 보이기: 상자·원판을 단면 윤곽 그대로의 회전체로 만들고, **상자만 90° 를 잘라내어**(판화에 없음 — 단면도를 대신하는 창) 홈 속의 고리 테와 틈이 보이게 한다. 잘린 면은 판화와 같은 단면 모양이다.
- 레버는 `bellCrank`(ㄴ자), 받침점은 뒤판 기둥(`wallPost`, 판화에 없음).

## 이미 구현됨 (키트 추가) — kit/gear6.ts, 모델 작성자는 다시 만들지 않는다

## 확인
- 판화 대조(E1·E3): 왼쪽 상자가 바깥 테+안쪽 턱(사이 고리 홈), 오른쪽 원판의 테가 그 홈으로 들어가는가. 상자의 잘린 창이 앞을 향하는 순간(theta = 0 부근과 한 바퀴마다) 단면이 판화와 같은 꼴인가.
- t=1(gap 0.12) → t=1.6(gap ≈ 0.019): 원판·포크·레버 팔이 같이 왼쪽으로 움직인다. 축 표시점은 두 장 모두 정지, 상자 표시점은 0.96 rad 돈다.
- 근접 `cam=-0.5,1.9,1.9,-0.5,1.7,0.28`: t=5(박힘)에서 테가 홈 벽을 뚫지 않고(틈 0.0026) 판 사이 틈 0.06 이 남는다. t=7 에서 다시 물러남.
- 옆 `cam=3.2,1.7,0.28,0,1.7,0.28`·위 `cam=-0.5,3.4,0.8,-0.5,1.7,0.28`: 포크가 목 홈 안, 레버 팔 끝이 포크 핀과 붙어 있다.
