# 020 도르래 배열 (20)
판화: 들보 갈고리에 위 도르래 F 하나, 그 왼쪽 아래에 도르래 M2, 더 왼쪽 아래에 도르래 M3 가 층층이 매달린다(아래로 갈수록 왼쪽으로 밀리고 지름이 작아짐). 세로 줄 세 가닥이 맨 아래 넓은 추 막대 위의 걸이 세 곳에 맨다. M3 의 왼쪽에서 줄 하나가 비스듬히 바닥 쪽으로 늘어진다(자유 끝). 원문: 19 와 같은 규칙.
구동: M3 왼쪽의 자유 끝을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 판화를 그대로 읽어, 줄 3개가 모두 추 막대에 매이는 구성으로 만든다 — 줄 a: 막대 → F 위 → M2 윗 눈, 줄 b: 막대 → M2 위 → M3 윗 눈, 줄 c: 막대 → M3 위 → 자유 끝. 이 연결의 정확한 이득은 2³ − 1 = 7배이다(줄이 막대에 직접 맨 가닥 수 4 + 2 + 1). 책의 설명문은 2ⁿ 규칙을 말하므로(019 가 그 규칙대로 8배), 이 모형에서는 notes 에 "7배"를 보이고 설명 문구는 판화 연결의 계산값임을 밝힌다. 줄은 수직으로 그린다(자유 끝의 비스듬함은 무시).

## 부품과 치수
016 의 `rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)를 쓴다. 파일이 없으면 016 의 '키트 추가' 대로 만든다. 줄 반지름 0.014, 줄 z = 0.22, 도르래 중심 z = 0.22, 두께 0.07, `Rope` 3개(a, b, c).
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [0.2])` → 고리 아랫점 (0.2, 2.94, 0.22).
- F: `pulleyBlock(0.26, { hookUp: 0.06 })`, 중심 (0.20, 2.60). 윗 눈 (0.20, 2.92) 과 고리를 `rod`.
- M2: `pulleyBlock(0.22, { hookUp: 0.06 })`, 중심 (−0.06, y2).
- M3: `pulleyBlock(0.18, { hookUp: 0.06 })`, 중심 (−0.28, y3).
- 추 막대: `weight(0.80, 0.20)`, 중심 (0.18, yb − 0.10) (yb = 막대 윗면 높이). 막대 윗면에 줄 맬 눈고리 3개(steel 토러스 반지름 0.025, 관 0.008, 축 Z)를 x = 0.46, 0.16, −0.10 에, 높이 yb + 0.03 에 단다.
- 자유 끝에 `ropeEnd()`.

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `u = 0.10 × p` (짐이 오른 높이).
- yb = 0.50 + u
- y2 = 1.74 − u (M2 는 짐이 오를 때 u 내려온다)
- y3 = 1.20 − 3u
- yF = 0.95 − 7u (자유 끝; 시작 0.95, 끝 0.25)

### 줄 경로 (z = 0.22, `arcPoints(c, r, a0, a1, 0.22)`, a1 < a0 이면 시계방향)
- 줄 a: (0.46, yb + 0.03) → (0.46, 2.60) → `arcPoints([0.20, 2.60], 0.26, 0, π)` (F 위를 반시계로 넘음: 오른쪽에서 올라가 왼쪽으로 내려옴) → (−0.06, 2.60) → M2 윗 눈 (−0.06, y2 + 0.28).
- 줄 b: (0.16, yb + 0.03) → (0.16, y2) → `arcPoints([−0.06, y2], 0.22, 0, π)` → (−0.28, y2) → M3 윗 눈 (−0.28, y3 + 0.24).
- 줄 c: (−0.10, yb + 0.03) → (−0.10, y3) → `arcPoints([−0.28, y3], 0.18, 0, π)` → (−0.46, y3) → (−0.46, yF).
(전부 오른쪽 가닥은 막대에서 위로, 도르래를 반시계로 넘어, 왼쪽 가닥은 아래로.)

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, u, yb, y2, y3, yF 재계산.
- 도르래 각(`userData.sheave.rotation.z`, 모두 반시계 +):
  - θ_F = +u / 0.26
  - θ_M2 = +2u / 0.22
  - θ_M3 = +4u / 0.18
- 이득 7: 자유 끝이 7u 내려갈 때 짐이 u 오른다. (M2 u 하강, M3 3u 하강)

## 표시

- tag 'F 고정 도르래', 'M2 움직도르래', 'M3 움직도르래', '짐', '당기는 곳'. 위치는 부품에서 0.35 바깥, 매 프레임 따라감.
- notes: `[{ label: '이득', value: '7배 (줄 3개 모두 추에 맴: 4+2+1)' }, { label: '당긴 줄 : 오른 높이', value: (7u).toFixed(2) + ' : ' + u.toFixed(2) }, { label: '책의 규칙', value: '2ⁿ (019 참고)' }]`

## 확인
- t=0.4 (p ≈ 0): 추 막대가 낮고(윗면 0.5), M2·M3 가 높다. t=3.9 (p ≈ 1): 추 막대 0.1 상승, M2 는 0.1·M3 는 0.3 하강, 자유 끝은 0.7 내려가 바닥(0.25) 가까이 간다.
- 세 도르래 모두 반시계, M3 가 가장 빠르다. 줄 가닥 x 는 0.46, 0.16, −0.10 / −0.06, −0.28, −0.46 으로 서로 다르다. M2 아랫쪽과 M3 윗 눈이 겹치지 않는다.
