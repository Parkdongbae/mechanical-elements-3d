# 163 물레방아 조속기 2
원문(요지): 물레방아 조속기의 다른 방식. 조속기가 **꺾인 지레**로 **벨트**에 작용해 셔틀(수문)을 조절한다. 벨트는 풀리 셋 가운데 하나에 걸리는데, 가운데 풀리는 조속기 축에 헐겁고 위·아래 풀리는 고정이다. 알맞은 속도에서는 그림처럼 벨트가 헐거운 풀리에 있다. 빨라지면 벨트가 아래 풀리로 옮겨져 수문을 올리는(물을 줄이는) 기어 장치에 작용하고, 느려지면 위 풀리로 옮겨져 반대 효과를 낸다.
판화 묘사: 위에 공 조속기(꼭지·머리·팔 둘·공 둘·링크 둘·슬리브). 슬리브 아래 고리에서 S 자로 굽은 지레 팔이 오른쪽 아래 받침점(틀 위 받침대의 겹원)으로 내려오고, 받침점에서 오른쪽으로 곧은 팔이 끝 핀까지, 그 핀에서 세로 막대가 아래로 벨트 포크(작은 네모 블록)까지 내려간다. 아래에 ㄷ 자 틀(스핀들이 위 가로대를 꿰뚫음) 안에 스핀들의 풀리가 쌓여 있고, 벨트가 가로로 오른쪽 끝까지 뻗는다(포크가 벨트를 감싼다). 건너편 장치·수문은 그리지 않았다.

## ★ 판화 읽기
판화는 그림 하나(정면, 약 500×540px). 스핀들 x ≈ 225.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 조속기 축의 풀리 셋(위 y 395, 가운데는 벨트에 가려짐, 아래 y 430 — 같은 지름 약 80px). 기어 없음(원문의 "suitable gearing" 은 판화 밖).
2. 줄·벨트는 몇 개이고, 각각 어디서 시작해 어느 바퀴의 어느 쪽을 차례로 지나 어디서 끝나는가? → 평벨트 하나: 조속기 축 풀리 셋 가운데 하나(판화 순간에는 가운데 헐거운 풀리)를 감고 오른쪽으로 가로로 뻗어 판화 밖(건너편 풀리)으로 간다. 오른쪽 x 400 에서 포크가 벨트 앞 가닥을 감싼다.
3. 교차하는 가닥이 있는가, 어디서? → 없음(열린 벨트, 정면에서는 두 가닥이 한 줄로 겹쳐 보임).
4. 고정점(천장·벽·바닥)은 어디인가? → ㄷ 자 틀(스핀들 받침)과 그 위의 지레 받침대. 모형은 뒤판 받침 팔·링과 뒤판에서 나온 받침점 축으로 대신한다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 조속기 축이 물레방아(기관)로 돈다.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 판화에 기어 없음. 보충한 건너편 장치: 이가 위로 난 아래 베벨과 이가 아래로 난 위 베벨이 수문 축 피니언을 위·아래에서 문다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 스핀들·슬리브·고리·풀리 셋이 한 세로선. 지레 옆 팔 끝 핀과 포크가 같은 세로선(x 400). 받침점과 옆 팔 끝이 같은 높이(옆 팔 수평).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 원문의 "기어 장치"는 판화 밖이고, 위·아래 풀리가 같은 축에 고정이라 벨트 방향만으로는 수문을 반대로 돌릴 수 없다 → 건너편에도 같은 높이의 풀리 셋을 두고 위·아래 풀리를 각각 다른 베벨 기어에 이어 수문 축을 반대로 돌린다(보충). 질문 거리 없음.
- 그 밖의 선: 슬리브 아래 겹친 고리 = 홈 고리(지레 끝이 홈에 든다). 받침점 아래 삼각 = 받침대.

## 해석(결정 사항)
- 조속기 팔·링크·공은 162 와 같은 키트 `addGovernor162`(힌지 높이 2.3).
- 속도는 한 주기(θ 6π = 11.8 s)에 알맞음 → 빠름 → 알맞음 → 느림 → 알맞음 으로, 단계마다 머문다(계단 S ∈ {+1, 0, −1}, 넘어감 0.3 rad). 벨트(포크) 높이 = 1.0 − 0.09·S 를 기준으로 연결봉 → 지레 → 고리 → 슬리브 → 팔 각을 거꾸로 풀어 모든 부품이 한 몸으로 맞는다.
- 벨트가 헐거운 풀리에 있으면 벨트는 멈춘다(헐거운 풀리가 헛돈다). 위·아래 풀리에 있으면 스핀들과 같은 속도로 흐른다.
- 빠름 머무름 반폭 0.4 rad, 느림 반폭 aS 는 "빠름 동안 스핀들 회전 = 느림 동안 회전"을 키트가 풀어(aS ≈ 1.027) 수문 축이 주기마다 닫힌다.
- 회전 방향: 스핀들 위에서 반시계. 빠름 → 슬리브 오름 → 지레 시계 → 옆 팔·포크 내림 → 벨트 아래 풀리(원문).

## 동작 (`state163(theta)`)
- S(v): |v| ≤ 0.4 빠름(+1), |v − π| ≤ aS 느림(−1), 그 사이 알맞음(0), 넘어감 0.3 rad 은 smoothstep.
- 포크 높이 yF = 1.0 − 0.09·S. A = 원(P, 0.4) ∩ 원((−0.12, yF), 0.46), 지레 각 β = atan2(A − P), 고리 쪽 끝 C = P + 0.2343·(cos(140.2° + β), sin(…)), 슬리브 sy = C.y + 0.22, 팔 각 α 는 sy 에서 이분법.
- 벨트 'low'(S > 0.5) / 'up'(S < −0.5) / 'loose'. 수문 축 각 gate(표, 주기마다 닫힘), farLow = gate, farUp = −gate, 피니언 = gate + π/16. 벨트 표시 = −0.136 × 벨트 누적각.
- 범위: β −13°~+13°, 슬리브 1.787~1.868, 팔 각 약 30°~43°.
- 시각: t = 1 알맞음(헐거운 풀리 — 판화 순간), t = 1.6 알맞음, t = 4.5 느림(위 풀리), t = 10.4 빠름(아래 풀리), t = 30 느림.
