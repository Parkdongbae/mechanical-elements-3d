# 169 링크로 이은 크랭크
원문: "A modification of 168, in which a link is used to connect the pitman with the main crank, thereby dispensing with the slot in the said crank." — 168 의 변형. 피트먼과 주축 크랭크를 짧은 링크로 이어 크랭크의 홈을 없앴다.

## ★ 판화 읽기
1. 바퀴: 없음. 크랭크 둘(가운데 둘째 크랭크, 오른쪽 주축 크랭크).
2. 줄·벨트: 없음.
3. 교차: 피트먼이 둘째 크랭크 핀 위를 지나고, 오른끝에서 짧은 링크로 주축 크랭크 핀에 이어진다(168 의 거울상).
4. 고정점: 둘째 크랭크 축·주축(받침 없음 — 뒤판 핀 보충), 왼쪽 끝 막대의 위 지점(위 고정 핀으로 보충).
5. 동력: 왼쪽 끝 눈 P3 에 달린 막대(왕복).
6. 기어: 없음.
7. 한 줄: 피트먼 직선 위에 P3 · 둘째 크랭크 핀 P2 · 링크 위쪽 끝 P1. 점선 타원이 주축 크랭크 둘레.
8. 글자 없음(번호 169 뿐).
9. 판화와 원문 불일치 없음. 168 과 같이 왼쪽 막대는 위 핀에 매달린 흔들이 막대로 읽는다. 질문 거리 없음.

## 해석(결정 사항)
- 168 의 좌우 뒤집은 배치. 홈 크랭크 → 보통 크랭크(반지름 0.55, 핀 Q) + 링크(길이 0.5, Q ↔ P1). P1(피트먼 연장점)의 타원이 주축을 에워싸 주축이 한 바퀴 돌 때 모두 한 주기로 닫힌다.
- 구동은 주축 각 psi = theta − 0.713(t = 1 에서 둘째 크랭크 핀이 위쪽 108°), 둘째 크랭크 각은 거꾸로 표로 푼다. 반시계.

## 구동
theta += OMEGA(1.6)·speed·dt. 한 주기 2π = 3.927 s. 주축 크랭크가 구동, 나머지 종동.

## 부품과 치수 (`kit/k168.ts` 공용 + 새 부품 `kit/k169.ts`, 이미 구현됨. 상수 `K169`)
- 주축 크랭크(name `crank1`): `crank2(0.55, 0.265)` — 주축 O1 (1.25, 1.59), 핀 Q 가 링크 눈까지 올라옴. z 0.06~0.105.
- 둘째 크랭크(name `crank2`): S2 (0.10, 1.55), 반지름 0.33.
- 피트먼(name `pitman`): `pitman168(F, { slotPin: false })`, P1 + 1.15 = P2, + 1.50 = P3, z 0.13~0.18.
- 링크(name `link`): `link169()` 길이 0.5, z 0.19~0.24, P1 쪽 핀이 피트먼 눈을 꿴다.
- 흔들이 막대(name `rocker`): H (−1.45, 2.95), 길이 1.45. 고정 핀 `axisMain` `axis2` `hPin`(판화에 없음). 점선 궤적(벽에 칠함).
- 받침대·뒤판 `displayStand()`. 가로 −1.95~1.9, 세로 0.9~3.0.

## ★ 깊이 계산
z −0.25~0.265 (뒤판 앞면 −0.30 의 점선·핀 뿌리 제외). 크랭크 0.06~0.105, 피트먼 0.13~0.18, 링크·흔들이 막대 0.19~0.24(서로 멀리 떨어짐), 핀 머리 ≤ 0.265, 화살표·이름표 0.3 ≤ 0.8.

## 동작
`pose169(theta)`: psi = theta + psi0, phi = 거꾸로 표(psi), 168 과 같은 `coupler` 로 P1·P2·P3, Q = 원(O1, 0.55) ∩ 원(P1, 0.5). `crank1.rotation.z = psi`, `crank2.rotation.z = phi`, 피트먼은 P1 에서 rotation.z = beta, 링크는 Q 에서 rotation.z = atan2(P1 − Q), 흔들이 막대 rotation.z = rock. 시각: t = 1, 1.6, 30.
