# 213 다른 종류의 멈추개
원문: "Another kind of stop for the same purpose." — 같은 목적(212 — 태엽을 감는 바퀴 수 제한)에 쓰이는 다른 종류의 멈추개. 쉬운 풀이: 212와 같은 일을 한다. 홈 바퀴가 한 칸씩 움직이다가, 홈이 없는 부분이 오면 더는 돌지 않고 멈춘다.
판화 묘사(원본 479×437 px, [x·y]): 위 큰 원판 B(축 [255·133], 테 반지름 약 90 px). 가운데 동그란 선(반지름 약 45 px, 가운데 작은 축 구멍)과 거기서 위 테까지 곧게 올라간 좁은 홈 한 줄(폭 약 14 px). 원판 아래쪽 약 90°(B 중심에서 225°~315°)만 테가 한 단 낮아지고 거기에 네모 홈 6개(17~18° 간격, 홈 바닥 반지름 73 px, 사이 이끝 87 px). 아래 톱니바퀴(축 [249·275], 네모 축, 반지름 약 80 px, 비스듬한 톱니 24개) — 위쪽은 B 뒤에 가려짐. 두 바퀴 사이 B 의 홈 입구에 작은 원 하나 [238·220](아래 바퀴 중심에서 약 56 px) = 아래 바퀴 앞면의 핀.

## ★ 판화 읽기
판화는 그림 하나(정면). 1 px ≈ 0.0095(축 거리 142 px = 1.35).
1. 바퀴는? → 2개. B 멈춤 원판(테 0.88) > 아래 톱니바퀴(감기 바퀴, 0.70).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 톱니바퀴 위쪽이 B 뒤에 가려짐(톱니바퀴가 뒤 층, B 가 앞 층), 핀은 톱니바퀴 앞면에서 B 의 층까지 나온다.
4. 고정점은? → 두 축(같은 세로선, x 249~255 px).
5. 추·손잡이·크랭크는? → 판화에 없음. 네모 축 = 태엽 굴대(열쇠 꽂는 곳) → 아래 바퀴가 감는 쪽(축 앞 손잡이 보충).
6. 기어는? → 기어 물림 없음. 아래 바퀴의 핀 하나가 한 바퀴마다 B 의 홈 하나에 들어가 B 를 18° 민다(핀 하나짜리 제네바). 톱니바퀴의 톱니는 B 와 다른 층이라 B 와 물리지 않는다(태엽 걸쇠용).
7. 한 줄에 놓인 것은? → 두 축이 한 세로선. 홈 6개는 그 세로선을 가운데로 좌우 대칭(판화 자세).
8. 글자가 가리키는 부품은? → 글자 없음(번호 213 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 동작은 그대로 된다(계산: 핀 회전 반지름 √(1.35² + 0.855² − 2·1.35·0.855·cos9°) = 0.523 = 판화의 56 px). 다만 B 의 가운데 동그란 선에서 테까지 올라간 좁은 홈의 쓰임은 판화로는 알 수 없음(멈춤 동작과 관계없음) → ★질문 거리. 기본값: 앞면에 새긴 줄(짙은 띠)로만 둔다. 또 B 를 잡아 두는 잠금은 그림에 없으므로 핀이 없을 때 B 는 마찰로 서 있는 것으로 둔다.

## 해석(결정 사항)
- 핀이 홈 하나를 지날 때 B 가 18°(홈 간격) 돈다. 홈 6개 → 양 끝 사이 6칸. 홈 줄 양 끝 너머는 높은 테(0.88)라 핀이 다음 홈 자리로 가기 전에 테 계단에 닿아 멈춘다. **양 끝 멈춤 사이 아래 바퀴 2460.9° = 6.84 바퀴**.
- 핀이 홈에 들어가는 반지름 Re = 0.855, 이끝 0.80(= Re − 핀 0.05 − 0.005, 들어가기 전 핀이 이끝에 닿지 않게), 물린 구간 ±aw = ±14.820°.
- 판화에 없는 보충: 감기 손잡이, 바퀴 수 표시등 6개, 계단 빨간 표지.

## 구동
아래 바퀴 A 를 감는다(반시계) → 끝에서 멈춤 → 풀기(시계) → 반대 끝에서 멈춤. 각속도 3.0 rad/s(171.887°/s). 주기 T = 31.634 초, u = t mod T:
- u ∈ [0, 14.317): 감기 α = αb + 171.887·u
- u ∈ [14.317, 15.817): 멈춤 α = αf(빨강)
- u ∈ [15.817, 30.134): 풀기 α = αf − 171.887·(u − 15.817)
- u ∈ [30.134, 31.634): 멈춤 α = αb
αb = −1320.45°, αf = 1140.45°(닿는 각 −1320.75°·1140.75° 에서 0.3° 앞).
