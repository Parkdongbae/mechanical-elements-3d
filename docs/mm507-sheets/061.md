# 061 차동 두 단 속도

## ★ 판화 읽기
(S1b 교차 읽기 — 설계표를 보기 전에 판화 `public/mm507/fig/061.png` 와 507movements.com 의 원본 그림을 따로 읽고 적었다. 결과: **기구 구성 일치**.)
1. 바퀴는 몇 개이고 크기 차례는? → 위 축에 긴 드럼 1개(폭이 아래 풀리 세 개를 합친 것과 같다). 아래 축에 지름이 같은 풀리 3개가 붙어 있다 — 왼쪽 L(벨트가 걸린 좁은 것), 가운데 M, 오른쪽 R. 네 바퀴 지름은 거의 같다. 점선 베벨 기어 3개(M 오른쪽 절반 ~ R 안쪽): A(M 허브에 고정), P(R 에 가로로 실린 유성), C(축에 헐거움). R 오른쪽 밖에 작은 허브(제동 드럼)와 그 둘레 띠.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 평벨트 1개. 위 드럼의 왼쪽 끝 부분 ↔ 아래 L 풀리(판화의 순간 = 헐거운 풀리, 아래 축 정지). 옆모습이라 세로 띠 하나로 보이고 가운데가 끊김 표시(지그재그)다. 열린 걸이.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 판화에는 축받이가 없다(위·아래 축 끝이 비스듬히 잘림). 마찰 밴드는 한쪽 끝이 틀에 고정되어야 하지만 판화에는 띠와 아래로 내려가는 두 줄만 있다.
5. 추·손잡이·크랭크는? → 마찰 밴드 끝에서 아래로 내려가는 줄 끝의 추(판화 아래 가장자리에서 잘림). 손잡이·크랭크 없음.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 베벨 셋이 한 꼭짓점에 모인다. A(이가 오른쪽을 봄) – P(축에 수직, 이가 축 쪽) – C(이가 왼쪽을 봄). A–P, P–C 가 물리고 A–C 는 직접 물리지 않는다.
7. 한 줄에 놓인 것은? → 위 드럼의 왼쪽 끝 = L 풀리 왼쪽 끝, 드럼 오른쪽 끝 = R 풀리 오른쪽 끝(벨트를 옆으로 밀어 세 풀리 어디에나 걸 수 있다). 풀리 셋·베벨 셋·제동 허브는 모두 아래 축 한 줄.
8. 판화의 글자는? → 없음(A·P·C·L·M·R 은 이 설계표가 붙인 이름).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → 없음. 원문의 "단순 / 2배"와 판화 구조가 맞는다. 판화와 다르게 만드는 곳 두 가지(구조는 같음): ① 판화는 베벨이 R 풀리 안에 숨어 있다(점선) → 보이도록 M 과 R 사이를 벌려 드러낸다. ② 케이지 막대·링·균형추, 축받이, 밴드의 고정 귀는 **판화에 없음**(보충 부품 — 뜬 부품을 없애려는 최소한).
판화(61): 그림 하나, 축이 **가로**인 옆모습. 위쪽에 긴 드럼(풀리) 하나가 위 축에 있고, 아래쪽에는 아래 축에 풀리 세 개가 이어 붙은 긴 통이 있다(통 안에 점선으로 베벨기어들이 비친다). 두 통 사이를 **벨트가 세로로** 내려오며 가운데가 지그재그(끊김 표시)로 잘려 있다 — 벨트는 아래 통의 맨 왼쪽 풀리에 걸려 있다. 아래 축 오른쪽 끝에는 축에 헐겁게 끼운 슬리브 + 밴드(고리) + 아래로 내려가는 줄(추)이 보인다. 위·아래 축 모두 양쪽 끝이 비스듬히 잘려 삐져나온다.
원문 요지: 두 속도, 그중 하나는 차동. 벨트는 아래 축의 헐거운 풀리 위에. 가운데 풀리는 축에 고정, 허브에 작은 베벨 A. 오른쪽 풀리는 헐겁게 끼워지고 **가로로(축에 수직으로) 또 다른 베벨 P(유성)** 를 달았다. 축에 헐겁게 끼운 셋째 베벨 C 는 끝에 추가 달린 마찰 밴드로 잡혀 있다. 벨트를 가운데 풀리로 옮기면 단순 운동, 오른쪽 풀리로 옮기면 축이 **2배 속도**. 밴드는 속도가 갑자기 바뀔 때 C 가 조금 미끄러지게 하려는 것.
판화 해석: 판화 하나뿐이라 그대로 만든다. 판화가 축을 가로(좌우)로 눕힌 옆모습이므로 **기구의 모든 축을 세계 X 방향**으로 둔다(키트의 Z 축 풀리를 `rotation.y = π/2` 피벗으로 눕힘). 정면(+Z)에서 보면 판화와 같은 직사각형 통 두 개 + 세로 벨트로 보인다. 통 안 점선 기어는 풀리 안에 가두면 아무것도 안 보이므로, 판화와 달리 **풀리 사이 틈에 드러낸다**(순서는 원문 그대로 A, P, C).
구동: 위 축(드럼)을 돌린다. θ += OMEGA·speed·dt. 위 축 각 = θ(세계 +X 둘레 양의 회전). 벨트는 주기 시간표(아래)로 가운데 고정(M) → 오른쪽 운반(R) → 왼쪽 헐거운(L) 풀리로 옮겨 걸린다.

## 동작 (모든 자세 = θ 의 함수)
α = 세계 +X 둘레 각(반시계가 +). 위 축 = θ, 벨트 속도비 k = r_위/r_아래 = 1.
- 차동 관계(항상): **αA + αC = 2φ**. 061 은 αC ≡ 0 이므로 αA = 2φ.
- **베벨 자세**(검증됨, `shots/_verify/s061_phase.mjs` — 여러 (φ, αA)에서 A–P, C–P 이 중심 간 최소 거리 = 반 피치 현 0.0392, 곧 이–이골이 정확히 엇갈림. 잇수 16 은 4 의 배수여야 성립):
  - `grpA.rotation.x = αA`
  - `grpC.rotation.x = αC` (pivot 이 `rotation.y = −π/2` 이므로 C 자신의 로컬 z 회전은 −αC)
  - `carrier.rotation.x = φ`, 유성 로컬 z 회전 **θP = φ − αA − π/16** (π/16 = 반 피치 = π/잇수).
- **주기 시간표**(주기 T = 26 rad; n = floor(θ/T), u = θ − nT; 속도 단위 = rad/θ):

| u 구간 | 상태 | 벨트 x | dαA/dθ | dφ/dθ | dαL/dθ | αC |
|---|---|---|---|---|---|---|
| 0 ~ 8 | 벨트가 M(고정) 풀리 | −0.75 | 1 | 0.5 | 0 | 0 |
| 8 ~ 10 | M → R 로 옮김(아래 정지) | −0.75 → 0.85 (smoothstep) | 0 | 0 | 0 | 0 |
| 10 ~ 18 | 벨트가 R(운반) 풀리 = 2배 | 0.85 | 2 | 1 | 0 | 0 |
| 18 ~ 20 | R → L 로 옮김(정지) | 0.85 → −1.20 | 0 | 0 | 0 | 0 |
| 20 ~ 24 | 벨트가 L(헐거운) 풀리 = 아래 축 정지 | −1.20 | 0 | 0 | 1 | 0 |
| 24 ~ 26 | L → M 로 옮김(정지) | −1.20 → −0.75 | 0 | 0 | 0 | 0 |

  - 한 주기 이득: αA 24, φ 12, αL 4. 절대 각 = n·이득 + (u 까지 구간별 적분). 초기화 때 구간 표로 누적값을 미리 계산해 두고 매 프레임 θ 로 다시 계산(음수 θ 는 floor 로).
  - M 상태: 벨트가 축을 직접 돌려 αA = θ, C 가 정지이므로 운반 풀리 R 은 헐거운 채 φ = αA/2 로 따라 돈다(유성은 자전 + 공전). R 상태: 벨트가 R 을 돌려 φ = θ, C 정지라 축 αA = 2θ. 속도비 위 축 : 아래 축 = 1 : 1(M), 1 : 2(R), 1 : 0(L).
  - 벨트 표시 흐름: `belt.setOffset(0.392·θ)`(경로가 (y, z) 반시계 = +X 양의 회전이고 위 드럼이 +θ 로 돈다). 캡처로 이음매 표시가 드럼 표면과 같은 쪽으로 흐르는지 확인, 반대면 부호 반전. 벨트는 옮기는 동안에도 흐른다.
  - 밴드 미끄러짐은 그리지 않는다(C 는 항상 정지).
