# 059 두 단 속도 기어
판화(public/mm507/fig/059.png, 확대 shots/_verify/059-fig-x4.png — Fable 교차 읽기 2026-11-25): 축을 옆에서 본 그림 하나. 맨 위에 가로 축 + 폭 넓은 통 풀리(원동 드럼). 드럼 **왼쪽 끝**에 감긴 세로 벨트가 아래로 내려가(꺾임 표시로 끊어 그림) 아래 묶음의 **맨 왼쪽 풀리(헐거운 풀리)** 에 걸려 있다. 아래 묶음에는 같은 지름의 풀리 셋이 나란히 붙어 있다(세로 금 2줄: 왼쪽 헐거운 것, 가운데, 오른쪽). 풀리를 꿴 축(A)은 왼쪽으로 뻗어 **작은 피니언**에 닿고, 오른쪽 풀리에서는 더 굵은 축(속 빈 축)이 오른쪽으로 나가 **큰 평기어**에 닿는다. 그 아래에 가로 축(B)이 하나 더 있어, 왼쪽 끝의 **큰 평기어**(판화 아래로 잘림)가 A 의 작은 피니언과, 오른쪽 끝의 **작은 피니언**이 A 쪽 큰 평기어와 물린다(왼쪽·오른쪽 톱니 띠는 저마다 위아래로 물린 기어 한 쌍을 가장자리에서 본 것). 판화 픽셀(확대본): 드럼 반지름 ≈ 222, 아래 풀리 ≈ 225(같은 지름), 큰 기어 ≈ 205~235, 작은 피니언 ≈ 55~65, 두 축 거리 ≈ 270.
원문 요지: 벨트는 아래 세 풀리 중 왼쪽의 헐거운 풀리 위에 있다. 가운데 풀리는 작은 피니언과 같은 축에 고정, 오른쪽 풀리는 속 빈 축에 고정되어 그 끝에 큰 평기어. 벨트가 가운데 풀리에 있으면 아래 축에 **느린** 운동, 오른쪽 풀리에 있으면 기어 지름에 비례하는 **빠른** 속도.

★ 판화 읽기
1. 바퀴: 풀리·드럼 4개(원동 드럼 1 + 아래 풀리 3, 지름 모두 같음), 기어 4개(큰 것 2 ≈ 풀리 지름, 작은 피니언 2 ≈ 큰 것의 1/3.5).
2. 줄·벨트: 1개. 원동 드럼의 왼쪽 끝을 감고 곧게 내려와 맨 왼쪽 풀리(헐거운 풀리)를 감는 열린 평벨트(닫힌 고리, 가운데는 끊어 그림).
3. 교차 가닥: 없음.
4. 고정점: 판화에 축받이가 그려져 있지 않다(판화로는 알 수 없음). 세 축(드럼 축, A, B)은 제자리에서 도는 축.
5. 추·손잡이·크랭크: 없음.
6. 기어: 모두 바깥 이. 왼쪽 쌍 = A 의 작은 피니언(위) ↔ B 의 큰 기어(아래). 오른쪽 쌍 = 속 빈 축의 큰 기어(위) ↔ B 의 작은 피니언(아래).
7. 한 줄에 놓인 것: 세 축이 평행(가로). 드럼 왼쪽 끝 = 헐거운 풀리 위(같은 세로선), 드럼 폭 ≈ 풀리 3개 폭. 두 기어 쌍은 저마다 한 세로선.
8. 글자: 판화에 글자 없음.
9. 판화와 원문이 다른 곳: 없음.

## 구동
맨 위 원동 드럼(축 X, 각 θ += OMEGA·speed·dt). 벨트가 주기 시간표대로 옆으로 옮겨 가 헐거움 → 가운데 → 오른쪽 → 헐거움으로 바뀐다.

## 부품과 치수
좌표 (x, y, z). 축 높이 z = ZC = 0.28(모든 축). 회전축은 전부 X. 키트 사용: `spurGear`, `pulley`(flat), `rod`, `rotArrow`, `tag`, `meshAngle`, `displayStand`. 전용 키트(kit/k059.ts): `hollowShaft`, `rimStripes`, `wallBracket`, `verticalBelt`.
**X축 부품 만드는 법**: 바깥 그룹 `outer.rotation.y = π/2`(로컬 z → 월드 +x, 로컬 x → 월드 −z), 안쪽 그룹 `inner.rotation.z = φ` 가 월드 +X 둘레 회전 φ. name 은 inner 에 붙인다. 풀리·기어는 로컬 XY 에 놓이므로 `meshAngle` 의 중심은 로컬 좌표 `[0, y]`(월드 y).
- 드럼 축 U: y = 2.80, `rod` x −1.25…0.95, 반지름 0.045. 원동 드럼: `pulley(0.45, { width: 0.90, spokes: 6, flat: true, driver: true })` + `rimStripes(0.45, 0.9, 6)`, x 중심 −0.13(x −0.58…0.32). name `drum`. 맨 위 y = 3.25.
- 축 A: y = 1.55, x −1.25…1.15, 반지름 0.045. 축 B: y = 0.925, x −1.25…1.15. A–B 중심거리 0.625 = 0.025·(14+36)/2.
- 기어(모듈 0.025, width 0.08, spokes 6): 큰 기어 36(피치 반지름 0.45, 이끝 0.475), 작은 기어 14(피치 0.175).
  - Pa(A 위, 14): x = −1.0, 축 A 에 고정. `spurGear(14, 0.025, { width: 0.08, spokes: 6 })`.
  - Gb(B 위, 36): x = −1.0, Pa 와 물림. `spurGear(36, 0.025, { width: 0.08, spokes: 6 })`.
  - Gh(A 의 속 빈 축 위, 36): x = 0.78. 속 빈 축 `hollowShaft(0.075, 0.05, 0.50)` 가 x 0.30…0.80 (오른쪽 풀리 → Gh 연결), 축 A 는 그 안을 통과. name `gearH`.
  - Pb(B 위, 14): x = 0.78, Gh 와 물림.
  - Gb·Pb 는 B 에 같이 고정(같은 θB, 한 그룹 name `shaftB`).
- 풀리(A 위, 반지름 0.45, `rimStripes`, flat) — 드럼과 같은 지름(판화):
  - 헐거운 풀리 L: x 중심 −0.45, width 0.26 (축 A 에 헐겁게 → 따로 돈다). name `pulleyL`.
  - 가운데 풀리 M: x 중심 −0.15, width 0.30 (축 A 고정, Pa 와 같이 돈다). name `pulleyM`.
  - 오른쪽 풀리 R: x 중심 0.17, width 0.30 (속 빈 축 고정, Gh 와 같이 돈다).
- 벨트(세로, YZ 평면): `verticalBelt([{c:[0.28, 2.80], r:0.46, ccw:false}, {c:[0.28, 1.55], r:0.46, ccw:false}], { width: 0.20 })`. 로컬 xy 는 월드 (z, y). 벨트 x 위치는 `setX(beltX)`. 앞쪽(z 큰 쪽) 가닥이 아래로 내려간다. name `belt`.
- 판화에 없음(보충): 뒤판에 닿는 지지대 `wallBracket` 6개(U 의 x −1.25·0.95, A·B 의 x −1.25·1.15, 각 축 높이 y, z = 0.28, backZ = −0.30)뿐. 예전의 벨트 포크(밀어 주는 막대)는 판화에 없어 뺐다 — 벨트만 옆으로 옮겨 간다(058 과 같게).
- 뒤판 `displayStand()` 하나. 전시 영역: x −1.3…1.2, y 0.45…3.25, z −0.195…0.755.

## 동작
θ = 구동 누적각(절대). 한 주기 20 rad(약 12.5초). `acc(θ, segs)` = 주기마다 구간 segs 에 머문 θ 길이의 누적(`floor(θ/20)·Σ길이 + Σ clamp(θ mod 20 − a, 0, b − a)`).
| θ mod 20 | 벨트 | beltX |
|---|---|---|
| 0–2.5 | 헐거운 L | −0.45 |
| 2.5–3.5 | L→M 이동(전달 없음) | −0.45→−0.15 |
| 3.5–9 | 가운데 M (느림) | −0.15 |
| 9–10 | M→R 이동 | −0.15→0.17 |
| 10–15.5 | 오른쪽 R (빠름) | 0.17 |
| 15.5–17 | R→L 이동(M 을 스침, 전달 없음) | 0.17→−0.45 |
| 17–20 | 헐거운 L | −0.45 |
- 벨트 비 = 0.45/0.45 = 1(드럼과 아래 풀리가 같은 지름). Dm = acc(θ, [[3.5, 9]]), Dr = acc(θ, [[10, 15.5]]), Dl = acc(θ, [[0, 2.5], [17, 20]]).
- 드럼: φU = θ. 벨트 표시: `belt.setOffset(0.46·θ)`.
- **자유도는 하나**(네 기어가 모두 물려 닫힌 사슬): θB = −( (14/36)·Dm + (36/14)·Dr ). 근거: 가운데 물림이면 A 가 드럼과 같이 돌고 B = −A·14/36; 오른쪽 물림이면 속 빈 축이 드럼과 같이 돌고 B = −(속 빈 축)·36/14.
- 모든 자세(로컬 rotation.z):
  - B 전체(Gb, Pb): θB.
  - A(가운데 풀리 M, Pa): θA = meshAngle([0,0.925], 36, θB, [0,1.55], 14).
  - 속 빈 축(오른쪽 풀리 R, Gh): θH = meshAngle([0,0.925], 14, θB, [0,1.55], 36).
  - 헐거운 풀리 L: θL = Dl (벨트가 있을 때만 구동되고, 아니면 멈춘 채 그 각을 유지).
- 속도비(드럼 대비): 가운데 구동 시 B = −14/36 = −0.389, 빠를 때 B = −36/14 = −2.571. 빠름/느림 = (36/14)² ≈ 6.6배. 가운데 구동 때 Gh 는 Pb 에 끌려 헛돌고(−0.389·(−14/36) = +0.151), 빠를 때 A 의 Pa 는 아주 빠르다(6.61배) — 모두 정상.
- 방향: 드럼 앞쪽 가닥이 내려가는 방향(+X 회전). 물린 기어쌍은 서로 반대 방향.

## 표시
- `rotArrow(0.55, true)`: 드럼 끝(x = −0.70, y 2.80)과 B 축 가운데(x = −0.1, y 0.925)에 각각 하나. 옆면이 정면이라 `rotation.y = π/2 − 0.9` 정도 비스듬히 돌려 둔다. 방향은 +X 회전 기준(B 는 반대).
- tag 이름표 7개: '원동 드럼'(0.75, 3.1, 0.5), '헐거운 풀리'(−0.45, 2.2, 0.75), '고정 풀리(느림)'(−0.1, 1.0, 0.78), '속 빈 축 풀리(빠름)'(0.6, 2.2, 0.75), '작은 기어'(−1.45, 1.95, 0.5), '큰 기어'(1.3, 2.15, 0.5), '출력 축 B'(−0.1, 0.5, 0.5).

## 확인
- t=1(θ=1.6): 벨트가 헐거운 풀리 위(판화의 상태), 드럼과 헐거운 풀리만 돈다, A·B 기어는 멈춤.
- t=3(θ=4.8), t=4(θ=6.4): 가운데 풀리 구동, B 느림(−0.39), A 의 작은 기어가 B 의 큰 기어를 돌림. t=8(θ=12.8): 오른쪽 풀리 구동, B 빠름(−2.57).
- 근접 `cam=-1.4,1.4,1.2,-1.0,1.2,0.28`: Pa–Gb 이가 골에 들어가는지, 기어 이끝이 뒤판(z −0.3) 앞이고 전시 z ≤ 0.8 인지. 벨트가 풀리 폭 안인지.

★ 줄·벨트 표
| 줄 | 지나는 바퀴 차례 | 바퀴별 감긴 각·쪽 | 림 종류 | 끝점 두 곳이 붙는 부품 |
|---|---|---|---|---|
| 평벨트 1개 | 원동 드럼 → (앞 가닥 내려옴) → 벨트가 걸린 풀리(L / M / R 가운데 하나) → (뒤 가닥 올라감) → 드럼 | 드럼 180° 위쪽 / 풀리 180° 아래쪽 | 납작 림 ↔ 평벨트 | 닫힌 고리(끝점 없음) |
- 벨트 평면 = YZ, 폭 방향 = X. 두 직선 가닥은 z = 0.28 ± 0.46 의 세로선.

★ 연결 표
| 부품 A 의 점 | 부품 B 의 점 | 허용 틈 |

| 가운데 풀리 M·피니언 Pa | 축 A | 0 (같은 각 θA) |
| 오른쪽 풀리 R·큰 기어 Gh | 속 빈 축 (x 0.30…0.80) | 0 (같은 각 θH) |

★ 깊이 계산
축이 X 방향이라 반지름이 깊이(z)로 나온다. ZC = 0.28, 최대 반지름 0.475(36 이 기어의 이끝), z −0.195~0.755. 풀리·드럼 0.45 + 벨트 0.02 → z −0.19~0.75.

- 남은 fail(wrap): 드럼 감긴 각이 207° 로 재진다(선언 180±12). 같은 지름 두 풀리라 실제 감긴 각은 180° 이고, 평벨트 허용 창(+0.01)이 반지름 0.46 에서 접점 양쪽 약 12° 씩 직선 가닥을 '앉은 호'로 세는 측정 덧붙음이다(058 은 선언을 209 로 둠). 검사 기준을 바꾸는 일이라 선언은 고치지 않았다 — 사람이 deg 207 또는 tol 30 으로 정할 것.
