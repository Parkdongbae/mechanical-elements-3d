# 172 달걀형 타원 운동
원문: "A mode of obtaining an egg-shaped elliptical movement." — 두 개의 크랭크 사이를 막대로 이어 두고 그 막대 위의 한 점을 보면 그 점은 원이 아니라 달걀 모양으로 한 바퀴 돈다.

## ★ 판화 읽기
판화는 그림 하나(정면, 가로 460·세로 460 px, 아래 [x·y] 는 원본 px).
1. 바퀴는? → 바퀴(풀리·기어)는 없다. 고리(눈) 달린 두 개의 크랭크: 왼쪽 위 눈 [92·232](반지름 28, 크랭크 축 자리)와 왼쪽 아래 눈 [47·295](반지름 25, 크랭크 핀) 을 짧은 두 겹 팔이 잇고(길이 77), 오른쪽 끝의 눈 [412·235](가장자리가 물결 모양 = 오른쪽 크랭크의 핀 자리)가 벽 근처에 있다.
2. 줄·벨트는? → 없음. 긴 막대(커플러) 1개: 왼쪽 아래 눈 [47·295] 에서 오른쪽 눈 [412·235] 까지 (길이 370).
3. 교차하는 가닥은? → 없음. 막대 위 [175·272] 에 작은 동그라미(표시점)가 있고 그 둘레에 점선 달걀 [155~305 × 175~290] 이 그려져 있다. 막대가 왼쪽 크랭크 눈 **앞**을 지난다.
4. 고정점은? → 판화에 선이 없다. 왼쪽 위 눈(크랭크 축)과 오른쪽 크랭크의 축은 고정. 오른쪽 세로선 [445] 는 벽(그림 가장자리).
5. 추·손잡이·크랭크는? → 왼쪽 크랭크(축 [92·232], 핀 [47·295], 길이 77)가 구동. 오른쪽 눈은 두 번째 크랭크.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 막대 오른쪽 눈 [412·235] 과 왼쪽 위 눈 [92·232] 이 거의 같은 높이(y 232~235).
8. 글자가 가리키는 부품은? → 글자 없음(번호 172 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화대로(왼쪽 크랭크 77, 막대 370, 오른쪽 눈이 막대 끝) 두 크랭크를 모두 한 바퀴 돌리려면 두 축 사이(약 323)가 가장 짧은 변이어야 하는데 그렇지 않아 오른쪽은 한 바퀴 돌 수 없고 **흔들이**(로커)가 된다. 점선 달걀의 크기(150×115 px)도 흔들이 쪽이 커야 나오므로, 오른쪽 크랭크를 짧은 팔의 흔들이로 보고 4절 링크로 만든다(막대 위 점의 곡선이 판화 달걀과 같은 크기·자리로 나옴을 숫자로 확인). → 질문 거리 없음(판화 기구를 가장 가깝게 푼 것).

## 해석(결정 사항)
- 4절 링크: 고정 변 = 크랭크 축 O1 ↔ 흔들이 축 O2, 크랭크 a = 0.58, 막대 L = 2.774(판화 370 px), 흔들이 c = 0.9. 흔들이 축은 오른쪽 눈의 바로 아래(판화에 없음, 오른쪽 크랭크의 보이지 않는 반)에 둔다.
- 1 px = 0.0075. 막대 위 표시점 비율 s = 0.35(판화 [175·272]). 점이 그리는 달걀 가로 1.13 × 세로 0.8(판화 1.12 × 0.86).
- 회전 방향은 판화에 없다 → 크랭크 반시계.
- 판화에 없는 보충: 두 축의 뒤판 보스(shaftZ), 달걀 궤적 점선(고정 장식), 흔들이 눈과 핀 머리.

## 구동
크랭크(theta 누적, 반시계). theta += OMEGA(1.6)·speed·dt. 한 바퀴 3.93 s 에 달걀을 한 번 돈다. 자세는 모두 `four172(theta)` 의 닫힌 식(원 교점).

## 부품과 치수 (새 부품은 `kit/k172.ts`, 이미 구현됨. 상수 `K172`)
배치: O1 = (−1.185, 1.85), 크랭크 시작각 −125.5°, O2 = (1.215, 0.9275), 층: 크랭크·흔들이 z 0.08~0.14, 막대 z 0.16~0.22, 핀 z 0.06~0.27, 달걀 점선 z 0.30.
- 크랭크(name `crank`): `linkPlate172(a, 0.06, 0.05)` 길이 0.58, 원점 = O1, rotation.z = phi. 자식 핀 `pinA`(로컬 (0.58,0), 반지름 0.03, 머리 반지름 0.05).
- 막대(name `rod`): 같은 판 길이 L = 2.774, 반폭 0.06, 원점 = A, rotation.z = 방향각. 자식 표시점 `tracer`(비율 0.35).
- 흔들이(name `rocker`): 판 길이 0.9, 원점 = O2, rotation.z = O2→B 방향각. 자식 핀 `pinB`(로컬 (0.9,0)).
- 축 2개(고정): `shaftZ(O1, 0.2, 0.045)`, `shaftZ(O2, 0.2, 0.045)`.
- 달걀 점선 `egg`: 반지름 0.012 점 48개(한 바퀴 위 표시점 자리).
- 받침대·뒤판 `displayStand()`.
- 전체 범위: x −1.52 ~ 1.5, y 0.88 ~ 2.7.

## 동작 (theta 의 닫힌 식 — `four172(theta)` = { phi, A, B, P, rodAng, rockAng })
phi = −125.5° + theta. A = O1 + a(cos, sin). B = 원(A, L) ∩ 원(O2, c) 중 위쪽 해. P = A + 0.35(B − A).
대입: `crank.rotation.z = phi`, `rod.position = A`, `rod.rotation.z = rodAng`, `rocker.rotation.z = rockAng`. 모두 같은 변수에서 나오므로 핀·눈이 어긋나지 않는다.
시각: t = 1 (theta 1.6), t = 1.6, t = 3 , t = 30.

## 표시
- rotArrow(0.32, true) 를 (O1, z 0.34) 에(반시계).
- tag 4개(z 0.35): '구동 크랭크' (−1.55, 2.75), '막대(커플러)' (0.3, 1.0) 막대를 가리킴, '흔들이' (1.55, 0.5) 흔들이를 가리킴, '달걀 궤적(점선)' (−0.2, 2.5).
- view: position (0, 1.7, 6.4), target (0, 1.6, 0).

## notes
① 크랭크 각(도) ② 흔들이 각(도) ③ '표시점 궤적 가로 1.13 × 세로 0.80' ④ 막대 길이 2.774 (항상 일정).

## 확인
- t = 1 정면: 판화처럼 크랭크가 왼쪽 아래로, 막대가 오른쪽 위 눈으로. 표시점이 점선 달걀 위. t = 1.6/3: 표시점이 달걀을 따라 도는지.
- 근접 `cam=-1.2,1.7,1.5,-1.2,1.7,0.1`(크랭크), `cam=1.2,1.3,1.5,1.2,1.2,0.1`(흔들이).
