# 065 탭핏 구동 간헐 회전 (원문: 탭핏 구동 간헐 회전, tappet-driven intermittent rotation)

## ★ 판화 읽기
(S1b 교차 읽기 — 설계표를 보기 전에 판화 `public/mm507/fig/065.png` 와 507movements.com 의 원본 그림을 따로 읽었다. 결과: 기구 구성은 일치, **스터드 수 11 → 10, 탭핏 모양·길이, 정지 레버 코의 자리(D 바로 아래)를 고침** — 동작 수치를 모두 다시 풀었다.)
1. 바퀴는 몇 개이고 크기 차례는? → 같은 크기의 민 원판 2개가 가로로 나란히, 테두리가 거의 닿는다(이는 없다). 왼쪽 C(구동), 오른쪽 D. D 에는 가장자리 가까이 둥근 스터드가 **10개**, 같은 간격(36°)으로 박혀 있다(판화 각: 0°, 36°, 70°, 105°, 144°, 180°, −145°, −113°, −75°, −38° — 손 판화의 오차 안에서 36° 간격, 쉬는 자리에 스터드 하나가 정확히 C 쪽(180°)에 있다).
2. 줄·벨트는 몇 개인가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 두 원판의 축(해칭 원), 그리고 두 원판 아래 사이의 정지 레버 받침점(해칭 원, 둘레에 고리).
5. 추·손잡이·크랭크는? → 없음. 구동은 C 의 축.
6. 무엇이 무엇과 닿는가? → ① 탭핏 A(C 에 고정, C 허브에서 뻗어 **C 테두리를 넘어** D 의 스터드 원 안쪽까지 닿는 쐐기 모양 팔 — 허브 쪽이 넓고 끝이 가늘고 둥글다) ↔ D 의 스터드. ② 정지 레버의 코(D **바로 아래**, 스터드 두 개 사이로 올라온 세모 이) ↔ 스터드. ③ 정지 레버의 꼬리(왼쪽 끝) ↔ C 의 테두리·홈(C 오른쪽 아래, 판화 각 −75° ~ −44°).
7. 한 줄에 놓인 것은? → 두 원판 중심이 같은 높이. 레버 받침점은 두 원판이 만나는 자리의 바로 아래. 코는 D 중심의 바로 아래(약간 왼쪽).
8. 판화의 글자는? → A = 탭핏, C = 왼쪽 구동 원판, D = 오른쪽 스터드 원판. 화살표: C 시계, D 반시계.
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → 없음. 판화의 순간 = 탭핏이 스터드를 치기 직전(탭핏이 중심선보다 약 11° 위), 홈이 레버 꼬리를 마주 보는 때. 탭핏이 미는 것만으로는 한 칸(36°)의 78%(28.2°)까지만 가고, 나머지는 C 테두리가 꼬리를 눌러 **쐐기 코가 다음 스터드 틈으로 올라오며** 채운다고 해석했다(원문 "the lever is again forced up in front of next stud"). 스포크(원판의 살)는 **판화에 없음** — 회전이 보이게 하는 보충.

원문 요지: C 가 한 바퀴 돌 때마다 탭핏 A 가 D 의 스터드 하나를 쳐서 D 가 스터드 한 칸(1/10 바퀴)만 돈다. 더 가지 않게 정지 레버가 있다. 탭핏이 스터드를 치는 순간 C 의 홈이 레버 쪽을 향해 레버 한쪽 끝이 홈으로 들어갈 수 있고, 그동안 D 가 돌면서 스터드가 코를 밀어 낸다. 탭핏이 스터드를 떠나는 즉시 C 의 둘레가 레버 다른 끝을 눌러 코가 다음 스터드 앞으로 올라와 D 를 잡는다.

## 구동
C 의 각 theta += OMEGA·speed·dt (OMEGA 는 1.6, 시계). 나머지는 모두 theta 의 함수(누적 절대 자세).

## 해석(결정 사항)
- 판화 그림 1개 → 그것을 만든다. 원판 두 개는 이로 물리지 않고, 구동은 오직 탭핏↔스터드 접촉, 정지는 레버↔스터드 접촉이다.
- 한 바퀴(2π) 중 D 는 한 번만(1/10 바퀴, 36°) 움직이고 나머지는 레버 코에 막혀 정지.
- 탭핏 접촉이 끝난 뒤(28.19°) 남은 7.81° 는 짧은 '마저' 구간(τ 1.7905~1.9905)에 채운다 — 쐐기 코가 틈으로 올라오며 밀어 맞추는 것으로 본다.
- 탭핏·스터드·레버의 앞뒤(z) 층을 나눠 탭핏이 레버를 지나쳐 가도 겹치지 않게 한다(아래 z 표).

## 동작 (모두 theta 의 함수)
상수: 스터드 간격 36°(2π/10), 쉬는 자리 ψ0 은 180°(스터드 0 의 각, D 중심 기준), 스터드 반지름 ρ 0.05, 탭핏 길이 1.25, 허브 반폭 0.085, 끝 반폭 0.03.
탭핏 앞가장자리(미는 변)는 (0, −0.085) 와 (1.22, −0.03) 을 잇는 직선: 축선과 이루는 각 δ 는 atan(0.055/1.22) → 2.581°, 원점에서 그 직선까지 거리 hE 는 0.085·cos δ → 0.0849, 직선 위에서 닿을 수 있는 끝은 1.2251(수선의 발에서 잰 길이).
- τ 는 theta mod 2π, n 은 floor(theta/2π)(몇 번째 바퀴).
- C: `C.rotation.z` 는 −theta (시계). 탭핏은 C 의 자식(로컬 각 87.741°)이라 축선의 세계 각 a(τ) 는 87.741° − τ.
- 접촉 풀이: 스터드 중심의 각이 D 중심 기준 ψ 일 때 C 중심 기준 극좌표 (r, p): r 은 |D + 0.83(cosψ, sinψ) − C|, p 는 atan2(…). 앞가장자리가 스터드를 밀 때 축선 각 a 는 p + asin((hE + ρ)/r) − δ 이고, 접촉이 유효한 조건은 √(r² − (hE + ρ)²) ≤ 1.2251. 접촉 시작 ψ 180°(a 는 4.662°), 접촉 끝 ψ 208.19°(a 는 −14.846°). ψ 를 이분법으로 풀어 τ → ψ 표를 만든다(64개 표본).
- 구간 시간표(τ, rad):
  | 구간 | τ | D 이동 g(τ) | 탭핏·레버 |
  |---|---|---|---|
  | 쉼 | 0 ~ 1.45 | 0 | 코가 스터드를 막고 있음(판화의 순간은 τ 1.345) |
  | 접촉(밀기) | 1.45 ~ 1.7905 | ψ(τ) − ψ0 (0 → 28.19°) | 탭핏 앞가장자리가 스터드를 밂, 스터드가 코를 밀어 내림(꼬리는 홈으로) |
  | 마저 | 1.7905 ~ 1.9905 | 3차 에르미트 28.19° → 36°, 끝 속도 0, 시작 속도 1.920 | 탭핏은 스터드를 떠남, C 테두리가 꼬리를 눌러 코가 올라오며 맞춤 |
  | 쉼 | 1.9905 ~ 2π | 36° 고정 | C 둘레가 꼬리를 눌러 코를 올려 둠 |
  접촉 구간 표본(τ : g°) — 1.450:0, 1.493:3.13, 1.535:6.27, 1.578:9.45, 1.620:12.73, 1.663:16.15, 1.705:19.80, 1.748:23.76, 1.7905:28.19.
  에르미트: s 는 (τ − 1.7905)/0.2, g 는 h00·gC + h10·0.2·gC′ + h01·(36°) (끝 속도 0), gC 는 0.4920 rad, gC′ 는 1.920(무차원).
- D: `D.rotation.z` 는 ψ0 + n·36° + g(τ) (반시계). 매 바퀴 한 칸씩 누적되며 역회전(speed<0) 때도 theta 의 함수라 되돌아간다.
- 레버: u 는 g(τ)/36° (0~1, 접촉·마저 구간에서만), `lever.rotation.z` 는 λ, λ 는 −0.14·sin(π u) rad (구간 밖은 0; 시계 방향이 코가 내려가고 꼬리가 올라가는 쪽). 최대 −8.0°.
- 근거와 검증(스크립트 `shots/_verify/s065.mjs` — 교차 읽기 뒤 스터드 10개·쐐기 탭핏으로 다시 돌렸다):
  - g 는 단조(역행 없음), 한 바퀴 끝에 정확히 36°.
  - 탭핏 쐐기 윤곽 × 스터드 원 겹침: 전 주기 최소 틈 0(접촉뿐, 침범 없음).
  - 레버 코 쐐기 × 스터드 원: 위 λ(u) 식으로 전 주기 최소 틈 +0.0132(침범 없음). 필요한 최소 후퇴각 곡선(u 0.2 에서 −2.52°, 0.45~0.5 에서 −7.33°, 0.85 에서 −0.92°)보다 크다.
  - 꼬리 윗가장자리 × C 홈 바닥(깊이 0.13): 최소 틈 +0.0003(쉴 때 닿음) — 홈 안에서 박히지 않음.
