# 082 두 발판으로 돌리는 래칫
판화(public/mm507/fig/082.png, 확대 shots/_verify/082-fig-x4.png · 082-pawls-x10.png · 082-right-x8.png · 082-wheel-x6.png 로 다시 읽음): 그림 하나(옆에서 본 모습). 왼쪽 위에 큰 톱니 바퀴 A(톱니 약 30개). 바퀴 축에서 오른쪽으로 팔 B 둘이 부채처럼 벌어져 나간다 — 위 팔은 약 +16°, 아래 팔은 약 −27°. 팔 끝마다 작은 원(핀)이 있고, 거기서 바퀴 둘레를 따라 **위쪽(반시계 쪽)으로** 굽은 뾰족한 폴이 나와 톱니에 박혀 있다. 팔 끝 핀 바로 옆의 둘째 원은 아래로 내려가는 이음대의 고리다(위 팔의 이음대는 길고, 아래 팔의 이음대는 짧다). 바닥에는 왼쪽 받침대(낮은 단 위)의 축에서 오른쪽으로 긴 발판 D 둘이 뻗어, 하나는 올라가 있고 하나는 내려가 있다. 긴 이음대는 올라간 발판에, 짧은 이음대는 내려간 발판에 걸렸다. 오른쪽에는 두 기둥으로 된 틀이 서 있고 꼭대기에 풀리 C 가 **옆으로 누운 모습(좁은 네모)** 으로 그려졌으며, 틀 가운데로 세로 줄이 발판까지 내려온다.
원문 요지: 두 발판 D 를 번갈아 밟으면, 흔들리는 팔 B 와 거기 달린 폴을 통해 래칫 바퀴 A 가 거의 끊김 없이 돈다. 발판마다 매단 사슬(띠)이 풀리 C 를 넘어가므로, 한쪽 발판을 밟으면 다른 쪽이 올라온다.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 2개. 래칫 바퀴 A(이끝 반지름 ≈ 0.94) ≫ 풀리 C(지름 ≈ 0.25, 옆으로 누워 보임).
2. 줄·벨트는 몇 개이고, 어디서 시작해 어느 바퀴의 어느 쪽을 지나 어디서 끝나는가? → 1개(사슬 또는 띠). 한 발판(받침축에서 발판 길이의 0.77 되는 곳)에서 곧게 올라가 풀리 C 의 **위쪽**을 반 바퀴 넘어 다른 발판의 같은 자리로 곧게 내려온다. 옆에서 본 그림이라 두 가닥이 겹쳐 한 줄로 보인다.
3. 교차하는 가닥이 있는가, 어디서? → 없음(두 가닥은 앞뒤로 나란하다). 두 발판은 받침축에서 가위처럼 벌어져 있을 뿐 서로 닿지 않는다.
4. 고정점은 어디인가? → 바퀴 축(판화에 받침 없음), 발판 받침대(낮은 단 위의 주철 받침), 풀리 틀 C(바닥에 발로 선 두 기둥).
5. 추·손잡이·크랭크는 어디에 달렸는가? → 없음. 사람이 발판 D 의 오른쪽 끝을 번갈아 밟는다.
6. 이는 어느 가장자리에 났고 무엇이 어느 쪽에서 물리는가? → 바퀴 A 바깥 둘레에 톱니(비대칭 톱니). 폴 둘은 바퀴 **오른쪽 둘레에서 바깥으로부터** 내려와 박히고, 폴 끝은 핀보다 반시계 쪽(위)에 있다 → 팔이 올라갈 때 폴이 톱니를 밀어 바퀴가 **반시계**로 돈다.
7. 한 줄에 놓인 것은? → 두 팔이 한 축(바퀴 축). 두 발판이 한 받침축. 풀리 C·줄·틀이 한 세로선. 위 팔의 핀과 이음대 고리는 팔의 연장선 위.
8. 글자가 가리키는 부품은? → A = 래칫 바퀴, B = 흔들 팔(두 팔 사이에 적힘), C = 풀리(틀 위), D = 발판(오른쪽 끝 두 막대 사이).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳은? → 없음. 판화로는 알 수 없는 것 둘을 아래처럼 정했다(운동은 어느 쪽이든 같다): ① 이음대 고리가 걸린 곳이 "팔 끝의 귀"인지 "폴의 꼬리"인지 → 팔 끝의 귀. ② 두 팔·두 발판의 앞뒤 순서 → 위 팔·긴 이음대·올라간 발판이 앞(판화에서 긴 이음대가 틀 기둥 앞을 지난다).
- 그 밖의 선: 톱니 방향은 판화로 가릴 수 없어 폴의 방향에서 정했다(곧은 면이 시계 쪽을 본다). 바퀴 안의 큰 원 = 테 안쪽 선. 틀 가운데 세로선 = 줄(두 가닥이 겹침), 그 아래 발판에 얹힌 반달 = 줄을 매는 고리. 바닥의 계단선 = 받침대가 선 낮은 단.

## 해석(결정 사항)
- **두 팔은 서로 다른 각 구역에서 흔들린다**(같은 구역이 아니다): 위 팔 3.1° ~ 15.6°, 아래 팔 −26.6° ~ −13.9°. 판화에서 두 이음대의 길이가 다르고(1.72 : 1.11), 발판의 움직임(이음대 자리에서 약 0.25)이 팔 끝에서 약 12.5° 에 해당하는 것과 맞는다. 판화는 "위 팔 꼭대기 · 아래 팔 바닥"의 순간.
- 바퀴 톱니 30개(12°). 발판 한 번 왕복에 폴 하나가 톱니 하나씩 → 한 왕복에 24°. 두 팔의 흔들림(12.50° + 12.70°)이 톱니 2개 + 헛걸음 2×0.6° 가 되도록 발판 진폭(±4.0°)을 이분법으로 정했다. 판화의 발판 벌어짐(약 7°)보다 1° 크다.
- 폴은 팔 끝 핀에서 바퀴 둘레 밖을 따라 굽어 가다가 코만 톱니 골로 내려온다(곧은 폴이면 뒤 톱니의 끝을 파고든다 — 판화의 굽은 모양이 그 때문). 위 폴의 중심각 18.8°(판화 약 20°), 아래 폴 24.4°(판화 약 22°)는 두 폴이 번갈아 0.6° 헛걸음으로 넘겨받도록 맞춘 값.
- 미는 폴이 꼭대기에서 돌아설 때 바퀴는 **뒤로 돌지 않고** 다음 폴이 닿을 때까지(구동각 약 0.3 rad) 제자리에 선다 → 원문의 "거의 연속".
- 치수를 바꾸면 `shots/_verify/s082.mjs` 를 다시 돌린다.

## 구동
발판 D(발로 번갈아 밟음). theta += OMEGA(1.6)·speed·dt. 키트에 넣는 각 θs = theta − 1.6 (t = 1 이 판화 자세). 발판 한 번 왕복 = 2π(3.93 s) 에 바퀴 24°(톱니 2개) → 바퀴 한 바퀴 58.9 s.

## 동작 (모두 `k82State(θs)` 의 값 — theta 의 절대 함수)
- 발판 기울기: g1 = −1.027° + 3.997°·cos θs, g2 = −1.027° − 3.997°·cos θs. `treadle1.rotation.z = g1`, `treadle2.rotation.z = g2`.
- 팔 각: 발판의 이음대 자리 T = F + ρ(cos g, sin g) 를 중심으로 반지름 = 이음대 길이인 원과, W 중심 반지름 = 귀 반지름인 원의 교점(W → T 의 왼쪽 해)이 귀 E. a1 = 3.10° ~ 15.60°, a2 = −26.60° ~ −13.90°. `arm1.rotation.z = a1`, `arm2.rotation.z = a2`.
- 바퀴: A1 = a1 + 18.8° + 24°·⌊(θs + π)/2π⌋, A2 = a2 + 24.4° + 36° + 24°·⌊θs/2π⌋, P = 직전에 돌아선 폴의 꼭대기 값. `wheelA.rotation.z = max(A1, A2, P)`. 큰 쪽이 지금 미는 폴(`pusher`).
- 폴: 미는 폴은 코가 이뿌리 구석에 있는 방향, 다른 폴은 코가 톱니 비탈에 닿는 방향(이분법, 톱니 하나를 넘을 때 약 13° 들렸다가 떨어진다). `pawl1.rotation.z = b1`, `pawl2.rotation.z = b2`.
- 이음대: 위치 T, rotation.z = atan2(E.y − T.y, E.x − T.x). 길이는 변하지 않는다(검사 선언 links).
- 줄: 앞 발판 고리 → 풀리 위 → 뒤 발판 고리. 풀리 회전(누운 그룹 안의 rotation.z) = `pulley` 값(= 앞 발판 줄 자리가 올라간 높이 ÷ 0.122, ±77°).
- 시각(t): **t = 1.0 (θs 0 — 판화 자세: 앞 발판·위 팔 꼭대기, 뒤 발판·아래 팔 바닥)**, **t = 1.6 (θs 0.96: 아래 폴이 미는 중, 위 폴은 비탈을 타고 내려감)**, t = 2.96 (θs π: 반대 끝), t = 4.93 = 판화 자세로 돌아옴(바퀴는 24° 더 돈 뒤).
