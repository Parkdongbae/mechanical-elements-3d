# 175 한 행정에 한 바퀴
원문: "A means of giving one complete revolution to the crank of an engine to each stroke of the piston." — 피스톤이 한 번 왕복하는 동안 크랭크가 정확히 한 바퀴 도는 장치다. 설명은 이 한 줄뿐이다(catalog 의 ko·easy 도 같은 내용).
판화 묘사: 받침 위에 선 주물 프레임 하나. 왼쪽은 낮게 솟아 위에서 큰 구멍 베어링(크랭크 축)을 감싼 아치로 끝나고, 오른쪽은 훨씬 높은 기둥으로 올라가 안쪽에 양끝이 둥근 세로 슬라이드 홈이 나 있다. 프레임 가운데는 네모난 창이 뚫려 있다. 아치 베어링에서 짧은 크랭크 팔이 내려와 팔 끝 핀에 연결 막대가 걸리고, 막대는 오른쪽 아래로 내려가 홈 속 피스톤 핀에 닿는다. 크랭크 축 둘레에 점선 원이 그려져 핀의 궤적을 보여 준다. 그려진 순간에는 축 · 핀 · 피스톤이 한 직선 위(하사점)다.

## ★ 판화 읽기
판화는 그림 하나(정면). 저장소 그림 `public/mm507/fig/175.png` 와 Brown 1871 스캔본 판 46(archive.org, `fig175-book.png`)을 4배 확대해 함께 읽음. 아래 px 는 스캔본 3배 확대 그림 기준.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 도는 것은 **크랭크 팔** 하나뿐(민 팔, 점선 원이 궤적). 부품은 프레임(고정) · 크랭크 · 연결 막대 · 피스톤 넷.
2. 줄·벨트는 몇 개이고 어디서 시작해 어느 바퀴의 어느 쪽을 지나 어디서 끝나는가? → 없음. 대신 연결 막대 하나: 위 눈은 크랭크 핀(축에서 오른쪽 아래 58°, 스캔 px (575·940)), 아래 눈은 홈 속 피스톤 핀(px (788·1160))에 걸린다.
3. 교차하는 가닥이 있는가, 어디서? → 없다. 겹침 차례: 연결 막대와 크랭크가 프레임 **앞**을 지난다(창 오른쪽 못과 기둥 왼쪽 못 위로 막대의 두 선이 이어져 그려진다). 크랭크 핀은 창의 왼쪽 위 모서리 바로 앞에 있다.
4. 고정점(천장·벽·바닥)은 어디인가? → 프레임 저체 전부: 빗금 바닥 위 받침, 왼쪽 아치의 베어링(크랭크 축), 오른쪽 기둥의 슬라이드 홈(피스톤의 안내면).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 크랭크 = 아치 베어링에 달려 도는 짧은 팔(끝에 핀). 추·손잡이 없음. 원문상 구동은 **피스톤**(행정이 크랭크를 돌린다).
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 맞닿는 짝: 크랭크 핀 ↔ 연결 막대 위 눈(회전 짝), 막대 아래 눈 ↔ 피스톤 핀(회전 짝), 피스톤 보스 ↔ 슬라이드 홈 두 옆벽(미끄럼 짝), 크랭크 허브 ↔ 프레임 베어링(회전 짝).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 크랭크 축 · 크랭크 핀 · 피스톤 핀이 **한 직선**(하사점 — 판화의 순간). 피스톤 핀과 홈은 같은 세로선. 창의 왼쪽 모서리와 왼 기둥 안쪽면이 이어진다.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 175 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구 해석은 원문과 같으나 **치수가 하나 모순된다**: 스캔으로 재면 축–홈 세로선 거리 285px, 크랭크 반지름 142px, 막대 306px 인데, 막대가 축–홈 거리 + 반지름(427px)보다 짧으면 핀이 점선 원의 왼쪽을 지날 수 없다(판화대로는 반 바퀴쯤에서 막대가 부러진다). → 모형 막대를 **1.30**(= 판화비 환산 0.99 에서 늘임)으로 정해 회전이 닫히게 하고, 크랭크 반지름을 0.46 → 0.36 으로 줄였다. 기구는 그대로 크랭크–막대–피스톤이라 질문 거리 없음.
- 그 밖의 선: 점선 원 = 크랭크 핀의 궤적(모형에서는 회전 화살표가 이 구실을 대신한다). 가운데 네모 창 = 주물 빼기 구멍(모서리가 크랭크 핀 뒤로 감긴다). 창 · 홈의 양 끝은 둥리다. 아치 바깥 지름은 점선 원보다 작아 점선이 아치 밖으로 조금 나온다. 받침 아래 빗금 = 바닥.

## 해석(결정 사항)
- 기구: 정식 크랭크–막대–슬라이더다. 홈이 피스톤의 실린더 구실을 하고, 피스톤 한 왕복 = 크랭크 한 바퀴(theta 주기 2π).
- 스캔 비를 그대로 옮기되 9번의 시정을 적용: 축–홈 거리 285px → 0.88, 크랭크 반지름 142px → 0.36(시정), 막대 306px → 1.30(시정), 홈 폭 44px → 0.15, 프레임 세로 900px → 2.92 (1px = 0.00325).
- 판화의 하사점 자세(핀이 축에서 −58° 방향, 판화 −60.7°)를 t = 1 로 맞춘다. 이 자세가 피스톤의 **아래사점**이다(위·아래사점에서 축·핀·피스톤이 한 직선이 되는 것도 판화와 같다).
- 회전 방향은 판화에 없다 → 크랭크 반시계로 정한다. 피스톤이 내려가는 행정(아래사점 → 위사점 아님 — 아래 참고)에 크랭크가 반 바퀴, 올라가는 행정에 나머지 반 바퀴.
- 피스톤 행정: 아래사점 0.512, 위사점 1.590 — 행정 1.078. 홈(0.42~2.86)의 아래쪽 절반만 쓴다(판화에서도 피스톤이 홈 아래쪽에 있다).
- 프레임 윤곽의 완만한 곡선(발 팔이 벌어진 받침, 아치·안장의 곡선)은 직선·호로 단순화했다(안목 검증 항목).

## 구동
모형에서는 크랭크를 구동 부품으로 theta 를 쌓는다(원문의 피스톤 구동과 같은 운동을 거꾸로 재생 — 모든 자세는 theta 하나의 닫힌 식). theta += OMEGA(1.6)·speed·dt. 한 주기 2π = 3.927 s 에 크랭크가 한 바퀴 도는 동안 피스톤이 한 번 왕복한다.

## 동작 (모두 theta 의 닫힌 식 — `pose175(theta)` 가 { phi, pin, linkAng, piston } 를 돌려준다)
- 크랭크: phi = theta − 2.6123 → `crank.rotation.z = A.phi`. 핀 P = O + 0.36·(cos phi, sin phi).
- 피스톤: 홈 세로선 위의 y = P.y − sqrt(L² − (0.33 − P.x)²) → `piston.position.set(0.33, y, 0.06)`.
- 연결 막대: `link.position.set(P.x, P.y, 0.165)`, `link.rotation.z = A.linkAng` = atan2(y − P.y, 0.33 − P.x).
- 사점: phi = −58.0° 가 아래사점(피스톤 0.512 — 판화 자세 · t = 1), phi = 160.0° 가 위사점(1.590). 사점에서 축·핀·피스톤이 한 직선이 된다. 행정 1.078.
- 피스톤 속도는 사점에서 0 이고 중간에서 가장 빠르다(정식 크랭크–슬라이더의 부등 속도).
- 시각: **t = 1 (phi −58.0°, 아래사점 — 판화 자세, 피스톤 0.512)**, **t = 1.6 (phi −3.0°, 핀이 오른쪽 수평 근처, 피스톤 0.710)**, t = 2.2 (phi 52.0°, 피스톤 1.083), t = 30 (theta 48 → phi 80.5°, 피스톤 1.266).

## 확인
- t = 1 정면: 판화와 같은 모양(핀이 축에서 오른쪽 아래 58°, 축·핀·피스톤이 한 직선, 핀이 창의 왼쪽 위 모서리 앞, 피스톤이 홈 아래쪽). t = 1.6: 핀이 오른쪽 수평으로 오르고 피스톤이 0.20 올라감. t = 2.2: 핀이 위쪽, 피스톤 1.08.
