# 021 도르래 배열 (21)
판화: 들보 갈고리에 위 도르래 F 하나, 그 왼쪽 아래에 도르래 M 하나가 매달린다. 줄은 두 개 — 줄 1 은 아래 추의 오른쪽 걸이에서 올라가 F 를 넘어 왼쪽으로 내려와 M 의 윗 눈(M 을 매다는 줄)에 맨다. 줄 2 는 추의 왼쪽 걸이에서 올라가 M 의 오른쪽 → 위 → 왼쪽으로 감기고, M 왼쪽에서 아래로 늘어진 자유 끝이 된다. 추는 넓은 통 모양.
구동: M 왼쪽 자유 끝을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 판화에는 고정점에 맨 줄이 없으므로 책의 2ⁿ 규칙(움직도르래 1개 → 2배)이 아니라 연결을 그대로 계산한다 — 추를 줄 1(장력 2T) 쪽과 줄 2(장력 T) 쪽이 함께 받쳐 이득은 3배(자유 끝이 3u 내려갈 때 추가 u 오름). notes 에 "3배"를 보이고 판화 연결의 계산값임을 밝힌다. 줄은 모두 수직으로 그린다(자유 끝의 비스듬함은 무시).

## 부품과 치수
`rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)와 `weight`, `rod`, `rotArrow`, `tag` 를 쓴다. 줄 반지름 0.014, 줄 z = 0.22, 도르래 중심 z = 0.22, `Rope` 2개(r1, r2). 상수 `Z = 0.22`.
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [0])` → 고리 아랫점 (0, 2.94, 0.22).
- F: `pulleyBlock(0.26, { hookUp: 0.06 })`, 중심 (0, 2.60). 윗 눈 (0, 2.92) 과 고리 (0, 2.94) 를 `rod(…, 0.008)` 로 잇는다.
- M: `pulleyBlock(0.22, { hookUp: 0.06 })`, 중심 (−0.26, yM). 윗 눈 (−0.26, yM + 0.28) 이 줄 1 의 끝.
- 추: `weight(0.78, 0.26)`, 중심 (0.11, yb − 0.13) (yb = 추 윗면 높이). 윗면 걸이 두 곳 (x = 0.26, −0.04)에 steel 토러스 눈고리(반지름 0.025, 관 0.008, 축 Z)를 높이 yb + 0.03 에 단다. `weight()` 가 가운데 윗면에 붙이는 고리(첫 자식 `children[0]`)는 눈고리와 겹치므로 `visible = false` 로 숨겨도 된다.
- 자유 끝에 `ropeEnd()`, 위치 (−0.48, yF).

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `u = 0.10 × p` (추가 오른 높이).
- yb = 0.64 + u
- yM = 1.55 − u (M 은 추가 오를 때 u 내려온다 — 줄 1 의 추 쪽이 u 짧아지므로)
- yF = 0.95 − 3u (자유 끝; 시작 0.95, 끝 0.65)

### 줄 경로 (z = 0.22, `arcPoints(c, r, a0, a1, 0.22)`, a1 < a0 이면 시계방향)
- 줄 1: (0.26, yb + 0.03) → (0.26, 2.60) → `arcPoints([0, 2.60], 0.26, 0, π, Z)` (F 위를 반시계로 넘음) → (−0.26, 2.60) → (−0.26, yM + 0.28).
- 줄 2: (−0.04, yb + 0.03) → (−0.04, yM) → `arcPoints([−0.26, yM], 0.22, 0, π, Z)` (M 위를 반시계로 넘음) → (−0.48, yM) → (−0.48, yF).
- 줄 길이 검산(항상 성립해야 함): 줄 1 수직 합 = (2.60 − yb − 0.03) + (2.60 − yM − 0.28) = 2.70 (상수), 줄 2 = (yM − yb − 0.03) + (yM − yF) = 1.48 (상수).

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, u, yb, yM, yF 를 다시 계산해 부품 위치·줄을 갱신(절대 자세).
- 도르래 각(`userData.sheave.rotation.z`, 반시계 +):
  - θ_F = +u / 0.26 (줄 1 오른쪽 가닥이 u 올라감)
  - θ_M = +2u / 0.22 (줄 2 는 M 에 대해 양쪽이 2u 씩 상대 이동: 추 쪽 +u + M 하강 u)
- 이득 3: 자유 끝이 3u 내려갈 때 추가 u 오른다 (M 은 u 하강).

## 표시
- `rotArrow(0.32, true)` 를 F 앞 (0, 2.60, 0.40) 에(F 는 반시계).
- tag 'F 고정 도르래'(1.15, 2.72), 'M 움직도르래'(−1.15, yM + 0.1), '짐'(0.95, yb − 0.13), '당기는 곳'(−1.0, yF), z 0.4. 움직이는 것은 매 프레임 따라간다.
- notes: `[{ label: '이득', value: '3배 (판화 연결을 계산한 값)' }, { label: '당긴 줄 : 오른 높이', value: (3u).toFixed(2) + ' : ' + u.toFixed(2) }, { label: '책의 2ⁿ 규칙', value: '고정점에 맨 줄이 있을 때(019·022)에 맞다' }]`

## 확인
- t=0.4 (p ≈ 0): 추 윗면 0.64, M 높음(1.55), 자유 끝 0.95. t=3.9 (p ≈ 1): 추 0.10 상승, M 0.10 하강, 자유 끝 0.30 하강(0.65).
- F·M 모두 반시계, M 이 F 보다 약 2.4배 빠르게 돈다(2u/0.22 대 u/0.26). 줄 가닥 x 는 0.26, −0.04, −0.26, −0.48 로 서로 다르고 겹쳐 박히지 않는다. M 윗 눈과 줄 2 가 M 위에서 부딪치지 않는다.
