# 168 홈 크랭크와 타원 궤도
원문: "The slotted crank at the left hand of the figure is on the main shaft of an engine, and the pitman which connects it with the reciprocating moving power is furnished with a pin which works in the slot of the crank. Intermediate between the first crank and the moving power is a shaft carrying a second crank, of an invariable radius, connected with the same pitman. While the first crank moves in a circular orbit, the pin at the end of the pitman is compelled to move in an elliptical orbit..." — 왼쪽의 홈 크랭크는 기관 주축에 붙고, 왕복 동력과 이어진 피트먼(연결 막대)의 끝 핀이 그 홈 안에서 움직인다. 중간 축의 둘째 크랭크(반지름 일정)도 같은 피트먼에 물린다. 홈 크랭크는 원을 돌지만 피트먼 끝 핀은 타원 궤도를 그린다.

## ★ 판화 읽기
1. 바퀴: 없음. 크랭크 둘 — 왼쪽 홈 크랭크(주축, 긴 홈 있는 막대), 가운데 둘째 크랭크(짧은 팔 + 핀, 점선 원).
2. 줄·벨트: 없음.
3. 교차: 피트먼은 홈 크랭크 앞, 둘째 크랭크 핀을 지나 오른쪽 끝 눈에서 끝난다(핀 둘레는 앞뒤 층).
4. 고정점: 주축, 둘째 크랭크 축(둘 다 판화에 받침 없음 — 뒤판 핀으로 보충), 오른쪽 위로 이어지는 막대(왕복 동력)의 위 지점(판화에서 잘림 — 위 고정 핀으로 보충).
5. 동력: 오른쪽 끝의 세로 막대가 피트먼 오른끝(P3)에 달려 왕복한다.
6. 기어: 없음.
7. 한 줄: 피트먼 막대 한 직선 위에 홈 핀 P1 · 둘째 크랭크 핀 P2 · 오른끝 P3 가 있다. 큰 점선 타원은 주축을 에워싼다.
8. 글자 없음(번호 168 뿐).
9. 판화와 원문의 불일치 없음. 판화의 세로 막대는 위 핀에 매달린 흔들이 막대로 읽는다(P3 는 호를 따라 오른쪽에서 왕복). 판화 치수대로는 오른끝이 세로 직선 슬라이드면 둘째 크랭크가 돌 수 없어(막대 길이 모자람) 흔들이 막대로 해석 — 기구는 같다. 질문 거리 없음.

## 해석(결정 사항)
- 4절 기구: 둘째 크랭크(P2 가 원) — 피트먼(P1–P2–P3 직선) — 흔들이 막대(위 핀 H 에서 P3). 피트먼 연장점 P1 이 세로로 긴 타원을 그리고, 그 핀이 홈 크랭크의 홈에서 미끄러져 홈 크랭크(주축)를 돌린다.
- 구동은 주축(홈 크랭크) 각 alpha = theta + alpha0 로 정하고 둘째 크랭크 각은 닫힌 형 표(거꾸로 표)로 푼다. P1 의 타원이 주축을 에워싸므로 주축이 한 바퀴 돌 때 모든 부품이 정확히 한 주기로 닫힌다.
- 회전 방향은 판화에 없다 → 반시계. t = 1 에서 홈이 위로 62°쯤 기운 판화 자세.

## 구동
theta += OMEGA(1.6)·speed·dt. 주축 각 alpha = theta − 0.52. 한 주기 2π = 3.927 s. 둘째 크랭크·피트먼·흔들이 막대가 종동(속도는 일정하지 않다 — 타원 효과).

## 부품과 치수 (새 부품은 모두 `kit/k168.ts`, 이미 구현됨. 치수 상수 `K168`)
- 홈 크랭크(name `crank1`): 허브 눈(구멍 0.05, 바깥 0.11) + 길이 0.78 가늘어지는 팔 + 홈(가운데선 0.24~0.68, 반폭 0.036). 주축 O1 (−1.25, 1.59). z 0.06~0.105.
- 둘째 크랭크(name `crank2`): 축 S2 (−0.10, 1.55), 반지름 0.33, 핀 P2 달림(핀 r 0.027). z 0.06~0.105.
- 피트먼(name `pitman`): 눈 셋 P1 · P2(P1+1.15) · P3(+1.50), 길이 2.65, 막대 가늘어짐. z 0.13~0.18. P1 핀(홈에 꽂힘)·P3 핀 달림.
- 흔들이 막대(name `rocker`): 위 핀 H (1.45, 2.95), 길이 1.45. z 0.19~0.24.
- 고정 핀 셋(뒤판에서 나옴, 판화에 없음): `axisMain` `axis2` `hPin`.
- 점선 궤적 셋(뒤판에 칠함): P1 타원, 둘째 크랭크 핀 원, 주축 둘레 원(반지름 0.46).
- 받침대·뒤판 `displayStand()`. 전체 가로 −1.95~1.8, 세로 0.9~3.0.

## ★ 깊이 계산
z −0.25~0.265(P3 핀 머리). 판은 층: 크랭크 0.06~0.105, 피트먼 0.13~0.18, 흔들이 막대 0.19~0.24, 핀 머리 ≤ 0.265, 화살표·이름표 0.3. 최대 z 0.3 ≤ 0.8.

## 동작
모두 alpha 의 닫힌 식 `pose168(theta)`: phi = 거꾸로 표(alpha), P2 = S2 + r2(cos phi, sin phi), P3 = 원(P2, 1.5) ∩ 원(H, 1.45) 의 아래쪽 교점, P1 = P2 + 1.15·(P2 − P3)/1.5. `crank1.rotation.z = alpha`, `crank2.rotation.z = phi`, `pitman` 은 P1 에 놓고 rotation.z = atan2(P3 − P1), `rocker.rotation.z = atan2(P3 − H) + π/2`.
P1 이 주축에서 떨어진 거리 s 는 0.33~0.59 로 오르내린다. 시각: t = 1(판화 자세), t = 1.6, t = 30(주기 3.927 s 로 닫힘).
