# 188 분리 장치 변형 2
원문: "Modifications of 186." — 186 의 변형. 쉬운 풀이: 186 의 손잡이를 길고 둥글게 휘어진 모양으로 바꾼 것. 손잡이를 당기면 핀이 편심 막대에서 빠진다.
판화 묘사: 가로 편심 막대(왼쪽 끝이 끊김) 오른쪽에 둥근 혹 모양 덮개와 길게 가늘어지는 꼬리. 덮개 아래 가장자리에 핀(원). 막대 위 작은 원(받침)에 걸린 레버: 오른쪽 짧은 팔은 위로 올라 덮개 속으로 들어가 점선으로 핀 위까지 내려간다. 왼쪽으로는 길고 둥글게 말린 고리 손잡이가 위로 올라 크게 돌아 막대 위의 작은 받침대로 내려온다. 고리 안쪽에 글자 a(노치).

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 512×470 px, [x·y]).
1. 바퀴는? → 바퀴 없음. 핀 [340·272](반지름 13)뿐. 팔·흔들 축은 판화에 없음.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 레버 짧은 팔이 덮개 뒤로 지나간다(점선 [320~345·230~265]). 고리 손잡이의 위로 가는 가닥과 내려오는 가닥은 서로 닿지 않는다.
4. 고정점은? → 판화에는 없음(막대·덮개·레버 모두 움직이는 쪽). 핀이 달린 팔의 축을 보충한다.
5. 추·손잡이·크랭크는? → 고리 손잡이(레버의 긴 팔) [15~210·60~240], 받침 [250·240] 은 막대 위. 손잡이 끝은 막대 위 받침대 [105·240] 에 놓인다.
6. 기어는? → 없음. 핀이 막대 아랫면의 갭에 든다.
7. 한 줄에 놓인 것은? → 막대·받침·손잡이 받침대·핀이 한 수평선(y 240~272). 덮개 꼭대기가 핀 바로 위.
8. 글자가 가리키는 부품은? → a = 고리 손잡이 안쪽의 노치.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 원문은 "186 의 변형" 뿐. 핀이 막대 아랫면에 있어 팔은 아래의 흔들 축에서 올라오게 보충, 편심도 왼쪽에 보충. 노치 a 에 걸리는 상대 걸쇠는 판화로 알 수 없어 노치 자리만 표시. 질문 거리 없음.
