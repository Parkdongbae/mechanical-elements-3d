# 277 콜트 리볼버 실린더 회전 장치
원문(en): "Col. Colt's invention for obtaining the movement of the cylinder of a revolving fire-arm by the act of cocking the hammer. As the hammer is drawn back to cock it, the dog, a, attached to the tumbler, acts on the ratchet, b, on the back of the cylinder. The dog is held up to the ratchet by a spring, c." — 공이치기(해머)를 젖히는 동작만으로 회전식 총의 실린더를 돌리는 콜트 대령의 발명. 해머를 뒤로 젖힐 때 텀블러에 달린 도그 a 가 실린더 뒷면의 래칫 b 를 민다. 도그는 스프링 c 로 래칫 쪽에 눌려 있다.
쉬운 풀이: 해머를 젖히면 해머 축에 붙은 텀블러가 함께 돌고, 텀블러에 핀으로 달린 길쭉한 도그가 위로 올라가며 실린더 뒤 래칫의 이 하나를 밀어 실린더를 1/6 바퀴(60°) 돌린다 — 다음 약실이 해머 앞에 온다. 해머가 떨어질 때 도그는 래칫에서 물러나 내려왔다가 스프링에 눌려 다음 이 밑으로 다시 들어간다. (역사적 기계 운동 교육용 — 래칫·도그·실린더 분할 회전만 보이고 총 모양은 단순한 틀로.)
판화 묘사(원본 436×455 px, **옆면**): 왼쪽에 실린더 옆면(세로 빗금 [0~90·90~410], 축은 가로), 그 뒷면(오른쪽 면 x 90) 가운데 아래쪽에 작은 톱니(래칫 b, [90~108·255~300], 옆에서 본 모습). 오른쪽에 큰 해머(축 = 빗금 원 [245·322], 위로 뻗은 몸과 오른쪽 위 손잡이 끝 [400·45], 왼쪽 위 코 [200·65]). 해머 축 왼쪽 아래 둥근 귀에 작은 핀 a([178·343]) — 여기에 달린 가늘고 긴 도그가 왼쪽 위로 올라가 래칫에 닿음([100·210] 근처). 그 오른쪽 위에 빗금 친 덩이([110~160·120~195], 틀)에서 내려오는 판 스프링 c 가 도그 등을 누름. 오른쪽 아래 등자 고리와 선(주 스프링 고리, [360·290]).

## ★ 판화 읽기
판화 하나(옆면). 판화 1 px ≈ 0.0075(해머 축 ↔ 핀 a 70 px → 0.52). 실린더 뒷면 x 90 px ↔ 세계 x −0.70, 실린더 축 높이 ↔ 세계 y 1.85.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 실린더 1(반지름 0.50, 약실 6), 래칫 b 1(이 6, 끝 반지름 0.30, 실린더 뒷면에 붙음). 크기 차례: 실린더 > 래칫.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 도그·텀블러·해머가 서로 다른 깊이 층에서 겹쳐 보인다.
4. 고정점은? → 틀: 실린더 굴대(앞 기둥에 박힘), 해머 축(옆판에 박힘), 스프링 c 의 덩이(앞 기둥·가로 팔). 
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 해머 손잡이(오른쪽 위 끝)를 엄지로 젖힌다(시간표). 텀블러는 해머 축에 해머와 한 몸, 도그는 텀블러 핀 a 에.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 래칫 b 는 실린더 **뒷면**의 별 모양 판 — 바깥 가장자리에 이 6(곧은 이면 + 비탈). 도그 끝이 래칫 **앞쪽 옆**(보는 사람 쪽, 축에서 0.21~0.26 떨어진 곳)에서 이면을 아래에서 위로 민다. 실린더 축은 가로(x), 도그는 세로면(xy)에서 움직임 — 앞 옆에서 위로 밀면 실린더가 x 축 둘레로 돈다.
7. 한 줄에 놓인 것은? → 실린더 축·굴대·래칫 중심이 한 가로선 y 1.85(깊이 0.28). 해머 코가 맨 위 약실(y 2.22)과 같은 높이. 해머·텀블러·도그 회전축은 모두 z 방향(평행).
8. 판화에 글자(A, B…)가 가리키는 부품은? → a = 도그, b = 래칫, c = 판 스프링. 
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) 옆면 그림만으로는 래칫이 모서리로만 보여 미는 모습이 안 보인다 → 비스듬한 오른쪽 위 앞에서 보는 view 로 래칫 뒷면이 보이게. (나) 도그가 래칫의 축 높이 앞 옆을 밀려면 도그 층이 실린더 축에서 앞으로 0.21~0.26 나와야 함 → 해머(깊이 0.21~0.35) 앞에 텀블러 판(0.36~0.47), 그 앞에 도그(0.49~0.54). (다) 해머가 떨어질 때 도그가 다음 이를 넘어야 한다 — 실제 콜트는 이 모서리 모따기가 도그를 밀어내는데, 모델은 도그 끝을 래칫 뒷면 뒤(x −0.618)로 물렸다가(뒷면 위를 미끄러짐) 맨 아래에서 스프링이 다시 밀어 넣는 순서로 함(시간표 + 닿는 면). (라) 판화에는 실린더를 멈추는 걸쇠(실린더 볼트)가 없다 → 넣지 않음. (마) 스프링 c 의 덩이를 받칠 틀이 판화에 없다 → 앞 기둥과 가로 팔(앞 층) 보충. 질문 거리 1(도그 물러남), 2(실린더 볼트), 3(view).

## 해석(결정 사항)
- 좌표: 실린더 축 = (y 1.85, z 0.28) 의 x 방향. 래칫 면 좌표 (z′, y′) = (z − 0.28, y − 1.85), 각 α 는 +z′ 에서 +y′ 쪽으로.
- 실린더 각 ψ: `cylinder.rotation.x = −ψ`(ψ 가 늘면 앞쪽(+z) 이가 위로). 래칫 이면(곧은 면)은 ψ = 0 에서 α = −24° + 60°·j.
- 도그 끝 T(앞 윗모서리)가 미는 점: 도그 층 z′ = 0.21~0.26. 이면이 α ≥ 0 이면 안쪽 모서리(z′ 0.21), α < 0 이면 바깥 모서리(z′ 0.26)가 닿음 → **α = atan(y′_T/0.21)(y′_T ≥ 0) / atan(y′_T/0.26)(y′_T < 0)**. 한 번 미는 동안 α: −24° → 36°(= 60°), T 높이 y′ −0.1158 → 0.1526. 접점 반지름 0.21~0.285(이 뿌리 0.20 ~ 끝 0.30 안).
- 해머·텀블러: 축 H = (0.40, 1.22). 젖힘 각 β(시계 +). 핀 a: A(β) = H + Rot(−β)·(−0.482, −0.208).
- 도그: 길이 L = 0.88(A → T). T 의 x 를 정하면 T = (x_T, A_y + √(0.88² − (x_T − A_x)²)) — **닫힌 식**. 밀 때 x_T = −0.698(도그 앞면이 실린더 뒷면 −0.70 에 닿음, 틈 0.002), 내려올 때 x_T = −0.618(래칫 뒷면 −0.62 위를 미끄러짐, 틈 0.002).
- β: 0 → 8.163°(빈 행정, 도그 끝이 이면 밑으로 다가감) → 37.549°(이면을 밀어 ψ +60°). 떨어질 때: 높이를 y′ 0.1506 으로 지키며 x_T −0.698 → −0.618(β 37.549° → 29.193°) → x_T −0.618 로 β → 0 → 스프링이 x_T 를 −0.618 → −0.698 로(맨 아래, 다음 이면 밑).
