# 018 고정 둘·움직 하나 도르래
> **주의**: 아래 치수 중 일부는 2026-11-25 사용자 지적 수정으로 바뀌었다. 최신 값은 맨 끝 "사용자 지적 후 수정 (Opus, 2026-11-25)" 절이 우선한다.
판화: 들보 갈고리 한 곳에 고정 도르래 두 개가 세로로 포개져 매달리고(위가 조금 큼), 그 아래 멀리 작은 움직도르래 한 개에 추가 걸린다. 줄 하나가 이 세 도르래를 모두 감는다. 원문: 고정 도르래 둘과 움직도르래 하나를 결합한 것.
구동: 줄의 자유 끝을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 판화의 줄이 여러 가닥으로 보여, 가장 흔한 3:1 연결로 읽는다 — 줄 한 끝을 M 의 윗 눈에 매고, 위 도르래 P2 를 넘겨 M 밑을 돌고, P1 을 넘겨 자유 끝으로 내린다. 움직도르래 M 을 받치는 줄이 3가닥이라 이득이 정확히 3배다.

## 부품과 치수
016 의 `rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)를 쓴다. 파일이 없으면 016 의 '키트 추가' 대로 만든다. 줄 반지름 0.014.
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [0.0])` → 고리 아랫점 (0, 2.94, 0.22).
- 위 도르래 P1: `pulleyBlock(0.26, { hookUp: 0.06 })`, 중심 (0, 2.62), z = 0.15. 윗 눈 (0, 2.94) 가 고리와 맞닿는다(막대 불필요). 아랫 눈 (0, 2.30) 도 만든다(`hookDown: 0.06`).
- 아래 도르래 P2: `pulleyBlock(0.22, { hookUp: 0.06 })`, 중심 (0, 1.95), z = 0.30. P1 아랫 눈 (0, 2.30, 0.15) 과 P2 윗 눈 (0, 2.23, 0.30) 을 `rod`(반지름 0.008)로 잇는다.
- 움직도르래 M: `pulleyBlock(0.16, { hookUp: 0.06, hookDown: 0.06 })`, 중심 (0, yM), z = 0.225.
- 추: `weight(0.30, 0.26)`, 중심 (0, yM − 0.44). M 아랫 눈 (0, yM − 0.22) 에서 추 윗면 (0, yM − 0.31) 까지 `rod`.
- 줄: `Rope` 1개 + 자유 끝 `ropeEnd()`.
- 도르래 두께는 0.07(소도르래 M 은 0.06 가능). P1·P2·M 의 z 가 서로 달라 줄 가닥이 겹쳐도 박히지 않는다.

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `h = 0.25 × p`.
- yM = 0.85 + h
- yF = 1.60 − 3h (자유 끝; 시작 1.60, 끝 0.85)

### 줄 경로 (`arcPoints(c, r, a0, a1, z)`, a1 < a0 이면 시계방향). 점의 z 는 각 점에 적힌 값이고 직선 구간은 양끝 점 사이를 이으면 된다.
1. (0, yM + 0.22, 0.225) — M 윗 눈에 맨 줄 끝
2. (−0.22, 1.95, 0.30) — P2 왼쪽 끝점
3. `arcPoints([0, 1.95], 0.22, π, 0, 0.30)` — P2 위를 시계로 넘음
4. (0.22, 1.95, 0.30) → (0.16, yM, 0.225) — M 오른쪽 끝점
5. `arcPoints([0, yM], 0.16, 0, −π, 0.225)` — M 밑을 시계로 감음
6. (−0.16, yM, 0.225) → (−0.26, 2.62, 0.15) — P1 왼쪽 끝점
7. `arcPoints([0, 2.62], 0.26, π, 0, 0.15)` — P1 위를 시계로 넘음
8. (0.26, 2.62, 0.15) → (0.26, yF, 0.15) — 자유 끝(손잡이)

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, h, yM, yF 재계산.
- 도르래 각(반시계 +, `userData.sheave.rotation.z`), 모두 시계 방향:
  - θ_P2 = −h / 0.22
  - θ_M = −2h / 0.16
  - θ_P1 = −3h / 0.26
- M·추 = yM, 손잡이 = yF.

## 확인
- t=0.4 (p ≈ 0): 추가 아래, 자유 끝이 높다. t=3.9 (p ≈ 1): 추가 0.25 올라가고 자유 끝은 0.75 내려가 있다.
- P1·P2·M 모두 시계로 돌고 M 이 가장 빠르게(각속도 비 P2 : M : P1 = 1/0.22 : 2/0.16 : 3/0.26) 돈다. 줄 가닥이 도르래 모서리에서 서로 겹치지만 z 가 달라 박히지 않는다.

## 사용자 지적 후 수정 (Opus, 2026-11-25)
본문의 P1·P2·M **z 가 서로 다름**(0.15/0.30/0.225), 반지름 0.26/0.22/0.16, 중심 2.62/1.95, yM = 0.85+h, 눈 사이 `rod` 연결, 호별 `arcPoints` 경로는 모두 **옛 방식**이다. 판화는 세 도르래가 한 수직선·한 평면이므로 다음처럼 고쳤다.
- **P1·P2·M 모두 z = 0.22(들보 고리 z)와 x = 0 같은 선상**. 반지름 **P1 0.28 / P2 0.20 / M 0.17**. 중심 **Y1 = 2.60**, **Y2 = 1.97**, M 시작 **yM0 = 0.80**(yM = 0.80 + h), 자유 끝 yF0 = 1.60(yF = 1.60 − 3h). M 가닥이 P2 옆을 스쳐도 가닥 간 틈 ≥ 0.006 이 되게 반지름·높이를 정했다.
- **줄은 `ropeAround`(진짜 접선, seg 24, z 일정)**: M 윗 눈 → P2 위(시계) → M 밑(시계) → P1 위(시계) → 자유 끝(x = R1). `arcPoints` 직접 경로는 쓰지 않는다.
- **고리 사슬 이음**: 블록의 눈고리를 세워(yz 면, `turnEye`) 들보 고리 ↔ P1 윗 눈, P1 아랫 눈 ↔ P2 윗 눈(간격 LINK 0.03)이 서로 꿰이게 하고, 추 고리(꼭대기 추 중심 +0.208)도 M 아랫 눈에 직접 꿴다(WT_DY = RM + 0.06 + 0.208). **추 윗면~M 눈 사이 막대는 제거**.
- 도르래 각: P2 = −h/R2, M = −2h/RM, P1 = −3h/R1(모두 시계).
