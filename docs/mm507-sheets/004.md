# 004 같은 평면의 직각 전동
판화: 위에 큰 풀리 1개, 아래 양쪽 모서리에 작은 풀리 2개, 아래 가운데에 **수직축**의 홈 풀리(축이 아래로 삐죽 나옴). 벨트는 위 풀리에서 X자로 엇걸려 내려와 양쪽 아래 풀리를 돌고, 아랫가닥이 가운데 홈 풀리를 감고 지나 삼각형을 이룬다. 원문: 서로 직각이고 축선이 같은 평면에 있는 다른 축으로 운동을 전달한다. 여기서는 엇걸이 벨트, 열린 벨트를 써도 되지만 엇걸이가 더 잘 붙잡는다.
구동: 위 풀리.

## 부품과 치수
- `displayStand()`
- 풀리 T(구동, `driver: true`) r = 0.42, 중심 (0, 2.7), 회전축 Z, z = 0.25. `shaftZ(0, 2.7)`.
- 아래 안내 풀리 L, R: r = 0.2, 중심 (∓1.25, 1.05), 회전축 Z, z = 0.25, 각자 `shaftZ`.
- 가운데 홈 풀리 G(종동): `pulley(0.16, { grooved: true, spokes: 4 })` 를 **회전축 Y** 로 눕힌다(rotation.x = π/2 의 감싸는 그룹). 중심 (0, 0.85, 0.45). 축: Y 방향 둥근 막대(`rod`) y 0.35 ~ 1.0, 받침대 위 `pillow(0, 0.45, 0.45, …)` 대신 받침대에서 올라오는 작은 주철 브래킷(상자 0.3 × 0.12 × 0.3, castIron)을 y = 0.42 에 두고 축이 그것을 관통한다. 축 아래 끝은 판화처럼 브래킷 밑으로 0.08 삐죽 나온다.
- 벨트(폭 0.11, 두께 0.02) 경로 — 3D 점열을 직접 만든다:
  ① T 를 감는 호, ② T → R 왼쪽 가닥 / T → L 오른쪽 가닥이 **X자로 교차**(교차부는 002 처럼 두 가닥의 z 를 0.22 / 0.28 로 달리 함), ③ L·R 바깥 아래쪽을 감는 호, ④ 아랫가닥: L 밑점 (−1.25, 0.85, 0.25) → G 앞쪽을 감고(G 의 앞 반원 중 벨트가 닿는 부분, z = 0.45 + 0.16 = 0.61 에서 접함) → R 밑점 (1.25, 0.85, 0.25).
  아래 안내 풀리 밑점 높이 1.05 − 0.2 = 0.85 = G 중심 높이 → 아랫가닥은 수평.
  **띠의 폭 방향**: L·R·T 위에서는 Z 방향, G 위에서는 Y 방향. L→G, G→R 직선 구간에서 폭 방향을 Z → Y 로 부드럽게 돌린다(벨트가 1/4 비틀림) → 키트 추가 `widthDirs`.

## 키트 추가 (belt.ts)
- `BeltOpts.widthDirs?: THREE.Vector3[]` — 경로 점마다 띠의 폭 방향(단위 벡터)을 직접 준다. 없으면 기존 계산. `setPath` 에도 선택 인자 `widthDirs?` 를 받는다. (003 처럼 꼬이는 벨트도 이것을 쓸 수 있다.)
- `beltPathAround(circles: { c: V2; r: number; ccw: boolean }[], seg?: number): V2[]` — 평면 원 여러 개를 차례로 감는 닫힌 벨트 경로. `ccw` = 그 원을 반시계로 감는지(바깥/안쪽 접선을 자동 선택: 이웃한 두 원의 감는 방향이 같으면 바깥 접선, 다르면 안쪽(교차) 접선). 이 운동의 ①~③ 과 006 이 이것으로 경로를 얻는다.

## 동작
- T.rotation.z = theta. 벨트 속도 v = theta' × 0.42 → `belt.setOffset(theta * 0.42)`.
- L, R: 각 = −theta × 0.42 / 0.2 (엇걸이라 T 와 반대 방향, 둘은 같은 방향).
- G: 회전축 Y, 각 = theta × 0.42 / 0.16 (벨트 진행 방향과 맞게 부호를 정한다 — 아랫가닥이 −X → +X 로 흐르면 위에서 볼 때 반시계).

## 표시
- `rotArrow` T(반시계), G(수평면에 눕힌 화살표). tag '구동 풀리', '안내 풀리', '종동 풀리(수직축)'.
- notes: `[{ label: '축의 관계', value: '직각 · 같은 평면' }, { label: '벨트', value: '엇걸이' }, { label: '속도비', value: '1 : ' + (0.42/0.16).toFixed(2) }]`

## 확인
- 정면 t=1, t=1.6: T 의 표시점과 G 의 스포크가 돌았다. 벨트가 삼각형이고 위에서 X 자로 교차한다.
- 위에서 비스듬히 `cam=1.6,3.4,3.6,0,1.0,0`: 아랫가닥이 G 앞쪽을 감고, 띠가 G 위에서는 세로로 서 있다(비틀림).

## 검증 후 수정 (Fable, 2026-11-25)
- 밧줄(둥근), 위 교차 간격 0.10. 가운데 G 는 캡스턴 드럼(밧줄 3바퀴, 피치 2.9·ROPE_R), 드럼은 뒷면이 밧줄 평면에 접하게 GZ = Z0 + GR.
