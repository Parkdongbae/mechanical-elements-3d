# 118 행정을 두 배로 늘리기
원문 요지: 피스톤 막대의 행정(또는 크랭크의 던짐)을 **두 배로** 늘리는 방법. 연결봉(피트먼)에 붙은 축(스핀들)에서 도는 **피니언이 고정 랙과 물려** 있다. 피니언의 반대쪽에는 **위의 안내봉에 실려 앞뒤로 자유롭게 움직이는 또 하나의 랙**이 물린다. 연결봉은 피니언에 제 행정만큼만 준다 — 아래 랙도 움직일 수 있다면 윗랙은 그만큼만 가겠지만, 아래 랙이 고정이라 피니언이 굴러 돌고, 그래서 **윗랙은 두 배의 거리**를 간다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/118-fig-x4.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 피니언 1개(이 13개쯤, 바깥 지름 ≈ 원본 92px). 허브에 두 겹 원(스핀들과 연결봉 끝 눈). 다른 바퀴 없음.
2. 줄·벨트는? → 없음. 대신 랙 2개: 위의 랙(이 17개쯤, 아래로 향함, 몸통이 얇은 곧은 막대)과 아래의 랙(이 18개쯤, 위로 향함, 타원 창 3개가 난 받침대 위에 한 몸). 곧은 막대 1개(연결봉)가 왼쪽 아래에서 올라와 피니언 허브에 걸린다(왼쪽 끝은 파단선 — 그 너머의 크랭크는 그리지 않음).
3. 교차하는 가닥은? → 없음. 겹침 순서: 연결봉 끝이 피니언 **앞**에 걸린다(봉 끝 눈의 선이 피니언 이 위로 지나간다).
4. 고정점은? → 아래 랙의 받침대(발이 굵은 바닥선 위에 놓임 = 바닥에 고정). 윗랙의 안내봉은 원문에만 있고 판화에는 그려지지 않았다 — 모형은 위에 고정 안내봉 하나와 양끝 받침을 둔다(판화에 없음, 원문에 있음).
5. 추·손잡이·크랭크는? → 판화에는 없다. 구동은 연결봉(원문: 연결봉이 피니언에 행정을 전한다). 연결봉이 왼쪽으로 약 7° 처져 있으므로 그 끝에 크랭크가 있다고 보고, 모형은 왼쪽에 크랭크 원판을 둔다(판화에 없음 — 구동 보충).
6. 이는 어디에 났고 무엇이 물리는가? → 피니언은 바깥 이. **아래쪽에서 고정 랙(이가 위로)**, **위쪽에서 윗랙(이가 아래로)** 과 동시에 물린다. 두 랙의 피치선은 평행하고 피니언 지름만큼 떨어져 있다.
7. 한 줄에 놓인 것은? → 두 랙이 수평으로 평행. 피니언 중심이 두 피치선의 한가운데. 판화 순간에 피니언은 고정 랙 이 줄의 가운데에서 조금 왼쪽에 있다.
8. 글자가 가리키는 부품은? → 글자 없음(번호 118 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 판화에는 피니언 스핀들을 곧게 이끄는 안내가 없다(실제 기관에서는 피스톤 막대의 크로스헤드가 맡는다) → 모형은 뒤판에 가로 홈 레일을 붙여 스핀들 뒤 끝의 블록을 받친다(판화에 없음, 떠 있지 않게 하는 최소 보충). 기구는 같으므로 사용자 확인 불필요.
- 그 밖의 선: 받침대 안의 타원 3개 = 무게를 던 창. 받침대 위의 두 겹 선 = 랙 몸통과 받침대의 턱. 맨 아래 굵은 선 = 바닥. 윗랙 오른쪽 끝의 굵은 세로선 = 막대의 끝면(오른쪽으로 길게 나온 부분 = 일을 받는 쪽으로 가는 막대).

## 해석(결정 사항)
- 피니언 중심의 이동 s, 피니언 회전 −s/0.35(고정 랙 위를 미끄럼 없이 구름), 윗랙의 이동 = 2s. 순간 중심이 아래 접점이라 피니언 꼭대기 속도가 중심의 2배.
- 잇수: 피니언 14(판화 13개쯤 — 짝수로 해 위·아래 물림 위상을 같게), 랙은 각 10개(판화 17~18개 — 전시 폭 안에서 윗랙이 두 배로 움직일 자리를 남기려고 짧게).
- 구동 보충: 크랭크 반지름 0.25, 연결봉 길이 1.7(치우침 없는 크랭크) → 피니언 행정 0.50, 윗랙 행정 1.00. 판화의 순간(연결봉 왼쪽이 아래로 처짐, 피니언이 가운데보다 왼쪽)을 t = 1 로 맞춘다: 크랭크 각 −150°. 크랭크는 반시계.
- 크랭크·크랭크 축, 스핀들 뒤의 안내 레일·블록, 안내봉 받침은 판화에 없음(이름표에 '보충' 표시는 크랭크에만).

## 구동
크랭크(name `crank`, 판화에 없는 보충). theta += OMEGA(1.6)·speed·dt, 크랭크 각 a = theta − 1.6 − 150°(반시계). 한 바퀴 3.93 s 에 피니언·윗랙 한 번 왕복.

## 부품과 치수 (새 부품은 모두 `kit/k116.ts`, 이미 구현됨. 치수 상수 `K118`)
배치 상수: PX = 0.5(피니언 행정의 가운데 x), YP = 1.35(피니언 중심 높이), ZP = 0.1(랙·피니언 평면), ZROD = 0.215(연결봉 평면), CXC = −1.2(크랭크 축 x = PX − 1.7). 모듈 0.05.
- 고정 랙 + 받침대(name `bed`, 고정): `fixedRackBed118(0.7575)` 위치 (PX, YP − 0.35, ZP) = (0.5, 1.0, 0.1). 이 10개가 위로, 피치선 y = 1.0, 이뿌리선 0.9375, 받침대 바닥 y = 0.18(나무 받침 윗면에 선다). 가로 −0.415 ~ 1.415, 깊이 0.16. 황동 이 + 주철 받침대(타원 창 3개).
- 윗랙(name `rackTop`): `slidingRack118()` 위치 (PX + 2s, YP + 0.35, ZP) = (0.5 + 2s, 1.7, 0.1). 이 10개가 아래로, 피치선 y = 1.7, 몸통 윗면 1.8825, 반길이 0.797. 걸이 2개(랙 가운데에서 ±0.5)가 위 안내봉을 감싼다(고리 구멍이 x 방향). 청동(움직이는 쪽).
- 안내봉(고정, 원문에 있음): `hangerRod118(-0.68, 1.68, 0.1)` 위치 (0, 2.07, ZP). 반지름 0.035, 양끝 받침이 뒤판까지. 걸이가 다니는 범위 −0.56 ~ 1.56 이 받침(−0.69 ~ −0.61, 1.61 ~ 1.69) 사이.
- 피니언(name `pinion`): `rollingPinion118()` 위치 (PX + s, YP, ZP). 잇수 14, 피치 반지름 0.35, 이끝 0.40, 폭 0.10, 구멍 4개(회전이 보이게). rotation.z = −s/0.35. 청동.
- 스핀들 + 뒤 블록: `spindleBlock118(-0.35, 0.17, 0.115)` 위치 (PX + s, YP, ZP) — 돌지 않는다. 스핀들(반지름 0.046)이 뒤 블록에서 피니언 구멍·연결봉 눈을 꿰고 앞 너트까지. 자식 `spindle`(연결봉이 걸리는 자리, 키트가 이름을 붙여 둠).
- 뒤 안내 레일(고정, 판화에 없음): `slideRail118(0.4)` 위치 (PX, YP, −0.25) — 뒤판 앞면에 붙은 두께 0.10 의 홈 판. 홈 반길이 0.4, 반높이 0.07. 블록(반폭 0.10, 반높이 0.067)이 그 속을 ±0.25 다닌다.
- 크랭크 원판(name `crank`, 판화에 없음): `crankDisc118(0.17, 0.115)` 위치 (CXC, YP, ZP). 반지름 0.33, 핀이 로컬 +x 로 0.25. 자식 `crankPin`(키트가 이름을 붙여 둠). rotation.z = a. 청동.
- 크랭크 축: `shaftZ(CXC, YP, 0.185, 0.06)` — 뒤판 보스에서 원판 앞까지(끝 너트 z ≤ 0.185 라 연결봉 뒤로 지나간다). rotation.z = a.
- 연결봉(name `rod`): `pitman118()` — 눈 사이 1.7, 두께 0.05. 원점(한쪽 눈)을 크랭크 핀에 두고 +X 를 스핀들 쪽으로: 위치 (CXC + 0.25·cos a, YP + 0.25·sin a, ZROD), rotation.z = 봉 각. 강철.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위: 크랭크 원판 −1.53 ~ 윗랙 오른쪽 끝 1.797(안내봉 받침 벽판 1.74), 세로 0.18 ~ 2.16.

## 동작 (모두 theta 의 닫힌 식 — `state118(theta)` 가 돌려준다)
`const k = state118(theta)` → `{ a, pin, xp, s, roll, rack, rodAngle }`
- 크랭크·크랭크 축: rotation.z = k.a.
- 피니언 중심 x = PX + k.s, k.s = 0.25·cos a + √(1.7² − (0.25·sin a)²) − 1.7 (범위 −0.25 ~ +0.25). 스핀들·블록도 같은 x.
- 피니언 회전: `pinion.rotation.z = k.roll` (= −s/0.35, 오른쪽으로 갈 때 시계 방향). s = 0 에서 이가 정확히 위·아래를 향하고 두 랙의 가운데 이골에 든다(위상은 키트가 맞춰 둠 — 모델은 각을 더하지 않는다).
- 윗랙: `rackTop.position.x = PX + k.rack` (= PX + 2s, 범위 0.0 ~ 1.0).
- 연결봉: 위치 = 크랭크 핀 (CXC + k.pin[0], YP + k.pin[1]), `rod.rotation.z = k.rodAngle`. 기울기 최대 ±8.46°.
- 시각: **t = 1.0 (a = −150°, s = −0.221, 윗랙 −0.442, 봉이 오른쪽 위로 4.2° = 판화 자세)**, **t = 1.6 (a = −95°, s = −0.040, 윗랙 −0.080)**, t = 2.64 (a = 0°, 오른쪽 끝: s = +0.25, 윗랙 +0.5), t = 2.96 (a = 30°, s = +0.213).

## ★ 깊이 계산
깊이로 지름이 나오는 부품 없음(모두 뒤판과 나란한 판). 층: 뒤 안내 레일·블록은 뒤판 앞면에 붙은 두께 0.10 의 판(앞면 z = −0.2), 받침대 z 0.02~0.18, 랙·피니언 z 0.05~0.15, 크랭크 원판 z 0.06~0.14, 크랭크 축 끝 너트 z 0.13~0.185, 연결봉 z 0.19~0.24, 크랭크 핀·스핀들 끝 z 0.27~0.282, 화살표 z 0.3. 전부 −0.25 ~ 0.8 안. 흔들리는 팔: 연결봉(크랭크 핀을 따라감) → 최고 높이 = 1.35 + 0.25 + 눈 0.075 = 1.675. 가장 높은 부품은 안내봉 받침 벽판 윗면 2.16(≤ 3.3). 가로: 윗랙 끝 −0.797 ~ 1.797, 크랭크 원판 왼쪽 끝 −1.53(≤ 2.2).

(gain 은 "윗랙이 간 거리 ÷ 피니언 중심이 간 거리 = 2" 를 잰다 — 이 번호의 핵심. 침범 검사용 윤곽: 받침대 `userData.outlines.rackLower`, 윗랙 `userData.outlines.rackUpper`, 피니언 `userData.outline`(한 평면이라 랙과의 침범이 자동으로 돈다), 블록 `userData.outline` 과 레일 `userData.outlines.slot`(구멍으로 읽히는 이름 — 블록이 홈 안에 있는가). 주의: 레일·블록 평면(z −0.25)과 랙·피니언 평면(z 0.1)의 차 0.35 는 autocheck 가 "다른 층"으로 보는 0.3 보다 커야 한다 — ZP 를 낮추거나 레일을 앞으로 당기면 블록이 피니언 윤곽 안에 든 것으로 잘못 읽힌다.)
