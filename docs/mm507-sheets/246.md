# 246 축소·확대 제도기(팬터그래프)
원문(en): "Represents a pantograph for copying, enlarging, and reducing plans, etc. One arm is attached to and turns on the fixed point, C. B is an ivory tracing-point, and A the pencil. Arranged as shown, if we trace the lines of a plan with the point, B, the pencil will reproduce it double the size. By shifting the slide attached to the fixed point, C, and the slide carrying the pencil along their respective arms, the proportion to which the plan is traced will be varied." — 도면을 베끼고 확대·축소하는 팬터그래프. 한 팔은 고정점 C 에 붙어 그 둘레를 돈다. B 는 상아 추적점, A 는 연필. 그림처럼 맞추면 B 로 도면 선을 따라갈 때 연필이 두 배 크기로 그린다. C 의 슬라이드와 연필 슬라이드를 팔을 따라 옮기면 비율이 바뀐다.
쉬운 풀이: 마름모로 이은 막대의 한 점(B)으로 별을 따라가면, 다른 점(A)의 연필이 같은 별을 두 배로 그린다.
판화 묘사(원본 470×450 px, **위에서 본 그림**): 왼쪽 아래 C 에 둥근 공(고정점 손잡이)이 달린 긴 막대가 오른쪽 위로 뻗어 [272·303] 의 이음을 지나 오른쪽 끝 [440·237] 의 이음까지 간다(막대는 C 너머 왼쪽 아래 [30·410] 까지 조금 더 나옴). 오른쪽 끝 이음에서 다른 긴 막대가 왼쪽 위로 [268·162] 의 이음을 지나 왼쪽 위 끝까지 가고, 그 끝 가까이 [90·85] 에 네모 블록(연필 슬라이드) A, 그 너머 [35·65] 까지 막대가 나옴. 짧은 막대 둘이 왼쪽 가운데 이음 B [112·237] 에서 위·아래 이음([268·162]·[272·303])으로 가서 마름모(평행사변형) B–위–오른쪽–아래를 만든다. 이음은 모두 이중 원(핀).

## ★ 판화 읽기
판화 하나(위에서 본 평면도). 세계 1 px = 0.0065.
1. 바퀴는 몇 개이고 크기 차례는? → 바퀴 없음. 막대 4개(긴 팔 2, 짧은 막대 2), 이음 핀 6개(C·아래 D·오른쪽 F·위 E·B·A).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 막대는 서로 다른 층(앞뒤)으로 겹쳐 핀으로만 이어진다.
4. 고정점은? → C(공 달린 핀, 제도판에 박힘) 하나뿐.
5. 추·손잡이·크랭크는? → 없음. 추적점 B 를 손으로 도면 선(별)을 따라 끈다(손은 그리지 않음). 연필 A 는 긴 팔 끝 슬라이드에.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → C·D·F 가 한 직선(긴 팔 하나), A·E·F 가 한 직선(긴 팔 하나). B 와 F 가 같은 높이(y 237). 이상화하면 C·B·A 가 한 세로선(x 95)이고 B 가 C–A 의 가운데 — 두 배 확대의 조건.
8. 글자가 가리키는 부품은? → A = 연필(왼쪽 위 네모 블록), B = 추적점(왼쪽 가운데 이음), C = 고정점(왼쪽 아래 공).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 손으로 그린 개략이라 C·B·A 가 한 직선에서 조금 벗어나 있다(B 가 오른쪽으로 약 17 px). 정확히 두 배가 되려면 D 가 C–F 가운데, E 가 A–F 가운데, B = D + E − F 여야 하므로 그렇게 맞췄다(D·E·F 자리는 판화와 5 px 안). 또 판화는 책상 위에서 내려다본 그림인데 전시 깊이(z 1.05)에 눕히면 너무 작아지므로 **제도판을 뒤판에 세워** 정면에서 판화와 같은 모양으로 보이게 했다 → ★질문 거리.

## 해석(결정 사항)

- 기구학(닫힌 식, `kin246(B)`): d = |B − C|, M = (C + B)/2, h = √(L² − (d/2)²), D = M + h·(Bᵧ − Cᵧ, −(Bₓ − Cₓ))/d (C→B 의 오른쪽), F = 2D − C, E = B + F − D, A = 2E − F(= 2B − C). 막대 6마디(C–D, D–F, D–B, B–E, E–F, E–A) 길이는 식에서 늘 L(파이썬 검산 오차 9e-16).
