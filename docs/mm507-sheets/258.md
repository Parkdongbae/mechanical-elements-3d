# 258 V홈 풀리
원문(en): "A smooth-surface V-grooved pulley for a round band." — 둥근 줄(밴드)을 거는, 표면이 매끄러운 V자 홈 풀리.
쉬운 풀이: 테두리에 V자로 파인 홈이 있어 둥근 줄이 두 비탈면 사이에 쐐기처럼 끼어 꽉 물린다. 아래 작은 구동 풀리가 돌면 줄이 미끄러지지 않고 위 풀리를 돌린다.
판화 묘사(원본 463×435 px, 축이 화면 좌우로 누운 **옆 모습**): 가운데 세로로 선 테(x 200–292, 폭 ≈ 92 px, 위 y ≈ 60, 아래 y ≈ 400 → 반지름 ≈ 170 px). 테 위·아래 끝에 **V자로 파인 홈**: 입구 x 218–275(폭 ≈ 57 px), 깊이 ≈ 50 px, 바닥에 아주 좁은 평평한 곳(≈ 10 px — 테 앞면의 세로선 둘 x ≈ 245·255). 홈 양옆 좁은 턱(각 ≈ 18 px). 양옆 짧은 네모(x 182–200, 292–312, 반지름 ≈ 48 px) = 허브, 바깥 둥근 축(반지름 ≈ 25 px). 줄·다른 풀리는 없음.

## ★ 판화 읽기
판화는 그림 하나(옆 모습). 판화 1 px ≈ 0.00365(반지름 170 px = 0.62).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 V홈 풀리 1개. 보충: 같은 V홈의 작은 구동 풀리 1개. 크기 차례: 큰 풀리(바깥 0.62, V 바닥 0.438) > 구동 풀리(바깥 0.32, V 바닥 0.138).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에는 없음. 보충: 둥근 줄 1개(닫힌 고리, 반지름 0.07) — 큰 풀리 위쪽 V홈을 반시계로 감고 왼쪽 가닥으로 내려와 구동 풀리 아래 V홈을 감고 오른쪽 가닥으로 올라간다.
3. 교차하는 가닥이 있는가? → 없음(열린 걸이).
4. 고정점(천장·벽·바닥)은 어디인가? → 두 축 모두 뒤판 보스에서 나온 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 아래 구동 풀리 축이 일정하게 돈다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음(줄 전동).
7. 한 줄에 놓인 것은? → 두 풀리 중심 x = 0(y 2.12 / 0.82). 두 V홈 가운데·줄이 모두 깊이 0.10.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 258 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 어긋남 없음. V홈은 판화 치수 그대로(입구 반폭 0.104, 바닥 반폭 0.018, 깊이 0.182 — 비탈 반각 25.3°). 둥근 줄은 바닥에 닿지 않고 **두 비탈면에 닿아 쐐기로 물리는** 굵기(반지름 0.07)로 둔다. 판화는 풀리 하나뿐이라 구동 풀리·줄 보충. 판화는 옆 모습이고 모델은 축을 깊이(Z)로 두어 45° 시점(질문 거리 1·2).

## 해석(결정 사항)
- 큰 풀리 = 판화 그대로: 폭 0.34 테, 가운데 V홈(입구 a ±0.104 at r 0.62 → 바닥 a ±0.018 at r 0.438), 양옆 턱(폭 0.066) + 웹 + 허브. 표면 매끈.
- 줄 = 둥근 줄(반지름 0.07). 비탈면 직선(0.438, 0.018) → (0.62, 0.104)(단위 방향 (0.90414, 0.42723))에서 줄 중심 (r, 0) 까지 거리가 0.07 이 되는 r = **0.56375** — 줄은 비탈 두 곳 (0.53385, ±0.06329) 에 닿고, 바닥(0.438)과는 0.056 떨어져 쐐기로 물린다. 줄 꼭대기 0.634(테 위로 0.014 드러남). 둥근 줄 ↔ V홈 짝.
- 구동 풀리 = 같은 단면 함수로 바깥 0.32 인 V홈 풀리(같은 홈 크기) — 줄 중심 0.26375(= 0.32 − 0.05625).
- **단면 보이기**: 큰 풀리 림·웹을 ψ = −90° ~ −25° 잘라 낸 회전체 + 주홍 단면판 둘(세계 고정, 회전 대칭). 돌아감은 허브 표시·너트·줄 표시로. 잘린 자리는 줄이 닿지 않는 구간(접점 ψ −13.34°, 여유 11.7°).
- autocheck 표식: 키트 V홈 식(gw ≤ 0.055, 기울기 0.7)은 키트 풀리 전용이라 맞지 않는다. 그래서 `groove: 'round'` 로 적고 bottom 에 **줄이 실제로 앉는 높이**(줄 중심 − 줄 반지름 = 0.49375 / 0.19375)를 준다 — autocheck 자리 = bottom + 0.07 = 줄 중심. 실제 V 바닥은 `vBottom` 에 따로 적는다.

## 구동
구동 풀리 φ2(t) = 1.2·t [rad], 정면 반시계. 줄 흐름 s = 0.26375·φ2. 큰 풀리 φ1 = s / 0.56375 = 0.46785·φ2.

## 동작 (`state258(t)` — 결정적)
1. φ2 = 1.2t. `driveShaft`·`drivePulley` 의 `rotation.z = φ2`.
2. φ1 = 0.46785·φ2. `bigShaft`·`bigPulley` 의 `rotation.z = φ1`. `bigRimGroup` 은 그대로.
3. `rope.setOffset(0.26375·φ2)`.
4. 방향: 반시계 고리 — 두 풀리 반시계.
5. 감긴 각: 큰 풀리 206.68°(위쪽, ψ −13.34° → 193.34°), 구동 풀리 153.32°(아래쪽, ψ 193.34° → 346.66°). 접선 끝점: 큰 (±0.54854, 1.98990) ↔ 구동 (±0.25663, 0.75913).
