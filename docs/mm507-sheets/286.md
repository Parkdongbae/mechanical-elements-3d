# 286 증기 기관 밸브 들개
원문(en): "Toe and lifter for working puppet valves in steam engines. The curved toe on the rock-shaft operates on the lifter attached to the lifting-rod to raise the valve." — 증기 기관의 퍼핏 밸브(들어올림 밸브)를 움직이는 토(발톱)와 들개(리프터). 흔들 축(락 샤프트)에 달린 굽은 토가 들어올림 막대에 붙은 들개를 밀어 밸브를 들어 올린다.
쉬운 풀이: 흔들 축이 조금 시계 방향으로 돌면, 축에서 왼쪽으로 뻗은 굽은 토의 윗면이 들개의 평평한 밑면을 밀어 올린다. 들개는 세로 막대에 붙어 있어 막대째 올라가고, 막대 위 끝의 밸브가 자리에서 떠서 열린다. 축이 반대로 돌면 토가 내려가고, 막대는 제 무게로 내려와 밸브가 다시 자리에 앉는다(토는 들개에서 떨어진다).
판화 묘사(원본 448×564 px, **정면** — 흔들 축이 화면에 수직): 오른쪽 가운데 흔들 축(중심 [320·232], 바깥 고리 반지름 ≈ 40 px, 가운데 짙은 축 단면 반지름 ≈ 23 px). 축에서 왼쪽으로 굽은 토가 뻗어 끝 [61·155] 에서 가늘어지고 둥글다 — 윗면은 끝에서 축 쪽으로 완만하게 내려가는 볼록한 곡선, 아랫면은 끝에서 축 아래쪽으로 크게 휘어 내려감. 토 끝 바로 위에 들개: 밑면이 수평([45~398·151])인 쐐기 판, 윗면은 왼쪽 끝 [45·148] 에서 오른쪽 위 [340·75] 로 올라가 칼라(네모 보스 [340~398·70~151])에 붙음. 칼라를 세로 막대(들어올림 막대, x [355~383], 위 [40] ~ 아래 [405])가 꿰뚫고, 막대는 흔들 축 고리 바로 오른쪽 **앞**을 지나 아래로 내려간다(고리와 겹쳐 그려짐).

## 해석(결정 사항)
- **움직임은 접촉이 만든다**: 흔들 축 각 b(t)(시계 방향 +, 도)만 시간표로 주고, 막대 높이는 '토 윗면의 가장 높은 점'과 '밸브 자리' 가운데 높은 쪽으로 정한다(들개 밑면이 수평이므로).
- 토 윗면 = 반지름 ρ = 4.0 원호, 중심 O(토 좌표, b = 0) = (−0.82996, −1.92214) — 판화의 토 끝 윗점 (−1.2075, 2.06) 과 허브 쪽 윗점 (0.66, 1.79) 을 지나는 볼록 곡선. O 는 흔들 축 S = (0.735, 1.45) 에서 (−1.56496, −3.37214)(거리 3.7176).
- 토를 b 만큼 돌리면 O 도 S 둘레로 돌고, 원호의 가장 높은 점 = O + (0, 4.0) → **h(b) = 5.45 + 1.56496·sin b − 3.37214·cos b**, 닿는 점 x = 0.735 − 1.56496·cos b − 3.37214·sin b. b = 0 에서 h = 2.07786 = 판화의 들개 밑면 높이.
- 닿는 점의 토 좌표 각(O 기준) = 90° + b — b ∈ [−21.9°, 5.4°] 이면 원호 안. 쓰는 범위 b ∈ [−6°, 4°] ✓.
- 막대 들림 lift = max(0, h(b) − 2.07786). b = 4° 에서 0.1174(밸브 들림 최대).

| 0.0961 ~ 0.75 | 0 → 4° | 토 원호가 들개를 밀어 올림(닿는 점이 왼쪽으로 0.23 미끄러짐) | 0 → 0.1174 |
