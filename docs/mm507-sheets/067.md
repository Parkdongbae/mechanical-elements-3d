# 067 텀블러를 이용한 점프 운동
원문: 64번의 변형. 스프링과 캠 대신 **속 빈 축에 고정된 추(텀블러) E** 를 쓰고, 웜기어 축의 핀 C 와 함께 작동한다. 쉬운 풀이: 핀이 추를 올렸다가 놓으면 추가 돌아서 갑자기 떨어진다.

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴는 몇 개이고 크기 차례는? → 웜기어 B 하나 + 그 아래 가로 웜 하나(나사산 3바퀴 남짓, 양끝은 짧은 막대 토막). 반달 추 E 의 바깥 호 반지름은 B 이끝 반지름의 약 1.8배.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(웜 축 양끝이 잘림).
5. 추·손잡이·크랭크는? → **반달 모양의 큰 추 E(텀블러)**. 윗부분이 큰 호, 왼쪽 뿔(거의 수평)·오른쪽 뿔(아래로 휘어 내려감)로 끝나고, 아래 가장자리는 허브 밑으로 완만하게 휘어 축 둘레(속 빈 축)를 품는다. 무게중심은 축 위쪽(오른쪽으로 약 12° 기움).
6. 기어의 이는 어디에 났고 무엇이 물리는가? → B 의 바깥 둘레. 맨 아래에서 웜이 문다. 이는 아래쪽만 그리고 나머지 둘레는 점선 원 두 개(이끝·이뿌리)로 줄여 그렸다(66번과 같은 그림 방식 — 추에 가리지 않은 왼쪽 아래 둘레도 점선). 나사산은 정면에서 `\`(오른나사).
7. 한 줄에 놓인 것은? → 축 C 와 웜 가운데가 같은 세로선.
8. 글자가 가리키는 부품은? → B = 웜기어, C = 웜기어 축에 박힌 핀(축 단면 꼭대기의 작은 돌기), E = 추(텀블러). 화살표(추 위, 왼쪽을 향함) = 반시계.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 같다(없음). 다만 **앞뒤 순서가 판화만으로는 정해지지 않는다**: 추의 아래 가장자리는 B 의 원 안에서만 점선(추가 B 뒤)인데, 핀 C 와 축 둘레 고리는 실선으로 맨 앞에 보인다(속 빈 축 끝이 앞). 기구·운동은 어느 쪽이든 같으므로 질문 거리는 아니다 — 아래 해석 참조.
- 그 밖의 선: 축 단면의 빗금 = 잘린 축, 축 둘레 두 겹 원 = 속 빈 축.

## 구동
웜(가로축). 웜기어 B 가 축을 천천히 돌리고, 축의 핀 C 가 추 E 를 들어 올렸다가 놓친다. theta += 0.8·speed·dt 가 B 의 각 ψ, B 한 바퀴 = 한 주기(7.85 s).

## 해석(결정 사항)
- 판화에 그림은 하나. 64번의 장치를 그대로 쓰되 스프링·캠을 추로 바꾼 그림이라, 64의 "속 빈 축 한쪽을 반쯤 자르고 핀이 그 안에서 돈다"를 따른다.
- 앞뒤 순서: **추 E·속 빈 축·핀을 앞(z 큼), 웜기어 B·웜을 뒤**에 둔다. 판화의 선 종류로는 추가 B 뒤로도 읽히지만(추 아래 가장자리가 B 원 안에서 점선), 그렇게 하면 핀과 반쯤 잘린 속 빈 축이 B 뒤에 숨어 이 기구의 요점(핀과 추 사이의 헐거움)이 보이지 않는다. 판화도 핀 C 와 고리를 맨 앞에 실선으로 그렸다. B 의 점선 원은 "가려짐"이 아니라 이 생략 표기다.
- 추가 떨어지는 것은 중력 때문이다. 추의 무게중심은 축에서 0.415 떨어진 곳(축에서 본 각 78°, 윗쪽)이라 위로 올라가면 불안정하고 꼭대기를 넘으면 앞으로 쏟아진다. 반쯤 잘린 속 빈 축의 홈(반원 180°)이 핀과 추의 상대 각을 제한해 추는 꼭대기에서 반바퀴만 떨어지고(무게중심이 맨 아래로) 멈춘다 — 핀이 따라잡을 때까지 쉰다.
- 정확한 중력 동역학 대신 주기 시간표(아래)로 쓴다. 모든 자세가 θ 의 함수이다.

- 웜 기어 B: `wormWheel(24, 0.05, { width: 0.14, spokes: 6, tanLead: −0.2083 })`, 피치 반지름 0.6, z = 0.00. 바닥 쪽 이가 드러나게 추 뒤.

  - 웜+B는 **031 배치(웜이 휠 위)를 Z축으로 180° 돌린 그룹**으로 만든다: `set = Group(position (0,1.95,0), rotation.z = π)`, 안에 wheel(원점), worm(0, +0.72, 0). 손잡이(나사 방향)는 회전해도 그대로다. 막대: `rod`(−0.52,1.23,0)~(0.55,1.23,0) 반지름 0.045(토막 양끝), 뒤판에 붙은 축받이 블록 x = ±0.42(폭 0.18, 높이 0.22, z는 STAGE.backZ ~ 0.09; 031 `bearingBlock` 방식).
- 텀블러 E: `tumblerWeight(0.08)` (k067) — 바깥 호 반지름 1.1(−23.5° ~ 178°), 아래 가장자리는 판화에서 딴 점 22개(왼 뿔 끝 (−1.10, 0.04) → 허브 밑 (−0.02, −0.28) → 오른 뿔 끝 (1.00, −0.44)). z 가운데 = 0.26(0.22~0.30; 웜 최대 z 0.17보다 앞). 면적 무게중심 `tumblerCom()` = (0.086, 0.406), 각 γ = 78.1° = 1.363 rad.
- 속 빈 축: `halfCutTube(0.10, 0.16, 0.07, 0.31, 0.41, a0)` (k067) — 온 원통 z 0.07~0.31(E가 이 위에 붙음), 0.31~0.41은 반쪽 벽만 남음. 벽이 남은 각(E 로컬) = [a0, a0 + π], **a0 = 85° = 1.484 rad**(판화에서 핀이 고리 위쪽에서 보이게). E와 같은 그룹.
- 핀: 축 C(B)에 고정된 짧은 막대 — 상자 0.05(접선) × 0.11(반지름 방향, r 0.08~0.19) × 0.05(z), 중심 z = 0.36(홈통 구간), 철제. 모델에서 `pinGroup.rotation.z = P`.
- 받침대·뒤판 `displayStand()`.

## 동작 (모두 theta 의 함수)
- B 각 ψ = theta (theta += 0.8·speed·dt — 한 주기 7.85 s, 웜은 24배인 19.2 rad/s ≈ 3회전/초). 설계가 OMEGA 1.6 대신 0.8 을 쓰는 이유: 웜이 너무 빨라 흐려지는 것을 줄이려고.
- 웜(안쪽 로컬, 위 배치 기준): ϑ = 24ψ, `worm.rotation.x = ϑ`. B(안쪽 로컬) `wheel.rotation.z = ψ + π/2 − π/24` (반시계; 오른나사 웜이 휠 위, 031의 오른나사 식). 그룹이 π 돌아 있으니 실제로는 B 반시계, 웜이 맨 아래.
- 주기 변수 c = (ψ + 2.1) mod 2π (처음부터 올라가는 중간에서 시작: t = 1 이 판화 상태).
- 핀 각(절대) P = 4.833 + c (rad) — 핀이 B 와 함께 도는 각. (4.833 = 276.9° : 추를 걸어 올리기 시작하는 핀 자리 = 바닥 오른쪽.)
- 추 무게중심 각(맨 아래 기준 반시계) α(c):
  - c ∈ [0, π): **올림** α = c. (핀이 홈 끝에 걸려 추를 함께 올림.)
  - c ∈ [π, π + 0.6): **떨어짐** u = (c − π)/0.6, α = max(c, π + π(1 − cos(πu/2))) — 처음엔 핀이 밀다가(u ≈ 0.15 까지) 중력으로 앞서 나간다.
  - c ∈ [π + 0.6, 2π): **쉼** s = c − (π + 0.6), α = 2π − 0.22·e^(−s/0.3)·|sin(14 s)| (바닥에 부딪혀 두어 번 튀고 정지). 핀이 따라잡는 것은 c = 2π.
- E 자세: `E.rotation.z = 3π/2 + α − γ = 3.349 + α` (E·속 빈 축 같은 그룹이라 함께 돈다).
- 핀과 홈의 간격 λ = α − c ∈ [0, π − 0.6 = 2.54] — 항상 0 이상, 반원(π)보다 작으므로 핀이 홈 끝을 넘지 않는다(떨어지는 동안 홈 안에서 뒤처짐).
- 시각표: t = 0 → c = 2.1(올리는 중, E 120°); t = 1.0 → c = 2.9(꼭대기 직전, **판화 모양**: E.rotation.z ≈ −0.03, 핀이 위쪽); t ≈ 1.3 → 꼭대기; t = 1.6 → c = 3.38 (떨어지는 중간, E가 핀보다 0.36 rad 앞); t = 2.0 → c = 3.7 (거의 바닥); t ≥ 2.2 → 쉼(핀이 따라잡기까지 약 4.5 s 후 다시 올림).

## 확인
- t=1, t=1.6 정면: t=1 은 판화와 같은 모양(추가 위로 큰 초승달, 핀이 고리 위). t=1.6 은 추가 핀보다 앞서 쏟아지고 있다. 추가 B 이·웜을 가려도 되지만(판화처럼 B 아래쪽 이는 추 밖으로 보임) 웜은 추 아래 가장자리 밖에 보여야 한다.
- 추 모양 비교: 판화 확대와 나란히 — 윗호 크기, 왼 뿔(수평에 가깝게 뻗음)·오른 뿔(아래로 휘어 내려감), 허브 밑 곡선.
- 근접: `cam=0.5,2.4,1.1,0,1.95,0.3`(핀이 홈통 안에서 도는지; 핀이 고리 반쪽 벽 밖으로 튀어나오지 않는지), `cam=0.8,1.4,1.0,0,1.25,0.0`(웜 나사산이 B 이 사이에 앉음 — 031과 같은 방식), 옆 `cam=3.2,1.95,0.25,0,1.95,0.25`(추 z 0.22~0.30 이 웜·B 와 겹치지 않는지, 앞으로 튀어나옴 없음).
- 수치: E 반지름 1.1 → 위 y = 3.05(≤ 3.3), 아래 y = 0.85. 추가 모든 각도에서 웜(z 최대 0.17)과 z 로 겹치지 않음(E 뒷면 z 0.22).
- t = 2.0 과 t = 3 도 찍어 떨어짐·정지를 본다.
