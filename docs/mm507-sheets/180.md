# 180 한쪽 죔쇠(목수 작업대 죔쇠)
원문: "This only differs from 174 in being composed of a single pivoted clamp operating in connection with a fixed side-piece." — 174(두 턱 죔쇠)와 다른 점은, 축 하나로 도는 **굽은 죔쇠 하나**가 **고정 옆판**과 짝을 이룬다는 것뿐이다. 174 에서 막대 끝이 꼬리를 밀어 턱이 닫히듯, 여기서는 작업물(나무 판)이 아래에서 밀려 올라오며 죔쇠 위쪽 안쪽 면을 밀어 죔쇠를 돌리고, 아래 갈고리가 작업물을 옆판에 눌러 문다.

## ★ 판화 읽기
판화는 그림 하나(정면, 원본 px [x·y], 521×519).
1. 바퀴는? → 바퀴 없음. 부품: ① 세로로 선 고정 옆판 [127~183·0~426](아래 끝은 끊긴 물결선) ② 옆판의 일자 홈 나사 둘 [153·145], [152·372](반지름 13) ③ 옆판 오른쪽에 붙은 작업물(세로 사각) [183~230·123~412](아래 끊긴 선) ④ 콩팥 모양 굽은 죔쇠 [148~346·31~418] ⑤ 죔쇠 가운데 일자 홈 나사(축) [292.5·246.5](반지름 26).
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 단 죔쇠 위 끝 [148~183·31~68] 은 옆판 뒤로 넘어가 점선으로 그려졌다(옆판이 앞, 죔쇠가 뒤).
4. 고정점은? → 옆판(나사 둘로 작업대에), 죔쇠 축 나사(작업대에 박힘). 작업물은 손으로 밀어 넣는 것(고정 아님).
5. 추·손잡이·크랭크는? → 없음. 구동은 작업물을 아래에서 밀어 올리는 손(그림 없음).
6. 기어는? → 없음. 닿는 짝: 작업물 윗모서리 [230·123] ↔ 죔쇠 위쪽 안쪽 면(판화에서 정확히 닿아 있음), 작업물 오른쪽 면 [x 230] ↔ 아래 갈고리 왼쪽 볼록 [231·370~400], 작업물 왼쪽 면 ↔ 옆판 오른쪽 면 [x 183].
7. 한 줄에 놓인 것은? → 옆판 두 나사가 같은 세로선(x 152~153). 작업물 오른쪽 면과 갈고리 왼쪽 끝이 같은 세로선(x 230). 축은 옆판 두 나사 높이 사이(조금 아래쪽).
8. 글자는? → 번호 180 뿐.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 판화는 물린 순간 한 장. 죔쇠가 풀리려면 위 끝이 옆판 뒤로 더 들어가야 하므로 층을 나눈다(옆판 앞, 죔쇠 뒤). 질문 거리 없음.

## 해석(결정 사항)
- 1 px = 0.0068, 세계 x = (px − 236)·0.0068, y = 3.12 − py·0.0068. 축 P = (0.384, 1.444).
- 죔쇠 각 φ(반시계 +): 0 = 판화 자세(물림), 풀림 0.10 rad(5.7°). 작업물 윗모서리가 위쪽 안쪽 면을 밀면 축보다 왼쪽을 밀어 올리므로 시계 방향으로 돌고, 그때 축보다 왼쪽 아래의 갈고리는 왼쪽(작업물 쪽)으로 온다 → 물림. 174 의 "막대 끝이 꼬리를 밀어 턱이 닫힘"과 같은 원리.
- φ 는 작업물 윗면 높이에서 계산: 작업물 기둥 위에 걸친 안쪽 면의 가장 낮은 점 = 윗면(+틈 0.004) 이 되는 φ(이분법). 윗면이 물림 높이(φ=0 의 값, 2.283 = 판화 123 px 와 같음) 이상이면 φ=0, 너무 낮으면 φ=풀림.
- 작업물 오른쪽 면 = 물린 갈고리 왼쪽 끝 − 0.004, 왼쪽 면 = 옆판 오른쪽 면 + 0.002 (같은 식에서).
- 판화와 다르게: 옆판 왼쪽 가장자리를 3 px 넓힘(127 → 124) — 풀린 죔쇠 위 끝이 옆판 뒤에 숨도록.
- 판화에 없는 보충: 옆판 뒤 받침 조각(나사 자리, 뒤판까지), 축 나사 뒤판 보스.

## 구동
작업물을 밀어 올리고 내리는 손(그림 없음). theta += OMEGA·speed·dt. s = smoothstep(0.5 + 0.65·cos(theta − 1.6)), 작업물 윗면 = 1.963 + 0.32·s. 한 주기 3.93 s: 올라오며 물기 → 물린 채 멈춤(t ≈ 1) → 내려가며 풀림 → 내려간 채 멈춤(t ≈ 3).

## 부품과 치수 (새 부품은 `kit/k180.ts`, 이미 구현됨. 상수 `K180`)
층(z): 작업물 −0.05~0.11, 죔쇠 −0.05~0.05, 옆판 0.06~0.16(죔쇠 앞면 0.05 보다 앞 → 죔쇠 위 끝이 옆판 뒤로 지나감, 작업물은 두 층에 걸쳐 옆판·죔쇠와 다 닿음).
- 고정 옆판(name `sidePiece`): `sidePiece180()` x −0.762~−0.360, y 0.223~3.12, 아래 끝 끊긴 물결선. 받침 조각 2개(나사 자리, 높이 0.3, 뒤판 −0.30 ~ 0.06).
- 고정 나사(name `fixScrew1`, `fixScrew2`): `screw180(x, y, 0.16, 0.088, 홈각, backZ)` 를 (−0.564, 2.134), (−0.571, 0.590) 에. 일자 홈 둥근 머리.
- 작업물(name `workpiece`): `workpiece180()` x −0.358~−0.039, 길이 1.75(윗면 기준 아래로), 아래 끝 끊긴 선. position.y = 윗면 높이. userData.outline 직사각형.
- 회전 죔쇠(name `clamp`): `clamp180Body()` 를 P 에, rotation.z = φ. 판화 px 52점을 centripetal Catmull-Rom 으로 이은 윤곽(320점), 두께 0.10, 축 구멍 0.05. userData.outline.
- 축 나사(name `pivotScrew`): `screw180(P, 0.05, 0.177, π/2, −0.05)` — 뒤판 보스(−0.30 ~ −0.05) 에서 나와 죔쇠 구멍을 꿰고 죔쇠 앞면에 일자 홈 둥근 머리(반지름 0.177).
- 전체 범위: x −0.762 ~ 0.69, y 0.20 ~ 3.12.

## 동작 (`clamp180(theta)` = { top, phi, grip, gap })
`clamp.rotation.z = phi`, `workpiece.position.y = top`. t = 1 물림(φ = 0, 갈고리 틈 0.004), t = 3 풀림(φ = 5.7°, 갈고리 틈 0.096).
