# 046 퓨지 체인과 태엽통
원문: 퓨지 체인과 태엽통은 일부 시계, 특히 영국제 시계의 원동력이다. 오른쪽 퓨지는 태엽이 풀리면서 줄어드는 힘의 손실을 보상한다. 시계를 감았을 때는 태엽의 힘이 가장 크므로 체인이 퓨지의 지름이 작은 쪽에 걸려 있다.

★ 판화 읽기 (질문표) — 판화 `public/mm507/fig/046.png`, 4배 확대 `shots/_verify/046-fig-x4.png` 를 설계표보다 먼저 보고 적음
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 2개. 왼쪽 **태엽통**(곧은 원통, 지름 ≈ 높이의 1.6배)과 오른쪽 **퓨지**(아래가 넓고 위로 좁아지는 **4단 계단 원뿔**). 퓨지 맨 아랫단 지름 ≈ 태엽통 지름보다 조금 큼, 맨 윗단 지름 ≈ 맨 아랫단의 반. 두 축 모두 세로.
2. 줄·벨트는 몇 개이고 어디서 어디로? → 체인 1개(점이 박힌 사슬). 태엽통 둘레에 가로로 **4줄** 감겨 있고(윗줄은 중간에서 시작 — 끝 걸이), 맨 아랫줄에서 태엽통 앞쪽을 떠나 오른쪽으로 곧게 건너가 퓨지의 **맨 아랫단 윗면(턱) 위에 얹혀 둘째 단 둘레**를 앞쪽에서 감아 돈다. 퓨지에는 한 줄만 걸려 있다(= 거의 다 풀린 상태).
3. 교차하는 가닥이 있는가? → 없음. 자유 가닥은 하나뿐이고 두 원통의 앞쪽(보는 쪽) 바깥 접선 — 열린 벨트 꼴이라 두 축이 같은 방향으로 돈다.
4. 고정점은? → 판화에 받침 없음(축 끝이 끊겨 그려짐). 뒤판 축받이 4개는 **판화에 없음(보충)**.
5. 추·손잡이·크랭크는? → 없음. 퓨지 위 축 끝이 네모지게 깎여 있다(감는 열쇠 자리). 태엽통 위로도 짧은 축 끝.
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 태엽통 밑면과 퓨지 밑 테가 거의 같은 높이. 자유 가닥은 수평(태엽통 아랫줄 높이 = 퓨지 아랫단 턱 높이).
8. 글자가 가리키는 부품은? → 글자 없음(번호 46 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳은? → ① 판화의 퓨지는 동심 원판 4장을 쌓은 계단인데, 그대로면 체인이 단에서 단으로 넘어갈 수 없다 → 실제 퓨지처럼 **계단이 나선으로 오르는 턱**(4바퀴)으로 만든다(겉모습은 판화의 4단 계단 그대로). ② 판화는 다 풀린 쪽, 원문은 감긴 쪽(체인이 작은 지름에)을 말한다 → 두 상태를 오가게 한다. ③ 태엽통 윗면의 동심원은 속의 태엽을 암시하는 선으로 읽었다(홈선 3개). 사용자 질문 거리는 아님.

구동: 원동력은 태엽통 속 태엽이고 퓨지가 그 힘을 받아 시계 톱니바퀴열로 넘긴다. 모델은 퓨지 풀림각 ψ 를 정해 준다 — `theta += OMEGA·speed·dt`, ψ(theta)를 아래 식으로 만들어 `fuseeSystem().set(ψ)`.

## 해석(결정 사항)
- **(S1b 에서 고침)** 처음 표는 판화의 4단 계단을 "매끈한 곡선 원뿔 + 가는 나선 돌기"로 바꿨다. 판화와 한눈에 대응되지 않으므로 **나선 계단**으로 다시 만들었다: 턱(체인이 얹히는 면)이 나선으로 4바퀴 오르고, 체인은 턱 위에서 위 단의 벽에 기대어 감긴다. 단 사이 반지름 차는 "태엽 힘 × 반지름 = 일정" 곡선에서 나오므로 아래 단일수록 턱이 넓다(한 바퀴마다 체인 중심 반지름 0.408 → 0.346 → 0.297 → 0.265 → 0.245, 턱 너비 0.063 · 0.049 · 0.033 · 0.020).
- 판화는 '다 풀린' 모습. 원문의 '감았을 때'까지 보이도록 ψ 를 왕복시킨다(시계가 가는 동안 풀리고, 다 풀리면 열쇠로 4배 빠르게 되감는다).
- 체인은 판화처럼 작은 판이 한 코씩 이어진 사슬.

## 이미 구현됨 (키트 추가) — kit/gear6.ts, 모델 작성자는 다시 만들지 않는다

  - `FuseeSystem = { group, barrel, fusee, psiMax, chainLength, set(psi): FuseeState }`
  - `set(psi)`: psi = 퓨지가 풀린 각(0 = 감긴 상태, `psiMax` = 7.2π ≈ 22.62 rad = 3.6바퀴 = 다 풀림). 부를 때마다 두 회전과 체인 전체 경로를 다시 계산한다(절대 자세).
  - `FuseeState = { psi, spent(0~1), force(1→0.6), rExit, torque(=force×rExit/0.245, 늘 1.00), alphaE, barrelAngle, barrelTurns }`
- `FUSEE_Y = { base: 1.05, barrelTop: 1.78, fuseeTop: 1.83 }`, `wallBearing(x, y, zc, axis, bore)`.

## 동작
- 풀림각 ψ(theta) — 주기 18.56 rad(약 11.6 초): `c = mod(theta, 18.56)`
  - c < 11.31: ψ = 2·c (시계가 가는 중 — 풀림) / 11.31 ≤ c < 12.11: ψ = psiMax (다 풀린 채 멈춤) / 12.11 ≤ c < 17.76: ψ = psiMax − 4·(c − 12.11) (열쇠로 감는 중) / 나머지: ψ = 0.
- 퓨지는 풀릴 때 `rotation.y = −ψ`(위에서 보아 시계 방향), 태엽통도 같은 방향으로 `barrelAngle`(음수, 누적). 열린 벨트 꼴이라 같은 방향.
- 힘×반지름: 태엽이 당기는 힘 F = 1 − 0.4·(풀린 정도), 퓨지 반지름 r = 0.245/(1 − 0.4·ℓ/ℓmax) → F × r = 0.245 로 일정(`FuseeState.torque` = 1.00).
- 표본(ψ 비율 → F, 체인 반지름, 태엽통에 감긴 바퀴): 0% → 1.00, 0.245, 0.50 / 50% → 0.83, 0.297, 1.67 / 100% → 0.60, 0.407, 3.16.
- t=1(theta 1.6): ψ = 3.2 rad, t=1.6: ψ = 5.12 rad. 그 사이 퓨지 −1.92 rad, 태엽통 −1.216 rad(비는 일정하지 않다 — 체인이 걸린 반지름이 변하므로).

## 표시
- rotArrow: `rotArrow(0.42, false)` 를 `rotation.x = −π/2` 로 눕혀 (−0.85, 1.93, 0.30), (0.85, 1.93, 0.30).
- tag: '태엽통(태엽이 안에 있음)' (−0.85, 2.35, 0.40), '퓨지(계단 원뿔 도르래)' (0.85, 2.45, 0.40), '체인' (0, 0.95, 0.70), 선택 '체인이 걸린 반지름' (1.55, 1.4, 0.45).
- notes(`FuseeState`): ① '태엽 힘(감겼을 때 = 100%)' → `(force*100).toFixed(0)+'%'` ② '체인이 걸린 퓨지 반지름(감긴 상태 = 1)' → `(rExit/0.245).toFixed(2)` ③ '힘 × 반지름' → `'≈ ' + torque.toFixed(2) + ' (일정)'` ④ '상태' → '시계가 가는 중(태엽이 풀림)' / '다 풀림' / '열쇠로 감는 중' / '다 감김' ⑤ '태엽통에 감긴 체인' → `barrelTurns.toFixed(1)+'바퀴'`.
- view: 기본 정면.

## 확인
- 판화 대조(E1·E3): 퓨지가 **계단**으로 보이는가(매끈한 원뿔이면 불합격), 아래가 넓은가, 체인이 태엽통의 아랫줄에서 나와 앞쪽으로 건너가는가. 다 풀린 자세(theta ≈ 11.5)가 판화와 같은 모습(체인이 퓨지 맨 아랫단, 태엽통에 3줄 남짓).
- 근접 `cam=0.3,1.6,1.7,0,1.4,0.3`: 체인이 턱 위에 얹혀 벽에 붙어 감긴다(벽에 박히거나 뜨지 않음 — 틈 0.002). 자유 가닥이 떠나는 곳에서 오르는 턱 모서리에 닿지 않는지(턱이 바깥으로 0.02 낮아지게 해 둠 — 눈으로 한 번 더).
- t=1·1.6 정면: 두 표시점이 같은 방향으로 돈다. 감긴 자세(theta 0)와 다 풀린 자세 두 장.
- 옆 `cam=3.2,1.5,0.3,0,1.5,0.3`·위 `cam=0,3.6,1.0,0,1.5,0.3`: 체인 z 가 −0.16~0.76 안.
