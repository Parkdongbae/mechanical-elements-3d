# 079 왕복 막대로 돌리는 래칫 (면 래칫과 흔들 팔 2개)
원문: 막대 B 의 **직선 왕복 운동**이, 흔들리는 방사형 팔 C, C 의 끝에 달린 폴들로 **톱니 면을 가진 바퀴(ratchet-faced wheel) A** 를 거의 연속으로 돌린다. (catalog.json 의 en 은 문장 앞머리 "Reciprocating rectilinear motion of" 가 78번 쪽으로 잘못 잘려 갔다.)
판화(public/mm507/fig/079.png, 4배 `shots/_verify/079-fig-x4.png`, 폴 7배 `shots/_verify/079-pawls-x7.png`): 정면 그림 하나. 왼쪽에 바퀴 A — **테가 띠 모양이고 그 띠에 반지름 방향 금이 촘촘히 그어져 있다**(바깥 둘레는 매끈한 원). 가운데 축(빗금 = 축의 단면)과 두 겹 허브. 허브에서 오른쪽 위·오른쪽 아래 45° 로 **팔 C 두 개**가 테를 지나 바깥까지 뻗고, 팔이 테를 지나는 자리마다 작은 **폴**이 하나씩(작은 원 = 폴의 축, 거기서 테를 따라 시계 방향으로 짧은 혀). 두 팔 끝의 고리에서 **이음 막대 두 개**가 오른쪽의 한 점 B 로 모이고, B 에는 오른쪽으로 갈래진 끝(잘린 막대)이 있다. 바퀴 안의 화살표는 위에서 오른쪽(시계).

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 1개(A). 테 띠(안쪽 반지름 : 바깥 = 435 : 520, 4배 판화 픽셀)에 반지름 방향 금이 약 10° 간격 → **36칸**. 가운데는 살 없이 비어 그려짐(얇은 원판으로 본다)과 허브(반지름 약 150), 축(반지름 약 65).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 두 이음 막대는 B 에서만 만난다.
4. 고정점(천장·벽·바닥)은 어디인가? → 바퀴 축뿐(팔 두 개도 이 축에 헐겁게 끼어 있다). 판화에 받침대·막대 안내는 없다(왼쪽 세로선은 판 테두리).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 구동은 막대 B(오른쪽으로 잘려 나간 갈래 끝)의 좌우 왕복.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 바깥 둘레에도 안쪽 둘레에도 이가 없고, **테의 앞면(옆면)** 에 반지름 방향 톱니가 나 있다(원문의 ratchet-faced, 판화의 반지름 금 = 톱니의 곧은 면). 폴은 팔에 달려 테 앞면 위에 얹혀 있고 혀끝이 **시계 방향**을 향한다: 위 팔의 폴은 오른쪽 아래로, 아래 팔의 폴은 왼쪽 아래로. 팔이 시계로 돌 때 혀끝이 톱니의 곧은 면을 민다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 바퀴 축과 B 가 같은 가로선(막대 B 의 운동선). 두 팔과 두 이음 막대는 이 선에 대해 위아래 대칭(팔 ±45°).
8. 판화에 글자(A, B…)가 가리키는 부품은? → A = 바퀴, B = 왕복 막대(의 핀), C, C = 흔들리는 팔 둘. 화살표 = 바퀴 회전 방향(시계).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 적어 둘 것: 판화의 폴은 작은 원(축)과 혀로만 그려져 있어 폴이 어느 방향으로 까딱이는지는 그림만으로는 알 수 없다. 톱니가 테의 **면**에 있으므로(원문·반지름 금) 폴은 팔의 길이 방향을 축으로 **앞뒤(z)로 까딱이는 판**으로 만든다 — 정면에서 보면 판화와 같은 모양(팔 옆에서 테를 따라 뻗은 혀)이다.
- 그 밖의 선: 허브의 겹원 = 두 팔의 허브 고리와 바퀴 허브, 축의 빗금 = 잘린 축 단면, 팔·이음 막대의 겹선 = 납작한 막대의 두 모서리, 팔 끝과 B 의 겹원 = 핀과 고리.

## 해석(결정 사항)
- 팔 C 두 개는 바퀴 축에 **헐겁게** 끼어 있고(바퀴와 따로 돎), 이음 막대로 B 에 묶여 가위처럼 벌어졌다 오므라든다. B 가 오른쪽으로 가면 두 팔이 오므라들고(위 팔은 시계, 아래 팔은 반시계), 왼쪽으로 가면 벌어진다.
- **B 가 오른쪽으로 갈 때 위 팔의 폴이**, **왼쪽으로 갈 때 아래 팔의 폴이** 바퀴를 시계로 민다. 쉬는 폴은 톱니의 비탈을 타고 넘으며 딸깍거린다.
- 한 행정에 톱니 2칸, 한 왕복에 **정확히 4칸(40°)**. 팔 벌림각 γ 는 34.25° ~ 55.75°(가운데 45° = 판화), 헛걸음 0.15칸.
- 위상 조건: γ 최소 + γ 최대 = 90° = 톱니 9칸이라 두 폴이 같은 치수로 정확히 번갈아 걸린다(닫힌 식, 풀이 필요 없음).

## 구동
막대 B(theta 가 왕복 위상). theta += OMEGA(1.6)·speed·dt. B 핀의 x = 바퀴 중심에서 1.6488 − 0.2053·cos(theta) (사인 왕복, 행정 0.4106). 한 왕복 = 2π(3.93 s).

## 부품과 치수 (모두 키트 `kit/k077.ts`, 이미 구현됨. 값은 `K79` 상수)
바퀴 중심 O = (−0.75, 1.6). 막대 B 의 운동선 y = 1.6.
- 바퀴 A(name `wheelA`): `faceRatchetWheel79()` 를 (−0.75, 1.6, 0.03) 에. 테 바깥 반지름 0.8, 안쪽 0.67, 테 앞면(z = 0.08)에 톱니 36개(높이 0.035, 곧은 면이 로컬 각 k·10°). 얇은 원판(구멍 6개) + 허브. 황동, 톱니는 강철.
- 축: `shaftZ(-0.75, 1.6, 0.27, 0.045)` — 뒤판에서 나와 바퀴(구멍 0.05)와 두 팔의 허브 고리(구멍 0.05)를 꿴다.
- 위 팔 C(name `armU`): `radialArm79(0.03)` 를 (−0.75, 1.6, 0.18) 에. 길이 0.94(축 → 끝 핀), 반지름 0.735 자리에 폴 경첩 받침. 청동.
- 아래 팔 C(name `armL`): `radialArm79(0.065)` 를 (−0.75, 1.6, 0.215) 에(허브가 위 팔 앞에 겹쳐 놓임).
- 팔 끝 핀: 위 팔의 자식으로 `rod(V(0.94, 0, -0.07), V(0.94, 0, 0.03), 0.02)`, 아래 팔의 자식으로 `rod(V(0.94, 0, -0.03), V(0.94, 0, 0.07), 0.02)` — 팔 끝 고리와 이음 막대 구멍을 꿴다.
- 폴 2개(name `pawlU`, `pawlL`): `flapPawl79()` — 길이 0.15, 폭 0.09 의 얇은 강철 판. 바퀴 중심을 원점으로 하는 그룹 (−0.75, 1.6, 0) 의 자식으로 두고 `placeFlapPawl79(pawl, 팔 각, 기울기, 0.15)` 로 놓는다(경첩 높이 z = 0.15 = 테 앞면 0.08 + 0.07).
- 이음 막대 2개(name `linkU`, `linkL`): `linkBar79()` — 길이 1.2. 위 것은 z = 0.135(위 팔 뒤), 아래 것은 z = 0.26(아래 팔 앞). 강철.
- 왕복 막대 B(name `rodB`): `forkRod79(0.9, -0.09, 0.085)` 를 (−0.75 + xB, 1.6, 0.2) 에. 핀이 두 이음 막대를 꿰고, 둥근 막대가 오른쪽으로 0.9. 청동(구동).
- 막대 안내(판화에 없음 — 막대가 직선으로만 가게 받침): `rodGuide79(0.2)` 를 (1.4, 1.6, 0.2) 에. 뒤판에서 나온 기둥 끝의 구멍 뚫린 블록. 주철.
- 받침대·뒤판 `displayStand()`.
- 가로 범위 x −1.55(바퀴 왼쪽) ~ 2.0(막대 끝이 가장 오른쪽일 때), 세로 y 0.76 ~ 2.44. 흔들리는 팔 끝의 최고 높이: 팔 끝 고리 윗면 y = 1.6 + 0.94·sin 55.75° + 0.06 = 2.44(B 가 가장 왼쪽일 때), 가장 낮은 자리는 대칭으로 0.76.

## 동작 (모두 theta 의 함수 — `state79(theta)` 가 한 번에 돌려준다)
`const s = state79(theta)`:
- 막대 B: position.x = −0.75 + s.xB (바퀴 중심 기준 1.4435 ~ 1.8541 → 세계 0.694 ~ 1.104).
- 팔: armU.rotation.z = +s.gamma, armL.rotation.z = −s.gamma. γ = acos((0.94² + xB² − 1.2²) / (2·0.94·xB)).
- 이음 막대: linkU 는 위 팔 끝 E = O + 0.94·(cos γ, sin γ) 에 놓고 rotation.z = atan2(1.6 − E.y, (−0.75 + s.xB) − E.x). linkL 은 위아래 대칭(E' = O + 0.94·(cos γ, −sin γ)).
- 바퀴: rotation.z = s.wheel (시계로 쌓여 줄어든다. 한 주기에 정확히 −40°).
- 폴: `placeFlapPawl79(pawlU, s.gamma, s.tiltU, 0.15)`, `placeFlapPawl79(pawlL, -s.gamma, s.tiltL, 0.15)`. 기울기는 13.5°(톱니 끝 위) ~ 27.8°(골 바닥).
- s.pushing = 'U' | 'L' | null, s.steps = 지금까지 넘긴 톱니 수.
- 주기 시간표(theta 를 0 ~ 360° 로): 0° ~ 32.5° 헛걸음(바퀴 정지) → 32.5° ~ 180° **위 팔의 폴이 밂**(20°, B 가 오른쪽으로) → 180° ~ 208° 헛걸음 → 208° ~ 360° **아래 팔의 폴이 밂**(20°, B 가 왼쪽으로). 한 주기의 약 83% 동안 바퀴가 돈다.
- 미는 동안 바퀴 각 = 팔 각과 같이 간다(바퀴 회전 = γ 최대 − γ − 헛걸음). 쉬는 폴의 기울기는 판 끝이 톱니 면에 얹히는 각을 풀어 구하고, 톱니 끝에서 골로 떨어질 때만 떨어지는 속도를 제한한다.
- 시각: **t = 1.0**(theta 1.6, γ = 45.5° — 판화 자세, 위 팔의 폴이 미는 중), **t = 1.6**(theta 2.56, γ = 36.3°, 위 팔이 거의 다 밀었음), t = 3.0(γ = 46.7°, 아래 팔의 폴이 미는 중).
