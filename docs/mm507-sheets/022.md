# 022 도르래 배열 (22)
판화: 들보에 걸이 4개 — 왼쪽 셋(줄 3개의 고정 끝)과 오른쪽 하나(F). 오른쪽 위에 큰 도르래 F, 그 왼쪽 아래로 움직도르래 m1, m2, m3 가 반 지름씩 옆으로 밀리며 계단식으로 내려오고, 맨 아래 m3 에 넓은 추 통이 매달린다. 줄마다 왼쪽 끝은 들보에 맨 뒤 도르래 왼쪽으로 내려와 밑을 돌아 오른쪽으로 올라가, 바로 위 도르래의 아랫 눈(가운데)에 맨다. 맨 위 줄은 m1 을 돈 뒤 F 를 넘어 오른쪽으로 늘어진다(자유 끝).
구동: F 오른쪽 자유 끝을 아래로 당긴다. theta 는 당김 주기의 위상.

읽기(한 줄): 019 와 같은 연결(줄 3개의 왼쪽 끝은 모두 들보, 줄 2·3 의 오른쪽 끝은 바로 위 움직도르래 아랫 눈, 줄 1 은 F 를 넘어 자유 끝)이며 책의 2ⁿ 규칙대로 이득 2³ = 8배다(이 판화는 019 의 계를 F 를 오른쪽으로 옮겨 펼쳐 그린 것). 책의 설명과 계산이 일치하므로 별도 정정은 없다. 줄은 수직으로 그린다.

## 부품과 치수
`rope.ts` 키트(`Rope`, `arcPoints`, `pulleyBlock`, `ceilingBeam`, `ropeEnd`)와 `weight`, `rod`, `rotArrow`, `tag`. 줄 반지름 0.012, 줄 z = 0.22, 도르래 중심 z = 0.22, `Rope` 3개(rope1~3). 상수 `Z = 0.22`, `R = 0.16`(움직도르래), `RF = 0.18`, `EYE = 0.22`(= R + 0.06, 아랫 눈 오프셋).
- `displayStand()`
- 들보: `ceilingBeam(-0.9, 0.9, 3.0, [-0.40, -0.24, -0.08, 0.42])` → 고리 아랫점 y = 2.94. 앞 세 고리는 줄 3, 2, 1 의 고정 끝, 마지막은 F 걸이.
- F: `pulleyBlock(0.18, { hookUp: 0.06 })`, 중심 (0.42, 2.66). 윗 눈 (0.42, 2.90) 과 고리 (0.42, 2.94) 를 `rod(…, 0.008)`.
- 움직도르래(모두 반지름 0.16, 두께 0.05, spokes 3): `pulleyBlock(0.16, { hookDown: 0.06, width: 0.05, spokes: 3 })`
  - m1 중심 (0.08, y1), m2 중심 (−0.08, y2), m3 중심 (−0.24, y3)
  - (x 는 한 단계마다 0.16 = R 씩 왼쪽. 그래서 줄 k 의 오른쪽 가닥이 바로 위 도르래의 중심 x 와 같다. F 의 왼쪽 가닥 x = 0.42 − 0.18 = 0.24 = m1 의 오른쪽 가닥.)
- 추: `weight(0.76, 0.30)`, 중심 (−0.24, y3 − 0.45). m3 아랫 눈 (−0.24, y3 − 0.22) 에서 추 윗면 (−0.24, y3 − 0.30) 까지 `rod(…, 0.008)`.
- 자유 끝에 `ropeEnd()`, 위치 (0.60, yF).

### 변수
`p = (1 − cos(theta × 0.5)) / 2`, `u = 0.08 × p` (추가 오른 높이).
- y3 = 1.00 + u
- y2 = 1.48 + 2u
- y1 = 1.96 + 4u
- yF = 1.40 − 8u (자유 끝; 시작 1.40, 끝 0.76)

### 줄 경로 (z = 0.22, a1 < a0 이면 시계방향)
- 줄 3: (−0.40, 2.94) → (−0.40, y3) → `arcPoints([−0.24, y3], R, π, 2π, Z)` (밑을 돎) → (−0.08, y3) → (−0.08, y2 − EYE) [m2 아랫 눈].
- 줄 2: (−0.24, 2.94) → (−0.24, y2) → `arcPoints([−0.08, y2], R, π, 2π, Z)` → (0.08, y2) → (0.08, y1 − EYE) [m1 아랫 눈].
- 줄 1: (−0.08, 2.94) → (−0.08, y1) → `arcPoints([0.08, y1], R, π, 2π, Z)` → (0.24, y1) → (0.24, 2.66) → `arcPoints([0.42, 2.66], RF, π, 0, Z)` (F 를 위로 넘음, 시계) → (0.60, 2.66) → (0.60, yF).

## 동작
- theta 를 `theta += OMEGA(1.6) × speed × dt` 로 누적, 매 프레임 p, u, y1~y3, yF, 줄, 이름표를 다시 계산.
- 도르래 각(`userData.sheave.rotation.z`, 반시계 +):
  - θ_m3 = +u / R, θ_m2 = +2u / R, θ_m1 = +4u / R (고정된 왼쪽 가닥을 타고 굴러 오른다. 위로 갈수록 두 배씩 빠름)
  - θ_F = −8u / RF (시계)
- 이득 8 = 2³: 자유 끝이 8u 내려갈 때 추가 u 오른다.

## 표시
- `rotArrow(0.24, false)` 를 F 앞 (0.42, 2.66, 0.40).
- tag 왼쪽 열 x = −1.15 에서 각 도르래 높이를 따라감: 'm1'(y1), 'm2'(y2), 'm3'(y3), '짐'(y3 − 0.45). 오른쪽: 'F 고정 도르래'(1.25, 2.66), '당기는 곳'(1.25, yF). z 0.4.
- notes: `[{ label: '이득', value: '8배 (2×2×2)' }, { label: '움직도르래', value: '3개' }, { label: '당긴 줄 : 오른 높이', value: (8u).toFixed(2) + ' : ' + u.toFixed(2) }]`

## 확인
- t=0.4 (p ≈ 0): m1~m3 가 계단식으로 낮고 간격 0.48 씩. t=3.9 (p ≈ 1): m3 0.08, m2 0.16, m1 0.32 상승, 자유 끝 0.64 하강.
- 각 줄의 오른쪽 올라가는 가닥이 위 움직도르래 아랫 눈에 정확히 이어진다. 줄 가닥 x 가 서로 달라(−0.40, −0.24, −0.08, 0.08, 0.24, 0.60) 겹치지 않고, m2·m1 윗부분이 줄 1·2 의 왼쪽 가닥 끝과 부딪치지 않는다.
