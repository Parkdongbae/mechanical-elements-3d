# 075 왕복 운동 래칫
판화(public/mm507/fig/075.png, 4배 확대 shots/_verify/075-fig-x4.png · 바퀴 6배 shots/_verify/075-crop-wheel.png 로 다시 읽음): 그림 하나, 축 방향에서 본 정면. 가운데에 톱니(래칫) 바퀴 A(이 약 36개, 안쪽에 동심원 하나 = 테 안쪽 가장자리). 바퀴 위에 시계 방향 화살표. 바퀴 축에는 허브 고리가 끼워져 있고 거기서 **곧은 막대 D** 가 양쪽으로 뻗는다: 왼쪽 위(약 148°)로 긴 팔이 바퀴 테 밖까지 나가 끝에 핀(이중 원)이 있고, 오른쪽 아래(약 −26°)로 짧은 팔이 나가 끝에 핀이 있다(두 팔은 거의 일직선, 174°). 긴 팔 끝 핀에는 **폴 B**(굽은 뿔 모양)가 달려 바퀴 테 위로 시계 방향으로 누워 끝이 약 112° 자리의 이 사이에 들어가 있다. 짧은 팔 끝 핀에서는 **막대 C** 가 곧장 아래로 내려간다(아래 끝은 잘려 있음). 오른쪽 위(약 46°, 바퀴 밖)에 고정 핀(이중 원)이 하나 더 있고 거기서 쉼표 모양의 **멈춤 폴**이 아래로 늘어져 끝이 약 30° 자리의 이에 걸려 있다(글자 없음).
원문 요지: 막대 C 의 왕복 직선 운동이, 흔들리는 막대 D 끝의 폴 B 를 통해 바퀴 A 에 간헐 회전 운동을 준다.

★ 판화 읽기
1. 바퀴는 몇 개이고 크기 차례는? → 톱니(래칫) 바퀴 1개(A). 이는 약 36개(위쪽 간격으로 세면 40, 오른쪽 간격으로 세면 33 — 36 으로 잡음), 이 깊이는 바깥 반지름의 약 9%. 테 안쪽 동심원 반지름 ≈ 바깥의 0.75배.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 겹침만 있다: 막대 D 가 바퀴 **앞**을 가로지르고(D 의 윤곽이 바퀴 위에 그려짐), 막대 C 도 바퀴 아래쪽 이 앞을 지난다.
4. 고정점은? → 바퀴 축(가운데), 멈춤 폴의 핀(오른쪽 위, 바퀴 밖). 판화에 받침대는 없다.
5. 추·손잡이·크랭크는? → 없음. 구동은 막대 C 의 위아래 왕복(원문). C 의 아래 끝은 잘려 있어 무엇이 미는지는 판화로는 알 수 없음.
6. 기어의 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 바퀴 바깥 둘레에 톱니(한쪽은 곧고 한쪽은 비스듬). 폴 B 의 끝이 위쪽(약 112°)에서, 멈춤 폴의 끝이 오른쪽 위(약 30°)에서 이 사이에 든다. 두 폴 모두 끝이 핀보다 시계 쪽에 있고 곧은 면을 시계 방향으로 민다(받친다) → 바퀴는 시계 방향으로만 돈다(화살표와 같다).
7. 한 줄에 놓인 것은? → D 의 긴 팔 핀 — 바퀴 축 — 짧은 팔 핀이 거의 일직선. 막대 C 는 짧은 팔 핀에서 곧은 세로선. D 의 허브는 바퀴 축과 같은 중심.
8. 글자가 가리키는 부품은? → A = 톱니 바퀴, B = 긴 팔 끝의 폴, C = 세로 막대, D = 흔들 막대(원문과 같다). 오른쪽 위 멈춤 폴에는 글자가 없고 원문도 말하지 않는다.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 없음. 방향은 판화로 정했다: C 를 **아래로 당기면** 짧은 팔이 내려가 D 가 시계로 돌고, 긴 팔 끝의 폴이 이를 밀어 바퀴가 시계로 돈다. C 를 올리면 폴은 이 등 위를 미끄러져 돌아가고 멈춤 폴이 바퀴를 붙든다.
- 그 밖의 선: D 의 가는 평행선 = 막대의 두께 표현, 축의 흰 원 = 축 끝, 그 둘레 고리 = D 의 허브(D 는 축에 헐겁게 끼워져 축과 따로 돈다).

## 구동
막대 C 의 왕복(판화에 미는 것은 없음 — 모형은 아래 끝 핀이 세로 안내 홈을 오르내리게 하고 그 운동을 구동으로 본다). theta += OMEGA·speed·dt (OMEGA = 1.6 rad/s), 한 왕복 = theta 2π(약 3.93초). 모든 자세는 `feedState(FEED, theta)` (k074) 한 번으로 정한다.

## 부품과 치수 (키트: `kit/k074.ts` — 이미 구현됨. 좌표는 바퀴 중심 O = (0, 1.70) 기준으로 적고 세계 좌표는 거기에 더한다)
- 톱니 규격 SPEC = { teeth: 36, rOut: 0.78, rRoot: 0.71, dir: −1 } (dir −1 = 시계로만 도는 바퀴, 곧은 면이 반시계 쪽을 봄). 피치 q = 10°.
- 바퀴 A: `sawWheel(SPEC, { width: 0.08, ringR: 0.585, holes: 5 })`, 중심 (0, 1.70), z = 0.04 (z 0.00~0.08). name `wheelA`. rotation.z = st.wheel.
- 축: `shaftZ(0, 1.70, 0.26)` (고정 축 — 바퀴와 D 가 각각 그 위에서 돈다).
- 이송 치수 FEED = { spec: SPEC, rPivot: 0.86, span: 36°, a0: 159.5°, steps: 2, slack: 3° } (각은 라디안으로 넣는다). 긴 팔은 159.5° → 136.5° 로 23°(= 2피치 + 헛걸음 3°) 갔다 온다(판화의 148° 가 그 한가운데).
- 흔들 막대 D: `rockerBar(0.86, 0, 0.39, −174°)` (긴 팔 0.86 = 로컬 +X, 짧은 팔 0.39 = 로컬 −174° 방향). 그룹 position (0, 1.70, 0.13), rotation.z = st.armAngle. name `rockerD`. 허브 구멍 0.05 로 축에 헐겁게.
  - 긴 팔 끝 핀 P = O + 0.86·(cos armAngle, sin armAngle). 짧은 팔 끝 핀 Q = O + 0.39·(cos(armAngle − 174°), sin(armAngle − 174°)).
  - D 의 자식으로 핀 두 개: 긴 팔 끝에 `rod((0.86, 0, −0.13) → (0.86, 0, 0.03), 0.017)` (뒤로 뻗어 폴의 구멍을 지남), 짧은 팔 끝에 `rod((x, y, −0.03) → (x, y, 0.09), 0.02)` (앞으로 뻗어 막대 C 의 눈을 지남, (x, y) = 0.39·(cos(−174°), sin(−174°))). 짧은 팔 끝 핀에 name `pinQ` + markPin.
- 폴 B(구동 폴): shapeB = `pawlShape(SPEC, 0.86, 36°, 0, { wBase: 0.09, wTip: 0.03 })` → 핀–끝 길이 0.5057. `ratchetPawl(shapeB)`, position (P, z 0.04), rotation.z = `followerAngle(SPEC, st.wheel, P − O, shapeB.L, −1)`. name `pawlB`. 바퀴와 같은 층(z 0.01~0.07).
- 멈춤 폴(판화의 오른쪽 위 쉼표 모양): shapeH = `pawlShape(SPEC, 0.98, 15.5°, 0, { wBase: 0.08, wTip: 0.028 })` → 핀–끝 길이 0.3514. 고정 핀 PH = O + 0.98·(cos 49.8°, sin 49.8°) = O + (0.6325, 0.7485) = 세계 (0.6325, 2.4485). `ratchetPawl(shapeH)`, position (PH, z 0.04), rotation.z = `followerAngle(SPEC, st.wheel, PH − O, shapeH.L, −1)`. name `pawlHold`.
  - 받침: `wallPost(0.6325, 2.4485, 0.04)` (gear6 — 뒤판에서 나온 기둥 + 핀).
  - 이 폴은 판화처럼 가파르게 늘어진 꼴이라, 이끝이 지나가면 면에서 2.75° 떨어진 이 등(반지름 0.726)에 내려앉는다(되돌림 유격 2.75°). 모형의 바퀴는 뒤로 돌지 않으므로 유격은 보이기만 한다.
- 막대 C: `eyeRod(0.95)` — 위 눈이 Q, 아래 눈이 미끄럼 핀 S. 그룹 position (Q, z 0.19), rotation.z = atan2(S − Q). name `rodC`.
  - S = (0.3435, Q.y − sqrt(0.95² − (Q.x − 0.3435)²)) (O 기준 x 0.3435 의 세로선 위). 세계 y: 쉬는 자리 0.653 → 다 당긴 자리 0.513. 미끄럼 핀 `rod((S, 0.10) → (S, 0.215), 0.022)`, name `pinS` + markPin.
  - 판화의 C 는 "곧은 세로 막대"다. 모형의 C 는 위 끝이 원호(반지름 0.39, ±11.5°)를 따라가므로 세로에서 ±2.1° 까지 기운다.
- 안내 판(판화에 없음, 보충 부품): `framePlate([(0.2435, 0.38), (0.4435, 0.38), (0.4435, 0.79), (0.2435, 0.79)], [{ a: [0.3435, 0.47], b: [0.3435, 0.70], r: 0.03 }], 0.04)` (k056, 세계 좌표 그대로) 를 z = 0.13 에. 뒤판에 `rod((0.3435, 0.405, −0.30) → (0.3435, 0.405, 0.11), 0.03)`, `rod((0.3435, 0.765, −0.30) → (0.3435, 0.765, 0.11), 0.03)` 두 개로 받친다.
- 뒤판·바닥 `displayStand()`.
- 판화에 없음(보충 부품): 안내 판과 받침 막대 2개, 멈춤 폴의 벽 기둥. 그 밖에는 없다.

## 동작 (모든 자세는 theta 의 절대 함수 — `feedState`)
- u = theta mod 2π, 왕복 횟수 n = floor(theta/2π). 긴 팔이 간 각 a = (23°/2)·(1 − cos u). st.armAngle = 159.5° − a.
- 바퀴가 시계로 돈 누적 각 w: u < π(미는 행정)이면 20°·n + max(0, a − 3°), u ≥ π(돌아가는 행정)이면 20°·(n + 1). **한 왕복에 정확히 2이(20°)** — 누적 오차 없음.
- st.wheel = 159.5° − 3° − 36° − w = 120.5° − w (바퀴 rotation.z. 로컬 각 0 의 곧은 면이 처음에 폴 끝 자리 120.5° 에 있다).
- 폴 B: 미는 동안(a ≥ 3°)에는 끝이 곧은 면 뿌리에 닿은 채 D 와 한 몸으로 돈다(측정: D 에 대한 각 변화 0.007°). 돌아가는 동안에는 이 등을 타고 최대 7.96° 들렸다가 이끝을 넘을 때마다 떨어진다(두 번). 모두 `followerAngle` 이 정한다 — 모델은 따로 경우를 나누지 않는다.
- 멈춤 폴: 바퀴가 도는 동안 이 등에 밀려 6.9°~17.4° 들리고, 이끝이 지나면 떨어진다.
- 막대 C·미끄럼 핀: 위 식의 Q, S.
- 역회전(speed < 0)은 같은 식을 거꾸로 따라간다(되감기).

## notes
- 상태 '밀기(C 내려감) / 헛걸음 / 돌아가기(C 올라감)', 한 왕복에 '2이(20°)', 지금까지 민 이 수(= w/10° 의 정수 부분), 긴 팔 각, 헛걸음 3°.

## 키트 추가
이미 구현됨: `kit/k074.ts` (이 묶음 074·075·076 공용. 075 전용 파일 k075.ts 는 만들지 않는다. 모델은 `'../kit/k074'` 에서 직접 import)
- `sawWheel(spec: SawSpec, opts?: { width?; bore?; holes?; ringR?; kind? }): THREE.Group` — 톱니(래칫) 바퀴. 판 메시 userData.outline, userData.mm = { kind:'ratchet', … }.
- `sawOutline(spec): V2[]`, `sawRadius(spec, a): number` — 윤곽과 극각별 반지름.
- `pawlShape(spec: SawSpec, rPivot: number, span: number, tipA?: number, opts?: PawlOpts): PawlShape` — 폴 윤곽·길이 L·물린 각 lambda0.
- `ratchetPawl(shape: PawlShape, opts?: PawlOpts): THREE.Group` — 폴 부품(원점 = 핀, 끝 = 로컬 +X 의 L). userData.outline.
- `followerAngle(spec: SawSpec, wheelAngle: number, pivot: V2, L: number, side: 1 | -1): number` — 폴 끝이 톱니에 얹힌 자세의 핀 → 끝 방향 각.
- `feedState(f: FeedSpec, theta: number): FeedState` — { u, a, armAngle, w, wheel, pushing }.
- `rockerBar(lenLong: number, aLong: number, lenShort: number, aShort: number, opts?): THREE.Group` — 두 팔 흔들 막대(허브 + 팔 + 끝 보스).
- `eyeRod(length: number, r?: number): THREE.Group` — 양끝에 눈이 달린 이음 막대(원점 = 한쪽 눈, +X).
