# 107 홈 캠으로 만드는 왕복(물결 홈)
원문(106·107 공통): "Uniform reciprocating rectilinear motion, produced by rotary motion of grooved cams." — 홈이 파인 캠의 회전으로 일정한(등속) 왕복 직선 운동을 얻는다. 107번은 드럼 둘레에 물결 모양 홈을 여러 번 파서 한 바퀴에 여러 번 왕복시킨 꼴.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/107-fig-x4.png`, 6배 부분 확대 `shots/_verify/107-fig-crop.png` 로 다시 읽음.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없고 **드럼(원통 캠) 1개**. 가로축에 꿰인 짧고 굵은 원통을 옆에서 본 모습(세로로 긴 네모 = 지름, 가로 = 축 방향 길이). 4배 확대 px: 지름 660, 길이 280(지름 : 길이 ≈ 2.36 : 1), 축 굵기 100.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음. 대신 드럼 겉면에 **물결(지그재그) 홈 한 줄**이 둘레를 따라 돌며 좌우(축 방향)로 흔들린다. 앞면에 오른쪽 꼭대기 3~4개·왼쪽 꼭대기 3개(약 3주기)가 보이고 아래쪽은 그늘에 묻혔다. 홈 폭 ≈ 30px, 좌우 진폭 ≈ ±70~85px(드럼 길이의 ±1/4~1/3).
3. 교차하는 가닥이 있는가? → 없음. 홈은 한 줄로 이어지고 스스로 만나지 않는다.
4. 고정점(천장·벽·바닥)은 어디인가? → 맨 위의 빗금 덩어리 = **천장(고정)**. 거기서 **걸이 2개**가 내려오고, 걸이 아래쪽 구멍에 가로 막대가 꿰여 있다. 드럼 축의 받침은 그리지 않았다(축 왼쪽 끝은 잘린 단면 = 더 이어짐).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 가로 **미끄럼 막대** 가운데에 작은 **블록**(나사 머리가 보임)이 있고, 블록에서 **핀**이 아래로 내려가 드럼 맨 위의 홈에 꽂혀 있다. 구동은 드럼 축(원문 "rotary motion of grooved cams").
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 핀 ↔ 홈 양쪽 벽(캠 짝), 막대 ↔ 걸이 구멍 2개(미끄럼 짝), 드럼 축 ↔ 받침(회전 짝, 판화에는 받침 없음).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 드럼 가운데·핀·블록·두 걸이의 가운데가 같은 세로선(x 867~870px). 막대는 드럼 윗면에서 110px(지름의 1/6) 위에 수평. 걸이 2개는 드럼 양 옆면 바로 위(x 710, 1025px — 드럼 옆면 735, 1010px)에 좌우 대칭.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 107 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 분명하고 계속 돈다. 다만 판화의 물결은 그린 대로면 기울기가 너무 가팔라(둘레 길이로 재면 한 바퀴 8~12주기, 압력각 60° 이상) 실제로는 핀이 끼인다 — 판화가의 과장으로 보고 **한 바퀴 6주기**(앞 절반에 3주기 — 판화에서 또렷이 보이는 수), 압력각 47° 로 정했다. 원문의 "uniform(등속)"에 맞춰 물결은 곧은 비탈 + 둥근 꼭대기(둥근 삼각파). 질문 거리는 없다.
- 그 밖의 선: 드럼의 가로 줄무늬와 아래쪽 검은 칠 = 둥근 면의 그늘. 축 왼쪽 끝의 타원 = 잘린 단면. 걸이 아래 끝이 막대보다 조금 더 내려와 있다(구멍이 걸이 끝에서 조금 위).

## 해석(결정 사항)
- 드럼(홈 캠)이 돌면 맨 위 한 자리에 묶인 핀이 홈 벽에 밀려 좌우로 가고, 핀이 달린 막대가 걸이 구멍 속에서 직선 왕복한다. 106번(한 바퀴 한 번 왕복)의 여러 번 왕복 판.
- 물결 수 6, 진폭 ±0.10, 꼭대기 둥글림 50 %(반주기의 절반은 등속, 나머지는 포물선으로 방향 전환).
- 회전 방향은 판화에 없다 → 드럼 윗면이 앞(보는 사람 쪽)으로 넘어오는 방향으로 정함.
- 판화에 없는 보충: 드럼 축의 벽걸이 축받이 2개(축이 떠 있지 않게), 전시대.

## 구동
드럼 축(theta 누적). theta += OMEGA(1.6)·speed·dt. **캠 각 a = theta/2 + 상수** (물결이 6개라 theta 그대로면 초당 1.5번 떨어서 보기 어렵다 → 절반 빠르기. 한 바퀴 7.85 s 에 6번 왕복, 한 번 왕복 1.31 s).

## 부품과 치수 (새 부품은 모두 `kit/k107.ts`, 이미 구현됨. 치수 상수 `K107`)
배치 상수: CY = 1.5 (드럼 축 높이), ZC = 0.28 (드럼 축·막대·걸이의 z), 드럼 가운데 x = 0. BY = CY + K107.R + K107.barUp = 2.14 (막대 축 높이).
- 홈 캠 드럼(name `drum` — 키트가 rotor 에 붙여 둠): `camDrum107()` → `{ group, rotor, map, set }`. `drum.group.position.set(0, CY, ZC)`. 드럼 반지름 0.48, 길이 0.42(x −0.21 ~ 0.21), 홈 반폭 0.026·깊이 0.05, 축 반지름 0.07(x −0.57 ~ 0.46). 회전축 = X. **돌릴 때는 `drum.set(a)` 만 부른다**(rotor.rotation.x 와 검사용 홈 지도를 함께 맞춘다 — group 을 직접 돌리지 않는다). 청동 드럼 + 강철 축.
- 미끄럼 막대(name `bar`): `sliderBar107()` — 원점 = 막대 축 위·핀 바로 위. 막대 반지름 0.035, 길이 0.84, 가운데 블록 0.13 × 0.11 × 0.11, 핀 반지름 0.022(끝이 드럼 윗면보다 0.042 아래 = 홈 바닥 위 0.008). 위치 (x(θ), BY, ZC). 키트가 child `followerPin`(드럼 윗면 높이)과 검사용 `pinOutline` 을 달아 둔다.
- 천장 들보와 걸이(name `hanger`, 고정): `hangerFrame107(ZC)` — 원점 = 막대 축의 가운데 → 위치 (0, BY, ZC). 걸이 2개 x = ±0.228(두께 0.09, 구멍 반지름 0.04, 구멍 축 = X), 걸이 아래 끝 y = BY − 0.10 = 2.04(드럼 윗면 1.98 위 0.06). 들보 밑면 y = BY + 0.335 = 2.475, 높이 0.2(윗면 2.675), 가로 −0.80 ~ 0.66, 뒤판까지 닿는다. 나무 들보 + 주철 걸이.
- 드럼 축받이 2개(판화에 없음): `wallBearing(−0.44, CY, ZC, 'x', 0.078)`, `wallBearing(0.36, CY, ZC, 'x', 0.078)` (`'../kit/gear6'` 에서 import). 고리 구멍이 X 방향(축 방향)이고 팔은 뒤판에서 나온다 — 기둥이 축에 박히지 않는다. 고리 x 범위 −0.51 ~ −0.37, 0.29 ~ 0.43(드럼 옆 허브 끝 ±0.25 와 닿지 않음).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 범위: 가로 −0.80 ~ 0.66, 세로 1.02 ~ 2.675.

## 동작 (모두 theta 의 닫힌 식 — `cam107(theta)` 가 `{ a, x, p }` 를 돌려준다)
- 캠 각 a = theta/2 − 0.8 + 5π/12. `drum.set(a)`.
- 물결 위상 p = 6·a/2π (주기 단위). 막대 위치 x = 0.10·roundTri(p, 0.5) — `roundTri` 는 −1 ↔ +1 을 오가는 둥근 삼각파(반주기의 가운데 50 % 는 등속, 양 끝 25 % 씩은 포물선).
- `bar.position.set(x, BY, ZC)`. 범위 x = −0.10 ~ +0.10(행정 0.20). 드럼·막대 말고 움직이는 것은 없다.
- 시각: **t = 1.0 (a = 1.309, x = 0.000, 핀이 가운데를 오른쪽으로 지나는 중 — 판화 자세)**, **t = 1.3 (x = +0.099, 오른쪽 끝)**, t = 1.6 (x = +0.022, 돌아오는 중), t = 30 (x = +0.081).

## ★ 깊이 계산
드럼은 축이 가로(X)라 지름이 깊이로 나온다: ZC = 0.28, 최대 반지름 0.48, z −0.20~0.76 (−0.25 ~ 0.8 안). 축 옆 허브(반지름 0.14)·축받이 고리(바깥 반지름 0.128)는 그 안쪽. 막대·블록·걸이는 드럼 축과 같은 깊이에 폭 ±0.08 이내. 들보는 뒤판에 붙어 앞으로 0.48 까지 나온다(드럼 앞끝보다 안쪽). 흔들리는 팔 없음 — 가장 높은 부품은 고정된 들보 윗면 2.675(≤ 3.3), 움직이는 것 가운데 가장 높은 것은 블록 윗면 2.195. 가로는 막대 끝 ±0.52 가 최대(±2.2 안).
