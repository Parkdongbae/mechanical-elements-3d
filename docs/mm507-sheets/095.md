# 095 경사 원판 캠
원문: 세로 축을 돌리면, 기울어진 원판이 그 윗면에 얹힌 세로 막대에 왕복 직선 운동을 준다.
판화 묘사: 옆에서 본 그림 하나. 오른쪽에 빗금 친 벽(단면), 벽 왼쪽 면에 볼트로 붙인 네모 받침, 받침을 꿰뚫고 선 세로 축, 축 꼭대기의 나팔 모양 허브 위에 **모서리로 보이는 기운 원판**(왼쪽이 낮고 오른쪽이 높다), 원판의 높은 쪽 가장자리 위에 **포크에 작은 롤러를 문 세로 막대**.

## ★ 판화 읽기
판화는 그림 하나(옆에서 본 모습). 확대본 `shots/_verify/095-fig-x4.png`, 포크 `095-fork-x8.png`.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴는 없다. 도는 것은 기운 원판 1개(반지름이 축 반지름의 약 8배)와 막대 끝의 작은 롤러 1개(원판 반지름의 약 1/9).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 오른쪽의 빗금 친 덩어리가 벽(또는 기계 틀)의 단면이다. 윗면은 가로선, 왼쪽 면은 세로선. 그 왼쪽 면에 네모난 축 받침이 붙어 있고(받침 오른쪽 끝의 ㄷ 모양 = 볼트 머리), 축이 받침을 세로로 꿰뚫는다. 막대를 세로로 잡아 주는 안내는 그려져 있지 않다(막대 위쪽이 끊겨 있음).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 축 아래쪽이 끊겨 있어 구동 장치는 그림 밖이다(원문: 세로 축을 돌린다).
6. 기어는 어느 가장자리에 이가 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝은 **원판 윗면 ↔ 롤러** 하나뿐이다. 롤러는 포크의 두 갈래 사이에 서 있고 핀이 좌우로(원판의 반지름 방향) 꿰어 있다 — 핀 양쪽 머리가 포크 바깥으로 튀어나와 보인다. 그래서 롤러는 원판이 도는 방향(둘레 방향)으로 구른다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 축·받침 구멍·허브·원판 중심이 한 세로선. 막대는 그 오른쪽 세로선(원판 반지름의 약 0.8배 자리)에 있고 벽 윗면 바로 위를 지난다. 벽 윗면은 허브 아래 끝과 거의 같은 높이.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 원문과 판화가 같고 그대로 계속 돈다(막대는 제 무게로 원판에 얹혀 있다 — 원문 "resting upon its surface").
- 그 밖의 선: 원판 왼쪽 끝의 톱니 모양 = 끊어 그린 자리(원판이 더 이어짐). 받침 속의 세로 겹선 = 받침 속 축. 받침 바로 아래의 얇은 띠 = 축에 끼운 고리(축이 위로 빠지지 않게). 허브와 받침 사이의 흐린 두 세로선 = 축. 판 오른쪽의 굵은 세로선 = 판화 칸막이(부품 아님).
- 판화에서 잰 값: 원판 기울기 14.3°(확대본에서 가로 940 : 세로 240), 원판 반지름 : 막대 자리 = 480 : 380, 축 반지름 61, 받침 높이 195·벽에서 왼쪽으로 415.

## 해석(결정 사항)
- 깊이 제한(z −0.25 ~ 0.8) 때문에 원판 반지름을 0.5 로 잡았다(세로 축 둘레로 도는 원판은 지름이 그대로 깊이가 된다). 나머지는 판화 비율대로.
- 롤러는 둥근 통(반지름 0.06 의 공에서 폭 0.06 만 남긴 띠) — 기운 평면에 한 점으로 닿아 높이 식이 정확한 코사인이 된다. 납작한 원통이면 모서리가 원판을 0.007 파고든다.
- 축 아래 끝의 발받침, 막대 안내(벽 위 기둥·팔·슬리브)는 **판화에 없음** — 떠 있는 부품을 없애려고 더한 최소 보충.
- 구동 장치(손잡이·벨트)는 더하지 않는다. 회전 화살표로 대신한다.

## 구동
세로 축(theta 가 축의 누적 각, 위에서 보아 반시계). theta += OMEGA(1.6)·speed·dt. 축 한 바퀴(3.927 s)에 막대가 한 번 오르내린다.

## 부품과 치수 (모두 키트 `kit/k095.ts`, 이미 구현됨. 값은 `SWASH` 상수)
기준점 P = 원판 윗면의 중심 = (−0.15, 2.0, 0.28). 아래에서 AX = −0.15, HY = 2.0, ZC = 0.28.
- 회전체(name `rotor`): `swashRotor(1.72)` 를 P 에 둔다. 들어 있는 것 — 기운 원판(반지름 0.5, 두께 0.05, 기울기 14°, 높은 쪽 = 로컬 +X, 청동, 높은 쪽 가장자리에 어두운 표시점), 나팔 허브(아래 반지름 0.085 → 위 0.15, 원판 밑면에 맞춰 깎임, P 아래 0.19 까지), 세로 축(반지름 0.06, P 아래 1.72 까지 = 높이 0.28), 받침 밑 고리(P 아래 0.522 ~ 0.555), 축의 키 표시.
- 고정 틀(name `frame`): `swashFrame(1.82)` 를 P 에 둔다(1.82 = P 에서 받침판 윗면 y 0.18 까지). 들어 있는 것 — 벽(x 0.175 ~ 0.85, y 0.18 ~ 1.78, 깊이 −0.17 ~ 0.58), 축 받침(x −0.255 ~ 0.175, y 1.48 ~ 1.68, 깊이 0.18 ~ 0.38, 축 구멍), 볼트 머리, 바닥 발받침(반지름 0.11, y 0.18 ~ 0.28, 판화에 없음), 막대 안내(기둥 x 0.65·y 1.78 ~ 2.72, 팔 y 2.62 ~ 2.72, 슬리브 x 0.25·y 2.57 ~ 2.77, 판화에 없음).
- 막대(name `rod`): `forkRod(0.9)` — 원점 = 롤러 중심. 자리 (AX + 0.4, HY + lift, ZC) = (0.25, 2.0 + lift, 0.28). 롤러(자식 name `roller`, 반지름 0.06, 반폭 0.03, 축 = X), 포크·핀, 막대(반지름 0.025, 롤러 중심 위 0.11 ~ 0.9).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 가로 범위 x −0.65 ~ 0.85, 높이 0.18 ~ 3.07(막대 끝 최고), 깊이 −0.22 ~ 0.78.

## 동작 (모두 theta 의 닫힌 식)
- ψ = theta − 1.6 (t = 1 에서 ψ = 0 — 판화 자세: 원판의 높은 쪽이 막대 쪽).
- `rotor.rotation.y = ψ` (위에서 보아 반시계).
- lift = `swashLift(ψ)` = rr/cosα + rc·tanα·cosψ = 0.0618 + 0.0997·cosψ → `rod.position.y = 2.0 + lift`. 범위 −0.038 ~ 0.162, 행정 0.1995(= 2·rc·tanα). 단순 조화 운동.
- 롤러 굴림: `roller.rotation.x = ψ·(0.4/0.06)` (원판 윗면이 롤러 밑을 −Z 로 지나간다).
- 시각: **t = 1.0 (ψ = 0, 막대 맨 위 — 판화)**, t = 1.6 (ψ = 55°, lift 0.119, 내려가는 중), t = 2.96 (ψ = 180°, 맨 아래 — 원판의 낮은 쪽이 막대 밑).

## 표시
- rotArrow: `rotArrow(0.22, true)` 를 `rotation.x = −π/2` 로 눕혀(화살표가 수평면에, 위에서 보아 반시계) (−0.15, 1.05, 0.28) 에. 세로 축을 감싼다.
- tag 4개: '세로 축(구동)' (−0.95, 1.05, 0.3), '기운 원판' (−0.95, 2.4, 0.3), '롤러 달린 막대' (1.15, 2.35, 0.3), '벽에 붙은 축 받침' (−1.0, 1.58, 0.3).

## notes
① 행정 '막대 행정 = 2 × 0.4 × tan 14° ≈ 0.20' ② 지금 막대 높이(lift, 소수 둘째 자리)와 '올라감 / 내려감'(sinψ < 0 이면 올라감) ③ '원판 기울기 14°, 한 바퀴에 한 번 왕복' ④ 구동 회전수.

## 확인
- t = 1 정면: 판화와 같은 모양 — 원판이 모서리로 보이고 왼쪽이 낮고 오른쪽이 높다, 막대가 맨 위. t = 2.96 정면: 원판 기울기가 반대, 막대가 0.2 내려와 있음. t = 1.6: 원판이 타원으로 보임.
- 근접 `cam=0.9,2.5,1.6,0.1,2.1,0.28`(롤러와 원판 윗면의 접점), 옆 `cam=3.0,2.1,0.28,0,2.0,0.28`(+X 에서 — 깊이), 위 `cam=-0.15,4.6,0.3,-0.15,2.0,0.28`.
- 수치: `node shots/_verify/s095.mjs` → 롤러 ↔ 원판 평면 거리 오차 0(1e−16), 접점의 X 치우침 최대 0.0145(롤러 반폭 0.03 안), 원판 가장자리 최저와 벽 윗면의 틈 0.0505, 포크 갈래와 원판의 틈 0.01 이상, 막대 끝 최저(P 위 0.862)가 슬리브 위(0.77)보다 높음.

## ★ 깊이 계산
세로 축 둘레로 도는 기운 원판이 깊이로 지름을 낸다: ZC = 0.28, 최대 반지름 0.5, z −0.22~0.78 (기울어도 가로 뻗음은 0.5·cos14° + 0.05·sin14° = 0.497 ≤ 0.5). 벽 깊이 −0.17 ~ 0.58, 그 밖의 부품은 ZC ± 0.12 안.

## 키트 추가
이미 구현됨: `kit/k095.ts` 의
- `SWASH`(치수 상수: R, th, alpha, rc, rr, rw, shaftR, wallTop, wallX, sleeveY0, sleeveY1)
- `swashRotor(shaftDown: number): THREE.Group` — 세로 축 + 고리 + 나팔 허브 + 기운 원판. 원점 = 원판 윗면 중심, 회전축 = 로컬 Y
- `swashFrame(baseDrop: number): THREE.Group` — 벽 + 축 받침 + 발받침 + 막대 안내. 원점 = 원판 윗면 중심
- `forkRod(len: number): THREE.Group` — 포크·롤러 달린 세로 막대. 원점 = 롤러 중심, 자식 name `roller`
- `swashLift(psi: number): number` — 롤러 중심 높이(원판 윗면 중심 기준)
모델은 `'../kit/k095'` 에서 직접 import.
