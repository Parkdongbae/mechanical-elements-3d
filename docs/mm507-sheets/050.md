# 050 유니버설 조인트 (1) — 8자 틀 이중 십자형
원문: 두 가지 유니버설 조인트(50·51 공통의 한 줄). 카탈로그의 영문은 뒤쪽이 52번 이후 설명과 섞여 있다(OCR) — 이 번호에 해당하는 말은 "Two kinds of universal joints" 뿐이다.

★ 판화 읽기 (질문표) — 판화 `public/mm507/fig/050.png`, 4배 확대 `shots/_verify/050-fig-x4.png` 를 설계표보다 먼저 보고 적음. 비스듬히 위에서 본 입체 그림.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 부품은 ① 가운데 **8자 틀**(안경테처럼 둥근 고리 두 개가 잘록한 허리로 이어진 띠 고리) 1개, ② 그 두 고리 안에 **X 모양 십자** 2개, ③ 양쪽 축 끝의 **길쭉한 고리 포크** 2개(두 가지가 틀의 고리를 바깥에서 감쌈) + 축 2개.
2. 줄·벨트는? → 없음.
3. 교차하는(서로 꿰인) 곳은? → 포크의 두 가지가 틀의 고리 한 개를 사이에 끼고, 십자의 한 팔은 포크 가지 끝의 눈(작은 원)에, 다른 팔은 틀 띠의 눈(작은 원)에 꿰인다. 조인트가 **두 곳**(왼쪽 고리, 오른쪽 고리).
4. 고정점은? → 판화에 받침 없음(두 축 끝이 끊겨 그려짐, 왼쪽 축 끝은 깃 홈). 축받이 2개는 **판화에 없음(보충)**.
5. 추·손잡이·크랭크는? → 없음. 왼쪽 축을 구동으로 삼는다(원문에 지정 없음).
6. 기어는? → 없음.
7. 한 줄에 놓인 것은? → 두 십자와 틀이 거의 수평 한 줄, 두 축은 그 양 끝에서 각각 약 45°(재 보면 47°·48°)로 아래 바깥쪽으로 꺾여 위가 뾰족한 'ㅅ' 꼴 — 좌우 대칭. 두 축 사이 꺾임은 모두 90°쯤을 틀이 반씩 나눠 받는다.
8. 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 알 수 없는 곳은? → ① 틀 아래로 가로지르는 띠(양 끝에 작은 원)는 **따로 된 연결대가 아니다** — 비스듬히 내려다본 띠 고리의 **앞쪽 변**(띠의 폭이 보이는 것)이고 작은 원은 틀 쪽 핀이 꿰인 눈이다(가운데 빗금 = 띠의 바깥 면). ② 원문은 구조를 설명하지 않는다 → 판화대로 이중 십자(후크) 조인트로 만든다. 계속 도는 데 막히는 곳 없음.

구동: 입력축(왼쪽). `theta += OMEGA·speed·dt`, 입력각 φ1 = theta.

## 해석(결정 사항)
- **(S1b 판정) 이중 후크 조인트라는 읽기는 판화와 일치.** [입력 포크 ─ 십자 ─ 틀 왼쪽 고리] 와 [틀 오른쪽 고리 ─ 십자 ─ 출력 포크]. 틀은 한 몸이라 두 십자의 틀 쪽 핀이 서로 평행하다.
- **(S1b 에서 고침)** ① 처음 표는 틀을 "긴 둥근 판에 둥근 사각 구멍 둘(허리 없음)"로 만들었다 → 판화처럼 **둥근 고리 두 개가 잘록한 허리로 이어진 8자**로 다시 만들고(고리 바깥 반지름 0.36, 구멍 0.25, 허리 반폭 0.13, 띠 두께 0.07), 띠 가장자리에 핀 눈 4개를 달았다. 십자 사이 거리도 1.10 → 0.80 으로 줄여 두 고리가 붙어 보이게 했다. ② "판화 아래의 연결대는 생략"이라는 처음 판단은 틀렸다 — 연결대는 원래 없다(질문 9-①). ③ 처음 치수(포크 가지 ±0.22)로는 **포크 가지가 틀의 고리 끝을 뚫고 지나갔다**(표본점 검사: 한 바퀴 117만 점 가운데 22,328 점이 틀 속 — 처음의 긴 판 틀에서도 같은 자리에서 뚫림). 판화의 포크는 틀의 고리를 넉넉히 감싸는 긴 고리이므로 가지를 **±0.34** 로 벌렸다(고리가 가지 쪽으로 가장 기울 때 0.36·sin 45° + 0.035 = 0.29 < 0.34 − 0.034). 다시 재면 0 점.
- 꺾임 각은 입력·출력 모두 β = 45°. 십자 중심 J1 (−0.40, 1.55, 0.28), J2 (+0.40, 1.55, 0.28), 틀 중심 (0, 1.55, 0.28).
- 비등속식: 조인트 하나는 `tan χ = cos β1 · tan φ1`, 이중이면 `tan φ2 = (cos β1 / cos β2) tan φ1`. β1 = β2 이면 φ2 = φ1(출력 등속), 틀만 입력보다 최대 ±9.9° 앞서고 뒤선다.

## 이미 구현됨 (키트 추가) — kit/gear6.ts, 모델 작성자는 다시 만들지 않는다
- `universalJointPair(beta1 = 45°, beta2 = 45°): JointAssembly` — 입력 포크+축, 출력 포크+축, 십자 2개, 8자 틀, 받이 2개. `{ group, set(theta): HookeState, anchors, beta1, beta2 }`. 부품 name: `yokeIn`, `yokeOut`, `cross1`, `cross2`, `frame8`.
- `hookeAngles(phi1, beta1, beta2): HookeState = { phi1, chi, phi2, dChi, dOut }`, `FR8`(틀 치수), `YOKE_D`(포크 가지 거리 0.34), `quatZTo(dir)`.
- 검증: 십자 두 팔 직교·두 십자의 틀 쪽 핀 평행(처음 작성 때, 내적 0). `shots/_verify/s046-050.ts`: 한 바퀴 360 자세에서 포크 가지·눈·가로대·허브 겉면 표본 124만 점 가운데 **틀 속에 든 점 0**(새 8자 틀 + 가지 ±0.34), t = 1 → 1.6 에서 `yokeIn` −0.9600, `yokeOut` +0.9600 rad(각자 축 바깥 방향 기준 — 크기 같음), 틀 1.0943 rad. 전체 상자 x −1.31~1.31, y 0.64~1.93(표본 자세 기준).

## 부품과 치수 (assembly 안 — 참고용)
- 틀 `frame8`(강철): 중심 x = ±0.40 인 원 고리 둘(바깥 반지름 0.36, 구멍 반지름 0.25)이 허리(반폭 0.13)로 이어진 윤곽, 띠 두께 0.07, 핀 눈 4개(고리마다 위·아래), 허리에 표시점. X 축 둘레로 돈다.
- 십자 `cross1`·`cross2`: 가운데 정육면체 0.09 + 포크 쪽 팔 ±0.38(반지름 0.024, 가지 끝 눈을 꿰어 나옴) + 틀 쪽 팔 ±0.38(틀 띠의 눈을 꿰어 나옴).
- 입력 포크 `yokeIn`(청동)·출력 포크 `yokeOut`(황동): 축(반지름 0.05, 십자 중심에서 0.42~1.25), 허브(반지름 0.10), 가지 두 개(반지름 0.034, 핀 방향 ±0.34 — 키트 상수 `YOKE_D`) + 가지 끝 눈 + 가지를 잇는 가로대, 축 끝 표시점.
- 축 방향: 입력 u1 = (−cos β, −sin β, 0), 출력 u2 = (cos β, −sin β, 0). 축 끝 ≈ (∓1.28, 0.67).
- 받이(판화에 없음): 각 축의 십자 중심에서 0.95 되는 곳 — (−1.07, 0.88), (+1.07, 0.88) 에 `wallBearing(x, y, 0.28, 방향 벡터, 0.058)`.

## 동작
- 입력 포크 각 = φ1 = theta. 틀 각 `χ = atan2(cos β1 · sin φ1, cos φ1)`(연속각), 출력 각 `φ2 = atan2(sin χ, cos β2 · cos χ)`. `dChi = χ − φ1`, `dOut = φ2 − φ1`(β 가 같으면 0).
- 자세는 핀 벡터에서 `Matrix4.makeBasis` 로 정한다: 입력 포크 핀 p1 = cos φ1·Ẑ + sin φ1·eb1, 틀 쪽 핀 q = normalize(X̂ × p1), 출력 포크 핀 p2 = normalize(u2 × q). 전부 `set` 안.
- 표본: theta 1.6(t=1): φ1 = 91.7°, χ = 92.4°. theta 2.56(t=1.6): φ1 = 146.7°, χ = 155.1°(+8.4°). 틀이 가장 앞서는 곳 φ1 ≈ 135°(+9.9°).
- 모델 `update(dt, speed)`: `theta += OMEGA * speed * dt; st = asm.set(theta);`

## 표시
- rotArrow(축에 직각으로 세움): 입력 `rotArrow(0.2, false)` — `quaternion = quatZTo(u1)`, 위치 (−1.14, 0.81, 0.28); 출력 `rotArrow(0.2, true)` — `quatZTo(u2)`, 위치 (1.14, 0.81, 0.28).
- tag(`anchors`): '입력축' `anchors.input` (−1.45, 0.38, 0.55), '출력축' `anchors.output` (1.45, 0.38, 0.55), '8자 틀(가운데)' `anchors.frame` (0, 2.05, 0.55), '십자(핀)' `anchors.cross1` (−0.70, 2.45, 0.60).
- notes: ① '입력축 각(도)' → `mod(phi1, 360)` ② '가운데 틀 − 입력(도)' → `(dChi*180/π).toFixed(1)` ③ '출력 − 입력(도)' → `(dOut*180/π).toFixed(1)` + ' (꺾임이 같아 0)' ④ '식(조인트 하나)' → `'tan χ = cos 45° · tan φ  (최대 ±9.9°)'`.
- view: `{ pos: [0.5, 2.6, 5.0], target: [0, 1.4, 0.28] }`(판화처럼 조금 위에서 내려다봄 — 틀의 두 구멍과 십자가 보이게).

## 확인
- 판화 대조(E1): 'ㅅ' 꼴로 꺾인 두 축, **잘록한 허리의 8자 틀**(구멍 두 개가 보임), 구멍마다 십자, 포크 가지가 고리를 감쌈. 틀이 눕는 자세(theta ≈ 0, π)에서 판화와 가장 비슷하다.
- t=1·1.6 정면: 입력·출력 표시점이 같은 각만큼 돈다(91.7° → 146.7°).
- 근접 `cam=-0.4,2.0,1.2,-0.4,1.55,0.28`·`cam=0.4,2.0,1.2,0.4,1.55,0.28`: 십자 몸통이 구멍 한가운데, 포크 가지 눈이 십자 팔 끝에, 틀 쪽 팔이 띠의 눈을 꿰고 있다. 두 시점 이상에서 포크 가지·가로대가 틀을 뚫지 않는다(꼭짓점 검사 0 — 눈으로 한 번 더).
- 위 `cam=0,3.6,1.0,0,1.55,0.28`·옆 `cam=3.4,1.55,0.28,0,1.55,0.28`: 포크·틀이 돌 때 z −0.16~0.72 안.
