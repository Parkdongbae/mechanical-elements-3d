# 050 유니버설 조인트 (1)
판화: 가운데에 8자 모양의 납작한 틀(큰 둥근 구멍 두 개가 좌우로 나란하고 가운데 잘록한 허리)이 눕고, 틀의 왼쪽·오른쪽 구멍 안에 작은 X 모양 십자(핀)가 하나씩 들어 있다. 왼쪽 구멍에는 긴 타원 고리(포크, 가는 막대 두 개가 감싼 모양)가 걸리고 그 고리 끝이 왼쪽 아래로 뻗어 굵은 축이 되며 축 끝은 홈이 난 키 자리다. 오른쪽에도 같은 고리와 축이 오른쪽 아래로 뻗는다. 두 축은 틀을 가운데로 위가 뾰족한 'ㅅ'(역 V) 모양으로 꺾여 있다. 틀 아래로 가는 막대(고리와 핀으로 이어진 연결대)가 가로지른다.
원문(해석 가능한 부분만): 유니버설 조인트 두 종류. 축이 꺾여 있어도 회전을 전한다.
구동: 입력축(왼쪽). `theta += OMEGA·speed·dt`, 입력각 φ1 = theta (입력축 둘레, 십자 중심 쪽으로 향하는 방향이 +).

## 해석(결정 사항)
- 판화는 8자 틀 하나를 사이에 둔 **이중 후크(훅) 조인트**로 읽었다: [입력 포크 ─ 십자 ─ 틀 왼쪽 구멍] 과 [틀 오른쪽 구멍 ─ 십자 ─ 출력 포크]. 두 십자는 틀 구멍 안에 있다. 틀은 평면이라 두 십자의 틀 쪽 핀이 서로 평행하다(V자 배치 → 틀의 비등속이 서로 상쇄).
- 꺾임 각은 입력·출력 모두 β = 45°(판화의 'ㅅ' 모양). 십자 중심: J1 (−0.55, 1.55, 0.28), J2 (+0.55, 1.55, 0.28), 틀 중심 (0, 1.55, 0.28).
- 판화 아래의 연결대(가는 막대)는 구현하지 않는다(틀이 두 십자를 이미 잇는다). 의문점에 적음.
- 이 표의 '정확한 비등속식': 조인트 하나만 보면 입력 φ1, 틀 χ 사이 `tan χ = cos β1 · tan φ1`; 이중이면 출력 `tan φ2 = tan χ / cos β2 = (cos β1 / cos β2) tan φ1`. β1 = β2 이면 φ2 = φ1(출력은 등속), 틀은 입력보다 앞서고 뒤서며 최대 ±9.9° 흔들린다(sin δmax = (1 − cos β)/(1 + cos β)).

## 이미 구현됨 (키트 추가) — kit/gear6.ts, 모델 작성자는 다시 만들지 않는다
- `universalJointPair(beta1 = 45°, beta2 = 45°): JointAssembly` — 입력 포크+축, 출력 포크+축, 십자 2개, 8자 틀, 받이 2개(`wallBearing` 방향 벡터형). `{ group, set(theta): HookeState, anchors, beta1, beta2 }`. `set(theta)` 가 모든 자세를 벡터로 다시 계산한다(핀 p1(φ1) = cosφ1·Ẑ + sinφ1·eb1, 틀 핀 q = normalize(X̂ × p1), 출력 핀 p2 = normalize(u2 × q)).
- `hookeAngles(phi1, beta1, beta2): HookeState = { phi1, chi, phi2, dChi, dOut }` — 위 식(연속각으로 풀어 줌).
- `quatZTo(dir)` — +Z 를 dir 로 보내는 회전(회전 화살표를 축에 직각으로 세울 때).
- 검증(node): 십자 두 팔이 직교(내적 0.000000), 입력·출력 핀이 틀 핀 q 와 직교(0.000000), 두 십자의 q 가 같음(차 0.000000), 틀 y 축 = q. 식 tan χ = cos β tan φ 와 일치(0.96534 = 0.96534), β2 = 25° 일 때 tan φ2 = (cos β1/cos β2) tan φ1 와 일치(1.06513). β1 = β2 이면 φ2 − φ1 = 0(3.6e-15). 틀 편차 −9.88°~+9.88°. 전시 영역 x −1.46~1.46, y 0.64~1.85, z −0.30~0.58.

## 부품과 치수 (assembly 안 — 참고용)
- 틀(강철): 윤곽 `roundedRect(−0.92, −0.30, 0.92, 0.30, 0.30)`(긴 둥근 판), 구멍 두 개 `roundedRect(−0.86, −0.20, −0.24, 0.20, 0.20)`, `roundedRect(0.24, −0.20, 0.86, 0.20, 0.20)`, 두께 0.05, 위쪽에 표시점. 틀 가운데는 허리(가운데 판 0.48 폭).
- 십자: 가운데 정육면체 0.09 + 핀 팔 ±0.20(포크 쪽, 반지름 0.024) + 틀 쪽 팔 ±0.27(틀 변 안에 끝남).
- 입력 포크(청동)·출력 포크(황동): 축(반지름 0.05, 길이 1.2 — 십자 중심에서 0.42~1.25), 허브(반지름 0.10), 포크 가지 두 개(반지름 0.034, 핀 방향 ±0.22, 십자 중심까지) + 가지 끝 눈(핀 구멍) + 가지를 잇는 가로대, 축 끝 표시점.
- 축 방향: 입력 u1 = (−cos β, −sin β, 0), 출력 u2 = (cos β, −sin β, 0). 입력 축 끝 ≈ (−1.40, 0.70), 출력 축 끝 ≈ (+1.40, 0.70).
- 받이: 각 축 중간(십자 중심에서 0.95)에 뒤판 팔 + 보스 링(`wallBearing(x, y, 0.28, 방향, 0.058)`): (−1.22, 0.88)과 (+1.22, 0.88) 근처.

## 동작
- 입력 포크 각 = φ1 = theta(축 u1 둘레, `−u1` 방향이 +: 가로 축 쪽으로 돌려 들어가는 방향).
- 틀 각 χ: `χ = atan2(cos β1 · sin φ1, cos φ1)` (연속각으로 풀어 줌, 틀은 X 축 둘레 +방향). `dChi = χ − φ1`.
- 출력 각 φ2: `φ2 = atan2(sin χ, cos β2 · cos χ)`(연속). `dOut = φ2 − φ1` (β1 = β2 이면 0).
- 십자 두 개와 두 포크, 틀은 위 핀 벡터로부터 `Matrix4.makeBasis` 로 방향을 정한다 — 항상 두 핀이 직교하고 틀·핀이 십자에 박히지 않는다.
- 표본: theta = 1.6(t=1): φ1 = 91.7°, χ = 92.4°(+0.7°), φ2 = 91.7°. theta = 2.56(t=1.6): φ1 = 146.7°, χ = 155.1°(+8.4°), φ2 = 146.7°. 틀이 입력보다 가장 앞서는 곳은 φ1 ≈ 135°(+9.9°), 가장 뒤서는 곳은 ≈ 45°(−9.9°)·225°.
- 모델 `update(dt, speed)`: `theta += OMEGA * speed * dt; st = asm.set(theta);`

## 표시
- rotArrow(축에 직각으로 세움): 입력 `rotArrow(0.2, false)` — `quaternion = quatZTo(u1)`, 위치 = J1 + 1.05·u1 근처 (−1.29, 0.81, 0.28) — 입력은 `−u1` 방향 둘레(+) 이므로 ccw 는 false; 출력 `rotArrow(0.2, true)` — `quatZTo(u2)`, 위치 (1.29, 0.81, 0.28), ccw true. (입력 축 방향 벡터 u1 = (−0.707, −0.707, 0), u2 = (0.707, −0.707, 0).)
- tag(`anchors`, 3개 이상): '입력축' `anchors.input` (−1.45, 0.38, 0.55), '출력축' `anchors.output` (1.45, 0.38, 0.55), '8자 틀(가운데)' `anchors.frame` (0, 2.05, 0.55), '십자(핀)' `anchors.cross1` (−0.70, 2.45, 0.60), 같은 이름 `anchors.cross2` (0.70, 2.45, 0.60) 또는 하나만.
- notes: ① '입력축 각(도)' → `mod(phi1,360)` ② '가운데 틀 − 입력(도)' → `(dChi*180/π).toFixed(1)` ③ '출력 − 입력(도)' → `(dOut*180/π).toFixed(1)` + ' (β1=β2 라 0)' ④ '식(조인트 하나)' → `'tan χ = cos 45° · tan φ  (최대 ±9.9°)'`.
- view: `{ pos: [0.5, 1.9, 5.4], target: [0, 1.4, 0.28] }`(꺾인 축이 잘 보이게).

## 확인
- t=1, t=1.6 정면: 입력·출력 표시점(축 끝 노란 표시)이 같은 각만큼 돈다(φ1 91.7° → 146.7°). 틀의 표시점은 입력보다 0.7° → 8.4° 앞선다(눈으로 구분이 어려우면 `mmcheck` 의 moved 로).
- 근접(십자 한 곳) `cam=-0.55,2.0,1.2,-0.55,1.55,0.28`·`cam=0.55,2.0,1.2,0.55,1.55,0.28`: 십자 가운데 몸통이 틀 구멍 한가운데, 포크 가지 눈이 십자 팔 끝에 있고 틀 변에 팔이 끝나 있다. 두 시점(theta 1.6, 2.56 이상)에서 포크 가지·십자가 틀을 뚫지 않는다(키트 검사 직교 확인됨, 시각 확인).
- 위 `cam=0,3.6,1.0,0,1.55,0.28`·옆 `cam=3.4,1.55,0.28,0,1.55,0.28`: 틀이 X 축 둘레로 돌며 z −0.02~0.58, 포크 가지 z 가 0.8 이하.
- 판화 대조(G6): 'ㅅ'자로 꺾인 두 축, 틀의 두 구멍 안 십자, 가지가 구멍을 감싸는 고리 포크 — 부품 수 일치(포크 2·십자 2·틀 1).

## 의문점
- 판화의 연결대(틀 아래 가로 막대)와 고리 끝 위치의 정확한 역할을 원문이 설명하지 않는다(원문의 해당 부분은 51번 이후 설명과 섞여 있음). 이 표는 틀 하나가 두 십자를 잇는 이중 후크로 해석했다. 필요하면 틀 아래 연결대는 장식으로 추가할 수 있다.
- 한 개짜리 후크 조인트(출력이 비등속)를 보이려면 `universalJointPair(45°, 30°)` 처럼 β 를 다르게 주면 `dOut` 이 0 이 아니게 된다(성능 확인용). 기본은 45°·45°.
