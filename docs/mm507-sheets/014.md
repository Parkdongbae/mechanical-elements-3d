# 014 복활차 (블록과 태클)
판화: 위에 **고리로 매달린 도르래 블록**(가로로 누운 나무 원통, 안에 홈 4개), 아래에 같은 모양의 **움직이는 블록**(아래 갈고리에 둥근 공 모양 추). **한 가닥 줄**이 위아래 블록의 도르래 4개씩을 번갈아 지나며 비스듬히 엇갈려 내려오고, 끝은 위 블록 오른쪽에서 오른쪽 아래로 비스듬히 늘어진다. 원문: 힘의 이득은 "아래 블록의 도르래 수의 두 배"(= 줄 가닥 수 8)로 계산한다.
구동: 줄의 자유단(손)을 당겼다 놓는다. 아래 블록이 d 올라가면 자유단은 8d 내려온다.
이 판화는 블록을 **옆에서** 본 모습 — 블록의 축이 X 방향(가로)이고 줄은 YZ 평면에서 도르래를 감는다(정면에서는 줄이 수직선으로 겹쳐 보이고 도르래 사이를 오갈 때만 비스듬하다).

## 부품과 치수
- `displayStand()`
- 들보: `BoxGeometry(1.9, 0.12, 0.65)` castIron, 중심 (0.1, 3.07, 0.05).
- 블록 축 방향 X, z 중심 zc = 0.25. 도르래 4개의 x: x_j = (j − 1.5) × 0.16 = −0.24, −0.08, 0.08, 0.24 (j = 0..3). 도르래 폭 0.12, 줄 중심 반지름 RC = 0.22 → `pulley(0.20, { width: 0.12, grooved: true, spokes: 4 })`. 007 처럼 **감싸는 그룹 `rotation.y = π/2`**(로컬 Z → 월드 X) 에 넣고, 안쪽 풀리의 `rotation.z` 가 X축 회전이다.
- 블록 껍데기(위·아래 공통): 양쪽 볼(나무 `wood()` 원판 반지름 0.26, 두께 0.04, 회전축 X) x = ±0.34, 가운데 축 막대 `rod(V3(−0.40, y, 0.25), V3(0.40, y, 0.25), 0.03)`. 도르래 사이 틈 0.04.
- **위 블록 U**: 중심 (0, 2.55). 위로 막대 `rod(V3(0,2.81,0.25), V3(0,2.94,0.25), 0.03)` + 고리(`TorusGeometry(0.05, 0.012, …)`, 중심 (0, 2.99, 0.25), XY 평면), 들보 아래 핀에 건다. 위치 고정.
- **아래 블록 L**: 중심 (0, y_L), y_L = 1.20 + d. 아래로 막대 `rod((0, y_L−0.26, 0.25), (0, y_L−0.46, 0.25), 0.03)` + 고리(중심 (0, y_L − 0.50, 0.25)). 그 아래 공 추: `SphereGeometry(0.14)` darkSteel, 위에 고리(`TorusGeometry(0.04,…)`), 중심 (0, y_L − 0.78, 0.25).
- **줄**: 012 의 `ropeAround` 를 **map = (u, v, w) → V3(w, v, u)** (u = z, v = y, w = x)로 쓴다. 모두 ccw: 줄이 뒤쪽(z−) 선을 따라 내려와 아래 도르래 밑을 돌아 앞쪽(z+) 선으로 올라가 위 도르래 위를 넘어 다시 뒤쪽으로 내려오는 방향이 (z, y) 평면에서 반시계다. `new Rope(0.018)`.
  ```
  ropeAround(
    { p: [0.03, 2.55], w: x_0 },                 // 묶는 점: 위 블록 첫 도르래 뒤쪽 가장자리(높이 2.55)
    [ L0, U0, L1, U1, L2, U2, L3, U3 ],           // 아래 L_j = { c:[0.25, y_L], r:0.22, ccw:true, w:x_j }, 위 U_j = { c:[0.25, 2.55], r:0.22, ccw:true, w:x_j }
    { p: [0.03, y_E], w: 0.62 },                  // 자유단
    { seg: 12, map: (u, v, w) => new THREE.Vector3(w, v, u) })
  ```
  줄 가닥: ① 묶는 점 → L0 (뒤쪽 수직) ② L0 → U0 (앞쪽 수직) ③ U0 → L1 (뒤쪽, x 가 x_0 → x_1 로 이동 → 비스듬히 엇갈림) ④ L1 → U1 … ⑧ U3 → 자유단(뒤쪽을 내려오며 x 가 0.24 → 0.62 로 벌어져 오른쪽 아래로 늘어진다). 아래 블록에 닿는 가닥 수 = 8.
- 자유단 손잡이: `rod(V3(0.62, y_E, 0.03), V3(0.62, y_E − 0.16, 0.03), 0.05)` + 구 반지름 0.06.

## 키트 추가
없음 — 012 의 `kit/rope.ts`(`ropeAround`, `map` 인자 포함)를 쓴다.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- 올림 d(theta) = 0.10 × (1 − cos(0.5 × theta)) (0 ~ 0.2).
- 아래 블록 y_L = 1.20 + d (추도 같이). 자유단 y_E = 2.05 − 8d (0.45 ~ 2.05).
- 도르래 회전(모두 같은 방향, 도르래마다 속도가 다름 — 각각 헐거운 도르래). 반시계(z,y)이므로 월드 X 회전은 음수 → 안쪽 풀리 `rotation.z = −φ`:
  - 위 U_j: φ = (2j + 2) × d / 0.22 (2, 4, 6, 8 배)
  - 아래 L_j: φ = (2j + 1) × d / 0.22 (1, 3, 5, 7 배)
  (줄 속도: 묶는 점 쪽 가닥 0 → 2d → 4d → 6d → 8d, 아래 블록이 d 로 올라가는 것을 반영.)
- 줄은 매 프레임 `ropeAround` → `setPath`.

## 표시
- `rotArrow(0.3, …)` 은 두 블록 옆(x = 0.5, YZ 평면에 눕힘)에 하나씩. tag '위 블록(고정)', '아래 블록(움직)', '추', '당기는 끝(8배 이동)'.
- notes: `[{ label: '줄 가닥 수(아래 블록)', value: '8' }, { label: '힘의 이득', value: '8배 (힘 1/8)' }, { label: '추 올라간 높이', value: d.toFixed(2) }, { label: '당긴 줄 길이', value: (8 * d).toFixed(2) }]`
- view: `{ pos: [1.3, 2.1, 5.8], target: [0, 1.7, 0] }` (블록의 옆면·줄의 엇걸림이 보이게 살짝 비스듬히).

## 확인
- 정면 t=0.5(d ≈ 0.01) 와 t=3.9(d ≈ 0.2): 아래 블록이 0.2 올라가 있고 자유단 손잡이는 그 8배(1.6) 내려가 있다. 네 개 도르래의 표시점이 서로 다른 각으로 돌아 있다.
- 비스듬히 `cam=2.0,1.8,3.4,0,1.6,0`: 줄이 위·아래 도르래 홈을 번갈아 감고 이웃 도르래로 건너갈 때 비스듬히 엇갈린다. 줄이 블록 볼·뒤판을 뚫지 않는다.
