# 112 페르시아식 드릴
원문 요지: 페르시아 드릴. 드릴 몸통(stock)에는 아주 급한 나사가 났고, 몸에 대고 누르는 위쪽 머리에 받쳐져 자유롭게 돈다. 나사 가운데의 단추(너트)를 손으로 꼭 쥐고 몸통을 따라 빠르게 위아래로 당기면 몸통이 오른쪽·왼쪽으로 번갈아 돈다.

## ★ 판화 읽기
판화는 그림 하나(세로로 선 드릴). 4배 확대 `shots/_verify/112-fig-x4.png` 로 다시 읽음(치수는 4배 그림의 px).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 세로 막대 하나에 꿰인 것이 위에서부터 **버섯 꼴 머리**(갓 지름 365px) → 머리 아래 **고리**(지름 170px, 높이 50px) → **꼬인 나사 몸통**(지름 100px, 길이 890px) → 가운데의 **실패 꼴 너트**(테 지름 320px, 높이 195px) → **네모 물림쇠**(가로 135px, 높이 110px) → **날**(지름 60px, 길이 190px, 끝이 뾰족).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음(활 드릴과 달리 줄이 없다 — 너트를 손으로 직접 민다).
3. 교차하는 가닥이 있는가? → 없음. 몸통의 빗금은 모두 오른쪽 위로 올라가는 "/" 한 방향 — 여러 줄의 급한 오른나사(빗금 사이 세로 35px, 기울기 약 55°).
4. 고정점(천장·벽·바닥)은 어디인가? → 판화에 없음. 원문으로는 머리가 "몸(가슴)에 기대어" 고정되고, 날 끝이 뚫을 물건에 닿는다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 손잡이 = 가운데 너트(위 테 높이 70px, 오목한 허리 75px, 아래 테 50px). 몸통 한가운데보다 17px 위에 그려졌다. 손은 그리지 않았다.
6. 이는 어디에 났고 무엇이 어느 쪽에서 물리는가? → 몸통 바깥의 나사산 ↔ 너트 구멍 안쪽(보이지 않음). 머리 ↔ 몸통 위 끝은 회전 짝(머리는 돌지 않고 몸통만 돈다).
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 머리·고리·몸통·너트·물림쇠·날이 모두 한 세로 중심선 위(x 850px).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 112 뿐).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 다르지 않고, 너트를 오르내리는 대로 몸통이 번갈아 돈다. 문제 없음.
- 그 밖의 선: 너트 허리의 가로 짙은 띠는 오목한 홈의 그늘. 머리 갓 아래의 벌어지는 두 곡선은 목. 물림쇠 아래로 가늘어지는 선은 날의 어깨.

## 해석(결정 사항)
- 몸통 나사: 6줄, 리드 0.8(한 바퀴에 0.8 — 판화 빗금 기울기 55°에서 2π × 0.095 × tan 55° ≈ 0.85). 판화는 12줄쯤으로 더 촘촘하나 산이 보이도록 6줄로 줄였다(리드·기울기는 판화대로).
- 너트는 돌지 않고 오르내리기만 한다(손이 잡는다). 손은 만들지 않고, 너트 옆면에 "돌지 않음"을 보이는 노란 점을 둔다. 너트는 몸통 나사에 끼워져 받쳐진다.
- 판화에 없음(최소 보충): 머리를 뒤판에 붙이는 받침 팔(가슴 대신), 날 끝이 얹히는 받침 나무(뚫을 물건).

## 구동
너트(theta 누적 → 위아래 왕복). theta += OMEGA(1.6)·speed·dt, 너트 높이 nutY = 0.5·sin(theta − 1.6). 한 번 오르내림 3.93 s.

## 부품과 치수 (새 부품은 모두 `kit/k110.ts`, 이미 구현됨. 치수 상수 `K112`)
배치 상수: 축 x = 0, 깊이 ZC = 0.3, 날 끝 높이 0.40.
- 받침 나무(name `work`, 고정, 판화에 없음): `workBlock112(0.22)` 를 (0, 0.40, 0.3) 에. 가로 0.8 × 높이 0.22 × 깊이 0.5, 윗면이 y 0.40(날 끝 자리), 아랫면이 받침대 윗면 0.18.
- 드릴 몸통(name `stock`): `drillStock112()` 을 (0, 0.40, 0.3) 에. 축 = Y, 원점 = 날 끝. 아래에서부터: 날(0 ~ 0.34, 반지름 0.05, 끝 뾰족) → 네모 물림쇠(0.34 ~ 0.54, 맞변 0.24 — 네모라 도는 것이 보인다) → 나사 몸통(0.54 ~ 2.14, 골 반지름 0.075, 산 반지름 0.095, 6줄 오른나사) → 머리 속 핀(2.14 ~ 2.26, 반지름 0.05). 황동 나사 + 짙은 강철 날.
- 머리(name `head`, 고정): `drillHead112(0.6)` 을 (0, 2.544, 0.3) 에(몸통 나사 위 끝 2.54 바로 위, 틈 0.004). 고리(반지름 0.153, 높이 0.09) + 벌어지는 목(0.126) + 버섯 갓(반지름 0.33, 높이 0.153). 꼭대기 y 2.91. 갓 뒤에서 뒤판까지 받침 팔(판화에 없음). 나무.
- 손잡이 너트(name `nut`): `drillNut112()` 을 (0, 1.74 + nutY, 0.3) 에. 실패 꼴: 테 반지름 0.29, 허리 반지름 0.225, 전체 높이 0.35(아래 테 0.09, 허리 0.135, 위 테 0.125 — 판화처럼 위 테가 더 두껍고 윗모서리가 비스듬). 짙은 나무.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 ±0.4, 세로 0.18 ~ 2.91.

## 동작 (모두 theta 의 닫힌 식 — `drill112(theta)` 가 돌려준다)
`const D = drill112(theta)` → { nutY, psi, dir }. `const sp = stockSpan112()` → { y0: 0.54, mid: 1.34, y1: 2.14 }.
- nutY = 0.5·sin(theta − 1.6) — t = 1 에서 0(몸통 한가운데 = 판화 자세), 올라가는 중.
- `nut.position.y = 0.40 + sp.mid + D.nutY` (1.24 ~ 2.24). 너트 전체 범위 1.065 ~ 2.415 가 나사 몸통 0.94 ~ 2.54 안(위아래 0.125 씩 남음).
- `stock.rotation.y = D.psi` — psi = −2π·nutY / 0.8. 너트가 0.8 올라가면 몸통이 위에서 보아 시계 방향으로 한 바퀴, 내려가면 반시계로 한 바퀴. 한 번 훑을 때(1.0) 1.25바퀴씩 번갈아 돈다.
- **매 프레임 `setSection112(stock, sp.mid + D.nutY)`** 를 부른다 — 몸통의 단면 윤곽을 너트 높이로 옮겨, "몸통 단면이 너트 구멍 안에 있는가"를 자동 검사가 볼 수 있게 한다(식이 틀리면 단면이 구멍 밖으로 0.016 나간다).
- 시각: **t = 1.0 (nutY 0, psi 0 — 판화 자세)**, **t = 1.6 (nutY +0.410, 몸통 −0.512바퀴, 올라가는 중)**, t = 2.0 (맨 위 +0.5, −0.625바퀴, 방향 바뀜), t = 30 (nutY +0.331, 내려가는 중).

## 표시
- rotArrow 2개(도는 방향이 바뀌므로 번갈아 보임): `rotArrow(0.24, false)` 와 `rotArrow(0.24, true)` 를 둘 다 rotation.x = −π/2 로 눕혀 물림쇠 가운데 높이 (0, 0.84, 0.3) 에(네모 물림쇠 모서리 반지름 0.17 바깥 — 나사·너트를 가리지 않는다). `D.dir` 이 +1(너트가 올라가는 중)이면 앞의 것(위에서 보아 시계)만, −1 이면 뒤의 것(반시계)만 visible.
- tag 이름표 4개: '머리(고정)' (1.2, 2.75, 0.3) 고정, '급한 나사 몸통' (−1.3, 2.2, 0.3) 고정, '손잡이 너트' (1.25, 1.74 + nutY, 0.3) — 너트를 따라 오르내린다(update 에서 position.y), '드릴 날' (−1.0, 0.75, 0.3) 고정.
- view: 전시대 전체가 보이게 조금 오른쪽 위에서 — pos (0.9, 2.2, 6.3), target (0, 1.6, 0.2).

## notes
① 너트 — '올라가는 중 / 내려가는 중, 가운데에서 +0.41 (끝은 ±0.5)' ② 몸통 — '위에서 보아 시계로 도는 중 / 반시계로 도는 중, 지금 −0.51 바퀴' ③ 나사 — '6줄, 리드 0.8: 너트를 0.8 밀면 한 바퀴' ④ 한 번 훑기 — '너트 1.0 → 몸통 1.25 바퀴'.

## 확인
- t = 1 정면: 판화와 같은 모양(위에 버섯 머리, 가운데 실패 꼴 너트, 아래 네모 물림쇠와 뾰족한 날). t = 1.6 정면: 너트가 0.41 올라가고 네모 물림쇠가 반 바퀴 돌아 있음.
- 근접 `cam=1.8,2.3,4.0,0,1.5,0.2`(너트·나사 산), `cam=1.2,1.0,2.2,0,0.6,0.3`(물림쇠·날 끝·받침 나무), 옆 `cam=3.5,2.4,0.3,0,2.4,0.3`(머리 받침 팔이 뒤판에 닿는지).
- 수치(이미 잼): `node shots/_verify/s110.mjs` — 몸통 단면 ↔ 너트 구멍: 옳은 식에서 구멍 밖 0.0000, 안쪽 여유 0.0026 / psi 를 0.9배 하거나 부호를 뒤집으면 구멍 밖 0.0160(검사가 잡는다). 몸통 메시 ↔ 나사 면 식 차 0. 그림 `node shots/_verify/s110draw.mjs` → `shots/_verify/s110-sheetB.png` 의 3·4번째 칸.

## ★ 깊이 계산
ZC = 0.3, 최대 반지름 0.33 → z −0.03~0.63 (최대 반지름 0.33 은 머리 갓). 너트 z 0.01~0.59(옆면 노란 점까지 0.612), 물림쇠 모서리 z 0.13~0.47, 받침 나무 z 0.05~0.55. 받침 팔은 갓 뒤에서 뒤판 앞면까지.
흔들리는 팔은 없다. 가장 높은 점: 머리 꼭대기 2.91. 너트 윗면 최고 = 1.74 + 0.5 + 0.175 = 2.415(머리 고리 아랫면 2.544 아래), 너트 아랫면 최저 = 1.74 − 0.5 − 0.175 = 1.065(물림쇠 윗면 0.94 위).
