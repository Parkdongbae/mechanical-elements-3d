# 117 요크 안의 캠과 롤러
원문 요지: "요크 안에서 두 마찰 롤러 사이에 작용하는 캠. 증기 기관의 밸브를 움직이는 데 쓰인 적이 있다."(이 두 문장이 전부) — 캠이 돌면 위·아래 롤러를 번갈아 밀어, 롤러를 단 틀(요크)이 위아래로 왕복한다. 캠은 어느 방향으로 재도 두 롤러 사이의 폭이 같아서 두 롤러가 늘 함께 닿는다(스프링 없이 양쪽으로 끌려 다닌다).

## ★ 판화 읽기
판화는 그림 하나(정면, 세로로 긴 그림). 4배 확대 `shots/_verify/117-fig-x4.png`, 요크 부분 3배 `shots/_verify/117-fig-c.png` 로 다시 읽음.
1. 바퀴는 몇 개이고 크기 차례는? → 캠 1개(둥글지 않은 큰 판)와 롤러 2개(위·아래, 같은 크기). 판화 치수(원본 px): 캠의 축에서 위로 69, 아래로 147, 오른쪽 127, 왼쪽 97 → 위 + 아래 = 216, 왼 + 오른 = 224 로 **어느 쪽으로 재도 폭이 거의 같다**(지름이 일정한 캠). 롤러 반지름 34(캠 최소 반지름의 약 0.5배), 축(빗금 원) 반지름 46.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음. 겹침 순서: 캠의 윤곽선은 옆 막대·굵은 마디가 지나는 자리에서 끊긴다 → **옆 막대가 캠 앞**을 지난다. 빗금 친 축 단면은 두 옆 막대 사이에 꼭 끼어 그려졌다(막대 안쪽 간격 ≈ 축 지름).
4. 고정점은? → 맨 아래의 가로 판(오른쪽 끝이 톱니 꼴 파단선 = 더 이어지는 고정 몸체. 아래 막대가 이 판을 꿰뚫고 내려간다) = 막대 안내(밸브 상자의 덮개쯤). 캠 축은 제자리에서 돈다(받침은 그리지 않음). 위 막대는 잘려 있어 그 위의 안내는 보이지 않는다 — 모형은 위 막대에도 안내 고리를 하나 둔다(판화에 없음).
5. 추·손잡이·크랭크는? → 없음. 구동은 캠 축(원문: 캠이 롤러에 작용).
6. 이는 어디에 났고 무엇이 물리는가? → 기어 없음. 맞닿는 짝: 캠 윤곽 ↔ 위 롤러(캠의 위쪽에서), 캠 윤곽 ↔ 아래 롤러(캠의 아래쪽에서). 롤러는 요크의 위·아래 가로대에서 V 꼴로 모이는 받이(두 줄의 빗선)의 끝 핀에 달렸다. 판화 순간에는 캠의 가장 큰 반지름이 아래를 향해 **요크가 가장 낮은 자리**다(요크 가운데가 축보다 행정의 절반만큼 아래).
7. 한 줄에 놓인 것은? → 위 막대·위 롤러 중심·캠 축·아래 롤러 중심·아래 막대가 한 세로선. 옆 막대 둘은 그 세로선에 대칭. 위·아래 가로대는 수평.
8. 글자가 가리키는 부품은? → 글자 없음(번호 117 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 다른 곳 없음. 다만 판화의 캠 윤곽은 손으로 그린 울퉁불퉁한 선이라(왼쪽 아래의 잘록한 곳, 오른쪽 아래의 작은 턱) 그대로는 두 롤러가 함께 닿지 못한다 → 판화의 네 방향 반지름 비(위 최소·아래 최대·오른쪽이 왼쪽보다 큼)를 지키는 매끈한 "지름 일정" 곡선으로 만든다(아래 "해석"). 기구는 같으므로 사용자 확인 불필요.
- 그 밖의 선: 옆 막대 가운데의 굵은 네모 = 막대에 끼운 굵은 마디(슬리브). 고정 안내인지 막대의 일부인지 판화로는 알 수 없음 → 요크와 함께 움직이는 마디로 본다(안내는 위·아래 막대가 맡는다). 옆 막대 끝의 작은 턱·아래 가로대 밑의 작은 꼭지 = 막대 끝 고리와 너트. 아래 가로대 밑의 두 겹 턱 = 아래 막대의 플랜지. 위 막대 꼭대기의 타원 = 잘린 둥근 막대의 단면.

## 해석(결정 사항)
- 캠 = 지름이 일정한 캠: 롤러 중심이 그리는 피치 곡선 ρ(α) 가 ρ(α) + ρ(α + 180°) = 1.02(두 롤러 중심 사이 거리)를 늘 만족. 캠 윤곽은 그 곡선을 롤러 반지름만큼 안으로 물린 곡선. 최소 반지름 0.25, 최대 0.53(들림 0.28 = 요크 행정), 판화 비(69 : 147 → 0.25 : 0.53)와 같다.
- 판화처럼 한쪽이 불룩하게: 최대·최소 자리 뒤로 40.5° 머문 뒤 코사인 곡선으로 넘어간다 → 판화 자세에서 오른쪽 반지름 0.452, 왼쪽 0.328(판화 127 : 97).
- 옆 막대는 4개(앞 둘·뒤 둘)로 한다. 판화는 정면이라 앞의 둘만 보인다 — 캠·롤러가 옆 막대 뒤 평면에 있으므로(3번), 가로대를 깊이 방향으로 길게 하고 캠 뒤쪽에도 한 쌍을 두어야 요크가 한쪽으로 쏠리지 않는다(뒤의 한 쌍은 판화에 없음 — 가려진 것으로 봄).
- 회전 방향은 판화에 없다 → 반시계로 정함. 판화의 순간(요크 최저)을 t = 1 로.
- 캠 축 반지름은 판화 비(캠 최소 반지름의 0.67배)보다 조금 가늘게 0.12(판화 비대로면 0.17 — 캠 허브가 롤러 받이에 너무 가깝다).

## 구동
캠 축(name `shaft`)과 캠(name `cam`). theta += OMEGA(1.6)·speed·dt, 캠 각 c = theta − 1.6 (반시계). 한 바퀴 3.93 s 에 요크 한 번 왕복.

## 동작 (모두 theta 의 닫힌 식)
- 캠·축: `cam.rotation.z = shaft.rotation.z = c`, c = theta − 1.6.
- 요크: `yoke.position.y = CY + yokeLift117(c)` (= 위 롤러 쪽 피치 반지름 ρ(90° − c) − 0.51, 범위 ±0.14). c = 0 에서 최저(−0.14, 판화 자세) → 139.5° 까지 오름 → 180° 까지 꼭대기에서 머묾(+0.14) → 319.5° 까지 내림 → 360° 까지 바닥에서 머묾.
- 롤러: `rollerTop.rotation.z = rollerTurn117(c, true)`, `rollerBottom.rotation.z = rollerTurn117(c, false)` (닿는 자리의 캠 둘레 속도를 따라 구르는 어림 식, 둘 다 시계 방향, 캠 한 바퀴에 3.25 바퀴).
- 시각: **t = 1.0 (c = 0, 요크 −0.14 = 판화 자세)**, **t = 1.6 (c = 55°, 요크 −0.046 오르는 중)**, t = 2.96 (c = 180°, 요크 +0.14 꼭대기), t = 4.0 (c = 275°, 내리는 중).
