# 006 반원 세그먼트로 왕복 회전
판화: 위 가운데에 양 끝에 공(손잡이)이 달린 수평 레버, 레버 가운데 축에 붙은 **반원 세그먼트**(아래로 열린 반원 림 + 스포크 5개). 세그먼트 림에서 벨트가 X자로 엇걸려 내려와 아래 양쪽의 같은 크기 풀리 2개를 감고, 아랫가닥이 두 풀리 밑을 잇는다. 원문: 레버가 받침점을 중심으로 왕복하면 엇걸이 벨트가 아래 두 풀리에 왕복 회전을 준다.
구동: 레버(왕복).

## 부품과 치수
- `displayStand()`
- 받침점 P = (0, 2.8), `shaftZ(0, 2.8)`. 레버: 길이 2.7 의 둥근 막대(반지름 0.035, steel) 가 P 를 지나 수평, 양 끝에 공(반지름 0.07, brass), 가운데 허브(원통 반지름 0.1). z = 0.3.
- 세그먼트 S: 레버와 한 몸(같은 그룹). 림 = 반지름 Rs = 0.62 의 **아래쪽 반원**(각 π ~ 2π) 띠, 폭 0.14(z 방향), 바깥면에 얕은 홈. 스포크 5개(허브 → 림, 각 π+π/6·k, k=1..5), 림 양 끝은 레버에 닿는다. 재질 brass, `driver` 느낌으로 bronze.
- 아래 풀리 L, R: r = 0.34, 중심 (∓1.05, 0.85), z = 0.3, `pulley(0.34, { spokes: 4 })`, 각자 `shaftZ`.
- 벨트(폭 0.12): `beltPathAround([{ c:[0,2.8], r:0.63, ccw:true }, { c:[1.05,0.85], r:0.35, ccw:false }, { c:[-1.05,0.85], r:0.35, ccw:false }])`(004 의 키트 추가). 세그먼트와 풀리의 감는 방향이 달라 그 사이 두 가닥은 교차 접선, 두 풀리 사이(아랫가닥)는 바깥 접선이 된다. 교차부는 002 처럼 두 가닥 z 를 0.27 / 0.33 으로 띄운다.
  벨트는 세그먼트 림 양 끝에 고정된 것으로 본다(세그먼트는 반 바퀴 안에서만 움직인다) — 경로는 고정, 표시점만 흐른다.

## 동작 (구동 = 레버의 왕복)
- 레버·세그먼트 각 φ = 0.55 × sin(theta). (theta 는 누적 각, OMEGA 기본값)
- 벨트 이동량 s = Rs × φ → `belt.setOffset(s)`.
- L, R 각 = −s / 0.34 (엇걸이라 세그먼트와 반대 방향, 둘은 같은 방향 — 아랫가닥으로 이어져 있다).
- 세그먼트 림이 벨트 위에서 미끄러지지 않는 것처럼 보이게 표시점(림 위 작은 점 3개)이 벨트 표시와 같이 움직인다.

## 표시
- 레버 위에 양방향 굽은 화살표(`rotArrow` 두 개를 반대로) — '왕복'. 아래 풀리에도 양방향 화살표. tag '레버(왕복)', '반원 세그먼트', '종동 풀리'.
- notes: `[{ label: '레버 각도', value: (φ·180/π).toFixed(0) + '°' }, { label: '풀리 각도', value: (−s/0.34·180/π).toFixed(0) + '°' }, { label: '각도비', value: '1 : ' + (0.62/0.34).toFixed(2) }]`

## 확인
- t=1 과 t=2.6(sin 부호가 바뀌는 두 시점): 레버가 반대쪽으로 기울고, 두 풀리 스포크도 반대쪽으로 돌아가 있다. 풀리는 같은 방향, 레버와는 반대 방향.
- 벨트가 X 자로 교차하고 세그먼트 림 아래쪽을 감는다.

## 자동 검사 후 수정 (Opus, 2026-11-25)
autocheck fail(전시 영역·교차 가닥 틈)을 고쳤다. 본문의 P = (0, 2.8), 레버 길이 2.7, 진폭 0.55, 교차부 z 0.27/0.33 은 **옛 값**이다.
- 받침점 **P = (0, 2.5)**, 레버 길이 **2.4**, 진폭 **φ = 0.5 sin θ** — 레버 끝 공의 최고 y = 2.5 + 1.2·sin0.5 + 0.07 ≈ 3.145(뒤판 위 끝 3.15 안, 예전 3.575).
- 교차부 두 가닥 z = **0.245 / 0.355**(DZ 0.055) — 로프 지름 0.09 보다 0.02 더 벌어져 서로 박히지 않는다(예전 0.06 간격, −0.003 박힘).
- 이름표 '레버(왕복)' (1.0, 2.75), '반원 세그먼트' (−0.95, 1.65) 로 옮김(레버 끝 공과 겹치지 않게).
