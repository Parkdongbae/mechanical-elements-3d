# 066 추를 이용한 점프 운동
원문: 64번을 바꾼 것. 스프링과 캠 대신, 웜기어 축에 놓인 팔에 추 D 를 달아 쓴다. (64번: 웜 → 웜기어 B. 웜기어 축을 감싼 속 빈 축에 캠이 붙고, 속 빈 축의 짧은 한 부분은 반쯤 잘려 있다. 웜기어 축에 박힌 핀이 속 빈 축을 돌리다가, 압력 방향이 바뀌면 캠이 웜기어와 상관없이 갑자기 떨어지고 핀이 따라잡을 때까지 쉰다.)

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴는 몇 개이고 크기 차례는? → 웜기어 B 하나(둥근 바퀴) + 그 아래 가로 웜(나사) 하나. 웜은 B 지름의 약 1/4 굵기, 나사산 3~4바퀴.
2. 줄·벨트는? → 없음.
3. 교차하는 가닥은? → 없음.
4. 고정점은? → 판화에는 받침이 없다(웜 축 양끝이 잘린 채, 오른쪽 끝에 작은 고리 = 손잡이 자리).
5. 추·손잡이·크랭크는? → 큰 공 모양 추 D 가 곧은 팔 끝에 달렸다. 팔은 B 의 축을 **둘러싼 고리(= 속 빈 축)** 의 바깥에서 시작해 위(오른쪽으로 약 14° 기울어)로 뻗는다. 팔 길이(축 → 공 중심)는 B 이끝 반지름의 약 1.9배, 공 반지름은 약 0.6배. 팔은 B 앞을 지나간다(실선이 B 를 가림).
6. 기어의 이는 어디에 났고 무엇이 물리는가? → B 의 바깥 둘레에 이. 맨 아래에서 웜이 문다. **이는 아래쪽 7개쯤만 그리고 나머지 둘레는 점선 두 줄(이끝원·피치원)로 줄여 그렸다 — 이가 없다는 뜻이 아니다.** (67번도 같은 그림 방식: 추에 가리지 않은 왼쪽 아래 둘레도 점선이다. 이가 없는 테라면 실선 원 바깥에 아무것도 그리지 않았을 것이다.) 나사산은 정면에서 `\` 로 기운다(오른나사).
7. 한 줄에 놓인 것은? → B 의 축과 웜의 가운데가 같은 세로선. 웜 축은 가로.
8. 글자가 가리키는 부품은? → B = 웜기어, D = 추. 화살표(B 위쪽, 왼쪽 아래를 향함) = 반시계.
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → **있다.** 원문은 "팔이 웜기어 축에 고정"이라고만 하는데, 웜은 거꾸로 돌릴 수 없어(자기 잠금) 팔이 축에 그대로 붙어 있으면 추가 떨어질 수 없다. 판화에는 축 둘레에 넓은 고리가 있고 팔이 그 고리에 붙어 있다 → 64번의 **속 빈 축(반쯤 잘림) + 핀**을 그대로 두고 캠·스프링만 팔·추로 바꾼 것으로 읽는다. 핀과 잘린 자리는 판화에 보이지 않는다(64번에서 가져옴). ★질문 참조.
- 그 밖의 선: 축 단면의 빗금 = 잘린 축. 추의 굵은 오른쪽 윤곽 = 음영.

## 해석(결정 사항)
- **웜기어 B 는 온 둘레에 이가 있고 쉬지 않고 천천히 돈다.** 뛰는 것은 B 가 아니라 **추 달린 팔**이다(앞 설계표는 점선을 "이 없는 테"로 읽어 B 가 통째로 떨어지게 했다 — 판화·64번과 다른 기구라 버린다).
- 팔은 속 빈 축에 붙어 웜기어 축 위에서 헐겁게 돈다. 속 빈 축 앞쪽 끝은 반쯤(180°) 잘려 있고, 웜기어 축에 박힌 핀이 그 잘린 자리 안에서 돈다 → 핀과 팔 사이에 반 바퀴 가까운 헐거움.
- 한 주기(B 한 바퀴): 핀이 팔을 맨 아래에서 오른쪽으로 돌려 꼭대기까지 올림(반 바퀴) → 꼭대기를 넘는 순간 추의 무게로 팔이 핀보다 앞서 왼쪽으로 쏟아져 맨 아래까지 떨어짐 → 맨 아래에서 조금 흔들리다 서서, 핀이 따라잡을 때까지 쉼(반 바퀴 가까이).
- 정확한 진자 풀이 대신 주기 시간표(아래). 모든 자세는 theta 의 함수.
- 웜 세트(웜·웜기어·받침)는 **067번과 같은 치수·같은 식**을 쓴다.

## 구동
웜(가로축, 판화의 손잡이 달린 축). theta += 0.8·speed·dt 가 **웜기어 B 의 각 ψ**(B 한 바퀴 = 한 주기 7.85 s), 웜 각은 24·ψ(19.2 rad/s). OMEGA(1.6) 대신 0.8 인 까닭: 웜이 24배로 돌아 너무 빨라 보이는 것을 줄이려고(067 과 같다).

## 동작 (모두 theta 의 함수, 절대 자세)
- B 각 ψ = theta. 웜(그룹 안 로컬) `worm.rotation.x = 24ψ`, B(그룹 안 로컬) `wheel.rotation.z = ψ + π/2 − π/24` (067·031 의 오른나사 식. 그룹이 π 돌아 있어 실제로는 B 반시계, 웜이 맨 아래).
- 주기 변수 c = (ψ + 2.1) mod 2π.
- 팔 각 α(c) — 맨 아래에서 반시계로 잰 각:
  - c ∈ [0, π): **올림** α = c (핀이 속 빈 축의 벽 끝을 밀어 올림. 맨 아래 → 오른쪽 → 꼭대기).
  - c ∈ [π, π + 0.6): **떨어짐** u = (c − π)/0.6, α = max(c, π + π·(1 − cos(πu/2))) (꼭대기를 넘으며 점점 빨라져 맨 아래까지).
  - c ∈ [π + 0.6, 2π): **쉼** s = c − (π + 0.6), α = 2π + 0.3·e^(−s/0.25)·sin(12 s) (맨 아래를 조금 지나쳤다가 두어 번 흔들리고 섬).
- 팔 자세: `armGroup.rotation.z = α − π/2` (α = 0 이면 팔이 아래, α = π 이면 위).
- 핀: 핀 반각 δ = 0.025/0.13 = 0.19 rad. `pinGroup.rotation.z = P = c − δ` (올림 동안 핀 앞면이 벽 끝(팔 로컬 90°)에 닿는다: P + δ = (α − π/2) + π/2).
- 헐거움 검사: 앞섬 λ = α − c. 최대는 쉼 첫 흔들림에서 약 2.64 rad < π − 2δ = 2.76(반대쪽 벽 끝이 핀 뒤에 닿기 전) → 핀이 벽을 뚫지 않는다. λ ≥ 0 (떨어짐 식의 max, 쉼에서는 2π − c > 0).
- 시각표: t = 0 → c = 2.1(올리는 중). **t = 1.0 → c = 2.9, α = 166°: 판화 모양(팔이 꼭대기 조금 오른쪽).** t ≈ 1.3 꼭대기. t = 1.6 → c = 3.38(떨어지는 중, 팔이 왼쪽 위 → 왼쪽). t = 2.05 → 맨 아래 도착. t ≈ 2.1 ~ 6.55 쉼. 그 뒤 다시 올림.
