# 251 말뚝 박는 기계의 해제 고리
원문(en): "Releasing-hook, used in pile-driving machines. When the weight, W, is sufficiently raised, the upper ends of the hooks, A, by which it is suspended, are pressed inward by the sides of the slot, B, in the top of the frame; the weight is thus suddenly released, and falls with accumulating force on to the pile-head." — 말뚝 박는 기계의 해제 고리. 추 W 가 충분히 올라가면 추를 매단 고리 A 의 윗끝이 틀 꼭대기 홈 B 의 옆면에 밀려 안쪽으로 오므라들고, 추는 갑자기 풀려 쌓인 힘으로 말뚝 머리 위에 떨어진다.
쉬운 풀이: 줄로 고리 받침을 끌어 올리면 받침에 핀으로 달린 두 집게(고리 A)가 추 W 의 T 머리를 물고 함께 올라간다. 집게 윗끝이 틀 꼭대기의 깔때기 홈 B 에 들어가면 홈 옆면이 윗끝을 안쪽으로 밀어 집게가 핀을 중심으로 돌고, 아래 발끝이 바깥으로 벌어져 추가 떨어진다. **집게를 돌리는 것은 홈 B 의 옆면이다(시간표로 돌리지 않는다).**
판화 묘사(원본 501×461 px, [x·y]): 세로 기둥 둘(왼쪽 x 130~165, 오른쪽 300~335)과 위 가로대(y 12~40, x 118~348). 가로대 가운데에 글자 B, 그 아래 면에서 위로 좁아지는 비스듬한 두 선(왼쪽 [183·40]→[193·13], 오른쪽 [267·25]→[257·13]) = 깔때기 홈 B. 줄이 가운데([232·0~80])로 내려와 작은 고리([232·80])에 매이고, 그 밑에 가로 막대([175~290·97])와 짙게 칠한 받침 덩이(위 계단꼴 [200~265·100~140], 아래 마름모 [215~250·150~200]). 받침 아래쪽 핀 두 개([205·183], [262·183]) 둘레로 초승달꼴 집게 둘: 윗팔은 바깥으로 휘며 올라가 끝([190·65], [276·65])이 바깥으로 말렸고, 아랫부분은 핀 밑에서 안쪽으로 굽어 T 꼴 머리([217~247·200~213])의 밑을 받친다. T 머리 줄기가 내려가 큰 추 W([158~306·245~410], 네 모서리 옆에 둥근 턱 = 기둥을 끼고 미끄러지는 신발)에 이어진다. 기둥 사이 뒤쪽 가로선(y 195, 240, 410)은 틀의 뒤 가로대.

## ★ 판화 읽기
판화 하나(정면). 세계 1 px ≈ 0.0065, 판화 x 232 = 세계 x 0.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 바퀴 없음. 줄을 감는 감개(드럼) 1 개를 틀 꼭대기 위에 보충(판화 밖, 줄이 위로 나가는 곳).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 줄 1 개: 받침 꼭대기 고리 → 곧게 위로 → 홈 B 의 가운데를 지나 → 감개 드럼의 왼쪽 면에 감김. 바퀴를 돌아 꺾이는 곳 없음(곧은 줄 + 드럼에 감긴 띠).
3. 교차하는 가닥이 있는가? → 없음. 줄은 두 집게 윗끝 사이 한가운데를 지난다.
4. 고정점은? → 두 기둥(땅 덩이 위에 섬)과 위 가로대(기둥 위에 얹힘), 가로대 홈 B 옆면의 덧판, 감개 축 받침(뒤판). 땅 덩이 = 고정.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 추 W 는 T 머리로 두 집게 발끝에 매달림(풀리면 말뚝 위에 얹힘). 판화에 손잡이 없음 → 감개 축 앞끝에 크랭크 보충.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 집게 발끝이 T 머리 밑을 **안쪽으로** 받치고(각 집게는 자기 쪽 핀에 달림, 서로 엇갈리지 않음), 윗끝은 홈 B 옆면에 **안쪽에서** 닿는다.
7. 한 줄에 놓인 것은? → 줄·받침 고리·T 머리·추 가운데·말뚝이 한 세로선(x 0). 두 핀이 같은 높이, 두 집게 끝이 같은 높이(좌우 대칭).
8. 판화에 글자가 가리키는 부품은? → A = 두 집게(고리), B = 틀 꼭대기 가로대의 홈, W = 추.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳은? → (가) 판화 집게는 발끝이 핀보다 안쪽이라 추 무게가 집게를 벌리는 쪽으로 돈다 — 그대로 두면 처음부터 풀린다. 그래서 받침 기둥과 두 윗팔 사이에 **누름 스프링 2 개**를 넣어 윗팔을 바깥으로 밀어 둔다(판화에 없음, 내릴 때 발끝이 T 머리를 다시 물려면 어차피 필요) → ★질문 거리. (나) 판화의 홈 옆면 기울기(세로에서 약 20°)로는 가로대 두께 안에서 윗끝을 0.10 밀어 넣지 못한다 → 가로대를 조금 두껍게(0.22), 옆면을 세로에서 33° 로. (다) 판화에는 말뚝·땅·감개가 없다 → 땅 덩이와 말뚝 머리, 꼭대기 감개를 보충. (라) 한 번 칠 때마다 말뚝이 0.04 들어가므로 주기를 닫으려고 추가 높이 들린 동안 말뚝이 사라졌다(0.5 초) 0.04 위에서 다시 나타난다(247 번의 '새 공' 처리와 같은 규약) → ★질문 거리. (마) 판화의 집게 끝은 바깥으로 말렸으나, 홈 옆면에 닿는 곳이 한 점이 되게 둥근 코(반지름 0.03)로 줄였다.

## 해석(결정 사항)
- **움직임의 원인**: 감개 크랭크가 줄을 감아 받침을 올린다(받침 높이 Yp 만 시간표). 집게 각 α 는 **홈 B 옆면이 코를 밀어서**(올라갈 때·내려올 때), 또는 **T 머리 모따기가 발끝을 밀어서**(다시 물 때) 정해지고, 닿지 않을 때는 스프링이 α 0 으로 되돌린다. 추 높이는 발끝이 받친 높이(물린 동안), 자유 낙하(풀린 뒤), 말뚝 머리(얹힌 동안)로 정해진다.
- 오른쪽 집게 `hookR` 는 반시계(+α)로 돌 때 윗끝이 안쪽, 발끝이 바깥으로 간다. 왼쪽 집게 `hookL` 은 x 거울(`rotation.z = −α`).

## 구동
주기 12 초, `tc = t mod 12`. ss(u) = u²(3 − 2u) (u 를 0~1 로 자름). Yo 1.38, Ytop 2.17143.
| 구간 | 일 | 받침 높이 Yp |
|---|---|---|
| 0~5.5 | 감개를 감아 올림 | Yo + (Ytop − Yo)·ss(tc/5.5) |
| 5.5~6.5 | 꼭대기에서 멈춤 | Ytop |
| 6.5~10.5 | 줄을 풀어 내림 | Ytop − (Ytop − Yo)·ss((tc − 6.5)/4) |

## 동작 (`state251(t)` — 결정적, 아래 식 그대로)
1. 홈 각 `alphaSlot251(Yp)`: 코 중심 N(α) = (0.185, Yp) + R(α)·N0, R(α) = 반시계 회전. 홈 오른쪽 면의 안쪽 법선 n = (−1, −0.65)/1.19269, 면 위 한 점 B0 = (0.33, 2.76). n·(N(0) − B0) ≥ 0.03 이면 α 0. 아니면 A cos α + B sin α = c 의 가장 작은 양의 근: A = n·N0, B = n·(−N0y, N0x), c = 0.03 + n·B0 − n·(0.185, Yp). (근 = atan2(B, A) − acos(c/√(A² + B²)) 를 (−π, π] 로.) 첫 닿음 Yp 2.007, α 7.409° 에서 풀림(Yp 2.15143), 꼭대기 Yp 2.17143 에서 8.380°.
2. 풀림 각 αR = 7.409°: 발끝 원 중심 x = 0.185 + (−0.08 cos α + 0.305 sin α) 가 0.145(T 머리 끝 0.12 + 0.025)에 닿는 각.
3. 추를 받친 높이 `support251(Yp, α)`: 발끝 중심 C = (0.185, Yp) + R(α)·L0. C.x ≤ 0.12 이면 Tu = C.y + 0.025, 0.12 < C.x ≤ 0.145 이면 Tu = C.y + √(0.025² − (C.x − 0.12)²)(T 모서리가 발끝 원 위를 미끄러짐).
