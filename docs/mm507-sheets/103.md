# 103 나사로 미는 슬라이드
원문: "Rectilinear motion of slide produced by the rotation of screw." — **나사가 돌면 슬라이드가 직선 운동**을 한다. 설명은 이 한 줄뿐이다(선반의 이송 장치 같은 방식).
판화 묘사: ㄴ자 틀(왼쪽에 선 기둥 + 오른쪽으로 뻗은 바닥판, 오른쪽 끝은 톱니꼴 파단선). 기둥 윗부분을 가로 나사가 꿰고 있다 — 기둥 왼쪽으로 턱과 짧은 끝이 나와 있고, 오른쪽으로 굵은 네모 나사산이 길게 이어지다 파단선으로 끊긴다. 나사 가운데쯤에 **T자를 뒤집은 꼴의 슬라이드**(나사가 꿰는 세로 몸통 + 아래의 넓은 발)가 끼워져 있다. 발은 바닥판 위의 긴 덩이(베드)에 얹힌 안내 레일 위에 놓였다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/103-fig-x4.png` 로 다시 읽음(px 는 4배 확대본 기준).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 부품은 셋: ① ㄴ자 틀(기둥 x 165 ~ 365 · y 605 ~ 1330, 바닥판 y 1240 ~ 1330, 그 위의 베드 x 395 ~ 1255 · y 1070 ~ 1240, 베드 위의 안내 레일 윗면 y 985) — 고정 ② 가로 나사(축 높이 y 775, 바깥지름 150px, 골지름 80px, 피치 110px) ③ T자 슬라이드(몸통 x 835 ~ 945 · 윗면 y 655, 발 x 700 ~ 1055 · y 930 ~ 1030).
2. 줄·벨트는? → 없음. 대신 나사산 한 줄: 기둥 오른쪽 턱 (x 400) 에서 파단 끝 (x 1290) 까지 산이 8줄 보인다(슬라이드 왼쪽에 4줄, 오른쪽에 3 ~ 4줄).
3. 교차하는 가닥은? → 없음. 나사산은 정면에서 **왼쪽 위 → 오른쪽 아래("\")** 로 기운다 = 가로로 누운 **오른나사**. 슬라이드의 발이 레일 윗변의 선 (y 985) 을 가리고 그 아래 y 1030 까지 내려온다 = 발의 앞 턱이 레일을 걸터타고 앞을 덮는다.
4. 고정점은? → ㄴ자 틀 전체(기둥·바닥판·베드·레일). 나사는 기둥의 구멍에 받쳐지고, 기둥 양쪽의 턱(왼쪽 x 125 ~ 165, 오른쪽 x 365 ~ 400)이 나사가 축 방향으로 움직이지 못하게 잡는다.
5. 추·손잡이·크랭크는? → 손잡이는 그려지지 않았다. 기둥 왼쪽으로 나온 나사의 짧은 끝 (x 65 ~ 125) 이 돌리는 자리(크랭크나 손바퀴를 끼우는 끝). 구동은 나사(원문 "by the rotation of screw").
6. 이(나사산)는 어디에 났고 무엇이 물리는가? → 나사 바깥에 수나사, 슬라이드 몸통의 구멍 안에 암나사(보이지 않음) — 슬라이드가 너트를 겸한다. 슬라이드의 발 ↔ 안내 레일(미끄럼 짝, 슬라이드가 나사를 따라 돌지 못하게 막는다). 나사의 축목 ↔ 기둥 구멍(회전 짝).
7. 한 줄에 놓인 것은? → 나사의 끝·두 턱·나사부가 한 수평 축. 슬라이드 몸통의 가운데가 그 축 위. 레일 윗변이 기둥에서 파단선까지 한 수평선(슬라이드가 가는 길). 바닥판·베드·레일이 나란하다.
8. 글자가 가리키는 부품은? → 글자 없음(번호 103 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 기구는 원문과 같고 질문할 것은 없음. 판화의 오른쪽은 파단선(더 이어진다는 뜻)이라 모형은 나사·레일·베드·바닥판을 반듯한 끝으로 마감했다. 나사의 오른쪽 끝은 받침 없이 두었다(판화에 받침이 없고, 기둥과 슬라이드가 받친다).
- 그 밖의 선: 굵은 선(기둥 오른쪽 변, 베드 윗변·왼변, 발 아랫변, 바닥판 아랫변) = 그림자 쪽 변(판화의 음영 관습) — 따로 만들 것 없음. 기둥 오른쪽 변과 베드 왼변 사이의 좁은 틈 (x 365 ~ 395) = 베드가 기둥에서 조금 떨어져 있음. 몸통과 발 사이의 둥근 선 = 둥근 살(필릿). 오른쪽 아래로 내려간 지그재그 = 판이 잘린 자리의 파단선.

## 해석(결정 사항)
- 판화 비를 그대로(1px = 0.0028): 기둥 폭 0.56 · 높이 2.03, 바닥판 두께 0.25, 베드 윗면 0.73, 레일 윗면 0.97, 나사 축 높이 1.55, 나사 바깥 반지름 0.21 · 골 반지름 0.115 · 피치 0.30, 슬라이드 몸통 폭 0.31 · 발 폭 1.0 · 발 높이 0.28 (높이는 바닥판 밑면에서 잼).
- 슬라이드의 발은 아래에 홈이 있어 레일(반두께 0.11)을 **걸터탄다**(발의 앞·뒤 턱이 레일 옆면을 0.13 덮음) — 판화에서 발이 레일 윗변을 가리고 내려온 모습 그대로이고, 이것이 슬라이드가 돌지 못하게 한다.
- 오른나사(판화의 산 기울기). 나사 끝에서 슬라이드가 빠지지 않게 **4바퀴 갔다가 4바퀴 돌아오는 왕복**(삼각파, 누적 오차 없음). 행정 1.2. 판화 자세(슬라이드가 왕복의 한가운데) = t = 1.
- 틀은 바닥판·기둥·베드의 뒷면이 뒤판에 붙는다(떠 있지 않음). 판화에 없는 보충 부품은 없다(나사 끝을 네모로 깎은 것과 표시줄뿐).

## 구동
나사(theta 누적). theta += OMEGA(1.6)·speed·dt. 나사 각 beta 는 theta 의 삼각파: 4바퀴(8π) 갔다가 돌아옴, 주기 16π rad = 31.4 s. 슬라이드가 종동(직선).

## 부품과 치수 (새 부품은 모두 `kit/k101.ts`, 이미 구현됨. 치수 상수 `K103`)
배치 상수: FX = −1.05, FY = 0.5 (틀 원점 = 기둥의 안쪽 면 × 바닥판 밑면), ZS = 0.15 (나사 축의 깊이). 나사 축의 세계 높이 = 0.5 + 1.55 = 2.05.
- 틀(name `frame`, 고정): `screwFrame103(0.45, 0.40)` 을 (−1.05, 0.5, 0.15) 에. 세계 좌표로 기둥 x −1.61 ~ −1.05 · y 0.75 ~ 2.53(나사 구멍 반지름 0.119 가 **X 방향**으로 뚫림), 바닥판 x −1.61 ~ 1.89 · y 0.50 ~ 0.75, 베드 x −0.96 ~ 1.84 · y 0.75 ~ 1.23, 안내 레일 x −1.05 ~ 1.84 · y 1.23 ~ 1.47 · 반두께 0.11. 기둥·바닥판은 뒤판에서 앞 0.55 까지, 베드는 앞 0.45 까지. 주철(레일은 강철).
- 이송 나사(name `screw`): `leadScrew103()` 을 (−1.05, 2.05, 0.15) 에, `rotation.x = beta`. 원점 = 축이 기둥 안쪽 면과 만나는 점. 왼쪽부터 네모 끝(한 변 0.20, x −1.89 ~ −1.72), 바깥 턱(반지름 0.265, x −1.72 ~ −1.61), 기둥 속 축목(반지름 0.115), 안쪽 턱(반지름 0.24, x −1.05 ~ −0.95), 오른나사부(x −0.95 ~ 1.79, 바깥 반지름 0.21, 피치 0.30, 네모 나사산). 바깥 턱에 노란 표시줄.
- 슬라이드(name `slide`): `screwSlide103()` 을 (−1.05 + x, 2.05, 0.15) 에(x = 틀 로컬의 슬라이드 가운데, 0.855 ~ 2.055). 원점 = 나사 축 위. 몸통 폭 0.31 · 윗면 y 2.39 · 나사 구멍 반지름 0.215, 발 폭 1.0 · y 1.34 ~ 1.62, 반두께 0.27, 발 밑의 레일 홈 반폭 0.113(홈 천장이 레일 윗면 1.47 에 얹힘). 청동. 돌지 않는다.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 범위: 가로 −1.89 ~ 1.89, 세로 0.50 ~ 2.53.

## 동작 (모두 theta 의 닫힌 식 — `screw103(theta)` 가 { a, beta, x, dir } 를 돌려준다)
- a = `triWave(theta − 1.6 + 4π, 8π)` 의 a: 0 → 8π → 0 (주기 16π). t = 1 에 a = 4π(2바퀴, 한가운데)이고 늘어나는 중.
- beta = −a (오른나사) → `screw.rotation.x = beta`.
- x = 0.855 + `screwAdvance(0.3, beta, false)` = 0.855 + 0.3·a/2π → `slide.position.x = −1.05 + x` (세계 −0.195 ~ 1.005). 나사 한 바퀴에 슬라이드가 정확히 피치 0.30 만큼 간다.
- 나사산과 슬라이드의 관계: 나사가 돌면 정면에 보이는 나사산 무늬가 가로로 옮겨 가는데, 슬라이드도 같은 양·같은 방향으로 가므로 **슬라이드에서 보면 나사산이 흐르지 않는다**. 부호가 틀리면 산이 슬라이드를 뚫고 흐르는 것처럼 보인다.
- dir = 나사가 지금 도는 방향(+1 = rotation.x 가 느는 쪽). 슬라이드가 오른쪽으로 가는 동안 −1(오른쪽 끝에서 나사를 보아 시계 방향), 돌아올 때 +1.
- 시각: **t = 1 (a = 4π, 판화 자세: 슬라이드 세계 x 0.405, 오른쪽으로 가는 중)**, **t = 4 (a = 17.37 rad, 세계 x 0.634)**, t = 8.85 (오른쪽 끝 1.005, 방향 바뀜), t = 24.56 (왼쪽 끝 −0.195).
