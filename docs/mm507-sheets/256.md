# 256 평 풀리
원문(en): "A plain pulley for a flat belt." — 평벨트용 보통 풀리.
쉬운 풀이: 테두리가 평평하고 매끈한(가운데가 아주 살짝 볼록한) 원통형 풀리이다. 아래 작은 구동 풀리가 돌면 납작한 벨트가 마찰로 이 풀리를 돌린다.
판화 묘사(원본 443×437 px, 축이 화면 좌우로 누운 **옆 모습**): 가운데 세로로 선 넓은 테(x 183–272, 폭 ≈ 89 px, 위 y ≈ 38, 아래 y ≈ 400 → 반지름 ≈ 181 px). 테의 위·아래 끝선이 **살짝 둥글게 부푼 호**(가운데가 끝보다 ≈ 3~4 px 높음 — 볼록 림). 플랜지·홈 없음. 양옆 짧은 네모(x 165–183, 272–295, 반지름 ≈ 49 px) = 허브, 그 바깥 둥근 축(반지름 ≈ 25 px, 오른쪽 끝이 잘린 원통). 벨트·다른 풀리는 없음.

## ★ 판화 읽기
판화는 그림 하나(옆 모습). 판화 1 px ≈ 0.00343(반지름 181 px = 0.62).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 판화에는 평 풀리 1개. 보충: 아래 작은 구동 풀리 1개. 크기 차례: 평 풀리(볼록 꼭대기 0.62, 끝 0.612) > 구동 풀리(0.22).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 판화에는 없음. 보충: 평벨트 1개(닫힌 고리) — 큰 풀리 위쪽을 반시계로 감고 왼쪽 가닥으로 내려와 구동 풀리 아래를 감고 오른쪽 가닥으로 올라간다(열린 벨트).
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 두 축 모두 뒤판 보스에서 나온 축.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 아래 구동 풀리 축이 일정하게 돈다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음(벨트 전동).
7. 한 줄에 놓인 것은? → 두 풀리 중심이 같은 세로선 x = 0(y 2.12 / 0.82). 풀리·벨트 가운데 평면이 모두 깊이 0.10.
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 256 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 어긋남 없음. 테 끝선이 둥근 것은 볼록(crowned) 림으로 읽는다(평벨트를 가운데로 모으는 보통 풀리 모양). 판화는 풀리 하나뿐이라 구동 풀리·평벨트를 보충. 판화는 옆 모습이고 모델은 축을 깊이(Z)로 두어 45° 시점으로 판화 윤곽과 벨트를 함께 보임(질문 거리 1·2).

## 해석(결정 사항)
- 큰 풀리 = 판화 그대로 넓은 볼록 림(폭 0.30, 끝 0.612 → 가운데 0.62, 볼록 0.008) + 웹 + 허브. 평벨트(폭 0.22, 두께 0.02)는 볼록 꼭대기에 앉는다(플랜지 없음 — 볼록이 벨트를 가운데로 모은다).
- 구동 풀리 = 키트 납작 림 풀리(평벨트 ↔ 납작 림 짝). 열린 벨트라 두 풀리 같은 방향.
- **단면 보이기**: 큰 풀리 림·웹을 평면각 ψ = −90° ~ −28° 만큼 잘라 낸 회전체 + 주홍 단면판 둘. 림·웹·단면판은 세계에 고정(회전 대칭이라 같은 모습), 돌아감은 허브 표시·너트·벨트 표시로. 잘린 자리는 벨트가 닿지 않는 구간(벨트 접점 ψ −17.92°, 여유 10°).

## 구동
구동 풀리 φ2(t) = 1.2·t [rad], 정면 반시계(`rotation.z = φ2`). 벨트 흐름 s = 0.23·φ2. 큰 풀리 φ1 = s / 0.63 = 0.36508·φ2.

## 부품과 치수 (새 함수는 `kit/k256.ts`, 상수 `K256`)

- **큰 풀리 림(고정, 잘린 회전체)**: `cutRim256()` → 그룹(name `bigRimGroup`, 위치 (0, 2.12, 0.10), 돌지 않음):

  - → 웹(두께 0.10, r 0.156 ~ 0.50, 허브 속으로 0.004 겹침) + 볼록 림 띠(r 0.50 ~ 0.62, 폭 0.30, 모서리 모따기 0.008).

## 동작 (`state256(t)` — 결정적)
1. φ2 = 1.2t. `driveShaft`·`drivePulley` 의 `rotation.z = φ2`.
2. φ1 = 0.36508·φ2. `bigShaft`·`bigPulley` 의 `rotation.z = φ1`. `bigRimGroup` 은 그대로.
3. `belt.setOffset(0.23·φ2)`.
4. 방향: 반시계 고리 — 두 풀리 반시계(ωz > 0).
5. 감긴 각: 큰 풀리 215.84°(위쪽, ψ −17.92° → 197.92°), 구동 풀리 144.16°(아래쪽, ψ 197.92° → 342.08°). 접선 끝점: 큰 풀리 (±0.5995, 1.9262) ↔ 구동 풀리 (±0.2189, 0.7492).
6. 틈 검산: 벨트 안쪽 면 r 0.62 = 볼록 꼭대기, 끝(a ±0.11)에서 볼록 면 0.6151 — 벨트 아래 틈 ≤ 0.005(볼록이라 정상). 벨트 폭 ±0.11 < 림 폭 ±0.15. 잘린 첫 면 ψ −28° 에서 벨트 중심 반지름 0.640(림 위 0.02). 화살표(깊이 0.32) ↔ 벨트(깊이 −0.01 ~ 0.21): 0.11.

## ★ 눈에 보여야 할 동작
- 핵심: 구동 풀리가 돌면 평벨트가 흘러 **평 풀리가 같은 방향으로 0.365배** 돈다. 벨트가 **넓은 볼록 림 위에 누워** 위쪽 215.8° 를 감고, 잘린 면에서 플랜지도 홈도 없는 평평한(살짝 볼록한) 림 단면이 보인다.
- 장치: 벨트 노란 표시 8개, 허브 노란 표시·너트, 구동 풀리 앞 화살표, 주홍 단면판.
- 수치: 구동 1.20 rad/s, 큰 풀리 0.438 rad/s, 벨트 속도 0.276 /s.

## ★ 난도·질문
