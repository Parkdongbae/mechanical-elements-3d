# 038 일정·변속 기어 (처음 이름: 부분 이 기어 변속)
판화: 같은 크기의 기어 두 개가 좌우로 놓이고 두 중심이 연결대로 이어져 있다. 각 기어는 둘레의 일부가 반지름 선 두 개로 나뉜 다른 구간이다. 원문: 한 바퀴 중 일부는 일정한 속도, 나머지는 속도가 달라지게 하는 회전 변환.
구동: 왼쪽 기어 theta += OMEGA·speed·dt. 오른쪽은 쉬지 않고 돌며, 변속 구간에서만 속도가 달라진다.

## 해석(결정 사항 — 검증 후 바뀜)
- 판화의 "두 기어 모두 부분 이"를 간헐 기어(이 없는 구간에서 피동 정지)로 만들 수는 없다: 피동이 쉬는 동안 위치를 잡아 줄 것이 없고, 한 바퀴에 16/24 바퀴씩 밀려 이가 없는 자리끼리 만나 멈춘다.
- 그래서 둘레 240°(2/3 바퀴)는 피치 반지름 0.6 의 보통 이로 1:1, 나머지 120°는 서로 맞물려 구르는 비원형 피치 곡선(rA + rB = 1.2)의 변속 구간으로 한다. 변속 구간 속도비 k = 1 + 0.3·sin(2π·u)(u = 구간 안 진행 0~1) — 평균이 1 이라 두 기어는 한 바퀴에 정확히 한 바퀴씩 돌고 매 바퀴 같은 자리에서 다시 물린다.
- 처음 설계("구동만 부분 이 16/24, 피동은 온 이, 쉬는 구간에 피동 정지")는 폐기. 원문의 "일정 + 변속"에도 지금 해석이 맞다.

## 부품과 치수 (키트 추가 `varSectorPair`)
- 둘레 이 수 24(두 기어 같음), 모듈 0.05 → 일정 구간 피치 반지름 0.6, 중심 거리 1.2. A(구동) 중심 (−0.6, 1.75), B(피동) 중심 (0.6, 1.75), 기어 z = 0.12, 폭 0.12.
- `varSectorPair({ teeth: 24, center: 1.2, module: 0.05, start: 3.403, sector: 2π/3, vary: 0.3, width: 0.12, spokes: 6 })` → `pair.a`(구동, 청동색), `pair.b`(피동).
- 변속 구간 피치 반지름: rA = d·k/(1+k), rB = d − rA. k = 1.3 일 때 rA 0.678 / rB 0.522, k = 0.7 일 때 rA 0.494 / rB 0.706.
- 이: 피치 곡선을 따라 호장 같은 간격(둘레/24)으로 놓은 사다리꼴 이(이끝 +m, 이뿌리 −1.25m, 이골 반폭 SA 0.24 / 이끝 시작 TA 0.38). 피동은 반 피치 어긋나 구동 이골 = 피동 이 자리.
- 각 기어 앞면에 변속 구간 경계선 2개(판화의 두 반지름 선), 표시점 1개.
- 연결대: 두 중심을 잇는 스타디움 막대(반폭 0.045), 기어 뒤쪽 z = 0(맞물림이 보이게). 양끝 머리 캡. `shaftZ(…, 0.3, 0.045)` 2개.

## 동작
- τ = theta mod 2π, q = floor(theta/2π). 변속 구간 τ ∈ [3.403, 5.498] rad(길이 γ = 2π/3), u = (τ − 3.403)/γ.
- 속도비 k(τ) = 1 + 0.3·sin(2πu) (구간 안), 그 밖 1. 누적각 K(τ) = τ + (0.3·γ/2π)(1 − cos(2πu)) (u 는 0~1 로 자름) — K(2π) = 2π.
- A.rotation.z = theta. B.rotation.z = −(q·2π + K(τ)) (`pair.angleB`). 지금 속도비 = `pair.ratio(theta)`.
- 피치 곡선: A 는 로컬 각 −τ 에 반지름 rA(τ), B 는 로컬 각 π + K(τ) 에 반지름 rB(τ) — 접점이 항상 중심선 위에 있고 두 곡선의 호장이 같다(순수 구름).

## 표시
- 회전 화살표: A 반시계, B 시계. tag: '구동 기어(일정 속도)', '피동 기어(속도 변함)', '연결대(기어 뒤)'.
- notes: 구간 '한 바퀴의 2/3 는 1 : 1 일정, 1/3 은 변속', 지금 속도비(피동/구동, 일정/변속 구간 표시), 피동 회전수(구동 회전수와 함께).

## 확인
- t=1, 1.6(일정 구간): 두 기어 표시점이 반대 방향으로 같은 각만큼 돈다. 변속 구간(구동 각 3.40~5.50 rad)에서는 notes 속도비가 1 → 1.3 → 1 → 0.7 → 1 로 변하고 피동이 멈추지 않는다. 구동 한 바퀴 뒤 피동도 정확히 한 바퀴.
- 가까이 `cam=0.3,1.9,1.9,0,1.75,0.1`: 일정·변속 구간 모두 이가 이골에 박히지 않음. 수치: 두 윤곽(`userData.outline`) 다각형 침범 검사, 호장 비 `pair.a.userData.arcCheck` ≈ 1.

## 키트 추가 (gear3.ts)
- `varSectorPair(opts): { a, b, angleB(thetaA), ratio(thetaA) }` — 일정 구간 + 비원형 변속 구간 기어 쌍.
- `partialGear(teeth, module, from, count, opts?)` 는 키트에 남아 있으나 38번에서는 쓰지 않는다.

- **부품**: `partialGear` + `spurGear` → `varSectorPair`(rA + rB = 1.2). 앞면에 구간 경계선 2개 추가.

- **표시**: tag·notes 문구를 '이 일부/쉬는 중'에서 '일정 속도/속도 변함'으로. 파일 머리말 이름도 '일정·변속 기어'.

## 사용자 지적 후 다시 만듦 (Fable, 2026-11-25)
위의 "비원형 변속 구간(varSectorPair)" 해석은 판화와 다르다. 판화 4배 확대와 507movements.com 38번 움직이는 그림으로 다시 읽었다. 이 절이 우선한다.
- 두 바퀴가 똑같이 세 구간: ① 원호 이(피치 반지름 0.6 = 중심 거리 1.2 의 절반, 약 234.8°) ② 긴 부채꼴(피치 반지름 0.9, 약 31.3°, 끝에 이) ③ 허브 가까이의 짧은 이(피치 반지름 0.3, 약 93.9°). 0.9 + 0.3 = 1.2.
- 물리는 짝: 원호 ↔ 원호(1 : 1), 구동의 긴 부채꼴 ↔ 피동의 짧은 이(3배), 구동의 짧은 이 ↔ 피동의 긴 부채꼴(1/3배). 세 구간의 호 길이 비가 맞아 한 바퀴에 정확히 한 바퀴.
- theta = 0 은 판화의 자세(두 중심을 잇는 굵은 선에 ②·③ 경계가 놓임). 피동 각: 구동 각 t 에 대해 3t → AS + (t − AB) → AS + A0 + (t − AB − A0)/3.
- 구간이 바뀔 때 새 구간의 첫 이가 옛 속도비로 다가와 부딪치므로, 긴 부채꼴과 원호 구간은 양 끝 이를 하나씩 덜었다(긴 부채꼴 이 2개, 원호 18개, 짧은 구간 4개). shots/_verify/c038t.mjs 로 한 바퀴 0.002 rad 간격 외곽선 침범 0.
- 모델은 키트 varSectorPair 를 쓰지 않고 m038.ts 안에서 외곽선을 만든다.
