# 078 폴 래칫 구동 변형 (톱니 바퀴와 갈고리 폴 2개)
원문: "77번의 변형이다." — 한 줄뿐(catalog.json 의 en 뒤에 붙은 "Reciprocating rectilinear motion of" 는 79번 문장의 앞머리가 잘못 잘려 들어온 것). 77번과 같은 원리: 레버가 흔들리면 두 폴이 번갈아 작용해 바퀴를 거의 끊임없이 한 방향으로 돌린다.
판화(public/mm507/fig/078.png, 4배 `shots/_verify/078-fig-x4.png`, 7배 `shots/_verify/078-left-x7.png` · `078-right-x7.png`): 정면 그림 하나. 바닥에 선 **A 자 틀**, 그 가로대 높이에 축이 걸린 **톱니(래칫) 바퀴 A**, 틀 꼭대기에 받침점을 둔 **레버 B**(오른쪽으로 긴 손잡이, 끝이 잘림). 레버에는 받침점 왼쪽 끝과 오른쪽에 핀이 하나씩 있고, 거기에 **갈고리 폴이 하나씩** 달려 있다. 화살표는 바퀴 오른쪽에서 아래로(시계).

## ★ 판화 읽기
판화는 그림 하나(정면).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 1개(A). 바깥 둘레에 톱날 모양 톱니, 안쪽에 테와 살 4개(가로 살이 틀 양옆으로 보인다)와 허브. 이끝 간격을 재면 약 13°(왼쪽 이끝 네 개가 158°, 171°, 184°, 199.5°) → **28개**로 잡는다. 이끝 반지름 : 이뿌리 = 515 : 465(4배 판화 픽셀).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 폴 2 는 틀의 왼쪽 다리와 레버 **뒤**를 지난다(판화의 점선 두 토막 = 가려진 폴의 윤곽).
4. 고정점(천장·벽·바닥)은 어디인가? → A 자 틀의 두 발이 바닥(굵은 가로선)에 놓였다. 틀 꼭대기 = 레버 받침점, 틀 가로대 = 바퀴 축 베어링.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 레버 B 의 오른쪽이 긴 손잡이(잘린 끝). 추·크랭크 없음.
6. 기어는 안쪽/바깥쪽 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 바깥 둘레의 톱날 톱니. **폴 1**: 레버 왼쪽 끝 핀에 매달려 왼쪽 아래로 내려와, 바퀴 왼쪽 위(중심에서 약 146°)의 톱니를 아래에서 걸어 **위로 당긴다**. **폴 2**: 레버 오른쪽 핀(받침점에서 오른쪽으로 약 240 픽셀)에서 왼쪽 아래로 뻗어 바퀴 꼭대기 왼쪽(약 109°)의 톱니를 걸어 **오른쪽으로 당긴다**. 둘 다 톱니의 곧은 면에 갈고리 끝을 거는 당기는 폴이고, 두 폴 모두 걸린 자리에서 바퀴에 거의 접선으로 놓였다.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 바퀴 축과 틀 꼭대기(레버 받침점)가 같은 세로선. 레버의 세 핀(왼쪽 폴 핀, 받침점, 오른쪽 폴 핀)이 레버 위 한 줄.
8. 판화에 글자(A, B…)가 가리키는 부품은? → A = 톱니 바퀴, B = 레버(손잡이). 화살표 = 바퀴 회전 방향(시계).
9. 판화와 원문이 다르거나, 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 적어 둘 것 두 가지: (가) 판화의 폴 2 는 레버 가운데 선 위의 핀에 달려 있어 손잡이를 올릴 때 당기는 힘의 팔이 짧다(폴 1 의 절반쯤) — 그래서 한 왕복 2톱니 가운데 폴 1 이 1.34톱니, 폴 2 가 0.66톱니를 맡는다. 판화대로 둔다. (나) 판화는 레버가 거의 수평인데 두 갈고리가 다 걸려 있다 — 실제로 둘이 함께 걸리는 때는 행정이 바뀌는 순간뿐이다(모형의 t = 1).
- 그 밖의 선: 틀 안의 두 삼각 구멍 = A 자 틀의 뚫린 곳, 축 둘레 작은 원들 = 허브와 베어링, 바퀴 안쪽 큰 원 = 테 안쪽 가장자리, 폴 2 옆 점선 = 틀·레버에 가려진 폴 2 의 모서리.

## 해석(결정 사항)
- 당기는 갈고리 폴 2개가 번갈아 톱니를 당긴다. **손잡이를 내리면** 레버 왼쪽 끝이 올라가 폴 1 이 왼쪽 톱니를 위로 당기고, **손잡이를 올리면** 오른쪽 핀이 올라가 폴 2 가 꼭대기 톱니를 오른쪽으로 당긴다. 한 왕복에 바퀴는 **정확히 톱니 2개(25.714°)**, 시계.
- 쉬는 폴은 톱니의 비스듬한 등을 타고 물러나다가 이끝을 넘으면 골로 떨어진다(딸깍). 폴 1 은 매달려 제 무게로 바퀴 쪽으로 기대고, 폴 2 는 바퀴 위에 얹혀 있다.
- 헛걸음(LOST = 톱니 간격의 0.15): 갈고리가 곧은 면보다 조금 더 물러났다가 돌아오며 걸린다 → 행정이 바뀔 때 바퀴가 잠깐(주기의 약 24%) 선다.
- 레버 진폭과 폴 2 길이는 "한 주기에 정확히 2톱니 + 두 폴의 위상"을 만족하도록 키트가 푼다(`solve78`): **진폭 ±21.17°, 폴 2 길이 0.7239**(판화 비 0.752 에서 4% 줄임).
- 갈고리 손가락은 톱니 깊이(0.085)보다 긴 0.12 — 막대가 이웃 이끝을 0.02 넘게 비킨다. 당기는 면은 14° 뒤로 누워 톱니에는 뾰족한 끝만 닿는다.

## 구동
레버 B(theta 가 왕복 위상). theta += OMEGA(1.6)·speed·dt, 레버 각 φ = 21.17°·sin(theta) (반시계 + = 손잡이가 올라감). 한 왕복 = 2π(3.93 s).

## 부품과 치수 (모두 키트 `kit/k077.ts`, 이미 구현됨. 값은 `K78` 상수)
바퀴 중심 O = (−0.3, 0.96). 바닥 y = 0.
- 톱니 바퀴 A(name `wheelA`): `sawWheel78(0.08)` 를 (−0.3, 0.96, 0.1) 에. 톱니 28개, 이끝 반지름 0.86, 이뿌리 0.775, 살 4개, 허브. 황동. 곧은 면의 반시계 쪽이 골(시계로 끌려 도는 방향).
- 바퀴 축: `shaftZ(-0.3, 0.96, 0.33, 0.045)` — 뒤판에서 나와 바퀴(구멍 0.05)를 지나 앞의 틀 가로대 보스에 꿰인다(뒤판 쪽 받침은 판화에 없음).
- A 자 틀(name `frame`): `aFrame78(0.6, 0.06)` 를 (−0.3, 0.96, 0.26) 에. 꼭대기 = 바퀴 중심 위 1.07 → (−0.3, 2.03), 두 발 x = −0.9, 0.3 (y = 0), 가로대는 축 높이. 주철. 바퀴 **앞**에 선다(판화에서 틀이 바퀴를 가림).
- 레버 B(name `leverB`): `handLever78(1.3, 0.3)` 를 받침점 (−0.3, 2.03) 에, z = 0.37(틀 앞). 왼쪽 폴 핀은 받침점에서 0.385, 오른쪽 폴 핀은 0.4, 손잡이 끝 1.3(나무). 두 폴 핀은 뒤로 0.3 뻗어 바퀴 평면의 폴을 꿴다(틀 꼭대기 옆을 지나감). 청동(구동).
- 폴 1(name `pawl1`): `hookPawl78(K78.L1)` — 길이 0.723, z = 0.1(바퀴와 같은 평면).
- 폴 2(name `pawl2`): `hookPawl78(solve78().L2)` — 길이 0.7239, z = 0.1.
- 받침대·뒤판 `displayStand()`.
- 가로 범위 x −1.29(폴 1 의 갈고리 등) ~ 1.0(손잡이 끝), 세로 y 0 ~ 2.50. 흔들리는 팔 끝의 최고 높이: 손잡이 끝 y = 2.03 + 1.3·sin 21.17° = 2.50, 가장 낮을 때 1.56.

## 동작 (모두 theta 의 함수 — `state78(theta)` 가 한 번에 돌려준다)
`const s = state78(theta)`:
- 레버: rotation.z = s.phi.
- 바퀴: rotation.z = s.wheel (시계로 쌓여 줄어든다. 한 주기에 정확히 −25.714°).
- 폴 1: position = O + s.pin1, rotation.z = s.psi1 (약 −125° ~ −107°). 폴 2: position = O + s.pin2, rotation.z = s.psi2 (약 −169° ~ −140°).
- s.pulling = 1 | 2 | null (지금 당기는 폴), s.steps = 지금까지 넘긴 톱니 수.
- 주기 시간표(theta + 90° 를 한 주기 0 ~ 360° 로): 0° ~ 45° 헛걸음(바퀴 정지) → 45° ~ 180° **폴 2 가 당김**(8.45°, 손잡이 올라감) → 180° ~ 223° 헛걸음 → 223° ~ 360° **폴 1 이 당김**(17.26°, 손잡이 내려감). 한 주기의 약 76% 동안 바퀴가 돈다.
- 당기는 폴의 끝은 이뿌리 모서리(반지름 0.775)에 있고(두 원의 교점), 쉬는 폴의 끝은 톱니 윤곽 위에 얹힌 자리를 풀어 구한다. 이끝에서 골로 떨어질 때만 떨어지는 속도를 제한한다(0.085 를 약 0.09 s 에).
- 시각: **t = 1.0**(theta 1.6, φ = +21.2° — 손잡이가 가장 높이 올라간 교대 순간. 폴 2 가 막 다 당겼고 폴 1 이 골에 들어앉음 — 판화처럼 두 갈고리가 다 걸림), **t = 1.6**(theta 2.56, φ = +11.6° 로 내려가는 중, 폴 1 이 당기는 중), t = 3.0(손잡이가 가장 낮은 교대 순간).
