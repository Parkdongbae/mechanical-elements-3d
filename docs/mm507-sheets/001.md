# 001 열린 벨트 전동
판화: 같은 크기의 풀리 2개가 위아래로 놓이고 열린(평행) 벨트가 걸려 있다.

## 부품과 치수
- `displayStand()`
- 풀리 A(구동, `driver: true`) r = 0.52, 중심 (0, 2.55). 풀리 B(종동) r = 0.52, 중심 (0, 0.95). 둘 다 `pulley(r, { spokes: 4 })`, z = 0.25.
- 축: `shaftZ(0, 2.55)`, `shaftZ(0, 0.95)`.
- 벨트: `new Belt(planar(openBeltPath([0,2.55], 0.52 + 0.01, [0,0.95], 0.52 + 0.01), 0.25), { width: 0.13 })`.

## 동작
- `theta += OMEGA * speed * dt` (OMEGA = 1.6).
- A.rotation.z = theta, B.rotation.z = theta (같은 방향, 같은 속도).
- 벨트 표시: `belt.setOffset(theta * 0.53)` — 표시가 풀리 림과 같은 속도로 흐른다(오른쪽 직선부에서 theta > 0 일 때 위로? 아래로? → 풀리의 반시계 회전과 일치하는 쪽. 캡처에서 표시 이동 방향이 림의 회전 방향과 같아야 한다. 반대면 부호를 바꾼다).

## 표시
- `rotArrow(0.7, true)` 를 A, B 둘레에 하나씩(같은 방향). `tag('구동 풀리', …)` A 오른쪽, `tag('종동 풀리', …)` B 오른쪽.
- notes: `[{ label: '회전 방향', value: '같은 방향' }, { label: '속도비', value: '1 : 1' }]`

## 확인
- t=1 과 t=1.6 에서 두 풀리의 스포크 각이 같은 방향으로 같은 만큼 변한다. 벨트가 풀리 바깥을 감고 직선부가 평행하다.
