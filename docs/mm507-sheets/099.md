# 099 나선 안내 홈(드릴 이송)
원문: 원판 면에 붙인 **나선 안내(spiral guide)**. 드릴링 기계의 이송 운동에 쓴다.
판화: 큰 원판(가운데 빗금 축) 면에 나선 줄이 4바퀴 반쯤 감겨 있다. 원판 아래쪽, 나선 사이에 둥근 고리(안에 작은 원)가 걸려 있고 그 아래로 네모 토막 → 가는 막대 → 세로줄이 난 넓적한 토막 → 막대가 차례로 내려간다. 막대 양옆에 세로선 두 줄.

## ★ 판화 읽기
판화는 그림 하나(정면). 확대본 `shots/_verify/099-fig-x4.png`(px 는 4배 확대본 기준, 원판 가운데가 px 로 1175·760, 반지름 약 700).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 회전체는 **원판 1개**. 그 밖에 위아래로 미끄러지는 종동절(고리 + 막대) 1개, 고정 안내(양옆 세로선) 1벌.
2. 줄·벨트는? → 없음. 원판 위의 굵은 줄은 벨트가 아니라 **나선 리브**(원판 면에 붙인 안내 턱)다.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 원판 축(가운데 빗금 원)과 막대 양옆의 세로선(안내 = 드릴 기계 기둥, 아래로 잘려 그려짐).
5. 추·손잡이·크랭크는? → 없음. 구동은 원판 축(원문은 구동을 따로 적지 않았다 — 나선 원판이 돌아야 이송이 생기므로 원판이 구동).
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 물림은 없다. 맞닿는 짝은 **나선 리브 ↔ 종동 핀**. 나선은 바깥 끝이 위(반지름 630 px), 안쪽 끝이 오른쪽 아래(반지름 약 200 px), 줄 간격 약 110 px 로 4.5바퀴. **반시계로 따라갈수록 반지름이 줄어든다**(위에서 재면 630 → 545 → 435 → 320 → 215, 왼쪽은 535 → 430 → 315 → 200).
7. 한 줄에 놓인 것은? → 원판 축, 고리, 네모 토막, 막대, 세로줄 토막이 **한 세로선** 위(원판 중심 바로 아래).
8. 판화에 글자가 가리키는 부품은? → 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 기구는 같다. 한 방향으로만 돌리면 종동 핀이 나선 끝에 닿아 멈추므로, 전시에서는 원판을 **2.25바퀴 돌렸다가 되돌린다**(실제 기계도 이송이 끝나면 되돌린다). 세로줄 난 토막의 정체는 판화로는 알 수 없음(널링 칼라 또는 스핀들 기어) — 막대에 붙은 고리로만 만든다. 질문 없음.
- 그 밖의 선: 고리의 바깥 원(반지름 115 px)은 막대 머리의 눈고리, 안쪽 원(70 px)은 나선 사이에 든 종동 핀의 머리. 고리 양옆에서 나선 두 줄이 고리 뒤로 들어간다(고리가 나선보다 앞). 세로줄 토막의 세로선 = 둘레에 난 줄(널링).

## 해석(결정 사항)
- 나선은 한 줄짜리 **리브**(턱)이고 종동 핀은 이웃한 두 리브 사이 골에 든다. 아르키메데스 나선: 반지름 = 0.2 + 0.16·(감긴 각/2π), 4.5바퀴(0.2 → 0.92). 원판 반지름 1.0.
- 판화의 줄 간격 110 px = 0.157 → 0.16. 골 폭 = 0.16 − 리브 두께 0.03 = 0.13, 종동 핀 지름 0.12(틈 한쪽 0.005).
- 원판이 반시계로 한 바퀴 돌면 종동절이 0.16 **바깥쪽(아래)** 으로 간다(이송). 시계로 돌면 올라온다.
- 판화의 고리는 리브 간격보다 크게 그려져 있다(지름 230 px ≒ 두 칸). 그래서 고리(눈고리 머리, 반지름 0.15)는 리브보다 앞 층에 두고, 골에 드는 것은 그 뒤로 내려간 핀(반지름 0.06)이다.
- 안내: 판화의 양옆 세로선 = 받침 위에 선 기둥 2개. 막대가 지나는 **가로대와 구멍 보스는 판화에 없음**(막대가 떠 있지 않게 하는 최소 보충).

## 구동
원판 축. theta += OMEGA(1.6)·speed·dt. 위상 θe = theta + 2.817. 원판 각 ψ 는 θe 의 세모꼴 주기 함수(아래). 원판은 theta 의 2배 빠르기(3.2 rad/s)로 돈다.

## 부품과 치수 (키트 `kit/k098.ts`, 이미 구현됨. 값은 `SPIRAL099` 상수)
- 원판(name `disk`): `spiralGuideDisk()` 중심 (0, 2.25), 그룹 z = 0.04(원판 면 z 0 ~ 0.08, 리브 z 0.076 ~ 0.14). 반지름 1.0, 주철. 리브(name `rib099`, 황동): 두께 0.03, 높이 0.06, 4.5바퀴, 안쪽 끝이 원판 로컬 −90°(반지름 0.2), 바깥 끝이 +90°(반지름 0.92). 허브 보스 반지름 0.15.
- 원판 축: `shaftZ(0, 2.25, 0.14, 0.07)` — 뒤판에서 나와 허브 앞에서 끝난다(종동절 머리 z 0.15 보다 뒤).
- 종동절(name `follower`): `spiralFollower()` 그룹 위치 (0, 2.25 − rf, 0.18). 원점 = 종동 핀 중심. 눈고리 머리(반지름 0.15, z 0.15 ~ 0.21), 핀(name `roller099`, 반지름 0.06, z 0.085 ~ 0.22 — 리브 층에 든다), 네모 토막(0.2 × 0.12, 핀 아래 0.2), 막대(반지름 0.03, 핀 아래 0.25 ~ 1.26), 세로줄 난 칼라(반지름 0.2, 높이 0.15, 핀 아래 0.66, 청동).
- 안내(name `guide`): `feedGuide()` 그룹 위치 (0, 0.18, 0.18) — 받침 윗면에 선다. 기둥 2개(x = ±0.32, 높이 1.02 → 꼭대기 y 1.2, 원판 아래 끝 y 1.25 보다 낮다), 가로대(y 0.62 ~ 0.70)와 구멍 보스(y 0.615 ~ 0.705, 구멍 반지름 0.033).
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 범위: 원판 x −1.0 ~ 1.0, y 1.25 ~ 3.25. 종동 핀 y 1.45 ~ 1.81, 칼라 y 0.715 ~ 1.225(원판 아래 끝 1.25 미만, 보스 윗면 0.705 초과), 막대 아래 끝 y 0.19 ~ 0.55(받침 윗면 0.18 초과, 보스 아랫면 0.615 미만 — 늘 구멍에 꿰여 있다).

## 동작 (모두 theta 의 주기 함수)
- ψ = `spiralDiskAngle(θe)`: m = (2·θe) mod 9π, ψ = m < 4.5π ? m : 9π − m. (0 → 4.5π 로 반시계 2.25바퀴 = 이송, 다시 0 으로 = 되돌림. 주기 θe 4.5π = 8.84 s. 누적 없음.)
- `disk.rotation.z = ψ`.
- rf = `spiralFollowerRadius(ψ)` = 0.44 + 0.16·ψ/2π (0.44 ~ 0.80, 이동 0.36). `follower.position.y = 2.25 − rf`.
- 시각: **t = 1.0 (ψ 1.406바퀴, rf 0.665, 핀 y 1.585 — 판화의 고리 자리, 이송 중)**, **t = 1.6 (ψ 1.712바퀴, rf 0.714, 핀 y 1.536)**, t = 2.66 (ψ 2.25바퀴, rf 0.80, 맨 아래 — 여기서 되돌림), t = 4.0 (되돌리는 중).

## 표시

- tag 4개: '나선 안내 원판(구동)' (−1.3, 3.1, 0.3), '나선 리브' (1.35, 2.6, 0.3), '종동 핀과 이송 막대' (1.0, 1.0, 0.45), '안내 기둥(고정)' (−0.95, 0.75, 0.3).

## notes
① '원판 한 바퀴에 막대가 0.16 내려감(나선 한 칸)' ② 지금 상태 '이송 중(반시계) / 되돌리는 중(시계)' ③ 막대가 내려간 거리(rf − 0.44) ④ 원판이 돈 바퀴 수(ψ/2π).

## 확인
- t=1 정면: 판화와 같은 모양 — 나선 원판, 아래쪽 골에 걸린 고리, 그 아래 네모 토막·막대·세로줄 칼라가 한 세로선. t=1.6: 고리가 0.05 더 내려가 있음.
- 근접 `cam=0.0,1.6,1.4,0,1.6,0.1`(핀과 리브), 옆 `cam=3.0,1.6,0.2,0,1.6,0.1`(원판·리브·머리·막대의 층), t = 2.66(맨 아래)과 t = 5.4 부근(맨 위, ψ ≈ 0)에서 막대 끝이 보스에 꿰여 있고 칼라가 원판·보스에 닿지 않는지.
- 수치: `node shots/_verify/s099.mjs` → 핀과 리브의 최소 틈 0.0049, 핀 중심이 리브 안에 든 횟수 0, 종동 반지름 0.440 ~ 0.800, 양 끝에서 안쪽·바깥 리브가 모두 있음.
