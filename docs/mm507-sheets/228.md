# 228 체인과 체인 풀리 2
원문(en): "Another kind of chain and pulley." — 다른 종류의 체인과 풀리.
쉬운 풀이: 폭 넓은 드럼 바퀴의 테 위에 쐐기 모양 이가 줄지어 서 있고, 사다리처럼 생긴 체인(양쪽 줄 + 가로대)의 가로대가 쐐기 사이에 끼어 바퀴를 따라 오르내린다.
판화 묘사(원본 470×447 px, 왼쪽 위에서 비스듬히 본 그림): 폭 넓은 **원판 드럼**(앞면이 오른쪽 아래를 향함, 앞면 가운데 짧은 축 끝과 칼라), 뒤쪽(왼쪽 위)으로 긴 축이 삐져나옴. 드럼 테 위(위쪽·왼쪽 반 바퀴)에 **쐐기(삼각 기둥) 이**가 테 폭 전체에 걸쳐 줄지어 섬. 체인은 **사다리 꼴**: 테 앞·뒤 가장자리를 따라 두 줄의 긴 고리(마디마다 둥근 혹), 마디마다 두 줄을 잇는 **가로대**. 가로대가 쐐기 바로 옆(쐐기 사이)에 놓임. 양쪽(왼쪽·오른쪽)으로 사다리 체인이 **곧게 아래로** 내려가 그림 밑에서 잘림. 드럼 지름 ≈ 270 px, 체인 마디 사이 ≈ 78 px → 한 바퀴 이 약 11 ~ 12 개.

## ★ 판화 읽기
판화는 그림 하나(왼쪽 위 앞에서 비스듬히). 세계 1 px ≈ 0.004.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 드럼 바퀴(테 반지름 0.55, 폭 0.30) + 테 위 쐐기 이 12.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 사다리 체인 1개. 왼쪽 세로 가닥(아래 끝 = 짐 추) → 드럼 위쪽 180°(9시 → 12시 → 3시) → 오른쪽 세로 가닥(아래 끝 = 반대쪽 추). 판화에는 끝이 잘림.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 드럼 축의 뒤쪽(뒤판 축받이). 판화의 긴 뒤 축이 뒤판으로 들어간다고 본다.
5. 추·손잡이·크랭크는? → 판화에 없음. 보충: 양 끝 추, 드럼(축)을 왕복으로 돌린다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 드럼 **테 바깥면**에 쐐기 이 12(반지름 방향으로 섬). 체인의 **가로대**가 이웃한 두 쐐기 사이에 끼고, 쐐기의 가파른 면이 가로대를 민다.
7. 한 줄에 놓인 것은? → 두 세로 가닥은 x = ±0.573(가로대 원의 9시·3시 접선). 체인의 두 줄은 드럼 앞면·뒷면 바로 바깥(z0 ± 0.175).
8. 판화의 글자가 가리키는 부품은? → 글자 없음(번호 228 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 원문은 한 줄뿐이라 어긋남 없음. 판화의 쐐기 수는 정확히 셀 수 없어(보이는 반쪽에 5 ~ 6) **12** 로 정함(★질문 거리 1). 체인 끝이 잘려 있어 추를 달고 왕복(질문 2). 판화의 비스듬한 시점은 view 로 맞춤. 쐐기 모양·자세는 한 주기 내내 가로대와 닿지 않게 파이썬으로 정함(최소 틈 0.003, 가로대가 앉은 자세에서 가파른 면과 0.013).

## 해석(결정 사항)
- 마디(가로대) 15개 i = −7 … 7, 마디각 30°, 가로대 중심 원 반지름 Rr = 0.573(테 0.55 + 가로대 반지름 0.02 + 틈 0.003). 이웃 마디 사이(곧은 옆 고리 길이) p = 2·0.573·sin 15° = **0.2966**.
- 쐐기는 이웃 마디 사이 골마다 하나(12개). 짐(왼쪽)이 체인을 반시계(위에서 왼쪽)로 당기므로, 각 가로대는 **자기 왼쪽(반시계 쪽) 쐐기의 가파른 면**에 기댄다 → 쐐기의 가파른 면은 시계 쪽.
- 굳은 사슬: 드럼 위 마디는 드럼과 함께 돌고, 벗어난 마디는 세로 가닥 위에 p 간격(`chainJoints228`).
- 드럼 왕복: θ(t) = −(π/3)·sin(0.5t)(반시계 +). 먼저 시계 → 짐이 올라감. 진폭 = 쐐기 2개(60°), 체인 이동 ≈ 0.60.

## 구동
드럼 축을 돌린다. θ(t) = −1.047198·sin(0.5t) [rad]. t = 0 = 판화 자세(가로대 하나가 12시).

## 동작 (`state228(t)` — 결정적)
1. `chainJoints228(θ)`: 마디 i = −7 … 7, 모든 칸 step = π/6, chord = 0.2966.
   - ang(i) = π/2 + θ − i·π/6.
   - 0 ≤ ang(i) ≤ π 이면 J[i] = (0.573·cos ang, 0.573·sin ang).
   - 바퀴 위 가장 작은 번호 lo, 큰 번호 hi. i < lo: J[i] = (−0.573, J[i+1].y − √(0.2966² − (J[i+1].x + 0.573)²)). i > hi: J[i] = (0.573, J[i−1].y − √(0.2966² − (0.573 − J[i−1].x)²)).
2. 적용: `drumSpin.rotation.z = θ`, 가로대 i 위치 = C + J[i], 옆 고리 배치, 멍에 원점 = C + J[∓7].
3. t = 0 마디(C 기준): −7 (−0.573, −1.1864) / −6 (−0.573, −0.8898) / −5 (−0.573, −0.5932) / −4 (−0.573, −0.2966) / −3 (−0.573, 0) / −2 (−0.4962, 0.2865) / −1 (−0.2865, 0.4962) / 0 (0, 0.573) / 1 (0.2865, 0.4962) / 2 (0.4962, 0.2865) / 3 (0.573, 0) / 4 (0.573, −0.2966) … 7 (0.573, −1.1864).
4. 끝 마디 세계 y: t = 0 에 1.1636, 왕복 중 0.5704 ~ 1.7568.
5. 간섭 검산(파이썬, θ −60° ~ +60° 1201 자세, 굳은 사슬): 가로대(반지름 0.02) ↔ 드럼+쐐기 최소 틈 **0.003**(테 위에 앉음). 앉은 가로대 ↔ 가파른 면 0.0133. 옆 고리(z 0.15 ± 0.175, 반지름 0.012)는 드럼 앞뒤 면(z 0.15 ± 0.15) 바깥 0.013. 쐐기는 테 폭 안(z ±0.15)이라 옆 고리·혹과 닿지 않음.
6. 추 검산: 짐 추 바닥 최저 0.5704 − 0.3568 = 0.214(받침 윗면 0.18 위), 추 몸 꼭대기 최고 1.7568 − 0.2568 + 0.10 = 1.60 → 드럼 중심에서 (−0.483, −0.75) → 거리 0.89 > 쐐기 꼭대기 원 0.62.
