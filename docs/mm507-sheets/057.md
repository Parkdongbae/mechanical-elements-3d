# 057 내접 기어 이중 구동 (유성 기어)
판화(public/mm507/fig/057.png, 확대 shots/_verify/057-fig-x4.png — Fable 교차 읽기 2026-11-25): 그림 하나. 맨 위에 작은 풀리가 있고 그 왼쪽 위로 짧은 크랭크 팔과 손잡이 고리가 달려 있다. 풀리에서 띠 두 줄이 내려온다. 바깥쪽 두 가닥(아래로 벌어짐)은 아래 **큰 링 기어의 바깥 테두리를 감는 열린 띠**, 가운데에서 X 자로 엇갈리는 두 가닥은 링 속 **동심 기어(태양 기어)를 둘러싼 둥근 테(풀리)** 를 감는 엇걸이 띠다. 링 기어는 지름이 가장 크고 **이가 안쪽**으로 났다. 그 안에 이가 바깥으로 난 태양 기어, 그리고 링과 태양 **사이 맨 아래**에 작은 피니언 하나가 양쪽에 모두 물려 있다. 판화 픽셀 반지름(확대본): 윗 풀리 120, 링 바깥 360, 링 피치 ≈ 300, 태양 풀리(엇걸이 띠가 감는 원) 190, 태양 기어 피치 ≈ 150, 피니언 ≈ 70, 윗 풀리–기어 중심 거리 620. 피니언 받침(캐리어)과 링 받침은 그려져 있지 않다.
원문 요지: 위의 작은 풀리가 구동. 큰 내접 기어와 그 속의 동심 기어는 띠로 **서로 반대 방향**으로 돌고, 동시에 맨 아래 중간 피니언에도 운동을 주어, 피니언은 **제자리에서 돌면서 두 기어의 공통 중심 둘레로도 돈다**.

★ 판화 읽기
1. 바퀴: 풀리 2개(윗 풀리, 태양 풀리) + 띠가 감기는 링 바깥 테, 기어 3개(링 48 안쪽 이 > 태양 24 > 피니언 12). 크기 차례: 링 바깥 > 태양 풀리 > 태양 기어 > 윗 풀리 > 피니언.
2. 줄·벨트: 2개. (가) 열린 띠 — 윗 풀리 위쪽을 감고 양옆으로 내려가 링 바깥 테의 아래쪽을 감는다(닫힌 고리). (나) 엇걸이 띠 — 윗 풀리 위쪽을 감고 내려오며 한 번 엇갈린 뒤 태양 풀리의 아래쪽을 감는다(닫힌 고리).
3. 교차 가닥: 엇걸이 띠의 두 가닥이 윗 풀리와 링 꼭대기 사이에서 한 번 교차한다. 열린 띠는 교차 없음.
4. 고정점: 판화에 받침이 그려져 있지 않다(판화로는 알 수 없음). 윗 풀리 축과 태양 축은 고정 축으로 본다.
5. 크랭크: 윗 풀리에 짧은 팔 + 손잡이(왼쪽 위 방향으로 그려짐). 추 없음.
6. 기어: 링은 **안쪽** 가장자리에 이, 태양·피니언은 바깥 이. 피니언은 맨 아래에서 태양(위쪽)과 링(아래쪽)에 동시에 물린다.
7. 한 줄에 놓인 것: 윗 풀리 중심 — 태양·링 공통 중심 — 피니언 중심이 한 세로선(x = 0).
8. 글자: 판화에 글자 없음.
9. 판화와 원문이 다른 곳: 없음(열린 띠 = 같은 방향, 엇걸이 띠 = 반대 방향 → 원문의 "서로 반대 방향"과 맞음). 다만 판화의 크기 비 그대로면 피니언 공전이 거의 0 이 된다 — 아래 "판화 대조" 절. 질문 거리는 아님(치수 선택).

## 구동
윗 풀리 theta += OMEGA·speed·dt (반시계). 나머지는 모두 theta 의 함수.

## 동작 (theta = 누적 구동 각, 절대 자세)
- 윗 풀리(두 단)·크랭크: rotation.z = θ.
- 속도 계수(풀리 각 1 당): 링 kR = 0.33/0.9905 = **+0.3332**(같은 방향, 반시계), 태양 kS = −0.33/0.37 = **−0.8919**(반대 방향, 시계).
- 캐리어(피니언 공전) kC = (24·kS + 48·kR)/72 = **−0.0752** (윌리스 식). 피니언 자전 kP = 3·kC − 2·kS = **+1.5582**.
- 자세:
  - 태양(기어·풀리·축): rotation.z = θs = kS·θ.
  - 캐리어 각 φ = −π/2 + kC·θ (θ=0 에서 피니언이 맨 아래). 피니언 중심 = C + 0.63·(cos φ, sin φ). 캐리어 팔 rotation.z = φ, 핀 위치 = 피니언 중심.
  - 피니언: rotation.z = `meshAngle(C, 24, θs, 피니언 중심, 12)`.
  - 링: rotation.z = θr = −1.8326 + kR·θ (초기 위상 −105°: θ=0 에서 피니언 이가 링 이골에 드는 값 — 잇수와 방향만으로 정해져 모듈과 무관). 링 플랜지도 같은 각.
  - 롤러: rotation.z = −θr·1.04/0.09.
  - 벨트 표시 `setOffset`: 열린 벨트·엇걸이 로프 모두 θ·0.33.
- 간헐·변속 없음(연속 운동).

## 판화 대조 후 고친 것 (Fable 교차 읽기 2026-11-25)
- 구성(윗 풀리 + 크랭크, 열린 띠 → 링 바깥, 엇걸이 띠 → 태양 쪽 풀리, 맨 아래 피니언)은 판화와 일치.
