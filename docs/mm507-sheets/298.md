# 298 옛 회중시계 탈진기(왕관 바퀴·버지)
원문(en): "An old-fashioned watch escapement." — 옛날 방식의 회중시계 탈진기이다. (원문은 이 한 줄뿐 — 구조는 판화로 읽는다.)
쉬운 풀이: 가로축에 달린 왕관 바퀴(테 한쪽 면에 톱니가 솟은 바퀴)의 톱니 앞을 세로 굴대(버지)가 지나고, 버지에는 위·아래로 깃발 모양 팔레트 둘이 서로 100° 벌어져 붙어 있다. 왕관 바퀴 맨 위 이와 맨 아래 이는 서로 반대 방향으로 움직이므로, 버지 꼭대기의 균형 바퀴 C 가 좌우로 돌 때 위 팔레트와 아래 팔레트가 번갈아 이를 막았다 놓는다. 한 번 오갈 때 왕관 바퀴가 이 하나(24°)만큼 돈다. 왕관 바퀴 축 왼쪽의 웜은 아래 톱니바퀴와 물려 있다.
판화 묘사(원본 448×516 px, **비스듬한 앞모습**): 위에 큰 수평 균형 바퀴(타원으로 보임, 가로 [25~420·150~215], 살 3, 글자 C, 가운데 허브 [230·185]). 허브에서 가는 세로 굴대(버지)가 아래로 [220·420] 까지. 버지 왼쪽에 옆에서 본 왕관 바퀴(북 모양 [165~210·255~370], 오른쪽 가장자리에 지그재그 톱니), 그 위 끝 [200~250·250~285] 에 버지를 감싸는 줄무늬 덩이(위 팔레트와 맨 위 톱니). 왕관 바퀴 축이 왼쪽으로 [10·255] 까지 뻗고, [70~100·245~270] 에 두 바퀴 감긴 나사(웜). 웜 아래 왼쪽에 정면으로 본 톱니바퀴(중심 [95·385], 이 약 30, 창 4), 그 오른쪽 [160·410] 에 위를 가리키는 화살표(반시계).

## ★ 판화 읽기
판화 하나(비스듬한 앞모습 — 축이 서로 엇갈린 3D). 왕관 바퀴는 보이게 키움(판화 반지름 ≈ 57 px → 0.42). 판화 왕관 바퀴 중심 ↔ 세계 (0.30, 1.55, 0.27), 버지 ↔ x 0.55·z 0.27 의 세로선.
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 균형 바퀴 C(수평, 반지름 0.48) > 웜 휠(정면, 이 20, 피치 반지름 0.50) > 왕관 바퀴(세로 면, 이 15, 테 반지름 0.42). 웜 1(왕관 바퀴 축). 보충한 태엽통(웜 휠 뒤, 반지름 0.40).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 축 셋이 엇갈림: 왕관 바퀴 축 = x(가로), 버지 = y(세로), 웜 휠 축 = z(앞뒤). 버지는 왕관 바퀴 톱니 끝보다 0.07 앞(+x)을 지난다.
4. 고정점은? → 왕관 바퀴 축 받침 2(뒤판 기둥), 버지 아래 받침·위 받침(뒤판에서 나온 팔 — 판화에 없음, 보충), 웜 휠 축(뒤판 보스).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 균형 바퀴 C 가 스스로 흔들림(각만 시간표). 웜 휠은 태엽통(보충)이 반시계로 밀고, 웜을 거쳐 왕관 바퀴를 민다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 왕관 바퀴는 테의 +x 면에 톱날 이 15(앞면이 축 방향으로 곧고, 등이 비스듬). 맨 위 이는 +z(앞), 맨 아래 이는 −z(뒤)로 움직인다. 위 팔레트는 위 이의 앞면 끝 모서리를, 아래 팔레트는 아래 이의 앞면 끝 모서리를 막는다. 웜은 웜 휠 맨 위 이와 물림.
7. 한 줄에 놓인 것은? → 버지·균형 바퀴 축·두 팔레트가 세로선 (x 0.55, z 0.27). 왕관 바퀴 축·웜이 가로선 (y 1.55, z 0.27). 웜 휠 중심은 웜 바로 아래(x −0.85).
8. 판화에 글자(A, B…)가 가리키는 부품은? → C 균형 바퀴. 나머지 글자 없음.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 있음(★ 질문 거리). (가) 원문이 한 줄뿐이라 판화로 읽음: 버지 탈진기. (나) 판화의 줄무늬 덩이를 위 팔레트 + 맨 위 톱니로 읽고, 아래 팔레트는 판화에서 가려 보이지 않지만 버지 탈진기에 꼭 있어야 하므로 넣음. (다) 균형 바퀴는 깊이 한계(z −0.25~0.8) 때문에 반지름 0.48 로, 왕관 바퀴는 보이게 키워 판화 크기 비(3.7:1)와 다름. (라) 판화의 웜 + 톱니바퀴는 시계 바퀴열로 보고 그대로 넣되, 움직임은 왕관 바퀴를 따른다(웜 휠 = 왕관 바퀴 각 ÷ 20). (마) 버지 탈진기는 본디 되튐이 크다 — 걸린 동안 바퀴가 4.8° 뒤로 밀린다(판화대로).

## 해석(결정 사항)
- **균형 바퀴 각만 시간표, 왕관 바퀴 각은 접촉에서**: θ(t) = 30°·sin(π t)(주기 2 초, 버지 `rotation.y` +). 왕관 바퀴는 웜(태엽통)이 늘 +φ 쪽(맨 위 이가 +z 로)으로 민다 → 매 순간 φ = 걸린 이의 바깥 끝 모서리가 팔레트 닿는 면에 닿는 각.
- 깃발 팔레트는 버지 축을 품은 평면이고 세로(y)로 곧으므로, 닿음은 **xz 평면**에서 풀린다: 이 끝 모서리는 늘 x = 0.48(톱니 끝 면)에 있고 z 만 움직이며(z = 0.27 + 0.42·sin α), 팔레트 닿는 면이 x = 0.48 을 지나는 높이가 곧 이의 z. 이 끝이 팔레트 끝(길이 0.12)을 지나면 놓인다.
- shapely 로 톱니 투영(반지름 0.38·0.40·0.42 의 세 단면)과 깃발 다각형을 균형 위상 0.1° 간격 3600 자세로 겹쳐 보아 접촉 식과 같음(차 0.00012°, 겹침 0).
- 한 주기(2 초)에 정확히 +24°(이 하나). 반 주기마다 드롭 5.62°, 되튐 4.77°.

## 동작 (`state298(t)` — 결정적, 닫힌 접촉 식)
1. n = floor(t/2), τ = t − 2n, θ = 30·sin(π τ)(도).
2. 닿는 면 높이: z(γ) = 0.07·tan γ − 0.008/cos γ(버지 축선에서, 톱니 끝 면 x 0.48 에서 잰 값). 닿는 점이 깃발 위 s(γ) = (0.07 − 0.008·sin γ)/cos γ ≤ 0.12 이고 γ < 89.9° 일 때만 닿음(아니면 '놓임').
3. 위: γu = 50 + θ, α = asin(z(γu)/0.42). 아래: γl = 50 − θ, α = 180° + asin(z(γl)/0.42). φ = α − 24°·k.
4. 구간: τ < 0.5 → 위·k = 0, 놓이면 아래·k = 7. 0.5 ≤ τ < 1.5 → 아래·k = 7, 놓이면 위·k = −1. τ ≥ 1.5 → 위·k = −1. φ 에 24·n 을 더한다. (놓이는 γ = 58.2198°, 즉 θ = ±8.2198°.)
5. 기대값(파이썬 검산 — 0.002° 안에서 맞아야 함):

   |---|---|---|---|
