# 281 홈 캠 원판과 레버
원문(en): "The revolution of the disk causes the lever at the right to vibrate by the pin moving in the groove in the face of the disk." — 원판이 회전하면 원판 앞면의 홈 속에서 핀이 움직여, 오른쪽의 레버가 흔들린다.
쉬운 풀이: 원판 앞면에 콩팥 모양의 닫힌 홈이 파여 있다. 레버 팔 끝의 핀(롤러)이 그 홈 속에 들어 있어서, 원판이 돌면 홈이 핀을 원판 중심 쪽으로 당겼다 바깥으로 밀었다 하고, 위 받침점에 매달린 레버가 좌우로 흔들린다. 레버 움직임은 **홈 모양이 만든다**.
판화 묘사(원본 508×528 px, 정면): 큰 원판(중심 [205·293], 반지름 ≈ 110 px)이 두 다리 A 자 받침([100~300·390~470]) 위에 서 있다. 원판 앞면에 두 줄 선으로 그린 콩팥 모양 닫힌 홈(허브 [205·293] 둘레, 왼쪽이 허브 가까이 오목, 오른쪽 위가 테두리 가까이 부풂). 원판 오른쪽 위 [283·147] 에 레버 받침점(작은 고리), 거기서 오른쪽 아래 [345·460] 으로 긴 레버, 받침점 바로 아래에 레버에서 원판 쪽으로 나온 삼각 팔([255~295·190~255]) — 이 팔 끝의 핀이 홈 오른쪽 위에 들어감. 받침점에서 원판 뒤로 점선 기둥(받침점 받침).

## ★ 판화 읽기
판화 하나(정면). 판화 1 px ≈ 0.0091(원판 반지름 110 px = 1.0). 원판 중심 [205·293] ↔ 세계 C = (−0.40, 1.70).
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 홈 원판 1(반지름 1.0), 홈 속 롤러 1(반지름 0.05). 기어·풀리 없음.
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음. 레버(팔·막대)가 원판 앞을 지나간다(다른 깊이 층).
4. 고정점은? → 원판 축(뒤판 보스 + A 자 다리 위 베어링 고리), 레버 받침점(뒤판 받침대의 핀).
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 없음. 원판이 일정하게 돈다(원문 "revolution of the disk").
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 기어 없음. 레버 팔 끝 핀의 롤러가 원판 앞면 **닫힌 홈 속**에 들어가 양쪽 벽 사이에 갇힘(틈 0.003).
7. 한 줄에 놓인 것은? → 레버 받침점 P 는 원판 중심 C 에서 오른쪽 0.75, 위 1.20. 롤러 중심은 늘 홈 가운데선 위, 레버 팔 위(P 에서 1.25).
8. 판화에 글자(A, B…)가 가리키는 부품은? → 글자 없음(번호 281 뿐).
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → (가) **움직임은 홈이 만든다**: 레버 각은 시간표가 아니라 "롤러가 홈 가운데선 위에 있다"는 조건에서만 나온다. 홈 모양은 핀이 원판 중심에서 떨어진 거리 ρ = 0.55 + 0.30·cos φ 가 되게 정한 닫힌 곡선(판화처럼 한쪽이 허브 가까이 오목한 콩팥 꼴). (나) 판화의 받침점 기둥(원판 뒤 점선)은 원판 뒤를 지나 어디에 서는지 알 수 없음 → 뒤판에 붙은 받침대로 바꿈. (다) 롤러가 레버 팔 끝에 가려지지 않게 팔 끝을 가늘게(폭 0.05) 하고 팔이 롤러 중심에서 끝남. 질문 거리 1(받침점 기둥).

## 해석(결정 사항)
- 원판 각 φ(반시계). 롤러(핀) 중심 Q 는 P 를 중심으로 반지름 Lp = 1.25 원 위, C 에서 거리 ρ(φ) = 0.55 + 0.30·cos φ(0.25 ~ 0.85). 두 원의 교점 가운데 **P 에서 볼 때 C 방향의 반시계 쪽** 해.
  - |PC| = 1.41510, 기준각 b0 = atan2(C − P) = −122.005°. γ = acos((2.00250 + 1.5625 − ρ²) / 3.53774), θpin = b0 + γ, Q = P + 1.25·(cos θpin, sin θpin).
- **홈 가운데선**(원판 좌표) G(φ) = Rot(−φ)·(Q(φ) − C), φ 0 → 2π — 닫힌 곡선(롤러가 지나는 길 그대로). 이 식으로 홈을 만들고, 같은 식으로 레버를 움직이므로 롤러는 늘 홈 가운데선 위.
- 레버는 한 몸: 팔(P → Q 방향, θpin), 막대(θpin + 35°, 길이 2.3), 사이 삼각 판, 허브. 레버 흔들림 28.44°(θpin −113.91° ~ −85.47°).
