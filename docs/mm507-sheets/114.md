# 114 결손 피니언과 이중 랙
원문: "Uniform circular motion into reciprocating rectilinear motion, by means of mutilated pinion, which drives alternately the top and bottom rack." (스캔 글자가 뒤섞여 있어 바로잡아 읽음) — 이가 일부 빠진 피니언이 위 랙과 아래 랙을 번갈아 밀어, 한 방향의 고른 회전을 직선 왕복으로 바꾼다.

## ★ 판화 읽기
판화는 그림 하나(정면). 4배 확대 `shots/_verify/114-fig-x4.png` 로 다시 읽음(px 는 4배 그림 기준).
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 틀 안 가운데의 **결손 피니언**: 이끝 반지름 약 195px, 가운데에 짙은 축 단면과 허브 고리. 이는 **오른쪽 절반쯤에만** 7개쯤(위쪽 75° 방향에서 오른쪽을 돌아 아래 왼쪽 −115° 방향까지), 왼쪽은 이 없는 매끈한 원호(이뿌리 반지름쯤). 이를 온 둘레에 채우면 12~13개 자리(피치 약 80px, 피치 반지름 약 160px).
2. 줄·벨트는? → 없음. 대신 **긴 고리 꼴 틀 1개**(바깥 길이 약 1170px × 높이 560px, 띠 두께 약 85px, 양 끝이 둥글다)의 안쪽 윗변에 아래로 난 이 9개, 안쪽 아랫변에 위로 난 이 9개(랙 두 줄, 길이 약 690px — 안쪽 길이 1020px 의 0.68배). 틀의 양 끝에서 두 줄 선(납작 막대, 높이 약 80px)이 좌우로 뻗어 그림 밖으로 이어진다.
3. 교차하는 가닥은? → 없음. 피니언의 이가 아래 랙에 물린 자리가 검게 칠해져 있고, 위쪽 이 하나도 위 랙 이에 닿아 있다(9번 참고).
4. 고정점은? → 판화에는 없다. 피니언 축은 제자리에서 돌고(축 단면), 틀은 양 끝 막대가 안내에 끼여 좌우로만 움직이는 것으로 읽는다(안내는 그리지 않음 — 막대가 잘려 있다).
5. 추·손잡이·크랭크는? → 없음. 구동은 피니언(원문 "mutilated pinion, which drives").
6. 이는 어디에 났고 무엇이 물리는가? → 랙의 이는 틀 **안쪽** 위·아래 변에(서로 마주 봄). 피니언은 **틀 안에서** 위 랙에는 아래에서, 아래 랙에는 위에서 물린다. 한 번에 한쪽만 물려야 한다.
7. 한 줄에 놓인 것은? → 피니언 축 중심, 틀의 가운데선, 양 끝 막대의 가운데선이 같은 높이. 위·아래 랙은 길이가 같고 같은 x 범위. 피니언은 틀 가운데에서 조금 오른쪽(왕복 도중의 한 순간).
8. 글자가 가리키는 부품은? → 글자 없음(번호 114 뿐).
9. 판화와 원문이 다르거나 판화대로 돌 수 없는 곳은? → 원문과 어긋나는 곳·기구가 달라지는 곳은 없음. 다만 이 수는 줄여야 돈다: 판화는 이를 반 바퀴 넘게(약 190°, 7개) 그려 위·아래 랙에 **동시에** 닿아 있는데, 그러면 두 랙을 반대쪽으로 밀어 끼인다. 원문은 "번갈아" 민다고 하므로 이 구간을 줄여야 돈다 → 12개 자리 가운데 **4개**(120° 구간)만 남긴다(node 모의로 끼임 없이 도는 가장 큰 수를 확인. 5개는 한쪽을 놓기 전에 반대쪽에 닿는다). 기구의 종류·구성은 판화 그대로이므로 사용자 질문 거리는 아님.
- 그 밖의 선: 피니언 왼쪽의 가는 반원 = 이를 깎아 낸 매끈한 둘레. 축 둘레의 두 겹 원 = 허브. 틀 바깥선·안쪽선 두 줄 = 띠의 두께. 막대와 틀이 만나는 곳의 둥근 선 = 살붙임(모형은 생략).

## 해석(결정 사항)
- 판화 비: 랙 9개 이 두 줄, 피니언 12개 자리(모듈 0.04, 피치 반지름 0.24), 틀 안쪽 길이 1.7(랙 길이 1.13 의 1.5배), 양 끝 납작 막대.
- 이는 4개만(9번). 랙 이끝은 모듈의 0.7배로 낮춤(잇수 12 짜리 인벌류트 이의 뿌리를 랙 이끝이 파고드는 것을 막음 — 모의에서 침범 0).
- 회전 방향은 판화에 없다 → 반시계로 정함. 반시계일 때 위 랙에 물리면 틀이 왼쪽, 아래 랙에 물리면 오른쪽으로 간다.
- 판화에 없는 보충(최소): 피니언 축의 뒤판 보스, 양 끝 막대의 납작 막대 안내 2개(벽걸이).

## 구동
결손 피니언(name `pinion`, 반시계로 계속 돈다). theta += OMEGA(1.6)·speed·dt, 피니언 각 psi = theta + `K114.pose` (pose = 250° − 1.6 rad — t = 1 에 판화 자세). 한 바퀴 3.93 s 에 틀이 한 번 왕복. `k114State(theta)` 가 돌려준다.

## 부품과 치수 (새 부품은 모두 `kit/k113.ts`, 이미 구현됨. 치수 상수 `K114`)
배치 상수: CY = 1.75 (피니언 축·틀 가운데선 높이, x 는 0), ZF = 0.2 (피니언·틀의 가운데 평면).
- 결손 피니언(name `pinion`): `mutilatedPinion113(12, 0.04, 4, 0.1)` — 피치 반지름 0.24, 이끝 0.28, 이 없는 둘레 0.192. 이는 로컬 0°~120° 구간에 4개(이 중심 15°·45°·75°·105°). 위치 (0, 1.75, 0.2). 청동, 표시점은 이 구간 가운데 방향.
- 피니언 축: `shaftZ(0, 1.75, 0.3, 0.045)` — 뒤판 보스에서 틀의 빈 안쪽을 지나 피니언 앞까지.
- 고리 틀(name `frame`): `rackFrame113(K114.frame)` — 위치 (x(θ), 1.75, 0.2). 피치선은 가운데선에서 ±0.24, 안쪽 반높이 0.29(이뿌리선), 안쪽 반길이 0.85(끝 호 반지름 0.32), 띠 두께 0.09 → 바깥 반길이 0.94·반높이 0.38, 두께 0.1. 랙 이 9개씩(피치 0.1257, 이 범위 ±0.551, 위·아래 모두 가운데에 이 하나). 양 끝 납작 막대: 높이 0.09, 끝 x = ±1.77(틀 좌표). 강철.
- 납작 막대 안내 2개(고정): `barGuide113(−1.36, 1.75, 0.2, 0.09, 0.1)`, `barGuide113(1.36, 1.75, 0.2, 0.09, 0.1)` — 길이 0.14(x 1.29~1.43). 막대가 X 방향으로 미끄러지는 네모 구멍(틈 0.004). 뒤판에서 나온 받침 덩어리 + 위아래 턱 + 앞 덮개.
- 받침대·뒤판 `displayStand()` (판화에 없음 — 공통 받침).
- 전체 가로 범위: 막대 끝 ±1.77 → 왕복 때 ±2.10. 세로 1.37 ~ 2.13.

## 동작 (모두 theta 의 절대 함수 — `k114State(theta)` 가 { psi, x, side } 를 돌려준다)
- 피니언: `pinion.rotation.z = psi`, psi = theta + pose.
- 틀: `frame.position.x = x = frameShift114(psi)` — 준정적 접촉 모의로 구운 표 `SHIFT114`(1° 간격 180개, 나머지 반 바퀴는 x(psi + 180°) = −x(psi))를 보간. 한 바퀴마다 정확히 되풀이(누적 오차 없음, 역회전도 같은 표).
- 한 바퀴(psi)의 시간표: **312.6° → 118.0°** 위 랙에 물려 틀이 왼쪽으로 0.657(+0.3285 → −0.3285), **118.0° → 132.6°** 어느 쪽에도 안 물리고 쉼, **132.6° → 298.0°** 아래 랙에 물려 오른쪽으로 0.657, **298.0° → 312.6°** 쉼. 물린 동안 틀 속도 = 피치 반지름 × 각속도(이가 들어오고 나가는 끝에서만 최대 1.26배).
- side: 1 = 위 랙에 물림, −1 = 아래 랙, 0 = 쉼(notes·이름표 강조용).
- 시각: **t = 1.0 (psi = 250°, 이가 오른쪽 아래에서 아래 랙을 미는 중 = 판화 자세, x = +0.165)**, t = 1.6 (psi = 305°, 쉬는 중, x = +0.3285 오른쪽 끝), **t = 2.2 (psi = 0°, 위 랙을 미는 중, x = +0.128)**, t = 3.0 (psi = 73°, x = −0.179).

## 키트 추가
이미 구현됨: `kit/k113.ts` (113·114·115 공용). 모델은 `'../kit/k113'` 에서 직접 import.
- `K114` — 치수 상수 { module, teeth, count, frame: RackFrameSpec, pose }
- `k114State(theta: number): K114State` — { psi, x, side }
- `frameShift114(psi: number): number` — 구운 표 `SHIFT114`(간격 `SHIFT114_STEP` = 1°) 보간
- `mutilatedPinion113(teeth: number, module: number, count: number, width?: number): THREE.Group` — 결손 피니언(`userData.outline`)
- `mutilatedOutline113(teeth: number, module: number, count: number): V2[]` — 그 윤곽(순수 함수)
- `rackFrame113(s: RackFrameSpec): THREE.Group` — 안쪽 위아래 랙 + 양 끝 막대(`userData.outlines.hole`)
- `frameHole113(s: RackFrameSpec): V2[]`, `frameOuter113(s: RackFrameSpec): V2[]` — 틀 안쪽·바깥 윤곽(순수 함수)
- `barGuide113(x: number, y: number, zc: number, barH: number, barT: number, len?: number): THREE.Group` — 납작 막대 안내(벽걸이)
