# 085 캠으로 들어 올리는 낙하 막대
판화(public/mm507/fig/085.png, 4배 확대 shots/_verify/085-fig-x4.png 로 다시 읽음): 그림 하나(정면). 오른쪽에 바닥에 선 기둥 틀(등이 오른쪽으로 휜 버팀), 기둥에서 왼쪽으로 **안내 팔 두 개**(위·아래)가 나와 세로 막대 A 를 잡고 있다. 막대 아래 끝에는 사다리꼴 쇳덩이(스탬프 머리)가 바닥에서 조금 떠 있다. 막대와 기둥 사이에 축(두 겹 원)이 있고, 축에서 **굽은 팔(와이퍼) 두 개**가 서로 반대쪽으로 나와 있다. 왼쪽 위 팔의 끝이, 막대에 박힌 짙게 칠한 네모 B 의 밑면을 받치고 있다.
원문 요지: 캠(와이퍼) 두 개가 달린 축이 계속 돌면서 막대 A 의 돌기 B 를 밀어 올리고, 놓으면 막대는 제 무게로 떨어진다 — 간헐적인 오르내림. 광석 스탬프·분쇄기·해머에 쓴다.

## ★ 판화 읽기
1. 바퀴(풀리·기어·도르래)는 몇 개이고 크기 차례는? → 바퀴 없음. 축 하나에 굽은 캠 팔 둘(180° 간격, 끝 반지름 ≈ 허브 반지름의 3배).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 없음.
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점(천장·벽·바닥)은 어디인가? → 바닥에 선 기둥 틀(밑이 오른쪽으로 넓게 퍼짐). 안내 팔 둘과 캠 축 받이(기둥에서 나온 둥근 귀)가 기둥에 붙어 있다.
5. 추·손잡이·크랭크는 어디에 무엇에 달렸는가? → 막대 A 아래 끝의 스탬프 머리(무게). 손잡이·크랭크 없음(캠 축이 구동).
6. 기어는 어느 가장자리에 이가 났고 무엇이 어느 쪽에서 물리는가? → 기어 없음. 캠 팔의 **볼록한 윗면**이 돌기 B 의 **밑면을 아래에서** 받쳐 올린다. 닿는 곳은 캠 축의 왼쪽(막대 쪽), 캠 축보다 높은 자리.
7. 한 줄에 놓인 것(같은 높이·같은 세로선)은? → 위 안내 팔 구멍 — 돌기 B — 아래 안내 팔 구멍 — 스탬프 머리가 한 세로선(막대 A). 캠 끝이 닿는 점도 그 세로선 안(돌기 너비 안).
8. 판화의 글자가 가리키는 부품은? → A = 세로 막대, B = 막대의 돌기(짙은 네모). 원문 글자와 같다. 캠에는 글자가 없다.
9. 판화와 원문이 다르거나 판화대로는 계속 돌 수 없는 곳이 있는가? → 없음. 판화에서 캠 팔이 막대 너비 안까지 겹쳐 그려져 있다 → 캠은 막대 **앞**의 평면에서 돌고, 돌기 B 는 막대 앞면에서 앞으로 나온 것으로 읽었다(막대를 뚫지 않는다).
- 그 밖의 선: 막대의 굵은 오른쪽 선 = 그림자 쪽 윤곽. 안내 팔 밑의 비스듬한 선 = 팔의 버팀 살. 기둥의 세로 두 줄 = 기둥 앞면 모서리. 캠 축 오른쪽의 둥근 선 = 기둥에서 나온 축받이 귀. 바닥 가로선 = 바닥.

## 해석(결정 사항)
- 캠 축은 **시계 방향**(왼쪽 팔이 올라간다). 팔의 일하는 면은 기초원 반지름 0.2 의 **인벌류트** — 평평한 돌기 밑면과는 언제나 캠 축에서 0.2 왼쪽의 세로선에서 닿고, 막대는 등속으로 오른다(캠 1 rad 에 0.2). 스탬프 밀에서 실제로 쓰는 꼴이다.
- 인벌류트가 끝나면(끝 반지름 0.32) 팔 끝 모서리가 돌기 밑면을 오른쪽으로 0.03 쓸며 조금 더 올리고, 돌기 오른쪽 모서리를 벗어나는 순간 막대가 떨어진다. 그때 캠의 모든 점은 돌기 오른쪽에 있어 떨어지는 돌기와 부딪히지 않는다(수치 확인).
- 떨어짐은 포물선(캠 각 0.3 rad ≈ 0.19 s), 그 뒤 모루 위에서 쉰다. 반 바퀴(π)마다 되풀이.
- 판화의 축받이 귀는 만들지 않고 캠 축은 뒤판 보스가 받친다(공통 받침). 모루(받침쇠)는 판화에 없음 — 머리가 떨어져 멈출 자리.

## 구동
캠 축(시계). theta += OMEGA(1.6)·speed·dt, thetaE = theta + 2.6416. 반 바퀴 = 1.963 s 에 한 번 들었다 놓는다.

## 부품과 치수 (키트 `kit/k083.ts`, 치수 상수 `K85`)
캠 축 = (0.224, 2.0). 막대 A 중심선 x = 0.
- 캠 축: `shaftZ(0.224, 2.0, 0.42, 0.05)`.
- 캠(name `cam`): `wiperCam(0.07)` 위치 (0.224, 2.0, 0.31), `rotation.z = −thetaE`. 허브 반지름 0.1, 기초원 0.2, 끝 반지름 0.32, 팔 둘. 청동(구동).
- 막대 A(name `rodA`): `stampRod(-1.48, 0.85, 0.11)` 위치 (0, 2.0 + lift, 0.2). 네모 막대 0.11 × 0.11(쉴 때 y 0.52 ~ 2.85), 앞면의 돌기 B(x −0.046 ~ 0.054, 밑면 y 2.05 + lift, 높이 0.07, 앞으로 0.11), 아래 머리(사다리꼴, 윗변 0.24·밑변 0.45·높이 0.25, 쉴 때 밑면 y 0.27).
- 기둥 틀(name `frame`): `stampFrame(2.57, 0.58, [1.07, 2.5], 0.2)` 위치 (0.58, 0.18, 0.2). 기둥 왼쪽 면 x 0.58, 꼭대기 y 2.75, 버팀 밑 끝 x 1.53. 안내 팔 높이 y 1.25, 2.68(팔 높이 0.09), 팔 끝 네모 구멍이 막대를 감싼다(틈 0.004).
- 모루(판화에 없음): `anvilBlock(0.56, 0.09, 0.34)` 위치 (0, 0.18, 0.2) — 윗면 y 0.27.
- 뒤판·바닥 `displayStand()`.
- 가로 범위 x −0.28 ~ 1.53, 높이 0.18 ~ 3.07(막대 꼭대기, 가장 높이 들렸을 때).

## 동작 (모두 thetaE 의 함수 — `k85Lift(thetaE)`, `k85Mode(thetaE)`)
- β = thetaE mod π. 캠 `rotation.z = −thetaE`.
- β ≤ 0.25: 쉼(lift 0). 0.25 < β ≤ 1.249: 인벌류트 — lift = 0.2·(β − 0.25) (등속, 0 → 0.20). 1.249 < β ≤ 1.3641: 끝 모서리 — lift = 0.32·sin(0.8958 + β − 1.249) − 0.05 (0.20 → 0.2211). 1.3641 < β < 1.6641: 떨어짐 — lift = 0.2211·(1 − ((β − 1.3641)/0.3)²). 그 뒤 쉼.
- 막대 `position.y = 2.0 + lift`. 돌기 밑면 높이 = 2.05 + lift, 닿는 점 x = 0.024(인벌류트 구간) → 0.054(끝 모서리 구간).
- 한 주기(π) 가운데 올림 0.355, 떨어짐 0.095, 쉼 0.55. 누적 오차 없음(β 만의 닫힌 식).
- 시각: **t = 1 (thetaE 4.2416, β 1.10)** 거의 다 들림(lift 0.17) — 판화 자세(왼쪽 위 팔 끝이 B 밑). **t = 1.6 (β 2.06)** 떨어진 뒤 쉼, 다음 팔이 아래에서 올라오는 중. t = 1.2 (β 1.42) 떨어지는 중.
