# 227 체인과 체인 풀리
원문(en): "Represents a chain and chain pulley. The links being in different planes, spaces are left between them for the teeth of the pulley to enter." — 체인과 체인 풀리. 고리들이 서로 다른 평면에 있어서 그 사이에 풀리의 이가 들어갈 틈이 생긴다.
쉬운 풀이: 별 모양 바퀴의 골에는 납작한 판 고리가 눕고, 별의 뾰족한 이는 판 고리와 직각으로 선 철사 고리의 구멍(틈)으로 들어간다. 그래서 체인이 미끄러지지 않고 바퀴를 따라 오르내린다.
판화 묘사(원본 510×443 px, 정면): **별 모양 바퀴**(중심 약 [258·195], 뾰족한 이 6개 — 0°·60°·120°·180°·240°·300°, 이끝 반지름 ≈ 167 px, 이 옆선은 살짝 오목). 가운데 두 겹 동그라미(허브, 반지름 ≈ 37·25 px). 체인이 위쪽 반 바퀴를 감는다: 위쪽 골 셋(90°·150°·30°)에 **둥근 끝 납작 판**(구멍 둘, 구멍 사이 ≈ 60 px, 폭 ≈ 22 px)이 하나씩 누워 있고, 판과 판 사이(이 자리)에는 판이 그려져 있지 않고 별의 이끝이 체인 선 밖으로 나와 있다. 판의 구멍 자리는 바퀴 중심에서 ≈ 130 px. 왼쪽·오른쪽(9시·3시)에서 체인이 **곧게 아래로** 내려가 그림 밑에서 잘린다(늘어진 가닥에도 둥근 끝 판과 구멍이 보임).

## ★ 판화 읽기
판화는 그림 하나(정면). 세계 1 px ≈ 0.0037.
1. 바퀴는 몇 개이고 크기 차례는? → 1개. 별 모양 체인 풀리(이끝 반지름 0.62, 고리 마디 원 반지름 0.48, 이 6).
2. 줄·벨트는 몇 개이고 어디를 지나는가? → 체인 1개. 왼쪽 세로 가닥(아래 끝 = 짐 추) → 바퀴 위쪽을 9시 → 12시 → 3시로 180° 감음 → 오른쪽 세로 가닥(아래 끝 = 반대쪽 추). 판화에는 끝이 잘려 있다 → 끝은 추 둘(보충).
3. 교차하는 가닥이 있는가? → 없음.
4. 고정점은 어디인가? → 바퀴 축(뒤판에 박은 고정 축, 판화의 두 겹 동그라미).
5. 추·손잡이·크랭크는? → 판화에 없음(가닥이 잘림). 보충: 왼쪽 끝에 짐 추, 오른쪽 끝에 작은 반대쪽 추. 바퀴를 왕복으로 돌려(축을 돌린다고 봄) 짐이 오르내린다.
6. 기어는 어디에 이가 났고 무엇이 물리는가? → 별의 **바깥**에 뾰족한 이 6. 이는 체인의 **철사 고리(판과 직각인 평면) 구멍** 속으로 들어가고, 판 고리는 이 사이 **골 바닥**(평평)에 눕는다.
7. 한 줄에 놓인 것은? → 두 세로 가닥은 x = ±0.48(마디 원의 9시·3시 접선)으로 나란. 위쪽 판 고리는 12시 골 가운데(바퀴 중심의 바로 위).
8. 판화의 글자가 가리키는 부품은? → 글자 없음(번호 227 뿐).
9. 판화와 원문이 다르거나 계속 돌 수 없는 곳이 있는가? → 원문 "고리들이 서로 다른 평면"을 판화는 판 고리만 그렸다(이 자리 고리는 옆에서 본 선이라 이 뒤에 숨음). → **해석: 판 고리(바퀴 면과 나란, 바퀴와 같은 평면)와 철사 고리(바퀴 면과 직각인 평면, 타원 고리)가 번갈아** 이어지고, 이가 철사 고리 구멍으로 들어간다(★질문 거리 1). 판화의 가닥은 끝이 잘려 있어 끝에 추를 달고 왕복으로 움직인다(질문 2). 이 해석으로 한 주기 내내 판이 별에 박히지 않음을 파이썬으로 검산(최소 틈 0.003).

## 해석(결정 사항)
- 체인 = **판 고리 9개 + 철사 고리 8개**(번갈아). 마디(판 구멍) 18개 i = −8 … 9. 마디 i → i+1 사이 칸이 i 짝수면 판 고리, 홀수면 철사 고리.
- 바퀴 위에서 판 고리는 마디각 α = 26.6°(0.46426 rad), 철사 고리는 β = 33.4°(0.58294 rad), α + β = 60° = 이 하나. 마디 원 반지름 Rj = 0.48 → 판의 구멍 사이 a = 2·0.48·sin(13.3°) = **0.2208**, 철사 고리 구멍 사이 b = 2·0.48·sin(16.7°) = **0.2759**.
- 체인은 **굳은 고리 사슬**: 바퀴 위 마디는 바퀴와 함께 돌고, 바퀴에서 벗어난 마디는 세로 가닥 위에 앞 마디로부터 고리 길이(a 또는 b)만큼 떨어진 자리(아래 `chainJoints227`).
- 바퀴는 왕복: θ(t) = −(π/3)·sin(0.5t)(반시계 +). 먼저 시계 방향 → 왼쪽 짐이 올라간다. 진폭 = 이 하나(60°), 체인 이동 ≈ 0.50.

## 구동
바퀴(축 앞 허브)를 돌린다. θ(t) = −1.047198·sin(0.5t) [rad]. t = 0 = 판화 자세(위쪽 판 고리가 12시 골 가운데, 9시·3시에 이).

## 동작 (`state227(t)` — 결정적)
1. `chainJoints227(θ)`: 마디 i = −8 … 9. 칸 i(마디 i → i+1)의 바퀴 위 각 크기 step(i) = 짝수 i 면 α, 홀수 i 면 β(**음수 i 의 짝홀은 ((i % 2) + 2) % 2 로**), 길이 chord(i) = 짝수 a, 홀수 b.
   - 마디 각 ang(i) = π/2 + α/2 + θ − cum(i), cum(0) = 0, cum(i+1) = cum(i) + step(i), cum(i−1) = cum(i) − step(i−1).
   - 0 ≤ ang(i) ≤ π 이면 바퀴 위: J[i] = (0.48·cos ang, 0.48·sin ang).
   - 바퀴 위 마디 가운데 가장 작은 번호 lo, 큰 번호 hi. i < lo(왼쪽 가닥, i = lo−1 부터 내려가며): J[i] = (−0.48, J[i+1].y − √(chord(i)² − (J[i+1].x + 0.48)²)). i > hi(오른쪽, hi+1 부터): J[i] = (0.48, J[i−1].y − √(chord(i−1)² − (0.48 − J[i−1].x)²)).
2. 적용: `star.rotation.z = θ`. 고리 배치(위). 추 고리 원점 = C + J[−8] / C + J[9], 추 위치는 그 아래(부품 절).
3. t = 0 마디(C 기준): −8 (−0.48, −1.3515) / −7 (−0.48, −1.1306) / −6 (−0.48, −0.8548) / −5 (−0.48, −0.6339) / −4 (−0.48, −0.3580) / −3 (−0.48, −0.1372) / −2 (−0.4598, 0.1379) / −1 (−0.3493, 0.3292) / 0 (−0.1104, 0.4671) / 1 (0.1104, 0.4671) / 2 (0.3493, 0.3292) / 3 (0.4598, 0.1379) / 4 (0.48, −0.1372) … 9 (0.48, −1.3515)(좌우 대칭).
4. 끝 마디 높이(세계 y): t = 0 에 1.0985. 왕복 중 0.6018 ~ 1.5952(왼쪽·오른쪽이 반대로).
5. 간섭 검산(파이썬, θ −60° ~ +60° 1201 자세, 굳은 사슬 그대로): 판 고리(끝 반지름 0.04 포함) ↔ 별 윤곽 최소 틈 **0.003**(골 바닥 위에 누운 자세). 마디 ↔ 이 옆선 거리 0.043(판 끝 반지름 0.04, 철사 고리 끝이 z ≈ 0 에서 차지하는 반지름 0.033 보다 큼). 철사 고리 곧은 변(z ±0.06, 철사 0.011)과 이(z ±0.035): 틈 0.014. 철사가 판 구멍(0.016)을 지나는 자리의 벗어남 0.0019 + 철사 0.011 = 0.013 < 0.016.
6. 추 검산: 짐 추 바닥 최저 0.6018 − 0.392 = 0.21(받침 윗면 0.18 위), 추 몸 꼭대기 최고 1.5952 − 0.152 = 1.443 → 별 이가 쓸고 가는 원(반지름 0.62)에서 0.99 거리.

- 핵심: 바퀴가 이 하나만큼(±60°) 왕복하는 동안 **이가 철사 고리 구멍에 들어갔다 빠지고, 판 고리가 골에 앉았다 떠나며** 체인이 미끄럼 없이 따라가 왼쪽 짐이 0.50 오르내린다. 두 종류 고리가 서로 직각인 평면이라는 것이 비스듬한 시점에서 보인다.
- 장치: 판(밝은 steel)과 철사 고리(bronze)의 색 차이, 바퀴 노란 점, notes 의 짐 높이.
- 수치: 체인 속도 최대 0.48·(π/3)·0.5 = 0.251 /s, 짐 높이 0.602 ~ 1.595.

## ★ 난도·질문
난도 **C**(상) — 비원형 별 윤곽 + 두 종류 고리가 굳은 사슬로 바퀴를 감는다(띠 계열). GLM 금지, Sonnet(또는 Opus).
질문 거리(사용자에게) — 기본값으로 진행:
1. "서로 다른 평면의 고리": 판화에 그려진 판 고리 사이(이 자리)의 고리가 안 보인다. 기본값: 판 고리(바퀴와 같은 평면)와 **직각 평면의 타원 철사 고리**가 번갈아, 이가 철사 고리 구멍으로 들어감.
2. 체인 끝: 판화는 가닥이 잘려 있다. 기본값: 왼쪽 짐 추·오른쪽 반대쪽 추, 바퀴 왕복(±60°).
