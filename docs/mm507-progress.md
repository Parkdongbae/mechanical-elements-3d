- **새 파이프라인 실측(2026-11-25~26)**: 41~70번 28개 약 2시간, 71~100번 30개 약 2시간(설계표 70분 + 모델·검증 50분). autocheck 1~100 fail 0. 공용 rotArrow 시계 화살표 110° 버그 수정.

- **병렬 실행(2026-11-24)**: GLM 키는 여러 건을 동시에 돌려도 잘 된다(사용자 지시: 한 키로 **7개까지** 동시 실행 — 10개는 요청 한도 오류). basic 키가 5시간 한도면 Pro 키로.
- 설계표는 Sonnet 서브에이전트가 병렬 작성(5개씩), Opus 가 키트 정의 충돌·수치 모순을 정리.
- GLM 은 동시에 여러 건을 돌리면 요청 한도에 걸린다 → 순차 실행.
- glm-5.3 과 glm-5.3-flash 비교(미션 '시소'): 품질 비슷, flash 가 3배가량 빠르고 요청이 적다 → **모든 작업 flash**(사용자 지시 2026-11-24).
