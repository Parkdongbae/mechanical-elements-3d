## 실측 메모
- GLM 은 동시에 여러 건을 돌리면 요청 한도에 걸린다 → 순차 실행.
- glm-5.3 과 glm-5.3-flash 비교(미션 '시소'): 품질 비슷, flash 가 3배가량 빠르고 요청이 적다 → 양산은 flash, 뼈대는 glm-5.3.
- 책 원문을 모델이 길게 옮겨 적으면 출력 필터에 막힌다 → 원문은 OCR 로, 모델은 번역·풀이만.
