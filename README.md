# 기계요소 3D 실험실

중학교 기술·가정(2022 개정) '기계의 구성과 동력 전달' 단원용 3D 학습 웹앱.
고장 난 기계를 살펴보고 알맞은 기계요소를 골라 조립하면 동력이 전달되는 모습을 볼 수 있다.

- **미션 27종** — 생활 속 기계 12, 자동차 장치 5, 자동차 구동방식 5, 기어와 구조물 5
- **탐구 실험실 8종** — 자전거·자동차 기어 변속, 자동차의 동력 전달, 풍동 실험, 엔진의 작동 원리, 엔진의 종류, 증기 기관, 우물 손펌프
- **기계요소 도감** — 22가지 부품을 돌려 보며 역할·쓰임새 익히기
- **단원 퀴즈** — 10문제로 분류·이름·쓰임새 점검
- 밝음/다크 테마, PC·태블릿·모바일 대응

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

기술 스택: Vite 5, TypeScript, Three.js 0.170, cannon-es.
